# 侧栏组织状态持久转换

> 侧栏组织状态的严格 DTO 与容错恢复边界。

## 决策与红线

- **有序槽位记录**：按钮与打开视图使用有序 `slot/view` 记录，重复视图与同槽多开由领域校验判定，不在结构解码时经映射合并。原因：严格 DTO 必须拒绝领域损坏，容错恢复又必须保留确定归一所需的顺序事实。边界：规范编码只接受有效状态；重复 JSON 字段仍属结构损坏，容错恢复不得复用严格解码器静默放宽。
- **恢复分流与聚合**：高版本与未知类型先于字段恢复分流；仅当前版本执行任意层级重复字段检查和独立字段恢复。原因：高版本必须保留原数据，当前版本结构损坏不得被字段容错掩盖。边界：未知项过滤、重复项保留首次、同槽打开冲突保留首次并聚合警告；缺失注册视图按默认槽位和注册顺序合并不警告，打开意图跟随归一后的实际按钮槽位。

## 验收与测试

- 新增持久损坏形态必须分别覆盖严格 DTO 错误分类与恢复后的字段级结果；定向测试遵循 `slterm_sidebar` 根指令。
