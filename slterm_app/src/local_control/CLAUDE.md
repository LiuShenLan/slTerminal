# LocalControlServer

> 仅监听 loopback 的本机控制面；OS 单实例锁、GPUI 前台与凭据门面分别归各自所有者。

## 决策与红线

- **首包认证**：连接首条请求必须是 `runtime.hello`，版本、client_id、凭据和 handover 作用域全部有效才开放 `instance.handover`；认证失败直接断开，不返回协议预言机，不记录请求行或凭据。
- **有界传输**：请求上限 128 KiB，握手读取限时 5 秒，后续读取限时 600 秒；单连接顺序处理，连接上限 64。超限或无效请求不得进入应用回调。
- **线程所有权**：accept 与连接 worker 均有显式句柄和 shutdown 路径；关闭拒绝新请求，唤醒 accept、断开活跃连接并 join，不留孤儿线程。首个 join 终止错误必须由 server 保存并在后续 shutdown/Drop 重放，正常重复关闭仍返回成功。不得在 GPUI 前台执行监听、读取、写入或 join。
- **客户端前台禁令**：同步 handover 客户端只在创建 GPUI 前的第二实例启动路径调用；更晚的调用点必须改用后台执行体，禁止 GPUI 前台阻塞。原因：客户端包含有界但阻塞的连接、写入与读取。边界：本切片不接启动链，后续接线不得绕过此前提。
- **凭据写入所有权**：仅已持 OS 单实例锁的首实例可加载或创建 Runtime/handover 凭据，客户端只读加载，缺失返回 NotFound，绝不生成或写入。原因：以单写入者避免首次创建竞态，不另设互斥锁。边界：空值、长度或编码非法的持久凭据明确失败，不自动覆盖或轮换。
- **首实例服务组合**：控制面服务只能在已持 OS 单实例锁时启动，顺序固定为 handover 凭据、loopback listener、本次发现记录；任一步失败必须回收已建资源，不得留下监听或新端点。发布失败保留发布根因与错误 kind，同时聚合 listener 回收错误，不得静默丢弃。原因：第二实例只能观察到完整可用的本次服务。边界：启动、显式关闭与 Drop join 都只能在 GPUI 外执行，后续接线不得把这组阻塞生命周期放到前台。
- **真实运行合同**：hello 的持久世代取工作区元数据，流世代取本次 `run_id`，新事件流 revision 从零开始；发现记录使用同一 `RunMarker` 与实际绑定端点，散列按外部合同从随包 schema 原始字节推导。原因：客户端必须核对真实运行与合同版本，占位值会伪造世代或兼容性。边界：不得另造运行身份、读取第二份元数据或修改 schema 字段。
- **回执有界等待**：server 回调只经 `app_shell::try_send_handover` 投递，worker 等待回执的生产上限为 4 秒；超时映射 NotReady，回执发送端断开映射 Closing，helper 错误原样返回。原因：客户端总 deadline 为 5 秒，服务端必须更早给出结构化终态且不能无界占用 worker。边界：不在回执等待后追加无界 join。
- **统一关闭**：服务显式 shutdown 必须依次尝试 server shutdown 与发现撤销，前者失败不得跳过后者，汇总首个错误；重复调用保持安全，Drop 仅尽力。原因：监听与发现记录是同一服务的两个可观察资源，不能只回收一半。边界：正常退出必须显式调用并处理错误，不能依赖 Drop。
- **发现记录无凭据**：端点发现只使用 Runtime v2 封闭 DTO，读取预算 4 KiB；发布经原子写收敛为仅当前用户的受保护 DACL，guard 绑定文件身份与内容，撤销排除所有其他读写句柄并把最终组件按 reparse 点自身打开，显式撤销上抛错误，Drop 只尽力清理。原因：端点可供本机客户端发现，但 token 不得进入普通文件，旧实例不得误删替代记录或链接目标，delete-pending 不得伪装为目录项已撤销。边界：客户端只读；损坏、未知字段、非 loopback、零端口与超限记录一律失败，正常关闭必须先显式撤销。
- **能力边界**：当前只实现 hello 与 handover，不添加 Runtime 占位方法。路径授权、项目选择和窗口行为由后续 AppRoot 接线复核，不在传输层扩权。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests local_control -- --test-threads=1`。
- 使用临时 loopback 端点、内存凭据库与 `sk-test` 假凭据，覆盖有效握手、真实运行世代与随包散列、Focus 接受、结构化 Closing、事件与回执断连、短超时注入、QueueFull、发布失败回收与回收错误聚合、重复终止错误、在途回执关闭、双失败关闭与端点撤销；另覆盖错误凭据、首包越序、超限请求与活跃连接 shutdown。断言真实线程退出，不访问真实用户数据根。
- 发现记录覆盖发布读取、损坏与超限、所有权撤销及写失败保旧；用真实 Win32 ACL 查询断言禁止继承、唯一当前用户 ACE 与宽 ACL 替换收敛，用真实 NTFS junction 覆盖 reparse 点防护，不得跳过。文件符号链接的权限边界与兜底见测试豁免表。
