# LocalControlServer

> 仅监听 loopback 的本机控制面；OS 单实例锁、GPUI 前台与凭据门面分别归各自所有者。

## 决策与红线

- **首包认证与双作用域**：连接首条请求必须是 `runtime.hello`，协议版本、client_id 与作用域凭据全部有效才完成握手；Runtime 与 handover 使用两项独立凭据，同一连接只接受自身作用域的方法，作用域不匹配或方法不属于该作用域直接断开。认证失败不返回协议预言机，不记录请求行或凭据。原因：两个作用域的安全边界不同，凭据混用会把移交意图提升为 Runtime 能力。边界：路由与能力摘要以方法注册表的 `scopes` 为唯一判据，hello 能力与 describe 按已认证作用域收窄；注册表只登记真实可用方法，不为未实现方法保留路由。
- **有界传输**：请求上限 128 KiB，握手读取限时 5 秒，后续读取限时 600 秒；单连接顺序处理，连接上限 64。超限或无效请求不得进入应用回调；认证后解析失败在可取到 `id` 时返回封闭 `InvalidRequest` 并保留连接，首包与无法解析 `id` 的帧才断开。
- **线程所有权**：accept 与连接 worker 均有显式句柄和 shutdown 路径；关闭拒绝新请求，唤醒 accept、断开活跃连接并 join，不留孤儿线程。首个 join 终止错误由 server 记录并在首次 shutdown 返回；资源已回收后的重复关闭只记录日志并返回成功，避免一次 join 失败永久阻断退出。不得在 GPUI 前台执行监听、读取、写入或 join。
- **客户端前台禁令**：同步 handover 客户端只在应用创建 GPUI 前的第二实例启动路径调用；更晚的调用点必须改用后台执行体，禁止 GPUI 前台阻塞。原因：客户端包含有界但阻塞的连接、写入与读取。边界：发现、只读凭据加载与客户端移交依次完成，任一失败均终止第二实例，不得返回可创建窗口的实例 guard。
- **启动意图映射**：封闭启动状态只允许持锁 Primary 与已接受 HandedOver；显式工作目录仅在锁冲突时校验并转为绝对 UTF-8 打开项目，缺省为聚焦既有实例。原因：首实例的坏目录回退与第二实例的明确移交语义不同，失败分支不能携带窗口创建所有权。边界：Primary 不预校验移交目录；仅锁原语的 `Ok(None)` 进入移交，普通 I/O 错误直接上抛，`ErrorKind::AlreadyExists` 不是冲突判据。
- **凭据写入所有权**：仅已持 OS 单实例锁的首实例可加载或创建 Runtime／handover 凭据，客户端只读加载，缺失返回 NotFound，绝不生成或写入。原因：以单写入者避免首次创建竞态，不另设互斥锁。边界：空值、长度或编码非法的持久凭据明确失败，不自动覆盖或轮换；唯一写入例外是 Runtime 轮换维护子命令，它先取得同一实例锁、冲突即明确失败，且只轮换 Runtime 作用域，handover 凭据与目标保持不变。
- **首实例服务组合**：控制面服务只能在已持 OS 单实例锁时启动，绑定顺序固定为 handover 凭据、loopback listener；此时保留本次发现记录但不发布，只有窗口可服务后的显式开放才原子发布。发布幂等；发布失败必须立即回收监听与事件环，保留发布根因与错误 kind，并逐项聚合两处回收错误，不得静默丢弃任一失败或重发死端点。原因：第二实例只能在首帧可服务后观察到完整可用的本次服务。边界：绑定、开放、显式关闭与 Drop join 都只能在 GPUI 外执行。
- **真实运行合同**：hello 的持久世代取工作区元数据，流世代取本次运行身份，新事件流 revision 从零开始；快照 revision 取事件环当前末尾并原子更新，不再固定为握手起点；发现记录使用同一运行标记与实际绑定端点，散列按外部合同从随包 schema 原始字节推导；handover 客户端同时核对发现记录协议版本与 hello 的协议／schema 散列，失配在发送移交意图前退出。原因：客户端必须核对真实运行与合同版本，占位值会伪造世代或兼容性。边界：不得另造运行身份、读取第二份元数据或修改 schema 字段。
- **回执有界等待**：server 回调只经 application 单点 helper 投递移交请求，worker 等待移交回执的生产上限为 4 秒；超时映射 NotReady，回执发送端断开映射 Closing，helper 错误原样返回。Runtime 写派发按意图分级等待：普通写 4 秒、Agent 启动 12 秒、应用关闭 120 秒、快照 2 秒；超时或回执通道断开一律记结果未知，不写成功或可重试失败。原因：客户端总 deadline 为 5 秒，服务端必须更早给出结构化终态且不能无界占用 worker；关闭必须等到保存与本地冲刷落定。边界：不在回执等待后追加无界 join。
- **统一关闭**：服务显式 shutdown 必须依次尝试 server shutdown 与发现撤销，前者失败不得跳过后者，汇总首个错误；重复调用保持安全，Drop 仅尽力。原因：监听与发现记录是同一服务的两个可观察资源，不能只回收一半。边界：正常退出必须显式调用并处理错误，不能依赖 Drop。
- **发现记录无凭据**：端点发现只使用 Runtime v2 封闭 DTO，读取预算 4 KiB；发布经原子写收敛为仅当前用户的受保护 DACL，guard 绑定文件身份与内容，撤销排除所有其他读写句柄并把最终组件按 reparse 点自身打开，显式撤销上抛错误，Drop 只尽力清理。原因：端点可供本机客户端发现，但 token 不得进入普通文件，旧实例不得误删替代记录或链接目标，delete-pending 不得伪装为目录项已撤销。边界：客户端只读；损坏、未知字段、非 loopback、零端口与超限记录一律失败，正常关闭必须先显式撤销。`slterm runtime discover --json` 是唯一输出 Runtime token 的入口：端点记录与凭据域只读加载后经协议 DTO 序列化（Debug 脱敏），不带 `--json` 只打印非敏感元数据；CLI 不接受 token 参数、环境变量或命令行注入。
- **Operation 派发与查询**：写操作参数散列只经协议 crate 的 `params_sha256`；派发顺序固定为登记 → Running → 执行 → 终态，登记与推进只经唯一工作区写线程的封闭命令，本模块与 server 不直开 SQLite。相同幂等键与参数散列返回原 Operation 且执行体不重跑；同键不同参数映射 `mutation_conflict`；线缆 `expected_revision` 与事件环当前末尾 revision 原样进入派发器，在登记前复核，失配映射 `revision_conflict` 且不消耗 mutation_id。无法证明副作用的执行体必须返回结果未知，该终态可查询、禁止自动重发；启动维护把当前世代遗留 Queued 收敛为 Failed、Running 收敛为结果未知，旧世代与终态不改写。`runtime.operation_get` 与 `runtime.operation_wait` 只读持久记录；wait 在 worker 内 100 毫秒轮询、受 600 秒上限与关闭状态约束，超时 NotReady、关闭 Closing，持久记录不存在映射 `unknown_operation`。原因：断线重查与幂等命名空间必须只由一份持久事实裁定。边界：派发器只在后台 worker 同步等待有界回执；前台与 GPUI 线程禁止调用；写方法族接入时只负责构造请求与执行体，不另建写通道。
- **有界读取**：终端、Git diff 与 Agent 读取共用同一分页语义：单页正文预算 160 KiB（按 JSON 最坏六倍转义后仍低于 1 MiB 响应上限，并为信封留裕度）、切分点保持在完整 UTF-8 字符边界、预算内优先收束在行尾、超预算单行也必须前进。游标是服务端生成的不透明文本，绑定稳定资源身份、资源代次与输出 revision；任一变化、跨资源复用、非 UTF-8 字符边界、非法文本或越界都返回 `StaleCursor`，客户端必须重新读取而不是拼接旧页。尾部仍有内容时必须返回续读游标，禁止把截断内容伪装成完整结果。续页从有界不可变全文缓存切片，按条目数与总字节双上限 LRU 淘汰；终端续页先以最近帧 revision 验真，Git diff 续页先以两侧源字节指纹验真，失配仍返回 `StaleCursor`，不得以旧快照绕过 revision 失效。原因：三种读取共享同一响应预算与失效规则，第二套分页会造成游标语义漂移；每页重物化会让读取成本随页数放大。边界：本模块只做纯切分，不读取文件、PTY 或网络；真实读取与快照捕获由各方法族在后台完成；终端读取游标绑定 worker 最近发布的帧 revision；验真端口不可用时退回完整读取而不伪造缓存命中。非分页响应（如快照、Git 状态）编码后超过 1 MiB 时返回封闭 `ResponseTooLarge` 并保留连接，不得静默断开。
- **事件环与订阅**：事件环线程独占事件环（容量 1,024）与订阅表；发布与订阅都经容量 64 的命令通道进入，AppRoot 只持有非阻塞发布器，队列满丢弃事件而不反压前台。每订阅客户端队列容量 64，滞后客户端只移除自身订阅并使接收端断开，不影响其他订阅、UI 或 PTY；订阅写线程发现事件源结束立即置完成标记，连接线程在下一次读超时关闭连接，不留下静默长连接。续传必须同时匹配 `store_epoch + stream_epoch + since_revision`，积压超过客户端队列同样返回 `resync_required`。订阅连接只承载事件：独立写线程推送通知，worker 只等待取消订阅或断开；取消确认与事件写共用写锁，连接结束时先关闭流再 join 事件线程。关闭顺序为 server → 发现撤销 → 事件环 join，任一失败不跳过后续。原因：事件发布、订阅与回收必须有单一所有者，过期事件不得回填。边界：事件负载只含 revision、类型名、资源身份与代次；正文、正文长度与凭据禁止进入事件；发布点在 AppRoot 前台状态提交成功之后。
- **写意图单点**：Runtime 写方法只构造封闭写意图（稳定身份与已校验输入），server 解析稳定 UUID、ViewKey JSON 或组身份失败即 InvalidRequest；执行体把意图经壳事件交给 AppRoot，复用项目命令与既有布局转换，不另建项目、布局或关闭通道。每次写都先经派发器登记 Operation 再执行；相同幂等键与参数返回原记录，执行体不重跑；执行回执超时或断开记为结果未知，等待方只得到可查询结果。原因：控制面不得形成第二套写路径或伪成功入口。边界：写意图只服务当前已登记方法；新增方法必须先有真实命令与 AppRoot 接线；参数散列只使用规范字段，视图身份必须可无损编码；面板身份不暴露运行期 PanelId；终端输入直接复用终端视图的 worker 命令，不在控制面另建 PTY 写通道。
- **能力边界**：Runtime 作用域当前覆盖 hello、describe、snapshot、Operation 查询与等待、事件订阅与退订、项目列表与写方法、面板组与面板写方法、终端写方法与分页读取／等待、Agent 读写方法、Git 读／破坏写／打开方法、应用聚焦与关闭；handover 作用域只覆盖 hello 与实例移交。方法清单、线缆名、作用域、副作用类别与 schema 只以协议 crate 的方法注册表为真值，describe 由 server 直接用注册表与握手同一散列回答，不回调前台；新增方法先登记注册表，再接线服务器与 AppRoot，不添加占位方法。原因：控制面只转发封闭意图，项目选择、原子启动、授权与窗口行为必须由 AppRoot 单点复核。边界：仅成功后前置窗口并返回 accepted，不得隐式创建项目或改投活跃项目；snapshot 不得返回 PTY、输出、正文、凭据或非 Unicode 路径的有损替代。
- **终端语义**：输入把 `data` 原样写入 PTY（不追加回车、不模拟键盘事件）；执行只接受不含 `\0\r\n` 的单行命令并由服务端追加一次回车；两者都按稳定终端身份与 PTY 代次定位，记录非 Launch、Registry 无目标、代次不匹配或面板缺失均为 NotReady，不猜测重连后的新进程。读取复用同一身份与代次校验，只读允许已退出但保留画面的终端；前台只把读取命令入队并把应答端交还连接线程，文本捕获与分页都在后台完成，游标失效映射 stale_cursor。等待在连接线程内 100 毫秒轮询前台最近帧 revision，超过起始 revision 即返回；每轮非阻塞探测连接 EOF，客户端断开立即按 Closing 结束，超时 NotReady，默认与上限均为 600 秒。关闭经写派发器复用既有终端关闭协调器，请求代次必须等于快照中的当前 PTY 代次（无 worker 为零），失配映射 revision_conflict；未知终端为 InvalidRequest。重连复用同一焦点重连实现分发到稳定身份，只接受已退出终端；运行中映射 NotReady，成功分配新代次。重命名在候选快照更新自定义标题并复用同一持久提交，空白、超过 128 字符与未知终端均为 InvalidRequest，`null` 表示清除。原因：原始输入与显式执行是两种语义，身份与代次不得命中另一进程。边界：schema 只保证结构与范围，运行意图与代次匹配由 AppRoot 裁定。
- **Agent 与 Git 语义**：Agent 列表与获取经同一前台资源端口派生活跃关联，获取按对外身份过滤，无匹配映射 unknown_agent；输入与关闭同时携带对外身份、稳定终端与 PTY 代次，AppRoot 重新派生该终端当前身份并比对，失配映射 unknown_agent，关闭的代次失配映射 revision_conflict，写入与关闭分别复用终端输入与终端关闭链；读取与等待复用终端分页读取与等待端口，但由 AppRoot 在同一处校验身份后才访问 worker。启动、恢复与分支先经 AgentCatalog 解析 CLI 或校验会话身份构造命令，再复用新终端创建链并在首个真实提示符注入一次，回执等待注入落定，明确失败为 NotReady，View 取消或销毁由派发器记为结果未知；未知 CLI、不支持的恢复／分支能力与非法会话身份均为 InvalidRequest。Git 状态前台只解析项目与仓库入口，仓库命令由连接线程在 Git 门面后台执行；porcelain v2 快照映射为封闭条目，访问拒绝映射 Unauthorized、其他读取失败映射 NotReady，错误不携带命令输出或路径。Git diff 只接受无 `..` 的仓库相对路径，后台以固定版本与有界工作区读取构造同一差分输入并渲染为仅含变更行的文本；revision 取正文 SHA-256 前 8 字节，旧游标在内容变化后返回 stale_cursor，二进制、非法编码与超限明确失败。回滚与删除是破坏写：前台只解析项目与写授权并返回目标，状态重检与写盘在连接线程的 Operation 派发内完成，成功后尽力通知前台刷新同一项目的 Commit 视图；声明形态不成立映射 revision_conflict 且不写盘，项目根外路径映射 Unauthorized，回收站不可用映射 NotReady 且不隐式升级为永久删除。打开 Diff 与打开已删除在连接线程复核状态映射并捕获仓库绑定，再经壳事件让 AppRoot 复用 Commit 同一打开链；映射不一致为 InvalidRequest；事件已投递后回执超时或断连一律映射可查询的结果未知，不写成可重试失败。原因：Runtime 与面板必须消费同一 Git 状态与写语义。边界：Git 访问与打开不另建执行体或落点。
- **应用与面板语义**：应用聚焦只把主窗口带到前台并请求重绘。应用关闭只接受封闭的 documents（save／discard）与 hooks（discard）策略：存在脏 Document 或 Hooks 草稿而策略缺失时返回 decision_required，不弹模态、不丢弃、不开始关闭；策略齐备后复用带显式决定的应用关闭链，无 writer 且需要保存时明确 NotReady；运行终端没有保留策略，关闭按作用域停止目标 PTY。成功回执延迟到全部保存、PTY 停止与本地持久冲刷落定，保存失败回失败并保持现场；进程退出期间连接可能先断开，结果不明由派发器记为可查询结果未知，不得把未落定的关闭伪装成成功。项目移除对项目范围最后引用的脏 Document 与 Hooks 草稿要求显式策略：缺少时返回 decision_required 且不开始关闭；hooks=discard 先清项目草稿，documents=save 走项目关闭保存阶段后再提交删除意图。面板关闭只关闭目标视图并复用同一批量关闭链：视图必须属于活跃项目布局，最后引用的脏 Document 缺少策略时返回 decision_required，未活动项目或不存在视图为 InvalidRequest／NotReady。打开文件复用真实文档打开链，回执在打开落定后发送；相对或非法路径为 InvalidRequest，项目根外路径为 Unauthorized，类型不支持为 InvalidRequest。保存只接受编辑器或 Markdown 视图，回执由唯一保存链在写盘落定后发送；布局外视图、未知 Document 与非文本视图为 InvalidRequest，保存失败为 NotReady。原因：非交互关闭不得静默丢弃正文或草稿，打开与保存不得出现第二执行路径。边界：服务端不得弹模态或自动丢弃，策略由调用方以新 mutation_id 重试。

## 验收与测试
