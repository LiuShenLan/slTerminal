# Markdown 安全资源

> Markdown 的 SVG 静态光栅化、本地图片授权与有界解码缓存。

## 决策与红线

- **单向安全链**：SVG 先经 core 白名单 XML 投影，再由禁用外部图片、字体和网络的光栅化器输出静态像素；源 XML 不进入视图。本地图片只经 `PathOperation::ResourceRead` 的持久授权与真实文件身份复核。原因：文档可读或路径可解析均不等于资源可读。边界：远程 URL 与链接分派不属于本模块当前切片。
- **预算与缓存**：单资源编码字节、解码分配、像素面积和缓存字节均有上限；动画只解出静态首帧，失败不伪造图片。缓存键绑定规范位置、文件身份和内容版本。原因：缓存不得跨文件替换或未授权资源复用。边界：后台执行与 GPUI 图片适配由视图接线，前台不得调用阻塞读取。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests markdown -- --test-threads=1`。
- 必测面：危险 HTML／SVG、DTD／实体／外部引用、根外文档相邻图片、文件替换、尺寸与字节预算、静态首帧和 LRU 内容版本失效。
