# Markdown 安全资源

> Markdown 的 SVG 静态光栅化、本地图片授权与有界解码缓存。

## 决策与红线

- **单向安全链**：SVG 先经 core 白名单 XML 投影，再由禁用外部图片、字体和网络的光栅化器输出静态像素；源 XML 不进入视图。本地图片只经 `PathOperation::ResourceRead` 的持久授权与真实文件身份复核。原因：文档可读或路径可解析均不等于资源可读。边界：远程 URL 与链接分派不属于本模块当前切片。
- **预算与缓存**：单资源编码字节、解码分配、像素面积和缓存字节均有上限；动画只解出静态首帧，失败不伪造图片。本地、远程与 data 图片共享同一 LRU；本地键绑定规范位置、文件身份和内容版本，远程键绑定 DocumentId、精确 URL、授权代次和内容版本。原因：缓存不得跨文件替换、未授权资源或授权代次复用。边界：后台执行与 GPUI 图片适配由视图接线，前台不得调用阻塞读取。
- **远程单次授权**：未点击只查询成功缓存；新 URL、Document 或代次必须重新点击，失败不缓存并允许显式重试。HTTP 只发起一次零重定向请求，10 秒总超时，不使用环境代理，不携带凭据、Cookie 或 Referer；`srcset` 候选各自使用独立 URL 键。data URL 使用标准流式解码并复用相同格式与预算，非图片媒体拒绝。
- **链接分派**：锚点只消费 Comrak 投影的已解析目标；HTTP／HTTPS、mailto、tel 经可注入系统端口打开。其他协议拒绝；本地路径先尝试持久 Read，显式点击的根外目标只获得精确文件 Session Read，不派生写、资源或终端能力。该授权由 AppRoot 按 DocumentId 保活到最后布局引用，只并入链接读取与 watcher 外部刷新，重启不持久化。已解析链接与普通打开共享同一 FIFO；跨文件 fragment 只在目标当前 revision 的 Comrak 投影中解析，不存在锚点不得滚动。链接仍经统一 Document 打开服务，不另建面板或读盘通道。
- **本地位图公式**：公式只经既有 `compile_formula_source` 与 `bitmap::compose` 生成不可变 BGRA；缓存键覆盖源码散列、行内／块级、名义字号、DPI、缩放、主题 revision 和实际颜色。主题变化产生新键而不改文本；失败保留原源码与封闭原因，不生成伪位图。原因：缓存不得把旧公式、旧主题或旧缩放结果用于新请求。边界：后台计算与 Document revision 丢弃由渐进渲染接线，前台不得直接执行编译或光栅化。
- **渐进调度**：超过 5,000,000 字节或 100,000 行时持久渲染态不得覆盖默认源码降级；当次显式授权才进入渐进渲染，超过 50,000,000 字节始终禁止。视口与 overscan 只生成有限块任务，每个任务携带 Document revision 和独立渲染代次；同一 revision 的滚动保留已渲染结果并跳过重排，只有 revision 变化或显式取消才换代与清缓存；来源按 Rope 字节区间切片，不复制全文。取消或重排后旧回执丢弃，单块失败仅回退该块原始源码。原因：大文档不得因恢复状态或迟到任务阻塞或污染当前正文。边界：实际后台执行与 GPUI 虚拟列表由块视图接线，倒置或空视口不得产生任务。

- **双态与共享正文**：Markdown 首开使用渲染态；源码与渲染共享同一 DocumentSession，源码编辑经 AppRoot 同步事务入口，渲染态只读且没有块级编辑。两态共用稳定 FocusHandle 与 ViewState 租约；源码子视图只更新源态度量，不提供独立语言覆盖，不得覆盖渲染阅读状态。原因：切换不得读盘、丢草稿或产生第二撤销／保存链。边界：大文档降级优先于持久形态，当次显式覆盖不持久化。
- **渲染态键盘**：`Ctrl+Shift+O` 切换大纲；方向键与 PageUp／PageDown／Home／End 只滚动渲染列表，源码态一律传播给内嵌编辑器；`Alt+↑`／`Alt+↓` 按文档顺序循环链接焦点并滚入视口，`Alt+Enter` 激活焦点链接，`Escape` 清除；焦点链接以选区色标识，大纲按钮经 Tab 可达并在工具提示展示快捷键。原因：键盘与辅助技术用户需要完成形态、滚动、链接、大纲、查找和重置全路径，且不得与源码编辑器键位抢占。边界：链接焦点不进入持久状态，正文变化即清空。
- **大纲浮层与层级**：大纲项按标题深度逐级缩进且同级对齐；大纲是覆盖在正文右侧的浮层，不参与内容行宽分配，关闭前后正文宽度不变。原因：层级是大纲的核心信息，固定侧栏会永久压缩长文档阅读区。边界：浮层宽度固定，不覆盖标题层级以外的结构（列表、表格）。
- **阅读状态与虚拟化**：形态、大纲、25%–400% 缩放和标题锚点／相对块序／块内偏移按完整 ViewKey 保存；锚点消失按比例回退，选区、查找、焦点、菜单和当前 revision 的 BlockId 不持久化。虚拟列表只调度可见块与 overscan，后台回执绑定 Document revision 和渲染代次；普通文本与代码块选择复制只读 Comrak 可见文本，查找只在同一可见文本上匹配。原因：恢复不得依赖失效块身份，渲染不得扩大资源或编辑权限。
- **视图资源任务**：图片与公式服务由 AppRoot 共享；可见本地／data 图片和公式在后台生成静态位图，远程图片只有显式点击才请求。任务由视图持有，按请求序号与 revision 对账；视图只强持当前 revision 的可见／overscan 块位图，离屏、源码态、路径变化、缩放与正文变化取消或失效旧任务并释放不再可见的位图，重新可见须经共享服务复核内容版本。原因：缓存共享不等于授权共享，迟到结果不得污染当前正文，视图不得绕过共享 LRU 形成无界位图缓存。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests markdown -- --test-threads=1`。
- 必测面：危险 HTML／SVG、DTD／实体／外部引用、根外文档相邻图片、文件替换、尺寸与字节预算、静态首帧和 LRU 内容版本失效；远程点击前零请求、精确 URL／Document／代次隔离、失败重试、逐出重授权、真实回环请求头与零重定向；data 非图片拒绝、锚点与危险协议分派、根外链接精确会话读授权、统一 FIFO 与跨文件 fragment；公式缓存键与失败源码保留；大文档阈值、当次覆盖、视口分片、代次丢弃与单块源码回退；双态共享最新正文、统一自动保存、真实 SQLite 渲染阅读位置恢复、行内与代码块真实拖选复制、查找导航、Ctrl 缩放、资源视口回收与瞬态字段拒绝。
