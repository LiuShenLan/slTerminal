# text_view

> Document、Markdown、Diff 与分页只读内容的专用 GPUI 文本视图。

## 决策与红线

- **正文不复制**：实时正文只归 DocumentSession；视图只持不可变 Rope 展示快照与选区、光标、滚动、折叠、布局缓存，禁止第二份可写正文。可见行可以按需物化，分页正文只经授权后台读取与页缓存进入视图。GitShow 固定快照经无 Editor 租约的只读入口复用同一文本实现，不注册 DocumentRegistry，不持久化搜索、滚动、选区或焦点；其内部子视图共享面板永久 FocusHandle，加载形态切换不得使焦点注册失效。
- **编辑同步对账**：输入法编辑经注入的同步端口提交 DocumentRegistry，成功后在同一调用内回投权威快照，再更新选区与组合范围；不得先按未接受事务改写瞬态，也不经排队事件猜测下一 revision。原样普通替换不重置选区；原样 IME 提交仍应用组合内选区并清除组合态。共享 Document 的普通外部编辑必须携带原事务以重定位选区与组合范围；无增量的快照更新取消组合并复位选区，禁止把旧字节偏移直接套到新正文；滚动行/列保留当前阅读位置，越界行只按新正文夹紧，不得把视口拉回光标顶部。删除、换行与撤销／重做复用同一同步端口；历史移动不产生编辑增量，因此复位视图瞬态，空历史或拒绝请求保持原状态。
- **生产事务与保存端口**：普通源码编辑 sink 携带来源 EntityId，由 AppRoot 同步写唯一 Registry 并向其余视图广播真实事务快照；视图不得直接持有 Registry 或跨项目正文副本。`Ctrl+S` 只发出 Save 事件，保存任务、写盘与回执由 AppRoot/core 闭环。
- **坐标按字素**：UTF-8 字节、Rope 行与显示列转换不得拆分字素簇；IME 组合文本与普通输入共用同一事务入口，CJK、组合字符与 emoji 共用同一显示宽度实现。系统输入中的 CRLF 在计算范围前统一为 LF，字素内部的显式选区或替换范围明确拒绝。键盘左右移动按完整字素跨行，纵向移动保留目标显示列，Shift 只扩展选区；组合期间移动命令不改变选区。
- **前台绘制有界**：canvas 必须裁剪横纵溢出；Rope 长行只物化并 shaping 与可视列窗口相交的完整字素，Paged 经共享页句柄保留跨页字素文本，页接缝重建游标并先判定边界，避免上游 RI 预上下文重复计数；窗口在接缝前满足后不再读取续页，不得仅因重绘复制或 shaping 不可见部分。光标移动同时调整横纵滚动，窗口起点可以落在宽字素中间，绘制与命中测试仍使用实际显示列。
- **Rope 软换行**：wrap 开启时按视口完整显示列切分完整字素，`scroll_line` 表示显示行而非逻辑行；纵向移动、Home／End、鼠标命中、IME、滚动与光标可见性共用同一显示行索引。索引在后台按 TextStateId 与宽度构建，调度与最终校验只使用本帧 prepaint 的实际宽度；只保存逻辑行和固定间隔的稀疏段检查点；查询按字节或显示行二分，单段最多续扫一个检查点窗口，旧索引不得服务新正文或新宽度。显式编辑或移动在索引未就绪时记录待 reveal，有效回投后统一消费；toggle 后尚未转换时只能保存确定的显示行 0，不得混入旧逻辑行；视图 Drop 必须显式清空任务槽，打破 future 对任务槽的持环并取消在途构建。共享折行边界使用瞬态 CaretAffinity，双向裁剪都不得把光标画到另一段；Tab 保留逻辑行显示列。只有可见段物化与 shaping，布局缓存同时包含 wrap 开关；索引未就绪时不得按逻辑行数夹紧或回写恢复位置。`EditorViewState` 明确携带 `scroll_unit`：所有写入方持久化**逻辑行**，Editor 软换行下由索引把显示行换算成逻辑行后写入，恢复时先把逻辑行挂为待揭示目标，索引完成后换算显示行；Paged 只接受 `LogicalLine`，显示行记录无法在无全文索引时换算，退回顶部且不反写。分页软换行正式延期：全文显示行索引需要随文件长度与视口宽度重建，超出 Paged 的有界页读取模型，当前由 Rope Editor 承担软换行、Paged 承担超限只读；分页只读的行号、查找、折叠与高亮降级同属该延期面，追溯矩阵不得把未接线能力标为已自动化。解除条件 = Paged 得到有界、可后台重建的显示行索引与对应只读控件。原因：持久化开关不能替代真实布局，前台与绘制成本不得随全文或不可见段增长。边界：不得把显示行静默当逻辑行，也不得让 Paged 以本地前缀索引冒充全文换行。
- **鼠标与滚轮**：左键点选、拖拽与 Shift 点击共用同一命中测试和选区状态；丢失按键的拖动不得继续改选区。正文快照、历史移动或 IME 组合开始必须取消在途拖拽，禁止旧锚点进入新正文。滚轮按行高累计像素余量，正方向上滚、负方向下滚并夹紧真实行范围。真实 OS 手势仍按既有豁免验收。
- **剪贴板键位**：Document 文本复制只用 `Ctrl+Shift+C`，粘贴用 `Ctrl+Shift+V`；空选区复制不得覆盖既有剪贴板，粘贴复用同一编辑事务与换行归一化，只读和组合期间拒绝粘贴。
- **分页后台加载**：缺页只形成 Loading 与精确页号请求，读取经视图持有的后台 Task 调用真实分页端口；回执核对源代次与指纹后才进入共享 LRU，旧代次不得结算当前请求，失败不得逐帧自动重试，但必须显示可见失败态并提供显式重试入口。Task 禁止 detach，回调只持 WeakEntity，完成句柄在后续调度点回收；视图销毁即取消在途读取，最后布局引用消失时由 AppRoot 显式 `close`，清任务并屏蔽迟到回执，之后才回收共享缓存。纯外部改名保持源代次、页缓存与阅读瞬态，只取消旧位置的在途页请求并替换 reader，待续移动立即经新 reader 重调度；内容重载则同时更换源代次、文本请求与 reader，取消旧坐标动作和复制任务。
- **分页选区复制**：Paged 鼠标与全选只持全局 UTF-8 字素边界；复制经 `DocumentTextRequest::copy_range` 在后台读取真实分页块，不得把缓存前缀当完整选区。每次复制取消旧任务并推进代次，回执只持 WeakEntity；空选区、旧代次与读取失败不得覆盖剪贴板。
- **分页键盘导航**：方向键、Home／End 与 Shift 变体共用全局 UTF-8 字素、行和显示列坐标；纵向移动保留目标列，折叠全选等未知列须从缓存重算。目标页缺失时只保留最新待续移动，页回执后才改选区并调整滚动，禁止前台读盘或物化整行；新鼠标选择、全选、关闭或目标页失败且无可等待请求时取消旧移动。
- **语法视图单源**：`DocumentSyntax` 按 DocumentId + LanguageId 共享 worker、编译查询与最新树；单视图语言覆盖不得改写其他 ViewKey，非当前语言的缓存也须跟进编辑。事务按 core 降序应用顺序生成中间正文坐标，无增量快照与历史移动全量重建。视图只使用与当前 revision 一致的树，采纳新树才推进语言 revision 并清布局缓存；轮询 Task 只持 WeakEntity 且解析完成即退出。高亮颜色只映射既有主题语义 token，不新增裸色值。
- **布局缓存完整失效**：行布局缓存键包含 DocumentId、TextStateId、语言 revision、字体族与度量、视口／换行宽度、首个可视列、DPI 和主题 revision；任一变化只清布局缓存，不重建 Document。缓存条目有容量上限，超过时只保留最近插入行两侧的窗口，远距离滚动必须淘汰旧行，前台内存不得随阅读距离无界增长。主题 revision 由视图对实际文本相关 token 的变化推进，不能假定外部 Theme 自带代次。
- **Editor 阅读状态**：语言覆盖、Rope 软换行开关、滚动行与列按完整 `ViewKey` 经 ViewStateStore 保存和预载，普通与 Paged 共用该通道；Markdown 在同一 Store 中使用专属 `MarkdownViewState`，内嵌源码阅读字段，容器与源码子视图共享租约；Diff 使用同一 Store 中的专属 `DiffViewState`，保存固定 DiffBinding、显示模式、同步滚动、列宽、侧折叠、交换、空白模式、未变更折叠及源码 wrap／语言覆盖，滚动、选区、搜索、当前差异与临时错误均不持久化；可见性复核成功的 HEAD 身份经同一 DTO 检查点推进，失败不改写，源码子视图与 Diff 共享租约且滚动检查点不得覆盖展示参数。Markdown／Diff 因外部重载转为 Paged 时沿用原 ViewKey 与对应 DTO，不改写为 Editor 身份。语言选择器经 AppRoot 模态焦点链接入，覆盖只改变本视图高亮；外部改名只更新自动语言，手动覆盖保持不变。选区、目标列、IME、鼠标拖拽与待续动作不得进入 DTO。恢复的滚动行夹到正文行范围，滚动列夹到「源字节数 × 每字节最大显示列数」的上界（Tab 展开上限 4 列），Editor 与 Paged 同规则；坏记录不得以 `usize::MAX` 进入绘制或命中测试。只有实际覆盖、wrap 切换或滚动变更才写盘，启动默认态与未编辑恢复态不得自动回写；普通队列拒收保留终态副本，项目关闭 StateCommitted 后旧实体的迟到检查点与 Drop 不得复活记录；外部形态转换构造失败时须重新签发仍存活旧视图的租约，不得让回滚后的阅读状态静默失写。

- **Editor Git 行标**：编辑域固定预留行标槽位，宽度不随瞬态行标显隐变化；行标只是 AppRoot 注入的最新 core 差分投影（行号＋新增／修改／删除语义，删除用细条、新增/修改用主题 success/warning 语义色），不属于正文、布局缓存键或持久 ViewState；越界旧行号不得进入绘制；任一 `TextStateId` 变化立即清空旧行标，后台新结果按当前代次重新投影。行标点击只发 `OpenGitDiff { line }`，视图不读取 Git、不计算差分；普通与软换行布局共用同一逻辑行定位，越界旧行号不得进入绘制。

- **阅读辅助瞬态**：代码折叠区域只从共享语法树的当前语言 fold query 派生，按逻辑行闭区间保存，起始行保持可见；折叠集合、行号、当前行、括号匹配、跳转行栏与候选补全全部是视图瞬态，不写 Document、不进入 ViewState。正文变化立即清空折叠集合，旧区域随之展开；新语法树到达只保留仍有效的起始行。原因：折叠是显示过滤，不是正文或持久事实，旧树行号不得在新正文上继续生效。边界：软换行下折叠区间换算为显示行；折叠/隐藏行不得进入绘制、命中测试、光标可见性或持久滚动换算；光标进入折叠区域必须自动展开。

- **编辑辅助命令**：行号槽固定按最大行号位数预留，当前行使用 accent 低权重背景；`Ctrl+Alt+G` 跳转行按 1 起算，越界夹取到 `1..=行数` 并在栏内说明实际范围，非法输入不移动光标；文档内补全只扫描当前 Rope 标识符，不依赖外部语言服务，超过 10,000,000 字节或只读时关闭，接受候选走唯一编辑事务；`Tab`/`Shift+Tab` 缩进整行或选中行，整次操作是一个撤销组。字号为进程级全局值（8–32px，默认 14），`Ctrl+滚轮` 逐像素调整且不滚动正文。查找、跳转与折叠命令进入统一命令目录；缩进与补全接受是正文输入键。原因：这些能力共享正文与命令单点，不得在面板侧另建正文或键位表。边界：只读视图保留行号、选择、复制、查找、换行与折叠，不提供编辑、缩进、补全或替换。

## 验收与测试


- 纯计算覆盖 Unicode 边界、字素宽度、软换行段、稀疏检查点有界性与 caret affinity；虚拟窗口覆盖选区、IME、布局失效、Rope wrap 切换／恢复／导航／共享边界光标、Rope／Paged 共享正文，以及 Paged 缺页后台回投、滚动请求、键盘导航与缺页续动、失败抑制、代次隔离、真实 Rust 首树、编辑后高亮与主题 token 映射。
- 编辑器能力必须走真实视图绘制、键盘动作与共享 Document 编辑入口：`rust_fold_query_hides_the_body_and_editing_expands_the_region`（真实 Rust fold query、正文不变、编辑自动展开）、`line_numbers_and_current_line_highlight_follow_the_cursor`、`go_to_line_clamps_out_of_range_and_reports_the_actual_range`、`bracket_matching_highlights_the_pair_under_the_cursor`、`document_identifier_completion_is_applied_through_the_edit_transaction`、`completion_is_disabled_over_ten_megabytes_and_in_read_only_views`、`status_bar_reports_language_encoding_bom_line_ending_and_read_only_reason`、`ctrl_wheel_zooms_shared_editor_font_between_eight_and_thirty_two`、`tab_indents_and_shift_tab_outdents_selected_lines`、`read_only_view_keeps_selection_copy_find_wrap_and_folding`。折叠、补全、查找词与跳转提示不得进入 `EditorViewState`。
- 真实 OS IME 与像素级手势不得虚称自动化覆盖，按既有豁免登记边界。
