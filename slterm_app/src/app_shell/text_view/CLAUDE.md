# text_view

> Document、Markdown、Diff 与分页只读内容的专用 GPUI 文本视图。

## 决策与红线

- **正文不复制**：实时正文只归 DocumentSession；视图只持选区、光标、滚动、折叠与布局缓存，禁止第二份实时 String 或 Rope。可见行可以按需物化，分页正文只经授权后台读取与页缓存进入视图。
- **坐标按字素**：UTF-8 字节、Rope 行与显示列转换不得拆分字素簇；IME 组合期不派发编辑命令，CJK、组合字符与 emoji 共用同一显示宽度实现。

## 验收与测试

- 纯计算覆盖 Unicode 边界、字素宽度与可见行；虚拟窗口覆盖选区、IME、布局失效和 Rope／Paged 共享正文。
- 真实 OS IME 与像素级手势不得虚称自动化覆盖，按既有豁免登记边界。
