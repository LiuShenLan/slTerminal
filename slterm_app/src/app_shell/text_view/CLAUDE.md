# text_view

> Document、Markdown、Diff 与分页只读内容的专用 GPUI 文本视图。

## 决策与红线

- **正文不复制**：实时正文只归 DocumentSession；视图只持不可变 Rope 展示快照与选区、光标、滚动、折叠、布局缓存，禁止第二份可写正文。可见行可以按需物化，分页正文只经授权后台读取与页缓存进入视图。
- **编辑同步对账**：输入法编辑经注入的同步端口提交 DocumentRegistry，成功后在同一调用内回投权威快照，再更新选区与组合范围；不得先按未接受事务改写瞬态，也不经排队事件猜测下一 revision。原样普通替换不重置选区；原样 IME 提交仍应用组合内选区并清除组合态。共享 Document 的普通外部编辑必须携带原事务以重定位选区与组合范围；无增量的快照更新取消组合并复位选区，禁止把旧字节偏移直接套到新正文。删除、换行与撤销／重做复用同一同步端口；历史移动不产生编辑增量，因此复位视图瞬态，空历史或拒绝请求保持原状态。
- **生产事务与保存端口**：普通源码编辑 sink 携带来源 EntityId，由 AppRoot 同步写唯一 Registry 并向其余视图广播真实事务快照；视图不得直接持有 Registry 或跨项目正文副本。`Ctrl+S` 只发出 Save 事件，保存任务、写盘与回执由 AppRoot/core 闭环。
- **坐标按字素**：UTF-8 字节、Rope 行与显示列转换不得拆分字素簇；IME 组合文本与普通输入共用同一事务入口，CJK、组合字符与 emoji 共用同一显示宽度实现。系统输入中的 CRLF 在计算范围前统一为 LF，字素内部的显式选区或替换范围明确拒绝。键盘左右移动按完整字素跨行，纵向移动保留目标显示列，Shift 只扩展选区；组合期间移动命令不改变选区。
- **前台绘制有界**：canvas 必须裁剪横纵溢出；Rope 长行只物化并 shaping 与可视列窗口相交的完整字素，Paged 经共享页句柄保留跨页字素文本，页接缝重建游标并先判定边界，避免上游 RI 预上下文重复计数；窗口在接缝前满足后不再读取续页，不得仅因重绘复制或 shaping 不可见部分。光标移动同时调整横纵滚动，窗口起点可以落在宽字素中间，绘制与命中测试仍使用实际显示列。
- **Rope 软换行**：wrap 开启时按视口完整显示列切分完整字素，`scroll_line` 表示显示行而非逻辑行；纵向移动、Home／End、鼠标命中、IME、滚动与光标可见性共用同一显示行索引。索引在后台按 TextStateId 与宽度构建，调度与最终校验只使用本帧 prepaint 的实际宽度；只保存逻辑行和固定间隔的稀疏段检查点；查询按字节或显示行二分，单段最多续扫一个检查点窗口，旧索引不得服务新正文或新宽度。显式编辑或移动在索引未就绪时记录待 reveal，有效回投后统一消费；toggle 后尚未转换时只能保存确定的显示行 0，不得混入旧逻辑行；视图 Drop 必须显式清空任务槽，打破 future 对任务槽的持环并取消在途构建。共享折行边界使用瞬态 CaretAffinity，双向裁剪都不得把光标画到另一段；Tab 保留逻辑行显示列。只有可见段物化与 shaping，布局缓存同时包含 wrap 开关；索引未就绪时不得按逻辑行数夹紧或回写恢复位置。原因：持久化开关不能替代真实布局，前台与绘制成本不得随全文或不可见段增长。边界：本切片只接入 Rope Editor，Paged 仍使用既有逻辑行索引，但写其他阅读状态时必须透传既有 wrap 偏好。
- **鼠标与滚轮**：左键点选、拖拽与 Shift 点击共用同一命中测试和选区状态；丢失按键的拖动不得继续改选区。正文快照、历史移动或 IME 组合开始必须取消在途拖拽，禁止旧锚点进入新正文。滚轮按行高累计像素余量，正方向上滚、负方向下滚并夹紧真实行范围。真实 OS 手势仍按既有豁免验收。
- **剪贴板键位**：Document 文本复制只用 `Ctrl+Shift+C`，粘贴用 `Ctrl+Shift+V`；空选区复制不得覆盖既有剪贴板，粘贴复用同一编辑事务与换行归一化，只读和组合期间拒绝粘贴。
- **分页后台加载**：缺页只形成 Loading 与精确页号请求，读取经视图持有的后台 Task 调用真实分页端口；回执核对源代次与指纹后才进入共享 LRU，旧代次不得结算当前请求，失败不得逐帧自动重试。Task 禁止 detach，回调只持 WeakEntity，完成句柄在后续调度点回收；视图销毁即取消在途读取，最后布局引用消失时由 AppRoot 显式 `close`，清任务并屏蔽迟到回执，之后才回收共享缓存。纯外部改名保持源代次、页缓存与阅读瞬态，只取消旧位置的在途页请求并替换 reader，待续移动立即经新 reader 重调度；内容重载则同时更换源代次、文本请求与 reader，取消旧坐标动作和复制任务。
- **分页选区复制**：Paged 鼠标与全选只持全局 UTF-8 字素边界；复制经 `DocumentTextRequest::copy_range` 在后台读取真实分页块，不得把缓存前缀当完整选区。每次复制取消旧任务并推进代次，回执只持 WeakEntity；空选区、旧代次与读取失败不得覆盖剪贴板。
- **分页键盘导航**：方向键、Home／End 与 Shift 变体共用全局 UTF-8 字素、行和显示列坐标；纵向移动保留目标列，折叠全选等未知列须从缓存重算。目标页缺失时只保留最新待续移动，页回执后才改选区并调整滚动，禁止前台读盘或物化整行；新鼠标选择、全选、关闭或目标页失败且无可等待请求时取消旧移动。
- **语法视图单源**：`DocumentSyntax` 按 DocumentId + LanguageId 共享 worker、编译查询与最新树；单视图语言覆盖不得改写其他 ViewKey，非当前语言的缓存也须跟进编辑。事务按 core 降序应用顺序生成中间正文坐标，无增量快照与历史移动全量重建。视图只使用与当前 revision 一致的树，采纳新树才推进语言 revision 并清布局缓存；轮询 Task 只持 WeakEntity 且解析完成即退出。高亮颜色只映射既有主题语义 token，不新增裸色值。
- **布局缓存完整失效**：行布局缓存键包含 DocumentId、TextStateId、语言 revision、字体族与度量、视口／换行宽度、首个可视列、DPI 和主题 revision；任一变化只清布局缓存，不重建 Document。主题 revision 由视图对实际文本相关 token 的变化推进，不能假定外部 Theme 自带代次。
- **Editor 阅读状态**：语言覆盖、Rope 软换行开关、滚动行与列按完整 `ViewKey` 经 ViewStateStore 保存和预载，普通与 Paged 共用该通道；Markdown 在同一 Store 中使用专属 `MarkdownViewState`，内嵌源码阅读字段，容器与源码子视图共享租约；Markdown／Diff 因外部重载转为 Paged 时沿用原 ViewKey 与对应 DTO，不改写为 Editor 身份。语言选择器经 AppRoot 模态焦点链接入，覆盖只改变本视图高亮；外部改名只更新自动语言，手动覆盖保持不变。选区、目标列、IME、鼠标拖拽与待续动作不得进入 DTO。只有实际覆盖、wrap 切换或滚动变更才写盘，启动默认态与未编辑恢复态不得自动回写；普通队列拒收保留终态副本，项目关闭 StateCommitted 后旧实体的迟到检查点与 Drop 不得复活记录；外部形态转换构造失败时须重新签发仍存活旧视图的租约，不得让回滚后的阅读状态静默失写。

## 验收与测试

- 纯计算覆盖 Unicode 边界、字素宽度、软换行段、稀疏检查点有界性与 caret affinity；虚拟窗口覆盖选区、IME、布局失效、Rope wrap 切换／恢复／导航／共享边界光标、Rope／Paged 共享正文，以及 Paged 缺页后台回投、滚动请求、键盘导航与缺页续动、失败抑制、代次隔离、真实 Rust 首树、编辑后高亮与主题 token 映射。
- 真实 OS IME 与像素级手势不得虚称自动化覆盖，按既有豁免登记边界。
