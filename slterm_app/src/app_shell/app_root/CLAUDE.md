# AppRoot 运行根

> 以唯一项目快照协调全部项目的运行面板、瞬时焦点与终端生命周期。

## 决策与红线

- **学习服务单源**：`AppRoot` 持有唯一 `LearningService`，每个补全 `Session` 共享其不可变快照；终端只经 Session 采集已确认命令与受管 cwd。原因：全局静态历史会形成第二写入与清空事实源。边界：不得在 TerminalView 或补全引擎另持历史文件、SQLite 连接或学习写队列。
- **项目与布局单源**：`AppRoot` 直持唯一 `ProjectSnapshot`；`projects` 只是全部 `ProjectView` 的强实体引用表，不复制项目注册、布局、逻辑终端或 Document 元数据。原因：运行实例不得成为第二项目或布局事实源。边界：`ProjectView` 只持 `PanelHost`、项目焦点容器与项目内瞬时焦点；`PanelHost` 以封闭 `PanelContent` 绑定运行视图，不得为编辑器伪造终端字段。
- **渲染只读单源**：画面只沿活跃项目的 `ProjectLayout` 树、组内 active `ViewKey` 与既有 `PanelHost` 组装；隐藏项目不挂载但继续保活，空项目不创建占位终端。原因：渲染不得派生第二布局或触发终端生命周期。边界：组内非激活视图与隐藏项目均不进入当前画面，激活与切换只复用既有实体。
- **候选原子提交**：新增与拆分先由快照产生候选，再执行一次可失败启动并登记实例，最后提交候选。原因：布局、逻辑终端记录与 PTY 不得出现半提交。边界：启动失败不保留无 worker 的占位面板，正式快照与实例表不变；PanelId 失败消耗后也不复用。
- **Document 真实打开**：打开按 FIFO 在后台只做路径解析与真实读取；前台在读取前后查重并独占注册，`DocumentRegistry` 始终留在 AppRoot，不得在打开或保存期间移出形成前台空窗。候选布局必须在编辑器实体、焦点注册与还焦全部成功后才提交并发布同一快照；同项目重复打开按完整 ViewKey 只还焦并复用既有编辑器／Markdown，Diff／GitShow 不参与普通视图去重；跨项目复用全局 DocumentId 与既有正文。编辑经来源 EntityId 标记的同步端口写唯一 Registry，并向其余视图广播权威快照，历史移动不产生增量快照；保存只由 AppRoot 按 DocumentId 持后台任务提交 core 回执，在途新请求只保留一个待保存标记，回执后接续最新快照，失败经既有通知回投原因并释放保存闸门，视图不得另存正文或直接写盘。快照提交同步回收失去全部项目引用的聚合、分页 reader 与页缓存；清理前先关闭仍被关闭流程保活的视图、取消任务并屏蔽迟到回执。超限文件注册完整分页源并安装专用视图，跨项目复用同一真实读取端口与全应用页缓存，不得以前缀 Rope 代替正文；重新打开命中恢复占位时按真实文件重读并替换占位。HTML 编辑器悬浮按钮只发事件，由 AppRoot 经有所有权的后台任务调用系统默认程序，不保存脏正文；按钮可见性按自动语言而非手动覆盖。读取、落点、焦点、项目代次失败或关闭开始均不留下空 Panel；新建聚合随失败回收，共享聚合不得误删；关闭开始同时排空未开始请求并丢弃在途回执。原因：真实 I/O、身份与布局必须一次闭合，前台不得阻塞或出现半打开状态。边界：入口只支持代码与 Markdown 文本，不为图片构造占位面板；启动正文恢复只经真实快照恢复器与同一 Registry。
- **共享正文派生视图可见性**：共享 Document 的编辑广播只投递当前可见的 Markdown／Diff 面板；隐藏面板只保留最后可见正文并取消在途解析／差分任务，不做每键全量重算。可见转换在快照提交后统一对账：新可见面板只采纳一次最新正文并重新调度，隐藏面板丢弃任务；Rope 编辑器仍接收全部共享编辑以保持保存与选区事实。原因：隐藏项目与背景页签不得随每次按键复制全文或启动不可取消的后台计算。边界：可见集合只是运行期派生，不进入持久 DTO；语言选择、保存与外部变化链不经该门控。
- **多项目 watcher 与外部变化**：`AppRoot` 持唯一 `FsWatchHandle`；前台只经有界信号提交存活 Document 与瞬态改名别名，普通文件事件与改名统一进入后台读取，目录树只由实际目录消费者登记。专用工作线程承担 notify 创建与 watch／unwatch 的同步 ACK，回调只分类并按因果顺序配对 From／To，隐藏项目继续监听。连续改名必须路由到同一 Document 并原子移除 source、登记 target，折返不得保留失效中间目标；旧 revision、位置或已被更新目标取代的回执只重试最新目标，保存与改名按 Document 双向排队，批量保存／丢弃同样等待改名完成再唤醒。后台重新解析、授权与读取后，回投必须按最新快照复核 grant 并集：`Relocated` 只重绑位置，`Reload` 更新干净正文与元数据，脏或在途保存进入共享冲突，Deleted 保留正文，ReadRevoked 携带原请求与尝试位置并停止监听。位置候选先经快照校验再提交 Registry 与同一快照；分页回执携带同批真实 reader，纯改名保留源代次与待续移动，内容变化推进代次，正文形态转换复用既有内容构造器并保持 PanelId 与 ViewKey，涉及的语言选择器先关闭并还焦，任一构造或焦点失败恢复原事实且不提交位置。原因：文件身份、持久元数据、正文与运行视图必须闭合，前台不得等待 OS watcher。边界：普通文件修改与目录刷新不因改名入口另建执行体。
- **托盘快照节拍**：壳事件泵以约 1 Hz 派生当前终端的 `TrayAgent` 快照（pane、CLI 与 cwd 尾段、`Blocked` 等待态），内容去抖后交给托盘；启用态每次节拍重投挂载请求，成为图标挂载失败后的实际重试者。原因：托盘是环境信息面，不得新增常驻 OS 定时器，也不能只声明重试而无人调用。边界：只在前台派生，不触 Win32 阻塞调用；关闭完成后停止节拍。
- **应用内通知保留面**：`Notification::ProcessAlert` 携带严重度；任何投递先进入进程级应用内队列，桌面通知开关与前台门控只影响系统 toast／闪烁，不隐藏应用内错误。`AppRoot` 事件泵排出后按文本与严重度去重展示，关闭只由用户显式操作；`Error` 映射任务栏错误并保留到关闭，`Info`／`Warning` 不发送清除信号，避免低优先级提示抹掉既有错误或等待态。原因：错误不得只留在日志，也不能被场景开关或焦点状态吞掉。边界：应用内通知不携带路径或正文之外的技术细节；启动汇总走同一队列，系统 toast 豁免前台门控。
- **侧栏状态读取合并**：Commit／Explorer 的状态读取按 `TaskId` 单任务；数据根切换推进 generation，在途期间的新请求只保留合并位，回执必须同时匹配当前项目、根与代次，旧结果丢弃后立即重投当前根，不得让新根停在加载中或把旧根汇总写入新视图。原因：单任务身份没有合并位会丢请求，缺少回执身份会错投。边界：Commit 与 Explorer 各自持有代次；合并位只消费一次。
- **局部终端关闭**：每个终端由独立 core `CloseCoordinator` 管理，close_id 使用 UUIDv7；`store_epoch` 只取启动恢复时同一工作区库读取的当前元数据，writer 存在而世代无效即拒绝；SHA-256 指纹只绑定关闭身份、作用域、世代、对象身份／代次／决定。生产顺序固定为候选收集 → 快照与关闭意图原子提交 → 按完整目标退休 worker → 后台真实 join → 持久阶段依次推进到 Panel 销毁；任一步失败不得提前销毁 Panel 或停止无关 PTY。初始提交在途或结果未知时，显式快照命令与任何新局部关闭都在焦点同步、候选构造和写请求前拒绝；无 Failed 关闭时先用只读实际焦点完成纯预检，再同步真实焦点，writer 的有效 `store_epoch` 与目标存在性也须在焦点同步和候选构造前验证，任何拒绝不得改变焦点投影、代次、普通写或待写快照；失败关闭的显式重试仍走原语义，Running 拒绝与未知结果不改判。恢复屏障期间同样拒绝新关闭；Exited 等内存更新可延期普通写，析构不得补交终态快照。成功后从最新内存快照重算关闭候选再摘除渲染与焦点注册；明确初始提交失败清除本次关闭并恢复延期写，后续失败保留 Panel 并从当前持久阶段重试；回执断连或重复任务导致结果未知时 fail-closed，不得盲目重登记。join Err 不推进持久状态，只有用户显式重试才可消费已观察到的异常终止事实，不得二次 join、重开 PTY 或记录 panic payload。回执须先核对 close 存在、attempt、目标 next 与持久前序，并完整比对 close_id、scope、store_epoch、对象与指纹后才可收割任务或改态；缺失、stale、错身份、错 next、错前序一律忽略。还焦失败只能 blur 原聚焦终端并经焦点权威同步，不得裸送工作区焦点绕过模态。局部关闭不停止全局服务、不写 `clean_shutdown`；任一局部关闭存活时全局关窗请求返回 false，全局关闭在途拒绝新局部关闭；无 writer 只允许内存测试根走同序降级。原因：关闭身份、持久阶段与 PTY 生命周期必须一次闭合。边界：局部关闭不产生全局退出事实。
- **局部关闭用户重试**：`CloseActiveTerminal` 对曾失败且未 Completed 的关闭按单调发起序号选最早项；已知 Failed 按原目标显式重试，未知结果仍拒绝，初次 Running 不进入失败重试，重试后的 Running 仍阻断后续目标。全部失败关闭 Completed 前不得解析或关闭新的焦点终端；命令目录不得因无焦点终端或无活跃项目提前阻断重试，全部解决后才恢复正常聚焦关闭。原因：持久提交后真实焦点可能已离开失败关闭身份。边界：重试只推进原持久阶段，不复活已摘除渲染，不提前销毁 Panel；多个失败按发起顺序处理，不按 TerminalId 隐含顺序选择。
- **组内批量关闭**：关闭其他／全部只构造统一命令，目标在同一 `ProjectSnapshot` 候选、同一 `CloseCoordinator` 与完整关闭意图中提交；关闭其他保留组内 active，关闭全部移除组内全部目标。含 Save 时先在前台捕获不可变保存请求，后台只执行条件写盘，前台按代次结算全部回执；任一失败保持 Failed(Save)，不提交候选、不摘除 Panel、不停 PTY；全部成功才进入持久提交。目标已有在途保存或外部变化时，Save 保持 Running、Discard 保留待提交标记，均待原回执结算后再推进；实际提交前重查在途外部工作，等待后的关闭候选从最新快照重算；Save 在全部回执后、保存成功前再次核对所有待关闭 Document 的当前 revision，任一写入期间的新编辑转为 Failed(Save)；Discard 恢复提交前同样核对代次。代次失配的显式重试经 core 重收集按当前快照与 Registry 重算，仍适用的原 Save／Discard 决定保留，新变脏的最后引用必须取得新决定。等待与恢复调度按 TaskId 幂等，重复回执不得把正常关闭打成结果未知；原子提交成功前不得停止 PTY 或摘除面板。提交后统一还焦并复用局部关闭的持久推进；停止观察事实必须证明成员集与批次完全相等且无重复，缺失、重复或未知身份一律标为结果未知且不得留下部分观察，后续只能显式重试原批次且不得二次 join。批量与单终端共享单调发起序号与较早失败优先闸门，关窗与项目移除等待存活批次。原因：逐条关闭会产生半批快照与不可恢复的失败顺序。边界：空组由 core 布局转换塌缩；没有真实 `PanelHost` 的视图明确失败；共享 Document 经最后引用与集合外引用守卫，不伪造保存对象或运行状态。
- **项目移除关闭**：`RemoveProject` 以稳定 ProjectId 为封闭命令目标，同一入口负责发起与显式失败重试；每个项目独立 `CloseCoordinator`，同时最多一个项目关闭，目标存在局部终端关闭或全局关闭在途时拒绝。初始原子提交保存其他项目与新活跃项、登记删除意图，但保留目标项目、布局与终端到后续清理；提交后从最新内存快照移除项目、摘除渲染与焦点注册，封锁该项目 Editor ViewState 的旧实例写入，移除活跃项时按既有恢复语义补齐下一项目隐藏 Launch，普通项目写延期到 Completed。所属 session 全部后台显式 join，任一 panic 只记录观察事实并由同一命令显式重试后消费，不二次 join；PTY 停止后的专用事务原子删除项目、纯数据库布局／终端、目标项目独占 Document、项目 ViewState 与 Nav／Explorer 分区，保留其他项目共享 Document 并同步清理内存 SideView，Completed 才释放 ProjectView 并恢复延期写。回执先校验完整身份、attempt、阶段与持久前序；断连或重复登记导致结果未知时 fail-closed。项目关闭存活阻止关窗，不停止全局服务、不写 `clean_shutdown`；单终端、批量与项目移除三条面板销毁链共享同一 AgentHub 关联与任务栏进度清理。原因：项目事实、共享正文与运行实例必须在同一关闭链中闭合。边界：清理失败保留可重试事实。
- **项目快照持久提交**：项目、布局、激活关系与运行意图的候选提交统一进入 WorkspaceWriter 的既有去抖队列，不在各命令另建 Terminal 写通道；普通队列拒收时保留最新待终态，后续成功入队作废旧副本，析构只在持久屏障解除后补交仍未解决的快照。原因：运行快照与持久事实必须同源，前台不得等待 SQLite。边界：只有已提交候选才入队；恢复失败期间普通与终态项目写均受屏障保护，只有成功重载对账或用户显式破坏性重置才能解除；启动失败保持原快照与原实例。
- **设置入口与无项目浮层**：设置入口有活跃项目时在聚焦组创建同项目单例的项目 Settings 面板（空项目按布局转换建首组），无活跃项目时创建 `AppRoot` 直接持有的应用级浮层（`ViewKey::AppSettingsOverlay`）；浮层打开期间重复入口只还焦浮层，不创建项目面板。浮层为非模态全局焦点节点，项目激活或切换只改变项目作用域，不销毁或重置浮层；Escape 与「返回工作区」共用显式关闭链，先还焦再注销注册并释放实体。原因：浮层草稿与页内状态的生命周期不能误绑当前项目，项目面板也不能伪装成浮层。边界：项目面板、独立 ViewState 与 Hooks 草稿归项目设置宿主；关闭期间不得新建任一设置宿主。
- **设置中心页面与导航**：页面集合固定为全局组（快捷键、后台定时任务、外观、终端、应用）与 Agent 组（基础配置、Hooks），顺序与分组单点定义；左导航按组渲染，组标题可折叠（瞬态），过滤输入只过滤导航并按页面标题与分组名大小写不敏感匹配，`Esc` 先清空查询再关闭浮层；页面选择持久化，过滤查询与折叠状态不持久化；页面选择器使用页面 slug 而非索引。原因：导航结构、搜索与持久选择必须由同一封闭页面模型驱动，索引选择器会随页面增删漂移。边界：过滤不改变选中页或配置值；未知或失效页回退到首个可用页并提示。
- **更新提示**：启动链在 `init` 后订阅注册表 `autoUpdateCheck`，检查结果只经壳事件回前台；关闭中或完成后的结果丢弃。提示面显示版本与当前版本：有可验证资产时可后台下载并校验，下载就绪后安装复用统一关闭守卫；`manual_reinstall` 或无可验证资产只提供打开发布页。稍后提醒与跳过版本写提示状态文件后关闭，不重复提示；`auto_download_updates` 开启且资产可装时自动开始下载。设置「应用」页的「检查更新」前台发起、后台联网，结果统一结算：有更新直接打开提示（手动检查绕过跳过／稍后抑制），已是最新与失败只经应用内通知，底层错误不进文案。原因：检查、下载与安装各有单源，提示面不得自建网络或安装通道。边界：提示状态写盘与网络都在后台执行体；下载状态只读更新下载会话，不进入设置或持久 DTO。
- **加密备份**：设置「应用」页的备份对话框由 AppRoot 持有（模态焦点节点），类别选择、口令与固定排除说明只写在对话框；导出任务取运行态设置白名单投影并经唯一写线程收集工作区持久事实，后台密封、原生目标选择与原子写。恢复先后台选择并读取文件、再用口令解密预览，关闭预检（脏 Document 与任何脏 Hooks 草稿）通过后经唯一写线程登记维护请求，重启维护期执行。对话框同时列出已应用恢复点，撤回经唯一写线程登记维护请求并在下次启动维护期按指纹执行。成功关闭或保留阶段性提示，失败只显示封闭文案。原因：备份与恢复不得读取第二份库文件或在前台处理口令与数据库，运行期也不得直接替换数据库。边界：短口令与空类别在前台拒绝；口令不落日志、通知或持久状态；无 writer 时明确不可用；恢复不替用户保存或丢弃正文。
- **诊断导出**：设置「应用」页的诊断对话框由 AppRoot 持有（模态焦点节点）；默认报告只含环境、健康、脱敏日志尾与端点发现元数据，完整路径必须显式勾选才加入并声明 `full-paths` 类别；后台收集、原生目标选择与原子写，成功通知、失败保留对话框与封闭文案。原因：诊断包可外发，敏感材料必须在构造期由用户显式选择。边界：完整路径不进入通知或日志；收集与写盘只后台执行。
- **清理入口**：设置「应用」页的清理对话框按封闭类别展示所有者候选：旧日志、更新下载残留与超过 7 天且不被布局引用的崩溃快照；当前日志、当前下载会话与布局引用由各所有者排除。普通缓存与审计日志分开确认，执行只经统一清理服务计划与逐项执行，结果回前台汇总并逐项写审计。原因：清理不得变成按路径猜测的删除，候选与活跃保护必须来自所有者。边界：不枚举任意目录、不删除目录、不触碰恢复点、隔离区与设置。
- **Runtime 状态面板**：设置「应用」页只读展示控制面 client 可用性与发现记录中的非敏感端点；切入页面时后台读取发现记录一次，缺失或损坏只显示未发布端点，不展示 token。原因：Runtime 状态必须来自唯一发现记录且不得在前台读文件。边界：面板只读，不提供启停或凭据操作。
- **设置导入导出**：导出只经设置转移模块的白名单投影生成版本化信封，后台选择目标并原子写，成功／失败经应用内通知；导入后台选择文件、按 1 MiB 上限读取、解析信封并完成版本／登记／导出资格／字段校验，通过后先显示影响域预览，确认后由设置存储的原子写与 `.bak` 备份落盘，写盘成功才把同一批更新采纳到运行值并热应用。原因：预检失败必须零写入，运行值不得先于持久事实改变。边界：不导入凭据、主题包、Hooks 或工作区；文件选择与写盘只后台执行，前台不阻塞。
- **快捷键页只读目录**：快捷键页只从命令目录的默认定义数组生成，按全局、终端、布局、侧栏分组，同一命令的多个默认绑定合并为一行；命令标签经 typed i18n，键位显示统一由页面格式化（修饰键固定顺序、命名键固定写法）。原因：页面不得维护第二份键位表或自拼英文枚举名。边界：未并入目录的命令不渲染；编辑器、文件树与补全键位仍由各模块注册，接入目录前不得在页面伪造。
- **设置页恢复默认**：字段页顶部提供页级恢复默认，把本页字段写回缺省并经同一快照重建热应用；平台键（开机启动）同步以注册表缺省落地；Hooks 页不提供页级恢复。左导航底部提供恢复所有设置默认：遍历全部字段页的可重置键、把后台任务外部段写回缺省并复位运行期任务。原因：恢复默认必须复用字段表与唯一设置写通道，不能逐控件手工清值或漏掉平台副作用。边界：恢复只影响本页字段或全部可重置字段，不可重置的授权类键保留；不触碰全局待写队列中的其他键。
- **后台任务页**：任务行只来自后台任务注册表，标题经 typed i18n；周期用文本输入，只在失焦或 Enter 提交，只接受整数并按注册表边界校验，非法草稿保留并显示范围；启停与合法周期经外部设置段整段写回，保留其他任务与字段，由设置待写队列落盘并立即热应用到运行期原子量。原因：任务元数据与运行配置各有单源，页面不得自建任务清单或第二写通道。边界：非法周期在提交前按注册表边界拒绝；页面不缓存任务状态，不进入持久 ViewState。
- **套餐余量**：AppRoot 持有唯一套餐余量运行态，构造期订阅注册表并以前台 1 秒拍驱动状态机；只有已配置且到期的来源才在后台查询，结果按凭据代次回填。设置「应用」页提供凭据对话框（掩码输入、保存／删除、手动刷新）与只读汇总；token 只经凭据域与即用即焚的秘密类型，不进入日志或持久 DTO。原因：调度、凭据与展示必须共用一套状态机，测试用例不能充当唯一构造点。边界：网络只在后台执行体；未配置来源零请求；失败与过期只显示封闭文案。
- **AgentRoot 设置管理**：Agent 基础页打开 AppRoot 持有的根管理对话框；自定义根的增删、改名、换目录与写／终端能力开关全部经真实目录查重，校验与设置写盘都在后台，写盘成功才采纳运行值并同步文件树；换目录重置为只读，能力变化推进授权代次。原因：设置页必须与文件树、授权共享同一根事实，候选根不得先改内存再补写。边界：内置根不可编辑；重复自定义、内置占用与非法目录分别显示封闭文案。
- **主题库管理**：外观页页头打开 AppRoot 持有的主题库模态对话框；行列表来自唯一主题库存储，内置与自定义身份并列，选择经主题与自定义主题双设置键写入。导入走后台原生文件选择与 JSON 导入，改名做显示名冲突与修订检查，删除前当前主题必须先另选且删除需对同一行二次点击确认，选择变化、改名或列表重载清除确认态；失败只显示封闭文案并保留对话框。原因：主题能力不能只存在于存储层，删除使用中主题必须在 UI 有执行点。边界：文件 I/O 与解析只在后台；对话框不持有主题正文或缓存定义。
- **设置中心字段控件**：字段行的唯一来源是静态字段表（页面、分区、标签、说明、控件形态与选项），键集合与设置注册表双向强等；主题编辑器专属键由宿主管理并显式排除。控件提交只调用唯一设置应用入口：注册表校验是唯一闸门，非法值只显示瞬态提示；合法值进入设置存储（自动字段去抖、显式字段立即到期），随后重建全局设置快照并热应用主题、语言、托盘与后台任务配置，并向全部项目（含隐藏项目）的既有终端视图扇出一次外观与度量更新。写盘只经后台批量任务：前台提交快照，回执清除与已写值一致的待写项并保留期间的新编辑，失败保留待写并退避一个延迟窗口，设置页显示保存中／已保存／保存失败并提供显式重试。文本控件由设置 revision 驱动回填：其他视图提交或保存回执后同步，聚焦中的输入不覆盖，切页强制回填并清除上一页非法文本；程序化赋值抑制 Change 回写。路径类字段（Shell、启动目录、背景图）先做绝对路径与扩展名形状校验，再在后台确认真实目标存在且类型匹配，非法值只标记字段、不写入运行值或全局队列，迟到检查按字段代次丢弃。启动读取只执行一次，损坏、高版本与读取失败进入设置页状态条；设置页聚合加载降级、单字段非法回退计数与写盘失败，明确区分本次运行生效与重启丢失。原因：控件、运行值、持久值与副作用不得各自维护第二份事实，失败事实也不能只留在日志；路径存在性检查是阻塞 I/O，不能进入 GPUI 前台。边界：视图渲染只读取字段值快照，不借用 store 内部引用；构造时注入的初始值只用于首帧，之后以运行值世代为准。
- **Hooks 编辑页**：Hooks 页只编辑 Claude 的 JSON 子树；User 层路径来自 Claude 配置目录，Project／Local 层固定为项目根的 `.claude/settings.json` 与 `.claude/settings.local.json`。载入、保存、丢弃全部是后台任务：保存必须在锁内重读基线并原子写，外部修改或删除零写入并保留草稿；丢弃只移除草稿与文档后重新载入。前台只持草稿文本与解析诊断，编辑器内容由草稿代次在帧间回填，不参与持久状态。默认 JSON，可切 GUI；两种模式编辑同一草稿，GUI 事件树／matcher 组／handler 字段由 `slterm_hooks` 的单一字段目录生成；JSON 或 schema 非法时停留 JSON 并列出完整诊断。原因：真实配置写入不得阻塞前台，且认领组与外部修改守卫只能由唯一文档事实保证。边界：面板稳定身份安装后绑定；应用级浮层没有项目身份时只提供 User 层并持独立草稿键，浮层关闭即释放；项目移除与根重定位守卫只看存在未提交编辑的 Project／Local 草稿，与磁盘一致的干净草稿不阻塞；层读写前必须证明真实根目录存在，缺失时禁用 Project／Local 并拒绝保存，绝不在缺失根下重建配置；保存成功后清除草稿并提示重启对应 CLI 会话；User 层保存前显示任意命令执行警告，页面提供显式重新加载；已载入层文件经同一 watcher 登记，事件只在 Hooks 页可见且所属项目活跃时后台重读比较基线，干净草稿重载采纳磁盘内容、脏草稿零副作用；注入／卸载完成后已载入 User 文档走同一守卫重读；面板销毁与项目专属清理必须同时释放草稿、文档与诊断，不留孤儿键；应用退出、单面板／批量关闭与设置浮层关闭遇到脏草稿必须拒绝并提示，不得静默丢弃；销毁时取消在途载入／保存，迟到回执按所有者存活复核；测试注入 Claude 配置目录，不触碰真实 home。
- **授权代次单源**：文件授权代次由进程级授权模块提供；项目移除、项目重定位、Agent 根增删改路径必须推进代次。创建计划、开始保存与执行写盘分别读取最新代次，旧代次计划或在途保存一律失败。原因：恒零代次会让撤销后的旧授权继续生效。边界：测试用代次必须与请求一致，不得回到硬编码 0。
- **Agent 根身份**：Agent Files 的持久分区身份是「根 id + 路径」；同 id 改路径按撤销旧身份处理，运行态、展开目录、当前行与授权代次一起清理，新根按新身份登记。真实目录查重由根注册表统一负责，内置根纳入查重与能力并集；生产快照由后台构建注册表，自定义根解码、解析或真实目录冲突作为显式错误状态保留并只保留内置根，树与授权只按已解析真实目录计算。原因：路径变化后旧目录状态不得套用到无关目录，损坏配置也不得静默变成空根集合。边界：只由根同步入口裁定，测试不得绕过同步直接调 remove。
- **AgentHooks 页端口**：AgentHooks 页的安装状态探测与 hook 安装／卸载只在后台执行体运行，前台只读快照、提交显式设置值并展示脱敏状态（失败只留封闭标记，不携带命令或配置正文）。探测只在进入页面或恢复面板停在该页时触发一次，重复请求复用同一任务；同一后台任务顺带读取 statusline 用量信号，页面只展示可解析的最近值；安装／卸载成功后才重新探测，失败保留开关值以便重试。启用命中安装审查门时零写入，页面展示待确认命令原文；用户确认后经恒放行审查门的通道重试一次，取消则回退设置值且不安装。原因：探测与安装是阻塞 I/O，真实用户配置写入路径只能在后台，危险既有命令不得未确认即被接管。边界：测试经注入端口运行，不读写真实 home；命令原文只进入确认面，不进入日志、通知或持久状态。
- **导航历史恢复入口**：导航视图在实例存在时后台扫描 CLI 原生会话；会话 cwd 只取记录中的真实 cwd，按词法最深项目根归属，编码目录名不参与猜测。双击已归属行先激活项目，再在后台复核 cwd 与项目根真实可用性，前台经统一新终端命令建终端并按真实程序名就绪等待注入恢复命令；就绪等待只由本模块按程序名分类并给出上限（cmd 约 0.5 秒，PowerShell、未知或缺失程序 10 秒），未知程序必须按上限等待，因为超时后仍会写入一次，等待不足会在 Shell 未就绪时丢命令；cwd 失效回退项目根并明确提示，项目根也失效则失败。未归属会话不静默落到活跃项目：双击只打开显示目标根的确认面，确认后才经同一项目打开 FIFO 创建项目、建终端并注入恢复命令，取消零副作用。原因：历史恢复必须复用项目、终端与注入唯一链路，目录归属与建项目都不得绕过显式确认。边界：扫描结果与相对时间都是瞬态，不进入持久 DTO；扫描在途只保留最新代次。
- **启动根状态探测**：生产启动链在 GPUI 前用路径解析器探测每个持久根：根缺失标记「需重定位」，其余解析失败标记「不可访问」，别名归一改绑规范根；真实重复根属于持久事实矛盾，保留原记录并进入诊断链。只有就绪项目恢复面板、启动 PTY 或自动读磁盘正文。原因：跨机恢复或外部删除根时必须先重定位与授权，再产生运行副作用。边界：探测只在生产加载入口，测试夹具的虚拟根走通用加载入口；状态不改写文档位置或终端 cwd。
- **根重定位生产入口**：导航项目行菜单触发唯一命令：后台原生目录选择与真实解析（含 junction 归一与目录校验），前台先按 Hooks Project／Local 脏草稿打开丢弃／取消决定面；保存仍须在 Hooks 页完成。有 writer 时经项目快照提交立即事务，回执成功后才采纳候选、推进授权代次并发布快照；失败或回执丢失保留原根。在途期间其他项目快照命令被拒绝，避免旧候选覆盖并发提交。原因：根关联只能建立在真实目标与已提交持久事实之上，不能先改内存再补写。边界：既有 PTY cwd、Document、Diff 与 GitShow 绑定不变；Runtime 目录选择不在本层提供。
- **生产快照恢复**：启动在首帧前经工作区库恢复唯一项目快照与侧栏状态，AppRoot 据此创建全部项目实体并初始化活跃项目作用域，再按已归一布局安装恢复 Document 的编辑器／Markdown／Diff，或共享的专用授权、分页、身份替换占位，重复恢复只复用既有 Panel，启动不送焦、不回写解析结果。常规启动有恢复项目时不额外打开 cwd，空工作区才走初始项目链，显式目录仍走既有打开链。编辑器、Markdown 与 Diff 阅读状态在 GPUI 前按完整 ViewKey 经同一 ViewState 存储预载，Diff 同时恢复固定绑定，不随项目根重定位改绑且保持 HEAD 旧路径；新固定绑定只在面板真实安装后发布，失败重试不得继承未生效请求，新打开同样遵守项目快照命令屏障；未知或损坏记录不回写默认态。文件缺失或不可解码的干净 Document 保留明确不可用占位（可由页签关闭入口移除），不得静默丢面板。授权占位的「重新授权」是唯一生产重授权入口：前台只取记录位置与精确文件会话授权，真实读盘在后台，回执复核目标未偏离记录位置后一次替换该 Document 的全部授权占位并复用同一 Panel，分页正文切专用占位，失败保留占位与可重试状态；关闭中、文档已离开布局或占位已被替换时丢弃回执。原因：首帧不得闪现默认布局，恢复也不得复制持久事实或制造新项目。边界：常规启动恢复失败不得按空工作区打开 cwd；显式目录可继续打开，但项目写屏障不得解除。
- **Diff HEAD 可见性复核**：Diff 只在所属项目可见且所在组 active 时读取 HEAD；隐藏立即取消任务并使旧票据失效，多次隐藏事件只保留合并位，重新可见只复核一次，可见时至多一个在途任务，stale 回执不得结算新任务。原因：不可见面板不得累积后台读取，也不能让旧结果覆盖新绑定。边界：只在原仓库绑定仍证明同一仓库时经固定绑定刷新 HEAD，HEAD 旧路径不变；根重定位或读取失败保留最后一次已验证快照与绑定，Panel 销毁同时取消任务并删除刷新代次。
- **Editor Git 行标**：每个 Editor Panel 以同一 Git 门面捕获当前 Diff 绑定与固定 HEAD，再以共享 Document 的最新 Rope 调用 core 差分；不读取工作区副本，不接第二套 LCS。编辑广播期间不得重入读取来源 Entity，捕获延迟到广播结束；同一 Panel 至多一个在途计算，连续编辑只采纳最新 TextStateId，已验证 HEAD 可供下一次计算复用。行标点击经既有打开 Diff 链打开同一 Document 并定位目标差异，HEAD 或新差分在途时目标行保持挂起，直到可映射到真实差异块；关闭与内容形态转换同时取消任务并清除状态。原因：行标、Diff 与保存必须共享正文、差分语义和生命周期。边界：非仓库或读取失败不产生伪行标，旧代次结果不得回投。
- **终端恢复运行态**：恢复按布局视图顺序创建活跃项目实例；可见 Launch 只启动一次，隐藏项目先保留记录并在首次激活时懒启动，Exited 只恢复退出状态而不创建 PTY；无旧 worker 的持久化 Exited 可在原 Panel 内经 Registry 启动新代次，已有旧 worker 则继续走保留回滚的重连链。启动或元数据失败保留错误面板且不重复记录。默认焦点从布局首个目标组的 active 面板解析，激活与重复打开必须在懒启动和焦点可见性同步前完成默认焦点解析及模态、token、项目作用域纯预检，失败不得产生 PTY；恢复后无失败重算实际默认焦点并经同一纯预检，无法采用时回退已预检 token，激活自身错误不得吞没。原因：持久运行意图决定恢复副作用，恢复前原子预检不能把首次激活焦点固定在项目容器。边界：终端输出、回滚与未知退出码不伪造恢复；已有实例再次激活不重建并保留运行期焦点记忆，隐藏项目的存活实例继续保活；恢复与重连只在真实进程创建目录错误后回退所属项目根并发出脱敏提示，不为 Shell 缺失或其他错误重试；AgentSession 随同一项目快照原子提交，命令边界只更新 AgentHub 与该候选。
- **单实例项目与终端移交**：打开项目先经规范路径纯校验，再经 FIFO 后台解析并复用候选添加项目；只有实际完成后才前置窗口并回执 accepted，解析或提交失败不改变原项目关系；新增根只打开空项目，重复根激活既有项目，均不得隐式创建终端或面板。仅非法路径映射 InvalidRequest、模态映射 Unauthorized、其他失败映射 NotReady，失败保持快照、实体、Panel／PTY 与焦点事实不变。新建终端同样先纯校验路径并复用命令目录：显式根只精确匹配既有项目，仅有 cwd 时选择根覆盖 cwd 的最深项目，两者同时提供时 cwd 必须位于显式根内，两者皆无才使用活跃项目；未知根、无覆盖 cwd、跨根 cwd 与模态均为 Unauthorized，非法路径为 InvalidRequest，其他未就绪失败为 NotReady，错误脱敏且不得改投或隐式创建项目。所有新建终端请求先同步真实焦点，再解析目标与克隆候选；隐藏目标的候选快照同时包含项目激活与新终端，目标组先复用焦点记忆，无可用面板焦点时按布局顺序选择既有组，空项目生成首组；启动器、实例登记、项目激活与新终端聚焦全部成功后才提交，失败须清理启动并恢复原 active 与实际焦点，成功后按既有恢复语义补齐其余隐藏实例。原因：第二实例必须共享项目、授权、目录和焦点语义，前台不得执行路径文件系统 I/O，隐藏恢复不得破坏原子提交。边界：仅成功后才前置窗口并返回 accepted，Closing 优先。
- **窗口几何观察**：窗口边界变化只在前台覆盖最新几何并经 500 毫秒去抖任务提交 writer；替换任务即取消上一次去抖，实体销毁后任务随之取消。无 writer 的内存测试根只观察不写盘。原因：拖动与缩放不得放大写盘，几何必须与真实窗口状态同源。边界：几何只在开窗链恢复（夹回可见工作区），运行期不回写窗口 bounds。
- **Runtime 快照端口**：`runtime.snapshot` 的只读资源只由前台按请求时刻从唯一项目快照派生；项目、面板组、布局树、终端与 Document 身份及元数据一次成稿，视图身份使用规范 ViewKey JSON 文本，布局树携带方向、比例与组身份以便推导 resize 路径；终端资源携带 Registry 当前 PTY 代次（无存活 worker 为零）。请求经有界壳事件通道进入，回执容量 1 非阻塞；关闭中、关闭完成或存在应用关闭时返回结构化 Closing。原因：快照必须与前台同一状态时刻一致，跨线程读共享可变状态会绕过单源。边界：快照不含 PTY、输出、正文、Agent 运行态或凭据；非 Unicode 路径与规范编码失败明确报错，不返回截断快照；快照 revision 由事件环当前末尾提供，split／resize 的最小空间按前台真实内容视口校验，不接受客户端自报视口。
- **Runtime 写意图**：写方法只接收已解析的封闭意图（项目激活／重命名／排序／移除；组拆分／合并／比例；面板激活／移动／设置；终端新建／输入／执行／关闭／重连／重命名），全部复用既有项目、布局、面板、设置与终端命令；关闭中、关闭完成或存在应用关闭时在命令前返回结构化 Closing。终端输入／执行只按稳定身份与 PTY 代次定位运行中视图并写唯一 worker；输入原样写入，执行追加一次回车；记录非 Launch、目标或面板缺失、代次不匹配一律 NotReady，不猜测重连后的新进程。终端关闭先要求快照记录存在，再要求请求代次等于 Registry 当前代次，失配返回 RevisionConflict，匹配后复用既有持久关闭链；重连走同一预检并只接受 Exited 记录；重命名经候选更新标题并复用同一持久提交，布局、焦点与 PTY 保持不变。改变项目／布局／终端记录的同步写意图与异步打开文件／Agent 启动的成功回执必须等唯一写线程提交项目快照事务；内存提交后立即回复成功属于协议错误。终端输入／执行、应用聚焦、Git 外部文件写与关闭链不在此列。实现经事件泵轮询事务回执，前台不等待磁盘；事务失败、写线程停止或关闭中回结构化失败，迟到回执丢弃。原因：Runtime 不得形成第二套项目写路径，授权、事务、焦点与关闭策略必须由既有命令单点裁定。边界：意图只含稳定身份与已校验输入，路径与授权解析不在本层；错误只映射为封闭领域码，不携带路径、SQL、正文或命令细节；新增写方法必须先接入真实命令再接事件。
- **Runtime Git 目标**：Git 只读目标只在前台解析项目（缺省取活跃项目）与仓库根，返回项目身份、根与 Git 门面；仓库读取、授权并集与 porcelain 解析全部在连接线程内后台执行，前台不 spawn git 子进程。Diff 目标复用同一项目解析并校验仓库相对路径（非空、不以分隔符开头、不含 `.`／`..` 或反斜杠），把已校验路径与仓库入口交后台。原因：Git 读取是阻塞 I/O，项目根解析与授权必须复用同一门面。边界：未知项目与非法路径为 InvalidRequest，无活跃项目为 NotReady，仓库状态错误映射不改写持久状态。
- **Runtime Git 破坏写**：回滚与删除只在前台校验路径形状并解析项目与写授权，阻塞的状态重检与写盘由连接线程在同一执行体内完成；成功后尽力刷新同一项目的 Commit 视图。面板与 Runtime 共用该执行体，破坏写进程内串行，写前重读状态复核调用方声明形态，前置不成立返回 RevisionConflict 且不写盘，项目根外路径为 Unauthorized，结果只经审计通道记 operation／path／source／result。原因：Runtime 与面板不得形成两套回滚／删除语义，GPUI 前台也不得等待 git 子进程。边界：状态重检使用独立门面避免命中共享缓存，成功后使共享状态缓存失效；回收站不可用只失败，不隐式永久删除；刷新事件尽力投递，丢失不影响已完成的写。
- **Runtime 应用聚焦与关闭**：应用聚焦只调用窗口前台聚焦与重绘；应用关闭先把封闭策略翻译为每文档关闭决定，Hooks 草稿只支持显式丢弃，缺决定返回 `decision_required` 且不触发任何交互通知。关闭入口返回 Completed／Started／Deferred／Rejected：决定齐备性先于无 writer 的完成路径；需要保存而无 writer 时明确 Rejected；在途文档工作期间 UI 路径保留决定并在恢复时继续，Runtime 路径明确 NotReady。原因：非交互关闭不得用 best-effort 丢弃正文，也不能把未开始的关闭伪装成成功。边界：关闭回执由最终关闭状态持有，保存、PTY 停止与本地持久冲刷全部落定后才发送成功；任一步明确失败回失败并保持现场，结果不明放弃回执并记结果未知；进程退出期间连接可能先断开。面板关闭只关闭目标视图并复用批量关闭链：先探测最后引用的脏 Document，缺策略返回 `decision_required`，策略齐备后以单视图集合登记关闭。面板关闭与项目移除的显式 Save／Discard 只覆盖关闭集合内最后引用的脏 Document；集合外仍有引用的共享 Document 不产生决定。
- **项目移除保存阶段**：项目关闭按关闭协调器的 Save 阶段执行：收集项目视图最后引用的 Document 决定，需要保存时先真实写盘与代次校验，成功后才提交删除意图，失败停在 Save 并保留项目；Runtime 项目移除把封闭策略翻译为每文档决定，Hooks 草稿只支持显式丢弃，缺决定返回 `decision_required`。原因：项目移除不得静默丢弃脏正文，也不得把未开始的关闭伪装成成功。边界：清理阶段失败沿用既有重试与失败态；无 writer 时移除明确失败。
- **Runtime 面板打开与保存**：打开文件复用真实文档打开链，回执在打开完成后发送，回调未兑现即由守卫回执 Closing；保存只解析编辑器或 Markdown 视图的 Document，把回执登记进保存等待者并调用同一保存链，唯一保存链在写盘落定后结算等待者，仍有排队保存时不提前成功。原因：打开与保存不得出现第二执行路径，Operation 结果必须对应真实副作用。边界：非文本视图、布局外视图与未知 Document 为 InvalidRequest；保存错误只映射封闭 NotReady，不携带路径或底层文本。
- **Runtime Git 打开**：打开 Diff 与打开已删除只在前台解析项目并返回目标；连接线程复核状态映射并捕获仓库绑定后，经壳事件把已捕获绑定交回前台，与 Commit 行激活共用同一打开链、落点与 Document 等待队列。原因：Runtime 不得复制打开映射或另建文档／面板打开路径。边界：映射不一致在投递前拒绝，前台只执行已接受的打开；关闭中拒绝；事件已投递后回执超时或断连记为可查询结果未知。
- **Runtime Agent 资源**：Agent 只读资源只在前台按请求时刻派生：遍历唯一快照的终端记录，运行期会话身份优先、持久 AgentSession 回退，状态取 AgentHub 仲裁器；纯 Shell 不产生关联行，同一原生会话 ID 可出现在多个终端关联中。对外身份有原生会话时用 `kind:native_session_id`，否则用 `kind@terminal_id`。写方法必须同时提供对外身份、稳定终端与 PTY 代次，重新派生目标终端当前身份并比对，失配返回 UnknownAgent；输入与关闭分别复用终端输入通道与终端关闭协调器，读取与等待复用终端读取／等待端口并在同一校验点比对身份，不另建 Agent 专属执行路径；启动、恢复与分支先由 CLI 类型与会话身份构造并校验命令，再复用新终端创建链并在首个真实提示符或超时后注入一次，Operation 回执延迟到注入落定，明确失败映射 NotReady，View 取消或销毁不回写，由服务端按结果不明处理。原因：活跃关联必须由同一 PTY 映射与会话事实派生，不能另存持久活跃映射。边界：不返回正文、历史记录或凭据；终端的持久会话身份与运行期 hook 状态都缺失时不猜测；未知 CLI 与不支持的动作返回 InvalidRequest。
- **Runtime 读取端口**：读取与写意图共用稳定身份与 PTY 代次校验，写输入要求 Launch 意图、只读画面允许已退出终端；校验通过只向唯一 worker 发送读取命令并把应答端交还调用方，前台不等待文本、不锁实时网格。等待复用同一校验，只返回视图最近帧 revision，不等待变化。关闭中、关闭完成或存在应用关闭时在命令前返回结构化 Closing。原因：读取必须与绘制同源且不得在前台阻塞。边界：不缓存正文、不提供增量输出流；代次不匹配、目标或面板缺失一律 NotReady。
- **Runtime 事件发布**：轻量事件只在后台状态提交成功后由统一发布器发布；协议封闭枚举当前只有项目激活事件，面板与终端事件在真实发布点接线前不得登记，客户端以快照与读取／等待 revision 对齐。负载只含类型名、资源身份与快照代次，revision 由事件环分配。发布经非阻塞提交，队列满丢弃事件；关闭中、关闭完成或存在应用关闭时不发布，避免销毁后回填过期事件。原因：事件必须与前台状态同源、同序，且不得反压 UI 或 PTY。边界：事件不含正文、路径内容、凭据或终端输出；隐藏项目的状态变更同样发布；不提供补发或内存重放通道。
- **单实例文件移交**：打开文件先纯校验规范路径，选择覆盖目标的最深既有项目根，不隐式创建项目；复用 Document FIFO 后台解析与读取，活跃项目使用聚焦组，隐藏项目复用焦点记忆或布局首组，空项目的首组延迟到请求完成时按最新布局解析，排队请求不得持有过期组 ID。项目激活、视图去重或安装、编辑器落点和真实焦点全部成功后才提交候选并前置窗口；失败恢复原 active 与实际焦点，不留下新 Document 或空 Panel，共享 Document 不误删。全部可失败准备完成后才移交 completion，活动、排队与在途请求在关闭时恰好结算一次 Closing；非法路径与不支持类型映射 InvalidRequest，无覆盖根、解析越权与模态映射 Unauthorized，其他读取与未就绪失败映射 NotReady，回执不得携带路径或正文。原因：第二实例必须与应用内打开共享身份、授权、布局和焦点事实，且不能出现半激活或丢失回执。边界：不为打开文件创建第二套读取、落点或占位面板通道。
- **生产身份与落点**：打开项目、新建与拆分命令由 application 以 UUIDv7 生成稳定身份；固定身份入口只供恢复协调与测试。普通新建进入活跃项目当前聚焦组，空项目生成首组；移交的新终端按移交规则选择目标项目与组；拆分必须已有聚焦组，关闭聚焦终端复用同一显式关闭链。原因：调用方不得自行拼身份或另判布局落点。边界：无活跃项目或应有聚焦组而缺失时明确失败，不隐式选择隐藏项目。
- **终端 cwd 授权**：未提供 cwd 时只使用目标项目根；显式 cwd 必须位于该项目根内，并在调用启动器前完成校验。原因：新终端不得继承另一终端目录，也不能因越权路径消耗 PTY 或 Panel 身份。边界：非法或越界 cwd 保持快照、实例和启动次数不变；Shell 内后续 `cd` 不改变既有授权来源。
- **项目元数据与真实路径打开**：重命名与排序经统一候选提交，只改名称或导航顺序，不改变活跃项目、布局、Panel 或 PTY；空白、超长与越界输入保持原快照。打开项目、打开目录与初始打开共用 FIFO 解析队列，系统 canonicalize 与目录校验只在后台执行体，任务归任务服务，完成回前台后仍经同一添加项目候选链；后一请求不得先于前一请求提交，失败不得新增项目、改投活跃项或伪造移交成功；completion 统一结算且只允许一个活动任务，关闭入口立即取消并排空队列，移交守卫在窗口或实体销毁时兜底 Closing。原因：项目关系与焦点必须确定，且真实路径 I/O 不得阻塞前台。边界：固定身份与假解析器只用于内存测试；生产不得绕过真实路径端口直接打开外部根。
- **可失败启动接缝**：终端先冻结配置并启动 PTY，成功后才构造实体。原因：GPUI 实体构造不能直接返回启动结果，失败不得先挂实体再补救。边界：成功启动只执行一次；非 Unicode Shell 路径在参数组装前拒绝，不做有损转换。
- **项目切换保活**：终端视图强持于各自 ProjectView，全部 PTY worker 由 AppRoot 的 Registry 统一强持；切换只调整输出可见性与焦点，隐藏项目的既有会话泵、输出解析和回滚继续运行，重新可见时主动补帧。原因：项目导航不得重建终端或丢失后台输出，视图也不得成为第二 worker 所有者。边界：普通显式新建只面向活跃项目；移交仅按单实例规则选择既有项目，隐藏项目的其余懒启动由恢复协调负责。
- **退出与关闭分离**：终端 Exited 只把逻辑记录改为退出意图，保留面板、实体、显示订阅与最后画面；显式关闭才从 Registry 退休 worker 并释放实例。重连只允许已退出终端，预检快照候选后才启动新 PTY；成功切换代次、提交启动意图并按旧目标后台回收，失败保留原 Panel、旧 worker 与可见错误。原因：进程退出不是用户关闭面板，退出后仍须允许滚动与复制，重连不得形成第二生命周期通道。边界：重复或迟到的退出事件不得关闭其他面板或终止显示订阅；未知运行身份不猜快照目标。
- **应用退出局部关闭**：OS 关窗与托盘退出统一经同一关窗请求创建应用退出作用域，先等待在途 Document 保存／外部工作，再对全部视图统一收集 Document；自动保存只给合格文档提供保存，其余脏文档未取得显式决定时取消退出并保留窗口，保存期 revision 变化后的重试必须重收集；随后收集全部逻辑终端，先移交侧栏终态，再原子提交项目快照与关闭意图；全部 session 在后台逐一显式 join，随后依次提交持久阶段，只有 Completed 才进入停止服务并复用最终冲刷。初始明确提交失败清除本次关闭并恢复编辑；停止后的明确写失败保留窗口，从原持久前序显式重试；join panic 只有显式重试才消费观察事实，不二次 join。断连或重复任务登记导致结果未知时 fail-closed，禁止盲目重登记；回执须先核对完整身份、attempt、next 与持久前序。应用关闭存活即冻结命令与移交，即使失败已清除关闭标记也不得解冻。原因：窗口销毁不得掩盖持久提交、PTY 回收或回执身份错误。边界：局部段不写 `clean_shutdown`；生产最终冲刷成功后经全局 client 请求 GPUI 外所有者，只有收到服务停止与正常退出提交完成或知情放弃回执，才推进全局阶段并销毁窗口；恢复失败仍在同一关闭状态机内执行 Document 保存与 PTY 停止，但不写持久关闭意图；最终冲刷后经同一全局段等待回执，断连同样 fail-closed；无 writer 仅允许内存测试根直接关窗降级。
- **关闭冲刷与冻结**：正常应用退出局部段完成或恢复失败屏障路径，都由最终状态提交移交项目、侧栏组织与 SideView 私有终态，再由工作区写客户端在后台执行可重试冲刷；冲刷失败保留窗口并允许重试，已停止的 PTY 不得因此重开。每次快照提交推进代次，冲刷返回时代次已变化则重新移交并再次冲刷，只有最新代次零失败才进入后续退出。生产全局 client 存在时，冲刷成功只发起全局段，Completed 或 Abandoned 回执才允许移除窗口；生产开窗必须注入非可选全局 client。关闭标记拒绝新命令、项目切换、鼠标激活与几何拖动，关闭时取消既有手势；关闭完成终止当前壳事件批的领域处理，同批剩余移交仍逐一非阻塞回复 Closing、其他事件丢弃，关窗回调只弱持 AppRoot。原因：最终持久提交失败或过期不得被窗口销毁掩盖，也不得形成第二退出通道。边界：GPUI 前台不等待数据库、控制面或 writer shutdown；正常退出标记由 GPUI 外的全局关闭所有者提交。
- **关闭决定面**：窗口关闭、组内关闭其他／全部、单面板关闭、项目移除与设置浮层关闭在存在最后引用脏 Document 或脏 Hooks 草稿时，先由唯一模态决定面取得保存／丢弃／取消；决定只描述范围，保存、关闭意图、PTY 停止与清理仍回到各自既有命令链。Hooks 草稿没有自动保存通道，决定面只提供丢弃或取消，保存必须在 Hooks 页显式完成；退出的 Document 自动保存可覆盖时不弹决定面。原因：交互关闭不得静默丢正文，也不得代用户写 CLI 配置。边界：决定面不直接写文件或改快照；取消只收合模态并恢复焦点。
- **编码选择面**：自动识别只接受 BOM 或合法 UTF-8；交互式打开因未知或非法编码失败时，由唯一模态编码选择面取得用户显式编码，再经同一 FIFO 读取与安装链重开，可编辑与超限分页分支共用该入口。原因：core 要求 GBK／GB18030 显式指定，应用必须提供唯一恢复路径而不是留下不可打开的文件。边界：二进制内容、非交互打开（移交／Runtime 回执）与其他 I/O 失败不进入该面；显式编码仍不可解码时回到同一选择面直到取消；选择面不读盘、不建面板，关闭决定面打开前先收合它。
- **保存冲突与另存为**：用户显式保存遇磁盘变化时，由唯一模态决定面取得覆盖／另存为／重载磁盘／保留本地／取消；覆盖只跳过磁盘字节基线比较，仍复核真实文件身份与权限；重载经后台重读真实文件后由 core 强制替换并清空撤销历史；另存为经平台集成在后台弹出原生目标选择，前台按 Registry 复核占用，写盘前再次解析授权目标，成功后同一 Document 重绑位置并刷新全部引用视图。自动保存、关闭保存与 Runtime 保存不弹面、不替用户选择覆盖。原因：冲突中的本地正文必须存在可完成的生产保存路径。边界：决定面收合后还焦原 Document 面板；目标已关联其他 Document 与同路径另存为在写前拒绝；非交互保存失败只回投封闭错误。
- **任务所有权**：任务服务集中登记封闭任务身份、GPUI 任务与显式取消令牌，禁止 `detach`；局部关闭按终端身份持有，组内批量按批次身份持有一个任务，重复身份拒绝且不得构造或丢弃替代资源；已发请求的重复登记只把本次结果标为未知并保持写屏障，原任务身份必须保留，未知结果处理不得顺带收割原任务；Running 停止 PTY 的重复调度保持幂等，不构造替代任务、不转 Failed、不标未知，保留原 attempt 与任务并等待原回执收割推进。shutdown 先标记全部取消再释放句柄并清除视图代次，析构复用同一路径。可见性复核以任务所有者与单调代次票据归属：可见时至多一个在途任务，其余事件只置合并位；隐藏立即使旧票据失效，重新可见只启动一次合并复核，当前完成后再启动已合并请求，stale 回执不得结算新任务。显式保存与文件操作结果不随视图显隐清除，也不另建内存结果副本。原因：周期与关闭任务必须有确定所有者与取消边界，不能留下游离循环或让 stale 回执取消新 attempt。边界：壳事件泵只经该服务注册，后台只定时唤醒，通道排水和状态变更仍在窗口前台；新后台任务先声明身份与取消语义。
- **命令目录单点**：终端与侧栏命令统一由命令目录消费包含封闭命令身份、来源、目标、上下文快照和可选参数的请求；键盘、鼠标、菜单与 application 调用只构造请求，默认键位与 GPUI action 在同一目录登记，固定身份构造仅保留为恢复与测试接缝。原因：键盘、菜单和 Runtime 不得形成不同领域执行路径。边界：项目与模态校验只作用于终端命令，侧栏组织菜单允许自身模态上下文；Shell、视口与比例沿请求传递，未携带对应参数即报错；`Ctrl+C` 不进入终端命令绑定，继续保留中断语义；连续拖动仍按手势处理，不伪造成离散命令。
- **布局操作与分隔线焦点**：移动、合并、既有视图拆分和比例调整统一经命令目录在候选布局上转换；不新建或销毁 Panel、逻辑终端或 PTY。移动与拆分聚焦被移动视图，合并聚焦目标组实际 active；候选验证后先完成送焦再提交，焦点失败不得改变正式快照。Shift+F10 仅在布局内容上下文打开当前聚焦组菜单，SideView 与活动栏不得触发；菜单先收合还焦再执行命令，单视图组不提供必然失败的移动拆分项，无可用动作时不创建空菜单；终端内容的右键复制／粘贴合同不得被布局菜单覆盖。分隔线以当前分割路径持有运行期焦点句柄，快照提交时按全部项目布局对账，项目切换同步可见性；关闭候选提交前记录将被删除且实际聚焦的分隔线，并复用关闭还焦链到剩余 active 面板；路径不是持久身份，不产生第二布局事实源。原因：非拖拽入口必须复用同一布局与焦点权威，不能在菜单或渲染层另写转换。边界：真实桌面焦点仍按既有豁免验收。
- **页签与完整列表**：页签严格按当前组视图顺序生成，激活索引从同一组 active 派生；点击与完整列表共用激活候选与既有面板送焦链，不重建 Panel 或 PTY；没有真实运行面板的视图明确失败，不用占位实例伪造激活。页签从面板实体投影共享 Document 脏标记与 AgentHub CLI 状态（形状＋颜色双区分），每个页签带关闭入口；关闭当前面板复用同一单面板关闭链，关闭当前聚焦视图而不要求终端。横向滚动句柄以项目与组为运行期键并随快照对账，组内顺序或激活项变化时将 active 滚入视野；完整列表由 AppRoot 持有并注册为焦点模态节点，取消只还焦，选择先收合再激活目标。原因：溢出只改变展示，不得丢失 ViewKey 或让未注册弹层与焦点权威争抢。边界：滚动位置不是布局事实，不进入持久 DTO；标题不是身份；终端自定义标题始终优先，否则使用运行视图的最新 CLI／OSC 标题，无实例或空标题才回退逻辑编号。
- **焦点弱所有权**：焦点管理器只弱引用焦点句柄与 owner 凭证，以不复用的代次 token、逻辑父链和项目焦点记忆协调还焦；控件销毁或隐藏后不得因渲染帧仍强持句柄而继续可聚焦。实际焦点经 pending-input 与 focus-lost 订阅同步，项目切换先快照真实焦点。文本输入等子控件不单独注册为节点；同步时按渲染树中最近的可聚焦注册祖先判定作用域，模态内与普通视图内的真实子控件焦点都保留，只有无法证明作用域的句柄才恢复。原因：焦点变更会触发 pending-input 观察者，若把未注册子控件一律视为失效，文本框将无法获得键盘输入。边界：Manager 不延长视图生命周期，模态层仍须自行遮罩背景指针命中。
- **面板循环与关闭落点**：`Ctrl+Tab`／`Ctrl+Shift+Tab` 以活跃项目布局的树顺序与组内顺序循环，全局绑定复用真实 PanelHost 与激活链，终端补全和编辑器不得截获或写入 PTY。关闭聚焦面板时由 core 候选的同组 active 提供下一个／上一个落点；组塌缩后按原组索引选择相邻组候选 active，再回退项目容器与工作区。原因：PanelId 字典序不是用户布局顺序，局部控件也不能形成第二套路由。边界：无真实面板的视图明确失败，真实桌面焦点仍按既有豁免验收。
- **侧栏快捷键与焦点所有权**：视图快捷键的打开、恢复、显示、聚焦与关闭只经 core 快捷键转换，AppRoot 统一协调焦点注册、可见性和还焦，不在 GPUI 层复制开关规则。SideView 与活动栏按钮均为全局非项目节点；按钮焦点生命周期独立于 SideView 实例，启动只注册不送焦，显式关闭注销节点，隐藏只撤销视图焦点资格。原因：实例代次与按钮持久身份不同，隐藏或销毁后不得残留可聚焦路径。边界：聚焦判定包含视图后代；关闭或隐藏聚焦视图后还焦其可见按钮，无可用按钮时回 workspace。
- **按钮菜单组织单源**：`Shift+F10` 与右键共用 AppRoot 持有的同一菜单入口；菜单注册为焦点模态节点，收合经既有还焦链返回触发按钮。排序、换区、隐藏与重置顺序只调用 core 组织转换，并复用统一实例效果、焦点可见性与实际变化才落盘协调。原因：菜单是拖拽的键盘等价物，不得形成第二套布局或焦点规则。边界：隐藏按钮保留已打开实例并还焦相邻可见按钮，无按钮时回 workspace；跨槽交换保留双方实例；重置顺序不改变分组、显隐、槽位或几何。
- **SideView 实例与私有状态**：侧栏宿主独占侧栏组织状态与全部存活实例，按 core 转换效果创建、替换、保留或关闭实例；SideView 独占强类型私有状态，关闭与 Drop 共用一次 checkpoint，写盘只经 WorkspaceWriter。原因：组织状态、GPUI 生命周期与持久事实不得形成双源。边界：隐藏不销毁实例；私有状态在进入 GPUI 前完成预载，无记录才允许默认态回写，读取或解码失败按视图设置写屏障，显式编辑才可解除；普通队列拒收的关闭快照保留为待终态，新一代次成功提交即作废旧待终态，持久化 owner 析构时只补交仍未解决的最新代次。
- **侧栏组织状态恢复**：启动在 GPUI 前从工作区库恢复唯一侧栏状态并移交给侧栏宿主；按钮与显隐等显式组织编辑统一经 WorkspaceWriter 保存。原因：首帧不得先显示默认组织再跳变，启动恢复失败也不得被默认态静默覆盖。边界：无记录或字段级修复不自动回写，只有显式编辑产生写请求；普通队列拒收时保留最新待终态，后续成功入队作废旧副本，持久化 owner 退出时经独立终态通道补交。
- **侧栏几何与手势**：侧栏状态只保存用户显式宽度与比例；窗口压缩只夹紧实际绘制和无障碍数值，主区与双槽保留各自最小尺寸，高度不足时侧栏整体纵向滚动，不回写临时几何。键盘与拖动从当前可见值起算，分隔线焦点资格、双击复位、全窗拖动覆盖层及组织变化时的手势取消由 AppRoot 统一协调。原因：临时视口约束不得污染持久偏好，不可见手势层不得截获输入。边界：可见值调整一旦成为显式编辑，仍按 core 几何范围夹紧并保存。
- **分屏空间边界**：拆分动作以窗口尺寸扣除活动栏与实际可见侧栏后的项目内容区校验最小组尺寸，渲染与动作共用同一占宽判定。原因：整窗宽度会让侧栏挤占后的过密分屏错误通过 core 校验。边界：隐藏整个侧栏才释放其宽度，隐藏单个按钮不改变内容区。
- **无旧恢复旁路**：本模块不读取、迁移或清理旧 session 与磁盘历史材料，不与旧 tabs／SplitTree 同步双写。原因：新根必须只有一条布局与生命周期通道。边界：生产恢复只能由启动协调显式注入一致快照，实体层不得自行读盘。

## 操作

- 新增视图：先扩封闭 ViewKey 与单一注册点，再由 AppRoot 所有权链接线。
- 新增启动副作用：接入同一启动链，不在子模块私开入口。
- 调整视觉语言：改主题表与语义 token，不在壳内写颜色字面量。
