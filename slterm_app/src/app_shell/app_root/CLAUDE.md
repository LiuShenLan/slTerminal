# AppRoot 运行根

> 以唯一项目快照协调全部项目的运行面板、瞬时焦点与终端生命周期。

## 决策与红线

- **项目与布局单源**：`AppRoot` 直持 `ProjectSnapshot`；`projects` 只是全部 `ProjectView` 的强实体引用表，不复制项目注册、布局或逻辑终端记录。原因：运行实例不得成为第二项目或布局事实源。边界：`ProjectView` 只持 `PanelHost`、项目焦点容器与项目内瞬时焦点，`PanelHost` 只持 `PanelId`、`ViewKey` 与 `TerminalView`。
- **渲染只读单源**：画面只沿活跃项目的 `ProjectLayout` 树、组内 active `ViewKey` 与既有 `PanelHost` 组装；隐藏项目不挂载但继续保活，空项目不创建占位终端。原因：渲染不得派生第二布局或触发终端生命周期。边界：组内非激活视图与隐藏项目均不进入当前画面，激活与切换只复用既有实体。
- **候选原子提交**：新增与拆分先由快照产生候选，再执行一次可失败启动并登记实例，最后提交候选；关闭先产生候选，提交后移除订阅与实例并显式 shutdown。原因：布局、逻辑终端记录与 PTY 不得出现半提交。边界：启动失败不保留 `session=None` 的占位面板，正式快照与实例表不变；PanelId 失败消耗后也不复用。
- **项目快照持久提交**：项目、布局、激活关系与 RunIntent 的候选提交统一经 `commit_project_snapshot` 进入 WorkspaceWriter 的既有去抖队列，不在各命令另建 Terminal 写通道。普通队列拒收时保留最新待终态，后续成功入队作废旧副本，AppRoot 析构只补交仍未解决的快照。原因：运行快照与持久事实必须同源，且前台不得等待 SQLite。边界：只有已提交候选才入队；恢复失败期间普通与终态项目写均受屏障保护，只有成功重载对账或用户显式破坏性重置才能解除；显式启动失败保持原快照与原实例，终态移交不阻塞 GPUI 前台。
- **生产快照恢复**：`AppRootPersistence` 在首帧前经工作区库恢复唯一 `ProjectSnapshot` 与侧栏状态，AppRoot 据此创建全部项目实体并初始化 FocusManager 的活跃项目作用域，启动不送焦、不回写解析结果。常规启动有恢复项目时不额外打开 cwd，空工作区才走初始项目链，显式目录仍走既有打开链。原因：首帧不得闪现默认布局，恢复也不得复制持久事实或制造新项目。边界：常规启动恢复失败不得按空工作区打开 cwd；显式目录可继续打开，但项目写屏障不得解除；后续损坏诊断与只读维护界面由 Startup 协调承接。
- **终端恢复运行态**：恢复按 `ProjectLayout::view_keys()` 顺序创建活跃项目实例；可见 Launch 只启动一次，隐藏项目先保留记录并在首次激活时懒启动，Exited 只恢复退出状态而不创建 PTY，启动或元数据失败保留错误面板且不重复记录。默认焦点从布局首个目标组的 active 面板解析，激活与重复打开在懒启动前完成模态预检，失败不得产生 PTY。原因：持久运行意图决定恢复副作用，显式新建的原子失败与送焦语义不能直接复用。边界：终端输出、回滚与未知退出码不伪造恢复；已有实例再次激活不重建并保留运行期焦点记忆，隐藏项目的存活实例继续保活。
- **生产身份与落点**：打开项目、新建与拆分命令由 application 以 UUIDv7 生成稳定身份；固定身份入口只供恢复协调与测试。新建进入活跃项目当前聚焦组，空项目生成首组；拆分必须已有聚焦组，关闭聚焦终端复用同一显式关闭链。原因：调用方不得自行拼身份或另判布局落点。边界：无活跃项目或应有聚焦组而缺失时明确失败，不隐式选择隐藏项目。
- **可失败启动接缝**：终端先经 `TerminalView::launch` 冻结配置并启动 PTY，成功后才经 `from_launched` 构造实体。原因：GPUI 实体构造不能直接返回启动 `Result`，失败不得先挂实体再补救。边界：成功启动只执行一次；非 Unicode Shell 路径在参数组装前拒绝，不做有损转换。
- **项目切换保活**：已恢复的 TerminalView 与存活 PTY 强持于各自 ProjectView；切换只调整 `output_visible` 与焦点，隐藏项目的既有会话泵、输出解析和回滚继续运行，重新可见时主动补帧。原因：项目导航不得重建终端或丢失后台输出。边界：显式新建只面向活跃项目；隐藏项目 Launch 的懒启动由恢复协调负责，不在显式命令中暗中 spawn。
- **退出与关闭分离**：TerminalView 的 Exited 只把逻辑记录改为 `RunIntent::Exited`，保留面板、实体与最后画面；显式 close 才释放实例。原因：进程退出不是用户关闭面板。边界：重复或迟到的退出事件不得关闭其他面板；未知运行身份不猜快照目标。
- **焦点弱所有权**：`FocusManager` 只弱引用 FocusHandle 与 owner 凭证，以不复用的代次 token、逻辑父链和项目焦点记忆协调还焦；控件销毁或隐藏后不得因渲染帧仍强持句柄而继续可聚焦。实际焦点经 pending-input 与 focus-lost 订阅同步，项目切换先快照真实焦点。边界：Manager 不延长视图生命周期，模态层仍须自行遮罩背景指针命中。
- **侧栏快捷键与焦点所有权**：视图快捷键的打开、恢复、显示、聚焦与关闭只经 core `activate_shortcut` 转换，AppRoot 统一协调焦点注册、可见性和还焦，不在 GPUI 层复制开关规则。SideView 与活动栏按钮均为全局非项目节点；按钮焦点生命周期独立于 SideView 实例，启动只注册不送焦，显式关闭注销节点，隐藏只撤销视图焦点资格。原因：实例代次与按钮持久身份不同，隐藏或销毁后不得残留可聚焦路径。边界：聚焦判定包含视图后代；关闭或隐藏聚焦视图后还焦其可见按钮，无可用按钮时回 workspace。
- **按钮菜单组织单源**：`Shift+F10` 与右键共用 AppRoot 持有的同一菜单入口；菜单注册为 FocusManager 模态节点，收合经既有还焦链返回触发按钮。排序、换区、隐藏与重置顺序只调用 core 组织转换，并复用统一实例效果、焦点可见性与实际变化才落盘协调。原因：菜单是拖拽的键盘等价物，不得形成第二套布局或焦点规则。边界：隐藏按钮保留已打开实例并还焦相邻可见按钮，无按钮时回 workspace；跨槽交换保留双方实例；重置顺序不改变分组、显隐、槽位或几何。
- **SideView 实例与私有状态**：`SideViewHost` 独占侧栏组织状态与全部存活实例，按 core 转换效果创建、替换、保留或关闭实例；`SideView` 独占强类型私有状态，关闭与 Drop 共用一次 checkpoint，写盘只经 WorkspaceWriter。原因：组织状态、GPUI 生命周期与持久事实不得形成双源。边界：隐藏不销毁实例；私有状态在进入 GPUI 前完成预载，无记录才允许默认态回写，读取或解码失败按视图设置写屏障，显式编辑才可解除；普通队列拒收的关闭快照保留为待终态，新一代次成功提交即作废旧待终态，持久化 owner 析构时只补交仍未解决的最新代次。
- **侧栏组织状态恢复**：启动在 GPUI 前从工作区库恢复唯一 `SidebarState` 并移交给 SideViewHost；按钮与显隐等显式组织编辑统一经 WorkspaceWriter 保存。原因：首帧不得先显示默认组织再跳变，启动恢复失败也不得被默认态静默覆盖。边界：无记录或字段级修复不自动回写，只有显式编辑产生写请求；普通队列拒收时保留最新待终态，后续成功入队作废旧副本，持久化 owner 退出时经独立终态通道补交。
- **侧栏几何与手势**：`SidebarState` 只保存用户显式宽度与比例；窗口压缩只夹紧实际绘制和无障碍数值，主区与双槽保留各自最小尺寸，高度不足时侧栏整体纵向滚动，不回写临时几何。键盘与拖动从当前可见值起算，分隔线焦点资格、双击复位、全窗拖动覆盖层及组织变化时的手势取消由 AppRoot 统一协调。原因：临时视口约束不得污染持久偏好，不可见手势层不得截获输入。边界：可见值调整一旦成为显式编辑，仍按 core 几何范围夹紧并保存。
- **分屏空间边界**：拆分动作以窗口尺寸扣除活动栏与实际可见侧栏后的项目内容区校验最小组尺寸，渲染与动作共用同一占宽判定。原因：整窗宽度会让侧栏挤占后的过密分屏错误通过 core 校验。边界：隐藏整个侧栏才释放其宽度，隐藏单个按钮不改变内容区。
- **无旧恢复旁路**：本模块不读取、迁移或清理旧 session 与磁盘历史材料，不与旧 tabs/SplitTree 同步双写。原因：新根必须只有一条布局与生命周期通道。边界：生产恢复只能由启动协调显式注入一致快照，实体层不得自行读盘。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests --features gpui-test-support app_shell::app_root::tests:: -- --test-threads=1`。
- 必测面：添加项目不自动建终端、启动失败原子性、新建/拆分/激活复用实体、关闭释放与空项目保留、项目切换保活、隐藏事件继续处理、Exited 留存、快照全变更落盘与队列拒收后的终态补交、可见/隐藏/Exited 恢复、恢复失败保留面板与写屏障、模态激活零副作用、active 默认焦点、启动不送焦/不写回/不自动打开 cwd、重复根激活、非 Unicode Shell 拒绝、生产 UUIDv7 身份与聚焦组落点；FocusManager 的弱生命周期、项目还焦与模态链；SideView 的实例转换、快捷键、鼠标送焦、活动栏键盘导航、按钮菜单组织与模态还焦、关闭重开、关闭/隐藏还焦、启动不送焦与恢复写屏障；分隔线键盘/鼠标手势、取消与还焦、压缩不回写、双槽最小高度和短窗整体滚动；真实窗口绘制须覆盖空态、组内 active 单视图、横纵分屏几何与项目切换画面。
- 测试启动器使用内存 `test_session`，禁止拉取真实 PTY 或访问用户数据。
