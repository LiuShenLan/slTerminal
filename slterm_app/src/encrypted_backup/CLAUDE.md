# 加密备份与选择性恢复

> 本机加密备份、选择性恢复与恢复点撤回；不承担可分享收集器的敏感字段过滤。

## 决策与红线

- **本机加密落盘**：恢复点正文使用 Windows DPAPI CurrentUser 加密后落本地根，不经会过滤敏感字段的可分享收集器；撤回不要求重新输入口令，密文被篡改或跨账户时解密失败且零写入。原因：恢复点必须能完整还原本机现场，但不能成为凭据外流通道。
- **恢复点范围私有**：撤回时「类别 + 相对名」目标集合必须与该次已验证恢复完全一致；外部导入文件不能借撤回扩展白名单或跨根改写。原因：撤回是写操作，范围必须由恢复时的事实锁定。
- **双根寻址**：设置类别只读写配置根下的 `settings.json` 与 `themes/`；恢复点始终写本地根。学习库、会话快照、工作区物理文件与旧历史文件不属于任何备份类别。收集、恢复、原现场采样与撤回共用同一类别根映射，不按文件名另建归属规则。
- **恢复写入时序单点**：运行期不提供整包或选择性恢复的直接写盘入口；恢复与撤回只写 staged 材料并登记维护请求，实际替换、恢复点采样与失败回滚全部在启动维护期执行。原因：运行中的数据库、设置与旧世代写必须同时失效，即时写入会绕过关闭预检与世代轮换。边界：恢复点原语只由维护执行器调用；撤回实现必须先扩展同一维护请求时序，不得恢复任何第二套运行期写通道；工作区条目的恢复复用 `workspace::restore_workspace` 的唯一快照写通道，不在备份层拼装第二套布局序列化。
- **符号链接拒绝**：恢复目标为符号链接时直接拒绝，不跟随。原因：避免借链写到白名单外。
- **原子写**：所有恢复写入经 `atomic_file`；不存在状态在撤回时删除文件，而不是留下恢复新建的文件。
- **备份格式**：`SLTMBK01 | salt(16) | nonce(12) | ciphertext`；AES-256-GCM，完整头部（魔数｜盐｜nonce）作 AAD；Argon2id m=19456 KiB、t=2、p=1；口令最少 8 字符；派生密钥/明文/恢复点明文全程 Zeroizing。原因：格式身份、盐与 nonce 都由认证标签显式绑定，不依赖 KDF／GCM 隐式性质；旧版仅魔数 AAD 的包一律拒绝。边界：头部任何字段变化都是格式变更，必须同步版本与拒绝用例。
- **备份类别与导出白名单**：设置类别只投影 `SettingsRegistry` 中「可导出且非敏感」的字段并附带合法主题文档；未知命名空间、未登记字段、会话原文、凭据值、AI 会话库、学习库、命令／目录历史与任意 home 路径永不进出包。工作区类别只含一个 `workspace.json` 逻辑投影：项目、规范布局 JSON、终端元数据、Document 位置、ViewState 持久 JSON、侧栏规范 JSON 与按机器窗口几何；不复制 SQLite 物理库、WAL、日志或任意文件。几何携带来源机器标识，恢复时只在本机匹配才写库。导出投影与导入复验共用同一注册表判据；收集目标必须是根内普通文件。原因：白名单即安全边界，名称黑名单无法证明非敏感，物理文件会带出未登记材料。
- **恢复序**：完整鉴权 → 全量校验 → 才允许落盘；任一条不过整单拒写。原因：半份不可信报文不得产生副作用。
- **维护期应用与回滚**：运行期只把所选类别投影为 DPAPI CurrentUser 加密的 staged 材料并登记 `backup.restore` 维护请求（先登记 owner 行、后原子写材料，写失败撤销 Prepared owner；指纹绑定密文、口令与解密明文不落盘；`maintenance/`、请求目录、恢复点目录与文件均收敛为当前用户显式 DACL 并切断继承）；应用在启动维护期进行：先采原现场并写 DPAPI 恢复点 → `Applying` → 逐项写入（设置经 `settings_store` 合并，其余原子写）→ 成功才在同一 Immediate 事务内轮换 `store_epoch` 并置 `Applied` → 清理恢复点与 staged：先删材料再清登记，删除失败保留可判定的阻断事实。暂存、逐项应用、恢复点、提交、回滚与清理都只经 `audit` 记录 operation/path/source/result。任一项写入失败立即全回滚并置 `RolledBack`；回滚失败或材料不可信（指纹/内容/恢复点集合不符）置 `NeedsAttention` 并保留材料。重启遇到 `Applying` 只按恢复点回滚、不重放未知副作用。原因：恢复必须一次要么完整生效要么回到原位，且旧世代写在恢复后必须全部失效。边界：staged 内容与恢复点行必须双向一致；清理失败保留阻断事实，不得静默忽略。

- **撤回与恢复点保留**：应用成功后回填每个对象的恢复后指纹并把恢复点行标记 `Applied`，恢复点密文与行跨重启保留；撤回经 `backup.undo` 维护请求在启动维护期执行，按恢复后指纹逐项比对：匹配项回到恢复前状态，冲突或失败项保留当前内容与恢复点材料，完整成功才删除行与密文。原因：撤回必须依据恢复时锁定的对象集合与真实指纹，不能猜测当前内容。边界：撤回不要求重输口令；已 `Applied` 的恢复点不阻断启动，未终结请求的遗留仍阻断。
- **恢复与维护期工作区**：运行期恢复只选择文件、后台解密预览、做关闭预检并经唯一写线程登记 `backup.restore` 请求；实际替换在启动维护期执行。工作区条目以逻辑投影采样为恢复点原值，应用经 `restore_workspace` 唯一快照写通道；回滚先恢复工作区再回写文件条目，阻断事实保留材料。原因：运行中的数据库不能直接替换，工作区对象也不能伪装成文件恢复。边界：脏文档与 Hooks 草稿在前台拒绝登记；ViewState 经 application 注入的完整注册表复验。
- **导出入口**：设置「应用」页的备份对话框只发起任务；设置类别取运行态 `settings_transfer` 白名单投影，工作区类别经 `WorkspaceWriterClient::collect_workspace_parts` 在唯一写线程先冲刷去抖状态再读取项目快照、ViewState、侧栏与几何。密封与用户目标选择都在后台，写盘只经 `atomic_file`；口令只在本次任务内存中存在。原因：导出必须反映最新生效事实，且不得在前台等待数据库或口令处理之外的文件操作。边界：无 writer 时明确不可用，不降级读取库文件；收集结果与归档条目同批校验，失败零写入。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests <filter> -- --test-threads=1`；禁止 `--lib` 或裸 filter 直打默认 lib target。
- 必测面：密封/打开往返覆盖设置类别与主题、恢复点 DPAPI 往返与篡改拒绝、失败回滚、注册表导出白名单与导入复验、未知段/未登记/敏感字段拒绝、非普通文件拒绝、鉴权失败零落盘、完整头部 AAD 绑死、旧版仅魔数 AAD 包拒绝。
- 维护期：`cargo test -p slterm --test lib_tests maintenance_restore -- --test-threads=1` 覆盖应用后世代轮换与旧世代写拒绝、中断应用重启回滚、应用失败回滚、staged 篡改阻断、空或未清洗材料零写入、凭据与白名单外文件不受影响。
- 真实备份/恢复 UI 流程由构建产物人工验收，边界见 `.claude/docs/testing/exemptions.md`。

## 操作

- 新增备份类别：先评审恢复边界，再扩白名单与往返用例。
- 修改格式或参数：属外部可见契约变更，须评审并补兼容/拒绝用例。
- 新增敏感键：同步导出剥除与导入复验两处，并补往返用例。
