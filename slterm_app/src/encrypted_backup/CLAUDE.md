# 加密备份与选择性恢复

> 本机加密备份、选择性恢复与恢复点撤回；不承担可分享收集器的敏感字段过滤。

## 决策与红线

- **本机加密落盘**：恢复点只在本机加密落盘，不经会过滤敏感字段的可分享收集器。原因：恢复点必须能完整还原本机现场，但不能成为凭据外流通道。
- **恢复点范围私有**：撤回时「类别 + 相对名」目标集合必须与该次已验证恢复完全一致；外部导入文件不能借撤回扩展白名单或跨根改写。原因：撤回是写操作，范围必须由恢复时的事实锁定。
- **双根寻址**：设置与主题归配置根，会话与两类历史归本地根；恢复点始终写本地根。收集、恢复、原现场采样与撤回共用同一类别根映射，不按文件名另建归属规则。
- **选择性恢复顺序**：先采原字节与「不存在」状态 → 本机加密落盘恢复点 → 原子写恢复；恢复失败自动回滚。原因：半份恢复必须可回退。
- **符号链接拒绝**：恢复目标为符号链接时直接拒绝，不跟随。原因：避免借链写到白名单外。
- **原子写**：所有恢复写入经 `atomic_file`；不存在状态在撤回时删除文件，而不是留下恢复新建的文件。
- **备份格式**：`TRMBK001 | salt(16) | nonce(12) | ciphertext`；AES-256-GCM，魔数同时作 AAD；Argon2id m=19456 KiB、t=2、p=1；口令最少 8 字符；派生密钥/明文/恢复点明文全程 Zeroizing。原因：格式身份与密文认证绑死，参数是外部可见的恢复边界。
- **备份类别与敏感键**：只读写登记的类别与主题目录；凭据值、AI 会话库、任意 home 路径永不进出包。敏感键表导出剥除 + 导入复验双闸。原因：白名单即安全边界。
- **恢复序**：完整鉴权 → 全量校验 → 才允许落盘；任一条不过整单拒写。原因：半份不可信报文不得产生副作用。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests <filter> -- --test-threads=1`；禁止 `--lib` 或裸 filter 直打默认 lib target。
- 必测面：密封/打开往返覆盖全部类别、恢复点撤回、失败回滚、符号链接拒绝、敏感键剥除与复验、鉴权失败零落盘、魔数/AAD 绑死。
- 真实备份/恢复 UI 流程由构建产物人工验收，边界见 `.claude/docs/testing/exemptions.md`。

## 操作

- 新增备份类别：先评审恢复边界，再扩白名单与往返用例。
- 修改格式或参数：属外部可见契约变更，须评审并补兼容/拒绝用例。
- 新增敏感键：同步导出剥除与导入复验两处，并补往返用例。
