# 主题库

> 版本化主题文档、自定义主题文件与单文件 JSON 导入；运行时值权威在 `slterm_settings`。

## 决策与红线

- **职责分层**：`document` 拥有版本化 JSON 信封，`store` 拥有自定义主题文件和有界导入；运行时定义值的唯一权威仍是 `slterm_settings`。原因：格式与持久化不应复制值模型。
- **主题文档**：版本化 JSON 信封，字段以 `deny_unknown_fields` 校验；内置主题由同一文档形态生成。原因：导入与内置目录共用同一格式。
- **单文件导入**：外部 JSON 与库内文件共用有界读取，完整解析校验后才调用既有 `import`；不读取 ZIP、不展开包资源、不改写来源文件，失败不产生库内部分写入。原因：导入授权只覆盖本次选择的文件。
- **冷路径同步**：主题文件检查与导入是冷路径同步操作，不落渲染回调。原因：文件读取不得阻塞前台绘制。
- **Revision 前置条件**：自定义主题写入带 revision 前置条件，过期写入被拒绝。原因：并发编辑不得静默覆盖。
- **校验门**：主题色值须过语义槽 WCAG 校验；不达标的主题不得入目录。原因：仅暗色与可读性是产品约束。

## 验收与测试

- 定向测试：`cargo test -p slterm --test lib_tests <filter> -- --test-threads=1`；禁止 `--lib` 或裸 filter 直打默认 lib target。
- 必测面：文档信封往返与未知字段拒绝、文件尺寸上限、非法 JSON 零写入、revision 前置条件、单文件导入与 WCAG 校验门。
- GPUI 用例覆盖文件选择器、合法导入、非法输入、取消与忙态复位。

## 操作

- 新增主题：以主题文档形态加入内置目录，并通过 WCAG 校验。
- 修改文档格式：同步 schema 版本、解析逻辑与导入用例。
- 自定义主题写入：必须带 revision 前置条件，冲突时拒绝而非覆盖。
