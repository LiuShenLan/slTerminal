# 输出规范

## 目录结构

```
{baseDir}/{topic-slug}/
├── README.md              # 总索引
├── D1-{slug}.md           # 方向 1 汇总
├── D2-{slug}.md           # 方向 2 汇总
├── D1/                     # 方向 1 子代理结果
│   ├── 01-{sub}.md
│   └── ...
└── D{N}/                   # 方向 N 子代理结果
```

- `{baseDir}`: 默认 `docs/research/`，可按需调整
- `{topic-slug}`: 主题的 kebab-case，如 `claude-code-hooks`
- 方向汇总文件在 `{baseDir}/{topic-slug}/` 根
- 子代理结果在 `D{N}/` 子目录

## README.md 模板

```markdown
# {topic} 信息检索总览

> 检索日期: {date}
> 目的: {一句话说明}

## 检索范围

{一段话描述}

## 文件索引

| 方向 | 汇总文件 | 子文件数 | 关键发现数 |
|------|---------|--------|----------|
| D1: {title} | [D1-{slug}.md](D1-{slug}.md) | {count} | {count} |
| ... | ... | ... | ... |

## 统计

- 文件总数: N
- 总行数: N
- 信息来源: 官方文档 > GitHub > 博客 > 社区

## 跨方向关键发现

1. {发现} (来源: D1, D3)
2. ...
```

## 汇总文件固定段落

每个方向的汇总 md 必须包含：

1. **检索日期 + 来源优先级声明**
2. **关键发现**：每条附 URL
3. **来源清单表**：URL | 类型 | 关键内容
4. **子代理结果引用**（如有）

可选段落：
- "对 {项目} 的启示"（若研究目的是为某项目提供决策依据）

必须包含的声明：
```markdown
> 检索日期: YYYY-MM-DD
> 来源优先级: 官方文档 > GitHub issues/discussions > 技术博客 > 社区讨论
```
