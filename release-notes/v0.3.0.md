# slTerminal 0.3.0

## English

### Added

- A Windows-native, single-process GPUI terminal: one window, one instance, dark mode only, GPU-accelerated rendering. No WebView or Node runtime.
- Tabs and split panes: terminal tabs, grid splits, pane zoom, drag-to-dock; layout, launch identity and WindowState are restored on restart.
- Settings center with application/appearance/profiles/interaction/advanced/localization/reset pages and an agent group; eight built-in dark themes (Linear default); English and Chinese UI.
- Sidebar with activity bar, top/bottom view slots and a file explorer (git status coloring, create/delete/rename/open, recycle-bin delete).
- AI CLI integration: screen detection and status projection for 27 AI CLIs; hook installation for Claude Code, Kimi, Codex, Pi and OpenCode; Claude Code and Codex session history; bundled runtime skill.
- Runtime API: loopback JSON Lines control plane, versioned envelope, `slterm ctl` and `slterm env`, window/tab/pane/agent resource verbs, single-instance handover.
- Files and editing: code/document/image tabs, read-only dual-pane diff, git gutter, Markdown math rendering, terminal math overlays, completion engine.
- System integration: tray, Windows toast notifications, taskbar progress, launch at login, window materials and wallpaper, update checking and background download.
- Security: credentials in Windows Credential Manager, audited settings writes, passphrase-protected encrypted local backup with a strict allow-list.
- Packaging: user-level Inno Setup installer, portable zip, SHA256SUMS, pinned size budget and a local release verification chain.

### Fixed

- Windows 10 handshake pollution: DA1 queries are no longer forwarded into user input, fixing the startup bell, `[?1;2c` on the input line and corrupted restore commands.
- Windows 10 key-event input: blind CPR injection removed; DSR is answered or stripped according to transport capability, fixing the lost first character.
- Windows 10 full-screen CLIs: bundled ConPTY host restores mouse-wheel scrolling in full-screen TUIs.
- Git concurrency: all git subprocesses use `--no-optional-locks`, avoiding index locks or background gc from read operations.

### Improved

- Rendering and terminal core run in one process without cross-process IPC round-trips; blocking I/O and network queries run in the background.
- Release chain treats the shared build and the embedded file manifest as a contract: installer and portable zip share the same feature graph, with freshness, version read-back and size-budget checks.

### Note

- Launching the GUI from an existing pwsh/cmd session blocks that shell. Use the installed shortcut or `Start-Process slterm` for daily use.

## 中文

### 新增

- Windows 原生 GPUI 单进程终端：单窗口单实例、仅暗色模式、GPU 加速渲染；不依赖 WebView 或 Node 运行时。
- 标签页与分屏：终端标签页、网格分屏、窗格缩放、拖拽停靠；布局、启动身份与 WindowState 在重启后恢复。
- 设置中心：应用/外观/配置/交互/高级/本地化/重置页与 Agent 组；八套内置暗色主题（默认 Linear）；中英双语界面。
- 侧栏：活动栏、上下双槽与文件浏览器（git 状态着色、创建/删除/重命名/打开、回收站删除）。
- AI CLI 集成：27 家 AI CLI 的屏幕检测与状态投影；Claude Code、Kimi、Codex、Pi、OpenCode 的 hook 安装；Claude Code 与 Codex 历史会话；随包 runtime skill。
- Runtime API：loopback JSON Lines 控制面、版本化信封、`slterm ctl` 与 `slterm env`、window/tab/pane/agent 资源动词、单实例移交。
- 文件与编辑：源码/文档/图片标签页、只读双栏 diff、git gutter、Markdown 数学渲染、终端数学覆盖层、补全引擎。
- 系统集成：托盘、Windows toast 通知、任务栏进度、开机启动、窗口材质与壁纸、更新检查与后台下载。
- 安全：凭据存入 Windows 凭据管理器、设置写审计、口令保护的本地加密备份（严格白名单）。
- 打包：用户级 Inno Setup 安装器、便携 zip、SHA256SUMS、体积预算钉测试与本地发布核验链。

### 修复

- Windows 10 握手污染：DA1 查询不再透传进用户输入，修复启动蜂鸣、行首 `[?1;2c` 与恢复命令被污染。
- Windows 10 键事件输入：移除盲注 CPR；DSR 按传输层能力代答或剥离，修复敲键丢首字符。
- Windows 10 全屏 CLI：捆绑新版 ConPTY 宿主，恢复全屏 TUI 的鼠标滚轮。
- git 并发：所有 git 子进程使用 `--no-optional-locks`，读操作不再触发 index 锁或后台 gc。

### 改进

- 渲染与终端核心在同一进程内运行，去掉跨进程 IPC 往返；阻塞 I/O 与网络查询在后台执行。
- 发布链以共享构建与包内清单为合同：安装器与便携包同源同 feature 图，新鲜度、版本回读与体积预算在发布前机械校验。

### 注意

- 从 pwsh/cmd 直接启动 GUI 会同步阻塞父 shell。日常使用请走安装器快捷方式或 `Start-Process slterm`。
