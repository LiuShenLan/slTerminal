# slTerminal 0.3.0

## English

### Added

- A Windows-native, single-process GPUI terminal: one window, one instance, dark mode only, GPU-accelerated rendering. No WebView or Node runtime.
- Projects and workspace: switching projects preserves running terminals; panel groups and splitters are adjustable, and layout plus per-view state restore by stable `ViewKey`.
- Shared documents: one live Document per real file across projects; Editor, Markdown and Diff share text, undo, dirty state and external-change conflicts; autosave and crash-snapshot recovery are included.
- Sidebar: activity bar, file explorer with planned file operations and recycle-bin delete, Commit view and agent global file roots.
- AI CLI integration: hook installation and status signals for Claude Code, Codex, OpenCode, Kimi, Pi and OhMyPi; terminal screen status fallback.
- Appearance and settings: built-in and custom color-only themes (Linear default), window materials, fonts and a local background image; English and Chinese UI.
- Runtime v2: a loopback-only control plane for discovery, snapshots, project activation events and panel/terminal operations; tokens live only in Windows Credential Manager.
- Security: PathPolicy authorization, audited settings writes, encrypted local backup with a strict allow-list.
- Packaging: user-level Inno Setup installer, portable zip, SHA256SUMS, pinned size budget and a local release verification chain.

### Fixed

- Windows 10 handshake pollution: DA1 queries are no longer forwarded into user input, fixing the startup bell, `[?1;2c` on the input line and corrupted restore commands.
- Windows 10 key-event input: blind CPR injection removed; DSR is answered or stripped according to transport capability, fixing the lost first character.
- Windows 10 full-screen CLIs: bundled ConPTY host restores mouse-wheel scrolling in full-screen TUIs.
- Git concurrency: all git subprocesses use `--no-optional-locks`, avoiding index locks or background gc from read operations.

### Improved

- Rendering and terminal core run in one process without cross-process IPC round-trips; blocking I/O and network queries run in the background.
- File identity, editing, undo, saving and external conflicts converge on one shared Document instead of per-panel copies of the text.
- The release chain treats the shared build and the embedded file manifest as a contract: installer and portable zip share the same feature graph, with freshness, version read-back and size-budget checks.

### Note

- Launching the GUI from an existing pwsh/cmd session blocks that shell. Use the installed shortcut or `Start-Process slterm` for daily use.

## 中文

### 新增

- Windows 原生 GPUI 单进程终端：单窗口单实例、仅暗色模式、GPU 加速渲染；不依赖 WebView 或 Node 运行时。
- 项目与工作区：项目切换保留运行中的终端；面板组与分隔线可调整，布局与逐视图状态按稳定 `ViewKey` 恢复。
- 共享 Document：同一真实文件跨项目只有一份实时正文；Editor、Markdown 与 Diff 共享文本、撤销、脏状态与外部冲突；支持自动保存与崩溃快照恢复。
- 侧栏：活动栏、文件浏览器（计划式文件操作与回收站删除）、Commit 视图与 Agent 全局文件根。
- AI CLI 集成：Claude Code、Codex、OpenCode、Kimi、Pi 与 OhMyPi 的 hook 安装与状态信号；终端画面状态兜底。
- 外观与设置：内置与自定义纯颜色主题（默认 Linear）、窗口材质、字体与本地背景图；中英双语界面。
- Runtime v2：仅 loopback 的控制面，支持发现、快照、项目激活事件与面板／终端操作；token 只存 Windows 凭据管理器。
- 安全：PathPolicy 授权、设置写审计通道、严格白名单的本地加密备份。
- 打包：用户级 Inno Setup 安装器、便携 zip、SHA256SUMS、体积预算钉测试与本地发布核验链。

### 修复

- Windows 10 握手污染：DA1 查询不再透传进用户输入，修复启动蜂鸣、行首 `[?1;2c` 与恢复命令被污染。
- Windows 10 键事件输入：移除盲注 CPR；DSR 按传输层能力代答或剥离，修复敲键丢首字符。
- Windows 10 全屏 CLI：捆绑新版 ConPTY 宿主，恢复全屏 TUI 的鼠标滚轮。
- git 并发：所有 git 子进程使用 `--no-optional-locks`，读操作不再触发 index 锁或后台 gc。

### 改进

- 渲染与终端核心在同一进程内运行，去掉跨进程 IPC 往返；阻塞 I/O 与网络查询在后台执行。
- 文件身份、编辑、撤销、保存与外部冲突收敛到同一共享 Document，不再按面板复制正文。
- 发布链以共享构建与包内清单为合同：安装器与便携包同源同 feature 图，新鲜度、版本回读与体积预算在发布前机械校验。

### 注意

- 从 pwsh/cmd 直接启动 GUI 会同步阻塞父 shell。日常使用请走安装器快捷方式或 `Start-Process slterm`。
