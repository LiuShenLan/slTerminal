# 发布说明纪律

## 决策与红线

- **只写证据**:每条都须有代码、构建或真实运行证据支撑,描述用户可核验
  的结果;禁用内部类型名、辅助函数名与提交标题充数。
- **双语同事实**:英文与中文小节表达同一变化,不增删事实。
- **同步纪律**:源文件、安装器内置 CHANGELOG、便携包内置 CHANGELOG 三处
  必须同步;正式构建前完成对应版本小节(打包脚本前置断言)。
- **开放范围如实**:部分覆盖或仍开放的问题标明范围,不写成已交付。
- **Issue 引用**:有公开 issue tracker 后再启用 URL 引用;引用前先读原文,
  不凭标题转述。
- **SHA256 禁手抄**:版本 notes 末尾的哈希块由 `scripts/verify-release.ps1`
  生成的 `SHA256SUMS` 填入。

## 文件形态

- `unreleased.md`:进行中变化的指针与草稿。
- `vX.Y.Z.md`:按版本归档,模板为 `# slTerminal X.Y.Z` + English +
  中文 + SHA256 块。
