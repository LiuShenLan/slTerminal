# 发布说明纪律

> 面向用户的版本说明；只写可核验结果，双语同事实。

## 决策与红线

- **只写证据**：每条都须有代码、构建或真实运行证据支撑，描述用户可核验的结果；禁用内部类型名、辅助函数名与提交标题充数。原因：发布说明是用户信任面。
- **双语同事实**：英文与中文小节表达同一变化，不增删事实。
- **同步纪律**：源文件、安装器内置 CHANGELOG、便携包内置 CHANGELOG 三处必须同步；正式构建前完成对应版本小节（打包脚本前置断言）。
- **开放范围如实**：部分覆盖或仍开放的问题标明范围，不写成已交付。
- **Issue 引用**：有公开 issue tracker 后再启用 URL 引用；引用前先读原文，不凭标题转述。
- **SHA256 禁手抄**：版本说明末尾的哈希块由 `scripts/verify-release.ps1` 生成的 `SHA256SUMS` 填入。
- **编号禁令**：发布说明不写内部阶段号/批次号/规则号；只写用户可感知的变化、版本、日期与哈希。

## 验收与测试

- 正式构建前检查对应版本小节存在且与 CHANGELOG 同步；打包脚本会拦截缺失。
- 双语小节逐条对照，确保事实一致。
- SHA256 块与 `SHA256SUMS` 复算一致。

## 操作

- `unreleased.md`：进行中变化的指针与草稿。
- `vX.Y.Z.md`：按版本归档，模板为 `# slTerminal X.Y.Z` + English + 中文 + SHA256 块。
