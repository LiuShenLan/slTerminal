# slterm_document（core 层）

> 文本、编码、差分、语法与 Markdown 语义核心，不持 GPUI 或 I/O。

## 决策与红线

- **纯文档边界**：只承载文本、编码、差分、语法与 Markdown 语义。原因：文档语义须可独立于界面和外部系统验证。边界：不得持有 GPUI 类型或执行 I/O。
- **文本状态身份**：`TextStateId` 使用 application 注入的 UUIDv7；新编辑产生新值，撤销／重做恢复原值，不以正文散列代替身份。Session 记录全部曾用值，redo 清空或历史淘汰后仍禁止新编辑复用。原因：同一正文经不同编辑路径到达时仍需精确区分保存与撤销状态。边界：本 crate 只校验和保存值，不生成随机数。
- **编辑事务单点**：所有 Rope 修改只经 `DocumentRegistry::apply` 消费 `EditTransaction`；校验 Document、revision、只读状态、UTF-8 字节边界、区间顺序与后台原文后，在候选 Rope 上按降序应用，成功才推进单调 revision 和当前状态。差量历史保存实际应用顺序的逆操作及前后 TextStateId；普通相邻输入按 600 毫秒合并，替换全部／重读／行尾变化不合并，撤销预算固定 8 MiB 并先淘汰最旧组。原因：文本、撤销和清脏必须共享一个原子事实。边界：undo／redo 只恢复文本与状态身份，不恢复视图瞬态；任何失败不改正文、revision 或历史。
- **后台查找与替换**：`DocumentTextRequest` 绑定 DocumentId、文本 revision、分页源代次与请求代次；Rope 与 Paged 均经连续 TextChunk 流式读取，字面量查找保留字符安全的跨块重叠区，完整复制不截断，选区复制到达右边界即停读，取消只经有界通道且发送端断连即取消。替换请求在后台编译正则并展开捕获组，确认后经一个 BackgroundReplacement 事务提交，旧 revision 或原文失配均不改正文；Paged 不提供替换全部或原地保存。原因：后台结果不得污染新正文，跨块匹配与整次撤销不能依赖视图分页。边界：界面状态与确认交互由视图层持有，core 不执行 I/O。
- **保存代次对账**：`begin_save` 捕获 DocumentId、TextStateId、Rope、磁盘基线、位置、编码、授权代次和单调保存代次，并建立撤销合并边界；同一 Document 同时最多一个在途保存。`complete_save` 只接受当前代次回执，更新替换后的磁盘基线与文件身份，并把 saved_state 设为请求捕获状态而非完成时当前状态；`fail_save` 只释放对应在途闸门。原因：后台写盘期间允许继续编辑，迟到回执不得清错新草稿或覆盖新一代基线。边界：保存请求不可变，后台不得回读 Session；失败与过期回执不改正文、保存状态或基线。另存为回执只能经 `complete_save_as` 提交，保持 DocumentId 并原子重绑全部路径与文件身份索引；目标被其他 Document 占用时提交同样失败且不改态。普通保存回执只更新当前位置的文件身份，不回滚已提交的外部改名。
- **编码与内容路由**：`DocumentContent` 封闭为 Editable／Paged／Unavailable；前 8192 字节按解码后的字符单元检查 NUL，UTF-16 不得因零字节误判二进制。自动识别仅接受 BOM 或合法 UTF-8，GBK／GB18030 必须显式指定，所有解码与回写均严格失败而不替换字符。文本统一为 LF，保存按首个磁盘换行恢复，BOM、原始编码与末尾换行事实独立保留；`DocumentEncoding::decode_prefix` 严格区分非法序列与不完整尾字符，并返回可安全切分的源字节边界；增量解码器的已读计数包含内部暂存字节，不得直接作为分页位置。新文件默认 UTF-8、无 BOM、CRLF。原因：未知编码、二进制与分页内容不得共享一个可保存正文基线。边界：真实字节数超过 10,000,000 关闭文档内补全，超过 50,000,000 进入 Paged，超过 200,000,000 关闭语法；Paged 的 `PageIndex` 只保存连续、非空且不超过 2 MiB 的源字节范围；`PagedSource` 同时持有页索引与行索引，外部刷新不得丢失行事实；`PagedLineIndex` 只保存逐页换行数、换行结尾事实与 UTF-8 页偏移，跨页长行归起始页并由视图拼接后续页首段，使可见行无需物化全文即可获得全局文本坐标；`DocumentPageCache` 以 DocumentId、源代次和页号隔离缓存，全应用 LRU 上限 128 MiB，不保存可编辑或脏正文。真实分页读取、Session 降级与外部增长切换由后续切片实现，本模块不把有限前缀伪装成完整可编辑正文。
- **Document 正文形态**：`DocumentBody` 封闭为 Editable Rope 与带页索引、全文件指纹、单调源代次的 `PagedSource`；`text()` 仅对 Editable 返回 Rope，Paged 在类型层只读且不得建立空 Rope 占位。原因：分页只读内容不得与可编辑正文共享保存或撤销入口。边界：模式切换清理不可用的文本历史，TextStateId 历史仍不得复用；Session 持久保存分页源代次高水位，Paged→Editable→Paged 不复用旧 PageKey，代次耗尽不得先改历史或正文。
- **Document 聚合单点**：`DocumentRegistry` 以 `DocumentId` 持有全部存活 `DocumentSession`，正文使用 Rope，并持原始编码、只读元数据与磁盘基线，另以文件身份与规范路径建立唯一索引。打开先命中真实文件身份；无法取得身份时按规范路径去重，后续取得身份只补充原聚合索引。别名命中只增加路径索引，不搬移既有保存位置。路径已绑定旧身份而本次解析为另一身份时必须创建新聚合，不继承旧正文。原因：路径、别名与文件替换都不能复制或错绑 Document，在途保存回执也不得落向另一别名。边界：本 crate 不执行解析或 I/O；真实身份由 application 在读取句柄上取得，编辑与保存共用同一 Session；失去全部布局引用或打开候选失败时经同一 Registry 回收聚合及全部别名索引。
- **异常恢复与重授权**：`DocumentRegistry::restore` 分别接收 saved/current TextStateId、正文、磁盘基线、冲突与 ReadRevoked，不建立撤销历史；`reauthorize` 只在显式重授权后更新真实位置、基线与冲突并清除失权，不改正文、状态身份或撤销；恢复目标已占用时 fail-closed，禁止以 Existing 结果吞掉输入。原因：异常恢复不能制造撤销树，根外正文恢复也不能隐式恢复磁盘授权。边界：本 crate 只执行纯状态转换，启动授权、读盘与快照校验由 application 完成。
- **外部变化单点**：`external_request` 捕获 revision、TextStateId、磁盘基线、位置与授权代次；`apply_external` 只接受仍匹配该快照的结果。干净重载更新正文、编码与基线并记录独立撤销组；干净 Editable 遇到超限外部增长可切为 Paged，脏或在途保存 Document 只进入冲突并保留 Rope 与保存出口；脏、在途保存或已有冲突转为全 Session 共享的 Modified 冲突并携带独立磁盘快照；Deleted 保留正文，删除后的重建也只转为 Modified，不自动清除冲突。ReadRevoked 保留全部内容并停止后续刷新；Relocated 复核目标占用与文件身份后只重绑位置，不改变 DocumentId、正文或 revision。原因：watcher 迟到结果、失权与改名不得覆盖新编辑或复制聚合。边界：冲突解决界面与显式重新授权由后续视图链消费同一 Session，不另建正文。
- **Git 固定版本值**：`CommitId` 只接受完整 40 或 64 位小写十六进制对象 ID；`RepoPath` 只接受正斜杠规范相对文件路径。原因：短哈希、引用名与多义词法路径不能固定版本对象。边界：对象存在性由 GitFacade 查询，本 crate 不执行 Git。
- **仓库路径事实单点**：`RepositoryBinding` 直接复用 `slterm_path` 的规范路径与文件身份，不另建路径 DTO。原因：绑定复核必须与 PathPolicy 使用同一身份事实。边界：本 crate 只比较纯值；真实路径解析、HEAD 存在性与对象读取由 application 提供。
- **语言注册单点**：`LanguageRegistry` 以封闭 `LanguageId` 与静态 `LanguageDescriptor` 统一扩展名、固定文件名、Markdown 别名、grammar、highlight 与 fold query；路径匹配忽略 ASCII 大小写，JSONC／JSON5 共用 JSON5 高亮超集但不承担 JSONC 验证。每种语言必须编译真实 highlight 与 fold query，只有 PlainText 无 grammar，未知类型不得借旧映射猜测。原因：路径映射、语法任务与视图不得各自维护语言表。边界：手动覆盖只改变后续语法高亮，不改变路径、内容或保存行为；Markdown 语义仍归 Comrak，Tree-sitter 只负责源码高亮。
- **增量语法后台单点**：`SyntaxWorker` 独占单个 Document 的 Rope 快照、Parser 与旧树；编辑按实际应用顺序携带全部 `InputEdit`，过期命令仍须推进正文与旧树，但只有当前代次可解析和发布。新代次与关闭经 `ParseOptions::progress_callback` 中止，取消即使返回 `None` 也必须先 reset 再解析新代次，禁止续跑旧栈。隐藏释放旧树，重新可见从最新 Rope 全量重建；无增量快照与历史移动同样经 `rebuild` 丢弃旧树；`SyntaxHighlighter` 复用编译查询，按可见范围输出裁剪后的非重叠语义 span，重叠捕获后者覆盖前者。命令与结果均有界，队列拒收只保留最新 Rope 待写副本，flush 或后续编辑经全量重建合并且不得断代，结果同时核对 revision 与代次，结果队列只传 `Weak<Tree>` 且采纳当前代次时才升级为 `Arc<Tree>`，结果满时只阻塞后台发布，shutdown 断开命令、排空结果后 join，前台 Drop 不等待。原因：迟到解析、取消残留与隐藏资产不得污染新正文或泄漏线程。边界：PlainText 不创建 worker；调用方必须提交真实完整编辑与单调 revision，分页正文不建立伪 Rope。
- **grammar 单一运行时**：`tree-sitter-json5 0.1.0` 与 `tree-sitter-dockerfile 0.2.0` 使用仓内锁定源码快照，Rust binding 统一为 `LanguageFn`，随包 highlights query 直接导出。原因：全部 grammar 必须由 tree-sitter 0.27.1 执行 ABI 与真实 query 审计，旧 binding 不得带入第二套原生运行时或重复 query 副本。边界：C grammar、scanner 与 query 只按各自快照锚升级；测试不开放手写 C 入口适配，生产库保持 `forbid(unsafe_code)`。
- **SCSS 固定 MSVC 修复 rev**：crates.io 的 `tree-sitter-scss 1.0.0` 会向 MSVC 直传 GCC 警告参数，固定上游 `9ab738d22bb248771d42e8678d1a307d14990df1`、版本仍为 1.0.0。原因：该 rev 相对发布基线不改 grammar、query 或 Rust 入口，只补平台构建分支及 README。边界：不得移动 rev；回到 crates.io 或升级前须重新审计并实测 Windows x64。

## 验收与测试

- 定向测试：`cargo test -p slterm_document --test lib_tests <filter> -- --test-threads=1`；禁止 `--lib` 或裸 filter 直打默认 lib target。
- grammar 审计：`cargo test -p slterm_document --test lib_tests grammar_audit -- --test-threads=1`；每种 grammar 必须实际验证 ABI 13–15、真实 highlights query 编译和最小合法样例无错误，禁止 skip、空 query 或占位 query。
- 语法 worker：`cargo test -p slterm_document --test lib_tests syntax::tests -- --test-threads=1`；覆盖完整多编辑、Unicode Point、revision 丢弃、取消后 reset、有界背压、隐藏释放、重新可见重建与关闭回收。
