2. 人工验证点 1：真实 claude 会话自动刷新

人工必测

验证目标：导航树历史区按配置频率自动更新（无需手动点刷新钮），与磁盘一致。

  1. 启动应用，打开一个项目，展开导航树历史区——记录当前会话条目数与最新标题。
  2. 在一个终端页签运行真实 claude 会话，让它产出若干条历史记录（或等磁盘 %USERPROFILE%\.claude\projects\**\*.jsonl 有新会话文件出现）。
  3. 不做任何刷新操作，等待默认 3 秒刷新周期（sessionRefresh 默认 intervalSec=3）的 2–3 倍。
  4. 观察历史区：新会话应自动出现；进行中会话的标题/时间应与磁盘 jsonl 一致。
  5. 点击刷新钮（手动触发）——结果应与自动刷新一致，无重复条目。

期望：新会话 3 秒内自动出现；手动刷新与自动刷新结果一致；无闪烁/无重复。

3. 人工验证点 2：禁用套餐余量 → 轮询停止 / footer 隐藏 / 恢复

人工必测

验证目标：勾选禁用 planBalance 后，后端轮询停止、导航树底部余量 footer 隐藏、最后快照保留；重新启用后恢复。

  1. 前置：在 user 层 settings.json（~/.claude/settings.json）配置套餐余量相关 env（假 key 或真实 key，视你的环境），启动应用。
  2. 确认导航树底部出现「套餐余量」footer 行（plan-balance-row）。
  3. 打开设置中心 → 「后台定时任务」页 → 取消勾选「套餐余量查询」行的启用开关。
  4. 观察：footer 应立即隐藏（事件驱动）；磁盘 settings.json 中 backgroundTasks.planBalance.enabled === false。
  5. 等待 ≥ 原轮询周期（默认 10 秒）× 2，确认无新轮询请求（可观察网络/日志）。
  6. 重新勾选启用——footer 应重显最后快照（不重新拉取也显示），磁盘 enabled 回 true，轮询恢复。

期望：禁用 → footer 立即隐藏 + 磁盘落盘 false + 轮询停止；重启用 → footer 重显最后快照 + 轮询恢复。全程无闪烁（初始加载也不显示后再隐藏）。

4. 人工验证点 3：设置中心「后台定时任务」页操作链路

人工必测

验证目标：新配置页两行任务（套餐余量查询 / 会话历史刷新）的勾选、频率修改、非法输入交互闭环。

  1. 打开设置中心 → 左侧导航应有「后台定时任务」页（原「套餐余量查询」页已替换）。
  2. 页面应显示两行：套餐余量查询（勾选默认开、频率默认 10、范围提示「10–3600 秒」）与 会话历史刷新（勾选默认开、频率默认 3、范围提示「2–300 秒」）。
  3. 改套餐余量频率为 15 → 失焦/回车 → 磁盘 backgroundTasks.planBalance.intervalSec === 15，输入框回显 15，无红字。
  4. 输入非法频率（如 1、abc、3.5、空）→ 失焦 → 行内红字显示范围提示，不提交、无 toast，输入保留。
  5. 取消勾选「会话历史刷新」→ 磁盘 sessionRefresh.enabled === false，导航树历史区停止自动刷新（可对照验证点 1 观察）；重新勾选恢复。

期望：两行齐备、默认值正确；合法频率落盘并回显；非法输入红字不提交不 toast；勾选启停即时生效（sessionRefresh 前端调度器 + planBalance 后端轮询双侧）。
