## 1. 概述

### 1.1 背景

slTerminal 已有 **agent 侧栏视图**（agent-status）展示**活跃**的 Claude Code 会话（运行中的 claude 进程，行级实时监控）。本需求为其补充**历史会话**能力：查询历史 session 并通过 `claude --resume <id>` 恢复。

### 1.2 目标

用户能在 slTerminal 内：
1. **查询**本机所有 Claude Code 历史会话（跨项目、按项目分组、元数据级搜索）
2. **恢复**任意历史会话——一键在终端面板中重新打开 `claude --resume <id>`，且工作区上下文自动编排到会话所属项目
3. **管理**会话：复制恢复命令、分支恢复（fork）、删除、重命名

### 1.3 价值与动机

- **跨项目找回**：官方 `claude --resume` picker 默认限定当前项目目录，50 条硬上限，跨项目是社区多年未实现的诉求（#59941/#41021/#49095 均 closed）；当前项目的最近会话用官方 `claude --continue` 即可，**专门 UI 的价值就在"找回不记得在哪开始的会话"**
- **Windows 生态空档**：社区 20+ 工具中明确支持 Windows 的仅 6 家，本项目是 Windows 原生终端模拟器，属空白机会
- **终端原生集成优势**：恢复 = 直接 spawn PTY 且 cwd 设为目标项目目录，天然免去 shell wrapper 的 eval/目录持久化问题（官方 picker 跨项目时只复制命令到剪贴板）

### 1.4 信息来源

`docs/claude-his/`（D1 存储位置、D2 JSONL 格式、D3 CLI 查询能力、D4 文件扫描与第三方、D5 resume 用法、D6 resume 限制、D7 开源工具、D8 终端集成）。以下全部事实约束均出自该系列文档，实施前如有版本疑问以官方文档（code.claude.com/docs）复核。

## 2. 领域术语

| 术语 | 定义 |
|------|------|
| **会话（Session）** | 一次 Claude Code 对话。有唯一 sessionId（UUIDv4），持久化为 transcript 文件 |
| **活跃会话** | 正在运行的会话（TerminalRegistry 有记录 = 运行中，二态模型：存在即运行中） |
| **历史会话** | 磁盘上存在的全部会话 transcript（含运行中的——两区重叠） |
| **Transcript** | 会话的 JSONL 记录文件，路径 `~/.claude/projects/<编码路径>/<sessionId>.jsonl` |
| **会话 ID** | UUIDv4，与 transcript 文件名主干一致，恢复命令 `claude --resume <id>` 的凭据 |
| **ai-title** | JSONL 中的自动标题条目（覆写式 last wins，写入文件尾部），列表标题的第二优先级来源（第一优先级为 custom-title，决策 22） |
| **summary** | JSONL 首行条目，含人类可读摘要 + leafUuid |
| **首条 prompt** | 会话中第一条"人类可见"的用户输入（跳过工具结果/元消息/本地命令输出） |
| **孤儿会话** | 会话起始目录已被删除/重命名/移动，无法再恢复的会话（磁盘文件仍在但不可达） |
| **运行中标记** | 历史列表中 ⚡ 标记，标识当前正在运行的会话 |
| **项目分组** | 「全部项目历史会话」下的二级折叠框，按会话起始目录分组 |

## 3. 数据源与格式约束（开发者必读）

> 本章是功能实现的事实基础，全部来自已核验检索报告。**违反本章任何一条都会导致功能在真实环境失效。**

### 3.1 存储位置与目录结构

- 存储根：`~/.claude/projects/`（Windows = `%USERPROFILE%\.claude\projects`）
- 一级目录名 = 会话启动时工作目录绝对路径的编码：非字母数字字符（含 `/`、`\`、`:`、`_`）全部替换为 `-`
  - 例：`C:\Users\you\app` → `C--Users-you-app`（冒号+反斜杠连续替换产生双破折号）
  - **编码有损不可逆**：真实路径**必须**从 JSONL 内容读取 `cwd` 字段，禁止反解码目录名
- 会话文件：`<uuidv4>.jsonl`，文件名主干 = sessionId
- 子代理 transcript：`agent-<id>.jsonl`（部分版本平铺于项目目录）或 `<session>/subagents/agent-<id>.jsonl`（子目录形态）——**两种形态均存在（随版本变化），必须都排除**

### 3.2 JSONL 行格式要点

每行一个 JSON 对象，关键行类型（未知类型必须忽略而非报错）：

| type | 用途 | 关键字段 |
|------|------|---------|
| `summary` | 会话文件首行 | `summary`（标题）、`leafUuid` |
| `user` | 用户输入或工具结果载体 | `message`（content 为字符串或块数组）、`isMeta` |
| `assistant` | 模型响应与工具调用 | `message`（含 content 块数组、usage） |
| `ai-title` | 自动/自定义标题（覆写式，last wins） | 标题文本 |
| 其他 | system/progress/queue-operation 等 | 忽略 |

信封字段（几乎所有行都有）：`type`、`uuid`、`parentUuid`、`timestamp`（ISO 8601 UTC，毫秒精度带 `Z` 后缀）、`sessionId`、`cwd`、`gitBranch`、`version`。

### 3.3 解析容错规则（硬性）

1. **未知 type 一律忽略**——格式随版本增长（已观测 15+ 种 type）
2. **字段可缺失、形状会漂移**——解析器永不崩溃，缺字段用回退
3. **容忍 EOF 处截断 JSON 行**——会话运行中文件持续写入，读时可能遇半行
4. **一条 API 消息可能拆多行**（同 `message.id`）——本功能不统计 token，不受影响；但首条 prompt 提取要注意不要取到工具结果载体
5. **文件从几 KB 到 20+ MB**——元数据扫描只读文件**首行 + 尾部 ≤64KB**（ai-title last wins 在尾部）+ 顺序扫描至首条可见 user 消息（大文件前几行通常是 user 消息），禁止整文件读取
6. **时间戳 `Z` 后缀**——解析时间须按 ISO 8601 UTC 处理

### 3.4 性能与体积约束

- 生态实测总量可达 ~1.6GB、数千会话——扫描必须轻量（每文件只读首行/尾部/首条 prompt），异步执行，展示加载态
- 生态实测元数据级扫描：18ms（小规模）～秒级（大规模），展开下拉框时全量扫描可接受

### 3.5 其他事实约束

- **30 天清理窗口**：`cleanupPeriodDays` 默认 30 天，Claude Code 启动时删除过期 transcript——历史覆盖面上限，删除不可恢复（用户改配置可延长）
- **明文存储**：transcript 未加密，可能含命令输出/凭据——列表展示的内容即敏感内容
- **无原生 list 命令**：官方无 `claude --list-sessions`，唯一非交互路径是 Agent SDK `listSessions()`（TypeScript，本项目不引入）；扫描文件是唯一通用方案

## 4. 功能需求

### 4.1 视图结构

**宿主**：扩展现有 agent 侧栏视图（agent-status）。视图内改为三个可展开/收起下拉框：

```
┌─────────────────────────────┐
│ AGENT 状态                  │  ← 视图标题（沿用现有样式）
├─────────────────────────────┤
│ ▸ 活跃会话 (3)              │  ← 下拉框 1：现有逻辑，完全不变
│ ▸ 当前项目历史会话 (12)     │  ← 下拉框 2：当前活跃项目的历史会话
│ ▸ 全部项目历史会话 (45)     │  ← 下拉框 3：本机全部项目，二级折叠分组
│    └ 📁 slTerminal (20)     │     项目分组标题 = basename + 悬停完整路径
│    └ 📁 myproject (25)      │     组内为会话行
└─────────────────────────────┘
```

**下拉框定义**：

| 下拉框 | 内容 | 展开时机 |
|--------|------|---------|
| `活跃会话` | 现有逻辑不变（TerminalRegistry 订阅实时） | 现有行为 |
| `当前项目历史会话` | 当前活跃项目（activePageId → project rootPath）下创建的会话 | 展开时全量扫描 |
| `全部项目历史会话` | 本机全部项目，按会话起始目录二级折叠分组 | 展开时全量扫描 |

**两区关系**：历史区（框 2 + 框 3）数据同源（磁盘全量扫描），**与活跃区重叠**——运行中的会话同样出现在历史区，行上加**与活跃区一致的四态 emoji**（v1.2 修复 ②：⚡🟡✅❌，sessionId/status 写入 TerminalRegistry 后两区同源派生；非固定 ⚡）。运行中状态经 TerminalRegistry subscribe 实时更新（不重扫磁盘）；局限：仅本应用 spawn 且能定位 transcript 的会话可感知（matchedCommand-only 会话无 sessionId/transcriptPath 无法标记），外部终端开的 claude 无法标记。

**项目分组**（v1.2 修复 ③）：
- **默认收起**（展开态白名单模型），组标题 = basename + `(N)` 会话计数
- 排序：按组内最近活动（会话最后活动时间）降序
- 无会话的项目分组不显示
- 分组标题：basename（如 `slTerminal`），悬停 tooltip 显示完整路径（如 `D:\data\learn\code\slTerminal`）

### 4.2 列表行

**行内容（3 字段，不含项目名）**：

| 字段 | 来源 | 说明 |
|------|------|------|
| 标题 | custom-title → ai-title → summary 首行 → 首条 prompt，四路回退 | 第一优先级 custom-title（用户重命名，读文件尾部，决策 22）；其次 ai-title（覆写式，读文件尾部）；再其次 summary 摘要；最后用首条 prompt 前 N 字（≤200 字符） |
| 首条 prompt 预览 | 首条"人类可见" user 字符串消息 | 跳过 `tool_result` 载体、`isMeta` 元消息、含 `<local-command-stdout>` 的本地命令输出 |
| 相对时间 | 最后活动时间 = 文件 mtime（或最后一条记录 timestamp，以实现为准但二者口径须统一） | 见时间粒度 |

**布局（双行式，v1.2 修复 ①④）**：

```
┌───────────────────────────────┐
│ ⚡ 修复登录 bug 的会话标题 3天前 │  ← 行1：四态标记 + 标题（12px 粗体）+ 右侧相对时间（灰色小字）
│ 修复了 token 过期问题导致的重…   │  ← 行2：prompt 预览（11px 灰，单行截断省略）
└───────────────────────────────┘
```

**字号层级（v1.2 修复 ④，三区统一）**：折叠框名 13px 粗体 > 会话标题 12px 粗体 > 第二行 11px 灰；区块内容缩进 12px + 左侧树形引导线，全部区组内容再缩进 12px 二级引导线。活跃会话行同构（行2 = 用量条 + 百分比 + 相对时间）。

**时间粒度**：刚刚（<1 分钟）/ N 分钟前 / N 小时前 / N 天前（<7 天）/ 更早显示日期（如 `07-01` 或 `2026-07-01`，跨年含年份）。活跃区时间口径与历史区统一（v1.2 修复 ①）。

**排序**：会话按最后活动时间降序。

**空态**：
- 当前项目无历史会话 → "该项目暂无历史会话"
- 全部项目无任何会话 → "暂无历史会话"
- 无活跃项目（activePageId 无对应项目）→ "当前项目历史会话"区显示空态提示（如"无活跃项目"）

**容错**：损坏/截断 JSONL 行 → 显示基础信息（文件名 + 时间），不崩溃、不阻塞其他行。

**孤儿会话（起始目录已删除）**：行标记 ✗（不可恢复态）——双击恢复与分支恢复**禁用**，仅可复制命令 / 删除。

### 4.3 交互

#### 4.3.1 选中与恢复

- **单击** = 选中（高亮）
- **双击** = 恢复（走 4.3.2 四步流程）
- **无键盘导航**（↑↓/Enter 均不做，明确决策）

#### 4.3.2 恢复流程（四步编排）

双击任意历史会话行（非孤儿、非运行中）：

1. **项目入列**：解析会话起始目录（JSONL `cwd` 字段），判断该项目是否已在项目列表打开；未打开则加入项目列表（项目名 = 路径 basename，rootPath = 会话 cwd）
2. **页面保障**：判断该项目是否有操作页面；无则新建操作页面
3. **页面切换**：切换到该项目的第一个操作页面（走既有页面切换语义）
4. **终端恢复**：前端 addPanel 新建终端页签（**cwd = 会话起始目录**）→ 轮询 TerminalRegistry 拿到 sessionId → `pty.write` 注入 `claude --resume <sessionId>\r`（fork 时追加 ` --fork-session`）。**零后端改动**——OSC 133 命令边界检测 / hooks 事件链路随终端自然生效（决策 25）

> 目的：规避官方"session ID 查找限定会话起始目录 + git worktrees"硬限制——cwd 正确则恢复必然成功。

**恢复失败兜底**：spawn 失败（claude 不可用、目录异常等）→ toast 错误提示，不中断其他流程。

#### 4.3.3 运行中会话行双击（v1.2 修复 ⑤）

弹窗「该会话已在运行中」，提供**「切换到该会话操作页面」**选项（其余动作：取消）：
点击后反查该会话所在终端（TerminalRegistry）→ 若当前操作页面不是该会话所在页面则切换 → 显示并聚焦该会话所在页签。
**分支恢复仅保留在右键菜单**（官方文档明示——同一会话两个终端不 fork 同时恢复，两条消息流会交错进同一 transcript，破坏性行为；双击弹窗不再提供以避免误操作）。

#### 4.3.4 搜索

- 位置：历史区顶部、两个历史下拉框之上
- 范围：过滤两区**当前展开**的列表（匹配标题 + 首条 prompt）
- 大小写不敏感
- 搜索框空 → 显示全部；无结果 → 显示空结果提示

#### 4.3.5 刷新

- **展开下拉框时**全量扫描（加载态指示）
- **手动刷新按钮**（历史区标题栏）——刷新后活跃会话区标题同步更新（v1.2 修复 ⑥：活跃区标题与历史区 scan 数据同源）
- 本地操作后（删除/恢复）**局部即时刷新**，不触发全量扫描

### 4.4 右键菜单（三项操作，v1.2 修复 ⑦：重命名已移除）

对历史会话行右键弹出。孤儿会话（✗）：仅"复制恢复命令"与"删除"可用；运行中会话：删除禁用。

| 操作 | 行为 | 边界 |
|------|------|------|
| **复制恢复命令** | `cd '<dir>' && claude --resume <id>`（带单引号路径）复制到剪贴板 | 所有行可用（含孤儿/运行中） |
| **分支恢复** | 走 4.3.2 四步流程，spawn 追加 `--fork-session`（复制历史到新 sessionId，原会话不动） | 孤儿行禁用；运行中行可用（fork 是安全路径） |
| **删除** | `dialog.ask` 确认弹窗 → 删除该会话 `<uuid>.jsonl`（含同名子代理/工具结果子目录）→ 列表立即刷新 | **运行中行禁用**（Windows 文件句柄占用删除失败 + 外部进程续写幽灵文件）；孤儿行可用（清理孤儿文件是主要用途之一） |

> 重命名功能已全链路移除（v1.2 修复 ⑦）：前端菜单/弹窗、IPC wrapper、后端命令与测试全部删除。官方 `/rename` 仍是 custom-title 的唯一写入方（决策 22 语义不变），本应用侧不再提供。

### 4.5 状态与数据流

```
展开下拉框 ──► 全量扫描 ~/.claude/projects/
                 │  每文件：读首行 summary + 尾部 ≤64KB（ai-title）+ 顺序扫首条可见 user 消息
                 │  排除：agent-*.jsonl / subagents/ 子目录 / 非 UUID 文件名
                 ▼
            会话元数据列表（标题/prompt/时间/cwd/sessionId/大小/孤儿态）
                 │
            前端渲染：两区共享数据（当前项目区 = 按 rootPath 过滤；全部项目区 = 按 cwd 分组）
                 │
TerminalRegistry subscribe ──► ⚡ 运行中标记实时更新（不重扫）
本地操作（删/改名/恢复）──► 局部刷新
手动刷新按钮 ──► 重扫
```

## 5. 边界条件与异常处理（场景清单）

| # | 场景 | 处理 |
|---|------|------|
| 1 | 会话起始目录已被删除/重命名（孤儿会话） | 行标记 ✗，双击/分支恢复禁用；仅复制命令/删除。恢复路径失败概率高（目录名编码有损 + 官方查找限定），禁用优于报错 |
| 2 | 运行中会话（⚡）双击 | 弹窗提示"已在运行中" + 引导分支恢复 |
| 3 | 运行中会话删除 | 菜单项禁用（Windows 句柄占用 + 幽灵文件风险） |
| 4 | 运行中会话重命名 | 允许（ai-title 追加写无冲突） |
| 5 | JSONL 损坏/截断（未知 type、缺字段、EOF 半行） | 该行显示基础信息（文件名+时间），不崩溃不阻塞 |
| 6 | 大文件（20MB+） | 只读首行/尾部/首条 prompt，禁止整读；扫描异步 + 加载态 |
| 7 | 无活跃项目 | 「当前项目历史会话」区显示空态提示，不报错 |
| 8 | 项目未打开/无操作页面（恢复场景） | 四步流程自动补全（入列 → 建页 → 切换 → 恢复） |
| 9 | 搜索无结果 | 空结果提示 |
| 10 | spawn 失败（claude 不可用等） | toast 错误提示 |
| 11 | 子代理 transcript（agent-*.jsonl / subagents/） | 一律排除，不出现在列表 |
| 12 | 跨项目恢复 | 四步流程自动切换工作区上下文到会话所属项目（恢复 ≠ 当前项目；explorer/commit 跟随项目上下文，属设计语义） |
| 13 | 两个历史区同源重叠 | 「当前项目历史会话」与「全部项目历史会话」可能显示同一会话——设计使然，非 bug |
| 14 | CLAUDE_CONFIG_DIR 重定位存储 | 不支持（扫描仅默认 `~/.claude/projects/`），后续增强 |
| 15 | 会话文件正在写入（运行中读取） | 容忍 EOF 截断行（容错规则 3） |

## 7. 非目标（明确不做）

- 会话详情阅读器（聊天式 transcript 阅读）——恢复后终端即完整上下文；阅读器是独立品类，后续单独评估
- 全文内容搜索（检索 transcript 正文/工具调用）——仅元数据级；全文需索引或全量扫描，工程量大
- token/成本统计——与"展开时轻量扫描"性能约束直接冲突
- 导出 Markdown/HTML——依赖详情渲染，与详情阅读器同批评估
- 键盘导航（↑↓/Enter）——明确决策不做
- CLAUDE_CONFIG_DIR 重定位扫描——仅默认目录
- 孤儿会话恢复——标记不可恢复，仅复制命令/删除
- 修改/清理 Claude 自有文件（除删除、重命名两个已批准操作外）——不写 memory、不动全局状态、不做 `claude project purge` 类全量清除

## 8. 验收要点

### 8.1 视图结构

- [ ] agent-status 视图含三个下拉框：`活跃会话`（逻辑不变）/ `当前项目历史会话` / `全部项目历史会话`
- [ ] 「全部项目历史会话」按项目二级折叠分组，组标题 = basename，悬停显示完整路径；无会话的项目分组不显示
- [ ] 展开下拉框显示加载态，完成后展示列表

### 8.2 列表

- [ ] 行 = 双行式：标题（粗体）+ 右上相对时间；第二行 prompt 预览单行截断
- [ ] 标题四路回退正确（有 custom-title 用 custom-title；无则 ai-title；无则 summary；再无则首条 prompt，决策 22）
- [ ] 首条 prompt 跳过工具结果/元消息/本地命令输出
- [ ] 排序按最后活动时间降序；时间粒度正确
- [ ] 运行中会话 ⚡ 标记且实时更新（TerminalRegistry 联动）
- [ ] 孤儿会话 ✗ 标记，双击/分支恢复禁用
- [ ] 损坏文件行显示基础信息不崩溃；空态文案正确

### 8.3 恢复

- [ ] 跨项目会话恢复：四步编排后终端 cwd = 会话起始目录，`claude --resume` 成功进入会话
- [ ] 项目未打开自动入列；无操作页面自动新建；切到第一个操作页面
- [ ] 运行中会话双击 → 提示 + 引导分支
- [ ] 分支恢复 → 新会话与原会话并存（原 transcript 不变）
- [ ] spawn 失败 → toast 错误

### 8.4 管理

- [ ] 复制恢复命令 = `cd '<dir>' && claude --resume <id>` 正确入剪贴板
- [ ] 删除：确认弹窗 → 文件删除（含子代理目录）→ 列表即时刷新；⚡ 行删除禁用
- [ ] 重命名：输入弹窗 → custom-title 追加写入 → 列表即时刷新 → 官方 picker 显示新标题（决策 22）

### 8.5 搜索与容错

- [ ] 搜索框过滤两区展开列表（标题 + prompt，大小写不敏感）
- [ ] 子代理 transcript（agent-*.jsonl / subagents/）不出现在列表
- [ ] 无活跃项目时「当前项目历史会话」空态不报错
