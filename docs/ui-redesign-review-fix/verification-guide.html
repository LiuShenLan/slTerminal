一、本次修复新增 5 个人工验证点

1. ConfirmDialog 焦点陷阱 FE-28 需实机手感

验证什么弹窗焦点管理：初始聚焦、Tab 循环、Enter/Esc 语义
怎么验证导航树项目行右键 → 删除项目 弹出确认框后： ① 观察确认钮是否带焦点环（键盘焦点样式） ② 按 Tab 数次——焦点须在「取消/确认」两钮间循环，不得逃逸到弹窗外控件 ③ Shift+Tab 反向循环同样成立 ④ 焦点在任一钮上按 Enter 触发该钮；按 Esc 取消关闭
期望结果弹窗打开瞬间焦点落在确认钮；Tab 永不逃出弹窗；Enter=执行焦点钮、Esc=取消（语义与 Stage 01 前一致）

2. 右键菜单 hover 无闪烁 FE-05/06 视觉对照

验证什么文件树/导航树右键菜单 hover 改 React state 驱动后无渲染闪烁
怎么验证① 文件树任意行右键弹菜单，鼠标在菜单项间来回移动（含快速扫动） ② 导航树项目行/页面行右键弹菜单，同上操作 ③ 观察菜单关闭再打开时高亮是否干净复位
期望结果hover 高亮顺滑跟随、无闪烁/无残留高亮；重开菜单无上次的悬停高亮残留（Stage 03 已加重置逻辑）

3. GitShow 大文件警告图标 FE-18 视觉对照

验证什么大文件只读视图警告处 ⚠ emoji 已替换为 lucide 三角告警图标
怎么验证① 项目内放一个 ≥1MB 文本文件并 git 提交 ② 文件树点击该文件，或在 git 变更列表打开它进入 GitShow 面板 ③ 观察内容顶部警告注释行（「文件过大…只读查看」）行首
期望结果行首显示 13px 线框三角告警 SVG 图标（琥珀黄 warning 色 #d6b25e），无 ⚠ emoji 字符；图标垂直对齐不破坏代码行排版

4. 侧栏双开 splitRatio 保留 FE-19 交互验证

验证什么单↔双视图切换不再无条件重置 0.5，用户调节的比例被保留
怎么验证① 活动栏依次点开两个视图（如「导航树」+「文件」，构成顶区双开） ② 拖动两视图之间的分隔条，把比例调到明显偏离 0.5（如 0.3/0.7） ③ 点活动栏「文件」关闭（回单视图），再点开「文件」（回双开）
期望结果步骤 ③ 后分隔条回到步骤 ② 调节的位置，不再被重置为 0.5；重启应用后该值同样保留（持久化链未动）

5. 项目删除 confirmDialog 实机 FE-03 替代原生弹窗

验证什么window.confirm 原生阻塞弹窗已被应用内自绘 confirmDialog 替代（WebView2 实机）
怎么验证① 导航树项目行右键 → 删除项目 ② 观察弹窗形态（深色自绘、danger 红色确认钮、圆角 6px） ③ 点取消：项目保留；再删除并点确认：项目行消失
期望结果出现的是应用内自绘弹窗（与编辑器脏确认同款组件），非 Windows 系统样式的原生阻塞框；取消/确认行为正确

二、继承 review 6 项未实机验证

6. 标题栏拖拽/双击/三钮手感 TB-07

怎么验证① 按住标题栏空白区拖拽移动窗口 ② 双击标题栏最大化/还原 ③ 依次悬停+点击最小化、最大化/还原、关闭三钮
期望结果拖拽顺滑无跳变；双击切换正常；关闭钮 hover 背景为红色 #c04747（FE-07 token 化后值不变），三钮点击行为正确

7. 导航树三级交互与旧 settings 启动 NAV-11

怎么验证① 导航树项目 → 页面 → 会话三级逐层展开/折叠，双击历史会话行恢复会话 ② 项目行/页面行/会话行各自右键菜单可用 ③ 用一个 2026-08 之前生成的旧版 settings.json（布局数据）启动应用
期望结果三级交互正常；旧 settings 启动不报错、不白屏，布局按迁移逻辑恢复或安全回退默认布局

8. dockview sash 拖拽热区 GL-04

怎么验证页签间分隔条（sash）逐条悬停观察光标变化，拖动调宽高后松开
期望结果悬停热区光标即时变为可拖形态（热区不虚胖也不难命中）；拖拽过程跟手、松开落位稳定

9. 产物对照 final-mockup.html 视觉验收

怎么验证浏览器打开 docs\ui-redesign\final-mockup.html，与应用窗口并排逐屏对照（整体布局/配色/圆角/间距）
期望结果应用与 mockup 视觉一致（配色 #0a0a0b 系、圆角档 6/8、间距节奏）；如发现偏差记录具体屏位

10. 断网字体回退 UI-202

怎么验证断网（禁用网卡或飞行模式）后启动应用，观察加载页 → 主界面 → 终端文字
期望结果无外网字体下载依赖，全部文字正常渲染；等宽文字回退到系统字体（Consolas / Microsoft YaHei UI），无豆腐块

11. 中文 CJK 渲染 UI-203

怎么验证① 终端内输入中文并回车（如 echo 中文测试）② 编辑器打开含中文的源文件 ③ 导航树用中文项目/页面名
