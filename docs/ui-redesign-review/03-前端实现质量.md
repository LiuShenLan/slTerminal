# 03-前端实现质量 Review 报告

> 范围：重设计新增/重写的前端代码（theme/lib/titleBar/navTree/sideViews/workspace/explorer/agentHistory/App.css/ipc）
> 严重度：P0 阻塞（功能 bug/泄漏/崩溃隐患）｜P1 严重（明确缺陷/错误模式）｜P2 次要（坏味道/死代码/小问题）｜P3 建议

## 问题清单

### [P1] 右键菜单「新建终端」在菜单弹出时即消耗 panelId，导致 terminal-N 编号跳号
- 位置：`src/workspace/PageDockviewHost.tsx:262`
- 描述：`createGetContextMenu` 每次右键重建菜单时调用 `nextPanelId()`，无论用户是否点击「新建终端」都会推进模块级计数器。连续右键两次再新建，编号会从 terminal-1 跳到 terminal-3。
- 修复建议：将 `nextPanelId()` 调用延迟到「新建终端」action 执行时。

### [P1] 删除项目仍使用浏览器原生 `window.confirm`，与统一浮层规范不一致
- 位置：`src/features/navTree/NavTree.tsx:566`
- 描述：页面/历史删除均使用 `confirmDialog`，但项目删除仍走 `window.confirm`。Tauri WebView2 中 native confirm 会阻断主线程且无法应用暗色主题，违反 OV-02 统一确认语义。
- 修复建议：项目删除也改用 `confirmDialog({ title, message, danger: true })`。

### [P1] 多处右键菜单通过直接修改 DOM `style.background` 实现 hover，重渲染时会出现闪烁
- 位置：
  - `src/features/explorer/FileTree.tsx:207-216`（TreeNodeRow）
  - `src/features/navTree/NavContextMenu.tsx:101-106`
  - `src/features/agentHistory/HistorySessionList.tsx:178-183`
- 描述：在 React 渲染周期外修改 `e.target.style.background`，组件重新渲染时 React 会用 inline style 对象覆盖该属性，导致 hover 背景在状态更新时被清空，鼠标未移动即出现闪烁/丢失。
- 修复建议：统一改为 React state 驱动 hover 背景（参考 `NavProjectRow` / `NavPageRow` / `TabContextMenuItem`）。

### [P2] 侧栏双开时每次都会把 splitRatio 重置为 0.5，丢弃用户调节值
- 位置：`src/features/sideViews/SideBarArea.tsx:58-63`
- 描述：从单视图切到双视图时，`useEffect` 无条件 `setSplitRatio(0.5)`。用户关闭下方视图后再打开，之前手动拖动的比例丢失。
- 修复建议：仅在首次进入双视图或比例越界时回退默认值，正常切换应保留已持久化的 `splitRatio`。

### [P2] 文件夹图标忽略 `gitStatus`，有 git 状态色的目录图标不会变色
- 位置：`src/features/explorer/FileIcon.tsx:104-115`
- 描述：`FileTree` 会向文件夹传递 `gitStatus`，但 `FileIcon` 在 `isDir` 分支写死使用 `EXPLORER_COLORS.fg`，`statusColorMap` 只在文件分支生效。若后端对目录返回 git 状态色，文件夹不会跟随变色。
- 修复建议：文件夹分支也根据 `gitStatus` 选择 `color`，无状态再回退 `EXPLORER_COLORS.fg`。

### [P2] TitleBar 订阅整个 `projects` 对象并全量遍历，导致任何项目变更都触发重渲染
- 位置：`src/features/titleBar/TitleBar.tsx:50-67`
- 描述：`useActiveProjectPage` 使用 `useProjects((s) => s.projects)`，projects 对象引用在任意 project.version 递增时都会变化，TitleBar 会重新遍历全部项目页面计算标题。
- 修复建议：拆分为 `activePageId` + 基于 projectId/pageId 的轻量 selector，或把标题推导上提到 store selector。

### [P2] 使用 dockview 非公开 API `panel.view?.contentComponent` 判断面板类型
- 位置：`src/workspace/PageDockviewHost.tsx:264`、`src/workspace/PageDockviewHost.tsx:337`
- 描述：`panel.view` 与 `contentComponent` 不是 `dockview-react` 公开类型，升级库版本后可能失效或类型报错，影响右键菜单「重命名」和标题恢复逻辑。
- 修复建议：通过 `panel.params` 中的 panelId/filePath 等已持久化字段判断类型（已有 `params.filePath !== undefined` 先例），避免依赖内部结构。

### [P2] `reconcileZones` 会 mutate 传入的 `saved.top` 数组
- 位置：`src/features/sideViews/sideBarState.ts:184`、`src/features/sideViews/sideBarState.ts:190-194`
- 描述：函数直接 `const top = saved.top.filter(...)` 得到新数组后又 `top.push(...)`，虽然返回了新 `Zones` 对象，但 `top` 数组是 `saved.top` 的 filter 结果；若调用方把持久化对象直接传入，会污染原数据。
- 修复建议：追加缺失 id 前先 `[...top]` 复制，保证纯函数语义。

### [P2] ActivityBar `onDragLeave` 在容器→子元素转移时会误清指示线
- 位置：`src/features/sideViews/ActivityBar.tsx:226-231`
- 描述：`e.currentTarget === e.target` 的判断在从容器空白区拖入按钮时（dragleave 目标为容器本身）会清空 `dropIndicator`，直到下一次 `dragover` 才恢复，造成插入指示线闪烁。
- 修复建议：用 `relatedTarget` 判断是否真正离开容器，或统一在 `dragend`/`drop` 清空。

### [P2] `handleNewPage` 返回值未被任何调用方使用
- 位置：`src/features/navTree/NavTree.tsx:309`
- 描述：`handleNewPage` 返回 `pageId`，但 `NavTree` 内新建页面右键 action 仅调用函数，不消费返回值，属于死返回。
- 修复建议：删除返回值，或确认是否需要用于切换/重命名后续操作。

### [P3] `registerCloseHandler` 清理函数未处理 `unlisten` Promise 异常
- 位置：`src/App.tsx:171`（配合 `src/ipc/window.ts:56-69`）
- 描述：effect 返回的清理函数执行 `unlisten.then((fn) => fn())`，若 Tauri 窗口已销毁导致 `unlisten` reject，清理会抛异常并可能造成重复注册监听器。
- 修复建议：清理函数内加 `.catch(() => {})` 吞掉已销毁窗口的异常。

### [P3] `HistorySessionList` / `HistorySessionRow` 已无生产消费方
- 位置：`src/features/agentHistory/HistorySessionList.tsx`、`src/features/agentHistory/HistorySessionRow.tsx`
- 描述：导航树历史区已改用 `NavHistoryRow`，两组件仅测试引用，代码仍留在仓库。虽然文档声明保留兼容，但增加了维护面和 bundle 体积。
- 修复建议：确认无生产引用后删除，或迁移测试到 `NavHistoryRow` 后移除。

### [P3] `findPanelForSession` / `findPageIdForPanelId` 在 NavTree 与 HistorySessionList 中重复实现
- 位置：`src/features/navTree/NavTree.tsx:107-139`、`src/features/agentHistory/HistorySessionList.tsx:202-234`
- 描述：同一复合键反查逻辑和 B14 panelId→pageId 解析逻辑复制了两份，后续修改容易遗漏。
- 修复建议：抽到 `src/lib/` 或 `src/features/agentHistory/historyModel.ts` 的纯函数，两处共用。

### [P3] ConfirmDialog 主按钮缺少自动聚焦与焦点陷阱
- 位置：`src/lib/ConfirmDialog.tsx:117-191`
- 描述：弹窗出现时焦点仍留在触发元素，Tab 可逃出弹窗；Enter 不能直接确认，Esc/遮罩点击仅返回 false 但焦点管理不完整。
- 修复建议：挂载后对确认按钮 `focus()`，并监听 Tab 在首尾元素间循环，或至少设置 `autoFocus`。

### [P3] ToastHost 缺少无障碍通知语义
- 位置：`src/lib/toast.tsx:93-125`
- 描述：通知容器无 `role="status"`/`aria-live`，读屏软件无法自动播报 toast 内容。
- 修复建议：外层容器加 `role="status" aria-live="polite"`。

## 核查覆盖说明

本次审查覆盖了 UI 重设计新增/重写的 theme、lib、titleBar、navTree、sideViews、workspace、explorer、agentHistory、App.css、ipc/window、ipc/dialog 等全部目标文件。整体代码结构符合「配色/布局/会话元数据单点」等硬约束，React 关键订阅与 disposable 清理基本到位，未发现阻塞性崩溃或内存泄漏。主要问题集中在：右键菜单过早消耗 ID、`window.confirm` 残留、hover 样式直接操作 DOM、侧栏 splitRatio 重置策略过 aggressive、以及少量可维护性/无障碍细节。未发现需求规格值（色值/尺寸）偏离，实现层缺陷均已列出。
