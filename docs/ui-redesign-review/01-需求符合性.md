## 实机验证项（非缺陷）

以下项依赖真实 WebView2/Windows 行为，静态源码层面已按设计实现，不记为缺陷：

1. **自绘标题栏拖拽/双击最大化/三钮功能**（TB-04）：`TitleBar.tsx` 已使用 `data-tauri-drag-region="deep"`，双击由 Tauri 原生拖拽脚本承担，三钮经 `src/ipc/window.ts` wrapper 调用。
2. **窗口阴影缺失与直角**：`decorations: false` 已启用，ADR-0003 已接受该权衡。
3. **ConPTY flags 固定 `0x7`**、PTY spawn 串行化、`cwd` 反斜杠规范：属于后端 Windows 关键坑，与 UI 需求符合性无关，源码已按 `src-tauri/src/pty/CLAUDE.md` 实现。
4. **HTML 预览 iframe sandbox**：`sandbox="allow-scripts"` 无 `allow-same-origin`，postMessage 三层校验已实施。
5. **UI-405/406/407（Agent 面板/Composer/状态行）**：需求已标注为「远期愿景，本期不实施」，源码未实现符合决策。
6. **Dockview 页签栏高 35px**：库默认值，checklist 明确无需修改。
7. **导航树历史节点文案「历史session」**：2026-08 人工验证修订结果，与 `NavTree.tsx` 注释一致，非缺陷。
