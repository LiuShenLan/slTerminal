# slTerminal UI 设计方案 —— 「Linear 极黑克制」

> 版本：v1.0（2026-08-16 定稿）。本文档是 slTerminal 客户端 UI 重设计的**权威设计规范**，由 6 个候选视觉稿评审选定（候选 A，无微调）。
> 配套文档：需求规格见 `./requirements.md`（UI-xxx 编号 + 可测验收标准）；视觉终稿见 `./final-mockup.html`。
> 调研依据：`docs/refer/`（11 款软件暗黑 UI 调研 + 总览）。硬约束：仅暗黑模式 / 字体全部 JetBrains Mono / 无动效 / 不做多主题切换。

## 1. 设计原则

1. **界面消失，内容最大**：UI 壳层退到背景，注意力全部留给终端/编辑器/会话内容。装饰零冗余——没有不必要的框线、阴影、渐变、图标。
2. **内容区最暗**：明度最低层永远留给内容区（终端/编辑器/Agent），壳层（侧栏/标题栏/页签栏）逐级提亮，层级靠**明度阶梯**而非描边或阴影表达。
3. **单强调色纪律**：全 UI 唯一强调色（现代蓝 `#6e9ff2`），只用于焦点、选中、激活指示、CTA，占界面像素 <5%，禁止装饰性使用。
4. **发丝线代替框线**：暗色下分隔一律使用半透明白发丝线（0.055–0.09 不透明度），禁止实色粗边框。
5. **克制**：无动效（用户硬约束）；字重只用 400/500；圆角小档位；图标单色线性。

风格锚点：Linear / Zed 式近纯黑现代风（调研总览 §2.1「近纯黑内容区」流派 + §2.7「UI 层让位于内容层」）。

## 2. 色彩体系

### 2.1 明度阶梯（中性微暖灰，自深至浅 6 档）

| token | 值 | 用途 |
|-------|-----|------|
| `l0-content` | `#0a0a0b` | **内容区**：终端 / 编辑器 / Agent 会话面板 —— 全界面最暗 |
| `l1-panel` | `#101012` | 侧栏、面板背景、状态行背景 |
| `l2-chrome` | `#141416` | 标题栏、活动栏、页签栏 |
| `l3-float` | `#1a1a1e` | 浮层、输入框、chip、徽标底 |
| `l4-hover` | `#222227` | 悬停背景（列表行/按钮/图标钮） |
| `l5-active` | `#2b2b31` | 按下/激活背景、关闭钮 hover |

规则：任何组件的背景只能取这 6 档之一；相邻层级差即「层级」，不再叠加阴影/边框。

### 2.2 发丝线（半透明白）

| token | 值 | 用途 |
|-------|-----|------|
| `hairline` | `rgba(255,255,255,0.055)` | 默认分隔：面板间 sash、标题栏/页签栏底线、侧栏边线、树引导线 |
| `hairline-strong` | `rgba(255,255,255,0.09)` | 浮层/输入框描边、胶囊边框等需要更强存在感的 1px |

### 2.3 文字（微暖白阶 4 级）

| token | 值 | 用途 | 对 l0 对比度 |
|-------|-----|------|--------------|
| `fg-1` | `#ece9e4` | 主文字 | 16.3:1 |
| `fg-2` | `#b3aea6` | 次级文字（列表行默认、正文辅助） | 9.0:1 |
| `fg-3` | `#8a857d` | 元数据（时间、路径、分组标题） | 5.4:1 |
| `fg-4` | `#6b675f` | 最弱——占位符/禁用/行号，**禁用于正文** | 3.5:1 |

### 2.4 强调色（现代蓝，全 UI 唯一）

| token | 值 | 用途 |
|-------|-----|------|
| `accent` | `#6e9ff2` | 焦点环、激活指示条、选中描边、CTA（对 l0 7.5:1） |
| `accent-fg` | `#8fb4f5` | 强调色文字/图标（链接、激活项文字） |
| `accent-dim` | `rgba(110,159,242,0.13)` | 选中态背景（树行/列表/活动栏图标） |
| `accent-dim-2` | `rgba(110,159,242,0.22)` | 选中态 hover、更强选中底 |
| `on-accent` | `#0c1220` | 强调底色上的文字（对 accent 7.0:1） |

### 2.5 语义状态色（低饱和暖协调，各带透明背景变体）

| 语义 | 主色 | 背景变体（12% 透明度） | 用途 |
|------|------|------------------------|------|
| success / ok | `#86bb7a` | `rgba(134,187,122,0.12)` | 运行中状态点、成功 toast、git added |
| warning | `#d6b25e` | `rgba(214,178,94,0.12)` | 等待态、警告、git modified |
| error | `#d9706b` | `rgba(217,112,107,0.12)` | 错误、删除、git deleted/conflict |
| info | `#6e9ff2` | 同 `accent-dim` | 信息提示、git renamed |

映射既有语义槽位：git 文件状态色（modified→warning、added→ok、untracked→`#6fbfc4` 青、deleted→error、renamed→info、conflict→error、ignored→fg-4）；用量条四档（low→ok、medium→`#a9c686`、high→warning、critical→error）。

### 2.6 终端 ANSI 16 色（暖协调，对 l0 全量 ≥4.5:1 校验）

| 色 | 基本色 | 亮色（bright） |
|----|--------|----------------|
| black / brightBlack | `#0a0a0b` | `#7d7871` |
| red / brightRed | `#d9706b` | `#e2877f` |
| green / brightGreen | `#93b573` | `#a8c98d` |
| yellow / brightYellow | `#d6b25e` | `#e3c67f` |
| blue / brightBlue | `#7fa8e8` | `#9dbfee` |
| magenta / brightMagenta | `#b48ce0` | `#c6a6e8` |
| cyan / brightCyan | `#6fbfc4` | `#8dd0d4` |
| white / brightWhite | `#cfcac1` | `#f0ede8` |

终端专用：`foreground #cfcac1`、`background #0a0a0b`、`cursor #6e9ff2`、`cursorAccent #0a0a0b`、`selectionBackground rgba(110,159,242,0.28)`、`selectionForeground #f0ede8`；滚动条滑块 `rgba(255,255,255,0.10)` / hover `0.20` / active `0.28`。

### 2.7 编辑器语法色（CodeMirror，暖协调 One Dark 系）

| 角色 | 值 | 角色 | 值 |
|------|-----|------|-----|
| 属性/键（property） | `#d9827e` | 字符串 | `#93b573` |
| 数字/布尔 | `#d89a66` | 关键字 | `#b48ce0` |
| 函数 | `#7fa8e8` | 类型/运算符 | `#6fbfc4` |
| 标点 | `#7d7871` | 注释 | `#6b675f` |
| 正文（editor fg） | `#b3aea6` | 行号 | `#6b675f`（当前行号 `#b3aea6`） |

lint 波浪线：error `#d9706b` / warning `#d6b25e` / info `#6e9ff2` / hint `#8a857d`；搜索匹配底 `rgba(214,178,94,0.25)`、选中匹配 `rgba(214,178,94,0.45)`。

### 2.8 启动 fail-safe 三处静态色（随本方案同步）

`index.html` body background、`tauri.conf.json` window backgroundColor、`main.tsx` 超时错误页背景 → 统一 `#0a0a0b`（错误页文字 `#ece9e4`、错误强调 `#d9706b`）。

## 3. 字体排版

- **全局字体栈**：`"JetBrains Mono", "Cascadia Mono", Consolas, "Microsoft YaHei UI", monospace`。
  - JetBrains Mono 无中文字形——CJK 经 `"Microsoft YaHei UI"` 回退（Windows 预装，与等宽西文混排基线协调）；终端/编辑器内 CJK 宽度按双宽处理（xterm.js 默认行为，不干预）。
  - 连字（ligatures）：UI 壳层关闭；终端/编辑器遵循渲染器默认，不强制开关。
- **字重**：仅 400（常规）与 500（项目名/面板标题/主按钮），禁止 700；暗色下不使用 300 以下细字重。
- **字号阶梯**：

| 场景 | 字号 | 字重 | 说明 |
|------|------|------|------|
| 分组标题（导航/区块头） | 11px | 500 | 全大写 + 字距 0.08em，fg-3 |
| 状态行 | 11.5px | 400 | fg-3 |
| 侧栏树/列表 | 12.5px | 400/500 | 行高 28–30px |
| 页签 | 12.5px | 400 | 激活 500 不加粗——用颜色区分 |
| 正文/Agent 会话 | 13px | 400 | 行高 1.5 |
| 编辑器/终端 | 12.5–13px | 400 | 行高 1.5–1.55 |
| 标题栏 | 12px | 400/500 | |

## 4. 间距与圆角

- **间距**：8px 网格，只允许 4 / 8 / 12 / 16 / 24 五档。组件内边距常用 6–12px（半个网格允许用于紧凑行内：树行 `0 8px`、chip `5px 10px`）。
- **密度**：中密度偏紧凑——标题栏 34px、活动栏 46px、页签栏 35px、树行高 28px（会话行 30px）、状态行 26px。
- **圆角**：`4px`（小控件/徽标/close 钮）、`5px`（树行/列表行）、`6px`（按钮/活动栏图标）、`8px`（输入框/浮层/对话框）；页签 0（扁平无边盒）；pill `999px` 仅用于计数徽标。

## 5. 图标体系

1. **装饰图标一律线性 SVG**：Lucide 风格——viewBox 24、显示尺寸 15px（高密度处 12–13px）、描边 1.5px、圆角线帽/线接、`currentColor` 随文字变色。禁止装饰性 emoji（📁🌿⭐ 等全部替换）。
2. **彩色文件类型图标**：仅文件树/页签内的文件图标允许彩色，统一低饱和盘（蓝 `#7fa8e8`、黄 `#d6b25e`、绿 `#93b573`、红 `#d9706b`、紫 `#b48ce0`、青 `#6fbfc4`），同色系不同明度区分类型；文件夹用描边款、文件用描边+小色块款。
3. **CLI 品牌 logo**（claude 花等）：保留彩色品牌图形，尺寸 14px（行内）/34px（面板 hero），不受单色纪律约束。
4. **状态圆点**：替代状态 emoji——7px 圆点，绿 `#86bb7a`=运行、黄 `#d6b25e`=等待输入、灰 `#6b675f`=空闲/结束；不使用描边/光晕。

## 6. 逐区域规范

### 6.1 自绘标题栏（34px，`l2-chrome` + 底部发丝线）

- 左：app logo（16px 圆角方块 + 终端提示符图形，accent-dim 底 accent-fg 图形）+ `slTerminal`（12px/500，fg-2）。
- 中：当前项目名（500）/ 当前页面名，fg-3，格式 `<b>项目</b> / 页面`。
- 右：自绘窗口控制（最小化/最大化/关闭，38×26px hit 区，12px 图标，fg-3；hover `l4-hover`；关闭 hover `#c04747` 白图标）。
- 整栏为窗口拖拽区；双击切换最大化。

### 6.2 活动栏（46px，`l2-chrome` + 右侧发丝线）

- 34×34px 圆角 6px 图标钮，fg-3；hover `l4-hover` + fg-1。
- 激活：`accent-dim` 底 + `accent-fg` 图标 + 左侧 2px 竖指示条（accent）。
- 视图固定三槽（上到下）：**导航树 / 文件 / Commit**；底部设置。

### 6.3 统一导航树（侧栏，`l1-panel`）

- 层级：**项目 → 页面 → 会话**；历史会话折叠为项目/页面级节点（时钟图标 + 计数 pill）。
- 行结构：chevron（12px，fg-3）+ 图标 + 名称 + 右侧元数据（fg-4，11px）。
- 项目行 500 字重 fg-1，彩色文件夹图标；当前项目带「当前」pill（accent-dim 底 accent-fg 字）。
- 会话行：状态圆点 + CLI 品牌 logo + 名称 + 相对时间；活跃会话默认 accent-dim 选中底。
- 缩进：每级 15px 左缩 + 发丝线引导线；行 hover `l4-hover`。
- 顶部：分组标题「导航」+ 刷新图标钮；其下搜索框（l3 底、focus accent 描边、占位「搜索项目 / 页面 / 会话…」）。

### 6.4 页签栏（35px，`l2-chrome` + 底部发丝线）

- 扁平页签：激活页签背景 = `l0-content`（与内容区连成一体）+ **底部 2px accent 指示条** + fg-1；未激活透明底 fg-3，hover fg-1（不改底）。
- 页签内容：状态圆点（终端/agent 页签）+ 品牌 logo/文件图标 + 名称；关闭 × 仅 hover 显示（14px 圆角 4px，hover `l5-active`）。
- 右侧「+」新建钮（22px 圆角 4px，fg-3，hover `l4-hover`）。
- 多面板组各自一条页签栏；面板组间 sash = 1px 发丝线。

### 6.5 Agent 会话面板（`l0-content`）

- Hero：34px 品牌 logo + CLI 名+版本（13.5px/500）+ 模型·计费行（12px fg-2）+ 路径行（11.5px fg-3）。
- 用户消息 chip：`l3-float` 底圆角 5px；思考/工作元信息：12px 斜体 fg-3。
- 底部输入框（composer）：`l3-float` 底 + `hairline-strong` 描边、圆角 8px、最小高 42px；focus 描边 accent。
- 状态行：`l1-panel` 底 + 顶部发丝线，11.5px fg-3；模型段 accent-fg、模式段 warning 色；分段间隔 `|` fg-4。

### 6.6 编辑器 / 终端（`l0-content`）

- 编辑器行号列 44px，行号 fg-4，当前行号 fg-2；正文 fg-2；语法色见 §2.7。
- 终端 ANSI 见 §2.6；选中、光标、滚动条色同 §2.6。

### 6.7 滚动条

- 9px 细条，轨道全透明；滑块 `rgba(255,255,255,0.10)`、hover `0.20`、拖动 `0.28`，圆角 5px；无箭头按钮。

### 6.8 浮层（右键菜单 / 对话框 / toast / tooltip）

- 统一 `l3-float` 底 + `hairline-strong` 1px 描边 + 圆角 8px + 阴影 `0 8px 32px rgba(0,0,0,0.35)`。
- 菜单项行高 28px、圆角 5px、hover `l4-hover`；危险项 fg error。
- 对话框：遮罩 `rgba(0,0,0,0.55)`；标题 13px/500；按钮主 = accent 底 on-accent 字，次 = l4 底 fg-1 字。
- toast：语义色 12% 底 + 语义色 1px 描边 + fg-1 文字，圆角 8px。
- 空态：居中——15px 线性图标（fg-4）+ 一句话说明（fg-3）+ 可选次级按钮。

## 7. 与现状的主要变更点

| 现状（darcula 时代） | 本方案 |
|----------------------|--------|
| 原生 Windows 标题栏 | 自绘 34px 暗色一体化标题栏 |
| 中灰蓝底色平铺（#2B2B2B 系） | 暖黑明度阶梯（#0a0a0b 起 6 档），内容区最暗 |
| 实色粗边框/面板间隙 | 半透明白发丝线（0.055/0.09） |
| 盒式页签 + 常驻关闭钮 | 扁平页签 + 底部 2px 指示条 + hover 显关闭钮 |
| 装饰 emoji（📁🌿⭐🟠） | 线性 SVG + 状态圆点；CLI 品牌 logo 保留彩色 |
| 侧栏多区块竖向堆叠 | 统一导航树（项目→页面→会话），文件/Commit 独立活动栏视图 |
| darcula ANSI/语法色 | 暖协调 ANSI 16 色 + 语法色全量重调（§2.6/§2.7） |
| 状态行多彩 emoji 分段 | 单排低饱和状态行，语义色仅保留模型/模式两处 |

## 8. 不做的事（明确排除）

- 不做亮色系主题、不做多主题切换机制（硬约束 #6 的 SchemeRegistry 单方案运行即可）。
- 不做任何动效（含 hover 过渡、主题切换 crossfade、页签滑入）。
- 不改功能交互逻辑（快捷键、右键菜单项、会话恢复流程等行为不变，仅视觉层与侧栏 IA 重构）。
