# slTerminal UI 需求规格

> 版本：v1.0（2026-08-16）。与 `design.md`（设计方案）配套：设计方案给「是什么」，本规格给「必须做到什么 + 怎么验收」。
> 每条 = 需求描述 + 可测验收标准 + 优先级（**P0** 必做 / **P1** 可选）。编号：UI-1xx 色彩 / UI-2xx 字体 / UI-3xx 布局 / UI-4xx 页签与面板 / UI-5xx 侧栏导航树 / UI-6xx 图标 / UI-7xx 内容区配色 / UI-8xx 浮层与反馈。
> 色值类条目括号内为 `src/theme/schemes/types.ts` 对应槽位（硬约束 #6 落位参照）。对比度总则见附录 A。

## UI-2xx 字体排版

| 编号 | 需求 | 验收标准 | 优先级 |
|------|------|----------|--------|
| UI-201 | 全局字体栈统一 | 全部界面文本的 font-family = `"JetBrains Mono", "Cascadia Mono", Consolas, "Microsoft YaHei UI", monospace`；grep 无其它字体声明 | P0 |
| UI-202 | JetBrains Mono 随产物可用 | 打包产物内置或可靠加载 JetBrains Mono（woff2，400/500 两字重）；断网环境打开界面不回退到非等宽字体 | P0 |
| UI-203 | CJK 回退正确 | 中文文本渲染为 Microsoft YaHei UI（而非宋体/ fallback 乱码）；中西文混排行不错位 | P0 |
| UI-204 | 字号阶梯 | 分组标题 11px / 状态行 11.5px / 标题栏 12px / 侧栏与页签 12.5px / 正文 13px / 编辑器终端 12.5–13px（为设计基准；终端/编辑器**内容区默认 14px**——用户 Ctrl+Wheel 可调 8–32——为登记例外）；不存在阶梯外字号 | P1 |
| UI-205 | 字重仅用 400/500 | grep `font-weight`，仅出现 400/500（normal/medium）；无 700/600/300 | P1 |
| UI-206 | 分组标题样式 | 11px + 全大写 + 字距 0.08em + fg-3（「导航」「AGENT STATUS」等区块头一致） | P1 |
