进度：0 / 0

准备：构建产物与参照物 前置

适用：全部验证项 | 预计 5 分钟
  1. 重建生产产物：在项目根目录执行 npx tauri build --debug --no-bundle
    期望：构建成功，产物位于 src-tauri\target\debug\slterminal.exe（debug 模式 = exe + dll 两个文件）。注意：最近一次构建是 E2E 测试构建（含测试后门），必须先重建。
  2. 启动应用：双击 slterminal.exe
    期望：窗口正常打开，默认 shell 为 PowerShell 7（pwsh），无报错弹窗。
  3. 打开视觉参照：浏览器打开 docs\ui-redesign\final-mockup.html（共两页稿），窗口并排对照。
    期望：能看到两页完整视觉稿，供 V4 逐区对照。
  4. 准备取色工具（V4 精确核色用）：PowerToys Color Picker（推荐），或 Win+Shift+S 截图后取色。
    期望：能读出屏幕上任意像素的精确 HEX 值。

验证 1：自绘标题栏 TB-07 / UI-301

无原生标题栏 | 34px | #141416 底 + 底部发丝线 | 预计 10 分钟

1.1 形态核对

  1. 观察窗口顶部：无 Windows 原生标题栏（无系统标题条/系统三钮）；自绘栏 34px 高，背景 #141416，底部 1px 发丝线 rgba(255,255,255,0.055)。
    期望：左 = 16px 圆角方块 logo +「slTerminal」（12px）；中 = 项目名（500 字重）/ 页面名；右 = 最小化/最大化/关闭三钮（38×26，图标 12px，默认 #8a857d）。

1.2 拖拽与双击

  1. 按住标题栏空白处（左段/中段）拖动窗口。
    期望：窗口跟随移动，无卡顿。
  2. 按住标题栏右侧三钮区域拖动。
    期望：不触发拖拽（按钮区排除在拖拽区外），按钮可正常点击。
  3. 双击标题栏中段。
    期望：窗口最大化；再次双击还原原始尺寸。

1.3 三钮功能与 hover

  1. 依次点击最小化 → 任务栏还原 → 最大化 → 还原 → 关闭。
    期望：最小化收进任务栏；最大化/还原切换正常；关闭后窗口退出。
  2. hover 三钮观察背景色：普通钮 hover #222227；关闭钮 hover #c04747（图标变白）。
    期望：hover 色与规格一致。

1.4 关窗 PTY 清理（P1-19 链路）

  1. 重新启动应用，新建终端并运行 claude（或长期进程如 ping -t 127.0.0.1）。
  2. 直接点自绘关闭钮（不先退出 claude）。
    期望：窗口关闭后，任务管理器（或 tasklist | findstr claude）中无残留 claude/pwsh 子进程——关窗必须杀掉 PTY 子进程树。

1.5 已知取舍确认

  1. 观察窗口外观并尝试 Win+方向键贴靠（Aero Snap）。
    期望：窗口无原生阴影与原生标题栏；Win+方向键贴靠仍可用——Aero Snap 是 OS 窗口管理功能，与 decorations:false 无关（2026-08 实机验证确认，文档修订）。实际失去的仅原生标题栏/阴影与拖拽悬停时的 Snap Layouts 预览。

验证 2：统一导航树与活动栏 NAV-11 / UI-302/303/501-506

活动栏 46px 三槽 + 配置钮 | 项目→页面→会话三级树 | 预计 25 分钟

2.1 活动栏形态

  1. 观察左侧活动栏：46px 宽，固定三钮（上→下：导航树 / 文件 / Commit）+ 底部独立「配置」钮；按钮 34×34 圆角 6px，图标 15px 线性，默认 #8a857d。
  2. 依次点击三钮切换视图；观察激活态。
    期望：激活钮 = rgba(110,159,242,0.13) 底 + #8fb4f5 图标 + 左侧 2px #6e9ff2 竖条；hover = #222227 底 + 文字色图标。三视图互斥单槽显示。

2.2 三级树结构

  1. 导航树视图下核对层级：恰为 项目 → 页面 → 会话 三级；历史会话折叠节点挂项目下（时钟图标 +「历史」+ 计数 pill）。
    期望：项目行 500 字重 + 彩色文件夹图标 + 「当前」pill（accent-dim 底 #8fb4f5 字 10px）；行高 28px（会话行 30px）、圆角 5px；每级左缩 15px + 1px 发丝引导线。
  2. 点击项目/页面行 chevron 折叠展开；hover 各行。
    期望：折叠/展开子级正常；行 hover #222227；选中行 rgba(110,159,242,0.13) 底 + 主文字色，选中行 hover rgba(110,159,242,0.22)。

2.3 活跃会话与跳转

  1. 打开一个终端运行 claude，回到导航树观察活跃会话行。
    期望：会话行出现在其所属页面下（正确归属），构成 = 状态圆点 + claude logo（14px 彩色）+ 标题 + 右侧 32×3 迷你用量条 + 百分比（11px #8a857d）；圆点绿 #86bb7a=运行、黄 #d6b25e=等待。
  2. 点击该会话行。
    期望：聚焦到对应终端页签（工作区跳到该页签并高亮）。

2.4 历史恢复与右键菜单

  1. 展开历史节点，观察历史行（状态圆点 + logo + 标题 + 右侧相对时间，单行 30px）；hover 行看 tooltip。
    期望：行容器原生 title tooltip 显示会话 prompt 预览（不再渲染为第二行文本）。
  2. 双击一条真实历史行。
    期望：创建新终端页签并注入 cd <cwd> && claude --resume <id>（真实进入会话属人工验收，观察命令注入与页签标题即可）。
  3. 右键历史行，验证菜单三项。
    期望：菜单 = 复制恢复命令 / 分支恢复 / 删除；项高 28px 圆角 5，hover #222227，删除项文字 #d9706b；点删除 → 应用内确认弹窗（见 V4.7 浮层形态）→ 确认后行消失。

2.5 搜索过滤

  1. 在搜索框输入某项目/页面/会话名的子串（分别试小写/大写混合）。
    期望：大小写不敏感过滤；命中子节点时父级（页面/项目）保留显示并自动展开；搜索框 #1a1a1e 底圆角 5、12px、占位「搜索项目 / 页面 / 会话…」、focus 时 1px #6e9ff2 描边。
  2. 输入必然无命中的字符串。
    期望：显示统一空态（15px 线性图标 #6b675f + 说明文字 #8a857d 居中）。

2.6 配置钮与页面 CRUD

  1. 点击活动栏底部「配置」钮。
    期望：打开 hooks 配置面板（优先落在活跃页面所属项目）；右键菜单中不再出现「打开 Hooks 配置」项（入口已唯一化）。
  2. 项目/页面右键菜单验证：新建操作页面、重命名、删除；页面行内联重命名（Enter 确认 / Esc 取消）。
    期望：CRUD 行为与旧版 SidebarTree 完全一致（仅视觉换新，功能零变化）。

2.7 旧 settings 兼容

  1. 关闭应用；把 ~\.slterminal\settings.json 中 sideBar 段 zones/open 手工改回旧值（含 projects/agent-status 未注册 id）；重新启动。
    期望：启动不崩溃，侧栏自动回退默认三槽（nav/explorer/commit），open 指向未注册 id 的字段置 null。

验证 3：面板分隔条拖拽热区 GL-04 / UI-304

1px 发丝线视觉 + ≥4px 热区 | 预计 5 分钟
  1. 创建分屏：把一个面板拖到主区右缘形成双面板组（或右键页签 → 分屏选项）。
  2. 观察分隔条视觉宽度与颜色。
    期望：视觉上仅 1px 发丝线 rgba(255,255,255,0.055)，无粗条无箭头。
  3. 慢慢横向移动鼠标靠近分隔条（左右 ±2~3px），观察光标变化并尝试按下拖动。
    期望：光标在视觉线外 2~3px 处即变为 resize 双箭头（热区 ≥4px），按下可顺畅拖动调整分屏比例，不抖动不误触面板内容。

验证 4：视觉对照（对照 final-mockup.html 两页） UI-1xx/4xx/6xx/7xx/8xx

逐区对照 + 取色精确核验 | 预计 30 分钟
l0 内容区 #0a0a0b l1 侧栏 #101012 l2 chrome #141416 l3 浮层 #1a1a1e l4 hover #222227 l5 按下 #2b2b31 accent #6e9ff2 accent-fg #8fb4f5 ok #86bb7a warn #d6b25e error #d9706b cyan #6fbfc4

4.1 明度阶梯与发丝线（UI-101/102/103）

  1. 取色核对六层背景：终端/编辑器内容区 = #0a0a0b（全界面最暗）；侧栏 = #101012；标题栏/活动栏/页签栏 = #141416；浮层/输入框 = #1a1a1e；hover = #222227；按下 = #2b2b31。
    期望：任何组件背景都落在 6 档之一，不出现第 7 种灰底；内容区恒为最暗层。
  2. 观察所有分隔线：面板 sash、标题栏/页签栏底线、侧栏边线、树引导线。
    期望：一律半透明白发丝线（0.055 或 0.09），无实色粗边框。

4.2 文字灰阶与强调色纪律（UI-104/105）

  1. 对照 mockup 核对文字层级：主文字 #ece9e4、次 #b3aea6、元数据（时间/路径/分组标题）#8a857d、最弱（占位符/行号/禁用）#6b675f。
  2. 全界面扫视强调色 #6e9ff2 出现的位置。
    期望：只出现在焦点环、选中态、激活指示条、CTA 按钮、页签指示条；无装饰性蓝色，任意界面中占比 <5%。

4.3 页签栏（UI-401-404）

  1. 观察激活页签：背景 #0a0a0b（与内容区连成一体）+ 底部 2px #6e9ff2 指示条 + 文字 #ece9e4；未激活页签透明底文字 #8a857d。
  2. hover 未激活页签：文字变 #ece9e4、底色不变；hover 时关闭 × 出现（14px 圆角 4px，自身 hover 底 #2b2b31），移开鼠标 × 消失；激活页签 × 不常驻。
  3. 核对页签构成：终端/agent 页签 = 状态圆点 + claude 彩色 logo + 名称；文件页签（editor/html/gitshow/diff）= 六色盘彩色文件图标 + 文件名；无任何 emoji。
  4. 页签栏右端「+」钮：22px 圆角 4px，默认 #8a857d，hover #222227。

4.4 图标与状态圆点（UI-504/601-604）

  1. 核对活动栏/导航树/空态图标：全部线性 SVG（15px、1.5px 描边、currentColor 随文字变色），全界面无装饰性 emoji（📁🌿⭐🟠⚡✅❌ 等）。
  2. 核对文件树/文件页签彩色图标：取色限于六色盘 #7fa8e8 蓝 / #d6b25e 黄 / #93b573 绿 / #d9706b 红 / #b48ce0 紫 / #6fbfc4 青；文件夹 = 描边款，文件 = 描边 + 左缘小色块款；git 状态着色保留（modified 黄/added 绿/deleted 红）。
  3. 核对状态圆点：页签与会话行上的圆点 7px、纯色无描边无光晕无动画；色 = 运行绿 #86bb7a / 等待黄 #d6b25e / 结束灰 #6b675f / 错误红 #d9706b。
  4. claude 品牌 logo（页签/会话行 14px）保留彩色（橙 #d97757 系），不受单色纪律约束。

4.5 终端 ANSI（UI-701/702）

  1. 打开终端运行 claude，观察实际会话输出配色（claude 输出含彩色 ANSI）。
    期望：前景 #cfcac1、背景 #0a0a0b、光标 #6e9ff2；红 #d9706b、绿 #93b573、黄 #d6b25e、蓝 #7fa8e8、品红 #b48ce0、青 #6fbfc4；暗红 #7d7871 系。整体暖调、对比清晰、无刺眼高饱和。
  2. 鼠标框选终端文本：选区背景 rgba(110,159,242,0.28)；拖动终端滚动条：滑块 rgba(255,255,255,0.10)、按住 0.28、圆角 5px。

4.6 编辑器语法色（UI-703/704/705）

  1. 分别打开一个 .ts 文件和一个 .md 文件，取色核对语法高亮。
    期望：关键字 #b48ce0 / 字符串 #93b573 / 数字 #d89a66 / 属性 #d9827e / 函数 #7fa8e8 / 类型与运算符 #6fbfc4 / 标点 #7d7871 / 注释 #6b675f；正文 #b3aea6；行号 #6b675f、当前行号 #b3aea6；行号列与正文间有发丝分隔线。
  2. 在 git 仓库中修改一个文件后打开编辑器与 Commit 视图：git gutter 标记 modified #d6b25e / added #86bb7a / deleted #d9706b。

4.7 浮层（UI-801-805）

  1. 触发右键菜单（页签/文件树/导航树/Commit 列表）：#1a1a1e 底 + rgba(255,255,255,0.09) 1px 描边 + 圆角 8px + 阴影 0 8px 32px rgba(0,0,0,0.35)；项高 28px 圆角 5px hover #222227；危险项（删除类）文字 #d9706b。
  2. 触发删除确认对话框（如删除文件/历史会话）：遮罩 rgba(0,0,0,0.55)；卡片同浮层规格；主按钮 #6e9ff2 底 + #0c1220 字；次按钮 #222227 底 + #ece9e4 字；ESC/遮罩点击取消。
  3. 触发 toast 通知（如 hooks 注入成功/失败、agent 任务完成通知）：右上角堆叠，语义色 12% 底 + 1px 语义描边 + #ece9e4 文字 + 圆角 8px，3~5 秒自动消失。
  4. 触发错误横幅（文件浏览器操作失败，如删除只读文件）：背景 rgba(217,112,107,0.12) + 边框 #d9706b + 文字 #ece9e4，关闭钮为线性 × 图标。

4.8 滚动条 / 焦点环 / 空态 / 分组标题（UI-206/806-808）

  1. 在文件树/历史列表制造长列表滚动：滚动条 9px 细条、轨道透明、滑块 rgba(255,255,255,0.10)/hover 0.20/拖动 0.28、圆角 5px、无箭头按钮。
  2. 连续按 Tab 键遍历焦点（搜索框→树行→按钮），再仅用鼠标点击各处。
    期望：键盘焦点处显示 1px #6e9ff2 outline；仅鼠标点击不显示焦点环。
  3. 核对空态三处：空文件树、导航树无搜索结果、无历史会话。
    期望：统一 = 居中 15px 线性图标（#6b675f）+ 一句话说明（#8a857d）+ 可选次按钮；无彩色插图无 emoji。
  4. 核对分组标题（导航树「导航」、Commit 视图「COMMIT」等）。
    期望：11px + 全大写 + 字距 0.08em + 颜色 #8a857d（fg-3），各处一致。

验证 5：断网字体回退 UI-202

JetBrains Mono 随产物内置，断网不回退非等宽 | 预计 5 分钟
  1. 禁用网络（飞行模式或禁用网卡），关闭并重新启动应用。
  2. 观察界面文字（侧栏、页签、标题栏）与终端内文字的字形。
    期望：仍为 JetBrains Mono（字体内置 woff2 随产物打包）；若回退到非等宽字体，界面文字宽度会明显变宽、终端对齐错乱——不允许出现。
  3. 恢复网络，确认无残留影响。
