# 设置中心 需求规格

> 特性编号：**F11**（实施时登记根 `.claude/CLAUDE.md` 需求编号索引）
> 状态：需求已冻结（经 15 轮问答确认）；本文档仅为需求规格，不含开发计划。

---

## 1. 背景与目标

### 1.1 现状

- 活动栏底部「配置」钮是 hooks 配置面板的唯一入口：`openHooksConfigFromActivityBar()` → 切页（项目 `pages[0]`，无则新建）→ 打开 `hooksConfig` 面板（同页单例，C13-7）。
- `hooksConfig` 面板是 hub 容器：顶部 CLI 选择行 + 编辑器槽，经 CLI profile `capabilities.hooks.configEditor` 分派（KZ-1）。
- 应用自有设置存 exe 同级 `settings.json`，SEC-11 白名单 5 键（`fontSize`/`keybindings`/`sideBar`/`colorScheme`/`planBalance`），各 store 各写各的顶层段、后端浅合并 + 原子写 + `.bak` 兜底 + `SETTINGS_SAVE_LOCK` 串行化。
- 其中两项配置**无 GUI**：`planBalance.intervalSec` 只能手改文件且启动时读一次（运行期改不生效）；`keybindings` 数据模型与运行时生效链路已就绪，可视化 UI 是 shortcuts 模块文档明示的「后续 feature」。

### 1.2 动因

配置项将增长为两类——全局级（套餐余量查询频率、快捷键等）与项目级（Hooks 配置等），「配置钮直达单一面板」的形态无法承载。需要：

1. 前端：统一的设置中心交互形态，新增配置页零框架改动。
2. 后端：配置代码高内聚、低耦合、易扩展，新增配置域的改动点收敛。

### 1.3 目标

- 一个设置中心面板承载全部配置页，左导航按「全局 / 项目」分组。
- 第一期落地 3 个配置页：Hooks 配置（迁入）、套餐余量查询频率、快捷键。
- 前端以配置页注册表承接扩展；后端以「域键名归域 + 哑存储 + 专用命令」轻量收口承接扩展。

## 2. 术语约定

以下术语为本次新增，**实施完成时同步 `CONTEXT.md`**：

| 术语 | 定义 |
|------|------|
| **设置中心**（Settings Center） | 本应用统一配置入口的 Dockview 面板（面板类型 `settings`）。左导航（全局/项目两组）+ 右侧配置页槽位，经 SettingsPageRegistry 分派渲染 |
| **配置页**（Settings Page） | 设置中心内的注册单元，一个配置域一个页 |
| **全局组** | 应用级单例配置，无需项目上下文即可编辑 |
| **项目组** | 需活跃项目上下文才能编辑的配置（无项目时入口被 toast 拦截，页不可达，R3 修订） |
| **前端消费型配置** | 消费侧在前端（store/注册表）的配置域，后端纯透传存储（fontSize/keybindings/sideBar/colorScheme）。写通道 = 通用 `save_settings` 段写 |
| **后端消费型配置** | 消费侧在后端的配置域（planBalance.intervalSec）。写通道 = 域模块专用命令（校验 + 内存态 + 落盘一体） |

语境区分：「**设置**」指本应用自有配置体系（设置中心/settings.json）；「**配置**」保留给按钮文案与 CC 配置文件语境（hooks 配置、settings.json of claude）。

## 3. 范围

### 3.1 第一期包含

- 设置中心框架：面板类型 `settings`、SettingsPageRegistry、打开编排（`openSettings`）、dirty 汇聚守卫、切项目自动关闭。
- 配置页 ×3：

  - **快捷键**（全局组）——`keybindings` 覆盖层可视化编辑。

- 配置项搜索。
- 字号 / 配色方案 / 侧栏宽度 GUI（登记为后续配置页候选，用于验证加页成本）。
- 设置导入 / 导出。
- 快捷键冲突强制解决（允许冲突 + 警告，见 §4.5）。
- 设置中心键盘快捷键入口（维持鼠标唯一入口，尊重 `Ctrl+Shift+H` 删除的历史收口决策）。

## 4. 功能需求

### 4.1 入口行为与全局单例不变量

- 活动栏底部「配置」钮为**唯一入口**（无键盘命令）。点击行为 = `openSettings` 编排：目标项目 = 活跃页面所属项目（兜底第一个项目）→ 目标页面 = 该项目 `pages[0]`（无则新建空布局页）→ 切页 → 打开/聚焦设置中心面板。
- **无项目不可打开**：点击配置钮 → toast「请先创建项目」，面板不打开（R1 修订：无项目=无页面=无 Dockview 宿主，面板无处承载）。
- **同页单例**（沿用 C13-7）：同页重复打开 → 聚焦已有面板。
- **全局单例不变量**：入口恒解析到项目 `pages[0]` + 同页单例 + 切项目自动关闭（§4.6），三者叠加 ⇒ **全应用任意时刻至多一个设置中心面板**。hooks 页 rootPath 推导、dirty 守卫范围均以此为前提。
- 页签标题固定「**设置**」，不随选中页变化。
- `openSettings` 预留可选 `pageId` 参数（深链定位某配置页），第一期无消费方。

### 4.2 面板形态

```
┌ 设置 ──────────────────────────────────────────────┐
│ ┌────────────┬───────────────────────────────────┐ │
│ │ 全局        │                                   │ │
│ │  快捷键     │        配置页槽位                  │ │
│ │  套餐余量   │     （SettingsPageRegistry        │ │
│ │ 项目        │       分派渲染选中页）             │ │
│ │  Hooks 配置 │                                   │ │
│ └────────────┴───────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

- 左导航固定 180px 不可拖拽；组序「全局」在上、「项目」在下。
- 默认选中：布局 `params.selectedPage` 有值恢复上次选中；无值或指向已不存在的页 → 回退全局组第一页。
- 导航项显示 dirty 圆点（状态圆点视觉先例）。
- 打开时若 `loadSettings` 返回 `corrupted=true`，面板顶部显示一次性警示条「设置文件已损坏，已从备份/默认值恢复」（可关闭、不阻塞）。
- 面板打开失败（页面 DockviewApi 未就绪）沿用轮询降级模式（console.warn，不抛异常）。

### 4.3 保存模型：各页自治 + 壳层 dirty 汇聚

- **保存语义归各配置页自治**，作为页注册契约的一部分；壳层不管「怎么存」，只管「有没有未存」。
- 页组件经 `onDirtyChange?: (dirty: boolean) => void` 上报（沿用 hooks 编辑器先例），壳层聚合到导航圆点 + 守卫。
- **守卫时机**：切换配置页、关闭面板（含 §4.6 自动关闭）时，dirty 页弹 `confirmDialog` 确认丢弃（askGuard 防循环先例）。
- 即时保存页（快捷键/频率）为离散提交、无 pending 窗口，**不上报 dirty**——dirty 守卫实际只服务显式保存页（hooks 及未来同类页）。

### 4.4 配置页：套餐余量查询频率（全局）

- 数值输入框（单位秒）+ 范围提示「10–3600 秒，默认 60」。
- **提交时机**：失焦 / 回车提交（非 debounce——避免删空重输的中间态越界）。输入非法（非数/越界）→ 行内红字提示，不提交、不 toast。
- **读取**：组件挂载时经通用 `loadSettings` 读 `planBalance.intervalSec` 段（不新增 get 命令、不新建 store，组件内状态）；缺失/越界显示默认值 60（与后端 `resolve_poll_interval` 钳制语义对齐）。
- **保存**：调专用命令 `plan_balance_set_interval`——后端校验 10–3600（复用现有钳制常量，越界返回 Err → 前端 toast）→ 更新 plan_balance 模块级 static 原子量 → 经 settings.rs 既有写通道落盘。**禁止自建第二写通道**（原子写 / `.bak` / `SETTINGS_SAVE_LOCK` 必须复用，否则 SPE-06 并发写竞态回归）。
- **立即生效**：轮询循环改为每轮 tick 前读当前内存间隔值（`tokio::time::interval` 的 period 不可变，实现上 drop 重建或改 sleep 循环）；不再「启动时读一次」。
- **生效反馈闭环**：专用命令成功后前端调一次 `refreshPlanBalance()` 拉取最新余量。
- 手改文件的「越界回退默认」容错继续保留在后端读取侧（两层不矛盾：GUI 拒绝越界写，手改越界读时回退）。

### 4.5 配置页：快捷键（全局）

- 按 `category` 分组的命令列表（数据源 `listCommands()`）；行 = 命令标题 + 当前生效键位 + 重置钮。
- 覆盖值高亮 + 行内 ↺ 重置钮（仅已修改行出现，重置 = 删 override）；已修改行附默认键小字；解绑行显示「未绑定」占位。
- **录制态**：点击行进入，下一次按键组合实时转 keystroke 字符串（复用 `keystroke.ts` 格式化）；`Esc` 取消；`Backspace`/`Delete` = 解绑（写 `null`）；录制中点击别处/切页 = 取消。
- **录制态屏蔽命令分发**（硬边界）：录制期间按键不得进入 ShortcutRegistry 命令分发（否则录制 `Ctrl+Shift+C` 会真执行复制）；IME 合成期间不录制（复用现有 IME 守卫）。
- **校验**（复用 `reserved.ts` 规则）：保留键/非法键 → 行内红字拒绝，不写入；**同 context 冲突 → 行内警告「与 XX 冲突，生效按优先级派发」但允许保存**（与运行期 winner-take-all 语义一致）。
- 保存 = 离散提交写 `useKeybindings` store（既有 debounce 持久化 + `wireKeybindings` 运行时立即生效链路不动）。
- 第一期不做搜索（命令十余条，分组后一屏可见）。

### 4.6 切项目自动关闭

- **触发**：活跃项目变化（activePageId 所属 projectId 变化）→ 关闭所有「所在页面不属于新活跃项目」的设置中心面板。**同项目内切页不触发**（面板留在原页面）。
- **dirty 处理**：自动关闭走 §4.3 壳层 dirty 守卫同一路径——有未保存修改 → `confirmDialog` 确认丢弃后才关闭；无 dirty 静默关闭。
- **整面板关闭**（含全局组选中态）——换来「设置中心面板任何时刻至多属于一个项目」的干净不变量。
- **实现归属**：面板自订阅自关闭（挂载时订阅活跃项目，发现自身所在页面不属于活跃项目 → 经 dirty 守卫后自行关闭），不新增全局编排器。
- 项目删除随既有页面销毁链处理，不新增逻辑。

### 4.7 边界场景汇总

| 场景 | 行为 |
|------|------|
| 无项目点击配置钮 | toast「请先创建项目」，面板不打开（R1 修订）；无项目时 hooks 页场景随之不可达（R3 删除——项目删除→页面销毁→面板随之销毁，hooks 页 rootPath=null 防御已足够） |
| 项目组配置的目标项目 | = 面板所在操作页面所属项目（沿用 hooks 配置现有 rootPath 推导链，不新建上下文源） |
| GUI 打开期间手改 settings.json | 不重读（hooks 配置的外部修改检测是其页内既有能力，不推广到全局页） |
| 布局恢复遇旧 `hooksConfig` 面板 | 白名单过滤静默丢弃（未注册类型），用户手动重开设置中心 |
| 布局恢复 `selectedPage` 失效 | 回退全局组第一页，不报错 |
| 频率保存失败（专用命令 Err） | toast 提示，输入框保留用户值 |
| settings.json 损坏 | 顶部一次性警示条（§4.2），各页显示默认值 |

## 5. 架构与设计约束

### 5.1 前端：SettingsPageRegistry（硬约束 #13 家族新成员）

注册表形态遵守注册表家族通用契约：模块级单例、`register(...)` / `getAll()`（按注册序）、`_reset()`（仅测试）、side-effect import 触发（触发点登记于所属模块 CLAUDE.md）。

注册项字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一标识（`"hooks"` / `"planBalance"` / `"keybindings"`）；导航选中态与布局持久化的锚 |
| `title` | string | 导航显示名 |
| `group` | `"global" \| "project"` | 分组即项目上下文需求；`project` 组需项目上下文（无项目时入口被 toast 拦截，页不可达，R3 修订） |
| `component` | React 组件 | 接收 `onDirtyChange?: (dirty: boolean) => void` 上报 |
| `order?` | number | 组内排序，缺省按注册序 |

配套约束：

- **嵌套分派不动**：hooks 配置页组件 = 现有 hub 内容（CLI 选择行 + `profile.configEditor` 分派）原样迁入；SettingsPageRegistry 不感知 CLI 层，新 CLI 自带编辑器仍走 profile 挂载（KZ-1）。
- **页内状态持久化命名空间**：面板 params 结构 `{ selectedPage, pageParams: { hooks: { selectedCli } } }`——各页状态挂自己命名空间下（hooks 页 `selectedCli` 先例平移），壳层不感知内容。
- 面板封闭（硬约束 #5）：新增面板类型 `settings` 走既定五步（目录 → panels/index → panelRegistry → PANEL_TYPES → capabilities）；`hooksConfig` 类型从注册表与 PANEL_TYPES 移除。

### 5.2 后端：轻量收口三段式

1. **域键名常量归域模块**：各域导出自有键名常量（如 `plan_balance::SETTINGS_KEY`），`settings.rs` 只聚合白名单数组——域键名不再是散落魔法字符串。
2. **settings.rs 保持哑存储**：白名单 + 浅合并 + 原子写 + `.bak` + 锁，不引入域语义。第一期白名单不变（3 个配置页复用已有键，无新增顶层键）。
3. **后端消费型域自备专用命令**：校验 / 内存态 / 落盘一体收在域模块内（planBalance 先例：`plan_balance_set_interval` 住 plan_balance 模块；内存间隔值入 **plan_balance 模块级 static 原子量**（读写双方同模块，SNAPSHOT 先例，State 注入不可直调单测），启动时 `resolve_poll_interval` 初始化）。

**写入通道二分**（配置域分类依据）：

| 类型 | 消费侧 | 写通道 | 例 |
|------|--------|--------|----|
| 前端消费型 | 前端 store/注册表 | 通用 `save_settings` 段写 | keybindings、fontSize |
| 后端消费型 | 后端模块 | 域专用命令（校验+内存+落盘） | planBalance.intervalSec |

### 5.3 模块拓扑

- `src/features/settingsCenter/`：SettingsPageRegistry + `openSettings` 编排（泛化取代 `features/hooksConfig/openHooksConfig.ts`）。
- `src/panels/settings/`：设置中心面板与各配置页组件（hooks 页组件迁入）。
- `src/features/hooksConfig/`：schema 单点保留（claude 专属资产，MC-223 语义不变），`openHooksConfig.ts` 删除。

### 5.4 既有红线引用（实施时遵守，不展开）

- 新命令 `plan_balance_set_interval` **三处注册**：`lib.rs` `generate_handler!` + `build.rs` `AppManifest` + `capabilities/default.json`（SEC-07 先例，src-tauri CLAUDE.md 红线）。
- 新面板 id 形态遵循 B14 单点收口（恢复面板 id 不含 Date.now 段）。
- DTO 双边对应（硬约束 #4）：专用命令 DTO 前后端同步 + 契约测试。
- hooks 页迁入后 SEC-05/D9 保存语义（user 层二次确认 + 后端写入审查）原样保留；注入/卸载工具栏（F2 并入 F6 现状）随页迁移。

## 6. 兼容与迁移

- **settings.json 键形态不变**：`planBalance.intervalSec`、`keybindings` 段结构不变，老版本配置文件无迁移。
- **布局兼容**：老布局 JSON 中的 `hooksConfig` 面板由恢复白名单过滤丢弃，无迁移映射（用户手动重开设置中心，体验断层可接受——已确认）。
- **手改文件并存**：GUI 与手改共用同一 settings.json；手改的容错钳制（后端读取侧）保留。
- **hooks 配置能力无回退**：迁入后全部既有能力（三层编辑/双模式/SEC-05 确认/外部修改检测/注入卸载）原样可用。

## 7. 验收标准

行为断言（Given/When/Then），实施时转化为测试用例并按硬约束 #11 登记 `.claude/test-inventory.md`：

**入口与单例**
1. 点击活动栏配置钮 → 当前项目 `pages[0]` 打开设置中心；再点 → 聚焦而非新开。
2. 无项目点击配置钮 → toast「请先创建项目」，面板不打开。
3. 任意时刻全应用至多一个设置中心面板（全局单例不变量）。

**分组与导航**
4. 选中页持久化：选中某页 → 重启应用 → 恢复该页选中态；`selectedPage` 失效 → 回退全局组第一页。
5. hooks 页 dirty 时切换配置页/关闭面板 → confirm 确认丢弃后才执行；确认放弃则不切。

**切项目自动关闭**
6. 项目 A 打开设置中心 → 切到项目 B → A 的设置中心面板已关闭；在 B 点配置钮 → 在 B 的 `pages[0]` 打开（不跳回 A）。
7. 同项目内切页 → 设置中心面板保留在原页面不关闭。
8. 自动关闭时 hooks 页 dirty → confirm 确认丢弃后才关闭。

**套餐余量查询频率**
9. 输入合法值（如 120）失焦 → 保存成功 → settings.json `planBalance.intervalSec=120` → 轮询间隔立即按新值执行（不重启应用）→ 余量自动刷新一轮。
10. 输入越界/非数 → 行内红字，不落盘、不 toast；后端直接收到越界值 → Err 拒绝且不落盘。
11. 手改 settings.json 为越界值 → 后端读取侧回退 60s（容错保留）。

**快捷键**
12. 录制新键位 → 行内生效键位更新 + ↺ 出现 → 对应命令立即可用（不重启）；录制态按 `Ctrl+Shift+C` → 不触发复制命令。
13. 绑定保留键/非法键 → 行内拒绝不写入；绑定同 context 冲突键 → 警告提示但允许保存，运行期按优先级派发。
14. ↺ 重置 → 恢复默认键；`Backspace` 解绑 → 显示「未绑定」。
15. `Esc`/点击别处 → 取消录制，键位不变。

**兼容**
16. 老布局含 `hooksConfig` 面板 → 恢复时静默丢弃，无报错。
17. settings.json 损坏 → 设置中心顶部警示条 + 各页显示默认值。

**防复发要求**：上述断言中可自动化部分（L1/L2/L4）必须常驻测试；不可自动化部分登记豁免清单。完整测试矩阵在开发计划中制定。

## 8. 决策记录

| # | 决策点 | 结论 | 被否方案与理由 |
|---|--------|------|----------------|
| 1 | 分组语义 | 按「是否需要项目上下文」分全局/项目组；hooks 整体归项目组，内部三层不动 | 按真实作用域拆分 hooks 编辑器（user 层挪全局）——把内聚编辑器按层劈开；按配置归属方分组——与用户心智不符 |
| 2 | 载体形态 | Dockview 面板（类型 `settings`），左导航 + 注册表分派槽位 | 模态框（遮罩终端、违背面板封闭心智）；独立窗口（违背单窗口定位约束）；侧栏视图（宽度放不下双模式编辑器） |
| 3 | hooksConfig 面板类型 | 直接退役，布局恢复白名单过滤兜底 | 一次性迁移映射（成本高于收益）；保留兼容薄壳（类型表淤积死类型） |
| 4 | 第一期范围 | 框架 + Hooks 迁入 + 频率 + 快捷键 | 纳入字号/配色/侧栏——配色仅一套方案 GUI 价值≈0，字号/侧栏留作后续验证加页成本 |
| 5 | 保存模型 | 各页自治 + 壳层 dirty 汇聚守卫 | 全部即时保存（废掉 SEC-05 确认）；全部显式保存（快捷键/频率体验倒退） |
| 6 | 频率生效 | 专用命令 + 内存原子量 + 每轮读值，立即生效 | 重启生效（设置中心信用受损）；notify 监听文件变更（多一条监听链，间接收敛不如直读） |
| 7 | 后端架构深度 | 轻量收口三段式（键名归域/哑存储/专用命令） | 完整后端注册表（自注册 crate 依赖，后端实际消费域仅 1 个，机制空转）；完全不动（键名魔法字符串散落） |
| 8 | 注册表契约 | id/title/group/component/onDirtyChange/order；dirty 回调上报 | 壳层轮询 getDirty()——回调与 hooks 编辑器先例一致，免轮询 |
| 9 | 快捷键交互 | 点击录制 + 保留键拒绝 + 冲突警告放行 | 冲突强制拒绝——与运行期 winner-take-all 语义不一致，冲突有时是故意覆盖 |
| 10 | 频率读取 | `loadSettings` 读段，不建 get 命令/不建 store | 新增 get 命令——settings.json 本就全量加载，重复通道 |
| 11 | 入口语义 | 同页单例 + 固定标题 + 180px 固定导航（无项目分支经 R1 修订为 toast 拦截，见决策 16） | — |
| 12 | 切项目 | 自动关闭整面板（dirty 走守卫），面板自订阅自关闭 | 老面板保留——rootPath 跟随活跃项目推导会显示新项目配置，错乱 |
| 13 | 频率提交时机 | 失焦/回车提交（修正早期 debounce 结论） | debounce——删空重输中间态越界 toast 轰炸 |
| 14 | 键盘入口 | 维持鼠标唯一入口 | `Ctrl+,` 快捷键——推翻「配置钮唯一入口」历史收口决策 |
| 15 | 损坏警示 | 顶部一次性警示条 | 保持静默——配置损坏是用户应知情的数据事件 |
| 16 | 无项目入口（R1 修订） | 点击配置钮 → toast「请先创建项目」，面板不打开 | 无项目可打开（全局组可用 + 项目组禁用）——无项目=无页面=无 Dockview 宿主（Workspace.tsx 主区 allPages.map），面板无处承载（计划期代码实证回弹） |
| 17 | 内存间隔值落点（R2 修订） | plan_balance 模块级 static 原子量 | AppState 原子量——读写双方同在 plan_balance 模块（无跨模块共享）；SNAPSHOT 模块级 static 先例（mod.rs:66）；State 注入使 L1 无法直调命令 fn（现有命令测试全为直调） |
| 18 | 项目组禁用（R3 修订） | 删除（不可达） | 无项目开不了面板（R1 toast 拦截）；项目删除→页面销毁→面板随之销毁；hooks 页 rootPath=null 防御（useHooksConfig 既有）已足够 |
