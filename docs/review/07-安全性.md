## 3. 权限与配置审查

### 3.1 `capabilities/default.json`

- 仅声明插件权限；自定义命令未显式白名单（Tauri 2 默认放行），已在发现 7 中记录。
- `clipboard-manager:allow-read-text` 过宽，已在发现 6 中记录。
- `core:default` 包含基础窗口权限，未包含危险能力，可接受。

### 3.2 `tauri.conf.json`

- `csp` 使用 `'unsafe-inline'` 并禁用 asset CSP 修改，见发现 9。
- `dragDropEnabled: false` 降低了拖拽注入面。
- `dev_tools: false` 在生产环境关闭 DevTools，正确。

## 4. 输入校验与路径沙箱

- `validate_path_within_root`（`state.rs:138-180`）覆盖 `fs_*`、`notify_watch`、`git_*`、`pty_spawn` 的 `cwd`，使用 `dunce::canonicalize` + `canonicalize_or_ancestor`，对 `..` 穿越和 symlink 指向根外路径有拒绝能力。
- `fs_write_file` / `fs_create_dir` 校验父目录，适应新建文件/目录场景。
- `fs_rename` 拒绝覆盖已有目录，正确。
- `pty_spawn` 对 `cols/rows` 做 `i16::MAX` 校验，正确。
- 缺失：`pty_reattach` 未沿用 `panel_id` 归属校验（发现 3）。

## 5. XSS 与渲染安全

- HTML 预览使用 `sandbox="allow-scripts"`（不含 `allow-same-origin`），与 Tauri 主进程不同源，基础隔离正确。
- `srcDoc` 内容经 `injectScript` 注入脚本，脚本来源固定，但 CSP `unsafe-inline` 降低了额外保护。
- 键盘转发存在 shortcut spoofing，见发现 4。

## 6. 敏感信息

- 设置与项目数据以明文 JSON 存于 exe 同级目录，无加密，见发现 11。
- 剪贴板读取权限存在泄露风险，见发现 6。
- PTY `output_ring` 保留最近 256KB 输出，以内存/ring buffer 形式存在，未持久化。

## 7. 文件监听安全

- Hook 信号 watcher 未过滤 symlink，见发现 2。
- 项目文件 watcher 未过滤 symlink，见发现 8。
- 两者均使用 debouncer + 轮询补漏架构，本身可靠，但补漏通道同样会消费 symlink。

## 10. 建议修复（按优先级）

1. **P0-1 Shell 白名单绕过**：将 `validate_shell_allowlist` 改为基于真实可执行文件路径/签名/哈希的校验，拒绝用户传入任意路径；`resolve_shell_info` 对用户指定路径不再信任文件名。
2. **P0-2 Hook 信号 symlink**：在 `process_signal_file_with` 和 `collect_signal_files` 中检查 `is_symlink`；对信号目录设置更严格 ACL。
3. **P1-3 pty_reattach 归属校验**：为 `pty_reattach` 增加 `panel_id` 参数并调用 `validate_session_ownership`。
4. **P1-4 HTML 预览 shortcut spoofing**：为 iframe 与父窗口之间的键盘转发引入不可伪造的 token，或仅允许白名单内的关键组合。
5. **P1-5 Hooks 配置语义校验**：为 `hooks` 子树增加 Schema 校验，限制事件名、`type`、`command` 内容，并对 `user` 层写入二次确认。
6. **P1-6 剪贴板读取权限**：移除 `clipboard-manager:allow-read-text`，改为由后端在收到用户粘贴动作时一次性读取。
7. **P1-7 自定义命令白名单**：在 `build.rs` 配置 `AppManifest::commands`，按窗口/ capability 显式授权。
8. **P1-8 文件监听 symlink**：在 watcher 事件循环中过滤 symlink 路径，避免将项目外部路径 emit 到前端。
9. **P2-9/10/11/12/13/14**：CSP 收紧、移除 `innerHTML`、设置/项目数据 Schema 与大小限制、statusline 命令审计、脚本哈希校验、`set_project_root` 规范化。
