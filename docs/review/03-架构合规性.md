## 2. 逐条合规结论

### 硬约束 #1：invoke 只出现在 `src/ipc/`
- **结论**：合规。
- **证据**：
  - `grep 'invoke\s*('` 在 `src/`（排除 `__tests__`）仅命中 `src/ipc/*.ts` 与 `src/ipc/CLAUDE.md` 中的注释。
  - `grep '@tauri-apps/api/core'` 在 `src/`（排除测试）仅命中 `src/ipc/*.ts`。
  - 未发现 `window.__TAURI__` 直接调用。
- **合规率**：抽查全部 17 处 `invoke(` 调用，0 处越界。

### 硬约束 #2：后端按功能分模块，共享只经 `state.rs` 的 `AppState`
- **结论**：基本合规，存在 1 处越界。
- **证据**：
  - 功能模块（`fs/git/notify/hooks/agent_history/pty`）均通过 `use crate::state::AppState` 获取共享状态，未发现互相直接调用。
  - **违规**：`src-tauri/src/projects.rs:5`：`use crate::settings::app_data_dir;`。`projects` 与 `settings` 均为顶层模块，但 `app_data_dir` 属于 `settings` 模块内部实现，未通过 `AppState` 暴露。
  - `state.rs` 本身导入 `notify::pool::LruWatcherPool` 与 `pty::spawn::PtyEvent` 以构造 `AppState`，属于共享状态的合理封装，不视为越界。
- **合规率**：约 95%（1/20 处跨模块导入违规）。

### 硬约束 #3：命令统一注册于 `lib.rs` 的 `generate_handler!`；一律返回 `Result<_, AppError>`；阻塞 I/O 用 `spawn_blocking`
- **结论**：命令注册与返回类型合规；阻塞 I/O 基本合规，2 处同步命令未走 `spawn_blocking`。
- **证据**：
  - `src-tauri/src/lib.rs:78-112` 的 `generate_handler!` 共注册 33 条命令，与 CLAUDE.md「33 条现行清单」一致。
  - 所有 `#[tauri::command]` 函数签名均返回 `Result<_, AppError>`（grep `pub (async )?fn .*-> Result<.*AppError>` 全命中）。
  - `fs/git/agent_history/hooks/pty/settings/projects` 的 async 命令均使用 `tokio::task::spawn_blocking` 包裹阻塞 I/O。
  - **偏差**：
    - `src-tauri/src/state.rs:186`：`set_project_root` 为同步命令，直接调用 `dunce::canonicalize`。
    - `src-tauri/src/notify/mod.rs:287`：`notify_watch` 为同步命令，直接调用 `FileWatcher::start_with_emitter`。
- **合规率**：29/31 条含阻塞 I/O 或系统调用的命令符合 `spawn_blocking` 要求；2 条同步命令未覆盖。

### 硬约束 #4：`src/types/` 与 Rust 模块 DTO 一一对应；Rust `snake_case` ↔ JS `camelCase`
- **结论**：合规。
- **证据**：
  - `src/types/pty.ts` ↔ `src-tauri/src/pty/spawn.rs`（`PtyEvent`、`SpawnRequest`）。
  - `src/types/agent.ts` ↔ `src-tauri/src/hooks/signal.rs`（`AgentEventPayload` 十字段 + 可选 `cliId`/`usedPercentage`）。
  - `src/types/agentHistory.ts` ↔ `src-tauri/src/agent_history/mod.rs`（`AgentHistorySession` 八字段、`AgentHistoryTitle` 两字段）。
  - `src/types/git.ts` ↔ `src-tauri/src/git/mod.rs`（`GitStatusEntry`、`DiffHunk`）。
  - `src/types/notify.ts` ↔ `src-tauri/src/notify/mod.rs`（`FsEventPayload`）。
  - `src/types/fs.ts` ↔ `src-tauri/src/fs/mod.rs`（`DirEntry`）。
  - Rust 侧 DTO 均带 `#[serde(rename_all = "camelCase")]`。
- **合规率**：抽查 7 组 DTO，0 处漂移。

### 硬约束 #5：Dockview 面板只能是 `panels/` 下注册过的类型，注册于 `panelRegistry.ts`
- **结论**：合规。
- **证据**：

  - `PANEL_TYPES` 数组与白名单校验 `isValidPanelType` 存在于同一文件。
  - `src/workspace/layoutSerde.ts:90` 使用 `isValidPanelType` 过滤布局恢复时的面板类型。
- **合规率**：100%。

### 硬约束 #6：配色单点；禁止硬编码颜色（既定例外已登记）
- **结论**：基本合规，存在 1 处动画效果偏差。
- **证据**：

  - 既定例外已登记并存在：

### 硬约束 #8：会话元数据单点；PTY 进程映射仅在 `panels/terminal/TerminalRegistry`
