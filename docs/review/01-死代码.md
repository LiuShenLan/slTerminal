## 3. 未覆盖区域

- **Rust 私有 helper 函数**：`cargo clippy -W dead_code` 仅基于 crate 可见性报告；未逐个人工核对各模块内部是否存在仅被测试调用的私有函数。
- **动态/注册式引用**：Dockview 面板、sideViewRegistry、CliProfileRegistry 等通过字符串 id 或 side-effect 注册，knip 可能漏报或误报；已按架构文档将注册表相关项排除。
- **类型-only barrel**：`src/types/index.ts`、`src/stores/index.ts` 等 barrel 未在生产中通过该入口导入，但大量具体类型通过源文件直接消费；未逐一确认每个类型是否仍有意义。
- **测试辅助代码**：`src/__tests__/`、`e2e-tests/`、`test/` 按审查要求整体排除，其内部是否存在测试-only 死代码未统计。
