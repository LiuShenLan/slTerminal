# 规格问题与裁决

> 目标态重建前的规格冲突、缺口与裁决记录；`docs/featureSpec/` 修订的依据。所有条目已关闭，无待决项。

## 裁决摘要

- 需求真值源仍是 `docs/featureSpec/`；本文件记录为落地目标态而对规格做的修订与设计层裁决。
- 已确认的代码基线：分层重建；新增项目/布局/面板领域 core crates；重建 app 壳与持久化；旧 workspace/tab/pane/dock/session 代码整体废弃。
- 已确认的产品边界：Windows 10/11、单窗口单实例、仅暗色、默认 PowerShell 7、不走 WSL、不迁移旧数据、不保留 Runtime v1 兼容层。
- 已确认的能力取舍：Image 面板、Merge 三栏、用户自定义主题、Markdown 渲染态实时块编辑、提示符跳转删除；vi 模式、终端补全、数学覆盖层、AI 修复条保留为迁移能力；Mermaid 首版不渲染。
- 已确认的存储与计划口径：结构化工作区状态使用本地 SQLite 单库；设置 JSON 留漫游根；机器本地文件统一放本地根；Runtime v2 协议先行、方法增量；旧壳先退状态模型/写路径，再按域删除旧 UI 宿主；会话领域归 `slterm_agents`；另存为授权不跨重启；主题不做任何对比度判断；契约按单一所有者收敛；主线开发不逐里程碑开分支。

## 二、featureSpec 修订矩阵

### `README.md`

- 跨域不变量与关键跨域决策：项目身份改为稳定 `ProjectId`；根路径唯一只是不变量。
- 术语表与文档地图：设置中心增加“应用”页；Markdown 条目改为“Mermaid 首版按源码显示”；删除无障碍描述；主题无可读性提示；另存为授权不跨重启。数据根与漫游/本地划分由 `settings-and-persistence.md` 定义，README 只引用，不重复。
- 键盘/焦点矩阵：切换项目恢复最后聚焦面板并送入焦点落点；终端键盘选区与复制；焦点循环为固定系统键。
- 明确不做：增加“Mermaid 首版不渲染”“外部文件拖入不支持”“无项目时应用设置浮层”等边界；把范围外能力与“明确不做”分开表述；PTY 并发 8 非契约；公开发布不因 AI Providers/助手与终端增强阻塞。

### `workspace/shell.md`

- 模型与不变量：新增 `ProjectId`；根路径唯一是不变量，不是身份。
- 项目生命周期：创建/重定位保留 `ProjectId`；根重定位对文件型面板的迁移规则。
- 设置中心入口：无项目时打开仅含应用页的全局设置浮层；有项目时仍为项目内设置中心。
- 切换项目焦点：恢复该项目最后聚焦的面板组/面板并把键盘焦点送入焦点落点；导航树不保留“焦点留在项目行”。
- 关闭链：受守卫集合为设置 JSON 与状态库全部 dirty facet，失败中止；最终终端簿/布局事务为 best-effort；项目移除确认后丢弃未保存修改、只提交项目相关状态库事务，批量关闭与窗口关闭逐个保存；两者都不触发全局设置/布局冲刷。
- 单实例：第二次启动可携带 `Focus/OpenProject/OpenFile/NewTerminal`；`NewTerminal` 按 cwd 最深匹配项目，否则活跃项目；目标组为该项目的聚焦组，无组则建首组；目标不存在不自动创建。
- 终端簿：标题、编号、最近 cwd 只归 `TerminalBook`/`project_terminals`；布局不保存这些字段与编号计数。
- 活动项目标识：由状态库 `workspace` facet 持久化；仅快捷键覆盖留在应用设置。
- Diff 去重：默认键为“项目 + 规范化工作区路径”，来源不参与；冲突快照瞬态，不持久化、不入布局。
- 窗口：默认尺寸/最小尺寸；窗口几何持久化列为范围外迁移，不在规格承诺。
- 无障碍基线：删除；保留键盘、焦点、IME、减少动效作为普通交互条款。
- 验收：删除无障碍行；增加应用页浮层、ProjectId、关闭链分类、单实例载荷、焦点恢复、终端簿权威与 Diff 去重。

### `workspace/navigation.md`

- 身份与不变量：`ProjectId` 是身份；根路径词法唯一 + 真实路径查重。
- 根目录重定位：文件型面板、Hooks、Diff/GitShow、终端 cwd、崩溃快照的迁移规则。
- 项目激活焦点：不在项目行保留焦点；切换项目后按工作区壳契约进入目标面板焦点落点。
- 视图状态：项目级状态以 `ProjectId` 为键，路径存相对形式。
- 无障碍与国际化：删除屏幕阅读器/播报/高对比度/大字体内容；保留 IME/CJK 与键盘操作。
- 验收：同步身份、重定位、状态作用域；删除读屏断言。

### `sidebar/framework.md`

### `sidebar/explorer.md`

- 跨类型重命名：默认形态保持源码（脏或原为源码），目标已打开显式确认替换。

- Git 行标：新增/修改/删除标记均可点击打开 Diff；删除标记定位到删除块。
- 崩溃恢复：配额 64 MiB / 256 MiB / 7 天；键 `(ProjectId, PanelId)`；聚合恢复提示。
- 脱离缓冲：文件已移出允许根仍可编辑可脏；自动保存暂停；`Ctrl+S` 走另存为；关闭走守卫。
- 另存为：授权只绑定当前文档与当前运行期，不写入布局；重启后根外路径按根外只读重新判定。
- 外部文件拖入：不支持。
- 无障碍：删除读屏/大字体/高对比度内容；保留 IME/CJK 与键盘。
- 验收：同步高亮、跨类型、冲突、gutter、快照、脱离缓冲；删除无障碍行。

### `panels/markdown.md`

- 无障碍：删除读屏/大字体/高对比度内容；保留 IME/CJK 与键盘。

## 三、设计层采纳（不修订需求）

| 领域 | 采纳结论 |

| 命令与焦点 | 分层派发表：临时面 > 系统键 > 面板固定键/保留键 > 面板命令 > 侧栏视图快捷键 > 全局命令 > 终端输入；固定层序，不按最近焦点；焦点循环 DFS；`Ctrl+Tab` 不可重绑。 |
| 设置中心 | 页面注册表；三保存模式；应用页单页分节；更新开关 `auto_check`/`auto_download`；语言失败保留本次运行中的语言；诊断包/自检；固定键参考（`Ctrl+Tab` 不可重绑）；导入导出/恢复默认作用域；Hooks 与 Agent 页联动；Agent 配置按 CLI/Agent 分域。 |

| 编辑器 | 复用文档内核；Tree-sitter；共享 `LanguageRegistry`；打开路由与去重；保存链写入前版本校验、原子替换、替换后外部变化更新基线；崩溃快照；gutter 三类标记；脱离缓冲自动保存暂停；HTML 源码与系统打开。 |
| Markdown | 两态 + 内存草稿；CommonMark/GFM；安全 HTML 子集；公式；Mermaid 源码显示 + 保留接口；链接/资源含 AgentRoot；大文档强制源码；块级按需索引，不保留全文 `plain_text`；草稿快照。 |
| Diff/GitShow | HEAD↔工作区、并排/行内、工作区侧可编辑、冲突快照；默认 Diff 去重键不含 `mode/source`；>10MiB 未保存缓冲只读快照；HEAD 10 秒面板定时器，监听不轮询；二进制临时文件。 |
| 通知 | 统一通知服务；默认 3/4/5 秒；视图覆盖 2/5/8 秒；系统通知仅窗口失焦；事件键去重 10 秒。 |
| 平台 | 单实例 Runtime v2 端点；移交线缆类型与 schema 归协议 crate，平台只做校验与结果映射；载荷以根路径定位、目标不存在只提示；窗口几何矩形+最大化+显示器+DPI，落本地根；托盘关闭即退出；回收站/默认程序/进程树；日志分根。 |

| 迁移 | 旧模块保留/改造/删除/新建表；新旧不并行；旧数据不迁移；旧状态模型/写路径先退役，旧 UI 宿主按域替换即删除；Runtime v2 协议先行、方法增量；范围外能力按应用页/终端/备份/更新分阶段迁移。 |
| Runtime v2 | `slterm_runtime_protocol` 在领域骨架期建立；壳实现最小端点与 `runtime.handover`；每个写方法补参数/结果 schema；`params_hash` 规范化；`mutation_id` 缓存按客户端隔离；垂直切片后交付 project/panel/terminal 方法与快照；git/agent/orchestrate 随域增量；收敛门后完整 conformance、CLI 与随包 skill。 |

## 六、目标态优化裁决

| 主题 | 裁决 | 原因 | 边界 |
|---|---|---|---|
| 状态存储 | 结构化状态使用单一 SQLite 库（WAL、单写线程、事务）；设置 JSON 保留；崩溃快照保留文件 | 消除跨文件提交顺序、孤儿目录、逐文件 generation 与恢复对账 | DB 放本地根；`PRAGMA user_version` 精确匹配；`integrity_check` 失败隔离整库 |
| 数据根划分 | 设置漫游；工作区状态、窗口几何、崩溃快照、隔离区、补全、更新、日志/审计/崩溃现场本地 | 项目根与窗口是机器相关事实；漫游 profile 不应携带锁、token 与大快照 | `SLTERM_CONFIG_DIR` 覆盖漫游根，`SLTERM_LOCAL_DIR` 覆盖本地根 |
| Runtime 节奏 | 协议先行、方法增量；壳只实现最小端点与 `runtime.handover`；垂直切片后交付 project/panel/terminal；git/agent/orchestrate 随域；收敛门后完整 conformance | 消除壳退出条件与控制面空窗；让领域模型尽早被 AI CLI 消费方验证 | 协议 v2 版本冻结；只追加方法，不改旧语义 |
| 旧壳退役 | 先退役旧状态模型/写路径，再按域删除旧 UI 宿主；每个域替换完成即删除该域旧壳，最后移除 allowlist | 双壳并存只增加编译面、误引用与门禁维护；一次性删除会留下未替换能力 | 保留已验证引擎；每个退役步骤有独立验收，旧测试映射在删除该域前建立 |
| 会话归属 | 会话扫描、元数据、归属、删除账本、恢复计划归 `slterm_agents::sessions` | 消除 workspace 与 agents 两套 `SessionRecord`/来源抽象 | `slterm_workspace` 只提供项目根索引；sidebar 依赖 agents |
| 另存为授权 | 不持久化；重启后根外路径按根外只读重新判定 | 根外写权限不应因一次布局持久化长期存在 | 当前运行期仍可编辑；再次另存为可重新授权 |
| 主题可读性 | 不做任何对比度判断，不提示 | 无判定标准的提示会变成实现分歧；产品只提供内置暗色主题 | 用户显式选择透明度/壁纸即接受结果；不自动回退 |
| 契约收敛 | 单一所有者 + README 契约索引；删除重复定义/依赖列表/快照数字；统一类型与字段名 | 施工图重复会直接复制进代码 | 凭据 target `slterm/<scope>/<id>`；删除 `ai_providers` 备份类别 |
| 分支策略 | 主线 + `checkpoint/<ascii-slug>` 标签；仅并行工作流用短分支 | 单开发者/AI 顺序重建，逐里程碑分支只增加合并成本 | 并行组仍可隔离；checkpoint 是回滚点 |
