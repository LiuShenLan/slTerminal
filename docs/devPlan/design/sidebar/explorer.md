# 文件浏览器

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 文件浏览器的树模型、多选、文件操作、树内剪贴板、名称过滤、忽略文件、Git 状态、监听与项目级持久化。

### 树模型

```rust
pub trait TreeSource: Send + 'static {
    fn list_dir(&self, path: &Path) -> Result<Vec<DirEntryInfo>, TreeError>;
}

pub struct TreeModel {
    root: PathBuf,
    generation: u64,
    nodes: HashMap<PathBuf, DirNode>,
    expanded: BTreeSet<PathBuf>, // 相对项目根或 Agent 根
    rows: Vec<TreeRow>,
}

pub enum DirState {
    Unloaded,
    Loading { batch: u32 },
    Loaded,
    PartialError { message: String },
    Failed { message: String },
}

pub struct TreeRow {
    pub path: PathBuf,
    pub rel: PathBuf,
    pub name: String,
    pub depth: u16,
    pub is_dir: bool,
    pub is_symlink: bool,
    pub expanded: bool,
    pub ignored: bool,
    pub git: GitBadge,
}
```

- 根固定为活跃项目根；无活跃项目显示 `选择一个项目以浏览文件`，标题栏与控件禁用。
- 行高 24px、每层缩进 16px、文件夹/文件图标 14px；文件夹有展开箭头，文件无箭头；名称单行省略，悬停显示完整名称。
- 根层首次读取显示占位，不先显示“空目录”；目录按需读取、分批追加，加载期间保持选择/展开/滚动可交互；任一批读取失败保留已显示条目并在末尾显示 `部分内容加载失败，点击重试`。
- 单目录读取失败保持展开并显示 `加载失败，点击重试`；空目录显示内联 `空目录`，根层空显示居中空态。
- 排序：文件夹在前、文件在后；同类按名称不区分大小写升序，稳定；`.git` 任意层级隐藏；其他点文件显示。
- 展开状态按项目、相对路径持久化；恢复时校验目录存在，不存在静默丢弃；刷新/重命名/删除后仍存在目录保持展开，磁盘删除的子树消失。
- 名称过滤只作用于已加载条目，不递归读取未展开目录。

### 选中与多选

```rust
pub struct SelectionSet {
    pub current: Option<PathBuf>,
    pub anchor: Option<PathBuf>,
    pub selected: BTreeSet<PathBuf>,
}
```

- 单击行：清空其他选中、选中该行、成为当前行与锚点、焦点进树；文件夹同时切换展开；单击已选中行不取消。
- `Ctrl+单击` 切换选中并更新当前行与锚点；`Shift+单击` 从锚点按可见行顺序选连续区间；无锚点按单击处理。
- `Ctrl+A` 选中全部可见条目；`Ctrl+Space` 切换当前行选中态；`Shift+Up/Down` 扩展/收缩区间；`Up/Down/Home/End` 移动当前行并重置选中集。
- 单击树内空白清空选中、焦点留在树；右键行属于多选集则保持，否则设为唯一选中并更新锚点；右键空白不改变选中。
- 批量操作按顶层项去重：祖先与其后代同时选中时只处理顶层。
- 切换项目按项目恢复当前行与单选锚点；路径不存在则清空；多选不跨项目或重启恢复；切换项目不自动抢焦。
- 刷新/删除/过滤导致当前路径消失：移到下一可见同级，没有则上一，最后清空；消失项从选中集移除。
- 树是单一 Tab 停靠点；行不单独进入 Tab 序列。

### 打开与文件操作

- 打开：双击文件、单选文件 `Enter`、右键 `打开`；多选时双击与 `Enter` 不打开。落点为活跃项目聚焦面板组；无组时创建首个组。文件类型路由、去重与标题由编辑器篇与工作区面板打开接口负责；本视图只发 `PanelOpenRequest`。打开失败显示错误横幅 `打开文件失败: …`。
- 双击目录只切换一次展开；单选目录 `Enter` 只切换展开。
- 新建文件/文件夹：文件夹行菜单或根级空白菜单；目标为触发文件夹或项目根；内联输入框自动聚焦，占位 `文件名`/`文件夹名`。
- 重命名：右键或 `F2`；内联输入预填，文件名选中扩展名前部分，文件夹全选；同名提交视为取消，仅大小写变化允许。
- 名称校验：长度 1–255；拒绝 `\ / : * ? " < > |`、`.`、`..`、尾随空格或点、Windows 保留设备名（含带扩展名形式）；与同目录条目不区分大小写比较，重名阻止提交并显示行内错误。
- 新建成功：文件 0 字节、目录创建；目标文件夹自动展开；新条目选中并滚动可见；成功不弹通知。
- 删除：作用于整个选中集，一次聚合确认；标题 `确认删除` 或 `确认删除 N 项`，默认焦点取消；统一移入系统回收站；回收站不可用时说明并将整个批量改为永久删除，需再次确认；取消则零变更。逐项执行、不回滚成功项；部分失败汇总错误横幅，失败项保持选中；外部已删除视为成功。成功后 2 秒 toast 报告 `已移到回收站` 或 `已永久删除`，批量报告数量。
- 复制相对路径：项目内复制 `/` 分隔相对路径；无法相对化复制规范化绝对路径；多选按可见行顺序每行一个；成功 toast 2 秒，失败错误横幅。
- 在终端中打开：文件 cwd 为所在目录，文件夹 cwd 为自身；每次新建终端，落点聚焦组；失败 `在终端中打开失败: …`。
- 错误反馈至少一种可见：内联错误、错误横幅、标题栏警告或 toast；错误横幅保留到手动关闭、项目切换或成功重试。

### 树内剪贴板

```rust
pub struct FileClipboard {
    pub mode: ClipboardMode, // Copy | Cut
    pub sources: Vec<PathBuf>, // 按顶层项去重
    pub generation: u64,
}
```

- 应用内剪贴板，不读写系统剪贴板；`Ctrl+C/X/V` 在树聚焦且无内联/过滤输入时生效；跨项目、隐藏视图、换槽保留，重启清空。
- 剪贴板与 Agent 全局文件共享；复制源可跨视图；剪切源与粘贴目标必须同属项目根或同属 Agent 根，项目根与 Agent 根之间不允许剪切移动。
- 复制/剪切替换旧剪贴板并清除旧剪切态；`Esc` 无浮层与输入时取消剪切态。
- 粘贴目标：当前行为文件夹取自身，文件取父目录，无当前行取项目根；根级空白菜单粘贴到项目根；多选以当前行为目标。
- 复制递归复制；剪切同卷优先原子改名，跨卷复制后删除源；文件夹递归；成功 toast `已复制 N 项`/`已移动 N 项`；复制后剪贴板保留，剪切全部成功后清除。
- 目标等于源父目录：跳过并提示 `已在当前位置`；文件夹粘贴到自身或后代：跳过该项并报错，其他项继续。
- 冲突按不区分大小写判断，弹出一次 `粘贴冲突`，列出数量与前若干名称，按钮 `替换 / 跳过 / 取消`，默认焦点 `跳过`。替换先将目标移入回收站（不可用时按删除规则说明并二次确认），替换文件夹整移不合并；跳过保留现有；取消中止整个粘贴且不改剪贴板。
- 批量逐项执行；部分失败汇总 `N 项粘贴失败: …`；剪切失败项保留剪切态；替换文件必须原子完成；源或目标在操作期间外部变化按冲突或失败处理。
- 粘贴完成后刷新目标目录与 Git 状态；过滤激活时新条目按过滤规则决定可见性，toast 报告实际处理数量。

### 名称过滤与忽略文件

- 过滤：标题栏输入框按条目显示名称做不区分大小写子串匹配；只用名称、不读内容；范围限已加载条目，不递归读取未展开目录。
- 过滤激活时显示匹配项及祖先目录链；祖先临时展开但不写入持久化展开记录；匹配目录只显示自身及匹配后代；展开匹配目录继续按规则加载过滤。
- 过滤变化裁剪选中集；当前行不可见时移到首个可见匹配行，无匹配清空；空态 `无匹配项` + `清除筛选`，不显示“空目录”。
- 清除过滤恢复过滤前展开与滚动位置；过滤文本在刷新、新建/重命名/删除、同组切页签后保留，切换项目与重启清空。
- 过滤输入聚焦时 `Esc` 清空并还焦树；被忽略隐藏项、`.git` 项、加载占位不参与匹配。
- “显示忽略文件”为按项目持久化开关，默认关闭；开启后忽略项以较暗忽略色与 `I` 标记显示；忽略判定基于条目自身 Git 忽略状态，只因后代含忽略项而聚合为忽略的文件夹仍显示。
- 根层或子目录全部条目因忽略隐藏时，空态 `仅包含已忽略的文件` 并提供 `显示忽略文件` 按钮；无 Git 信息时全部按非忽略显示，开关仍可切换。

### Git 状态

- 数据根 = 项目根所在 Git 仓库实际根；项目根可为仓库子目录；嵌套仓库不单独计算。
- 状态集合：修改 M、新增 A、未跟踪 U、删除 D、重命名 R、冲突 C、忽略 I。文件行图标/名称着色 + 行尾字母 + 完整状态提示；文件夹按后代聚合，优先级冲突 > 修改 > 新增 > 未跟踪 > 重命名 > 删除 > 忽略。
- 类型色块保留类型色，不被 Git 状态色覆盖；状态不改变排序或图标形状；状态不得只靠颜色表达。
- 保存文件后立即清除该文件状态，300ms 合并窗口后重算；外部变化 200ms 合并窗口后重读目录并重算。
- 读取失败标题栏显示 `Git 状态不可用` 警告，树用默认颜色，不弹错误横幅；手动刷新重试。
- Git 状态只用于展示；暂存、提交、回滚、分支等写操作不在本视图。

### 监听与刷新

- 视图可见时监听活跃项目根；隐藏或切到其他视图时暂停监听与合并刷新；重新可见时刷新一次；切换项目后原根事件丢弃。
- 文件系统变化 200ms 合并为一次刷新；刷新重读已展开目录，保留展开、选中、滚动与过滤文本；过期结果按 generation 丢弃。
- 编辑器保存后立即清状态，300ms 后只刷新保存路径最近的已展开祖先目录并原位合并；保存路径不在当前项目根时树与 Git 都不刷新。
- 手动刷新：刷新按钮、树聚焦 `F5`、根级空白菜单 `刷新`；进行中按钮忙碌、重复触发合并；失败错误横幅 `刷新失败: …` 并保留树。
- 监听不可用标题栏警告 `文件监听不可用` 并提示手动刷新；后台刷新不显示全屏加载、不改变滚动位置。

### 持久化与状态矩阵

| 状态 | 同组切页签 | 切换项目 | 视图关闭重开 | 应用重启 |
|---|---|---|---|---|
| 已展开目录 | 保持 | 按项目恢复 | 保持 | 按项目恢复，校验存在性 |
| 当前行 | 保持 | 按项目恢复 | 保持 | 按项目恢复，路径存在才恢复 |
| 多选选中集 | 保持 | 不保留 | 保持 | 不保留 |
| 滚动位置 | 保持 | 按项目恢复 | 保持 | 按项目恢复并夹取 |
| 名称过滤 | 保持 | 清空 | 保持 | 不保留 |
| 显示忽略文件 | 保持 | 按项目恢复 | 保持 | 按项目恢复 |
| 树内剪贴板/剪切态 | 保持 | 保持 | 保持 | 不保留 |
| 内联新建/重命名 | 失焦提交或取消 | 失焦提交或取消 | 不保留 | 不保留 |
| 错误横幅 | 保持至关闭/项目切换/成功重试 | 清空 | 保持 | 不保留 |
| 树内容缓存 | 保持 | 按项目缓存，切回先缓存再后台刷新 | 保持 | 重新加载 |
| Git 状态 | 保持并刷新重算 | 按项目重算 | 保持并显示时重算 | 重新计算 |
| 刷新进行中 | 保持 | 取消原项目 | 继续 | 不保留 |
| 键盘焦点 | 不改变树内选中 | 不自动进树 | 不抢焦 | 不抢焦 |

- 展开、当前行、显示忽略文件按稳定 `ProjectId` 持久化，路径存相对项目根的形式；根重定位时尝试按新根重写相对路径，无法重写的路径丢弃；恢复只应用仍存在项。删除/重命名/粘贴后同步更新记录；项目移除删除记录；重新添加同根是新项目，从空状态开始。持久化失败不阻塞使用，下次启动回退默认并写诊断日志。

### 复用与重建

| 旧实现 | 处置 |
|---|---|
| `side_panel::enumerate::ordered_entries` 的排序后截断、有序头部与字节预算 | 复用排序/截断算法；树模型改为按需分批加载 |
| `enumerate::tree_rows` 的 `.git` 隐藏、目录优先、展开集平铺 | 参考；重建为异步 `TreeModel`，去掉 `..` 合成行与单层平铺上限 |
| `gitignore::git_repository_root` | 直接复用（文件系统探测，不 spawn git） |
| `vcs::read_git`、`git::{status_cached, parse_status, StatusSnapshot, FileStatus}` | 复用解析与只读快照；多项目并发需把进程级单槽缓存改为有界多根缓存或按视图持有快照 |
| `platform::file_operations::{validate_entry_name, create_file, create_directory, rename, send_to_recycle_bin, open_in_system}` | 复用校验与执行；补永久删除回退、批量、复制/移动与冲突计划 |
| 旧文件树渲染的行距/水洗/路径栏/`..` 浏览、内容搜索三选项、单选中、系统路径拖拽 | 废弃；目标行高 24px、无路径栏、仅名称过滤、多选、无树内拖拽 |
| 旧 `FileTreeState` 跟随终端 cwd 的 custom_root | 废弃；根固定为活跃项目根 |
