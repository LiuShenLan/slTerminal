# Agent 全局文件

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> Agent 全局文件视图：内置与自定义节点、目录探测、统一树、过滤消费、监听、标题消歧与设置中心 Agent 页联动。

### 模型与模块

```text
slterm_sidebar/agent_files.rs
  AgentNodeId { Builtin(AgentKind), Custom(CustomAgentId) }
  AgentNodeDef / AgentConfigSnapshot / AgentFilterConfig / AgentRuntimeManifest / AgentProbe
  过滤匹配 / 标题消歧纯函数

sidebar_host/views/agent_files/
  mod.rs          AgentFilesView（SidebarView）
  state.rs        节点与每 Agent 树状态、统一滚动、选中
  probe.rs        后台探测与过期结果丢弃
  render.rs       节点行、文件树、视图头、空态/错误态
  menu.rs         文件/文件夹菜单、节点菜单
  watcher.rs      按 Agent 根的监听与 200ms 合并
  settings_link.rs 设置修订事件订阅与增量应用
  persist.rs      展开集合持久化
```

```rust
pub enum AgentNodeId {
    Builtin(AgentKind),  // 每个声明全局目录的内置 Agent 恰好一个节点
    Custom(CustomAgentId),
}

pub struct AgentNodeDef {
    pub id: AgentNodeId,
    pub display_name: String,
    pub root: PathBuf,
    pub writable: bool,        // 内置来自 GlobalDir.writable；自定义默认可写
    pub brand: Option<String>, // 内置 slug；自定义为 None
    pub order: u32,
}

pub enum AgentProbe {
    Unknown,
    Probing,
    Readable,
    Missing,
    Unreadable { detail: String },
}

// 以下配置由设置域拥有并持久化；本视图只持只读快照，不写回设置。
pub struct AgentFilterConfig {          // 每个 CLI 一份
    pub mode: FilterMode,               // All | Custom
    pub names: Vec<String>,             // 自定义名单，根层精确名称
    pub show_runtime: bool,
}

pub struct AgentRuntimeManifest {       // 每个 AgentNodeId 一份
    pub names: Vec<String>,             // 内置默认 + 用户增删后的有效清单
}

pub struct AgentConfigSnapshot {
    pub filters: BTreeMap<AgentKind, AgentFilterConfig>,
    pub runtime_manifests: BTreeMap<AgentNodeId, AgentRuntimeManifest>,
    pub custom_nodes: Vec<CustomAgentNodeDef>, // 应用级集合
}
```

### 节点来源与顺序

- 内置节点来自 `AgentDescriptor.global_dir`：每个声明了全局配置目录的 Agent 恰好一个节点，避免多目录到单根节点的映射歧义；显示名取 `AgentKind::display_name`，品牌图标按 slug，`writable` 取 `GlobalDir.writable`。
- 自定义节点来自设置中心 Agent 基础配置页，显示名 + 绝对目录 + 默认可写；没有品牌图标，使用通用图标。目录必须是绝对路径；盘符根、`%WINDIR%`、`System32` 拒绝。
- 多个自定义节点指向同一规范化真实路径时，树中独立显示；批量与破坏性操作按真实路径去重，写入只执行一次。
- 顺序固定：内置按注册顺序，自定义按添加顺序；不提供排序、拖拽排序或自定义顺序。
- 视图打开后焦点进入树：优先上次聚焦的树项，否则首个 Agent 节点；关闭或切走时未提交的行内操作按文件浏览器失焦规则处理。
- 节点行：折叠箭头、图标、显示名；节点获得焦点只显示焦点环，不产生文件选中态；右键节点不改变展开状态。
- 内置节点不可编辑/删除；自定义节点只在设置中心管理。删除自定义节点只移除配置，不删磁盘文件；显示名或目录变更后立即按新定义重新探测，旧目录停止监听。
- 内置与自定义均为空时只显示 `无可用 Agent`。

### 探测与展开

- 探测时机：每次展开 Agent、视图不可见后重新可见、应用启动后首次显示、视图头刷新、错误态重试。
- 探测结果不持久化；展开后三态：
  - 可读：先 `加载中…`，读取根层并申请该节点的监听租约，完成后显示文件树。
  - 不存在：`目录不存在` + `重试`，不加载、不申请监听租约。
  - 不可读：`无法读取目录` + 错误摘要 + `重试`，不得伪装为不存在。
- 视图存活期间目录状态变化可被重新展开/重试/刷新/视图重新可见感知；折叠期间根被创建，下次展开可见；根不存在时不监听父目录。
- 收起 Agent 释放该节点的监听租约与未触发的合并刷新计时，保留展开目录集合；重新展开重新探测、重读快照并申请租约。
- 视图头 `全部收起/全部展开` 只作用于 Agent 节点，不递归目录；存在已展开 Agent 时显示 `全部收起`，否则 `全部展开`；无已展开 Agent 时 `刷新` 禁用。
- 节点菜单 `展开全部 / 收起全部` 作用于该 Agent 下当前可见目录；按层后台读取；以最新操作为准，过期结果丢弃。
- 快速收起/展开、隐藏、过滤变更产生在途加载时，以最新探测/加载结果为准，不闪回旧树。

### 统一树与文件操作

- 主体是一棵统一树：Agent 节点为顶层项，其根下文件/目录缩进显示；整视图只有一个纵向滚动区；不提供每 Agent 独立滚动或嵌套滚动。
- 选中、多选、目录展开、右键菜单、新建/重命名/删除、树内复制/剪切/粘贴、冲突处理、快捷键、确认与错误反馈继承 `sidebar/explorer.md`；本视图差异：
  - 树根为对应 Agent 根，无项目根。
  - 多选可跨 Agent；批量删除逐项在所属 Agent 根内执行。
  - 树内粘贴目标必须位于 Agent 根内；复制允许跨根；剪切仅限同一 Agent 根内，跨 Agent 根、项目根与 Agent 根之间拒绝并汇总；跨 Agent 选中不放宽写入边界。
  - 文件/文件夹菜单路径项为 `复制绝对路径`；不提供根级空白菜单，根层新建/粘贴无入口。
  - 面板标题按本节规则，不按活跃项目根重算。
  - 每 Agent 独立记忆展开目录。
  - 无活跃项目时打开文件/在终端中打开提示 `请先创建项目`。
- 根目录是 Git 仓库时显示 Git 状态；不是仓库时不显示、不报错。
- 写操作限制在对应 Agent 根内；`AgentNodeDef.writable` 为假时新建、重命名、删除、粘贴与拖拽写入全部禁用并说明原因；符号链接、联接点、路径穿越按文件浏览器安全边界处理；跨根剪切或粘贴目标越界逐项拒绝并显示错误横幅。

### 打开、终端与标题

- 打开/终端落点为活跃项目聚焦面板组；无组时创建首个组；不切换、不创建项目。
- 双击文件、单选 `Enter`、右键 `打开`：按编辑器文件打开路由；同一绝对路径已在活跃项目布局中以相同打开形态存在时聚焦已有面板，不重复打开；不同项目各自独立。
- 无活跃项目时警告 `请先创建项目`，不创建面板。
- 在终端中打开：文件 cwd 为所在目录，文件夹 cwd 为自身；每次新建终端，不去重。
- 复制绝对路径：目录无尾分隔符；多选按可见行顺序每行一个；成功单项 `已复制绝对路径`、多选 `已复制 N 个绝对路径`，2 秒；失败错误横幅 `复制路径失败: …`。
- 节点菜单 `复制全局目录路径` 成功无提示、失败错误横幅；`在文件管理器中显示` 成功无提示、失败 `在文件管理器中显示失败: …`。
- 标题规则（工作区标题解析的登记例外）：
  1. 基础标题 = 文件名。
  2. 同一面板组内文件名冲突时，按 Agent 根内相对路径逐级追加上级目录名，取最短可区分前缀。
  3. 仍冲突且来自不同 Agent 时追加 Agent 显示名。
  4. 仍无法区分时追加完整绝对路径。
  5. 悬停提示始终显示完整绝对路径；标题随面板组页签集合变化重算。
- 面板参数只保存 `PersistedPath`（绝对路径）；标题重算时按当前 AgentRoot 登记表反查所属 Agent 与根内相对路径，不新增 `agent_root`/`agent_display_name` 持久化字段。节点被删除或根不可用时回退规范化绝对路径；这是标题输入派生，不是标题持久化。

### 过滤消费

- 配置唯一来源是设置中心 Agent 基础配置页；视图只消费 `AgentConfigSnapshot`，不内嵌编辑表单、不保存配置。
- 键控：
  - `AgentFilterConfig` 按 `AgentKind` 键控，每个 CLI 一份；内置节点使用其 `AgentKind` 对应的模式、名单与 `show_runtime`，各 CLI 互不影响。
  - `AgentRuntimeManifest` 按 `AgentNodeId` 键控，每个内置 Agent 与每个自定义节点各一份；内置节点有效清单为内置默认加用户增删，自定义节点默认空清单。
  - 自定义节点为应用级集合，不归属 CLI；不应用 `AgentFilterConfig`，其根层始终按自身 `AgentRuntimeManifest` 隐藏清单内条目。
- 内置节点的模式：
  - `全部`：显示根层全部条目；`show_runtime` 关闭时隐藏该节点运行时清单中的根层条目；开启时显示；用户增删与内置清单同等生效。
  - `自定义`：只显示该 CLI 名单中的根层条目；`show_runtime` 置灰且不生效，但保留值；名单条目即使属于运行时文件也显示。
- 匹配：根层条目完整名称、不区分大小写、精确匹配；名单项不得含路径分隔符、不支持通配符与多级匹配。
- 过滤只作用于根层：显示后的目录内部不再按名单过滤；被过滤根层条目不读取内容、不展开、不监听；其内部变化不触发刷新。
- 内置节点在 `自定义` 模式且名单为空：根层无可见条目，显示 `当前过滤条件下无可见条目`，不显示“空目录”。
- 当前过滤隐藏至少一个根层条目时，节点行尾显示过滤指示；悬停 `过滤：<全部|自定义|运行时清单>；已隐藏 N 项；在设置中心调整`，内置节点取 CLI 模式，自定义节点取运行时清单；不可点击；隐藏数为 0、根未加载或不可读时不显示。
- 设置变更后只刷新受影响节点：仍存在的展开目录保持展开；被过滤路径从展开记忆与选中中移除；不弹提示。

### 监听与刷新

监听模型为按节点租约：

- 租约条件：视图可见、Agent 已展开、根存在且可读；任一条件不满足即释放该 `AgentNodeId` 的租约，并取消未触发的合并刷新计时。
- 同一规范化根被多个自定义节点引用时共享一个底层 watcher 注册，按引用计数释放；租约键为 `(AgentNodeId, 规范化根)`。
- 租约事件按 200ms 合并为一次 UI 刷新；刷新重读根层与已展开目录，刷新 Git 状态，保留展开集合与仍有效选中；选中消失时移到最近仍存在的祖先，祖先不存在清除；滚动尽量保持。
- 视图不可见或收起 Agent：释放租约、丢弃未触发的合并刷新与后续 UI 更新；重新可见/展开时重新探测、重读根层与已展开目录快照并对账，重新申请租约。
- 视图关闭、退出应用：释放全部租约与未触发刷新，不阻塞退出。
- 被过滤根层目录内部变化不读取、不刷新，也不申请其租约。
- 根被删除或不可读：转对应状态并释放该节点租约；视图显示对应错误态。
- 监听失败/失效：非阻塞提示 `自动刷新不可用`，树继续可用；收起再展开、视图重新可见、视图头刷新或错误态重试恢复租约。
- 视图头刷新：重新探测所有已展开 Agent，重读根层与已展开目录，确保各节点租约已申请；保留展开集合与有效选中；没有已展开 Agent 时按钮禁用；不展开折叠节点。
- 单个 Agent 刷新失败只影响该 Agent，其他 Agent 保持可用。

### 设置中心联动

- 视图订阅设置修订事件，按变更键增量应用：按 CLI 的展示配置、按 Agent 的运行时清单、应用级自定义节点集合。
- 自定义节点新增：按添加顺序插入节点，折叠；删除：移除节点、文件树、释放租约、丢弃展开状态与节点运行时清单，不显示错误；编辑：按新显示名/目录重探测，保留仍有效展开路径与节点运行时清单，旧根释放租约。
- CLI 展示模式/名单/`show_runtime` 变更：只刷新该 CLI 的内置节点；运行时清单变更：只刷新对应 `AgentNodeId`；自定义节点集合变更：按新增/编辑/删除规则处理；隐藏集合变化不写回设置。
- 视图不提供节点或清单管理入口；节点菜单不提供添加、删除、重命名、修改目录。
- 设置页保存失败/只读时以设置页提示为准；视图只消费当前内存配置，不自行回滚。

### 状态矩阵与持久化

| 状态 | 同组切页签 | 切换项目 | 视图关闭重开 | 应用重启 |
|---|---|---|---|---|
| Agent 节点展开集合 | 保持 | 保持 | 保持 | 持久化 |
| 每 Agent 目录展开集合 | 保持 | 保持 | 保持 | 持久化；失效路径丢弃 |
| 当前行 | 保持 | 保持 | 保持 | 不保留 |
| 多选选中集 | 保持 | 保持 | 保持 | 不保留 |
| 滚动位置 | 保持 | 保持 | 保持 | 不保留 |
| 树内剪贴板/剪切态 | 保持 | 保持 | 保持 | 不保留 |
| 错误横幅 | 保持至关闭/新错误 | 保持（应用级视图，不随项目清空） | 保持 | 不保留 |
| 过滤配置/运行时清单 | 保持 | 保持 | 保持 | 由设置持久化 |
| 自定义节点定义 | 保持 | 保持 | 保持 | 由设置持久化 |
| 目录探测结果 | 保持 | 保持 | 重新探测 | 重新探测，不持久化 |

- 首次安装首次打开全部折叠；此后恢复 Agent 展开集合与每棵树展开集合。
- 恢复时不存在、不可读或被过滤隐藏的路径静默丢弃；根不存在的 Agent 仍恢复展开并显示 `目录不存在`。
- 持久化按 `AgentNodeId` 稳定身份；内置节点使用 `AgentKind` 枚举身份，自定义节点使用设置模型分配的稳定 ID，不用显示名或路径作身份。
- 当前行、多选、剪贴板、剪切态、滚动不落盘；视图槽位与宽度归侧栏框架。

### 错误与安全

- 独立文案：`无可用 Agent`、`加载中…`、`目录不存在`、`无法读取目录`、`文件树加载失败`、`空目录`、`当前过滤条件下无可见条目`、`自动刷新不可用`、`复制路径失败: …`、`在文件管理器中显示失败: …`。
- 错误横幅单行省略，保留至手动关闭或成功重试；新错误替换旧文案；立即提示。
- 只读取目录项名称与元数据，不读取文件内容；错误与日志只含操作、路径与结果，不含内容或凭据。
- 写入逐项限制在目标项所属 Agent 根内；`writable` 为假的根拒绝全部写操作；复制允许跨根，剪切仅限同一 Agent 根；粘贴逐项校验源与目标；符号链接与联接点按真实目标校验，防止根外写入。
