# 侧栏框架

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 活动栏、双槽、视图注册与显隐、按钮组织、快捷键状态机、宽度比例、视图状态声明与外观页共享状态。

### 注册表与模块

```text
slterm_sidebar/registry.rs
  SideViewId { Navigation, Explorer, Commit, AgentFiles }  // 视图 id：nav/explorer/commit/agent-files
  ViewDef {
    id, title_key, icon_token, default_slot, default_order,
    shortcut_command, state_spec
  }
  VIEWS: [ViewDef; 4]  // 唯一注册点
```

- 视图集合封闭；运行期不可增删改名；升级只能新增内置视图并按注册默认稳定合并。
- 每个视图单例；同一视图不能同时在上下两槽。
- 显示名、图标、默认槽位、默认顺序、默认快捷键均由注册表给出；图标只用主题语义 token。
- 每个视图声明需要跨重启保留的界面状态与作用域；搜索词、多选等瞬态状态不声明。

app 侧：

```text
sidebar_host/
  activity_bar.rs   34×34 按钮、提示、激活态、焦点环
  slot_host.rs      上/下槽、水平分隔线、内容挂载与焦点
  layout_editor.rs  活动栏拖拽/菜单与外观页共用的命令入口
  button_drag.rs    拖拽排序/换区状态机
```

### 布局状态与不变量

```rust
pub struct SidebarLayout {
    pub visibility_intent: bool, // 持久化为 state/sidebar.json 的 visible；表示显式意图，不是实际可见
    pub width: f32,
    pub split_permille: u16,
    pub slots: [Option<SideViewId>; 2], // 上、下
    pub buttons: BTreeMap<SideViewId, ButtonPlacement>,
}

pub struct ButtonPlacement {
    pub slot: Slot,
    pub order: u16,
    pub visible: bool,
}
```

- 实际可见 = 可见性意图为显示且至少一个槽非空。
- 每个可见视图恰好一个按钮；隐藏视图无按钮；隐藏不关闭视图、不改变槽内容、不改变可见性意图。
- 视图按钮的槽位归属等于视图打开时的槽位；按钮归属与打开状态独立。
- 每槽最多一个打开视图；每槽最多一个激活按钮；同一瞬间最多两个视图按钮激活。
- 视图实例懒创建后常驻；切换槽、隐藏侧栏、隐藏按钮、切换项目都不销毁。
- 首次启动默认：四按钮全部可见、上按钮组按注册顺序、下按钮组为空；导航树在上槽；侧栏可见、宽 250px、比例 50%。

### 视图按钮与配置钮

- 活动栏固定 46px，自上而下：上按钮组、弹性空白、下按钮组、配置钮贴底。
- 按钮 34×34px、图标 15px、水平居中、同组间距 4px；提示为显示名。
- 激活态 = 激活底色 + 强调色图标 + 左侧 2px 竖条；键盘焦点 2px 焦点环；按下态独立。
- 激活态与视图是否打开在该按钮所属槽一致，与侧栏是否实际可见无关。
- 配置钮固定 34×34px，提示 `设置中心`，不参与排序/拖拽/换区/持久化；激活态只看活跃项目内设置中心面板是否为所在组当前面板。
- 按钮不显示禁用态、计数、加载或快捷键提示；隐藏视图不保留占位。

点击按钮语义：

- 侧栏实际可见：视图未打开 → 在按钮所属槽打开，目标槽已有其他视图则关闭原视图但保留实例；视图已打开 → 关闭该视图。
- 侧栏实际隐藏：点击已打开视图按钮 → 设意图为显示并恢复，不关闭；点击未打开按钮 → 显示并在其槽打开；两槽皆空时点击任一按钮直接打开。
- 打开或关闭视图不切换活跃项目、不改变主区。
- 双击等同连续两次激活，不合并、不延迟。

显隐与槽位：

- 关闭最后一个视图使侧栏实际隐藏，但不改变可见性意图。
- 切换侧栏：实际可见 → 隐藏并保留槽内容；实际隐藏且有槽内容 → 显示并恢复；两槽皆空 → 在导航树按钮所属槽打开导航树；导航树按钮隐藏时打开第一个可见视图；无可见按钮时保持隐藏且不报错。
- 打开或聚焦视图把意图设为显示；关闭视图不改变意图。
- 打开视图替换同槽旧视图时，旧视图关闭、实例保留；不弹确认。

换区与排序：

- 同槽拖动只改顺序；跨槽未打开只改按钮归属；跨槽已打开到空槽 → 视图随迁；跨槽已打开到占用槽 → 两视图交换槽位，均保持打开，双方实例不销毁。
- 目标槽打开视图的按钮被隐藏时交换仍生效：隐藏视图保持无按钮，记住槽位更新为源槽。
- 按钮拖拽阈值 4px；悬停按钮上半部插入到该按钮之前，下半部插入之后；按钮组内空隙归该组，弹性空白以上下中点为界，空组落点从相邻组边缘延伸到活动栏顶端或配置钮上缘；配置钮不接收落点；拖出活动栏或按 `Esc` 取消。侧栏显式隐藏时仍可拖拽，但不自动显示侧栏。
- 允许隐藏全部视图按钮：活动栏只显示配置钮；侧栏仍按槽位内容决定显隐；不显示错误或占位。
- 菜单 `上移 / 下移 / 置顶 / 置底 / 换区 / 隐藏 / 重置顺序`；`换区` 插入目标组末尾，拖拽按指针位置。
- `重置顺序` 只按注册相对顺序重排各按钮组内可见按钮，不改槽位归属；隐藏视图的记住顺序同步归位。
- `恢复默认侧栏布局` 需二次确认：全部按钮可见、槽位与顺序回注册默认；可见性意图、宽度、比例不变；已打开视图保持并随按钮迁移；同槽冲突按注册顺序保留靠前者，其余关闭但保留实例。
- 外观页“侧栏默认布局”与活动栏拖拽/菜单共用同一 `SidebarLayout` 与同一命令入口，不建立第二套状态；页面修改立即作用于运行期，按 `persistence.md` 的侧栏域去抖保存。

### 快捷键状态机

“当前可见且聚焦” = 视图是其槽的打开视图、侧栏实际可见、键盘焦点位于该视图内容内（含内容区头部控件）。

按视图快捷键依次判断：

1. 按钮隐藏 → 先在记住位置恢复按钮；记住位置非法回退注册默认；恢复按钮本身不打开视图。
2. 视图未打开 → 在按钮所属槽打开；目标槽已有视图则关闭原视图并保留实例；意图设为显示；焦点进入视图内容。
3. 已打开但侧栏实际隐藏 → 设意图为显示，显示侧栏并聚焦视图内容。
4. 已打开且侧栏可见但焦点不在视图内 → 聚焦视图内容。
5. 已打开、侧栏可见且焦点在视图内 → 关闭视图；意图不变；两槽皆空则侧栏实际隐藏；焦点回到该视图可见按钮，没有则下一个可见按钮，仍没有则配置钮。

打开/聚焦落点 = 视图内容第一个可聚焦元素，没有则内容容器。快捷键恢复隐藏视图后若已打开，按上述聚焦或关闭规则处理。视图快捷键的层序见 `ux-framework.md`（面板固定键与面板命令之后、终端输入之前）；可重绑；冲突在设置中心快捷键页显示。

`切换侧栏` 默认 `Ctrl+Shift+B`，`聚焦活动栏` 默认 `Ctrl+Shift+L`；均走侧栏框架。切换侧栏与视图快捷键都不切换活跃项目、不改变主区面板。

### 宽度与比例

宽度：

- 最小 160px，默认 250px，保存范围 160–720px。
- 动态上限 = min(720, 窗口内容宽度 − 46 − 200)；实际显示宽度受动态上限约束。
- 竖向分隔线 4px 命中区 + 1px 可见线；拖动实时改宽，越界停边界；双击回 250px。
- 键盘聚焦：`←/→` 16px，`Shift+←/→` 64px，`Enter` 回 250px。
- 侧栏隐藏时保留宽度，重新显示沿用；窗口变窄优先压缩侧栏至动态上限且不低于 160px，主区不小于 200px；窗口变宽不自动扩大；临时压缩不回写保存宽度。
- 保存值非法回 250px；呈现时再受动态上限约束。

上下比例：

- 仅双槽同时打开时显示水平分隔线；比例 = 上槽高度 ÷ 两槽可用高度，默认 50%，保存范围 10%–90%，90% 合法。
- 水平分隔线 4px 命中区 + 1px 可见线；拖动实时改比例；双击回 50%。
- 键盘：`↑/↓` 2 个百分点，`Shift+↑/↓` 10 个百分点，`Enter` 回 50%。
- 每槽最小高度 120px；比例导致低于最小高度时按最小高度收紧，不改写保存比例；窗口恢复后重新应用。
- 两槽仍无法各保 120px 时侧栏区整体纵向滚动，不自动关闭视图。
- 关闭一侧后另一侧占满，水平分隔线消失；再次打开恢复上次比例。
- 调整比例不改宽度；调整宽度不改比例。

启动恢复在侧栏首次呈现前完成，不出现默认布局闪烁；恢复不阻塞主区首帧。

### 视图状态声明与持久化

```rust
pub trait ViewState: Serialize + DeserializeOwned + Default {
    const SCOPE: StateScope; // App 或 PerProject
    fn sanitize(&mut self);
}

pub struct ViewStateSpec {
    pub key: &'static str,
    pub scope: StateScope,
    pub schema_version: u16,
}
```

- 框架只保存视图声明的状态并原样交还；视图自行解释字段、项目维度与恢复规则。状态随侧栏布局保存，不写入设置中心配置。
- 状态损坏或无法恢复：仅该视图回退自身默认，其他视图与侧栏布局不受影响。
- 状态不得包含凭据、令牌、终端内容、文件内容或其他敏感值。
- 视图内部数据加载、错误、权限、空态由视图自己呈现；框架不提供统一骨架屏或空态。
- 重启后从未打开过的视图不创建实例。

持久化落点与字段级 schema 以 `design/persistence.md` 为准：侧栏布局写 `state/sidebar.json`，各视图声明状态写 `state/views/<view-id>.json`；视图 id 统一为 `nav`、`explorer`、`commit`、`agent-files`。本文件不内嵌 schema。

- 去抖按 `persistence.md` 的侧栏域；连续变更合并为最后一次完整状态；保存不得阻塞侧栏与主区；正常退出前冲刷。
- 恢复清洗顺序：整体损坏 → 默认布局并通知一次 `配置已损坏，已恢复默认侧栏布局`；部分字段非法 → 仅该字段默认；未知视图 → 对应槽置空、记录丢弃；缺失视图 → 按注册默认槽位/顺序稳定合并插入；重复视图 → 保留一个；打开状态与按钮槽位冲突 → 以按钮槽位为准；同槽多打开 → 按该槽按钮顺序保留最靠前，其余关闭；隐藏与打开独立还原；隐藏视图记住位置非法 → 回注册默认。
- 宽度加载夹取 160–720，非法回 250；比例夹取 10–90，非法回 50；呈现再受动态上限约束。
- 保存失败：通知 `侧栏布局保存失败，更改可能无法在重启后恢复`，保留内存状态，下次变更或退出前重试；退出冲刷失败同样警告。

### 键盘与焦点

- 活动栏按钮均可键盘到达；`↑/↓` 按视觉顺序移动，`Home/End` 首尾，`Enter/Space` 激活；`Shift+F10`/菜单键在视图按钮上打开菜单，配置钮不提供。
- `Tab` 顺序：上按钮组 → 下按钮组 → 配置钮 → 宽度分隔线 → 上槽内容 → 水平分隔线 → 下槽内容 → 主区；空组、隐藏按钮、空槽、不可见分隔线跳过。
- 分隔线可聚焦并用方向键调整；焦点环可见。
- 视图关闭或侧栏隐藏后焦点回活动栏按钮或配置钮，不留在不可见内容内。
- 拖拽结束后焦点回被拖动按钮；取消拖拽恢复不透明与无高亮。
