# Markdown 投影与安全资源

> 以 Comrak AST 为唯一 Markdown 语义来源，规定安全投影、资源授权、公式和渐进渲染；Mermaid 当前保持普通代码块。

## 决策与红线

### 解析与块投影

- Comrak 是唯一 Markdown 语义解析器。启用所需 GFM 表格、删除线、任务列表、自动链接、脚注、提示块、front matter 和 `$` 公式扩展；不启用 relaxed autolink、额外 Wiki／短代码语法或第二套 HTML 渲染。
- 解析结果一次投影为不可变 `MarkdownDocument { blocks, headings, anchors, links, visible_text }`。大纲、查找、链接、代码块、脚注和阅读锚点全部从该投影派生，不能各自再解析源码。
- 块模型包含段落、标题、列表、引用、分隔线、代码块、表格、提示块、脚注、数学块、front matter 和安全 HTML 片段。块键只用于当前 revision；持久阅读位置保存标题／块锚点与块内偏移。
- front matter 先以有界 YAML 事件解析校验；大小、深度或语法失败时关闭 front matter 解释并重新按正文解析。校验不展开别名，不执行标签，不把 YAML 内容交给任意反序列化器。
- 标题锚点由可见标题文本生成：Unicode 规范化与小写化、空白转连字符、移除不安全标点、空值使用固定占位，重名按出现顺序追加序号。文档内链接、大纲和脚注共用该锚点表。
- 代码块只保存规范化语言别名和源码。`mermaid` 当前产生普通 `CodeBlock { language: Mermaid }`，无专用 renderer trait、注册表、缓存、外部资源或占位界面；其最终静态图能力由用户后续单独实现。featureSpec 中的 Mermaid 终态不在本轮实现范围。

### 安全 HTML 与 SVG

- 不生成或嵌入 HTML。原始 HTML 经真实 `html5ever` TreeSink 做有界解析和白名单投影，禁止正则清洗或把源 HTML 交给 GPUI／WebView。
- 只允许 `br`、`hr`、`sub`、`sup`、`kbd`、`a`、`img`、`picture`、`source`、`details`、`summary`；属性只允许经校验的 `href`、`src`、`srcset`、`alt`、`title`、`width`、`height`、`open`。脚本、样式、事件、表单、框架、object、embed 和未知节点不执行，按转义文本或安全占位呈现。
- HTML TreeSink 限制节点数、嵌套深度、属性数和输入长度；超限只降级当前片段，不影响其他块。安全投影不包含 `style`、`class`、事件属性或自动导航。
- SVG 先用禁用 DTD、外部实体和外部引用的 XML 链清洗，再交给 `usvg`／`resvg` 静态光栅化。源 XML 不直接交给视图；`foreignObject`、脚本、事件、远程字体、外部图片和可执行内容一律拒绝或移除，清洗失败显示占位。
- 危险 HTML 的原始标签不进入渲染查找文本；安全节点的实际可见文字可进入 `visible_text`，URL、图片 alt 和原始 HTML 不进入。

### 图片与链接授权

- 本地图片逐资源经 PathAuthority 取得持久读授权；根外 Markdown 或链接不扩大资源边界。资源键包含位置、文件身份和版本，写前与重新可见时复核。
- 单资源上限 20 MB，解码缓存上限 128 MiB，按最近使用淘汰；视口附近懒加载，图片失败保留 alt、位置和简短原因，不阻断文档。
- 支持 PNG、JPEG、GIF、WebP、AVIF、BMP、ICO 和静态 SVG。解码设置总分配、尺寸、帧数和单资源预算；动画只保留当前帧与有界时钟，减少动效时显示静态帧。
- 远程 HTTP／HTTPS 图片默认不加载。用户点击某张图后，授权键至少包含 DocumentId、精确 URL 和授权代次，只发起一次请求；不自动跟随重定向，不带 Cookie、凭据或 Referer，单图 20 MB、超时 10 秒。
- `srcset` 的每个候选 URL 独立判定，不因一个候选获批而请求其他候选。缓存跨视图、Document 代次或重开使用前必须重新验证授权；授权不持久化。
- `data:image/...` 按同一大小、格式和安全规则处理，非图片 data 内容忽略。远程字体、样式、脚本和 Mermaid 外部资源永不加载。
- 链接分派只支持当前文档锚点、系统浏览器／处理程序、经 PathPolicy 的本地文件；`javascript:`、`data:`、`blob:`、`file:` 和其他协议无动作或显示策略拒绝。根外文件只有在用户显式点击本地链接后才获得该文件的会话级只读授权，不派生写入、资源、文件树或终端能力；重启后只显示重新授权占位。悬停与聚焦只做元数据检查，不读正文、不发起网络。

### 公式与渲染调度

- `$...$` 行内与 `$$...$$` 块级公式由 Comrak 数学扩展产生，避免把普通货币文本误判为公式。公式只使用内嵌 Latin Modern Math、OpenType MATH 布局和本地编译，不产生链接或外部请求。
- 公式结果以源码散列、行内／块级、字体参数、主题 revision 和缩放为键，后台生成不可变位图；编译、布局和位图预算沿用现有安全上限，失败显示公式源码和错误。
- 保留公式编译与位图生成，删除 terminal_math、终端扫描和覆盖层。渲染结果只接受当前 Document revision，主题变化使派生位图失效而不改文本。
- 渲染任务按视口附近块分片，携带 Document revision 与取消令牌；源码态不计算不可见渲染，切回渲染态再调度。整篇失败可重试并查看源码，单块失败降级为该块源码。
- 超过 5 MB 或 100,000 行默认强制源码态，允许用户当次“仍要渲染”并渐进取消；该授权不持久化。超过 50 MB 按大文件规则只读，禁止渲染且不提供该入口。
- 渲染缩放范围 25%–400%，按 1.1 倍步进；阅读位置以最近标题／块锚点和块内偏移恢复，锚点消失按比例回退并夹取有效边界。

### 视图状态与选择

- Markdown 首次打开默认渲染态，源码与渲染互斥；两态共享 Document，源码修改不读盘即可成为渲染源。渲染态只读，任务列表等控件不反向修改源码。
- 形态、大纲开关、缩放和阅读位置按 ViewKey 持久化；大文档降级优先于持久形态。查找栏、搜索词、临时缩放提示、菜单和焦点清除。
- 查找只按渲染后可见文本字面匹配，不搜索源码、URL、图片 alt 或原始 HTML；大纲、脚注和锚点共享同一投影。
- 代码块、宽表格和长公式在块内滚动，不撑破面板；普通文本选择复制仍可用，不增加代码块复制按钮或自定义渲染菜单。

## 验收与测试

- Comrak 投影测试覆盖 GFM、脚注、提示块、front matter、公式、锚点重名、缺失脚注和单块失败；大纲、查找和链接结果必须来自同一投影。
- 安全语料覆盖脚本、事件、危险协议、嵌套 HTML、SVG DTD／实体／外部引用、data 图片和超限输入；断言无网络、无脚本、无未授权文件读取。
- 远程图片测试验证点击前零请求、精确 URL 单次授权、无重定向／Cookie／Referer、超时和缓存重新授权；本地资源测试验证根外文档不扩大权限。
- 公式测试验证缓存键、主题与缩放失效、预算和错误降级；所有公式 fixtures 不发起外部请求。
- 大文档测试验证 5 MB／100,000 行降级、50 MB 禁止渲染、渐进取消、revision 丢弃和阅读位置恢复。
- 当前实现验收明确：`mermaid` 围栏只呈现普通代码块，不出现渲染器、网络请求或图内交互；最终能力不在本轮冒充完成。

## 操作

- 修改 Comrak 扩展或白名单必须同步投影、查找、链接、资源授权和安全语料，不允许只改渲染分支。
- 新增资源类型先定义授权键、解码预算、缓存代次和失败占位，再接入视图。
- 用户后续实现 Mermaid 时另行评审其静态安全边界；本轮不预留会诱导第二套渲染架构的接口。
