# 设置、主题、凭据与备份恢复

> 规定设置单例、纯颜色主题、Windows 凭据门面、加密备份和维护期逻辑恢复的统一实现。

## 决策与红线

### SettingsRegistry 与保存队列

- `SettingsRegistry` 是应用设置唯一字段目录：每项声明键、类型、默认值、作用域、校验器、敏感性、导出资格、重置资格和保存模式。设置页只生成控件，不自行读写 JSON。
- `SettingsStore` 持有一份运行值和一条写队列；项目 Settings 与无项目浮层订阅同一状态，关闭任一视图不取消全局待写。运行值与磁盘值分开，失败保留生效值并显示“本次运行生效、重启可能丢失”。
- 快捷键、外观、终端、Agent 基础和应用页立即生效、停止操作 2 秒后保存；后台任务、导入、恢复默认和清理显式提交立即写入。Hooks 草稿不走该队列。
- 显式动作先完整校验、预览影响域、保留上一代有效备份，再原子提交；预检失败零写入。恢复默认只重置已注册应用设置，未注册 CLI 命名空间原样保留。
- 普通设置导出只含登记为非敏感的应用字段，不含主题包、工作区、Hooks、任意 CLI 文件、凭据、学习历史、终端输出或快照；未知命名空间本地保留但不导出。
- 设置损坏按缺失、权限／锁／I/O、当前版本结构损坏、高版本、单字段非法分别分流；高版本只读，单字段只回退自身并聚合提示。

### Settings 视图与页内状态

- 项目 Settings 由所属 PanelHost 持有；无项目浮层由 AppRoot 独立持有，不隶属任何 ProjectView。激活或切换项目不销毁浮层及其 Hooks User 草稿；重复入口只聚焦既有视图，不重置选中页或草稿。用户显式关闭后，下次入口才按届时是否有活跃项目选择项目面板或浮层。
- `Settings { ProjectId }` 与 `AppSettingsOverlay` 分别拥有独立 `SettingsViewState { selected_page, declared_page_params }`，只经 ViewStateStore 保存，关闭重开与重启共用。浮层只提供应用级页面与 Hooks User，不读取或改写项目 Settings 的选中页；失效选中页回退到当前宿主第一个可用页面并提示，不创建空白页。
- 搜索、快捷键录制、菜单、通知、临时错误、焦点和普通未提交输入均为瞬态；切页卸载原页并清除普通输入草稿。Hooks 草稿仍按设置视图实例、CLI 与层级独立持有并走关闭守卫；当前 Hooks 层级和 GUI／JSON 模式不持久化，重建后回到 User 与 JSON。

### 主题与 ANSI

- 内置和自定义主题共用完整 `ThemeDefinition { theme_id, name, version, tokens, ansi16 }`。主题只负责颜色，移除排版、密度、卡片几何、背景图片、媒体、ZIP 和效果字段。
- ThemeTokens 是强类型完整语义槽位，组件只能引用 token，禁止硬编码颜色；缺槽、未知字段、非法色值、危险外部引用一律拒绝，不生成部分主题。
- 自定义主题为单文件版本化 JSON，ThemeId 使用 UUIDv7。为保持 `slterm_settings` 零生产依赖，JSON 值层及 ThemeId／AgentRootId 的 UUID 解析和格式化在本 crate 内实现，UUIDv7 的随机源由 application 提供；导入冲突拒绝，正常导入不自动启用；重命名只改显示名，写盘串行、原子、带 revision 前置条件。
- 删除未使用主题需确认；删除当前使用主题前必须另选，不自动替选。主题切换立即重绘全部视图，不重载 Document、不重启 PTY。
- ANSI 0–15 使用主题完整映射；16–231 采用标准色立方公式，色阶为 `[0, 95, 135, 175, 215, 255]`，索引为 `16 + 36*r + 6*g + b`；232–255 采用灰阶 `8 + 10*i`。主题不再保存第二份 256 色表。
- 不做 WCAG 校验、对比度提示、缺色回退或自动主题回退；材质、密度、字体与窗口几何不属于主题。

### 凭据门面

- `CredentialFacade` 是套餐专用 token、Runtime token 和 handover token 的唯一访问入口；真实值只存 Windows 凭据管理器，目标包含用途与本地根稳定散列，测试根相互隔离。
- 凭据写入、替换、删除和读取失败必须可见；值在内存中使用有界秘密类型并尽快清零，不进入 DTO、设置 JSON、快照、备份、日志、审计或诊断。
- 应用不读取 CLI 配置、CLI 环境变量或其他 CLI 凭据替代专用 token。普通导入、恢复默认、备份恢复不静默创建、替换或删除凭据。
- 设置页输入只用于本次凭据写入，保存后清空且不回显；已配置状态不显示 token 片段。凭据域外的请求构造器只接收短期借用，不持久保存。

### BackupPayload 与加密格式

- 备份明文是有界、版本化规范 JSON `BackupPayload`，类别只有 `settings` 与 `workspace`，至少选择一类。设置类别包含应用设置、快捷键、Agent 非敏感配置和自定义暗色主题；工作区类别包含项目、布局、ViewKey、侧栏、终端元数据和按机器窗口几何，不含终端输出。
- 永久排除：任何凭据及其明文表示、任意 CLI 配置与 Hooks、终端输出与回滚、AI 会话正文、剪贴板、崩溃快照、日志与审计、更新下载、命令历史与目录历史、隔离区和恢复点。
- 未注册或无法证明非敏感的字段不入包。工作区备份按逻辑对象导出，不复制 SQLite 物理文件、WAL 或任意文件；跨机几何保留来源机器标识，目标机不直接应用。
- 新格式使用魔数 `SLTMBK01` 与版本 1，盐 16 字节、nonce 12 字节，Argon2id `m=19456 KiB/t=2/p=1`，AES-256-GCM，完整头部作为 AAD；明文上限 64 MiB，旧格式拒绝。
- 口令只用于当前导出或恢复操作，不持久化、不写日志或错误。导出先完整构造并校验，再原子写用户选择目标；预览显示类别与排除项，不展示凭据或承诺秘密扫描。
- 备份包所有条目、类别和版本在恢复前完整鉴权与校验；任一条目篡改、口令错误或结构不支持，整包拒绝且现有数据零写入。

### 恢复点与维护期恢复

- 恢复在当前进程完成鉴权、校验、预览和关闭预检，再为所有受影响逻辑对象创建恢复点。恢复点记录原值／不存在、恢复后指纹、对象键和操作关系，不要求重输备份口令。
- 恢复点正文使用 Windows DPAPI CurrentUser 加密，写入本地根原子文件并限制当前用户 ACL；索引在 workspace.db，正文不入备份或诊断。恢复点跨重启保留，直到显式删除或符合规则的撤回。
- 原始备份路径的会话授权不跨重启延续。确认恢复前将已鉴权包复制为本地根暂存原子文件，记录 SHA-256 与维护请求；维护期只读取该受控副本，不重新读取旧外部路径。
- 关闭预检先处理所有脏 Document、Hooks 草稿和终端决定；用户取消时不创建恢复点或维护请求。预检通过后写入恢复点和请求，再进入统一关闭；最终关闭失败保留 Prepared 材料供重试或显式取消。
- 下一启动维护期验证暂存包、恢复点、store_epoch 和当前指纹，暂停相关写入与 Runtime 写命令后按包内类别替换；未包含类别保持原状。任一写入失败使用恢复点回滚，不报告部分恢复成功。
- 恢复或撤回提交后更换 store_epoch，并使旧 Runtime 幂等命名空间、任务代次和授权代次失效。跨机器项目先进入 RelocationRequired，未重新授权前不读正文、不启动 PTY。
- 撤回前逐项比较当前指纹与恢复后指纹；仍匹配的项回到恢复前状态，后续修改项标冲突并保留当前内容。撤回同样走维护期，失败项保留恢复点和重试材料。
- 恢复日志只记录操作、来源、结果和必要指纹，不记录口令、凭据或文件正文。恢复点不被一键诊断清理删除。

## 验收与测试

- SettingsRegistry 测试覆盖字段校验、未知命名空间保留、单字段回退、自动／显式队列、多个 Settings 视图同步和关闭不取消待写。
- GPUI 设置视图测试覆盖项目激活后浮层与草稿存活、重复入口不重置、两个 ViewKey 独立恢复选中页和页内参数、普通瞬态清除及 Hooks 层级／模式复位。
- 主题测试覆盖完整 token、未知字段、ANSI 公式、UUID 冲突、revision 写入、当前主题删除和零写入失败；断言没有媒体、ZIP、排版或 WCAG 旁路。
- 凭据测试使用 Windows 隔离假目标与 `sk-test`，验证专用 token 不读取 CLI 凭据、不回显、不进入任何持久材料或错误。
- 密码学测试覆盖口令错误、篡改头部／密文、AAD、大小上限、旧格式拒绝和原子导出；测试不得使用真实凭据。
- 恢复测试覆盖类别选择、永久排除、恢复点 DPAPI、暂存包、关闭取消、维护中断、回滚、撤回冲突和 store_epoch 更换。
- 跨机测试验证几何不直接应用、项目 RelocationRequired、未授权不读正文／不启动 PTY，缺凭据只显示重新配置。

## 操作

- 新增设置字段先登记敏感性、导出／重置资格和校验器，再添加界面；不得默认将新字段纳入备份。
- 修改备份格式必须同步版本、AAD、类别清单、恢复点和维护期测试，不保留旧格式兼容入口。
- 恢复或撤回实现不得直接替换运行中的数据库或设置文件；统一写维护请求并由启动维护期执行。
