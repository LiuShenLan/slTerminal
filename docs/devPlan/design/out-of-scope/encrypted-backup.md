# 加密备份迁移

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 职责：只登记加密备份的迁移增量：旧归档与旧类别删除、落点、迁移顺序、增量验证与不可自动化面。归档格式、类别、恢复点与数据路径归 `../persistence.md`；敏感键、加密与凭据边界归 `../security.md`；应用页入口归 `../settings/app-page.md`。本篇不重复定义目标态契约。

### 归档模型与路径

- 删除旧 `TRMBK001` 归档类型与兼容解密分支；新格式由 `../persistence.md` 定义。旧归档不导入、不转换、不降级。
- 删除旧类别（`session`、`themes`、旧 provider 独立文件等）；新类别映射、归档名与条目路径由 `../persistence.md` 定义。用户主题已删除，不再进入任何类别。
- Provider 元数据随应用设置域迁移，只保留 provider ID、显示元数据与 hint；凭据值、AI 会话正文、终端内容、剪贴板、崩溃快照与日志不进入备份。
- 旧 `backup-recovery/` 目录不读、不删、不视为恢复点；新恢复点路径由 `../persistence.md` 定义。
- 敏感键表由 `../security.md` 维护；迁移不新增旁路键表。

### 导出

- 删除旧导出入口、旧类别选择与旧序列化路径；新导出走 `../persistence.md` 定义的归档与 `../settings/app-page.md` 定义的入口。
- 迁移验证：导出不含凭据、Hooks、CLI 配置、AI 会话正文、终端内容、剪贴板与崩溃快照；旧类别不再出现。
- 旧导出文件不提供导入；写失败不留下半写文件由 `../persistence.md` 的原子写契约保证。

### 导入与恢复

- 删除旧导入入口、旧格式解析与旧恢复点读取；`TRMBK001` 及更早归档明确报“旧格式不受支持”。
- 恢复校验、恢复点、回滚与重启生效规则由 `../persistence.md` 定义；迁移只保证旧文件不被覆盖或删除。
- 迁移验证：旧格式零副作用拒绝；恢复失败回滚原字节；恢复点撤回只作用于对应恢复操作。
- 凭据不由恢复写入或删除；导入后凭据状态按 provider ID 实时查询。

### 敏感键与凭据边界

- 敏感键扫描、剥除与导入复验由 `../security.md` 定义；迁移沿用同一表，不复制规则。
- 凭据值永不入包；迁移测试只用假值，真实凭据不进入夹具、日志或错误消息。
- 错误消息只含路径、类别与失败原因，不含文件内容、口令或凭据。

### 应用页入口与所有权

- 应用页“备份与恢复”分节的控件、文案、默认类别与交互归 `../settings/app-page.md`；本篇只登记旧入口删除与新入口接线。
- 迁移前该节保持只读占位或禁用态；迁移完成后开放导出、恢复与撤回入口。
- 导出、恢复与撤回是显式动作，不进入自动保存；此行为由 `../settings/app-page.md` 定义，本篇不复制。

### 依赖里程碑

里程碑依赖只在 `plan.md` 的“里程碑”表定义；本文件不复制依赖列表。

### 迁移顺序

1. 冻结旧类别到新类别的映射；删除旧归档类型与兼容分支。
2. 实现新类别收集与敏感键剥除；删除旧导出入口。
3. 实现导入校验、恢复点、回滚与撤回；删除旧导入入口与旧恢复点读取。
4. 应用页备份入口接线，去掉占位或禁用态。
5. 删除旧格式兼容代码、旧类别与旧测试，保留加密原语测试并改类别夹具。

### 测试与验收

- 迁移：旧格式与旧类别被拒绝或不再出现；旧 `backup-recovery/` 不被读取；旧导出文件不导入。
- 新归档往返覆盖新类别；workspace 类别为状态库一致性快照，恢复后首次启动校验通过。
- 敏感键：导出剥除、导入复验整单拒绝；Provider hint 保留、明文不出现。
- 恢复：失败回滚原字节；恢复前不存在的文件在撤回时删除；恢复点目标集合不匹配拒绝。
- 应用页接线：迁移前占位或禁用，迁移后入口可用；取消不写入。

### 不可自动化面

- 真实文件选择器、口令输入体验与大文件导出/恢复的磁盘性能。
- 跨重启恢复的人工核验与恢复点清理策略。
- 用户对备份内容完整性的主观确认。
