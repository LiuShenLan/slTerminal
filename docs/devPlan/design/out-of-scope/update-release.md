# 更新与发布链迁移

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 职责：只登记更新与发布链的迁移增量：旧状态与旧 UI 删除、落点、迁移顺序、增量验证与不可自动化面。更新检查、下载、校验、安装交接、签名与发布链归 `../build-and-release.md`；更新状态路径与工作区快照的数据归属归 `../persistence.md`；窗口几何归 `../platform-windows.md`；应用页入口归 `../settings/app-page.md`。本篇不重复定义目标态契约。

### 更新状态与检查

- 删除旧 `update_state.json`、旧 `updates/` 与旧提示抑制状态；新状态路径由 `../persistence.md` 定义，状态机与检查规则由 `../build-and-release.md` 定义。
- 旧状态不读、不删、不迁移；首次新版本不继承旧提示抑制。
- 删除旧启动检查任务与旧弹窗接线；启动检查、手动检查与自动下载开关按 `../build-and-release.md` 重接。
- 迁移验证：旧文件存在不影响启动；旧提示状态不生效；检查失败不阻塞界面。

### 下载与校验

- 保留下载引擎与代次作废链；删除旧下载状态路径与旧 `.part` 复用逻辑。新路径与校验规则由 `../build-and-release.md` 定义。
- 迁移不新增第二下载器；下载任务只由更新服务创建。
- 迁移验证：旧 `.part` 不被复用；取消或换版本后旧任务结果失效；失败不留下可执行文件。

### 安装交接

- 删除旧会话快照适配与旧交接 schema；新 `HandoffWorkspaceV2` 由 `../build-and-release.md` 定义，状态库与侧栏数据取自 `../persistence.md`，窗口几何取自 `../platform-windows.md`。
- 保留两阶段文件机与恢复 ticket；迁移顺序为：冲刷设置与状态库 → 生成并原子写工作区快照 → 写安装授权 → helper 执行 → 下次启动恢复。
- 删除旧安装器接管入口与旧恢复适配；便携版与提权隔离会话按 `../build-and-release.md` 拒绝自动安装。
- 迁移验证：旧快照不被读取；未授权事务不安装；恢复失败保留当前安装；版本与 ticket 校验有效。

### 代码签名

- 签名策略、证书分支与无证书残余风险登记归 `../build-and-release.md`；迁移只在 handoff 前接入独立签名验证。
- 迁移验证：有证书与无证书两个分支均按所有者篇通过；签名验证失败拒绝安装，保持当前安装不变。

### 发布链

- 发布链、包清单与体积预算归 `../build-and-release.md`；迁移只登记资产删除与落点：
  - 删除 `assets/runtime-api-v1.schema.json`、v1 版文档与旧 skill 文案。
  - 加入 `assets/runtime-api-v2.schema.json`、`assets/runtime-control-api-v2.md` 与更新后的 `assets/skills/slterm-runtime/`。
  - 保留 app 图标、CLI logo、许可证与第三方 notices。
  - 安装器卸载钩子移除对旧 CLI `setup-ai` 的 no-op 调用，或由新 CLI 提供真实 `setup-ai --remove` 实现。
- 迁移验证：包清单与 staging/zip/安装器一致；v1 资产不存在；卸载钩子不再保留已知 no-op 步骤。

### 应用页入口与所有权

- 应用页“更新”分节的控件、字段与交互归 `../settings/app-page.md`；检查、下载、交接与恢复由 `../build-and-release.md` 拥有。
- 更新服务重接前该节保持只读占位或禁用态；重接后开放手动检查与安装入口。
- 迁移验证：入口只在服务可用后开放；“立即安装并退出”与“下次启动安装”走同一交接链，不产生第二状态机。

### 依赖里程碑

里程碑依赖只在 `plan.md` 的“里程碑”表定义；本文件不复制依赖列表。

### 迁移顺序

1. 保持旧更新引擎编译但停止从新壳调用；新状态路径与提示状态落地，旧状态不读。
2. 应用页接入手动检查、自动检查/下载开关与下载状态；入口在服务可用前禁用。
3. 工作区快照改为 `../build-and-release.md` 定义的 V2 快照；恢复 ticket 与版本化启动恢复接线。
4. 包清单、schema/docs/skill、体积预算与合规落点更新；删除 v1 资产与旧 skill 文案。
5. 跑假 release 服务器全链彩排与钉测试；再做真实安装器人工核验。
6. 删除旧更新弹窗、旧状态路径与旧会话快照适配；新 CLI 卸载钩子提供真实移除或由安装器删除调用。

### 测试与验收

- 迁移：旧 `update_state.json`/`updates/` 不读；旧提示抑制不继承；旧会话快照不恢复；旧更新弹窗与旧路由不存在。
- 交接：旧快照拒绝；未授权事务不安装；恢复失败保留当前安装；版本与 ticket 校验有效。
- 签名：有证书时签名验证；无证书时残余风险已登记；摘要校验不放宽。
- 发布链：v1 资产不存在；v2 资产随包；包清单全等；卸载钩子无已知 no-op。
- 应用页：服务不可用时禁用、可用后开放；检查与安装结果映射可见。
- 不可自动化面按 `.claude/docs/testing/exemptions.md` 登记。

### 不可自动化面

- 真实 `setup.exe` 覆盖安装、卸载残留、提权隔离与安全软件拦截。
- 更新 helper 在真实进程退出后的安装时序、系统重启/关机路径。
- GitHub Release 网络、限流、CDN 重定向与代理环境。
- 安装向导外观、安装目录权限、干净环境首发与人工发布核验。
- 真实用户数据跨版本升级后的首次启动观感。
