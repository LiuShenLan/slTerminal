# 终端增强迁移

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 职责：只登记终端增强的迁移增量：旧接线与旧设置键删除、落点、迁移顺序、增量验证与不可自动化面。终端扩展点、增强顺序与 AI 修复条行为归 `../panels/terminal.md`；开关键、默认值与保存归 `../settings/app-page.md`；补全数据路径归 `../persistence.md`；AI 请求与凭据边界归 `../security.md`。本篇不重复定义目标态契约。

### 终端面板扩展点

- 保留终端 core 与增强引擎；迁移把旧 pane 直连改为 `../panels/terminal.md` 定义的统一增强 host。
- 删除旧 pane 中的增强字段、按键拦截与绘制调用；增强顺序由所有者篇定义，迁移不新增第二顺序。
- 迁移验证：增强只经 host 接入；任何增强不修改网格、滚动位置、选区真值或复制文本。

### Vi 模式

- 保留终端 core 的 Vi 光标、运动与选择重算；迁移接入新 host 的切换命令与按键路径，删除旧 pane 直连绑定。
- 删除旧 Vi 设置键与旧命令注册；新命令名、默认键与重绑规则由 `../panels/terminal.md` 与 `../settings/app-page.md` 定义。
- 迁移验证：交替屏幕下不可进入；Vi 按键不发送 PTY；退出后选区交回普通终端复制语义；状态为面板运行期状态，不持久化。

### 终端补全

- 保留 `slterm_completions` 匹配引擎与 app 侧编排；迁移删除远程/SSH/WSL 来源与旧缓存路径。
- 数据文件迁至 `../persistence.md` 定义的新路径；缓存按面板持有，迁移不保留跨面板共享缓存。
- 删除旧设置键与旧呈现开关；新键与默认值由 `../settings/app-page.md` 定义。
- 迁移验证：按键路径零磁盘/子进程 I/O；取消后不回填；交替屏幕、Vi 与建议条打开时不抢占按键。

### 数学覆盖层

- 保留 `terminal_math` 扫描、投影与覆盖绘制；迁移只改 host 接线与开关读取，删除旧 pane 绘制直连。
- 扫描预算与投影规则由 `../panels/terminal.md` 定义；迁移不得放宽预算。
- 迁移验证：只遮源格、失败保留原文、不改网格与选区；开关关闭后不扫描、不绘制。

### AI 修复条

- AI 修复条 UI、按键与命令完成接线由终端增强回迁交付；Provider 请求器、凭据读取与助手配置由 AI Providers 里程碑交付。两边不重复实现。
- 保留建议条三态渲染与按键语义；迁移删除旧 pane 直连与旧 `PaneId` 归属，改接 `PanelId`。
- 关闭开关或助手关闭时不注册按键、不请求、不显示条；失败原因在条面显示。
- 迁移验证：建议条不改变网格与焦点；接受建议只贴入不执行；与补全不互相抢占。

### 提示符跳转删除

- 删除 `slterm_prompt_jump` 与提示符行标记 deque；删除相关按键、命令、文档与测试。
- 保留 OSC 133 解析出的命令开始/结束、提示符活动态、输入边界、标题/状态/退出码；这些是 Shell 集成与命令修复的基础，不得随跳转一起删除。
- 验收断言不存在跳转 API、按键绑定、设置项或恢复分支；`acceptance.md` 已登记“不提供按命令块跳转”。

### 设置开关

- 开关注册、默认值与保存归 `../settings/app-page.md`；本篇只登记迁移前后状态。
- 迁移前应用页以禁用态 `尚未启用` 呈现；迁移完成后去掉禁用态。
- 删除旧增强设置键与旧配置读取；迁移验证新键即时生效、关闭后不注册按键/不启动后台计算/不绘制覆盖层。

### 依赖里程碑

里程碑依赖只在 `plan.md` 的“里程碑”表定义；本文件不复制依赖列表。补全历史与目录数据使用 `../persistence.md` 定义的本地路径。

### 迁移顺序

1. 终端面板接管 PTY/网格/视图；接入扩展 host 与开关读取。
2. 删除提示符跳转 API、标记存储与测试，保留命令生命周期。
3. 回迁 Vi 模式入口与按键。
4. 回迁补全编排、缓存与数据路径；先接 inline，再接 popup/hybrid。
5. 回迁数学覆盖层与绘制预算。
6. 回迁 AI 修复条 UI、按键与命令完成接线（请求层由 AI Providers 里程碑提供）。
7. 删除旧 pane 视图中的增强接线、旧设置键与旧缓存路径。

### 测试与验收

- 迁移：旧增强接线、旧设置键、旧缓存路径与提示符跳转 API 不存在。
- Vi：切换/退出、运动、选择与复制、交替屏幕拒绝、未识别键透传、不向 PTY 发送 Vi 按键。
- 补全：按键路径零 I/O、缓存按面板失效、取消后不回填、只本地来源、交替屏幕/Vi 抑制、IME 输入镜像。
- 数学：扫描预算边界、投影与 reflow/选区同裁定、只遮源格、失败保留原文、开关关闭不扫描。
- AI 修复条：三态渲染、按键语义、关闭开关无请求；请求层测试归 AI Providers 迁移。
- 设置：开关即时生效、保存失败提示、重启恢复；迁移前去禁用态。

### 不可自动化面

- Vi 按键手感、选择与滚动手感。
- 数学公式与代码块的实际字形观感、公式渲染质量。
- 补全弹窗与 ghost 的视觉舒适度、候选排序主观质量。
- AI 建议质量与危险命令判定准确率。
- 真实输入法组合态与终端前台 TUI 的按键交互。
