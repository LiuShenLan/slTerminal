# 应用页与壳服务迁移

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 职责：只登记壳服务的迁移增量：旧接线删除、落点、迁移顺序、增量验证与不可自动化面。应用页契约归 `../settings/app-page.md`；托盘、任务栏、开机启动、窗口几何与单实例归 `../platform-windows.md`；通知归 `../cross-cutting.md`；更新入口归 `../build-and-release.md`；诊断动作归 `../diagnostics.md`；工作区行为归 `../workspace/shell.md`。本篇不重复定义目标态契约。

### 应用页

- 应用页的注册、全局组顺序、节序、保存模式、数据模型与无项目浮层由 `../settings/app-page.md` 独占；本篇只登记壳服务接线。
- 迁移前范围外节保持只读占位或禁用态；迁移完成后只去掉对应节的禁用态，不复制页面字段。

### 托盘

- 保留独立托盘线程与隐藏 Win32 消息窗；迁移只改路由键与菜单数据来源。
- 删除旧 `PaneId` 托盘路由、旧 tab 事件到托盘的接线与旧菜单模型；菜单模型、失败重试与状态发布归 `../platform-windows.md`。
- 菜单项路由改为 `ProjectId`/`PanelId`；回窗语义由 `../platform-windows.md` 定义。退出接线改为走 `../workspace/shell.md` 的聚合关闭守卫。
- 托盘创建失败策略引用 `../platform-windows.md`；迁移不引入进程内重试循环。

### 任务栏

- 保留 OSC 9;4 五态映射与进程级单进度条；状态语义、清除边与闪烁门控归 `../platform-windows.md` 与 `../cross-cutting.md`。
- 删除旧 pane 路由与旧 tab 切换清除逻辑；改接 `PanelId`；来源判定与清除边由 `../platform-windows.md` 定义。
- 迁移验证同面板去重、切项目/切面板清除与进度失败静默。

### 开机启动

- 保留 Startup 快捷方式写入与删除能力；快捷方式名称、目标与幂等规则归 `../platform-windows.md`。
- 删除旧注册表写入、旧启动项与旧布尔设置键；开关状态读取规则由 `../platform-windows.md` 定义。
- 安装器与运行时共用同一快捷方式；迁移验证旧启动项不残留、重复开关幂等。
- 首版不做静默启动；迁移不引入隐藏启动路径。

### 通知

- 唯一通知服务与平台投递保留；类别、时长、去重与门控归 `../cross-cutting.md` 与 `../platform-windows.md`。
- 删除旧 `PaneId` 通知路由与旧 tab 事件订阅；改接项目/面板身份。
- 迁移只验证接线：前台门控、去重、系统通知与任务栏闪烁使用同一事件源；通知正文不插值敏感值。

### 更新入口

- 更新检查、下载、校验、两阶段交接、恢复与签名归 `../build-and-release.md`；应用页控件归 `../settings/app-page.md`。
- 删除旧更新弹窗、旧 `PaneId` 路由与旧状态读取；更新服务重接前应用页显示不可用状态，不提供假入口。
- 迁移验证：入口只在服务可用后开放；失败保持当前安装；外部托管渠道禁用自动下载与安装。

### 壳生命周期、单实例与窗口几何

- 启动/退出顺序、单实例判定、窗口几何与 DPI 规则归 `../platform-windows.md`；关闭链行为归 `../workspace/shell.md`。
- 删除旧启动链、旧窗口状态与旧实例文件读取；新壳接管启动恢复与 `runtime.handover` 接收端。
- 迁移验证：旧端口文件与旧锁不影响启动；第二实例只发送移交并退出；窗口几何在迁移里程碑按所有者篇接入。
- 规格内关闭链不冲刷窗口几何；迁移里程碑才开放写入。

### 诊断集成

- 诊断动作集、二次确认、清理范围与脱敏由 `../diagnostics.md` 独占；应用页只放入口。
- 删除旧诊断入口与旧动作接线；新入口接入导出诊断包、环境自检与通知自检。
- 壳提供平台能力：通知投递、数据根与日志根访问器、Runtime 探测与 panic/崩溃现场落点。
- 迁移验证：诊断动作与清理规则由 `../diagnostics.md` 测试覆盖；应用页只验证入口可达。

### 依赖里程碑

里程碑依赖只在 `plan.md` 的“里程碑”表定义；本文件不复制依赖列表。

### 迁移顺序

1. 新壳接管启动恢复、单实例与 `runtime.handover`；旧端口、旧锁与旧窗口状态不再读取。
2. 通知服务与托盘/任务栏按 `ProjectId`/`PanelId` 重接；保留平台线程与实现。
3. 应用页与无项目浮层由 `../settings/app-page.md` 迁移；本篇只接壳服务。
4. 开机启动改读快捷方式实际存在性，删除旧注册表项与旧布尔键。
5. 更新入口在更新服务重接后开放；此前显示不可用状态。
6. 诊断入口接入导出诊断包、环境自检与通知自检。
7. 删除旧壳事件枚举、旧 `PaneId` 路由、旧更新弹窗与旧诊断入口。

### 测试与验收

- 迁移：旧端口/旧锁/旧窗口状态不被读取；旧 `PaneId` 路由与旧事件枚举不存在。
- 托盘：路由含项目与面板、无目标只回窗、退出走关闭守卫；失败策略与 `../platform-windows.md` 一致。
- 任务栏：`PanelId` 来源、切项目/切面板清除、进度失败静默。
- 开机启动：快捷方式存在性驱动开关、旧启动项不残留、重复开关幂等。
- 通知：同一事件源驱动应用内、系统通知与任务栏闪烁；正文不含敏感值。
- 更新入口：服务不可用时禁用、可用后开放；失败不产生半安装。
- 单实例与窗口几何：旧实例文件不影响启动；移交失败不建第二窗；几何写入只在迁移里程碑接线。
- 诊断：入口可达，动作集由 `../diagnostics.md` 测试覆盖。

### 不可自动化面

- 真实托盘图标、explorer 重启后的图标重建、菜单原生绘制与点击区域。
- AUMID 注册、WinRT toast 实际投递、系统通知中心呈现与任务栏闪烁。
- 开机启动在真实登录会话中的生效、快捷方式被安全软件拦截。
- 多显示器、混合 DPI、跨屏拖动与系统贴靠下的窗口几何。
- 真实双进程单实例移交与锁竞争；以条件跳过集成用例与构建产物人工 smoke 兜底。
