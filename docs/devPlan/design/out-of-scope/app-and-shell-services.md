# 应用页与壳服务迁移

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 职责：设计应用页落地，托盘、任务栏、开机启动、通知、更新入口，以及它们与壳生命周期、单实例、窗口几何和诊断的集成。

### 应用页落地

- 应用页是设置中心的全局页，注册项固定：标题 `应用`，作用域 `应用`，保存模式 `自动保存`。全局组顺序为快捷键 → 后台定时任务 → 外观 → 终端 → 应用；应用页不进入 Agent 组。
- 页面由分节组成，单页内按顺序渲染：界面语言、更新、托盘与开机启动、通知、Runtime API、AI Providers/助手、诊断、备份与恢复、终端增强。AI 与备份使用行内列表/对话框，不新增运行期页面注册。
- 数据模型新增键：
  - `app.language`：系统/中文/英文。
  - `app.tray.enabled`：默认开；关闭后托盘图标移除，静默启动失效。
  - `app.startup.silent`：默认关；是否隐藏由 `silent && tray` 合取决定。
  - `app.notifications.desktop_enabled`：默认开；系统通知与任务栏闪烁的总开关。
  - `app.notifications.taskbar_flash`：默认开；仅影响任务栏闪烁，不影响系统 toast。
  - `app.updates.auto_check`、`app.updates.auto_download`：默认分别为开、关。
  - `app.diagnostics.debug_log`：默认关；等价于显式打开调试日志落盘，不改常驻日志级别。
  - `ai.assistant.enabled`、`ai.assistant.provider`、`ai.assistant.ignored_exit_codes`：见 AI 设计。
  - `terminal.enhancements.vi`、`terminal.enhancements.completion`、`terminal.completion.style`、`terminal.enhancements.math`、`terminal.enhancements.ai_fix`：见终端增强设计。
- 开机启动不保存布尔键：页面显示用户 Startup 文件夹中 `slTerminal.lnk` 的实际存在性；切换开关即调用平台写入/删除，失败行内可见。避免设置值与快捷方式漂移。
- Provider 元数据保存到应用设置域（`state/settings.json` 的 app 段）；凭据写入是显式动作且立即提交；其余字段按 2 秒去抖。凭据输入框只写不读，写入成功后清空草稿并显示尾四掩码。
- 更新入口：显示当前版本、检查更新、自动检查/下载开关、下载页链接、安装待重启状态；手动检查在后台执行，失败显示原因，不弹阻塞错误。
- 诊断入口：打开状态目录、打开日志目录、复制诊断摘要、发送测试通知、运行 Runtime 探测。摘要包含应用版本、系统版本与架构、状态根、端点可达性、托盘/AUMID/更新渠道状态、活动 PTY 数、日志路径；不包含 token、环境变量值、终端内容、文件内容或凭据。
- 无项目时，活动栏配置钮与 `Ctrl+,` 打开仅含应用页的全局设置浮层：复用同一设置模型与页面组件，不创建项目/面板组/设置面板；`Esc` 或关闭按钮退出，关闭前冲刷待写设置。有项目时仍打开项目内设置中心。
- 应用页自身不创建第二套保存状态；页头显示 `保存中`、`已保存`、`保存失败`，失败提供重试。凭据、快捷方式、更新检查、备份操作是显式动作，各自显示行内状态。

### 托盘

- 保留独立托盘线程与隐藏 Win32 消息窗；GPUI 只发布快照并接收命令。托盘状态按 1 Hz 发布，内容相等不唤醒。
- 目标模型：
  ```rust
  struct TrayAgentEntry {
      project_id: ProjectId,
      panel_id: PanelId,
      label: String,
      needs_attention: bool,
  }
  enum TrayCommand {
      Focus(Option<(ProjectId, PanelId)>),
      Quit,
  }
  ```
- 菜单顺序：等待输入/权限确认的面板优先，其余按项目顺序与面板组顺序；每行显示 `项目名 · 面板标题` 与状态；末尾固定 `显示 slTerminal`、`退出`。无 agent 时不渲染空分组与孤立分隔线。
- 左键点击与“显示”走同一回窗语义：先还原并前置唯一主窗，再切换到目标项目、激活面板组与面板；无目标时只回窗。
- 托盘开启状态来自应用设置；首次启用时启动线程并 `NIM_ADD`，关闭只移除图标。`NIM_ADD` 失败按 1 Hz 快照重试；持续失败在应用页显示可见状态。
- 退出走与关窗相同的聚合关闭守卫；托盘不绕过脏面板与运行中终端确认。进程退出前删除图标。

### 任务栏

- 保留 OSC 9;4 五态映射与进程级单进度条；目标路由键改为 `PanelId`，只接受活跃项目的聚焦终端面板上报。
- 切换项目、切换面板、面板关闭、命令结束、agent 退出、OSC 0/未知状态均清除进度；清除边只清除来源面板的进度，避免其他面板收尾误抹。
- 同面板同形态去重；百分比限制 0–100；未知状态码按清除处理。
- 任务栏闪烁由通知服务触发，与进度条使用不同 `ITaskbarList3` 调用；闪烁只在窗口失焦且收到 CLI 状态事件时发生，回窗停止。
- 进度投递失败静默，不影响终端；真实 COM 面由人工 smoke 兜底。

### 开机启动

- 快捷方式固定为 Startup 已知文件夹下的 `slTerminal.lnk`；`IShellLinkW` 幂等写入，目标为当前 exe，工作目录为用户主目录，图标取 exe，不携带参数。
- 设置页读取实际文件存在性作为开关状态；开启失败、删除失败均行内提示。安装器管理同一快捷方式，二者不各写一份。
- 静默启动公式保持 `silent_start && tray.enabled`；显式 `--working-directory`/`-e` 启动不静默。无托盘时隐藏窗口无回窗入口，因此托盘未启用或托盘初始化失败时强制显示窗口。
- 静默启动首窗不 show、不 activate、不抢焦；托盘“显示”负责首次回窗。

### 通知

- 唯一通知服务同时服务应用内通知、系统 toast 与任务栏闪烁；其他模块不得直接调用平台通知。
- 应用内通知：右上角堆叠，单条最大宽度 320px；成功 3 秒、警告 4 秒、错误 5 秒；悬停暂停，关闭按钮移除；可操作通知带一个操作按钮，悬停/聚焦暂停倒计时。
- 系统通知：仅在窗口失焦时发送，类别为任务完成、等待输入、权限请求、错误；正文 `<项目名> · <类别> · <时间>`；同类事件按事件键去重；系统通知无点击跳转，任务栏闪烁是唯一回窗引导。
- 应用页开关只作用于系统通知与任务栏闪烁；应用内错误通知始终可见。通知内容不插值凭据、终端输出、剪贴板或文件内容。
- 权限确认动作按钮通过通知服务回传 `NotificationChoice`，壳只做回窗与审计；不猜测按键注入。

### 更新入口

- 应用页提供手动检查与安装入口；启动自动检查保持“首窗与首个会话安顿后延迟联网”的一次性后台任务。
- 更新提示、下载进度、安装授权、稍后提醒、跳过版本、预约安装均复用更新服务；应用页只消费状态，不复制状态机。
- 自动下载只预取，不授予安装权限；安装仍经两阶段 `prepare`/`commit` 用户授权。
- 外部托管渠道在应用页显示“由外部包管理器更新”，禁用自动下载与安装入口。

### 壳生命周期、单实例与窗口几何

- 启动顺序：进程准备（console 归一化、`SLTERM_CLI` 注入）→ 日志/panic → 单实例 owner 锁 → 读取设置 → 初始化通知 AUMID 与托盘回调 → 打开主窗（按静默公式决定可见性）→ 发布初始托盘快照 → 启动后台任务/更新检查 → 恢复项目与布局。
- 单实例：拿不到 owner 锁即视为已有实例；读取 v2 端点并发送 `app.handover`，载荷为聚焦、打开项目、打开文件、新建终端、激活项目之一；发送成功后本次启动退出。端点不可达时有限重试后报错退出，绝不创建第二窗口。
- 退出顺序：聚合关闭确认 → 冲刷设置/布局/项目/侧栏/窗口几何 → 并发终止 PTY（3 秒上限）→ 保存项目数据（3 秒上限）→ 托盘收尾 → 退出。设置冲刷失败按设置守卫中止关闭；PTY 终止与项目保存失败只记录。
- 窗口几何：持久化逻辑尺寸、位置、最大化、显示器提示与 DPI；多显示器恢复时若保存矩形与任何显示器工作区交集不足（至少保留可拖拽标题栏区域），回退主显示器默认尺寸并居中；尺寸夹取到工作区。DPI 变化按新缩放重算逻辑尺寸，不改变布局结构。
- 窗口状态（最大化/还原）以窗口事件回查为准，不用按钮本地翻转；双击拖拽区、系统贴靠与边框拖动结果一致。
- 窗口几何写入 500 毫秒去抖，关闭冲刷；不写入项目布局，不随项目切换。

### 诊断入口

- 应用页诊断分节提供：打开状态目录、打开诊断目录、复制诊断摘要、发送测试通知、运行 Runtime 探测。
- 诊断摘要字段固定，且只读不写；复制到剪贴板前再次过滤 token、端点凭证、环境变量值与文件内容。
- 保留 `slterm notify-test` 诊断子命令：注册 AUMID → 读取时长映射 → 投递测试 toast，逐段报告；失败返回非零。
- Runtime 探测调用 `runtime.describe`，只显示协议版本、能力面与端点可达性，不显示 token。
- 日志：常驻日志只放行自家 crate 与 `audit`；额外 target 与环境路径保持诊断用途；panic 日志进入 `diagnostics/`，panic 对话框行为保留。

### 依赖里程碑

- 项目与布局模型、工作区壳、面板宿主注册点。
- 设置模型与写通道、设置中心与应用页注册。
- 单实例与窗口服务、Runtime API v2 的 `app.handover`。
- 通知服务（本节自身）与终端面板状态事件。

### 迁移顺序

1. 新状态根、窗口几何与 owner 锁/端点先落地；随后接入 `app.handover`，先支持仅聚焦。
2. 通知服务与托盘/任务栏按新 `ProjectId`/`PanelId` 重接；保留旧线程与平台实现。
3. 应用页在设置中心页注册表稳定后接入；实现无项目浮层。
4. 开机启动与静默启动按实际快捷方式状态接入。
5. 更新入口在更新服务重接后开放；此前应用页显示不可用状态，不提供假入口。
6. 诊断入口最后接入，复用日志、通知与 Runtime 探测。
7. 删除旧壳事件枚举中的 `MuxAttach`、旧 `PaneId` 托盘路由与旧更新弹窗接线。

### 测试与验收

- 应用页：分节渲染、自动保存状态、凭据写入只写不读、快捷方式实际状态、无项目浮层只含应用页且不创建项目/面板。
- 托盘：菜单纯函数、等待输入优先、快照去抖、Focus 目标含项目、Quit 走关闭守卫、托盘关闭后静默启动失效。
- 任务栏：五态映射、百分比夹取、来源面板清除、切项目/切面板清除、闪烁与进度互不覆盖。
- 开机启动：`silent && tray` 真值表、`.lnk` 写读 round-trip、重复关闭幂等、显式 CLI 启动不静默。
- 通知：前台门控、去重、时长、悬停暂停、关闭、可操作通知、系统通知正文不含敏感值。
- 单实例：第二启动载荷映射到打开项目/文件/新建终端/聚焦；端点不可达不建第二窗；旧端口文件不影响启动。
- 窗口几何：默认尺寸、最大化回查、越界夹取、显示器缺失回退、DPI 变化不漂移。
- 诊断：摘要字段白名单、token 与内容不出现、测试通知逐段结果。

### 不可自动化面

- 真实托盘图标、explorer 重启后的 `NIM_ADD`、菜单原生绘制与点击区域。
- AUMID 注册、WinRT toast 实际投递、系统通知中心呈现与任务栏闪烁。
- 开机启动在真实登录会话中的生效、快捷方式被安全软件拦截。
- 多显示器、混合 DPI、跨屏拖动与系统贴靠下的窗口几何。
- 真实双进程单实例移交与锁竞争；以条件跳过集成用例与构建产物人工 smoke 兜底。
