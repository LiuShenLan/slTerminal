# 应用页与壳服务迁移

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 职责：设计壳服务迁移——托盘、任务栏、开机启动、通知集成、更新入口、壳生命周期、单实例、窗口几何与诊断集成；应用页契约由 `../settings/app-page.md` 独占，诊断动作由 `../diagnostics.md` 独占。

### 应用页

- 应用页的注册、全局组顺序、节序、保存模式、数据模型与无项目浮层由 `../settings/app-page.md` 独占；本篇不复述。
- 本篇只定义应用页背后的壳服务：托盘、任务栏、开机启动、通知、更新与诊断入口。

### 托盘

- 保留独立托盘线程与隐藏 Win32 消息窗；GPUI 只发布快照并接收命令。托盘状态按 1 Hz 发布，内容相等不唤醒。
- 目标模型：
  ```rust
  struct TrayAgentEntry {
      project_id: ProjectId,
      panel_id: PanelId,
      label: String,
      needs_attention: bool,
  }
  enum TrayCommand {
      Focus(Option<(ProjectId, PanelId)>),
      Quit,
  }
  ```
- 菜单顺序：等待输入/权限确认的面板优先，其余按项目顺序与面板组顺序；每行显示 `项目名 · 面板标题` 与状态；末尾固定 `显示 slTerminal`、`退出`。无 agent 时不渲染空分组与孤立分隔线。
- 左键点击与“显示”走同一回窗语义：先还原并前置唯一主窗，再切换到目标项目、激活面板组与面板；无目标时只回窗。
- 托盘开启状态来自应用设置；首次启用时启动线程并 `NIM_ADD`，关闭只移除图标。`NIM_ADD` 失败按 1 Hz 快照重试；持续失败在应用页显示可见状态。
- 退出走与关窗相同的聚合关闭守卫；托盘不绕过脏面板与运行中终端确认。进程退出前删除图标。

### 任务栏

- 保留 OSC 9;4 五态映射与进程级单进度条；目标路由键改为 `PanelId`，只接受活跃项目的聚焦终端面板上报。
- 切换项目、切换面板、面板关闭、命令结束、agent 退出、OSC 0/未知状态均清除进度；清除边只清除来源面板的进度，避免其他面板收尾误抹。
- 同面板同形态去重；百分比限制 0–100；未知状态码按清除处理。
- 任务栏闪烁由通知服务触发，与进度条使用不同 `ITaskbarList3` 调用；闪烁只在窗口失焦且收到 CLI 状态事件时发生，回窗停止。闪烁由 `taskbar_flash` 独立门控，不受 `desktop_enabled` 影响。
- 进度投递失败静默，不影响终端；真实 COM 面由人工 smoke 兜底。

### 开机启动

- 快捷方式固定为 Startup 已知文件夹下的 `slTerminal.lnk`；`IShellLinkW` 幂等写入，目标为当前 exe，工作目录为用户主目录，图标取 exe，不携带参数。
- 设置页读取实际文件存在性作为开关状态；开启失败、删除失败均行内提示。安装器管理同一快捷方式，二者不各写一份。
- 首版不做静默启动：不持久化开机启动/静默启动布尔键；启动始终显示主窗，不引入静默启动真值表。
- 开机启动状态只读 `slTerminal.lnk` 的实际存在性，不保存布尔键；避免设置值与快捷方式漂移。

### 通知

- 唯一通知服务同时服务应用内通知、系统 toast 与任务栏闪烁；其他模块不得直接调用平台通知。
- 应用内通知：右上角堆叠；时长、悬停暂停、可操作按钮、去重与关闭行为由 `../cross-cutting.md` 拥有，壳只负责接线。
- 系统通知：仅在窗口失焦时发送；类别、正文格式、去重与任务栏闪烁门控由 `../platform-windows.md` 与 `../cross-cutting.md` 拥有；系统通知无点击跳转，任务栏闪烁是唯一回窗引导。
- `desktop_enabled` 只控制系统 toast；`taskbar_flash` 独立控制任务栏闪烁；应用内错误通知始终可见。通知内容不插值凭据、终端输出、剪贴板或文件内容。
- 权限确认动作按钮通过通知服务回传 `NotificationChoice`，壳只做回窗与审计；不猜测按键注入。

### 更新入口

- 应用页提供手动检查与安装入口；启动自动检查保持“首窗与首个会话安顿后延迟联网”的一次性后台任务。
- 更新提示、下载进度、安装授权、稍后提醒、跳过版本、预约安装均复用更新服务；应用页只消费状态，不复制状态机。
- 自动下载只预取，不授予安装权限；安装仍经两阶段 `prepare`/`commit` 用户授权。
- 外部托管渠道在应用页显示“由外部包管理器更新”，禁用自动下载与安装入口。

### 壳生命周期、单实例与窗口几何

- 启动顺序：进程准备（console 归一化、`SLTERM_CLI` 注入）→ 日志/panic → 单实例 owner 锁 → 读取设置 → 初始化通知 AUMID 与托盘回调 → 打开主窗（首版始终可见）→ 发布初始托盘快照 → 启动后台任务/更新检查 → 恢复项目与布局。
- 单实例：拿不到 owner 锁即视为已有实例；读取 v2 端点并发送 `runtime.handover`，载荷按协议源以根路径定位（仅聚焦、打开项目、打开文件、新建终端）；发送成功后本次启动退出。端点不可达时有限重试后报错退出，绝不创建第二窗口。
- 退出顺序：聚合关闭确认 → 冲刷设置/侧栏/工作区索引/项目布局/终端簿 → 并发终止 PTY（3 秒上限）→ 保存项目数据（3 秒上限）→ 托盘收尾 → 退出。设置冲刷失败按设置守卫中止关闭；PTY 终止与项目保存失败只记录。
- 窗口几何属范围外迁移能力：持久化到 `state/window.json`，几何模型、DPI 与多显示器规则由 `../platform-windows.md` 拥有，本篇不复述。
- 规格内关闭链不冲刷窗口几何；迁移里程碑才接入写入。几何文件不写入项目布局，不随项目切换。

### 诊断集成

- 诊断动作集、二次确认、清理范围与脱敏由 `../diagnostics.md` 独占；应用页只放入口，本篇不另立动作表。
- 壳提供诊断所需的平台能力：AUMID/通知投递、数据根与本地日志根访问器、`runtime.describe` 探测与 panic/崩溃现场落点。
- `slterm notify-test` 保留为诊断子命令：注册 AUMID → 投递测试 toast，逐段报告；失败返回非零。
- 常驻日志只放行自家 crate 与 `audit`；额外 target 与环境路径保持诊断用途；panic 日志进入诊断目录，panic 对话框行为保留。

### 依赖里程碑

- 项目与布局模型、工作区壳、面板宿主注册点。
- 设置模型与写通道、设置中心页注册点。
- 单实例与窗口服务、Runtime v2 的 `runtime.handover`。
- 通知服务门面与终端面板状态事件。

### 迁移顺序

1. 新状态根与 owner 锁/端点先落地；随后接入 `runtime.handover`，先支持仅聚焦；窗口几何在迁移里程碑按 `state/window.json` 接入。
2. 通知服务与托盘/任务栏按新 `ProjectId`/`PanelId` 重接；保留旧线程与平台实现。
3. 应用页与无项目浮层由 `../settings/app-page.md` 迁移；本篇只接壳服务。
4. 开机启动按 `slTerminal.lnk` 实际存在性接入；首版不做静默启动。
5. 更新入口在更新服务重接后开放；此前应用页显示不可用状态，不提供假入口。
6. 诊断集成最后接入，复用日志、通知与 Runtime 探测；动作按 `../diagnostics.md`。
7. 删除旧壳事件枚举中的 `MuxAttach`、旧 `PaneId` 托盘路由与旧更新弹窗接线。

### 测试与验收

- 应用页：契约测试归 `../settings/app-page.md`；本篇只覆盖应用页与壳服务的集成点。
- 托盘：菜单纯函数、等待输入优先、快照去抖、Focus 目标含项目、Quit 走关闭守卫、托盘关闭后图标移除。
- 任务栏：五态映射、百分比夹取、来源面板清除、切项目/切面板清除、闪烁与进度互不覆盖；`taskbar_flash` 独立于 `desktop_enabled`。
- 开机启动：`.lnk` 实际存在性、写读 round-trip、重复关闭幂等；首版启动始终显示主窗。
- 通知：前台门控、去重、时长、悬停暂停、关闭、可操作通知、系统通知正文不含敏感值；`desktop_enabled` 只影响 toast。
- 单实例：第二启动经 `runtime.handover` 映射到打开项目/文件/新建终端/聚焦；端点不可达不建第二窗；旧端口文件不影响启动。
- 窗口几何（范围外）：默认尺寸、最大化回查、越界夹取、显示器缺失回退、DPI 变化不漂移。
- 诊断集成：测试通知逐段结果、Runtime 探测不含 token；动作与清理规则测试归 `../diagnostics.md`。

### 不可自动化面

- 真实托盘图标、explorer 重启后的 `NIM_ADD`、菜单原生绘制与点击区域。
- AUMID 注册、WinRT toast 实际投递、系统通知中心呈现与任务栏闪烁。
- 开机启动在真实登录会话中的生效、快捷方式被安全软件拦截。
- 多显示器、混合 DPI、跨屏拖动与系统贴靠下的窗口几何。
- 真实双进程单实例移交与锁竞争；以条件跳过集成用例与构建产物人工 smoke 兜底。
