# 工作区、布局与侧栏

> 规定 ProjectLayout、PanelGroup、PanelHost、SideViewHost 和统一命令焦点的实现模型。

## 决策与红线

### 布局树与面板

- `slterm_split` 提供不持产品 ID 的泛型树：`Group<G>`、固定方向的分割节点、比例和最小尺寸约束。`slterm_workspace` 用 PanelGroupId 包装它，并在组内保存有序 ViewKey 与激活 ViewKey。
- 每个项目恰好一个 ProjectLayout；有项目时恰好一个活跃项目，恢复发现活跃项目缺失时按持久顺序选择首个。Panel 类型封闭为 Terminal、Editor、Markdown、Diff、GitShow、Settings，禁止跨项目移动。
- PanelGroup 是布局与页签集合的稳定身份；Panel 是运行实例。持久布局只保存组、树结构、ViewKey 和展示参数，不保存 PanelId、GPUI Entity 或焦点。
- 新建文件、终端或设置可以在现有组中插入，也可以从指定源 Panel 拆分形成新组；拆分必须同时给出落点内容，空间不足以容纳 120×80 逻辑像素的新组时拒绝。空组自动移除，没有组时显示项目空态，不持久化空组。
- 合并将源组面板按确定顺序移入目标组，尺寸调整只修改几何，不改变 ViewKey 身份。页签溢出使用横向滚动与完整列表，关闭其他／全部只作用当前组并进入统一守卫；单面板错误隔离并提供重试。
- Editor／Markdown 显式切换保留 PanelId、DocumentId、撤销和共享编辑状态；Diff 与 GitShow 不因布局移动改变仓库绑定。Settings 归属项目，不能跨项目移动。
- 恢复时按注册顺序和持久顺序创建实例；未知 ViewKey 过滤并聚合提示，重复 Settings 或非法引用按确定性归一，不创建第二份草稿或 Document。
- 项目切换只改变活跃 ProjectView，隐藏项目布局、Document 和 TerminalRegistry 继续存活；隐藏内容不抢焦，不为切回重新解析全文。

### 项目与落点

- 项目命令只修改 ProjectRegistry 和 ProjectLayout；添加项目只选择目录，不递归索引正文，也不自动创建终端。根按词法唯一，创建和重定位额外进行真实路径查重；默认显示名取目录名，重名按确定后缀消歧，创建成功自动成为活跃项目。
- 根重定位先检查新根冲突、Hooks Project／Local 草稿和必要状态提交，再替换 ProjectRoot；既有 PTY cwd、Document、Diff 和 GitShow 绑定保持不变。历史归属按最新词法根重算。
- 移除项目只向 CloseCoordinator 发请求。提交删除意图后才终止相关 PTY、删除布局和项目专属 ViewState；共享 Document、历史会话和磁盘文件不删除。移除活跃项目后按导航顺序激活下一个，没有下一个则激活上一个，全部移除后进入无项目状态。
- 新文件必须落在已登记项目或明确授权的文件落点；Runtime 不隐式创建项目、重定位根或借路径参数取得新授权。未归属历史恢复需要新项目时必须先经用户确认。

### SideViewHost

`SideViewId` 封闭注册为 `NavigationTree`、`Explorer`、`Commit`、`AgentFiles`。每个视图全局单例，活动栏上下组与上下槽共用同一份组织状态。

- 槽位状态与视图实例分离：同槽显式替换关闭旧实例并取消私有任务；隐藏整个侧栏只暂停可见性相关监听，保留实例和运行态；隐藏按钮只移除入口，不销毁实例。
- 侧栏布局保存按钮顺序、显隐、槽位、可见性意图、宽度和比例，500 毫秒去抖；窗口临时压缩不回写用户尺寸。视图自己的 ViewState 按各所有者声明保存，搜索、多选、内联编辑、菜单、通知、错误和焦点不保存。
- 未打开过的视图启动不创建实例；已打开视图先恢复状态再呈现。未知 ID 不生成占位按钮，重复或同槽多开按确定顺序归一并提示。
- 侧栏隐藏不停止 PTY、显式保存、文件操作或套餐调度；历史扫描等纯界面周期任务按可见性暂停。关闭最后视图与显式隐藏是两个不同持久状态。
- 项目或 AgentRoot 删除只清理对应分区，不能清空整个应用级 SideView ViewKey。

### 命令、焦点与输入

- `CommandRequest` 包含封闭 CommandId、来源、上下文快照、目标身份和可选参数；菜单、键盘、设置页、侧栏和 Runtime 都走同一校验与执行入口。
- 上下文栈为模态／临时面 → 补全或菜单 → Panel／SideView → 全局 → 终端原始输入。终端 `Ctrl+C` 固定中断，`Ctrl+Shift+C` 为默认复制；其他上下文可独立绑定自己的复制命令。
- 输入顺序为 IME 组合、模态路由、命令解析、普通文本、终端编码；组合期间不派发命令。快捷键录制只暂停普通派发，退出录制必须恢复。
- FocusManager 维护带实例代次的 FocusToken 与逻辑父链，焦点层级为活跃项目 → 聚焦组 → 激活面板 → 面板内落点。切换项目恢复该项目最后聚焦位置；模态关闭还焦触发者，非模态视图不抢焦，不可见或已销毁目标不能接收焦点。
- `Ctrl+Tab`／`Ctrl+Shift+Tab` 在活跃项目全部面板间循环，终端与编辑器不得截获；关闭聚焦面板后依次尝试同组下一个、上一个、相邻组激活面板和工作区容器。通知悬停或聚焦暂停自动消失，通知、菜单和错误不持久化。
- 所有状态恢复在首次呈现前完成，避免默认布局闪现；恢复本身不执行网络、子进程等待或阻塞式扫描，不回写解析产生的布局。项目移除和批量面板关闭不写全局正常退出标记。

## 验收与测试

- 对泛型布局树做属性测试：拆分、合并、移动、尺寸约束、序列化往返和随机操作后无重复／丢失 ViewKey。
- GPUI 虚拟窗口覆盖跨项目切换、同槽替换、隐藏侧栏、隐藏按钮、跨槽交换、关闭重开与重启，检查实例和瞬态语义不同。
- 恢复测试注入未知 SideViewId、重复 Settings、非法尺寸、缺失 Document 和损坏布局，验证字段级回退、聚合提示和无重复实例。
- 命令测试验证同一 CommandId 从键盘、菜单、设置和 Runtime 进入相同执行路径；IME 组合、模态和终端保留键不可被普通绑定绕过。
- 项目移除、根重定位和共享 Document 测试验证提交失败不破坏资源，成功后才清理专属状态。

## 操作

- 新增 Panel 或 SideView 类型时同时登记封闭枚举、ViewKey、恢复过滤、命令上下文、持久状态和追溯场景。
- 布局变更只经 ProjectLayout 转换对；不得在 GPUI 组件内直接序列化另一份树或绕过快照。
- 新增视图后台任务时声明其作用域和可见性策略，隐藏与销毁必须走不同取消路径。
