# GitShow 面板

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> GitShow 面板只读展示文件在 HEAD 中的版本，唯一入口为 Commit 视图中的已删除文件。面板生命周期、焦点与关闭归工作区壳；入口状态分派归 Commit 视图。

### 面板模型、入口与去重

面板参数 schema 归 `domain-model.md` 的 `GitShowParams { repo_path: RepoPath }`；本节只定义运行期模型。

```rust
pub struct GitShowPanel {
    pub id: PanelId,
    pub project_id: ProjectId,
    pub params: GitShowParams,
    pub state: GitShowState,
    pub stale: bool,
    pub find: FindState,
    pub wrap: bool,
    pub generation: u64,
}
pub enum GitShowState {
    Loading,
    Text(TextSource),
    Simplified(SimplifiedSource),
    Binary { kind: String, head_bytes: u64 },
    Error(GitShowError),
}
```

- 唯一入口：Commit 变更列表双击 `deleted` 行；无其他入口。
- 打开落点为活跃项目聚焦面板组；双击即打开，无确认。
- 去重键归 `domain-model.md`：项目 + 仓库相对路径，大小写不敏感；命中聚焦已有面板，不新建、不重读、不提示。
- 同文件编辑器或 Diff 面板不参与去重；三者互不替代。
- 不同项目同路径各自独立。
- 创建失败（无活跃项目、仓库不可用、路径无效）不创建面板，显示非阻塞错误。
- 标题按 `domain-model.md`：默认文件名，同项目同名改用项目相对路径，项目根外使用规范化绝对路径，并追加 `(git delete)`；悬停显示仓库内完整路径；标题不持久化，冲突集合变化时重算。
- 扩展名图标：已知类型用类型图标，未知用通用文件图标。

### HEAD 读取与内容形态

- 内容源固定为当前 HEAD 中的文件内容，不读工作区、索引、暂存区、其他分支或提交。
- 仓库根为项目根所在 Git 仓库实际根；文件按相对仓库根路径解析；项目根可为子目录。
- 打开与手动刷新时读取；成功进入内容态，失败进入错误态。内容为最近一次成功读取的快照。
- 读取使用 `git` 服务的 HEAD blob 流：常规文本一次性有界读取；超过 10,000,000 字节使用可寻址的块流，按需读取并缓存区段，不整份物化。
- 文本解码：非 UTF-8 字节显示替换字符，并在内容上方显示常驻横幅“文件包含无法解码的字节，已以替换字符显示。”；横幅不属于正文。
- 二进制：前 8KiB 含 NUL 即判定；显示“二进制文件”占位、类型（按扩展名，未知“未知类型”）与 HEAD 字节数，提供“用系统默认程序打开”。系统打开把 HEAD 内容写入系统临时文件后交给默认程序，不写工作区/索引/仓库。临时文件使用唯一名称并保留原扩展名，仅当前用户可读写；启动清理超过 24 小时的旧文件；面板关闭或退出尝试删除，失败登记下次清理；日志只记操作与结果。
- 空文件：带行号的空白视图，不显示“文件为空”；查找显示 `0/0`。
- 长行默认不换行，可横向滚动；正文可纵向滚动。
- 只读：文本可选择、复制、移动光标，修改操作无效。

### 大文件分级

阈值按 HEAD 内容字节数独立判定：

| 条件 | 行为 |
|---|---|
| ≤ 1,000,000 | 常规只读文本视图 |
| > 1,000,000 且 ≤ 10,000,000 | 常规视图 + 警告横幅“文件较大（X.X MB），只读查看；语法高亮与搜索可能影响性能。” |
| > 10,000,000 | 简化只读浏览：信息条“HEAD · 简化只读浏览 · X.X MB”，无语法高亮，按需加载，滚动到未加载区短暂占位 |

- 边界：恰好 1,000,000 不警告；恰好 10,000,000 仍常规并警告；10,000,001 起简化。
- 二进制判定优先于体积分级。
- 简化浏览支持纵向/横向滚动、自动换行、查找、字号、选择复制与键盘滚动；查找异步扫描整个 HEAD 文本，显示进度，`Esc` 取消，扫描中显示 `n/…`。
- 区段加载失败保留已加载内容，信息条追加“部分内容加载失败”与重试，重试只重读失败区段。
- 所有形态的文件大小均来自 HEAD 字节数。

### 刷新与过期

- 刷新是唯一重读触发：头部刷新按钮或面板聚焦时 `F5`。
- 常规、简化、二进制形态均支持；刷新期间已有内容保持可见与可操作，头部显示进行中、刷新入口禁用。
- 成功：替换内容；滚动位置保留并在新长度内收敛；换行、字号与查找关键词保留，查找按新内容重跑。
- 失败：保留原内容，内容上方“刷新失败：〈原因〉”与重试，不切换整页错误。
- 同一时刻只采纳最后一次读取；旧结果晚到不覆盖。
- 无自动刷新、无轮询；面板存活期间检测 HEAD 与目标文件内容变化。最近一次成功读取后检测到变化进入过期态：横幅“内容已过期，点击刷新”，正文、滚动、换行与查找保持，不自动替换。监听不可用时，仅窗口聚焦/面板激活复核 HEAD 指纹，不轮询。
- 过期只在刷新成功后清除；刷新失败时失败横幅替代过期横幅，重试成功后一并清除。
- 面板隐藏期间检测到变化只更新过期状态，不抢焦点；去重聚焦不重读；关闭后重开/重启重新读取。
- 关闭面板中止在途读取、停止 HEAD 变化检测并丢弃结果。

### 查找、换行、字号、复制与系统打开

- `Ctrl+F` 打开内容区顶部查找框；字面量、不区分大小写；匹配高亮、当前匹配区别样式、计数“当前/总数”；`Enter`/`Shift+Enter` 与 `Ctrl+G`/`Ctrl+Shift+G` 前后跳转；`Esc` 关闭并焦点回内容区；无匹配 `0/0`。
- 不支持正则、替换或匹配选项。
- `Alt+Z` 切换自动换行，默认关闭，面板实例独立；不重置光标、滚动与查找。
- 全局编辑器字号：指针在内容区时 `Ctrl+滚轮` 每格 1px（8–32），所有编辑器与 GitShow 同步；约 2 秒持久化。
- `Ctrl+C` 复制选区，`Ctrl+A` 全选；大文件复制超长选区异步执行，显示进度可取消，取消/失败时剪贴板保持原内容。
- `Ctrl+S` 被消费：不写盘、不标脏，显示短暂轻提示“只读视图，无法保存”。
- 加载态、错误态、二进制占位态无正文时查找/换行/字号不可用。

### 焦点、状态保留与错误

- 焦点落点为只读内容区；简化浏览与二进制占位可聚焦；错误态焦点在重试。
- 显式打开/激活时焦点进入内容区；加载中可落在容器，内容就绪后补入仅当面板仍激活且焦点未被移走。布局恢复不抢焦。
- 刷新、失败、过期出现与区段重试不移动焦点；隐藏期间完成读取不抢焦。
- 持久化：面板类型、仓库相对路径、面板组归属、尺寸与顺序；标题不持久化；HEAD 内容、滚动、查找、换行、已加载区段、焦点不持久化。全局编辑器字号独立持久化。
- 同组切面板/切换项目保留内容、滚动、查找与换行，不重读；关闭重开/重启重新读取并重置状态。

错误：

| 条件 | 文案 |
|---|---|
| 仓库不可用/非仓库 | “无法读取仓库” |
| 仓库无提交 | “仓库尚无提交” |
| 文件不在 HEAD | “该文件不在 HEAD 中” |
| 其他读取失败 | “读取 HEAD 内容失败”，可展开详情 |
| 初始失败 | 整页错误 + 重试；不自动重试 |
| 刷新失败 | 保留正文 + 失败横幅 + 重试 |
| 系统打开失败 | 非阻塞错误；占位与入口保持 |

- 恢复时路径不在 HEAD/越出仓库：面板保留并显示错误与重试，不读取任意磁盘路径，不自动删除面板。
- 错误详情不含凭据或敏感信息。

### 模块树与复用/重建

```text
领域 core crate
  panels/gitshow/
    params.rs
    state.rs           # Loading/Text/Simplified/Binary/Error、stale
    title.rs           # 同名消歧
    find.rs

slterm_app/src/panels/gitshow/
  panel.rs
  view.rs              # 只读文本/简化浏览/二进制占位
  head_watch.rs
  find_bar.rs
  system_open.rs
```

复用：`git::repository_root`、`git::head_file`（扩展为块流）、`TextSnapshot` 解码、编辑器语法高亮与只读大文件视图、`atomic_file` 无关（只写系统临时目录）。重建：`CodeTabView::new_git_show` + `TextFileView::new_git_head`（8MB 截断、源码编辑外壳、gutter、无刷新/过期/简化浏览）、旧 gitshow 入口分派。

### 测试接缝

- 去重与标题：同路径聚焦、同名相对路径消歧、关闭后重算、跨项目独立。
- 内容：HEAD 与工作区不同、工作区已删除仍可读、空文件、非 UTF-8、二进制、系统打开临时文件。
- 阈值：1,000,000/10,000,001/10,000,000 边界，二进制优先。
- 刷新：F5/按钮、保留滚动与查找、失败保留正文、最后结果胜出、过期横幅、隐藏期间变化。
- 查找：字面量、大小写、计数、异步扫描与取消、大文件全选复制取消。
- 虚拟窗口：焦点落点、`Ctrl+S` 轻提示、`Ctrl+F`/`Alt+Z` 在无正文时无效。
- 人工核验：系统默认程序打开、超大文件滚动观感；豁免原因、兜底层级与核验方式登记见 `.claude/docs/testing/exemptions.md`。
