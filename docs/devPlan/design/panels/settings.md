# 设置中心

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 设置中心是项目布局中的普通面板，每个项目最多一个；它承载应用级配置页与该项目绑定的 Hooks 项目层。无项目时同一页面模型以全局浮层呈现，仅含应用页。设置值模型与写盘机制归 `slterm_settings` 与设置持久化设计；本篇拥有面板结构、页面注册表、导航、保存模式与页面契约。

### 面板归属与入口

- 面板类型 `Settings`，页签标题固定“设置中心”；每项目最多一个；可拖动、合并、排序，禁止跨项目拖动；关闭不保留占位。
- 常驻入口为活动栏底部配置钮；`Ctrl+,` 为全局命令，可重绑。
- 有活跃项目：打开或聚焦活跃项目的设置中心，不切换项目、不创建第二个；已存在则激活页签、聚焦面板组、焦点落面板根容器，不重置选中页。
- 无活跃项目：打开全局设置浮层，仅含“应用”页；不创建项目、面板组或项目布局。
- 激活态：设置中心是其所在面板组当前面板时配置钮持续高亮，与面板组是否聚焦无关；被其他页签覆盖或位于非活跃项目时不高亮。
- 面板激活时焦点落根容器；根容器不在 Tab 顺序，按 Tab 进入左导航。
- 布局恢复若在同一项目发现多个设置中心面板，按布局 DFS 保留第一个，其余静默关闭；不产生未保存状态与关闭确认，不隔离或改写原布局。

```rust
pub struct SettingsPanelModel {
    pub id: PanelId,
    pub project_id: ProjectId,
    pub selected_page: Option<SettingsPageId>,   // None = 没有任何配置页
    pub page_params: BTreeMap<SettingsPageId, PageParams>,
    pub collapsed_groups: BTreeSet<GroupId>,
    pub search: String,
    pub page_states: BTreeMap<SettingsPageId, PageSaveState>,
}

pub enum SettingsSurface { ProjectPanel, GlobalOverlay }
```

`SettingsSurface` 只在本篇定义；shell 与 `settings/app-page.md` 只引用，不另建枚举。`SettingsPageId` 与 `PageParams` 定义于 `domain-model.md`。无选中页用 `None` 表示，不使用哨兵 ID；布局 DTO 的对应字段同步采用可空形态。当前没有配置页定义页内参数：`page_params` 仍按布局 schema 持久化，未定义页写空对象，读取时未知页标识与未知字段一律忽略。

### 页面注册表与目录

```rust
pub enum SettingsScopeSpec {
    Fixed(SettingsScope),             // 固定 Application 或 Project
    ByLayer,                          // 按当前配置层返回作用域（Hooks）
}

pub struct SettingsPageDef {
    pub id: &'static str,             // 稳定路由 id，只追加不重用
    pub group: SettingsGroup,         // Global | Agent(AgentKind)
    pub order: u16,
    pub title: Message,
    pub search_terms: &'static str,
    pub save_mode: SaveMode,          // Auto | Manual | Submit
    pub scope: SettingsScopeSpec,
    pub factory: fn(&mut SettingsPageCx) -> Box<dyn SettingsPage>,
}

pub trait SettingsPage {
    fn mount(&mut self, cx: &mut SettingsPageCx);
    fn unmount(&mut self);
    fn scope(&self, cx: &SettingsPageCx) -> SettingsScope;
    fn manual_dirty(&self) -> ManualDirty;
    fn save(&mut self, cx: &mut SettingsPageCx) -> SaveResult;
    fn reset_page(&mut self, cx: &mut SettingsPageCx) -> SaveResult;
    fn render(&mut self, window: &mut Window, cx: &mut SettingsPageCx) -> AnyElement;
}
```

目录：

- `Global` 组顺序：快捷键 → 后台定时任务 → 外观 → 终端 → 应用。
- `Agent` 组按已注册 CLI 分节；分节标题显示品牌 logo（无资产只显示名称）与显示名；标题只折叠/展开，不切换页面；子页缩进为基础配置 → Hooks。
- 没有 Agent 配置页时整组不渲染；没有任何配置页时右侧“暂无配置页”，左导航无组。
- 页面目录在应用启动时确定，运行期不变；安装/移除 CLI 需重启应用更新。
- 同一页面 id 重复注册时只保留一条，后注册者覆盖前者；排序按 `(group, order, registration_seq)`。
- 新增页面只改注册表与页面实现，不改导航/保存框架。

### 导航、搜索与状态标识

- 左导航固定 180px，内容超出纵向滚动；顶部显示不可点击的“所属项目：〈项目名〉”；浮层不显示项目上下文。
- 搜索按页面标题、CLI 显示名与分组名过滤，大小写不敏感；`Esc` 清空；无结果“无匹配配置页”；搜索只过滤导航，不改变选中页或页面状态。
- 导航项为按钮；选中项使用选中底色；手动未保存显示 7px 中性色圆点；自动保存失败显示独立失败徽标；分组折叠时组标题聚合显示组内状态。
- 键盘：方向键移动、Home/End 首尾、Enter/Space 激活；分节标题 Enter/Space 折叠；焦点环使用主题 token。
- 选中页规则：创建时读取保存值；目标页已注册则选中，否则回退全局组第一页，再回退第一个已注册页；无页面时选中页为空。程序化打开可携带初始页，未注册则按回退处理。外部更新面板参数中的选中页时同步切换；未知页标识忽略并保留当前页。
- 用户切换页面后写入 `page_params`；选中页与 `page_params` 写入 layout schema 并随项目布局持久化，字段归 `domain-model.md`/`persistence.md`。关闭面板移除，重开为新面板。

### 作用域与保存模式

作用域：

- 全局组与应用页为应用级，作用于全部项目。
- Hooks 的 Project 与 Local 层属于设置中心所属项目，使用面板所属项目根，不使用当前活跃项目；User 层为应用级。Hooks 页声明 `SettingsScopeSpec::ByLayer`，按当前层解析为“应用”或“项目”；其他页为 `Fixed`。
- 页面页头显示“应用”或“项目”作用域标识；Hooks 在 Project/Local 层显示项目名。

保存模式统一为三种：

| 模式 | 页面 | 行为 |
|---|---|---|
| 自动保存 | 快捷键、外观、终端、Agent 基础配置、应用 | 控件立即作用于运行期；停止操作 2 秒后写盘；显示保存中/已保存/失败与重试 |
| 手动保存 | Hooks | 编辑产生未保存状态；保存按钮提交；User 层二次确认 |
| 提交即保存 | 后台定时任务 | 勾选或失焦/Enter 提交立即写盘；不做乐观更新；成功后刷新清单 |

外观页中的侧栏布局控件不进入应用设置 2 秒去抖，走状态库 `Sidebar` facet（500ms）；外观页只是同一 `SidebarLayout` 的控制面。

```rust
pub enum PageSaveState {
    Idle,
    Saving,
    Saved { at: Instant },
    Failed { reason: String, retryable: bool },
}
pub enum ManualDirty { Clean, Dirty }
```

- 自动保存按域合并短时间连续改动；失败仍在本次运行中生效，提示“设置保存失败，修改仅在本次运行中生效”。
- 手动未保存只在保存成功或确认丢弃时清除；面板隐藏、切项目不清除。
- 自动保存未完成/失败进入工作区关闭守卫的“需保存”集合，但不在页签声明脏状态。
- 关闭面板：有手动未保存直接进入统一关闭确认；有自动保存待写/失败先冲刷，失败进入确认；无未完成状态直接关闭。
- 窗口关闭按工作区聚合确认；批量关闭只处理被关闭面板的待写自动保存；项目移除不进保存链、不触发全局设置冲刷；跨项目以“设置（〈项目名〉）”区分。
- 设置文件损坏时面板顶部显示警示条，可关闭；本次面板生命周期内不再显示，重新打开重新检查。

### 页面契约

#### 快捷键页

- 分组顺序：全局 → 终端 → 编辑器 → 文件浏览器；命令目录以工作区全局命令表为准，包含切换侧栏、聚焦活动栏、四个侧栏视图快捷键、打开设置中心、项目内联改名/上移/下移，以及终端/编辑器/文件浏览器命令。
- 不包含终端搜索、Diff 的 `F6`/`F7`、焦点循环与面板内固定键。焦点循环不可重绑，`Ctrl+Tab`/`Ctrl+Shift+Tab` 固定为焦点逃逸键，只读展示且不进入录制与冲突检测。
- 键位显示与内部存储的物理键名格式、保留键集合、派发层序与冲突裁定归 `ux-framework.md`；本页只按该契约展示与录制，不复制键表或层序。
- 每行显示生效键：默认键普通色；用户覆盖用强调色并显示 `↺` 与默认键小字；解绑显示“未绑定”；`↺` 恢复默认且不进入录制。
- 点击整行/Enter/Space 进入录制：“按下新键位…Esc 取消”；`Esc` 取消，`Backspace`/`Delete` 解绑；纯修饰键忽略；IME 组合态零命令匹配，任何单键、组合键、功能键都不进入命令匹配。
- 命中保留键显示红字“保留键 〈键名〉 不可绑定”，保持录制；同上下文冲突允许写入并警告“与「〈命令名〉」冲突”，生效顺序按 `ux-framework.md` 的固定层序。
- 页内分两区：可重绑命令与固定键参考。固定键只读展示，不进入录制与冲突检测；包括焦点逃逸键、`Ctrl+F`、编辑器撤销/重做/缩进、Diff `F6`/`F7`、GitShow `F5`、树导航键等。
- 录制期间全局快捷键暂停消费；录制结束、取消、页面卸载、面板失活后恢复，不得遗留暂停。
- 覆盖层改动 2 秒后保存；保存中/已保存/失败状态行内可见；启动或运行期检测到绑定保留键、格式非法、未知命令时，覆盖不生效并显示修复横幅，提供逐条/全部恢复默认。
- 覆盖层保存在全局设置状态，跨页面、项目与面板隐藏保留。

#### 后台定时任务页

- 从 `BackgroundTaskRegistry` 读取任务清单与生效配置；每行：标题 + 启用勾选 + 频率输入 + 范围提示。
- 契约任务：套餐余量查询默认启用、10 秒、10–3600 秒；会话历史刷新默认启用、3 秒、2–300 秒。
- 勾选/取消立即提交；提交期间行内控件禁用并显示“保存中”，不做乐观更新；成功后用返回清单刷新所有行；失败显示“设置失败：〈错误信息〉”，界面回到提交前值。
- 频率输入在失焦或 Enter 提交；去空白；必须是范围内整数；非法输入行内红字显示范围，不提交、不弹提示、保留输入。
- 套餐余量任务停用后停止后续执行，保留快照，导航树余量区隐藏；重新启用后开始并显示最后快照；频率修改从下一次调度生效。
- 会话历史刷新由视图订阅触发：视图未打开或任务停用不启动计时器；打开且启用时立即执行一轮。
- 页面挂载异步读取；加载中/读取失败与重试/空清单“暂无后台任务”。
- “恢复本页默认”：二次确认后把全部后台任务的启用状态与频率写回默认值；作为显式提交立即写盘，不进入 2 秒去抖；失败不部分落地，行内回显原因并保留提交前值。

#### 外观页

- 仅内置暗色主题目录，默认 `Linear`；不提供浅色、跟随系统、用户自定义主题、主题包导入导出或主题编辑器。主题、透明度、壁纸、密度组合不做对比度校验、不提示、不自动回退、不静默改写用户设置（见 `../theme-and-i18n.md`）。
- 字体：终端与编辑器分别设置字体族与字号（8–32）；字体族从系统等宽字体选择并保留当前值；缺失回退默认并可提示；非法字号行内报错不提交。
- 侧栏默认布局：逐视图显隐、排序、上区/下区归属、恢复默认；与活动栏共用同一 `SidebarLayout`，外观页只是控制面，持久化归状态库 `sidebar` facet（500ms），不建第二套布局状态。恢复默认只恢复全部视图按钮可见与注册默认槽位/顺序，不改变侧栏可见性意图、宽度、分割比例、项目布局与面板内容；已打开视图按 `../sidebar/framework.md` 的迁移/关闭规则处理。
- 透明度 80%–100%，默认 100%；不提示、不回退、不静默改写用户值。
- 壁纸：选择/清除，支持常见图片；仅窗口背景，内容区保持主题背景；读取失败保留原壁纸并提示。
- 密度：紧凑/标准/宽松，默认标准，即时生效。
- 编辑器与 Diff 行为：新面板默认自动换行（默认关）；实时差异重算间隔（100–2000ms，默认 300ms）；自动保存（默认关）；Markdown 草稿崩溃恢复（默认开）。
- 该页不产生手动未保存状态；待写配置先冲刷。

#### 终端页

- “启动与显示”与“交互”两节。
- 默认 Shell：自动/显式/自定义路径；自动按 `pwsh.exe` → `powershell.exe` → `cmd.exe`；显式从检测列表选择；自定义为绝对可执行路径 + 浏览；只影响新终端。
- 回滚容量：整数行，1000–100000，默认 10000；失焦/Enter 提交；非法行内红字；只影响新终端。
- “允许非聚焦终端写入剪贴板”默认关，只作用于活跃项目内的终端；隐藏项目中的终端与后台非聚焦终端始终不可写入。边界归 `../security.md` §URL、终端 OSC 与剪贴板。
- “光标闪烁”默认开；系统减少动效时默认关；用户显式开启可覆盖；光标形状固定竖线。
- 自定义 Shell 路径校验：空、非绝对、不存在、非可执行分别给出固定文案。
- 不提供终端配色、终端搜索、光标样式、输入模式页。
- 自动保存；不产生手动未保存状态。

#### Agent 基础配置页

作用域矩阵：

| 数据 | 作用域 | 说明 |
|---|---|---|
| 侧栏展示模式与自定义名单 | 按 CLI | 每个 CLI 基础页独立读写该 CLI 的值 |
| 显示运行时文件 | 按 CLI | 每个 CLI 独立；自定义模式置灰但保留值 |
| CLI 别名 | 按 CLI | 每个 CLI 独立；只影响该 CLI 的命令行首 token 识别 |
| 运行时文件清单 | 按 Agent | 内置 Agent 与自定义节点各一份；内置 Agent 按所属 CLI 归属 |
| 自定义 Agent 节点 | 应用级集合 | 所有 CLI 基础页共享同一集合与添加顺序 |

- 侧栏展示内容：全部/自定义；自定义名单 chip 增删、空名单文案、添加行与校验（空、含路径分隔符、重名）。
- “显示运行时文件”默认关，自定义模式置灰但值保留；全部模式显示运行时文件清单。
- CLI 别名：内置命令只读 chip；别名 chip 增删；校验空、长度 32、空白、引号/反引号、`-` 开头、与已有别名/内置命令/其他 CLI 冲突；Windows 不区分大小写；添加后立即在命令行首 token 识别中生效。
- 自定义 Agent 节点：按添加顺序列出；显示名 + 绝对目录 + 编辑/删除；删除二次确认且不删除磁盘文件；目录不可用不阻止添加，节点在 Agent 文件视图显示错误；多个节点可指向同一目录但独立显示；名称/目录变更后立即重新探测并停止旧目录监听。
- 运行时文件清单：按 Agent/自定义节点分组，每个内置 Agent 与每个自定义节点各占一行；chip 增删；每行提供恢复默认，内置 Agent 回到内置清单，自定义节点清空该节点清单。
- 自定义节点不归属任何 CLI，不应用按 CLI 的 `显示运行时文件` 开关；其根层始终按节点自身运行时清单隐藏条目。
- 校验：名称空/路径分隔符/重名；目录空/非绝对；盘符根、`%WINDIR%`、`System32` → `目录不可用于自定义 Agent 节点`（规则 owner 为 `../security.md`）。
- “恢复本页默认”：二次确认后只复位当前 CLI 的四项（展示模式、自定义名单、显示运行时文件、CLI 别名）与该 CLI 内置 Agent 的运行时文件清单；不清除其他 CLI、自定义节点集合与自定义节点清单。
- 根层过滤匹配、隐藏集合、重探测与监听停止由 `../sidebar/agent-files.md` 拥有；本页只提供表单字段、校验与即时同步，不复制消费语义。
- 自动保存；页面重挂载时未提交输入与行内错误丢失。

#### Hooks 页

- 页面壳：始终显示；CLI 未声明配置编辑器能力时显示“该 CLI 未提供配置编辑器”，不提供编辑控件。
- 层级按钮布局：固定 `User`、`Project`、`Local`，工具栏显示“优先级：Local > Project > User”，初始 User；页头作用域随层级显示“应用/项目”与所属项目名。
- 保存模式为手动保存；User 层保存二次确认“hooks 可执行任意命令”，Project/Local 直接保存；切层、切换配置页、关闭面板有未保存确认。
- 事件与 handler 目录、schema 校验、GUI/JSON 双模式、保存事务、注入/卸载、托管条目、外部修改检测、文件锁与备份、错误映射归 `../integrations/hooks.md`；本页只保留页面壳、层级按钮布局、保存模式与焦点/重挂载页面级状态，不复制引擎契约。
- 重挂载与重置矩阵：

| 场景 | 层级 | 模式 | 未保存编辑 | 焦点 |
|---|---|---|---|---|
| 同组切页签/面板隐藏（未卸载） | 保留 | 保留 | 保留 | 离开时释放，返回落页面根容器 |
| 设置中心内切换配置页 | 重置 User | 重置 JSON | 确认后丢弃 | 重挂载后落页面根容器 |
| 关闭面板后重开 | 重置 User | 重置 JSON | 丢弃 | 落页面根容器 |
| 应用重启 | 重置 User | 重置 JSON | 丢弃 | 落页面根容器 |

#### 应用页

节级范围、键与默认值见 `../settings/app-page.md`；应用页是全局组最后一页，保存模式为自动保存。本篇不复制应用页键表或默认值。

### 导入导出与恢复默认

- 导出应用设置 JSON，顶层含 `schema_version`（当前为 1），不含 Hooks、CLI 配置文件、凭据、终端输出、剪贴板或崩溃快照。
- 导入：版本校验 → schema 校验 → 预览受影响域 → 用户确认 → 生成可恢复备份 → 原子写；版本不兼容提示“设置文件版本不兼容”，schema 失败提示“设置文件格式错误”，两种失败均零写入；取消/备份失败不写入；提交失败原设置不变；成功后当前可见页重新读取生效值。
- `恢复所有设置默认`：二次确认后复位全部应用设置域；不触碰 Hooks、CLI 文件、项目布局与内容、侧栏布局与视图状态。
- `恢复本页默认`：二次确认后只复位当前页所属应用设置域；Hooks 页无此项；Agent 页按 Agent 基础配置页的作用域矩阵复位当前 CLI 四项与该 CLI 内置 Agent 清单。
- 导入/导出/恢复默认不改变面板打开状态、所在面板组或所属项目；不接受文件拖入面板作为导入。

### 错误映射

| 条件 | 行为 |
|---|---|
| 设置文件损坏 | 隔离原文件，回退备份/默认；顶部警示条；不覆盖损坏件 |
| 设置文件只读/版本过高 | 只读警示，禁止写入，提供重试；不把读取失败当缺失 |
| 自动保存失败 | 页内“保存失败”与重试；修改仍在本次运行中生效；关闭时进入守卫 |
| 后台任务读取失败 | “任务配置读取失败”与重试，不显示空白行区 |
| 后台任务提交拒绝 | “设置失败：〈错误信息〉”，显示值回到提交前 |
| 快捷键覆盖非法 | 修复横幅，受影响命令按默认键工作 |
| Hooks 读取/保存/注入/卸载失败 | 见 `../integrations/hooks.md` §错误映射；页面只显示错误与重试入口 |
| 终端 Shell 路径非法 | 行内固定文案，输入保留 |
| Agent 名单/别名/节点/清单校验失败 | 行内固定文案，输入保留 |
| 所属项目根不可访问 | Project/Local 禁用并提示 |
| 当前 CLI 未注册 | “未知 CLI”防御占位，配置写回时保留 |

### 测试接缝

- 注册表：全局顺序、Agent 分节、重复 id 后者覆盖、启动期固定、无页面空态。
- 选中页空态、回退规则、外部更新同步与未知页参数忽略；页面重挂载临时态重置。
- 导航搜索过滤、Esc 清空、无结果、不改变选中页。
- 保存模式：自动 2 秒去抖（外观页侧栏控件走状态库 500ms）、手动脏守卫、提交即保存的失败回滚；关闭冲刷失败进入守卫。
- 快捷键：录制/取消/解绑/保留键/冲突警告/无效覆盖修复/录制期间全局命令暂停与恢复；`Ctrl+Tab` 不可重绑；IME 组合态单键、组合键与功能键均不进入命令匹配。
- 后台任务：范围校验、提交失败回显、清单刷新、订阅型任务计时；恢复本页默认立即写盘且不进入去抖。
- 外观：不做对比度校验、不提示、不自动回退的负向断言，字体字号校验、侧栏布局与 500ms facet、自动保存开关、草稿恢复开关；恢复默认只恢复按钮可见性。
- 终端页：Shell 三模式、路径校验、回滚容量、OSC52 与闪烁开关的即时作用；OSC52 隐藏项目终端负向断言。
- Agent 页：作用域矩阵（按 CLI 四项、按 Agent 清单、应用级节点集合）、跨 CLI 隔离、页级复位范围、名单/别名/节点/清单校验与即时生效。
- Hooks：页面壳、层级按钮布局、保存模式、切层/切页/关闭守卫与重挂载重置矩阵；引擎、schema、保存事务、注入/卸载与外部修改测试见 `../integrations/hooks.md` 的测试接缝。
- 导入导出/恢复默认：版本与 schema 校验、预览、备份、失败不写、作用域不越界；侧栏布局不参与导入导出与恢复默认。
- 应用页：见 `design/settings/app-page.md` 的测试接缝。
