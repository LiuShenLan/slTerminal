# Markdown 面板

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> Markdown 面板拥有源码/渲染两态、内存草稿、渲染管线、链接与资源安全、查找与大纲、缩放与阅读位置、外部修改、草稿快照。文件打开路由与 HTML 源码视图归编辑器；保存与关闭守卫的通用规则由编辑器与工作区定义。

### 面板模型与两态

面板参数 schema 归 `domain-model.md` 的 `MarkdownParams`（含 `PersistedPath.read_only`）；本节只定义运行期模型。

```rust
pub struct MarkdownPanel {
    pub id: PanelId,
    pub project_id: ProjectId,
    pub params: MarkdownParams,
    pub doc: EditorDocument,          // 与编辑器共用文档/保存链，但面板类型独立
    pub render: RenderState,
}
```

- 只处理 `.md`/`.markdown`；每项目每路径一个 Markdown 面板；去重键归 `domain-model.md`（项目 + 规范化真实路径）。
- 形态互斥，默认渲染；新建、关闭重开、形态值非法时进入渲染。
- 两态共用同一份内存草稿；切换不重新读盘；渲染源永远是草稿。
- 源码态遵循编辑器契约（保存、脏状态、外部修改、撤销、光标、查找替换、换行、字号、编码、行尾）；本篇只定义两态关系。
- 脏状态附着面板，两态共用；只有源码态产生修改。已登记 Agent 全局目录（`AgentRoot`）内可编辑保存；项目根外、仓库根内等只读面板不产生可保存草稿与脏状态；文件已移出允许根时保留草稿与脏状态，禁用原地保存，提供另存为。
- 源码切渲染：立即按当前草稿渲染，不等输入停止；渲染切源码：显示草稿并恢复源码态撤销历史、光标、选择与滚动。
- 形态、缩放、大纲开关、滚动锚点随项目布局持久化；关闭重开视为新面板，恢复默认渲染、100%、顶部、无大纲。
- 右上两段式切换控件显示“渲染”“源码”；文件加载失败时不显示。显式打开或激活时焦点进入面板容器，渲染态不自动进入内容区或查找框，源码态按编辑器焦点落点进入编辑区；布局恢复不抢焦点。
- 内容操作边界：代码块、公式与图片正常渲染；不提供代码块复制按钮/语言标签、公式源码复制、图片放大或复制路径、渲染态应用自定义右键菜单；任务列表勾选只读。

### 渲染管线

```rust
pub struct RenderDocument {
    pub blocks: Vec<RenderBlock>,
    pub headings: Vec<HeadingEntry>,
    pub links: LinkTable,
    pub plain_text: String,           // 渲染态查找索引
    pub revision: u64,
}

pub enum RenderBlock {
    Heading { level: u8, anchor: String, inlines: Vec<Inline> },
    Paragraph(Vec<Inline>),
    List(ListBlock),
    Quote(Vec<RenderBlock>),
    Code { language: Option<LanguageId>, text: String },
    Table(TableBlock),
    Math { source: String, display: bool },
    Mermaid { source: String },
    Image(ImageBlock),
    Html(HtmlBlock),
    Rule,
    FootnoteList(Vec<RenderBlock>),
}
```

步骤：

1. 解析：复用 `markdown::parser`（CommonMark 核心 + pulldown-cmark GFM 扩展），启用 tables、strikethrough、tasklists、footnotes、YAML metadata、math；新增 GitHub 提示块（引用首行 `[!NOTE]` 等）与标题锚点归一化（同名追加序号）。
2. 安全归一：原始 HTML 进入 `HtmlSanitizer`；未知/危险标签转义为文本；`details/summary` 的展开状态只保留在渲染结果。
3. 资源解析：图片与链接延迟解析；本地资源经 `ResourceResolver`，远程图片只生成占位与“加载”动作。
4. 渲染：文本块 shape；代码块走语法高亮；公式走 `compile_formula`；Mermaid 按代码块显示源码；表格按列对齐并在内部横向滚动。
5. 虚拟化：仅物化视口与 overscan 的块；屏外块释放布局与图片解码激活；长文档内存不随块数线性增长。

调度：

- 后台渲染，前台可交互；结果带 `revision`，过期结果丢弃。
- 首次渲染超过 100ms 显示“渲染中...”；首次完成后，后续重渲染保留上一版内容，不回退占位。
- 源码态编辑期间不触发渲染；切回渲染态立即渲染一次。
- 主题切换按新语义 token 重渲染，不重读磁盘。
- 渲染失败按块降级为源码文本；整篇失败显示“渲染失败”，提供“重试”“查看源码”。

排版：

- 正文最大行宽 900px；表格、代码块、图片可占满内容区；内边距由主题令牌定义。
- 代码块按语言高亮，长行不折行、内部横向滚动；内置语言至少覆盖 JavaScript、TypeScript、JSON、HTML、XML、CSS、SCSS、Bash、Shell、PowerShell、Python、Rust、Go、Java、C/C++、C#、SQL、YAML、TOML、INI、Diff、Markdown、Dockerfile、Makefile；别名归一（`js`/`node`/`jsx` → JavaScript 等），未知语言纯文本。
- 图片不超过内容宽度，小图不放大；缩放时随内容缩放。

### 安全 HTML、链接与资源

安全 HTML：

```rust
pub struct HtmlSanitizer;
impl HtmlSanitizer {
    fn sanitize(&self, raw: &str) -> Vec<HtmlNode>; // 仅白名单
}
```

- 白名单标签：`br`、`hr`、`sub`、`sup`、`kbd`、`a`、`img`、`picture`、`source`、`details`、`summary`。
- 白名单属性：`href`、`src`、`srcset`、`alt`、`title`、`width`、`height`、`open`，且链接与资源仍经分派/边界校验。
- `script`、`style`、表单、框架、`object`、`embed` 等不解析；危险或未知标签按转义文本显示。
- 文档内容不执行脚本、事件、表单或外部程序。

链接分派：

| 形态 | 行为 |
|---|---|
| `#fragment` | 当前文档内定位；空 `#` 回顶部；不存在无动作 |
| `http`/`https` | 系统默认浏览器 |
| `mailto`/`tel` | 系统默认处理程序 |
| Windows 盘符绝对路径 | 解析为本地路径后走本地打开规则 |
| 相对路径 | 以 Markdown 文件目录为基准；无磁盘路径时以项目根为基准 |
| `data:`/`blob:`/`javascript:`/`file:` 等 | 忽略 |

- 本地路径先归一分隔符、百分号解码、`..`，再做项目根边界校验；`?query` 不参与路径解析；`#fragment` 只定位。
- 项目根内文件走统一打开链路与去重；`.md` 打开 Markdown 默认渲染；`.html` 打开编辑器；其他文件打开编辑器。
- 项目根外本地路径仅由用户显式点击后根外只读打开并标注“项目根外”；不加入文件树/Commit/终端目录，不扩大资源读取边界。
- 目标不存在/不可读/目录：不创建面板，非阻塞提示对应文案。
- 悬停/键盘聚焦显示目标提示：外部完整 URL；本地归一化路径、类型与存在性；提示只做元数据检查，不读内容、不联网。

本地资源：

- 相对资源以 Markdown 文件目录为基准；盘符绝对路径可用；真实路径必须仍在项目根内（防符号链接/目录联接逃逸）。
- 支持 png、jpg、jpeg、gif、webp、avif、bmp、ico、svg。
- SVG 渲染前去脚本、事件属性、外部引用、`foreignObject`；清洗失败显示占位。
- 单资源上限 20MB；解码缓存 128MB，按最近使用淘汰；缓存键 = 真实路径 + 修改时间 + 大小。
- 视口懒加载；失败/超限/越界/格式不支持显示固定尺寸占位（alt + 原始路径 + 原因），不弹阻断式错误。
- `data:image/...` 按同一上限；非图片 data 忽略。

远程图片：

- 默认不加载、不发请求；显示“远程资源未加载”占位与“加载”动作。
- 点击只对该图发起一次请求；仅 http/https 图片；20MB、10 秒超时、不携带 Cookie/凭据；成功纳入同一解码缓存。
- 失败保留“加载”与原因；远程字体、样式、脚本永不加载。

### 公式与 Mermaid

公式：

- 复用 `slterm_app::math`：`compile_formula` 是唯一排版入口；行内 `$...$`、块级 `$$...$$`；识别时避免货币金额误判。
- 失败在原位显示公式源码与错误样式，不中断整篇；公式不生成链接或外部资源。
- 以文本呈现 LaTeX 源码。

Mermaid：

- 首版不渲染；`mermaid` 围栏按普通代码块显示源码，保留缩进与横向滚动。
- 保留可选 `MermaidRenderer` 注册槽作为扩展点；首版为空，具体类型随实现引入，不引入脚本执行面。
- Mermaid 源码按不可信文本处理；不加载外部资源、不响应图内点击；不做图表类型摘要。

### 查找、大纲、缩放与滚动锚点

查找：

- 渲染态 `Ctrl+F` 打开内容区顶部查找栏并聚焦；再次按下只聚焦。
- 字面量纯文本匹配，默认不区分大小写；不提供正则、全词匹配或替换。匹配高亮，当前匹配区别高亮并滚入视口；计数“当前/总数”，无匹配“0/0”。
- `Enter` 下一个、`Shift+Enter` 上一个；`Esc` 关闭、清除高亮、焦点回内容容器。
- 只搜索渲染后可见文本，不搜索源码、链接地址、alt、原始 HTML 标签；不提供正则/全词/替换。
- 草稿重渲染后重算匹配；查找栏不持久化。

大纲：

- 渲染态右上开关，默认关闭，随布局持久化；开启显示浮层，按层级列出标题；无标题显示“无标题”。
- 点击/键盘激活滚动到锚点；`Esc` 关闭浮层并同步关闭开关；源码态隐藏开关；重渲染后更新。
- 大纲不是独立模式。

缩放：

- `Ctrl+滚轮` 每累计 100px 步进一档，每档 ×1.1 或 ÷1.1；范围 25%–400%。
- 右上角显示缩放提示（取整百分比 + “重置”），最后一次变化后 3 秒消失；再次变化续期；`重置` 立即回 100% 并隐藏。
- 缩放按面板持久化；关闭重开从 100% 开始；源码态字号遵循编辑器，不使用渲染缩放。
- 重渲染/重启恢复缩放不显示提示；只有用户主动缩放显示提示。

滚动锚点：

持久化锚点使用 `domain-model.md` 的 `MarkdownAnchor { anchor, offset_px }`；块 id 与块内偏移是运行期映射，不写盘。

- 渲染态单一大垂直滚动容器；宽表格、代码块内部横向滚动。
- 切换形态、切面板、切项目保留滚动；重渲染按“最近块锚点 + 块内偏移”恢复，锚点不存在按比例回退，最后边界收敛。
- 应用重启恢复锚点；内容变化导致锚点消失按比例回退，再不存在回顶部。
- 关闭重开不恢复滚动，从顶部开始。
- 键盘滚动：方向键、PageUp/PageDown、Home/End、Space/Shift+Space；减少动效时无平滑动画。

### 外部修改、重命名与冲突快照

- 干净 + 磁盘修改/原子替换：自动重读刷新；渲染态恢复阅读位置，源码态按编辑器契约重载并提示。
- 脏 + 磁盘修改：顶部非模态横幅“文件已被外部修改”，提供“重载”“保留我的修改”“查看差异”；不抢焦点。
- “查看差异”：以磁盘版本创建临时只读快照，在 Diff 面板以冲突快照模式与当前草稿比较并定位首个差异块；不改变草稿、脏状态与横幅。
- “重载”丢弃草稿、清脏、关横幅、恢复阅读位置；“保留我的修改”保留脏状态并关横幅，磁盘再变时重新显示，之后保存按保存冲突规则处理。
- 外部删除：常驻横幅“文件已从磁盘删除”，提供“保留内容”“关闭面板”；内容保留可编辑；删除后保存走编辑器“文件已不存在”流程。
- 外部重命名/移动：跟随新路径，保留草稿、脏状态、形态、滚动与缩放；允许根外进入脱离态；无法关联按删除处理；新路径已打开按“目标文件已打开”。
- 跨分派类别重命名由 `PanelKindTransition` 转换类型，文本与脏状态保留。
- 重载读取失败：非模态横幅“无法读取外部修改”，提供重试、保留当前内容。
- 项目隐藏期间状态在内存更新，冲突横幅延迟到重新显示，不抢焦点。

保存与关闭：

- 源码态保存成功不提示，清脏；失败“保存失败：{message}”，保留脏状态。
- 关闭脏面板：工作区确认框标题“未保存的修改”，按钮取消、保存并关闭、丢弃并关闭；保存失败通知“保存失败，面板未关闭”，面板保持。
- 根外只读无脏状态；脱离草稿进入关闭守卫，“保存并关闭”通过另存为完成。
- 渲染态 `Ctrl+S` 不执行保存。

### 大文档分级与错误

- 文件超过 5MB 或超过 100,000 行：默认源码态，顶部“文档较大，已使用源码模式”与“仍要渲染”；选择后渐进渲染，图片懒加载，可随时切回源码。
- 超过 50MB：渲染态不提供“仍要渲染”；源码态按编辑器大文件契约只读，提示“文档过大，已只读打开”。
- 渲染、语法高亮、公式与图片解码不得阻塞前台；长任务可分块并响应取消。
- 1MB 以内文档打开后 1 秒内首屏可读。

空态与加载：

- 空文件或仅含空白的文件：渲染态显示居中“空文档”与“切换到源码”；源码态显示正常空编辑器。
- 读取期间居中“加载中...”，形态切换控件与缩放提示不显示；读取失败显示“加载失败: {message}”与重试/关闭。
- 首次渲染超过 100ms 显示“渲染中...”；首次完成后后续重渲染不回退占位。应用重启恢复时文件不存在显示加载失败，不恢复草稿。

错误映射：

| 条件 | 表现 |
|---|---|
| 文件路径缺失 | “加载失败: 未指定文件路径”，提供关闭 |
| 读取失败 | “加载失败: {message}”，提供重试、关闭 |
| 保存失败 | 非阻塞“保存失败：{message}”，保留脏状态 |
| 保存并关闭失败 | 通知“保存失败，面板未关闭”，面板保持 |
| 链接目标不存在/不可读/目录 | 对应非阻塞提示，不创建面板 |
| 图片失败 | 内联占位、alt、路径、原因 |
| 远程图片未加载/失败/超时/超限 | 占位与原因，保留“加载” |
| 公式失败 | 内联原始公式与错误样式 |
| 整篇渲染失败 | “渲染失败”，提供重试、查看源码 |

### 草稿快照

- 编辑期间周期性写入应用托管的草稿快照；正常保存、关闭面板、正常退出时清理。
- 快照不是自动保存，不写文档文件；只含草稿文本与文件路径。
- 外观页“Markdown 草稿崩溃恢复”默认开启；关闭后不写快照。
- 启动检测到未恢复快照时显示“恢复未保存的草稿”，提供恢复/丢弃；恢复后进入源码态且标脏，不自动写盘；丢弃后从磁盘读取。
- 快照不进入设置、布局或审计；恢复不恢复光标、选区、滚动、搜索或撤销历史。

### 测试接缝

- 解析：GFM、脚注、front matter、提示块、锚点稳定与重复标题、未知语言。
- 安全：脚本/事件/框架/`object`/`embed`/表单不执行；白名单属性；SVG 清洗失败。
- 链接：协议白名单、本地归一化、路径穿越、根外只读、锚点、缺失/目录提示。
- 资源：越界、符号链接、20MB、缓存淘汰、远程单次加载与超时、无 Cookie。
