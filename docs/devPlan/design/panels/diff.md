# Diff 面板

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> Diff 面板拥有 HEAD 与工作区的行级对照、并排/行内视图、工作区侧编辑与保存冲突、HEAD 刷新、外部修改、冲突快照模式与面板参数持久化。面板生命周期、焦点迁移与关闭守卫归工作区壳；编辑器通用能力与 GitShow 不在本篇。

### 面板模型与入口

```rust
pub struct DiffPanelParams {
    pub head_path: PathBuf,         // 仓库相对路径的 HEAD 侧
    pub worktree_path: PathBuf,     // 当前工作区路径
    pub view: DiffViewMode,         // SideBySide | Inline
    pub wrap: bool,
    pub sync_scroll: bool,
    pub split: f32,                 // 0.0..=1.0, 默认 0.5
    pub collapsed: Option<DiffSide>,
    pub swapped: bool,
}

pub enum DiffSource {
    HeadToWorktree { worktree_path: PathBuf },
    ConflictSnapshot {
        source_panel: PanelId,
        generation: u64,
        left: SnapshotText,
        right: SnapshotText,
        title: String,
    },
}
```

入口：

- Commit 视图双击 modified/renamed/conflict 条目。
- 编辑器 gutter 单击新增/修改/删除行标记；删除标记定位到删除行所属差异块。
- 冲突快照仅来自编辑器或 Markdown 冲突横幅“查看差异”。

打开规则：

- 默认模式标题 `〈文件名〉(git diff)`；重命名条目使用当前文件名；冲突条目显示 `冲突` 徽标并高亮冲突标记区间与计数。
- 默认模式去重键 = 项目 + 规范化工作区路径 + `mode/source`，同一键只有一个 Diff 面板；再次打开聚焦并定位目标差异块。冲突快照不参与去重（见下）。已有面板干净时，从 gutter 打开用当前编辑器缓冲替换工作区侧，从 Commit 打开重新读盘并刷新 HEAD；已有面板脏时不静默覆盖，只定位并提示，提供显式“用编辑器内容替换”或“重新加载磁盘内容”，二次确认丢弃 Diff 修改。
- 不同项目同路径各自独立，各自解析所在项目的 Git 仓库实际根。
- Diff 与同文件编辑器、GitShow 互不复用、互不替代。
- 从 Commit 打开工作区侧取磁盘；从 gutter 打开取编辑器当前缓冲（含未保存修改），并以脏状态打开、提示“已带入编辑器的未保存修改”。此后两者独立，通过保存与外部修改规则衔接。
- 默认模式参数为项目根、工作区路径、HEAD 路径；存活期间文件绑定固定，比较另一文件需关闭后新建。
- 布局恢复只恢复默认模式：重新解析仓库根并读取当前 HEAD，不冻结打开时 HEAD。

### 差异模型与行对齐

```rust
pub struct DiffModel {
    pub rows: Vec<AlignedRow>,
    pub blocks: Vec<DiffBlock>,
    pub stats: DiffStats,           // added/deleted
    pub options: DiffOptions,
}
pub struct AlignedRow { pub left: RowSlot, pub right: RowSlot, pub kind: RowKind }
pub enum RowSlot { Line(u32), Blank }
pub enum RowKind { Same, Added, Deleted, Modified }
pub struct DiffBlock { pub left: Range<u32>, pub right: Range<u32>, pub kind: BlockKind }
```

算法：

1. 行切分按 `\n`；行尾符差异与末尾换行有无不产生标记。
2. 先做基于行哈希的快速公共前后缀裁剪，再对中段做 Myers 或 histogram 行差异。
3. 相邻的删除段与新增段合并为一个修改块；块内按较小行数逐行配对为 `Modified`，多出的行分别 `Deleted`/`Added`。
4. 纯删除块在“删除位置相邻行”显示删除标记：删除点之后的第一个工作区行；若在文件末尾，显示在最后一行。
5. 纯新增块逐行新增；纯修改按配对行修改。
6. 空白选项只影响判定：`忽略行尾空白`、`忽略全部空白`，不改写文本与保存内容。
7. 冲突快照模式使用打开时的两侧快照，不重算、不刷新 HEAD、不检测外部修改。

实时重算：

- 工作区编辑停止输入后按配置间隔重算（100–2000ms，默认 300ms）。
- 保存成功、外部重载成功、HEAD 刷新成功立即重算。
- 计算期间保留上一份标记与占位，显示“差异更新中”；失败保留上一份并显示“差异可能过时”；无上一份时不显示标记。
- 过期结果不得覆盖新结果；以最近稳定缓冲为准。
- 二进制（前 8KiB 含 NUL）不显示标记与占位；工作区侧不可编辑、不可保存。

### 布局、虚拟化与滚动同步

- 并排默认 50/50，中间 1px 视觉分隔线，拖动命中区不小于 6px；每栏最小 240px；双击恢复 50/50。
- 总宽不足 480px 时两栏等分并各自横向滚动；变宽后恢复存储比例并继续受 240px 约束。
- 每栏包含列头、行号槽、行标记槽、内容视口；列头显示来源、路径、新增/删除统计；路径过长截断并提供完整路径提示。
- 行标记槽始终保留宽度；行号与标记槽固定在视口左侧，不随正文横向滚出。
- 行对高度取左右该行实际渲染高度较大值；空白占位补足到该高度。字号、换行、列宽变化立即重排。
- 空白占位无行号、无文本、不可选择/复制、不参与查找/编辑/保存，不响应鼠标与右键。
- 行内视图为单列统一视图：删除行以虚拟行插入，行号槽同时显示旧/新行号；不显示空白占位；工作区侧仍可编辑；交换、折叠、列宽控件隐藏但参数保留；同步滚动开关置灰。
- 虚拟化：按行对窗口渲染，屏外行不物化；大文件只读侧按需分页读取。
- 滚动同步：默认开启，以逻辑行对为基准；仅同步垂直方向；两侧横向独立；消除回环。差异不可用、某侧无内容/二进制/读取失败时停用。面板重新加载、参数变化、视图切换、布局恢复后重建同步关系。

### 编辑、保存与冲突

- 工作区侧可编辑（项目根内）：撤销、重做、查找、`Tab` 缩进、IME、保存；HEAD 侧只读，可聚焦、选择、复制、查找。
- 行内视图编辑作用于完整工作区文档；切回并排内容与脏状态一致。
- 脏状态 = 工作区当前内容与最近一次加载/保存/显式重载的磁盘基线不一致；撤销回基线自动清脏。
- 任一栏聚焦时 `Ctrl+S` 保存工作区完整缓冲；HEAD 侧无独立保存对象。
- 保存成功：清脏、立即重算、刷新标记与对齐、通知侧栏/Commit，不弹提示、不移动光标/滚动。
- 保存失败：“保存失败：〈原因〉”，保留脏状态，不刷新差异。
- 保存链：保存前检查相对基线的版本变化，保存后检查磁盘版本与本次写入预期一致（大小、修改时间、文件标识）；任一次不一致即进入保存冲突，不以写入后的磁盘状态静默建立新基线。原子替换前经 `PathGuard` 复核真实路径与重解析点。
- 保存冲突：显示“文件已被外部修改”，提供“覆盖保存”“重新加载”“取消”，默认“取消”。覆盖写入并更新基线；重新加载丢弃本地修改；取消保留。
- 工作区侧只读、折叠或冲突快照模式：`Ctrl+S` 不执行、不报错。
- 不提供另存为、部分保存、差异块级保存或 Git 写操作。

### HEAD 刷新与外部修改

HEAD 刷新：

- 触发：仓库元数据（HEAD、当前分支引用、索引、packed-refs）变化后 300ms 去抖；面板激活时距上次超过 10 秒；每 10 秒周期复核。
- 读取当前 HEAD 路径内容；重命名条目的 HEAD 侧始终读取打开时捕获的原路径。
- 内容未变不更新视图；变化则替换 HEAD 侧并按顶部可见行锚定滚动，立即重算。
- HEAD 中路径消失：HEAD 侧“该文件已不在 HEAD 中”空态，工作区全部行按新增显示；重新出现自动恢复。
- 读取失败：HEAD 侧“无法读取 HEAD：〈原因〉”与重试；工作区保持可编辑，差异暂停并显示“差异可能过时”。
- 刷新超过 500ms 在面板级提示“正在刷新 HEAD…”，完成后消失。
- 刷新不覆盖、不询问工作区未保存修改。

工作区外部修改：

- 通道：工作区路径事件（去抖 200ms）、面板激活复核、每 10 秒周期复核。
- 自身保存产生的变化按写入内容/版本忽略一次；只读元数据不触发重载。
- 磁盘与基线一致：无变化。
- 干净 + 变化：静默整份重载，更新基线，立即重算，按顶部行锚定滚动。
- 脏 + 变化：栏级“文件已被外部修改”，提供“重新加载”“保留本地”；保留后同一份磁盘内容不重复提示，再次变化重新出现。
- 外部删除：干净时工作区进入删除态并提供“重新创建”“关闭面板”；脏时提供“重新创建（保存当前缓冲）”“丢弃并关闭”“取消”；文件重新出现时退出删除态。
- 读取失败：“无法读取工作区文件：〈原因〉”与重试，不替换内容、不丢脏状态。
- 外部重载整份替换，不合并、不做三方冲突解决。

### 重命名跟随与移出仓库

- 工作区文件在同一仓库实际根内重命名/移动：更新工作区路径参数；HEAD 侧保留原路径；新路径在项目根内保持可编辑，项目根外、仓库内切换只读；保留缓冲、脏状态、光标、选择、滚动，立即重算。
- 标题使用当前文件名并标注原文件名；列头更新为 `HEAD · <原路径>` 与 `工作区 · <新路径>`。
- 文件移出仓库实际根：显示“文件已移出仓库”，工作区不可读写；提供“关闭面板”“重新打开”。重新打开按当前文件位置解析。
- 移出仓库或根外只读且存在未保存修改时，关闭确认不提供“保存并关闭”，只提供放弃与取消；移回项目根后恢复可编辑与保存。
- 无法关联新路径：按删除态处理；新路径已被另一 Diff 面板占用时不跟随，按删除态并提示路径已占用。
- 大小写变化视为同一路径，仅更新显示与参数。

### 冲突快照对比

- 左侧为冲突检测时磁盘版本只读快照，右侧为打开时当前缓冲只读快照；两侧不可编辑、不可保存、无脏状态。
- 冲突快照是瞬态 Diff 面板：有独立 `PanelId`，不持久化、不入布局、不参与去重，重启消失。每次“查看差异”新建快照并关闭旧快照面板；源面板关闭或冲突解决时也关闭快照面板。
- 标题 `〈文件名〉(冲突差异)`。
- 不读取 HEAD，不随 HEAD/磁盘/缓冲变化自动刷新；显示“快照不会自动更新”。
- 支持并排/行内、行标记、滚动同步、换行、查找、`F6`/`F7`、交换与单侧折叠；不支持保存、暂存、回滚或任何 Git 写。
- 快照只存在运行期，不写 `layout.json`、不入布局、不参与去重；关闭面板时清理；不参与编辑器/Markdown 保存冲突处理。
- 快照模式下本文 `HEAD` 侧对应磁盘快照，`工作区` 侧对应当前缓冲。

### 大文件与二进制

| 条件（按磁盘字节） | 行为 |
|---|---|
| ≤ 1 MiB | 正常编辑器视图 |
| > 1 MiB 且 ≤ 10 MiB | 正常视图；栏级提示“大文件（约 N.N MB），编辑可能影响性能”；工作区仍可编辑 |
| > 10 MiB | 该侧虚拟化只读视图；提示“只读浏览（约 N.N MB），可编辑上限 10 MiB” |

- HEAD 侧按 Git 对象字节大小，工作区侧按文件字节大小，两侧独立判定；界面按 MiB（1,048,576 字节）显示一位小数。
- 大文件提示条不属于文档内容，不加前缀、不计行号、不写盘。
- 只读视图按需加载、支持滚动/选择/复制/查找/字号/换行，不提供编辑、保存与脏状态；参与行对对齐与同步滚动。
- 差异计算超过 2 秒或不可用：先显示正文，栏级“差异计算超时，未显示行标记”，不显示标记与占位，两栏独立滚动；完成后自动补齐。
- 工作区侧超过 10 MiB 时不存在未保存状态，关闭不触发确认。
- 二进制：任一栏判定为二进制即不显示标记与占位，工作区不可编辑；该侧居中显示“二进制文件，无法进行文本比较”与“用默认程序打开”，另一侧仍可浏览。
- `用默认程序打开` 仅外部查看：工作区打开当前文件，HEAD 写入系统临时文件后打开；不作为编辑或保存通道。
- 文件大小无法取得时按已读字节估算并标注“约”。

### 焦点、键盘与参数持久化

- 显式打开或激活时焦点进入工作区可编辑侧；工作区只读时进入 HEAD 侧；两侧都不可聚焦时停在面板容器。
- 从 gutter 打开：光标放在被点击差异块对应行；从 Commit 打开：第一个差异块第一行。
- `F6`/`Shift+F6` 切栏（行内视图切 HEAD/工作区上下文）；跳过折叠侧；`F7`/`Shift+F7` 逐处差异并同步滚动，首尾循环；无差异时页脚“无差异”，`F7` 不移动。
- 当前差异块高亮，页脚“第 N / M 处差异”。
- 工具栏：视图模式、左右交换、单侧折叠；面板菜单：重新加载、同步滚动、自动换行、忽略行尾空白、忽略全部空白、折叠未变更区域、复制路径。
- 单击行标记/差异块定位并高亮，再次单击取消；空白占位不响应。
- 字号为全局编辑器字号，`Ctrl+滚轮` 调整；`Alt+Z` 两栏或行内同时切换自动换行。
- 参数持久化：视图模式、换行、同步滚动、列宽比例、折叠侧、左右交换随项目布局保存；文件参数默认模式随布局恢复，冲突快照不恢复。关闭重开恢复默认（并排、换行关、同步开、50/50、无折叠、无交换）。光标、选择、滚动、当前块、提示、删除/移出态、空白忽略开关、未变更区域折叠为实例内临时状态，关闭重开/重启重置。

### 错误映射

| 场景 | 行为 |
|---|---|
| 初始加载 | 整面板“加载中…”，不显示双栏与标记 |
| 两侧读取成功 | 双栏 + 异步差异，期间“差异更新中” |
| HEAD 读取失败 | HEAD 侧错误与重试；工作区可用 |
| 工作区读取失败 | 工作区侧错误与重试；HEAD 可浏览 |
| 两侧失败 | 整面板错误，列出两侧原因与重试 |
| 差异失败/超时 | 面板级/栏级提示，保留正文；超时无标记并停同步 |
| 保存失败 | 栏级“保存失败：〈原因〉”，保留脏状态 |
| 参数越界 | 整面板“无法打开文件：〈原因〉”，不读取根外路径 |
| 权限/占用 | 具体读取或保存原因，不合并文案 |
| 只读侧部分读取失败 | “部分内容读取失败”与重试，已读部分可浏览 |

### 模块树与复用/重建

```text
领域 core crate
  panels/diff/
    params.rs
    model.rs            # DiffModel/AlignedRow/DiffBlock
    engine.rs           # 行差异、块合并、行配对、空白选项

slterm_app/src/panels/diff/
  panel.rs
  view.rs               # 双栏/行内虚拟化视图
  side_editor.rs        # 工作区侧编辑（复用 editor 缓冲）

  worktree_watch.rs
  toolbar.rs
  dialogs.rs
```

复用：`git` 服务（仓库根、status、`head_file`、`file_hunks`、冲突三方对象）、`atomic_file`、`Document`/`TextSnapshot` 的载入与保存语义、`text_document` 的 BOM/行尾往返、编辑器 `TextBuffer`/`EditHistory`/`SearchState`、`EditorThemeTokens`。重建：现有 `DiffTabView` 的双 `InputState` 只读实现（无行对齐、无可编辑、无同步、无 HEAD 刷新与大文件分级）、`CodeTabView` 的 Diff 模式包装、`MergeTabView`（删除）。

### 测试接缝

- 纯函数：差异块合并、修改块配对、删除锚点、行尾/空白忽略、统计。
- 行对几何：左右高度取大、占位补足、字号/换行/列宽变化即时重排。
- 同步滚动：逻辑行对映射、单向同步无回环、横向独立、停用条件。
- 保存：干净保存、冲突三选一、保存中外部写入、只读/折叠不保存。
- HEAD：300ms 去抖、激活 10 秒、周期复核、路径消失/恢复、读取失败、最后结果胜出。
- 外部：干净重载、脏提示、保留/重载、删除/重建、重命名/移出/占用。
- 大文件：1MiB/10MiB 边界、二进制、只读虚拟化、2 秒超时。
- 虚拟窗口：F6/F7、交换/折叠、行内视图、参数持久化与关闭重开默认。
- 人工豁免：行对对齐观感与同步滚动舒适度。
