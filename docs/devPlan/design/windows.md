# Windows 服务、更新与发布

> 规定套餐查询、托盘、窗口、通知、语言、诊断、清理和更新移交的平台适配边界。

## 决策与红线

### WindowsIntegration 与窗口

- application 只经 `WindowsIntegration` 访问托盘、登录启动、材质、窗口几何、系统通知和任务栏；业务模块不得直接调用 Win32 或读取注册表。
- 托盘提供恢复窗口与退出；最小化仍到任务栏，关闭窗口始终走 CloseCoordinator，不提供关闭到托盘。静默启动只用于登录自启且依赖托盘可用，手动再次启动走单实例移交。
- 开机启动状态同时显示应用设置与 Windows 实际启动项；外部修改后重新对账，不用设置值伪造实际状态。托盘不可用时禁用静默驻留并说明，退出语义不变。
- 窗口尺寸、位置、最大化和显示器信息按机器保存；启动把离屏几何夹回当前可见工作区，DPI、显示器移除和工作区变化后保证标题栏与主要操作可达。跨机备份不直接应用几何。
- 材质固定为无、Mica、Mica Alt、Aero、Acrylic，默认无；平台或渲染能力不支持时禁用并说明，不改变主题 token，不宣称静默生效。GPU 不可用时允许软件渲染，功能不变。

### 套餐余量

- 只保留 DeepSeek、Kimi 两个内置来源，每来源最多一份启用配置；不提供自定义 Provider、模型管理、连接测试或 AI 助手。每个来源有固定 HTTPS endpoint、请求构造器、响应解析器和独立 CredentialFacade 目标。
- DeepSeek 使用 `GET https://api.deepseek.com/user/balance`，从 `balance_infos[0]` 读取金额与货币；Kimi 使用 `GET https://api.kimi.com/coding/v1/usages`，读取冻结态、5 小时和 7 天窗口及重置时间。两者使用 `Authorization: Bearer`，不读取 CLI base URL 或 token。
- 请求禁止自动重定向，响应上限 1 MiB，总超时 8 秒；响应解析只接受明确字段，失败保留旧结果并标错，不把缺失数据伪造为 0。
- `PlanBalanceService` 按来源维护配置、在途代次、最后成功时间、结果、下次计划时间和错误。自动与手动共用查询链，单来源防重入；手动全量刷新从实际发起时间计算 5 秒冷却。
- 后台默认启用、周期 60 秒，可配置 30–3600 秒；导航隐藏仍调度，退出后停止，结果只存内存，重启重新拉取。导航可见性只影响界面更新，不影响调度。
- 过期由当前周期、计划执行时间和来源响应状态判定：错过完整调度周期且仍无新成功结果才标过期；请求尚未达到自身超时且未错过该周期时保持查询中。失败不推进最后成功时间。
- token 替换、删除或来源配置代次变化使在途结果失效；旧结果不得回填。页脚文案优先冻结、金额、双窗用量、`--`，失败和过期同时有文字或图标。

### 通知、任务栏与语言

- `NotificationCenter` 按资源身份和代次去重，分别判定系统通知、任务栏闪烁和应用内反馈；桌面总开关只控制系统通知，应用内错误仍显示。
- 类别固定为任务完成、等待输入、权限请求和错误；任务栏闪烁独立且只在窗口失焦时触发，重新聚焦可清理等待提示，应用内错误保留到解决或关闭。
- 任务栏优先级为错误 → 等待输入暂停态 → 工作不确定进度 → 清除；高优先级不被低优先级覆盖，不伪造百分比，任务结束、取消和退出清理进度。
- typed i18n 键集在构建期校验缺键与多键；语言为 System、English、简体中文，System 或缺译回退 English。切换只替换目录并重绘，不重建工作区、不丢失修改；文件、终端、CLI、路径、协议字段和日志不翻译。

### UpdateService 与 handoff

状态机固定为：

```text
Idle → Checking → Available → Downloading → Ready → AwaitingClose → Handoff
```

失败携带检查／下载代次并可重试；自动检查默认开，后台下载默认关，手动检查始终可用。

- 仅直接安装形态自动安装；便携版和外部托管只提供手动下载。资产精确匹配版本、Windows x64 和 setup 类型，完整 SHA-256 缺失即拒绝，不自动降级或执行来源不明资产。
- 下载写入 `.part`，校验长度、512 MiB 上限、PE 头和完整哈希后原子改名；下载不等于安装，失败保留当前可用版本。
- 安装确认必须经 CloseCoordinator，先完成 Document、Hooks、PTY 和最终状态提交；最终状态提交失败取消 handoff，不以更新为由杀进程。
- handoff 计划带版本、PID＋进程创建时间、旁置锁、旧版回退和启动对账；更新移交有自己的退出后日志。新版本成功启动后才标记成功，启动或安装失败保留／恢复旧版本并提供重试。
- 不保存代理凭据，不清除用户数据修复更新，不让安装器直接删除数据目录。

### 诊断与清理

- `DiagnosticService` 从结构化健康快照生成白名单清单；复制诊断与导出共用 DTO 和脱敏链。默认包含版本、系统与运行能力、脱敏日志、错误码和健康状态。
- 默认路径只显示类别或稳定散列，完整路径须显式选择；预览实际条目、大小和脱敏内容，不承诺识别所有秘密。默认不包含历史、终端输出、文件正文、AI 会话、剪贴板、快照、恢复点、备份、原始内存转储或凭据。
- 环境自检异步执行，显示通过、失败或不可用及原因并可重跑；诊断失败不变成空报告。
- `CleanupService` 采用计划／执行两阶段，由各所有者提供候选和活跃排除代次；只清理可安全重建的旧日志、已完成更新下载和不再承担恢复职责的崩溃现场。
- 活跃恢复快照、恢复点、历史隔离区、设置、项目、CLI 文件和进行中任务占用文件永不进入普通清理。审计日志与普通缓存分开确认，禁止目录通配猜测删除，部分成功逐项报告。

### 发布链

- 正式发布只走 `scripts/release.ps1 -Version <X.Y.Z>`，发布清单、体积预算、许可与首发核验遵守 `.claude/docs/release/packaging.md`。
- 发布只收 Runtime v2 schema、参考文档和当前资产；旧 handover schema、v1 文档和旧 token 发现格式不得进入包。
- 全量语言、grammar、AVIF 静态链接和许可 notice 先测新基线，再按发布规则说明并重钉体积预算；不为旧预算擅自裁剪规格能力。

## 验收与测试

- 假 WindowsIntegration 覆盖托盘、启动项外部变化、材质不支持、离屏几何、通知开关、任务栏优先级和语言切换；真实桌面项按豁免登记人工核验。
- 本地 HTTP 测试覆盖 DeepSeek／Kimi 请求头、固定路径、无重定向、响应上限、8 秒超时、解析失败和 token 不泄露；真实服务出网只作人工验收。
- PlanBalanceService 用假 Clock 与凭据端口验证单来源防重入、手动冷却、隐藏调度、过期判定、代次丢弃和退出停止。
- 更新测试覆盖资产精确匹配、缺哈希、长度／PE／哈希失败、`.part` 原子改名、便携版只下载、关闭失败和 handoff 对账。
- 诊断与清理测试检查白名单、脱敏预览、完整路径显式选择、活跃排除代次和审计独立确认；任何敏感材料不得进入 ZIP。
- 发布验收使用真实安装器、便携包和 `slterm.exe`，检查版本、架构、schema、许可、更新回退与无孤儿进程。

## 操作

- 新增 Windows 能力先加入 WindowsIntegration 端口、平台实现和假实现，再接入业务服务；平台分支只在封装模块。
- 新增后台任务同时登记 TaskService 作用域、设置元数据、调度与关闭路径；套餐和更新不得使用游离线程。
- 发布前按 `scripts/release-checklist.md` 人工核验，并将桌面或特殊权限不可自动化面登记到测试豁免。
