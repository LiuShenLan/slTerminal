# 导航树

> 目标态实现级设计；需求真值源见 docs/featureSpec，裁决见 ../../spec-issues.md。

> 导航树的数据模型、项目与会话操作、扫描与归属、删除撤销、搜索刷新、套餐余量，以及逐字段状态作用域。

### 模型与模块

app 侧导航视图：

```text
sidebar_host/views/navigation/
  mod.rs            NavigationView（SidebarView 实现）
  state.rs          NavViewState / 展开集合 / 滚动 / 搜索 / 多选
  rows.rs           NavRow 投影与排序
  project_ops.rs    添加、重命名、排序、重定位、移除请求
  sessions.rs       活跃会话投影与历史会话行
  scan_service.rs   扫描编排、取消、失败来源
  restore.rs        恢复/分支恢复编排
  delete.rs         删除事务与撤销
  balance.rs        套餐余量页脚
  render.rs / menu.rs
```

纯领域逻辑在 `slterm_workspace::sessions`：归属匹配、相对时间、删除账本、状态过滤。CLI 扫描适配器在 app 侧，因为需要文件系统与 `AgentKind`。

### 扫描与操作接口

```rust
pub trait SessionSource: Send + Sync {
    fn id(&self) -> &'static str;
    fn scan(&self, ctx: &ScanContext) -> Result<Vec<SessionRecord>, SourceError>;
    fn delete(&self, records: &[SessionRecord]) -> Result<DeletionReceipt, SourceError>;
}

pub struct SessionCatalog { /* 扫描结果 + 项目根索引快照 */ }

impl SessionCatalog {
    // 由工作区提供项目根索引；归属只做词法最深前缀
    pub fn replace(&mut self, scanned: Vec<SessionRecord>, roots: &ProjectRootIndex);
    pub fn rows(&self, project: Option<ProjectId>) -> Vec<HistoryRow>;
    pub fn project_of(&self, key: &SessionKey) -> SessionOwner;
}

pub enum NavCommand {
    ActivateProject(ProjectId),
    AddProject,
    RenameProject { project: ProjectId, name: String },
    MoveProject { project: ProjectId, to_index: usize },
    RelocateProject { project: ProjectId },
    RemoveProject(ProjectId),
    FocusActiveSession(PanelId),
    RestoreSession(SessionKey),
    ForkSession(SessionKey),
    DeleteSessions(Vec<SessionKey>),
    UndoDelete,
    RefreshAll,
    SetSearch(String),

```

- `SessionSource` 的 `id` 是稳定来源名，与 `AgentKind` slug 对齐；app 适配器负责把 `AgentKind` 映射为 `SourceId` 与品牌信息。
- 扫描结果与删除事务都只携带会话身份、路径、标题与时间，不携带正文；删除事务的隔离目录与启动清理由 app 服务执行，账本纯逻辑在 core。
- 导航视图只发 `NavCommand` 与 `WorkspaceCommand`，不直接改项目目录、布局或面板。

### 项目与会话归属

- 根路径归一：绝对化、分隔符统一、忽略大小写、去重复与末尾分隔符（盘符根除外），按路径段边界比较；创建/重定位时同时记录真实路径，文件访问边界用真实路径。
- 项目根唯一；允许嵌套根；历史会话 cwd 等于或位于项目根之下时归属，多个命中取最深前缀；cwd 为空、相对路径或无法匹配进入“未归属会话”。
- 归属只做词法匹配，不因目录暂时不可访问而漂移；目录不可访问在项目行显示警示，仍可重命名、排序、重定位、移除。
- 项目添加、重定位、移除后立即重算归属；未归属节点固定位于全部项目行之后，不参与排序。
- 活跃会话归属其终端面板所在项目；所有项目的活跃会话都显示，项目收起时项目行徽标仍计数。
- 活跃会话按最近事件时间降序实时重排；选中底色规则：焦点在活跃项目的终端面板时对应行，否则最近事件最新的活跃会话行；同一时刻最多一条。
- 终止、面板关闭、项目移除时活跃会话行实时消失；面板不可定位时通知 `会话已结束` 并移除或更新行。

### 项目操作

- 添加：系统文件夹选择框；取消无变化；根已存在则激活、展开并滚动到已有项目，通知 `该项目已存在`；新项目追加末尾、成为活跃、展开并滚动到可见；失败通知 `添加项目失败` 与原因。
- 重命名：项目行右键或 `F2`；内联编辑，原名全选；`Enter`/失焦提交，`Esc` 取消；空名或纯空白拒绝，失焦则恢复原名；最长 80 字符；显示名可重复；只改显示名，不改根、文件夹名、会话数据、面板标题、顺序与展开。写盘失败保留内存值并显示错误指示。
- 排序：项目行拖拽超过阈值显示插入线；`Alt+Up/Down` 与菜单 `上移/下移` 等价；边界项禁用；排序不改变活跃项目、展开与焦点。索引变更立即入队 `workspace.json`；写失败保留内存顺序并显示错误指示，不回滚已生效排序。
- 重定位：系统文件夹选择框；新根与当前根相同不写盘；与其他项目根冲突拒绝并通知；成功保留项目身份、显示名、顺序、布局、面板与展开；既有终端继续原 cwd；新终端与文件浏览器使用新根；立即重算历史归属。索引变更只写 `workspace.json`；写失败保持原根并通知。
- 移除：只发请求；确认与销毁由 shell 负责。索引先行：shell 先成功写 `workspace.json`（移除条目并更新活跃项目），失败则移除中止、项目保持；成功后才删除项目目录与恢复快照。导航行在索引写成功后移除，活跃项目按回退规则迁移；磁盘文件与历史会话记录保留；重新添加同一根路径后历史重新归属；无撤销。
- 项目右键菜单：`重命名 / 上移 / 下移 / 重新定位根目录 / 移除项目`；移除危险色。

### 活跃会话操作

- 单击/`Enter`：若所属项目非活跃先激活，再切到面板所在组并聚焦终端输入区；连续点击以最后一次为准。
- 右键菜单：`聚焦`、`复制恢复命令`、`关闭面板`。不提供“删除会话记录”。
- `关闭面板` 走 shell 关闭守卫；取消保留面板与会话；关闭后行消失、项目徽标减少，历史记录不受影响。
- `复制恢复命令` 仅 CLI 支持且命令非空时可用；成功 `恢复命令已复制`；空命令 `无法生成恢复命令`；剪贴板失败 `复制失败`。
- 菜单支持方向键、`Home/End`、`Enter`、`Shift+F10`/菜单键、`Esc`，禁用项跳过并显示原因。

### 历史会话

- 历史来源为各 CLI 历史记录适配器 + hook 会话索引；索引只存“如何重新找到会话”（source、id、cwd、原生文件、标题、最近时间），不复制正文。
- 扫描合并同 `(source, id)`，modified 取较新者，缺字段互补；结果按修改时间降序，时间无效排最后；结果上限 2,000 条。
- 状态三态：运行中（可靠关联到运行中 CLI 会话）、已完成（CLI 记录表明结束）、未知（无法确认，中性色，不得显示为已完成）。
- 标题取会话标题；缺失取 ID 前 8 位；ID 缺失显示 `未知会话`。悬停按序显示完整标题、CLI 名、工作目录、首条提示词预览（超过 200 字符截断）。
- 相对时间六档：`刚刚`、`N 分钟前`、`N 小时前`、`N 天前`、`MM-DD`（同年）、`YYYY-MM-DD`；无效 `-`；视图打开期间每 60 秒重算。
- 历史节点仅项目展开且总数大于 0 时渲染，默认收起；未归属节点同理；无内容不渲染占位。
- 多选：单击选中，`Ctrl+单击` 切换，`Shift+单击` 连续区间，`Ctrl+A` 全选可见历史行，`Esc` 清除；只作用于历史会话行；搜索变化、切换项目、关闭视图、行消失时清除；多选右键只提供 `删除所选（N）`。
- 双击行为：运行中且面板可定位 → 激活并聚焦；运行中但面板不可定位 → 对账、通知 `未找到运行中的会话`；cwd 缺失/不可访问/不是目录 → 打开 `会话目录不存在` 对话框；其他 → 恢复。
- 恢复流程：最深项目根命中或按 cwd 创建项目（显示名取目录最后一段，根唯一幂等）→ 激活、展开、滚动可见 → 终端面板创建并分配编号，初始标题取历史标题 → 终端就绪后注入恢复命令并回车（PowerShell 系最长 10 秒、cmd 约 0.5 秒，超时仍注入一次）→ 失败通知 `恢复会话失败`（含 ID 前 8 位与原因）并提供重试；已创建项目与面板保留，重试复用。
- 分支恢复：仅 CLI 支持时显示；基于原会话创建新分支，原会话不变；失败通知 `分支恢复失败`。
- 复制恢复命令：仅单行；不支持或空命令不写剪贴板；失败通知原因。
- `会话目录不存在` 对话框：显示标题/ID 与缺失目录；操作 `复制恢复命令 / 删除会话 / 关闭`；`Esc`/遮罩关闭并还焦原行。
- 运行中的历史会话不可删除；`Delete` 通知 `运行中的会话不可删除`。

### 删除与撤销

- 单条删除不确认：行立即消失、计数更新，显示 5 秒可操作通知 `已删除 1 个历史会话` + `撤销`。撤销统一走可操作通知，不另设 UndoBar。
- 批量删除先确认：标题 `确认删除`，正文 `确定删除 N 条历史会话？删除后 5 秒内可撤销。`；选中含运行中会话时自动排除并注明 `M 条运行中会话已跳过`；全部运行中时不打开确认框并通知。
- 删除执行体使用删除事务：把来源文件原子移入应用隔离目录、保存 hook 索引条目快照；撤销时原路恢复文件与索引，恢复原顺序。5 秒结束、撤销通知关闭、窗口关闭或应用退出后清除隔离文件，删除永久化；启动时清理上次遗留的隔离目录（视为永久删除）。
- 同一时刻只有一个未决撤销；新删除先永久化旧事务；撤销失败通知 `撤销删除失败`，删除保持永久。
- 删除/撤销结果持久化；刷新与重启后不重新出现；删除失败行保留或恢复并通知原因。

### 搜索

- 输入即过滤；首尾空白忽略，纯空白等同未搜索；大小写不敏感子串匹配。
- 匹配范围：项目显示名、项目根路径；活跃会话标题；历史标题或 ID 前 8 位、cwd、首条提示词；未归属行同样匹配。根路径与 cwd 匹配前做斜杠归一。
- 结果规则：项目自身命中显示全部活跃会话，历史节点显示但默认收起可手动展开；项目未命中但子项命中时项目派生展开且只显示命中子项；祖先命中链自动展开且不可收起（项目自身命中的历史节点除外）；未归属节点仅在存在命中时显示并派生展开。
- 清空搜索恢复搜索前手动展开状态；搜索词不写持久化，切换项目与刷新期间保留，关闭视图与重启清空。
- 高亮显示名、副行根路径、活跃/历史标题中的命中子串；悬停提示中的 cwd/提示词同样高亮；使用主题搜索高亮 token；不改变文本、截断、排序与匹配结果。
- 性能契约：1,000 条项目/会话行输入到结果更新不大于 100ms。
- `Ctrl+F` 聚焦搜索框；`Esc` 清空并还焦树；清除按钮保持焦点在搜索框；IME 组合期间不过滤。

### 刷新与自动扫描

- 手动刷新：重扫全部历史来源、刷新套餐余量、对账活跃会话；不重载项目列表；按钮进行中禁用、重复触发忽略；成功不通知、悬停显示 `上次更新 HH:mm:ss`；失败通知 `刷新失败` 与失败来源，旧数据保留。
- 自动扫描：仅视图打开时运行；默认 3 秒，可配置 2–300 秒；禁用后只手动刷新；首次打开先显示上次结果再扫描；关闭视图停止；展开/收起不触发扫描。
- 单一来源失败保留旧数据并标记过期；全部失败保留全部旧数据并显示错误指示；无旧数据时行内 `历史会话加载失败，点击重试`；自动失败不重复通知，只在刷新按钮旁显示警示图标，悬停列出来源与原因；下次成功后消失。
- 后台扫描配置读取失败：仍执行首轮与手动刷新，不启动周期扫描，显示配置错误指示。
- 关闭视图、退出应用时取消扫描、恢复与余量请求，不阻塞退出。

### 套餐余量页脚

- 复用 `plan_balance` 的静态来源表、查询、快照合并与 watch 推送；导航视图只负责展示、节流与显隐。
- 显示条件：后台任务启用且至少一个来源；页脚上方分隔线；禁用或无来源时整体隐藏。
- 每来源一行：14px 品牌图标 + 一行文案；不把来源名作为可见文本，悬停可显示。
- 文案优先级：冻结 `已冻结`；金额 `¥ / $ / 货币代码 + 原值`；双窗 `5h xx% · 7d xx%`；其余 `--`。
- 悬停：冻结原因、上次更新时间、5h/7d 重置时间；无数据区分 `查询中…`、`查询失败，点击重试`、`数据可能过期`。
- 点击/`Enter` 刷新全部来源；5 秒节流，窗口内禁用并提示 `刷新冷却中`；进行中显示进度；失败保留旧值、显示警示与原因，不弹阻塞通知。
- 配置未加载完成时页脚隐藏；配置读取失败显示 `余量配置读取失败，点击重试`。
- 视图关闭期间保留结果；重新打开立即显示，超过 30 秒未更新时刷新；后台任务禁用时保留最后结果，重新启用立即显示。
- 重置时间格式：小于 1 小时 `Xm 后重置`；小于 24 小时 `Xh Ym 后重置`（分钟为 0 时 `Xh 后重置`）；超过 24 小时 `M月d日 HH:mm 重置`；已过期 `0m 后重置`。
