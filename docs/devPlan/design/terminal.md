# 终端、可信输入与学习

> 规定每 PTY 单 worker、输出背压、Shell 行信任、补全编辑和独立学习库，确保界面、Runtime 与进程状态不分叉。

## 决策与红线

### TerminalSession 与 PTY 代次

- 每个存活 PTY 由一个 `TerminalSession` worker 独占 `slterm_terminal::Term`、网格和子进程交互。读取线程只转发有界字节块；解析、搜索快照、resize、输入写入和关闭都经该 worker。
- TerminalRegistry 只保存 TerminalId → PTY 代次、进程身份和通道端点；Panel、Runtime、ShellLineTracker 不直接持有 Term 或子进程句柄。进程退出保留画面与退出状态，不自动重连。
- 输出通道同时限制消息数和字节数：读取块以 64 KiB 为上限，队列最多 64 块且总字节不超过 4 MiB；命令通道有界并合并纯绘制通知。队列满时对 PTY 读取施加背压，不丢输出、不阻塞 GPUI 前台。
- 隐藏项目或 Panel 只暂停绘制，不暂停进程或丢弃字节；重新可见显示最新缓冲，不补放中间帧。回滚默认 10,000 行，可配置 1,000–100,000 行，只保留主屏历史，备用屏不进入普通回滚。
- resize 请求携带输出水位。worker 先处理水位之前已接收字节，再应用网格尺寸并通知 PTY；初始尺寸不可用用 80×24，容器就绪立即适配。
- 写入、重连、关闭和进程退出都使旧 PTY 代次失效。新输出按 revision 使旧搜索和 Runtime 读取结果失效；重连保留内存回滚并插入新会话分隔，不恢复原进程。
- 应用级存活 PTY 上限 64，只统计存活进程；已退出和懒启动记录不占额度。额度不足保留记录和重试，不丢既有终端。逻辑终端编号从项目持久化的 `next_terminal_number` 单调分配，删除记录不回退，跨重启不复用。

### Shell 与可信输入镜像

- 默认 Shell 自动探测 `pwsh.exe` → `powershell.exe` → `cmd.exe`，候选须成功创建并在 500 毫秒稳定窗内未退出。显式或自定义 Shell 失败不静默换 Shell；自定义只接受可执行绝对路径，不提供参数注入。
- 显式 cwd 优先于项目根，必须重新通过终端能力判定；未提供 cwd 使用目标项目根，不继承另一终端。Shell 内 `cd` 只跟踪最近 cwd，下一次新终端或恢复重新授权。
- core 只提供主屏／备用屏、PTY 代次、提示符边界、命令开始／结束、cwd、resize/reset 等语义事实。application `ShellLineTracker` 独占输入镜像，只有本地受支持 Shell、受管集成、主屏和完整提示符边界同时成立才信任。
- 镜像由本地输入与 PTY 回显共同校验；历史召回、方向键、Home/End、复杂 Readline、控制序列、resize/reset、备用屏、TUI 或前台程序接管输入使当前提示符代次失效。失效时不补全、不采集历史，直到重新建立完整边界。
- PowerShell 集成只传提示符与执行边界，不把命令正文放进 `OSC 133;C`。Enter 处理器发出的候选边界不能单独证明执行；Shell 适配器必须结合实际执行／完成边界和本地镜像对账后才写历史。没有确认、空行或被取消的输入不入库。
- cmd 只支持明确声明的简单行能力，复杂编辑和控制序列按不可信处理；历史恢复的约 0.5 秒等待只是注入协调，不是执行成功证明。未知 Shell 使用字面量解析，不猜测复杂语法、不通过 WSL。

### 输入、粘贴与终端搜索

- 普通按键编码发 PTY，`Ctrl+C` 永远发送中断，`Ctrl+Shift+C` 复制，`Ctrl+Shift+V`／`Shift+Insert` 粘贴；命令由统一目录解析，IME 组合不直接编码为终端输入。
- 粘贴优先使用前台程序支持的括号粘贴，不自动追加 Enter；危险控制字符或超过 50 行须确认，超过 10 MB 拒绝，确认框不展示剪贴板正文。
- OSC 8 只允许 http、https、mailto 经 Ctrl+单击打开，超过 8 KB 或其他协议拒绝；OSC 52 只写不读，按聚焦、活跃项目和显式设置授权，单条上限 1 MB。
- 回滚搜索只读当前可提供的画面与回滚，不写 PTY、不改变前台程序状态；新输出使旧位置和结果失效。搜索、选区和高亮不持久化、不进入日志、备份或诊断。

### CompletionService

- `slterm_completions` 只做 PowerShell、Cmd、Posix 和 Literal 方言解析、候选匹配与纯数据编辑计算；application CompletionService 统一调度，无全局静态历史。
- 候选来源固定为命令历史、目录历史、可执行命令、路径、Git refs／remotes 和项目脚本声明。项目脚本只静态读取 `package.json`／`pnpm-workspace.yaml`，不执行项目代码、不联网；单一来源失败只移除该来源。
- 请求携带 TerminalId、PTY 代次、Prompt 代次、输入 revision、cwd、方言和项目代次；任何变化取消旧请求并丢弃旧结果。
- `CompletionEdit` 携带预期输入代次、合法 UTF-8 替换区间、原文指纹和插入文本，应用前复核当前镜像。接受候选只修改当前输入，不附加 Enter；加载中候选不能被 Enter 当作已接受。
- Inline、Popup、Hybrid 只改变呈现；Right、Tab、方向键、Enter、Esc 的统一命令语义不因来源不同而分叉。

### learning.db 与历史采集

- 只从可信 Shell 行且经适配器确认实际执行的命令采集；目录事实来自受管 cwd 边界。备用屏、CLI 交互提示和不可信镜像不采集。
- 命令按 Shell 类型与文本去重，保存首尾使用时间、次数和最近 cwd；目录保存规范词法路径和 frecency 数据。容量为命令 5,000 条、目录 2,048 条，并设置字段长度上限。
- 学习库独立写连接与队列，不进入灾难副本、备份、普通导出、日志或诊断；补全显示开关与命令／目录采集开关彼此独立，不承诺识别命令或路径中的所有秘密。
- 清空递增学习代次、取消待写、清内存并事务删除，再截断 WAL／压缩；失败保留可见错误。损坏或高版本暂停持久学习并提供显式重置，不覆盖原库。

### 恢复与 CLI 信号

- 应用重启恢复所有未关闭逻辑终端记录、编号、自定义标题和 cwd；自定义标题最长 128 字符且优先于 CLI 标题。输出、回滚、搜索和选区不恢复。可见且关闭前处于运行条件的终端自动创建 PTY，隐藏终端懒启动，已退出终端只恢复退出状态和重试。
- 恢复或重连按确定性顺序检查存活上限；失败保留 Panel、错误和重试，不创建重复记录。保存 cwd 失效只能按恢复例外回退目标项目根并提示。
- CLI 状态由命令边界、hooks 和状态信号更新；普通命令不伪造工作／注意／完成状态。自定义标题优先于 CLI 标题，CLI 运行中不可重命名。
- 历史恢复只注入经 AgentCatalog 能力校验的命令，等待 Shell 就绪：PowerShell 最长 10 秒，cmd 约 0.5 秒；超时仍只尝试一次，失败保留 Panel 与重试，关闭或退出取消注入。

## 验收与测试

- 真实 ConPTY 测试覆盖 UTF-8 跨块、洪峰背压、隐藏输出、主／备用屏、resize 水位、进程退出、重连和 64 个存活上限。
- ShellLineTracker 测试覆盖本地输入与回显不一致、历史召回、方向键、Readline、TUI、resize/reset、空行和取消；任何不可信状态都不得补全或写历史。
- 检查 PowerShell 集成 fixture：`OSC 133;C` 不含命令正文，只有执行确认对账后才产生学习记录。
- 补全测试覆盖方言、来源失败、cwd／输入／PTY 代次变化、CompletionEdit 原文复核和接受后不自动执行；项目脚本只读静态声明。
- 学习库测试覆盖去重、frecency、容量、字段上限、清空取消待写、损坏暂停和备份／诊断排除。
- GPUI 测试验证粘贴确认不泄露正文、OSC 52 权限、搜索零 PTY 写入和恢复懒启动。

## 操作

- 修改 PTY 读写、resize 或重连必须同时更新代次、背压和真实 ConPTY 测试，不得只在视图层加锁。
- 新增 Shell 适配器先声明可信边界、执行确认和失效条件，再开放补全或历史采集。
- 新增候选来源必须证明本地、静态、可取消，并加入单来源失败和备份排除测试。
