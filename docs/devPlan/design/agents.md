# Agent 目录、会话与历史隔离

> 以 AgentCatalog 统一 CLI 身份、命令和适配能力，以终端事件派生活跃会话，以隔离批次保证历史删除可恢复。

## 决策与红线

### AgentCatalog 与 AgentRoot

- `slterm_agents` 拥有唯一 AgentCatalog。每项声明 AgentKind、slug、显示名、内置命令与别名、AgentRoot、原生会话 ID 校验、命令构造器、历史适配器和 Hooks 适配器标识；UI、Runtime 和恢复流程不得各自维护 CLI 名单。
- 目标目录保留既有 AgentKind：

```text
Claude, Codex, Gemini, Aider, Amp, OpenCode, Copilot, Cursor,
Goose, Droid, Pi, Auggie, Hermes, Vibe, Antigravity, Grok,
Qwen, OhMyPi, Cline, Devin, Kimi, Kiro, Kilo, Qoder, Maki,
Trae, CodeBuddy
```

- 保留各 CLI 已声明的恢复与分支能力；命令构造器分别处理 start、resume、fork，并对原生会话 ID 做严格校验。恢复／分支能力不等于历史扫描能力，未声明历史适配器的 CLI 不展示猜测记录。
- 内置命令与自定义别名在 Windows 大小写规则下共享唯一命名空间；别名非空、最长 32 字符，不含空白、引号或反引号且不以 `-` 开头。配置变更立即影响后续识别，不改写既有历史身份。
- AgentRoot 有稳定 AgentRootId、显示名、规范目录和独立 read／write／terminal 能力。默认只读且禁止终端；真实目录查重失败拒绝注册或改路径，不用显示名作授权依据。
- 内置根不可删除或改路径；自定义根改路径按撤销旧根＋登记新根处理。删除根只移除配置并撤销授权、停止监听，不删除磁盘文件或强制终止既有 PTY。

### 活跃会话与历史扫描

- 活跃关联由 TerminalId、PTY 代次、AgentSessionKey、适配器事件和最近事件时间共同证明。TerminalRegistry 是唯一 PTY 映射，Agent 服务订阅其事件，不另存持久活跃映射。
- 纯 Shell 不建活跃会话行；同项目按最近事件排序，未知或过期用量显示 `--`，不以套餐余量代替 CLI 会话用量。
- 原生历史扫描只接入明确的 Claude／Codex 适配器；其他 CLI 只有声明适配器后才展示。扫描只读取本地既有记录，不建立另一份长期会话正文库。
- `HistoryRecordKey { agent_kind, native_session_id, adapter_version }` 是历史身份。记录保存来源位置、修改时间、cwd、标题、状态和首条提示词预览等有限元数据；正文只在必要时有界读取，不进入日志、备份或诊断。
- 历史归属使用 PathPolicy 词法 deepest-match；空、相对或无匹配 cwd 进入未归属，目录暂时不可访问不改变归属。来源读取失败保留旧来源数据并标错，不当作空历史或触发隔离永久化。
- 自动扫描只在导航树可见时调度，周期由设置注册表提供；隐藏后停止，重新可见先显示上次结果再扫描。手动刷新重扫来源并对账活跃会话，不重新加载项目列表或清除展开／搜索。

### 恢复与分支

- 双击运行中且可定位的会话只聚焦既有终端；其他可恢复会话使用 AgentCatalog 的 resume 构造器，不支持时明确提示且不创建 Panel。
- 已匹配项目复用该项目；未归属且需要创建项目时，先显示目标根并取得交互用户明确确认。Runtime 不获得这项隐式创建能力。
- 保存 cwd 失效时，只能在已确定目标项目内回退项目根并提示；项目根也无效则失败。未归属且 cwd 不可用打开目录不存在对话框，不改用其他目录。
- 恢复任务以 AgentSessionKey、目标 ProjectId、动作和根代次去重。先创建目标终端，再等待 Shell 就绪并注入经校验的命令；PowerShell 最长 10 秒，cmd 约 0.5 秒，超时仍只尝试一次。
- 注入失败保留已创建 Panel、错误和重试，重试不重复创建项目或逻辑终端；目标项目在恢复期间被移除则失败，不自动重建。分支复用同一 cwd、授权和失败语义，原会话不变。
- 活跃 Agent 对外 ID 关联多个终端或原生 ID 重复时，快照展示全部关联；写入必须提供可唯一定位的 Terminal／PTY 代次，否则返回 ambiguous_target，不按标题猜测。

### 历史隔离批次

每次确认删除形成独立 BatchId 与逐项清单，执行顺序为：

```text
Prepared
→ 写入并校验隔离副本
→ 复核来源指纹后删除来源
→ 提交完成时间与该批 5 秒绝对撤销期限
```

- 清单记录原始位置、列表顺序、AgentSessionKey、来源身份、前后指纹和副本位置。未成功隔离且仍在原位置的项不隐藏，也不属于撤销集合。
- 副本完整后才移除来源；部分失败列出失败项，不把整批伪装成功。完成时间提交后才启动绝对期限，提示悬停、聚焦、关闭视图、退出或重启不延长也不提前永久化。
- 启动先于历史展示对账：完整隔离项继续隐藏并归入原批次，未完成项保留或恢复来源；缺少完成时间或状态不明的批次保留全部可用副本并进入 NeedsAttention。
- 撤销以批次为单位，先全批预检期限、状态、副本完整性、目标不存在和来源指纹；任一失败不恢复任何项。执行异常保留双份材料并标记待处理，不伪装成功。
- 到期清理只处理已完成且无待处理错误的批次；失败批次可重试或导出 ZIP 原子文件。导出后仍须显式永久删除确认，导出本身不清除材料。
- 隔离区只保存用户明确删除的历史材料，不主动扫描或复制其他 CLI 数据；不属于备份、普通导出、日志或诊断。Runtime 不提供历史删除方法。

### Agent 文件树

- Agent 全局文件视图使用 AgentRoot 集合和共享 FileTreeModel，内置根按目录注册顺序、自定义根按添加顺序排列；所有根共享一棵树和一个滚动区。
- 根层显示过滤只影响显示，不是授权边界；被过滤条目不展开、不读正文、不启动私有监听。自定义名单只匹配根层完整名称，大小写不敏感，不支持路径或通配符。
- 文件打开、内部剪贴板、重命名、删除和粘贴复用 Explorer 与 FileOperationService；跨根复制逐项判定，跨根剪切拒绝。打开和新建终端落点为活跃项目，不隐式创建项目。
- 根删除或改路径后清理其专属 ViewState 分区，其他根、共享 Document 和内部剪贴板不受影响；既有 Document 保留内容并停止该根刷新。

## 验收与测试

- AgentCatalog 测试覆盖全部 AgentKind、别名冲突、命令构造、会话 ID 校验和恢复／分支能力矩阵；未声明历史适配器不得出现扫描结果。
- 用假终端事件验证活跃关联随 PTY 代次失效，纯 Shell 不建行，重复原生 ID 的写入返回 ambiguous_target。
- 历史扫描测试覆盖 cwd 最深匹配、无效时间、来源损坏、外部删除、预览上限和读取失败不清空旧结果。
- 恢复测试覆盖项目确认、cwd 回退、Shell 就绪超时、重复恢复、注入失败重试和项目中途移除；不得产生重复逻辑终端。
- 隔离测试在副本写入、来源删除、完成提交、撤销预检和永久化边界终止子进程，验证双份材料、5 秒绝对期限和 NeedsAttention。
- Agent 文件树测试覆盖能力并集、链接重定向、跨根操作、过滤不授权和根删除后的任务回收。

## 操作

- 新增 CLI 必须先登记 AgentCatalog、Root、命令与适配能力，再接入导航、Runtime 或 Hooks；不得先在 UI 加名称后补身份。
- 新增历史适配器必须声明版本、记录身份、来源指纹和隔离恢复器，适配器版本变化不能静默混用旧记录。
- 隔离材料只能由 HistoryQuarantineService 读写；导出、清理和诊断不得扫描其他 CLI 目录。
