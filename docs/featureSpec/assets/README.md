# 功能规格资产

> 说明功能规格所用图标与品牌资产的用途、预览和许可边界；资产集合与实现引用以仓库实际文件为准。

## 用途

- `icons/` 保存界面 SVG 原图；`cli-svg/` 保存 CLI 与套餐来源品牌 SVG；`brand/` 保存应用图标。
- `preview/` 只用于深色文档预览，不替代原图，也不是运行时主题或颜色 token 的来源。
- 正文可嵌入少量代表性资产说明样式；完整资产清单、尺寸和实际引用不在本文手工镜像。
- 品牌资产只用于识别对应 CLI、套餐来源或应用，不表示其能力、认证状态或合作关系。

- 项目自绘图标许可随项目；自绘窗口控制图标与通用文件图标同样适用。
- Cursor 与 GitHub Copilot 图标的 LobeHub MIT 声明收录于仓库根 [THIRD-PARTY-NOTICES](../../../THIRD-PARTY-NOTICES)。
- 其他 CLI 品牌 SVG 由项目作者逐文件确认可用于本文档与随包分发；文件本身不含许可证头不等于无许可。

## 预览边界

- 预览资产由受控生成流程从原图派生并校验，不手工维护第二套图形。
- 需要预览的单色或灰度资产可调整为深色文档可读的固定预览色；路径数据和原始资产不得被手工改写。
- 彩色品牌图直接使用原图，不为追求暗色背景而重绘品牌色。
- 预览转换只服务文档显示；产品运行时仍通过主题语义 token 着色，不继承预览色。
