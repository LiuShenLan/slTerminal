# 文件浏览器

> 拥有活跃项目文件树、文件操作、名称过滤、Git 状态展示和树内剪贴板；授权由 [PathPolicy](../path-policy.md) 判定，Document 与面板路由由各自所有者定义。

## 树根与加载

- 树根固定为活跃项目 ProjectRoot；无项目时显示“选择一个项目以浏览文件”，过滤、忽略开关和刷新禁用。
- 切换项目立即切换根并丢弃旧读取结果；各项目按 `ProjectId` 恢复自己的展开、当前行和滚动。根重定位后使用新根重新加载，不把旧根事件回填。
- 根不可访问时显示分类错误与重试，不显示空目录。根暂时不可访问不改变项目身份或历史归属。
- 目录按需分批读取，文件夹在前、文件在后，同类按名称不区分大小写稳定排序；根层默认折叠。
- 首次读取显示加载态；子目录失败保留展开并显示行内重试；部分批次失败保留已加载条目，不伪装为空目录。
- `.git` 文件或目录始终隐藏，其他点号条目正常显示。Git 忽略条目默认隐藏，可由按项目保存的“显示忽略文件”开关显示。
- 展开记录只针对仍存在的目录；已加载目录重新展开时可先显示缓存并后台复核，旧代结果不得覆盖新根或新过滤。

## 行、选择与键盘

- 行高 24、每层缩进 16、图标 14，均为逻辑像素。名称单行截断，悬停显示完整名称；树只纵向滚动。
- Git 状态同时使用语义色、行尾字母和文本：修改 M、新增 A、未跟踪 U、删除 D、重命名 R、冲突 C、忽略 I；类型色块不被状态色覆盖。
- 当前行与选中集分离。单击单选，`Ctrl+单击` 切换，`Shift+单击` 选范围；`Ctrl+A` 选全部可见项，`Ctrl+Space` 切换当前行。
- 方向键移动并重置选择，Shift+方向键扩展范围；Right／Left 展开、收起或进出层级，Home／End 到首尾。树是单一 Tab 停靠点。
- 选中集包含祖先和后代时，批量操作按最顶层项去重；同一路径只处理一次。
- 右键选中集内行保持多选，右键集外行改为单选。多选时 `Enter` 不打开文件，双击也不因第二次点击意外打开。
- 当前路径消失时移到下一个可见同级项，其次上一个；消失项从选中集移除。焦点离开树后树命令不再响应。
- 文件打开、删除、重命名、复制、剪切、粘贴和刷新进入统一命令目录；树导航键属于固定导航参考。IME 组合期间不派发树命令。

## 打开与定位

- 双击文件、单选文件按 `Enter` 或右键“打开”使用统一文件路由；落点为活跃项目聚焦 PanelGroup，无组时创建首组。
- `.md`／`.markdown` 首次默认 Markdown 渲染态，其他文本按 Editor；扩展名只决定首次默认视图。重复打开按 `ViewKey` 聚焦，不新建重复 Panel。
- 文件身份由 Document 全局去重；不同项目可建立引用同一 Document 的独立视图，不复制实时缓冲。
- 打开失败不留空 Panel 并显示原因；恢复失败与显式新建失败按工作区不同规则处理。
- 目录 `Enter` 或双击只切换展开；多选不打开。
- Commit 可请求定位项目根内文件。定位前校验活跃项目与 PathPolicy；视图不可见时先恢复显示。
- 定位不修改过滤或忽略开关；目标被它们隐藏时失败并提示。祖先临时展开不写入持久状态，成功后目标成为唯一选中、当前行并滚动可见。
- 目标缺失、越权或项目已切换时保留原状态并返回失败；焦点按统一还焦链返回发起方。新定位或视图关闭取消旧请求。

## 新建与重命名

- 文件夹菜单和根级空白菜单提供新建文件／文件夹；新建只落在触发目录。重命名通过 `F2` 或菜单，仅支持单项。
- 内联输入 `Enter`／失焦提交，`Esc` 取消；关闭视图或重启直接清除未提交编辑，不因实例销毁自动提交。IME 组合期间不提交或取消。
- 名称去除首尾空白，长度 1–255；不得含 `\ / : * ? " < > |`，不得为 `.`／`..`、尾随点或空格，也不得使用 Windows 保留设备名。
- 同目录重名按 Windows 大小写规则拒绝；仅大小写变化允许重命名。校验或磁盘失败保留输入，未发生写入。
- 新建文件为 0 字节，新建文件夹为空目录；成功后展开父目录并选中新项。
- 重命名只改目标路径，不重建引用它的 Document 或 Panel；打开文档的位置更新由 Document 统一处理。原展开状态迁移到新路径。
- 写前按 PathPolicy 重新解析父目录与目标，任何链接重定向或授权失效都中止，不沿用打开树时的旧授权。

## 删除

- `Delete` 或菜单作用于整个选中集，一次聚合确认；项目根本身不是树行，不能从本视图删除或重命名。
- 删除优先移入 Windows 回收站。任一卷不支持时明确披露将永久删除并再次确认；取消则不修改任何项。
- 执行前逐项重新校验真实目标、写授权和当前状态；符号链接或目录联接不得把操作传递到未授权目标。
- 批量逐项执行，可部分成功且不回滚；成功项移除，失败项保留并汇总错误。目标已被外部删除可视为该项已完成。
- 删除目录会处理其内容，确认文案必须明确；权限、占用和系统失败可见，不静默重试覆盖。
- 删除已打开文件不强制关闭 Document 视图；其内容保留和失读、失写行为由 Document 与 PathPolicy 决定。

## 路径、终端与内部剪贴板

- “复制相对路径”输出相对项目根的 `/` 分隔纯文本；多选按可见顺序每行一个。它与内部文件剪贴板及系统剪贴板写入分开。
- “在终端中打开”：文件使用父目录，目录使用自身，每次请求独立逻辑终端。cwd 必须仍有终端授权；非法或未授权时拒绝且不留空 Panel，不回退其他目录。
- 内部文件剪贴板为应用级会话状态，与系统文本剪贴板分离，可由文件浏览器和 Agent 文件树写入；切换项目或关闭视图不清空，重启清空。
- 复制允许跨根，但每次粘贴分别校验源读授权和目标写授权。剪切移动只允许同一根内，跨 ProjectRoot、跨 AgentRoot 或两类根之间均拒绝。
- 粘贴目标为当前目录、当前文件父目录或项目根；多选不分别向多个目录粘贴。禁止把目录放入自身或后代。
- 源与目标父目录相同则不执行该项并提示；源在粘贴前消失或被替换时该项失败，不创建空文件。
- 名称冲突一次聚合提供替换、跳过、取消，默认跳过。取消在开始前零修改；替换先把既有目标移入回收站，目录不合并，永久删除回退须再次披露。
- 批量粘贴可部分成功；成功项保留，失败项汇总，剪切失败项保留剪切态。文件替换采用原子写或等效可恢复步骤，不能把部分成功报告为全部成功。
- 多个粘贴操作串行，后一个基于前一个完成后的真实状态重新校验。

## 过滤与忽略

- 名称过滤只对当前已加载条目的显示名称做大小写不敏感子串匹配，不读取正文，也不递归读取未展开目录。
- 过滤显示匹配项及祖先链；祖先临时展开不写入持久状态。无匹配显示专用空态和清除入口。
- 过滤变化裁剪不可见选择并修复当前行；清除后恢复过滤前展开和滚动，已失效路径丢弃。
- 过滤是搜索态：切换项目、关闭重开和应用重启均清空；显式隐藏整个侧栏可保留运行态，重新可见后按最新内容重算。
- 忽略开关按项目持久化，关闭重开与重启均恢复。仅因后代含忽略项而聚合的目录不因此被隐藏。
- Git 信息不可用时条目按普通显示，开关仍可操作但不伪造忽略状态。

## Git 与刷新

- Git 状态读取项目根所在仓库的 RepoRoot；项目根可为仓库子目录，树仍只展示项目根内条目。非仓库或读取失败不阻塞文件树。
- 文件夹聚合优先级为冲突 > 修改 > 新增 > 未跟踪 > 重命名 > 删除 > 忽略；状态只用于展示，不提供 Git 写工作流。
- 视图可见时监听当前根；不可见时暂停监听，重新可见合并复核一次。文件事件按 200 毫秒合并，Document 保存后按 300 毫秒合并重算相关路径。
- 手动刷新通过按钮、`F5` 或根菜单，重读已展开目录并重算状态；重复触发合并，失败保留旧树并提示。
- 监听不可用时显示警示和手动刷新入口；不通过高频轮询伪装监听。
- 读取、排序、过滤和文件操作后台执行，大目录采用分批与可见行渲染，不递归预读未展开目录。

## 持久状态

| 状态 | 关闭视图后重开 | 应用重启 |
|---|---|---|
| 按项目的展开、当前行、滚动、忽略开关 | 恢复仍有效路径 | 恢复同一状态并再次校验 |
| 名称过滤、多选、内联编辑、菜单、通知、错误和焦点 | 清除 | 清除 |
| 树内容缓存与 Git 结果 | 重新读取 | 重新读取 |
| 内部文件剪贴板与剪切态 | 保留在应用会话 | 清除 |

- 持久路径保存为项目根相对路径并绑定 `ProjectId`；项目删除状态提交完成后才清理，重新添加同目录不继承旧项目身份。
- 重命名、删除和粘贴同步更新仍有效的持久路径；不存在路径在恢复时跳过，不改变其他状态。只有持久状态本身损坏时才按统一分流提示，不把正常的外部删除当成损坏。
- 显式隐藏整个侧栏不销毁实例，上述运行期状态可按原现场保留；其持久化口径不变。

## 验收判据

- **Given** 文件已在另一项目打开并有脏修改，**When** 从当前项目再次打开，**Then** 创建引用同一 Document 的本项目视图，文本与脏状态共享，不生成第二缓冲。
- **Given** 根内链接在树加载后重定向到未授权目标，**When** 保存、粘贴或删除，**Then** 写前重检拒绝，不继承旧授权。
- **Given** 复制源位于只读 AgentRoot、目标位于可写 ProjectRoot，**When** 粘贴，**Then** 可按能力并集复制；反向写入只读根被拒绝。
- **Given** 跨根剪切或目录粘贴到自身后代，**When** 执行，**Then** 对应项拒绝且其他合法项可按批量规则继续。
- **Given** 显式 cwd 已失效，**When** “在终端中打开”，**Then** 拒绝且不留空 Panel，不回退项目根或活跃项目。
- **Given** 过滤、多选、内联编辑和错误存在，**When** 关闭重开或重启，**Then** 均清除；展开、当前行、滚动和忽略开关按相同规则恢复。
- **Given** 未提交内联编辑，**When** 关闭视图，**Then** 不因其销毁自动写盘；显式文件操作已开始时则可按跨域规则完成并保留结果。
- **Given** 粘贴冲突选择取消，**When** 操作尚未开始，**Then** 文件与剪贴板不变；部分执行失败时如实汇总，不回滚成功项。
- **Given** 视图不可见期间发生多次文件事件，**When** 重新可见，**Then** 只合并复核一次，旧项目结果不回填。
- **Given** 项目根为仓库子目录，**When** 显示 Git 状态，**Then** 使用 RepoRoot 只读信息但树不越出 ProjectRoot。
