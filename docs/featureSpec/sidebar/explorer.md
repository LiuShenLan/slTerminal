# 文件浏览器

> 侧栏文件浏览器视图的目标态规格：文件树根、行构成、加载与展开、选中与多选、打开、新建/重命名/删除、树内复制/剪切/粘贴与冲突处理、名称过滤、忽略文件显示、Git 状态、自动与手动刷新、路径安全与状态保留。项目根与根目录重定位归[导航树](../workspace/navigation.md)；Commit 视图归 [Commit](commit.md)；Agent 全局文件归[Agent 全局文件](agent-files.md)；侧栏入口、槽位与可见性归[侧栏框架](framework.md)；文件打开路由与面板标题归[编辑器](../panels/editor.md)；终端面板与 PTY 生命周期归[终端](../panels/terminal.md)。

## 目标行为

共用文件树形态的视图（含 Agent 全局文件）继承本篇的展开、行构成、单选、右键菜单交互、新建/重命名/删除、树导航快捷键与键盘与输入规则，以及多选、批量操作（批量删除、复制相对路径）与树内复制/剪切/粘贴。各视图的入口、根、过滤、菜单项集合、空态与打开守卫归各自规格；Agent 全局文件的继承范围与差异以[Agent 全局文件](agent-files.md)为准。

### 树根与界面

- 文件浏览器是侧栏的单例视图，入口为活动栏上的「文件浏览器」按钮，默认位于导航树之后；再次点击关闭，打开同槽其他视图时替换。活动栏、按钮顺序、槽位、拖拽与焦点框架由[侧栏框架](framework.md)定义。
- 树根固定为活跃项目根。无活跃项目时不显示文件树，显示居中空态「选择一个项目以浏览文件」；标题栏仍显示，过滤输入框、「显示忽略文件」开关与刷新按钮禁用，刷新按钮提示「请先选择项目」。
- 活跃项目切换时，树根立即切换到新项目根，原项目不残留条目；各项目的展开、当前行、滚动位置与「显示忽略文件」开关按项目恢复。
- 视图隐藏、在侧栏槽位间移动或切换项目时，树状态保留。
- 项目根被重定位后，树按新根重新加载；重定位入口与确认归[导航树](../workspace/navigation.md)。
- 项目根不可访问时显示根加载错误态。
- 标题栏高 28px（设计契约）：左侧固定标题「文件浏览器」；右侧依次为名称过滤输入框、「显示忽略文件」切换按钮与刷新按钮。过滤输入框占剩余宽度，占位文案「筛选文件」，辅助名称「按名称筛选文件」，提供辅助名称为「清除筛选」的清除按钮；「显示忽略文件」辅助名称同名，按下时显示忽略条目；刷新按钮辅助名称「刷新文件树」。以上点击区均不小于 24×24px（设计契约）。
- 过滤输入框获得焦点时树快捷键暂停；Esc 清空过滤并把焦点还给树。
- 标题栏下方为错误横幅区，无错误时不占高度。横幅单行显示、超长省略，右侧关闭按钮 <img src="../assets/preview/icons/close.svg" width="14" height="14" alt="关闭图标">（`../assets/icons/close.svg`，14px，示意）辅助名称「关闭错误提示」。
- 树区域占据剩余高度，上下内边距 2px（设计契约）；垂直滚动；名称超宽时省略，不出现横向滚动。

### 加载与展开

- 首次显示某项目、项目根变化或手动刷新时，原树的过期读取结果不得回填到新树，过期结果直接丢弃。
- 根层条目默认全部折叠。条目顺序：文件夹在前、文件在后；同类按名称不区分大小写排序，排序稳定。
- 名为 `.git` 的条目（目录或文件）在任何层级都不显示。除 `.git` 外，点号开头的隐藏文件正常显示。Git 忽略条目默认隐藏，由「显示忽略文件」开关控制。
- 根层首次读取期间显示加载占位（骨架行或加载指示），不得先显示「空目录」。
- 根层与子目录均分批读取：首批立即可见，后续批次追加；加载期间展开、选择与滚动保持可交互。任一批次失败时保留已显示条目，并在列表末尾显示内联错误行「部分内容加载失败，点击重试」；重试继续读取未完成批次。
- 单击目录行切换展开/收起；选中目录后按 Enter、键盘 Right/Left 或右键「展开/折叠」同样可切换。双击目录行只切换一次，第二次点击不产生额外切换。
- 首次展开未加载目录时，箭头位置显示加载指示「…」；加载完成后显示子行与方向箭头。已加载目录再次展开时立即显示缓存子行，并在后台重读该层。
- 子目录读取失败时，该目录保持展开，并在其子级位置显示内联错误行「加载失败，点击重试」，不得表现为空目录。
- 任意已展开目录为空时，在其子级位置显示内联占位行「空目录」；根层为空时显示居中空态「空目录」。
- 目录中全部条目均因忽略隐藏而不显示时，根层空态文案为「仅包含已忽略的文件」并提供「显示忽略文件」按钮；子目录内联占位行文案相同。
- 根目录读取失败时不显示树，显示居中错误态：「文件树加载失败」+ 错误信息 + 「重试」按钮。重试成功后恢复树；再次失败则保持错误态。
- 刷新、新建/重命名/删除与项目切换后，仍存在的已展开目录保持展开；磁盘上已删除的目录及其子树消失，展开记录清除。名称过滤文本在刷新与新建/重命名/删除后保留，切换项目后清空。
- 展开状态按项目记录；恢复时逐个校验目录存在性，不存在的路径静默跳过。

### 行构成与视觉

- 行高 24px、每层缩进 16px、文件/文件夹图标 <img src="../assets/preview/icons/folder.svg" width="14" height="14" alt="文件夹图标">（`../assets/icons/folder.svg`）、<img src="../assets/preview/icons/file-generic.svg" width="14" height="14" alt="通用文件图标">（`../assets/icons/file-generic.svg`），显示尺寸 14px（设计契约，示意）。
- 行结构：缩进、折叠箭头（仅文件夹）、图标、名称、Git 状态标记（有状态时）。文件行在箭头位置留等宽空白。
- 文件夹展开时箭头向下 <img src="../assets/preview/icons/chevron-down.svg" width="12" height="12" alt="展开箭头">（`../assets/icons/chevron-down.svg`，12px，示意），收起时向右 <img src="../assets/preview/icons/chevron-right.svg" width="12" height="12" alt="折叠箭头">（`../assets/icons/chevron-right.svg`，12px，示意）；文件行不显示箭头。
- 文件图标左缘有类型色块 <img src="../assets/preview/icons/file-generic-typed.svg" width="14" height="14" alt="带类型色块的文件图标">（`../assets/icons/file-generic-typed.svg`，14px，示意）；不同扩展名族使用不同颜色，未映射扩展名不显示色块，此时使用通用文件图标 <img src="../assets/preview/icons/file-generic.svg" width="14" height="14" alt="通用文件图标">（`../assets/icons/file-generic.svg`）。类型色块颜色属于主题规范，本视图只引用语义 token。
- 名称单行显示，不换行。名称在行尾状态标记前以省略号截断；悬停显示完整名称，标签使用完整名称。
- 悬停行显示悬停底色；所有选中行显示选中底色，选中底色优先于悬停底色。树获得键盘焦点时，当前行显示焦点环，焦点环可与选中底色叠加；当前行未被选中时，焦点环与选中底色分离显示。
- 剪切态条目降低不透明度；粘贴成功、取消剪切或替换剪贴板后恢复。
- Git 状态通过图标/名称颜色、行尾单字母标记与完整状态提示共同表达；颜色使用主题的 Git 状态语义槽。
- 忽略条目默认隐藏；开启「显示忽略文件」后以较暗的忽略色与「I」标记显示。
- 加载中、空目录、错误行使用辅助样式，但不改变行高。

### 选中与多选

- 树为多选模型。选中集与当前行分离：当前行接收键盘动作并显示焦点环；选中集可包含多项，当前行通常属于选中集，`Ctrl+Space` 可将当前行切换为非选中状态。
- 单击任意行清空其他选中，仅选中该行，并把键盘焦点移入树；该行成为当前行与范围锚点。单击已选中行不取消选中。
- `Ctrl+单击` 切换该行选中态，不改变展开状态；该行成为当前行，范围锚点更新为该行。
- `Shift+单击` 以范围锚点为起点，按可见行顺序选中连续区间；该行成为当前行，锚点不变。无锚点时按普通单击处理。
- 单击树内空白区域清空选中，键盘焦点仍留在树；无选中时 `Delete`/`Enter`/`F2` 无效果。
- 右键行时，若该行属于多选选中集则保持选中集不变；否则将其设为唯一选中项并更新锚点。随后弹出菜单；右键空白区域不改变选中。
- 焦点离开树时选中态保留，树快捷键不再响应；焦点返回树时落到当前行；无当前行时落到首个可见行。
- 树是单一 Tab 键停靠点：`Tab` 进入树，`Shift+Tab` 离开；行不单独进入 Tab 序列。进入树后用方向键在可见行间移动焦点与选中。
- 方向键模型：`Up`/`Down` 移到上/下一个可见行，把选中集重置为该行并更新锚点；`Right` 展开文件夹，已展开时移到首个子行；`Left` 收起文件夹，已收起时移到父行；`Home`/`End` 移到首个/最后一个可见行，重置选中集并更新锚点；`Shift+Up`/`Shift+Down` 以锚点为起点扩展或收缩连续选中区间；`Ctrl+A` 选中全部可见条目；`Ctrl+Space` 切换当前行的选中态。
- 选中集包含祖先目录与其后代时，批量操作按顶层项去重，避免重复处理同一路径。
- 切换项目时按项目恢复当前行（单选锚点）；路径不存在时清空选中。多选选中集为瞬时状态，不跨项目切换或应用重启恢复。切换项目不把键盘焦点自动移入树。
- 刷新、删除或过滤导致当前路径消失或不可见时，当前行移到下一个可见同级项；无同级项时移到上一个；都没有则清空。消失项从选中集移除。
- 文件浏览器与 Agent 全局文件可能同时存在；两棵树各自维护独立选中，快捷键只作用于最后获得焦点的一棵。

### 打开文件

- 触发：双击文件行、仅选中一个文件时按 `Enter`、右键「打开」；多选时 `Enter` 与双击不打开文件。
- 打开目标为活跃项目布局中的聚焦面板组。项目布局尚无面板组时，按[工作区外壳](../workspace/shell.md)规格创建首个面板组并放入面板。
- 文件类型到面板类型的路由、同项目同文件去重、面板标题与初始形态由[编辑器](../panels/editor.md)规格定义，本视图不重复定义。`.html`/`.htm` 以编辑器源码态打开；`.md`/`.markdown` 默认渲染态；其余扩展名、无扩展名与点号隐藏文件按编辑器路由处理。
- 打开成功后面板获得焦点；本视图不额外提示。重复打开同一文件时按编辑器规格聚焦已有面板，不新增面板。
- 打开动作失败（路由失败、面板创建失败等）时显示错误横幅「打开文件失败: …」，不得静默。
- 仅选中一个目录时按 `Enter` 只切换展开/收起；双击目录只切换一次展开状态，不打开面板。多选时 `Enter` 无效果。
- 无活跃项目时树不显示，因而不存在从本视图打开文件的入口。

### 新建与重命名

- 新建入口：文件夹右键「新建文件」「新建文件夹」；根级空白右键同名项。新建目标始终为触发菜单的文件夹；根级入口的目标为项目根。
- 选择后在目标文件夹行下方（根级则在根层末尾）插入内联输入框并自动聚焦；占位文案「文件名」「文件夹名」。
- 重命名入口：右键「重命名」或选中行按 `F2`。原行被内联输入框替换，预填当前名称；文件名的扩展名之前部分优先选中，文件夹全选整个名称。
- 内联输入按 `Enter` 或失焦提交，`Esc` 取消；提交前去除首尾空白。新建时空白名称在 `Enter` 下显示内联错误「名称不能为空」，失焦则取消。重命名时提交与当前名称完全相同（区分大小写）视为取消，不发起磁盘操作；仅大小写变化允许提交。
- 名称校验（设计契约）：长度 1–255 个字符；不得包含 `\ / : * ? " < > |`；不得为 `.` 或 `..`；不得以空格或点结尾；不得使用 Windows 保留设备名（CON、PRN、AUX、NUL、COM1–COM9、LPT1–LPT9，含带扩展名形式）。
- 与同目录现有条目比较不区分大小写；重名时显示内联错误「已存在同名文件/文件夹」，不覆盖、不创建。校验失败时输入框保留、焦点不离开，用户可修改或按 `Esc` 取消。
- 新建成功：新建文件写入空内容（0 字节），新建文件夹创建目录；目标文件夹自动展开（若原为折叠），新条目被选中并滚动到可见位置；树刷新。
- 重命名成功：条目以新路径存在，选中迁移到新名称并滚动到可见位置；原展开状态迁移到新路径；树刷新。已打开面板对文件重命名的跟随、失效或提示由[编辑器](../panels/editor.md)规格定义，本视图只更新文件树。
- 新建失败时显示错误横幅「新建文件失败: …」或「新建文件夹失败: …」；重命名失败时显示「重命名失败: …」。两种情况均保留输入框以便重试，原行名称不变；`Esc` 可取消。
- 同一时刻只有一个内联输入框。在另一个入口开始编辑时，当前输入框先按失焦规则提交或取消。
- 名称始终在目标文件夹内创建；路径分隔符被校验拒绝，不能借名称创建嵌套路径或越过项目根。
- 输入期间 `Enter`/`Esc`/`Delete`/`F2` 由输入框消费，不触发树级动作；IME 组合输入期间 `Enter`/`Esc` 不提交或取消。

### 删除

- 入口：右键「删除」或树聚焦时按 `Delete`；作用于整个选中集（单选时即该项），先打开一次聚合确认对话框。
- 确认对话框标题：单项为「确认删除」，多项为「确认删除 N 项」；默认焦点在「取消」；`Esc` 取消；`Enter` 激活当前聚焦按钮。
- 删除统一移入 Windows 回收站。单项消息「确定将 "X" 移到回收站？」或「确定将文件夹 "X" 及其内容移到回收站？」；多项消息「确定将选中的 N 项移到回收站？包含文件夹时将递归处理其全部内容。」删除文件夹时递归处理全部内容。
- 回收站不可用的回退：任一目标所在卷不支持回收站或回收站不可用时，聚合说明「无法移到回收站，将永久删除选中的 N 项」，要求用户再次确认；用户取消则整个批量操作不做任何更改。永久删除仅作为回收站不可用时的回退执行。
- 删除成功：树刷新；成功项从选中集移除，当前行按相邻规则迁移；被删除目录的展开记录清除；显示短暂 toast「已移到回收站」，回退为永久删除时显示「已永久删除」，批量时报告相应数量（设计契约：2 秒）。
- 批量删除逐项执行，不要求原子性：部分项失败时成功项保留删除结果，失败项留在树中并保持选中，错误横幅汇总为「N 项删除失败: …」。
- 目标在操作前已被外部删除时，视为该项删除成功：刷新树并按相邻规则修复选中，不显示错误。
- 删除失败（权限、文件被占用等）时显示错误横幅「删除失败: …」，失败项选中保持不变，树在刷新后反映实际状态。
- 项目根不是树中的行，不能从本视图删除或重命名项目根；项目管理由[导航树](../workspace/navigation.md)规格定义。

### 复制相对路径

- 文件与文件夹右键菜单第一项为「复制相对路径」；多选行菜单同样提供；根级空白菜单不含此项。
- 目标位于项目根内时，复制相对项目根、以 `/` 分隔的路径（如 `src/a.ts`）；文件夹路径不带尾随 `/`。
- 目标无法相对化（路径不在项目根内）时，复制规范化的绝对路径。路径比较统一使用 `/`，在 Windows 上不区分大小写。
- 复制成功显示短暂 toast：相对路径为「已复制相对路径」，绝对路径回退为「已复制绝对路径」（设计契约：2 秒）；失败显示错误横幅「复制路径失败: …」。
- 多选时作用于整个选中集：按可见行顺序每行一个路径，以换行分隔；成功 toast 为「已复制 N 个相对路径」。单项无法相对化时该行回退为绝对路径，其余行不受影响。
- 写入系统剪贴板的是纯文本路径，与树内文件剪贴板相互独立。

### 在终端中打开

- 文件与文件夹右键菜单均含「在终端中打开」。
- 文件：终端工作目录 = 文件所在目录。文件夹：终端工作目录 = 该文件夹自身。
- 每次执行都新建一个终端面板，不去重；终端编号按项目级编号规则，由[终端](../panels/terminal.md)规格定义。
- 新终端放入活跃项目布局中的聚焦面板组；项目布局尚无面板组时创建首个面板组。需要并排终端时，用户通过布局操作把终端面板放入其他面板组；本视图不创建额外面板组。
- 目标路径不存在或无法作为工作目录时，显示错误横幅「在终端中打开失败: …」且不创建终端。终端工作目录在创建时确定，不随文件后续移动而更新。
- 终端启动后的 PTY 生命周期、标题、复制粘贴与状态保留由[终端](../panels/terminal.md)规格定义。

### 树内复制/剪切/粘贴

- 剪贴板为应用级内部文件剪贴板，不读写系统剪贴板，与 Agent 全局文件共享。`Ctrl+C`/`Ctrl+X`/`Ctrl+V` 在树聚焦且无内联输入、过滤输入框未聚焦时生效；剪贴板在应用会话内保留，切换项目、隐藏视图与侧栏换槽不改变内容。
- 复制源可跨视图；剪切源与粘贴目标必须同属项目根或同属 Agent 根，项目根与 Agent 根之间不允许剪切移动。
- `Ctrl+C` 将选中集（按顶层项去重）记为复制源；`Ctrl+X` 将其记为剪切源并进入剪切态，源行降低不透明度。再次执行复制或剪切替换当前剪贴板并清除旧剪切态；`Esc` 在无浮层与输入时取消剪切态。
- 粘贴目标：当前行是文件夹时为该文件夹自身；当前行是文件时为其父目录；无当前行时为项目根；根级空白菜单「粘贴」的目标为项目根。多选时以当前行为目标，选中集中的其他文件夹不分别接收粘贴。
- 复制源递归复制到目标目录，名称不变；剪切源移动到目标目录。文件夹递归处理全部内容；同卷移动优先使用原子改名，跨卷回退为复制后删除源。成功 toast：「已复制 N 项」或「已移动 N 项」；复制后剪贴板保留，剪切项全部移动成功后清除剪切态。
- 目标目录与源父目录相同：复制项与剪切项均不执行磁盘操作，跳过该项并提示「已在当前位置」；复制项不进入冲突对话框。
- 禁止将文件夹粘贴到其自身或后代目录：该项跳过并显示错误横幅「不能将文件夹粘贴到其自身或子目录中」，其他项继续。
- 名称冲突按不区分大小写判断。存在冲突时弹出一次聚合对话框「粘贴冲突」，列出冲突数量与前若干个名称，按钮「替换」「跳过」「取消」，默认焦点在「跳过」。
- 「替换」作用于全部冲突项：先将目标位置已有条目移入回收站（不可用时按删除的回退规则说明并二次确认），再写入；替换文件夹时整个目标文件夹及内容移入回收站后写入，不合并目录内容。「跳过」保留现有条目并继续粘贴非冲突项。「取消」中止整个粘贴，不修改任何条目，剪贴板保持不变。
- 批量粘贴逐项执行，不要求原子性：成功项保留；失败项汇总为错误横幅「N 项粘贴失败: …」；剪切态在失败项上保留以便重试，已移动成功项退出剪切态。粘贴替换文件必须原子完成，失败时目标文件保持不变。
- 源在粘贴前被外部删除或改名时，该项跳过并计入失败，不创建空条目；目标在操作期间被外部删除或替换时，按冲突或失败处理并显示可见反馈。
- 粘贴完成后刷新目标目录与 Git 状态；过滤激活时，新条目若不匹配当前过滤则不显示，toast 仍报告实际处理数量。

### 名称过滤

- 标题栏过滤输入框按条目显示名称做子串匹配，不区分大小写；只使用条目名称，不读取文件内容。过滤范围限于当前已加载条目，不递归读取未展开目录。
- 过滤激活时，显示匹配条目及其祖先目录链；祖先目录在过滤期间自动展开，但不写入持久化展开记录。匹配目录只显示自身及匹配的后代，不自动显示全部后代；展开匹配目录会加载其子层并按同一规则过滤。
- 过滤文本变化时，选中集裁剪为仍可见的项；当前行不可见时移到首个可见匹配行；无匹配时清空当前行。
- 无匹配项时显示居中空态「无匹配项」与「清除筛选」按钮，不显示「空目录」。
- 清除过滤后恢复过滤前的展开与滚动位置；展开状态以用户持久化记录为准，过滤期间的临时展开不保留。选中集保留过滤期间的结果，已不存在项丢弃。
- 被忽略且隐藏的条目、`.git` 条目与加载占位行不参与匹配。
- 过滤文本在刷新、新建/重命名/删除与同一面板组内切换面板后保留；切换项目与应用重启后清空。过滤输入框聚焦时 Esc 清空过滤并把焦点还给树。
- 过滤不改变磁盘状态、Git 状态与排序；过滤期间的新建、重命名、删除与粘贴照常执行，新条目按同一过滤规则决定是否显示。

### 忽略文件显示

- 「显示忽略文件」为按项目持久化的视图开关，默认关闭；关闭时忽略条目隐藏，开启时显示为较暗的忽略色与「I」标记。
- 忽略判定基于条目自身的 Git 忽略状态；仅因后代含忽略项而聚合为忽略的文件夹保持显示。
- Git 状态不可用时没有忽略信息，所有条目按非忽略显示；开关仍可切换但无可见差异。
- 根层或子目录中全部条目均因忽略而隐藏时，按「加载与展开」的空态规则提示「仅包含已忽略的文件」并提供「显示忽略文件」按钮。

### Git 状态

- Git 状态使用项目根所在仓库的实际根。项目根可为仓库的子目录；此时仍以仓库实际根读取状态，树中路径仍相对项目根展示。状态按仓库根统一计算，不按项目内子目录分别查询；嵌套仓库不单独计算。项目根不在任何 Git 仓库中或读取失败时，树仍正常显示，条目使用默认前景色。
- 状态集合与行尾字母标记：修改 M、新增 A、未跟踪 U、删除 D、重命名 R、冲突 C、忽略 I。
- 文件行：图标与名称按状态着色，行尾显示状态字母；悬停提示显示完整状态名，标签包含状态。
- 文件夹行：按其后代聚合状态着色并显示标记；聚合优先级为冲突 > 修改 > 新增 > 未跟踪 > 重命名 > 删除 > 忽略。
- 类型色块始终保留类型颜色，不被 Git 状态颜色覆盖；状态颜色不改变排序或图标形状，状态字母作为独立标记显示在行尾。
- 保存文件后立即清除该文件的状态颜色与标记，经过 300ms 合并窗口（设计契约）后重新计算。
- 文件系统变化触发的刷新经过 200ms 合并窗口（设计契约）后重新读取目录并重算状态。
- Git 状态读取失败时，标题栏显示警告指示 <img src="../assets/preview/icons/alert-triangle.svg" width="15" height="15" alt="警告图标">（`../assets/icons/alert-triangle.svg`，15px，示意；辅助名称「Git 状态不可用」），悬停显示原因；树使用默认颜色，不弹错误横幅。手动刷新会重试读取。
- Git 状态只由状态读取与刷新重算；展开、选中与新建/重命名/删除不直接改变状态（保存后的临时清除与重算除外）。
- Git 状态只用于展示，不提供暂存、提交、回滚、分支或差异操作；完整 Git 工作流由终端承担；Commit 仅保留项目根内文件级回滚/删除；GitShow 只读。

### 自动刷新与手动刷新

- 视图可见时监听活跃项目根，只处理当前根下的变化；视图隐藏或切到其他侧栏视图时暂停监听与合并刷新，重新可见时执行一次刷新；切换项目后原根事件丢弃。
- 文件系统变化到达后，200ms 合并窗口（设计契约）内的多次变化合并为一次刷新；刷新重读所有已展开目录，保留展开状态、选中、滚动位置与过滤文本；刷新结果先经忽略隐藏与名称过滤再进入可见行。
- 刷新后磁盘新增条目出现、删除条目消失；选中项不存在时修复；已展开目录在磁盘上被删除时整行与子树消失。
- 编辑器保存文件后立即清除该文件的 Git 状态；300ms 合并窗口（设计契约）后只重读保存路径最近的已展开祖先目录，并原位合并，保留其他子树。
- 保存路径位于未展开目录内时，只刷新其父层，该目录保持折叠。保存路径不属于当前项目根时，树与 Git 状态都不刷新。
- 手动刷新入口：标题栏刷新按钮、树聚焦时按 `F5`、根级空白菜单「刷新」。手动刷新重读已展开目录并重算 Git 状态；刷新期间刷新按钮显示进行中状态，重复触发合并为一次刷新，树保持可交互。
- 手动刷新失败时显示错误横幅「刷新失败: …」，保留现有树内容并可重试；重试成功后清除该横幅，成功无提示。
- 文件监听不可用或异常时，标题栏显示警告指示（辅助名称「文件监听不可用」），并提示使用手动刷新。
- 后台刷新不显示全屏加载指示，不改变滚动位置；过期刷新结果丢弃。

### 状态保留

状态保留按四个维度评估：

| 状态 | 同一面板组内切换面板 | 切换项目 | 视图关闭后重开 | 应用重启 |
|---|---|---|---|---|
| 已展开目录 | 保留 | 按项目保留并恢复 | 保留 | 按项目恢复，校验存在性 |
| 选中项（当前行） | 保留 | 按项目保留并恢复 | 保留 | 按项目恢复，路径存在才恢复 |
| 多选选中集 | 保留 | 不保留，恢复当前行 | 保留 | 不保留，恢复当前行 |
| 滚动位置 | 保留 | 按项目保留并恢复 | 保留 | 按项目恢复并夹取 |
| 名称过滤 | 保留 | 清空 | 保留 | 不保留 |
| 显示忽略文件 | 保留 | 按项目保留并恢复 | 保留 | 按项目恢复 |
| 树内剪贴板与剪切态 | 保留 | 保留（不随项目清空） | 保留 | 不保留 |
| 内联新建/重命名输入 | 失焦提交或取消 | 失焦提交或取消 | 不保留 | 不保留 |
| 错误横幅 | 保留至手动关闭、项目切换或成功重试；新错误替换旧文案 | 清空 | 保留 | 不保留 |
| 树内容缓存 | 保留 | 按项目缓存；切回先用缓存再后台刷新 | 保留 | 重新加载 |
| Git 状态 | 保留并在刷新时重算 | 按项目重算 | 保留并在显示时重算 | 重新计算 |
| 键盘焦点 | 不因切面板改变树内选中 | 不自动进入树 | 不自动抢焦 | 不恢复、不抢焦 |
| 刷新进行中状态 | 保留 | 取消原项目刷新 | 继续 | 不保留 |

- 展开状态、当前行与「显示忽略文件」开关按 `ProjectId` 持久化，路径保存为相对项目根的形式；名称过滤文本与多选选中集不落盘。恢复时只应用仍存在的目录与文件。
- 删除、重命名与粘贴导致路径变化后同步更新持久化记录；不存在的路径在下次恢复时丢弃。
- 视图在侧栏槽位间拖动不改变上述状态；拖动导致输入框失焦时按失焦规则提交或取消。
- 项目被移除时删除其状态记录；重新添加相同根路径的项目从空状态开始。
- 状态持久化失败不阻塞使用，下次启动回退默认状态，并写入诊断日志。

## 交互规则

全局工作区约定（面板生命周期、焦点层级、脏状态、关闭确认、错误与键盘基线）见[工作区外壳](../workspace/shell.md)与[跨域契约](../cross-cutting.md)；侧栏入口、槽位、宽度与拖拽见[侧栏框架](framework.md)。以下只定义文件浏览器视图内的交互。

### 入口与出口

- 活动栏「文件浏览器」按钮与全局视图快捷键 `Ctrl+Shift+E` 可打开本视图；本视图已可见且聚焦时，再次按下 `Ctrl+Shift+E` 关闭。按钮、槽位与替换行为遵循侧栏框架规格。本视图不自行创建窗口或浮动视图。
- 视图隐藏时不响应树快捷键、不弹出菜单；隐藏前未提交的内联输入按失焦规则处理。
- 视图没有「返回上一级」或地址栏；根固定为活跃项目根。
- 打开文件与终端面板是视图的主要出口；面板落点与后续生命周期归工作区外壳与对应面板规格。

### 鼠标

- 单击行：清空其他选中并选中该行；点击文件夹同时切换展开状态；键盘焦点移入树。
- `Ctrl+单击`/`Shift+单击`：按选中模型切换或扩展选中集，只改变选中，不切换展开状态。
- 双击文件：打开；双击文件夹：只切换一次展开状态。多选时双击不触发打开。
- 右键行：按选中模型调整选中集后打开行菜单；右键空白：打开根级菜单，不改变选中。
- 滚轮：垂直滚动树；不缩放、不横向滚动（名称省略）。
- 单击树内空白：清空选中，焦点仍留在树。

### 键盘与焦点

- 焦点层级遵循工作区外壳规格；本视图内部为标题栏控件与「树容器 → 当前行」。过滤输入框、「显示忽略文件」开关与刷新按钮各为独立 Tab 停靠点。
- `Tab` 进入树时，若已有当前行则聚焦当前行，否则聚焦首个可见行；`Shift+Tab` 离开树。
- 方向键移动当前行并重置选中集；`Shift+Up`/`Shift+Down` 扩展或收缩连续选中区间；`Ctrl+A` 选中全部可见条目；`Ctrl+Space` 切换当前行选中态。焦点环始终可见，且与选中底色可区分。
- 内联输入激活时，键盘输入优先给输入框；IME 组合期间不触发树级动作。内联输入中 `Tab`/`Shift+Tab` 按失焦规则提交或取消，然后移动焦点。
- 过滤输入框聚焦时，`Esc` 清空过滤并还焦树，不改变展开与选中。
- 菜单、确认对话框与「粘贴冲突」对话框打开时，焦点进入对应浮层并受限其中；关闭后焦点返回触发元素。
- 切换项目、视图重新显示或应用启动恢复时，不自动把焦点移入树、不抢焦。

### 右键菜单

- 文件菜单项及顺序：复制相对路径、复制、剪切、打开、在终端中打开、重命名、删除。
- 文件夹菜单项及顺序：复制相对路径、复制、剪切、粘贴、展开/折叠（文案随当前状态在「展开」「折叠」间切换）、在终端中打开、新建文件、新建文件夹、重命名、删除。
- 根级空白菜单项及顺序：粘贴、新建文件、新建文件夹、刷新。
- 多选时的行菜单项及顺序：复制相对路径、复制、剪切、删除；批量动作作用于整个选中集，不显示打开、在终端中打开、重命名、新建等单项动作。
- 剪贴板为空时「粘贴」禁用；剪切态下再次执行复制或剪切会替换剪贴板并清除旧剪切态。
- 菜单在指针位置弹出，最小宽度 160px、每项高度 28px（设计契约）。靠近窗口右/下边缘时翻转或夹紧，保证完整可见。
- 菜单支持键盘：打开时焦点进入首个可用项；`Up`/`Down` 移动（首尾循环），`Home`/`End` 到首/末项，`Enter`/`Space` 执行，`Esc` 关闭并把焦点还给原行；点击菜单外关闭。
- 同一时刻只存在一个菜单；打开新菜单前关闭旧菜单；滚动树、切换项目或视图隐藏时关闭。菜单项执行后立即关闭，执行失败时关闭菜单并显示错误反馈。
- 危险项「删除」与普通项之间使用分隔线；「删除」文字使用危险语义色，其余项使用普通文字色。
- 单选时右键行菜单的所有动作作用于被右键行；多选时作用于整个选中集。该行在菜单打开前成为当前行。
- 无活跃项目时不存在树，也不存在根级菜单；右键节点不冒泡为根级菜单。

### 快捷键

树聚焦且无内联输入、过滤输入框未聚焦时生效：

| 按键 | 动作 |
|---|---|
| Delete | 删除选中集，先聚合确认 |
| Enter | 仅单选文件：打开；仅单选目录：展开/收起；多选时无效果 |
| F2 | 仅单选时重命名当前行 |
| Ctrl+C | 复制选中集到树内剪贴板 |
| Ctrl+X | 剪切选中集到树内剪贴板 |
| Ctrl+V | 将剪贴板内容粘贴到当前目标目录 |
| Ctrl+A | 选中全部可见条目 |
| Ctrl+Space | 切换当前行的选中态 |
| Shift+Up/Down | 扩展/收缩连续选中区间 |
| Up/Down | 移到上/下一个可见行并重置选中集 |
| Right | 展开目录；已展开时进入首个子行 |
| Left | 收起目录；已收起时移到父行 |
| Home/End | 移到首个/最后一个可见行并重置选中集 |
| F5 | 刷新 |
| Shift+F10 / 菜单键 | 打开当前选中集的右键菜单 |
| Esc | 取消内联输入；关闭右键菜单；无浮层与输入时取消剪切态；过滤输入聚焦时清空过滤并还焦树 |
| Tab / Shift+Tab | 进入/离开树（树为单一 Tab 键停靠点） |

- 以上为默认键。只有设置中心快捷键页列出的工作区命令可重绑；本表所列视图内部按键不承诺可重绑。命令优先级、冲突处理与保留键由[设置中心](../panels/settings.md)快捷键页与工作区外壳规格定义。
- 内联输入激活时，`Delete`/`Enter`/`F2` 等由输入框消费；`Esc` 取消输入。过滤输入框聚焦时，`Ctrl+A`/`Ctrl+C`/`Ctrl+X`/`Ctrl+V` 与方向键由输入框消费。
- 树未聚焦时快捷键不生效；两棵树同开时只作用于最后获得焦点的一棵。
- `Ctrl+C`/`Ctrl+X`/`Ctrl+V` 只在树内生效，使用应用内文件剪贴板，不读写系统剪贴板；终端与编辑器聚焦时按各自规格处理复制粘贴。

### 反馈

- 任何失败必须至少有一种可见反馈：内联错误行、错误横幅、标题栏警告或 toast；禁止静默失败。
- 破坏性操作使用确认对话框；确认对话框默认焦点在安全按钮。批量删除使用一次聚合确认；「粘贴冲突」对话框默认焦点在「跳过」。
- 批量操作使用聚合反馈：成功与失败按数量汇总为一条 toast 或错误横幅，不逐项弹窗。
- 错误横幅不自动消失，保留至手动关闭、项目切换或成功重试后清除；新错误替换旧文案，只显示最新一条；悬停或聚焦可查看完整文本，立即显示。
- 成功类反馈使用短暂 toast（设计契约：2 秒），不阻塞操作，不抢焦点。
- 多个标题栏警告同时存在时汇总为一个指示，悬停或聚焦列出全部原因。
- 加载反馈分级：根加载用占位，子目录展开用行内「…」，手动刷新用按钮进行中状态；后台刷新不显示全局加载指示。

### 状态迁移

- 项目切换：清空原项目显示与过滤文本，切换到新项目根；恢复该项目的展开、当前行、显示忽略文件开关与滚动；不抢焦点；原项目未完成的读取与刷新结果丢弃。
- 视图隐藏/显示：实例与状态保留；重新显示时后台刷新一次，保留展开、选中与滚动。
- 新建/重命名成功：目标条目出现，选中迁移，父层展开，树刷新。
- 新建/重命名失败：输入框保留，显示内联错误或错误横幅。
- 删除成功：成功项消失并从选中集移除，当前行按相邻规则迁移，展开记录清除；部分失败时失败项保留并保持选中。
- 粘贴成功：目标目录刷新，新条目出现；目标目录折叠时按需展开以显示结果。过滤激活时新条目按过滤规则决定是否可见。
- 粘贴冲突取消：树、剪贴板与选中集均不改变。
- 剪切粘贴成功：源条目移动，已移动项退出剪切态；全部移动完成后剪贴板清空。
- 过滤文本变化：可见行更新；选中集裁剪，当前行迁移或清空；不清空持久化展开记录。
- 刷新成功：条目增减原位合并；展开、选中、滚动与过滤文本保留；选中失效时修复。
- 刷新失败：保留现有树，显示错误横幅或标题栏警告。
- 新建/重命名/删除与粘贴成功后本视图只刷新自身；其他面板对文件变化的响应由各自规格定义。

## 边界与错误

### 空态与初始态

- 无活跃项目：居中空态「选择一个项目以浏览文件」；标题栏仍显示，过滤输入框、「显示忽略文件」开关与刷新按钮均禁用，刷新按钮提示「请先选择项目」。
- 活跃项目根为空：居中空态「空目录」；根层不显示占位行。
- 已展开目录为空：子级显示内联「空目录」行。
- 根层条目全部因忽略隐藏：居中空态「仅包含已忽略的文件」+「显示忽略文件」按钮；子目录内联文案相同。
- 名称过滤无匹配：居中空态「无匹配项」+「清除筛选」按钮；不显示「空目录」。
- 无选中：树正常显示；`Delete`/`Enter`/`F2` 无效果。
- 项目根不在任何 Git 仓库中：树正常显示，无 Git 状态标记，无错误提示。

### 加载与性能

- 根层首次加载显示占位，不显示「空目录」。
- 任何目录均分批读取；批次追加期间不阻塞选择、展开与滚动。
- 手动刷新期间树保持可交互；刷新按钮显示进行中，重复触发合并为一次刷新。
- 设计契约：单目录 10,000 个条目时，滚动、选择与展开操作保持可交互；磁盘遍历不得阻塞界面交互。
- 深度嵌套按需加载；刷新只重读已展开目录，不递归扫描未展开子树。
- 名称过滤只遍历已加载条目，不触发未展开目录的递归读取；过滤与多选在 10,000 条目规模下保持可交互（设计契约）。
- 批量删除、复制、剪切与粘贴在后台执行，不阻塞界面交互；完成后一次性刷新与反馈。
- 大目录排序在后台完成，排序结果到达前保持稳定顺序，不跳变。
- 根加载、子目录读取与批量操作期间，窗口保持响应，其他面板照常工作。

### 错误与恢复

- 根读取失败：居中错误态「文件树加载失败」+ 错误信息 + 「重试」；重试成功恢复树。
- 子目录读取失败：该目录保持展开，子级显示「加载失败，点击重试」。
- 批次续载失败：保留已显示条目，列表末尾显示「部分内容加载失败，点击重试」。
- 刷新失败：保留现有树与状态，显示错误横幅「刷新失败: …」。
- Git 状态读取失败：标题栏警告指示 + 悬停原因；树使用默认颜色；手动刷新重试。
- 文件监听不可用：标题栏警告指示 + 提示手动刷新。
- 新建/重命名/删除/复制路径/复制/剪切/粘贴/打开/终端启动失败：按反馈规则显示可见反馈。
- 批量删除或粘贴部分失败：成功项保留，失败项汇总为一条错误横幅并保留可重试状态；不回滚成功项。
- 在「粘贴冲突」对话框中选择取消：不修改任何条目，不显示错误。
- 状态持久化失败：不阻塞使用，下次启动回退默认状态，写诊断日志。
- 根读取与目录读取等内联错误态在条件恢复或经重试后清除；错误横幅只在手动关闭、项目切换或成功重试后清除，不得无限叠加。

### 冲突与并发

- 新建或重命名与同目录条目重名（不区分大小写）：阻止提交，显示内联错误，不覆盖。
- 提交时目标已被外部创建或改名：按重名或不存在处理，显示错误，保留输入框。
- 内联编辑期间目标被外部删除：新建输入框保留并显示错误横幅；重命名输入框退出并显示错误横幅；树刷新。
- 刷新与新建/重命名/删除并发：过期刷新结果丢弃；操作成功后立即刷新目标父层，不被原刷新覆盖。
- 外部删除正在删除的条目：视为删除成功，刷新并修复选中。
- 项目切换时存在未完成读取或刷新：丢弃原项目结果，不写入新项目树。
- 打开文件时面板创建失败：显示错误提示，不残留可聚焦的无效面板记录。
- 删除确认对话框打开期间目标被外部修改：确认后按实际状态执行；目标不存在则按已删除处理。
- 粘贴重名：弹出一次聚合「粘贴冲突」对话框；替换、跳过与取消分别作用于全部冲突项。
- 粘贴到源文件夹自身或后代：拒绝该项并报告错误，其他项继续。
- 粘贴源在操作期间被外部删除或改名：该项失败并汇总；目标在操作期间被外部修改：按冲突或失败处理，不产生半写条目。替换文件必须原子完成；替换文件夹先移走旧目标，失败时保留可恢复状态。
- 多个粘贴操作并发：串行执行；后一操作基于前一操作完成后的目录状态判断冲突。

### 路径与平台

- Windows 路径不区分大小写；选中、重名、去重与持久化比较均按不区分大小写处理，但显示保留磁盘上的原始大小写。
- 名称校验拒绝路径分隔符、非法字符、`.`、`..`、尾随空格或点、Windows 保留设备名。
- 名称长度 1–255 个字符（设计契约）。
- 删除与粘贴替换优先移入回收站；不同卷的回收站能力不同。回收站不可用时回退为永久删除，并在聚合确认中说明原因。
- 粘贴冲突判断按不区分大小写比较名称；复制、剪切与替换沿用新建的名称校验与本节的路径长度规则。
- 网络驱动器、可移动卷可能不支持文件监听或回收站；分别按错误恢复与删除规则处理。
- 符号链接与目录联接按目标类型显示；链接的真实目标必须位于项目根内，根外目标显示占位或拒绝展开/读写，不跟随；展开只读取目标目录；检测到循环引用时不继续自动展开。对链接本身的重命名与删除只作用于链接，不作用于目标。复制或剪切链接条目时按链接本身处理，不递归复制目标内容；无法保持链接语义时跳过该项并报告。
- 文件被其他进程锁定时，删除或重命名失败并显示错误横幅；不做自动重试。
- 长路径按 Windows 长路径能力处理；超出系统限制时显示明确错误，不崩溃。
- `.git` 条目始终隐藏；其他点号隐藏文件正常显示。

### 键盘与输入

- 树、行、菜单、对话框均可仅用键盘完成操作；焦点顺序稳定，焦点环可见。
- 过滤输入框提供占位文案与清除按钮；「显示忽略文件」开关提供按下状态与名称；批量操作结果显示成功与失败数量。
- 复制、剪切、粘贴、批量删除、过滤与粘贴冲突选择均可仅用键盘完成；冲突对话框默认焦点在安全选项。
- Git 状态同时提供文字标签与行尾字母，不只依赖颜色。
- 内联输入支持 IME 组合；组合期间 `Enter`/`Esc` 不提交或取消。
- 文件名支持 Unicode 与 CJK；排序不区分大小写，保持稳定顺序。
- 尊重「减少动效」设置：加载指示可使用静态占位替代旋转动画。
- 行高、点击区与菜单项高度满足设计契约，触控板与高 DPI 下不重叠。

### 安全边界

- 名称校验阻止通过 `/`、`\` 等分隔符创建嵌套路径或越过目标文件夹。
- 所有文件操作的目标必须解析到树中显示的条目或其直接父目录；不接受来自外部输入的任意路径。
- 树内剪贴板只接受来自本视图选中集的源路径；粘贴目标必须解析到树中目录或项目根，禁止粘贴到源文件夹自身或后代。
- 粘贴替换文件必须原子完成；替换文件夹时先移走旧目标，失败时保留可恢复状态。
- 符号链接操作只作用于链接条目；展开链接目录时按真实目标校验项目根边界并检测循环，根外目标拒绝展开。
- 终端工作目录以单个路径参数传递，不拼接进 shell 命令文本。
- 错误消息可包含路径与系统错误，不包含文件内容或凭据。

## 验收判据

- 无活跃项目时显示「选择一个项目以浏览文件」，不显示树，标题栏控件禁用；有活跃项目时树根为该项目根。
- 项目 A/B 切换后树根立即切换；切回 A 时展开状态、当前行、滚动位置与「显示忽略文件」开关恢复；原项目读取结果不进入新树。
- 根层首次加载显示加载占位，不显示「空目录」；加载完成后文件夹在前、文件在后、名称不区分大小写排序。
- 空根显示居中「空目录」；任意空子目录展开后子级显示「空目录」。
- 根读取失败显示「文件树加载失败」、错误信息与「重试」；重试成功后恢复树。
- 子目录读取失败时该目录保持展开并显示「加载失败，点击重试」，不显示为空目录。
- 根批次续载失败时保留已显示条目，并显示「部分内容加载失败，点击重试」。
- 单击目录展开，再次单击收起；双击目录只切换一次。
- 行高 24px、缩进 16px、图标 14px（设计契约）；文件夹有箭头，文件无箭头；`.git` 在任何层级都不显示，其他点号文件显示。
- Git 状态同时呈现颜色与字母标记；类型色块保持类型色；开启「显示忽略文件」后忽略条目暗淡并带「I」。
- 项目根为 Git 仓库子目录时，Git 状态以仓库实际根计算并正常显示。
- 长名称在状态标记前省略，悬停显示完整名称；不出现横向滚动。
- `Tab` 进入树；`Up`/`Down` 移动选中；`Right`/`Left` 展开、收起与进出层级；`Home`/`End` 到首/末行；焦点环可见。
- 单击行选中；单击空白清空；焦点离开后选中保留且快捷键失效；焦点返回落到当前行。
- `Ctrl+单击` 切换行选中，`Shift+单击` 按可见顺序选中连续区间；`Ctrl+A` 选中全部可见条目；`Shift+Up`/`Shift+Down` 扩展或收缩选中区间；`Ctrl+Space` 切换当前行选中态。
- 多选时当前行显示焦点环，所有选中行显示选中底色；右键选中集内的行保持选中集，右键集外的行改为仅选中该行。
- 选中集包含祖先与后代时，批量操作按顶层项去重，同一路径只处理一次。
- 右键行先选中该行；文件、文件夹、根级空白与多选菜单的项与顺序符合规定；Esc 关闭并还焦。
- 菜单靠近窗口边缘时完整可见；方向键、`Home`/`End`、`Enter`/`Space` 可操作；删除项有分隔线与危险色。
- 双击文件、仅选中一个文件时按 `Enter`、右键「打开」均触发编辑器规格定义的打开路由；重复打开不新增面板。
- `.html`/`.htm` 以编辑器源码态打开；`.md`/`.markdown` 默认渲染态。
- 活跃项目布局无面板组时打开文件或终端会创建首个面板组，打开动作不因缺少落点失败。
- 打开失败显示可见错误提示，不静默。
- 复制项目内文件路径得到以 `/` 分隔的相对路径；成功 toast 持续约 2 秒（设计契约）；失败显示错误横幅。
- 多选「复制相对路径」按可见行顺序每行输出一个路径，以换行分隔；成功 toast 报告数量，单项无法相对化时该行回退为绝对路径。
- 右键文件「在终端中打开」后，终端工作目录为文件所在目录；右键文件夹时为该文件夹自身。
- 连续两次「在终端中打开」产生两个终端面板；并排终端通过把面板放入不同面板组实现。
- 新建文件/文件夹输入框位置与占位文案正确；`Enter`/失焦提交，`Esc` 取消。
- 新建名称含分隔符、非法字符、保留设备名、尾随点/空格或与现有条目重名时被拒绝，显示内联错误，不覆盖。
- 新建成功后目标文件夹展开、新条目选中并可见；新建文件为 0 字节。
- `F2` 与右键「重命名」进入内联输入；同名提交取消；仅大小写变化可提交；重名被拒绝。
- 重命名成功后选中迁移到新名称；失败显示「重命名失败: …」且输入框保留。
- 单项 `Delete` 与右键「删除」打开确认对话框，标题「确认删除」且默认焦点在「取消」；多选时标题为「确认删除 N 项」。
- 删除移入系统回收站；回收站不可用时回退为永久删除，并在聚合确认中说明原因、要求二次确认。
- 删除成功后选中移到相邻条目；删除文件夹后子树消失；外部已删除的目标按成功处理。
- 多选删除只打开一次聚合确认，标题为「确认删除 N 项」；部分失败时成功项删除、失败项保留并汇总为一条错误横幅。
- 批量删除成功的 toast 报告数量；逐项执行，不回滚已成功项。
- 保存文件后该文件状态先清除，约 300ms 后重算（设计契约）；外部变化约 200ms 后刷新（设计契约）。
- 刷新保留展开、选中、滚动与过滤文本；手动刷新失败显示「刷新失败: …」并保留树。
- 文件监听或 Git 状态不可用时标题栏显示警告指示，树继续可用，手动刷新可重试。
- `Ctrl+C`/`Ctrl+V` 复制文件与整个文件夹；`Ctrl+X`/`Ctrl+V` 移动；剪切态在粘贴成功后清除，复制后剪贴板可重复粘贴。
- 粘贴重名时弹出一次「粘贴冲突」对话框，默认焦点在「跳过」；替换、跳过、取消分别符合规则；取消不修改任何条目与剪贴板。
- 粘贴到源文件夹自身或后代被拒绝并显示错误，其他项继续；部分失败时成功项保留并汇总失败数量。
- 切换项目后树内剪贴板保留；应用重启后清空；`Ctrl+C`/`Ctrl+X`/`Ctrl+V` 不写入系统剪贴板。
- 名称过滤按子串不区分大小写；显示匹配项与祖先目录；无匹配时显示「无匹配项」；清除后恢复过滤前展开与滚动。
- 过滤不递归读取未展开目录，不写入持久化展开记录；被忽略且隐藏的条目不参与匹配。
- 忽略条目默认隐藏；开启「显示忽略文件」后显示并带「I」标记；开关按项目持久化。
- 根层仅含被隐藏的忽略条目时显示「仅包含已忽略的文件」并提供「显示忽略文件」按钮。
- 应用重启后按项目恢复展开状态、当前行、滚动位置与「显示忽略文件」开关；不存在路径被丢弃；多选选中集、过滤文本与内联输入不恢复。
- 任何失败场景都有可见反馈；错误横幅不自动消失，保留至手动关闭、项目切换或成功重试。
- 标签包含名称、类型、展开状态、选中状态、剪切态与 Git 状态；多选变化时更新数量；IME 组合期间 `Enter` 不提交。
- 重名比较不区分大小写；名称尾随点/空格被拒绝；符号链接循环不导致无限展开。
- 单目录 10,000 个条目时滚动、选择与展开保持可交互（设计契约）。
- Agent 全局文件继承本篇的展开、单选、右键菜单交互、新建/重命名/删除、树导航快捷键、键盘与输入规则、多选与批量删除、复制相对路径及树内复制/剪切/粘贴；其入口、根、过滤、菜单项集合、空态与打开守卫按该视图规格执行。

## 关键决策与依据

| 规则 | 原因 | 边界 |
|---|---|---|
| 树根固定为活跃项目根；项目根重定位后按新根重新加载 | 文件浏览器只服务当前项目，作用域单一，避免根选择歧义 | 项目根管理与重定位入口归导航树；本视图不设独立浏览层级 |
| 删除统一移入系统回收站 | 复用系统恢复能力，保证误删可恢复 | 回收站不可用时回退永久删除并二次确认；项目根不能从树删除 |
| 多选模型覆盖批量删除与批量复制相对路径 | 大目录整理效率；批量动作符合文件管理习惯 | 批量删除一次聚合确认；批量操作逐项执行，部分失败不回滚并聚合报告 |
| 名称过滤只匹配已加载条目及其显示名称 | 避免递归扫描大目录造成卡顿与 IO 放大，保持过滤即时可交互 | 不递归读取未展开目录，不写持久化展开记录；清除后恢复原展开与滚动 |
| 忽略文件默认隐藏，按项目提供显示开关 | 降低噪音，同时保留对忽略内容的可发现性 | 隐藏只依据条目自身忽略状态；聚合为忽略的文件夹保持显示；无 Git 信息时全部按非忽略显示 |
| Git 状态使用仓库实际根，颜色 + 字母 + 文本共同表达 | 项目根可为仓库子目录，状态必须与仓库一致；非颜色线索满足键盘与输入 | 读取失败不阻塞树，仅标题栏警告；Git 仅展示，不做版本库写操作 |
| 树内剪贴板与系统剪贴板分离 | 文件复制/移动与文本复制语义不同，避免互相污染 | 剪贴板会话内保留、跨项目保留、重启清空；只接受本视图选中集路径 |
| 自动刷新为主，手动刷新作为确定性恢复手段 | 外部文件变化无法瞬时同步，用户需要可控的重载入口 | 外部变化 200ms 合并、保存后 300ms 局部重算；监听不可用时仅警告并提示手动刷新 |
| 粘贴冲突聚合为替换/跳过/取消三选，默认跳过 | 批量粘贴避免逐项打断，默认选项不破坏现有文件 | 替换先移入回收站，替换文件夹整移不合并；取消零修改；逐项执行并聚合失败 |
| 视图状态按项目持久化 | 多项目同时存活，切换与重启不应丢失工作位置 | 仅恢复仍存在的路径；多选、过滤文本、内联输入与剪贴板不落盘；移除项目时清除记录 |
| Agent 全局文件继承本视图的树交互、批量与剪贴板规则 | 同形态文件树保持一致的键盘、键盘与输入与文件操作语义 | 入口、根、过滤、菜单项集合、空态与打开守卫由 Agent 全局文件规格定义 |
| 打开文件落点为活跃项目布局的聚焦面板组，缺失时创建首个面板组 | 保证打开动作始终可达，且面板落点与布局模型一致 | 面板组创建、面板焦点与布局操作归工作区外壳规格；文件路由归编辑器规格 |
