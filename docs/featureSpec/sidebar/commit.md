# Commit

> 侧栏 Git 变更视图：定义数据根、四渲染态、变更列表与计数、头部过滤、ignored 分区与显示开关、打开映射、右键菜单、回滚与删除、项目切换与状态保留。从 Commit 打开文件的面板入口与文件打开路由归[编辑器篇](../panels/editor.md)；文件树定位归[文件浏览器篇](explorer.md)；Diff、GitShow 与 Markdown 面板行为归各自面板篇；侧栏入口、槽位、显隐与视图状态持久化归[侧栏框架篇](framework.md)。

## 目标行为

### 数据根与范围

- 数据根 = 活跃项目根所在的 Git 仓库实际根。从项目根向上定位仓库，项目根可位于仓库子目录。
- 列表覆盖整个仓库工作区，包括项目根之外的仓库路径。列表、提示与工具提示中的相对路径统一相对数据根。
- 文件浏览器、Diff、GitShow 使用同一仓库根；数据根与文件浏览器当前浏览的子目录无关。
- 项目根不在任何 Git 仓库内为错误态，不自动执行仓库初始化。
- 无活跃项目为无根态。活跃项目变化、项目被移除、数据根不可访问或恢复时，按四渲染态迁移。
- 同一时刻最多一个 Commit 视图实例。视图标识固定为 `Commit`，标题固定为 `COMMIT`。
- 入口按钮、活动栏位置、槽位替换、拖拽换区、同区排序、显隐切换与视图快捷键重绑规则归侧栏框架篇；本篇只拥有视图标识、标题与视图内行为。
- 仓库工作流只读：不提供暂存/取消暂存（added 删除前的取消暂存除外）、提交、推送/拉取、分支、合并、冲突解决、历史浏览、stash、子模块内部状态。仓库写工作流由终端面板完成。
- 不区分 staged 与 unstaged；Changes 展示工作区与索引合并后的状态。
- 单行操作：无多选、无批量回滚/删除、无分页、无浮动视图或独立窗口。
- 不缓存跨项目数据；切换项目重新读取，不显示上一项目数据。

### 四渲染态

四态互斥，任一时刻只显示其中一种。

| 状态 | 触发 | 可见内容 | 不变量 |
|---|---|---|---|
| 无根 | 无活跃项目 | 居中提示 `选择一个项目以查看变更`；过滤输入框、刷新按钮与 ignored 开关禁用；不显示列表 | 无数据根 |
| 加载中 | 首次打开且存在活跃项目；数据根变化；错误态重试 | 居中提示 `加载中…`；头部控件禁用；不显示列表与分组 | 先前数据已清空；先前读取结果丢弃 |
| 错误 | Git 状态读取失败 | 居中主文案、原因详情、`重试` 按钮；过滤输入框与 ignored 开关禁用；刷新按钮等效重试；不显示列表 | 按错误分类，禁止统一归因 |
| 就绪 | 读取成功 | 头部（过滤输入框、刷新按钮、ignored 开关）与 Changes、Unversioned Files 分组；ignored 开关开启时增加已忽略分区 | 计数等于该组当前过滤后的条目数；ignored 默认不出现 |

- 数据根变化时立即清空列表，关闭右键菜单与确认框，清空聚焦行与过滤文本，滚动置顶，进入加载中；分组折叠状态、已忽略分区折叠状态与 ignored 开关保留。
- 自动刷新、手动刷新与操作后刷新均停留在就绪态：现有列表保持到新结果返回，再原位更新。刷新失败见错误处理。
- 错误态 `重试` 进入加载中；自动刷新事件也可在错误态静默重试，成功转就绪，失败保持错误态并更新原因。
- 就绪但无任何变更时，Changes 与 Unversioned Files 两个分组仍显示，展开后各显示 `无变更文件`；ignored 开关开启时，已忽略分区按自身空态显示。

### 列表内容与计数

- 就绪态为单一滚动区域，分组顺序固定为 Changes、Unversioned Files、已忽略（仅开关开启时）。
- Changes 包含已跟踪路径的 added、modified、deleted、renamed、conflict。无法识别的已跟踪状态也归入 Changes，使用中性色与文字标签 `未知`，工具提示显示原始状态码。
- Unversioned Files 仅包含 untracked 文件。普通未跟踪目录展开为逐个文件行，不显示目录行；嵌套 Git 仓库与子模块按单条目显示，不递归内部。
- renamed 只产生一行，显示新路径；工具提示显示 `旧路径 → 新路径`，不拆成删除行与新增行。
- ignored 默认不显示、不计数。ignored 开关开启后显示 `已忽略（N）` 独立分区：按仓库返回的忽略路径条目展示，目录条目显示为目录行且不递归展开内部；该分区条目不计入 Changes 或 Unversioned Files 的计数，也不计入任何变更总数。
- 分组标题固定为 `Changes (N)`、`Unversioned Files (N)`、`已忽略（N）`。N 为该组当前过滤后的条目数，无过滤时等于该组条目总数；折叠不改变计数；英文标题不随单复数变化。
- 折叠只改变行可见性，不改变计数、排序或数据。
- 每行包含：
  - 状态文字标签与语义色。Changes 标签为 `新增`、`修改`、`删除`、`重命名`、`冲突`、`未知`；Unversioned Files 为 `未跟踪`；已忽略分区为 `已忽略`。
  - 文件名。
  - 父目录相对路径后缀；文件位于仓库根层时不显示。
  - 工具提示：完整相对路径；renamed 追加旧路径与新路径。
- 状态不得仅以颜色表达。文件名与状态标签按状态使用对应语义色：新增与未跟踪用成功色，修改用信息色，删除与冲突用危险色，重命名用强调色，未知与已忽略用中性色；颜色经主题语义 token 引用，禁止硬编码，对比度遵循主题无障碍校验。
- 同一分组内文件名相同、目录不同的条目靠父目录后缀区分。
- 单行聚焦模型：同一时刻最多一行有焦点，不支持多选。
- 忽略项为只读条目：支持聚焦、过滤、工具提示与复制路径；不参与双击打开映射，不提供回滚/删除，不提供“在文件浏览器中显示”。

### 头部过滤

- 视图头部提供轻量过滤输入框，与刷新按钮、ignored 开关同区；无根、加载中与错误态禁用，就绪态启用。占位文案 `过滤文件`，无障碍名称 `过滤 Commit 文件`。
- 匹配对象为文件名与完整相对路径，按子串匹配，不区分大小写；两者任一命中即显示。renamed 按新路径匹配，不匹配旧路径；不匹配状态标签与工具提示文本。不支持通配符、正则与排除语法。
- 过滤对 Changes、Unversioned Files 与已忽略分区同时生效；输入即时生效，无需确认；计数 N 变为该组过滤后的条目数，排序与折叠状态不变。
- 过滤只改变可见行与计数，不改变底层数据、聚焦路径与滚动锚点；聚焦行被过滤掉时，方向键从最近可见行开始。
- 过滤无匹配时各可见分组仍显示，展开后各显示 `无匹配文件`；过滤文本为空时恢复全量。
- 过滤文本为视图内瞬态状态，不写入设置；切换项目与数据根变化时清空；切视图、换槽、隐藏时保留；应用重启不保留。
- 视图内 `Ctrl+F` 聚焦过滤输入框并全选现有文本；过滤输入框中 `Esc` 清空文本并保持焦点；`Enter` 不打开面板。

### ignored 分区与显示开关

- 头部提供 `显示已忽略` 开关，无障碍名称 `显示已忽略文件`；默认关闭。
- 关闭时：不显示 `已忽略` 分组标题，ignored 条目不显示、不计数，不提供任何入口；Changes 与 Unversioned Files 的行为不受影响。
- 开启时：在 Unversioned Files 之后显示 `已忽略（N）` 独立分区，默认为展开，可独立折叠；N 为该分区当前过滤后的条目数，不计入变更总数。
- 开关切换不改变过滤文本、其他分组计数、排序与折叠状态。开启后按当前仓库状态展示忽略条目；关闭立即隐藏分区。
- 已忽略分区受头部过滤约束；过滤无匹配时展开显示 `无匹配文件`，无忽略条目时展开显示 `无已忽略文件`。
- 忽略项只读：不回滚、不删除、不打开面板、不在文件浏览器中定位；可聚焦、可复制路径。
- 开关状态与已忽略分区折叠状态归侧栏视图状态持久化，由侧栏框架篇负责；切视图、换槽、隐藏、切换项目与应用重启后均保留。

### 排序

- Changes、Unversioned Files 与已忽略分区各自独立排序。
- 排序键为完整相对路径，不区分大小写与重音，按固定 Unicode 排序规则升序；权重相同时按原始字符串序数比较。
- renamed 使用新路径排序；ignored 目录条目使用目录相对路径排序。
- 排序结果不依赖系统区域设置，跨机器一致。
- 折叠、刷新、过滤与计数均不改变排序。

### 自动刷新与手动刷新

- 监听范围为仓库根内的工作区文件（含项目根之外的仓库路径），以及 Git 元数据中的索引、HEAD 与引用；Git 对象库与日志不单独触发刷新。仓库根之外的文件事件一律忽略。
- 文件事件按尾部去抖：静默 200 毫秒（设计契约）后触发一次状态重取；连续事件下最长 1000 毫秒（设计契约）内至少更新一次。
- 静默刷新不进入加载中：现有列表保留，结果返回后原位更新；尽量保持聚焦行（按路径匹配，消失时聚焦最近行）与滚动锚点；折叠状态不变。
- 刷新触发：仓库根内文件事件；回滚/删除结束（无论成功、失败或部分成功）；手动刷新；视图重新可见；数据根变化（走加载中）。
- 头部刷新按钮与过滤输入框同区；点击区域不小于 24×24 px（设计契约），工具提示与无障碍标签为 `刷新 Commit 列表`；视图内焦点时 `F5` 等效触发。
- 刷新按钮在无根与加载中禁用；错误态等效重试；就绪态执行静默刷新。
- 手动刷新进行中按钮显示忙碌态并禁止重复触发。任意时刻最多一次状态读取进行中；进行中的其他刷新触发合并为一次后续读取。
- 视图不可见（切到其他侧栏视图、换槽、隐藏侧栏）时暂停文件监听与自动刷新，并取消尚未触发的去抖计时；进行中的读取可完成并更新列表数据。重新可见时：数据根已变化则清空并加载，否则执行一次静默刷新。
- 就绪态刷新失败时不进入错误态、不移除列表，在分组上方显示行内警告 `刷新失败，列表可能已过期`，附原因与 `重试`；下次成功后自动消失。
- 不轮询；不自动初始化仓库；不在后台保持不可见视图的持续刷新。

### 双击打开映射

编辑器、Diff、GitShow 与 Markdown 文档面板的行为分别由其契约所有（[编辑器篇](../panels/editor.md)、[Diff 篇](../panels/diff.md)、[GitShow 篇](../panels/gitshow.md)、[Markdown 文档篇](../panels/markdown.md)）；本篇只定义按状态路由与面板标题后缀。

| Git 状态 | 打开的面板 | 面板标题后缀 | 内容 |
|---|---|---|---|
| added | 经文件打开路由分派 | 无（普通标题） | 工作区文件 |
| untracked | 经文件打开路由分派 | 无（普通标题） | 工作区文件 |
| deleted | GitShow | `(git delete)` | 只读 HEAD 内容 |
| modified | Diff | `(git diff)` | HEAD 与工作区对比 |
| renamed | Diff | `(git diff)` | 旧路径 HEAD 内容与新路径工作区内容对比 |
| conflict | Diff | `(git diff)` | HEAD 与工作区对比；冲突呈现由 Diff 面板契约定义 |
| unknown | 经文件打开路由分派；文件不存在时不创建面板 | 无（普通标题） | 存在则打开工作区文件；不存在则提示 `文件不存在` |
| ignored | 不打开面板 | 无 | 只读条目；查看内容经文件浏览器（开启其忽略文件显示后） |

- 面板标题为文件名直接拼接后缀，中间不加空格，例如 `a.ts(git diff)`；无后缀面板标题为文件名本身。面板标题后缀字符串由各面板篇定义；本篇只规定 Git 状态到面板类型与后缀的映射，并引用各面板的标题规则。
- 项目根外、仓库根内的条目仍显示与打开：modified、renamed、conflict 以 Diff 只读对比模式打开；added、untracked、unknown 经文件打开路由以根外只读模式打开；deleted 以 GitShow 只读打开。项目根外条目不提供回滚或删除。
- added、untracked 与 unknown 的目标是文件打开路由：Markdown 文件进入 Markdown 文档面板，其他文件进入编辑器面板；分派规则归编辑器篇的文件打开路由契约所有，本篇只按状态选择路由。
- unknown 不产生 `(git unknown)` 后缀面板，也不经 GitShow；文件存在时按文件打开路由以普通标题打开，文件不存在时提示 `文件不存在`、不创建面板并静默刷新。
- 落点为活跃项目的项目布局中当前聚焦的面板组；不存在面板组时创建第一个面板组。落点机制归[工作区外壳契约](../workspace/shell.md)所有。
- 去重键为项目 + 规范绝对路径（Windows 上大小写不敏感）+ 面板标题后缀。added、untracked 与 unknown 无后缀，键为项目 + 规范绝对路径，与文件打开路由打开的普通面板共用同一身份。命中时聚焦已有面板及其所在面板组，不重复打开。
- 同一文件的不同后缀是不同面板；无后缀面板与带后缀面板互不复用。
- 跨项目不聚焦：始终在活跃项目内打开，不聚焦其他项目中的同路径面板。
- 激活方式：双击行，或聚焦行上按 `Enter`。单击只设置聚焦/选中，不打开。
- 激活与创建之间若活跃项目已切换，放弃打开并给出可见提示。
- 文件在激活时已消失、状态已变化导致目标内容不可读、或面板创建失败时，必须给出非模态错误提示并静默刷新；禁止静默。
- 二进制文件仍按上表路由，内容呈现由对应面板契约决定。

### 右键菜单

- 除 unknown 外，每一行均可通过鼠标右键，或聚焦行上的 `Shift+F10` / `Menu` 打开上下文菜单。鼠标菜单跟随指针；键盘菜单锚定聚焦行并在屏幕边缘翻转。unknown 行不提供上下文菜单，仅保留双击打开。菜单的焦点、键盘、读屏与关闭规则遵循[全局交互基线](../README.md)与[工作区外壳契约](../workspace/shell.md)。
- 菜单项顺序：`在文件浏览器中显示`、`复制路径`、分隔线、破坏性操作（按状态出现）。
- 破坏性操作按状态出现，且仅对项目根内路径提供：
  - modified、deleted、renamed、conflict：`回滚`。
  - added、untracked：`删除`。
  - ignored：无破坏性操作。
  - 项目根外、仓库根内的行只提供复制路径；定位与破坏性操作禁用，破坏性项提示 `项目根外文件需在终端或外部工具中处理`。
- 忽略项只提供 `复制路径`；不提供 `在文件浏览器中显示`。
- 破坏性菜单项使用危险语义色；每行最多一个破坏性操作项。

#### 在文件浏览器中显示

- 仅当目标存在于工作区且其工作区路径位于项目根内时可用。执行时向文件浏览器发出定位请求：文件浏览器不可见时先恢复显示（槽位与顺序归侧栏框架篇），然后展开必要层级、选中目标行、滚动到可见区域并聚焦；名称过滤与忽略文件显隐的处理归文件浏览器篇。
- renamed 定位新路径。
- 目标位于项目根外（包括仓库根内、项目根之外的路径）时禁用，并以工具提示与无障碍描述说明 `文件不在项目根内，无法在文件浏览器中显示`。
- 目标为 deleted 状态时禁用并提示 `文件已删除，无法在文件浏览器中显示`；其他工作区不存在的条目禁用并提示 `文件不存在，无法在文件浏览器中显示`。
- 菜单打开后目标在执行前消失时，不执行定位，给出非模态提示 `文件不存在` 并静默刷新。
- 定位完成后 Commit 视图失去焦点；返回侧栏时按状态保留规则恢复视图状态。

#### 复制路径

- 复制目标在磁盘上的绝对路径：工作区存在的条目（added、modified、renamed、conflict、untracked、ignored）复制工作区绝对路径；renamed 复制新路径；deleted 复制由仓库根与 HEAD 记录路径拼出的绝对路径，即使该路径当前不存在。
- 复制成功给出非模态轻提示 `已复制路径`；剪贴板写入失败给出非模态错误提示，包含操作与原因。
- 复制内容仅为路径，不包含凭据、文件内容或 Git 错误详情。

### 回滚与删除

- 回滚与删除仅作用于项目根内路径；项目根外、仓库根内的条目禁用破坏性操作并提示原因。

| 状态 | 菜单项 | 确认标题 | 确认正文 | 结果 |
|---|---|---|---|---|
| modified | `回滚` | `确认回滚` | 确定将“<完整相对路径>”回滚到 HEAD 版本？工作区修改将丢失，此操作不可撤销。 | 用 HEAD 内容覆盖工作区文件 |
| deleted | `回滚` | `确认回滚` | 确定将“<完整相对路径>”恢复到 HEAD 版本？此操作不可撤销。 | 从 HEAD 重建文件 |
| renamed | `回滚` | `确认回滚` | 确定回滚“<新路径>”？旧路径文件“<旧路径>”将恢复为 HEAD 版本，新路径文件将被删除。此操作不可撤销。 | 恢复旧路径，删除新路径 |
| conflict | `回滚` | `确认回滚` | 确定将“<完整相对路径>”回滚到 HEAD 版本？冲突解决内容将丢失。此操作不可撤销。 | 覆盖为 HEAD 内容，丢弃冲突解决结果 |
| added | `删除` | `确认删除` | 确定删除“<完整相对路径>”？将先取消暂存，再移入系统回收站；回收站中的文件可恢复。若系统回收站不可用，将永久删除且不可恢复。 | 取消暂存后移入系统回收站；不可用时永久删除 |
| untracked | `删除` | `确认删除` | 确定删除“<完整相对路径>”？文件将移入系统回收站；回收站中的文件可恢复。若系统回收站不可用，将永久删除且不可恢复。 | 移入系统回收站；不可用时永久删除 |

- ignored 与 unknown 不提供回滚或删除。
- 确认框遵循[工作区外壳契约](../workspace/shell.md)的全局模态契约：危险主按钮为 `回滚` 或 `删除`，次按钮为 `取消`，默认焦点在 `取消`，`Esc` 取消。
- 执行前重新读取目标状态与路径。状态或路径已变化时中止，提示 `文件状态已变化，请刷新后重试`，并静默刷新；删除目标已不存在时提示 `文件不存在` 并刷新；回滚 deleted 时工作区文件缺失属于预期。
- renamed 回滚顺序：先恢复旧路径，成功后才删除新路径。旧路径恢复失败时不得删除新路径。新路径删除失败时按部分成功处理，刷新后显示真实现状。
- added 删除顺序：先取消暂存；取消暂存失败时不得删除或移动磁盘文件。取消暂存成功但移入回收站或永久删除失败时按部分成功处理，文件以未跟踪状态留存。
- 同一视图内破坏性操作串行执行；执行中的行显示忙碌态并禁止再次激活或打开菜单，其他行保持可见。
- 取消确认不产生磁盘或索引变化，不触发刷新。
- 操作结束（成功、失败或部分成功）后均静默刷新列表，使界面与真实状态一致。
- 成功时给出非模态成功提示，包含操作与完整相对路径；失败或部分成功时给出非模态错误提示，包含操作、完整相对路径、失败原因与已完成/未完成部分；禁止仅记录日志。
- 删除优先移入 Windows 系统回收站；系统回收站不可用（如网络盘、移动盘、权限或容量限制）时回退为永久删除。确认框说明恢复路径与回退后果，结果提示说明实际采用的方式。
- 符号链接只操作链接项本身，不跟随目标。无应用内撤销；回收站恢复由系统提供。

### 项目切换与状态保留

- 活跃项目变化：立即清空列表与过滤文本，关闭右键菜单与确认框，清空聚焦行，滚动置顶，进入加载中；分组折叠状态、已忽略分区折叠状态与 ignored 开关保留；先前读取结果丢弃。
- 活跃项目被移除且无后继项目：进入无根态。存在后继项目：加载后继项目，不显示被移除项目的数据；后继项目由[导航树契约](../workspace/navigation.md)决定。
- 视图不可见期间若数据根发生变化，重新可见时按切换项目处理：清空列表与过滤文本、滚动置顶、清空聚焦行并加载新项目；折叠状态与 ignored 开关保留。
- 回滚/删除成功后，文件浏览器、编辑器、Diff、GitShow 等其他视图按各自契约感知磁盘变化；Commit 不直接驱动它们。其他视图的变化也不直接驱动 Commit，Commit 只按自身刷新规则更新。
- 状态保留按下表执行。

| 状态 | 切侧栏视图、换槽或隐藏 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|
| 列表数据 | 保留；不可见期间暂停刷新；重新可见时静默刷新 | 清空并加载新项目 | 保留；重新可见时静默刷新 | 不保留；启动后首次加载 |
| 分组折叠 | 保留 | 保留 | 保留 | 保留（侧栏视图状态） |
| 已忽略分区折叠 | 保留 | 保留 | 保留 | 保留（侧栏视图状态） |
| ignored 开关 | 保留 | 保留 | 保留 | 保留（侧栏视图状态） |
| 滚动位置 | 保留（会话内） | 重置到顶部 | 保留（会话内） | 重置到顶部 |
| 聚焦行 | 保留；路径消失时聚焦最近行 | 清空 | 保留；路径消失时聚焦最近行 | 无 |
| 过滤文本 | 保留 | 清空 | 保留 | 不保留 |
| 右键菜单 | 关闭 | 关闭 | 不保留 | 不保留 |
| 刷新警告 | 保留；重新可见时静默重试 | 清除 | 保留；重新可见时静默重试 | 无 |
| 错误态 | 保留；重新可见时静默重试 | 清除并进入加载中 | 保留；重新可见时静默重试 | 无 |
| 进行中刷新 | 允许完成并更新列表数据，不更新不可见显示 | 丢弃先前结果 | 允许完成并更新 | 无 |
| 确认框 | 模态期间不可切换视图或项目；项目被外部变更时取消 | 取消且不执行 | 不保留 | 无 |

- 折叠状态、已忽略分区折叠与 ignored 开关归入侧栏视图状态声明，由侧栏框架篇持久化，不写入设置；默认两个变更分组展开、已忽略分区展开、ignored 关闭。
- 滚动位置、过滤文本与聚焦行仅在本次应用运行内保留，不跨重启。
- 视图可见性、槽位与宽度归侧栏框架篇，不属于本篇状态。
- 不做每项目数据缓存。

### 不变量

- 任一时刻只展示一个数据根的内容，绝不混入其他项目条目。
- 四渲染态互斥；就绪态下计数等于该组当前过滤后的可见条目数。
- 过滤只影响可见行与计数，不改变底层数据、排序与折叠状态。
- ignored 关闭时永不显示、永不计数；开启时只出现在独立分区，且不计入变更总数。
- 状态不得仅用颜色表达。
- 项目切换后上一项目列表立即消失，不短暂显示上一项目数据。
- 任何读取失败或操作失败都必须有可见反馈。
- 破坏性操作必须经确认并在执行前重校验状态。
- 折叠状态与列表数据相互独立。
- 同一时刻最多一个 Commit 视图实例，且只允许单行操作。

## 交互规则

### 入口、退出与可见性

- 视图入口按钮、活动栏位置、槽位替换、拖拽换区、同区排序与显隐切换由侧栏框架契约所有；本篇固定视图标识 `Commit` 与标题 `COMMIT`。
- 全局快捷键 `Ctrl+Shift+G` 打开或聚焦 Commit：不可见时显示并聚焦；可见但未聚焦时聚焦；已是当前可见且聚焦的视图时再次按下关闭该视图。快捷键全局生效并优先于终端输入，可重绑，规则归侧栏框架篇。
- 视图首次打开后常驻；切走、换槽、隐藏不销毁，状态按状态保留表处理。
- 打开视图不主动把焦点移入列表；键盘用户通过 `Tab` 进入头部控件与列表。
- 视图重新可见时按自动刷新与手动刷新规则决定整页加载或静默刷新。
- 视图内 `Ctrl+F` 聚焦过滤输入框；过滤输入框禁用时不响应。

### 鼠标

- 单击行：设置聚焦/选中，不打开。
- 双击行：按打开映射打开面板；ignored 行双击不打开。
- 右键有菜单的行：打开上下文菜单；unknown 行不响应右键菜单。
- 单击分组标题：折叠或展开该组；单击 ignored 开关：切换已忽略分区。
- 单击过滤输入框：聚焦输入框，输入即时过滤。
- 单击刷新按钮：按刷新规则刷新。
- 滚轮纵向滚动；横向滚动条在可见分组间共享；聚焦行始终滚动到可见区域。
- 悬停行显示完整相对路径工具提示；renamed 追加旧路径与新路径。
- 点击菜单外任意位置关闭菜单。

### 键盘

- `Tab` 顺序：过滤输入框 → 刷新按钮 → ignored 开关 → Changes 分组标题 → Changes 行列表（单一制表位） → Unversioned Files 分组标题 → Unversioned Files 行列表（单一制表位） → 已忽略分组标题 → 已忽略行列表（单一制表位）。ignored 开关关闭时跳过已忽略分组。
- 刷新按钮、过滤输入框或 ignored 开关上 `↓` 进入第一个分组标题；第一个分组标题上 `↑` 回到头部最后一个可用控件。折叠组的行不参与焦点序列；方向键跨越折叠组时落到下一分组标题。
- 过滤输入框中 `Esc` 清空文本并保持焦点；方向键在输入框内移动光标，不移动列表焦点。
- 分组标题上 `Enter` / `Space` 折叠或展开；`↓` 进入该组第一行；`↑` 回到上一分组标题或头部。
- 行列表中 `↑` / `↓` 逐行移动并可跨越分组边界；`Home` / `End` 到整体首行/末行；`PageUp` / `PageDown` 按可视页移动。
- 行上 `←` 折叠当前组并把焦点移到组标题；`→` 展开当前组。
- 行上 `Enter` 按打开映射打开面板；ignored 行上 `Enter` 不打开面板。
- 行上 `Shift+F10` 或 `Menu` 打开上下文菜单；unknown 行不响应。`Esc` 关闭菜单。菜单内方向键移动、`Enter` 执行、`Esc` 关闭，关闭后焦点返回原行。
- 视图内焦点时 `F5` 触发刷新；无根与加载中不响应，错误态等效重试。若与全局保留键冲突，以工作区外壳契约为准。
- 焦点环必须可见；刷新后若聚焦路径仍存在则保持，消失时移到最近行；项目切换后不保留聚焦行。
- 不使用多选、框选或拖拽行。

### 分组与滚动

- 两个变更分组默认展开，可独立折叠；ignored 开关开启时已忽略分区默认展开，可独立折叠。折叠后标题保留、计数不变、空态文案隐藏。
- 所有可见分组共用一个纵向滚动容器；内容超宽时出现横向滚动条，不超宽时不出现；分组共享横向滚动位置。
- 展开空组显示 `无变更文件`；过滤生效时展开空组显示 `无匹配文件`；另一组不受影响。
- 数据根变化时滚动置顶；同一项目内刷新尽量保持滚动锚点。

### 面板打开与落点

- 双击或聚焦行上 `Enter` 按打开映射打开面板。
- 落点为活跃项目的项目布局中当前聚焦的面板组；无面板组时创建第一个面板组；具体机制归工作区外壳契约所有。
- 命中同项目、同文件、同面板标题后缀（含无后缀）的已有面板时聚焦；不新建。
- 打开后目标面板获得焦点，Commit 视图失去焦点；返回侧栏时按状态保留表恢复视图状态。
- 打开失败必须有可见提示，禁止静默。

### 右键菜单与定位、复制流程

1. 行上右键，或聚焦行上按 `Shift+F10` / `Menu` 打开菜单；unknown 行不响应。
2. 选择 `在文件浏览器中显示`：按定位规则使文件浏览器可见并按文件浏览器篇的定位契约选中、滚动到目标；不可定位时菜单项禁用并说明原因。
3. 选择 `复制路径`：按复制规则写入剪贴板并给出非模态反馈。
4. 选择 `回滚` 或 `删除`：进入破坏性操作确认流程。

- 菜单打开后目标状态变化时，定位或复制执行前重新校验；目标不存在时提示 `文件不存在` 并静默刷新。
- 菜单关闭后焦点返回原行；原行已消失时聚焦最近行。
- 菜单与确认框的键盘、读屏与关闭规则遵循全局上下文菜单与模态契约。

### 回滚与删除流程

1. 行上右键或键盘菜单键打开菜单。
2. 选择 `回滚` 或 `删除`。
3. 模态确认框显示完整路径与后果；删除操作说明回收站恢复路径与不可用时的永久删除回退；取消则结束。
4. 确认后重新校验状态与路径；不一致则中止并提示。
5. 执行期间该行忙碌，破坏性操作串行。
6. 结束后静默刷新，并给出成功、失败或部分成功提示；删除提示说明实际采用回收站还是永久删除。
7. 焦点返回原行；若原行已消失，聚焦最近行。

- 模态确认期间阻断视图切换、项目切换与其他破坏性操作。
- 项目被外部移除或数据根变化时，确认框取消且不执行，并给出可见提示。
- 操作进行中切换项目时，操作继续完成并给出提示；若数据根已变化，不把结果写入新项目的列表。

### 项目切换与视图隐藏

- 活跃项目变化：按项目切换规则清空并加载，关闭菜单与确认框，先前读取结果丢弃。
- 视图隐藏：暂停监听与自动刷新，取消尚未触发的去抖计时；进行中的读取可完成并更新列表数据；进行中的破坏性操作继续，完成后提示仍可见。
- 重新可见：数据根已变化则清空并加载；否则执行一次静默刷新。
- 无活跃项目：无根态；头部控件禁用；不显示列表。

### 反馈

- 首次加载失败：错误态，显示分类文案、原因与 `重试`。
- 就绪态刷新失败：保留列表，显示行内警告 `刷新失败，列表可能已过期`、原因与 `重试`。
- 操作成功：非模态成功提示；操作失败或部分成功：非模态错误提示，明确已完成与未完成部分。
- 复制路径成功：非模态轻提示 `已复制路径`；失败：非模态错误提示。
- 禁止静默失败；提示内容包含操作、完整相对路径与原因。
- 操作成功/失败、刷新失败经读屏实时区域播报；常规自动刷新不播报。

## 边界与错误

### 空态与无变更

- 无活跃项目：仅显示 `选择一个项目以查看变更`，不显示分组与列表。
- 就绪但无变更：Changes 与 Unversioned Files 均显示，展开时各显示 `无变更文件`；ignored 开关开启时显示已忽略分区，无忽略条目时显示 `已忽略（0）`，展开后显示 `无已忽略文件`。
- 单组为空：仅该组显示空态文案；其他组不受影响。
- 过滤生效时，无匹配的分组展开后显示 `无匹配文件`，不显示 `无变更文件`；所有分组均无匹配时分组仍显示。
- 折叠的空组不显示空态文案。
- 列表无行（含过滤后无匹配）时，不允许双击、右键或键盘激活产生操作。

### 错误分类与恢复

| 类别 | 主文案 | 详情/提示 | 重试 |
|---|---|---|---|
| 数据根不可访问 | `数据根不可访问` | 项目根或仓库根路径与系统原因 | 有 |
| 非 Git 仓库 | `当前项目不是 Git 仓库` | 可在终端中运行 `git init` 后重试 | 有 |
| 未找到 Git | `未找到 Git` | 安装 Git 并确保其可执行文件在 PATH 中 | 有 |
| 权限不足 | `无法读取 Git 状态：权限不足` | 路径与系统原因 | 有 |
| 仓库数据损坏 | `无法读取 Git 状态：仓库数据损坏` | 索引或仓库错误摘要 | 有 |
| 其他读取失败 | `无法读取 Git 状态` | 错误摘要 | 有 |

- 所有错误态均不显示列表；`重试` 进入加载中；成功后转就绪。
- 错误态收到文件事件时可静默重试；失败时保持错误态并更新原因，不闪回加载中。
- 就绪态刷新失败不进入错误态，保留现有列表并显示行内警告 `刷新失败，列表可能已过期`；成功一次后警告消失。
- 操作失败或部分成功必须显示非模态错误提示，并刷新列表；禁止仅写日志。
- 错误提示与日志不得包含凭据值；路径与 Git 错误摘要可以显示。

### 并发与冲突

- 任一时刻最多一次状态读取进行中；刷新触发合并为一次后续读取。切换项目后，先前读取结果必须丢弃。
- 文件事件连续到达时按去抖规则合并，并设置最长更新延迟。
- 破坏性操作在视图内串行；执行中的行禁止再次操作。
- 确认框打开期间列表可刷新；确认后执行前必须重新校验状态与路径，已变化则中止。
- 回滚/删除与外部进程同时修改文件时，以 Git 命令结果为准；失败或部分成功必须可见并刷新。
- 索引被锁定或文件被占用时，操作失败并显示原因；不得重试覆盖用户文件。
- 操作进行中切换项目：操作继续完成并给出提示；若数据根已变化，不把结果写入新项目列表。
- 应用在操作中途退出时不保证事务性；下次启动按磁盘与仓库真实状态展示。

### 恢复与生命周期

- 视图隐藏或侧栏隐藏时暂停监听；重新可见时恢复订阅并执行一次静默刷新。
- 视图关闭后重开、换槽后重新显示均复用视图与状态保留表中的状态。
- 活跃项目被移除后按导航树契约激活后继项目；无后继项目则进入无根态。
- 应用重启后列表重新加载；分组折叠、已忽略分区折叠与 ignored 开关恢复；滚动位置、过滤文本与聚焦行不恢复。
- 文件系统不支持变更通知或监听启动失败时，就绪态显示行内提示 `自动刷新不可用，可手动刷新`；手动刷新始终可用；下一次项目切换或视图重开时重试监听。
- 网络盘、移动盘或权限变化导致监听失效时，同样降级为手动刷新提示。

### 性能

- 列表渲染与滚动不得阻塞前台；10,000 条目下连续滚动 5 秒无可感知卡顿（设计契约）。
- 状态读取、回滚与删除不得阻塞界面；执行期间行显示忙碌态。
- 不做分页；采用按需渲染，滚动到可视区域才构建行内容。
- 列表只保留当前数据根的一份数据；刷新时替换，不累积历史结果。
- 不可见视图不轮询、不持续刷新；监听按刷新规则暂停。
- 超大未跟踪目录展开为大量文件行、或已忽略分区包含大量目录条目时，仍须满足上述滚动与响应目标。
- 过滤在 10,000 条目下即时生效，不阻塞前台（设计契约）。

### 无障碍

- 视图为带名称的侧栏区域，名称为 `Commit`。
- 分组标题为可展开按钮，可访问名称包含标题、条目数与展开状态。
- 行列表采用列表/树语义；每行可访问名称包含状态、文件名与完整相对路径；renamed 追加旧路径。
- 状态文字标签与颜色并存，禁止仅颜色表达状态。
- 焦点环、对比度、减少动效遵循[跨域契约](../cross-cutting.md)的全局无障碍基线与主题校验。
- 上下文菜单、确认框、成功/失败提示均可键盘操作并被读屏感知；确认框焦点受困，默认焦点在 `取消`。
- 操作成功/失败、刷新失败、复制路径结果经实时区域播报；常规自动刷新不打扰读屏。
- 过滤输入框具有可访问名称 `过滤 Commit 文件`；ignored 开关具有可访问名称 `显示已忽略文件`；过滤后的计数变化可被读屏感知。
- 路径中的中文、日文、韩文与组合字符正确显示；不使用会破坏 Unicode 的截断方式。

### 平台、路径与安全

- 仅 Windows。界面路径分隔符统一显示为 `/`；系统对话框与外部程序按平台约定使用 `\`。
- 文件身份在 Windows 上大小写不敏感；显示保留原始大小写；仅大小写不同的两个条目均可显示，面板去重按规范路径。
- 支持长路径（超过 260 字符）的显示与操作（设计契约）。
- 符号链接、目录联接只操作链接项本身，不跟随目标。
- Git 链接工作树中 `.git` 为文件时同样工作；子模块与嵌套 Git 仓库只显示顶层条目，不解析内部状态。
- 索引或仓库返回的路径若规范化后越出仓库根，忽略该条目：不显示、不计数、不可操作。
- 文件被占用、只读、磁盘满或权限不足导致操作失败时，显示原因并刷新；不得静默。
- 删除优先使用系统回收站；回收站不可用（网络盘、移动盘、无权限、容量限制等）时回退永久删除，并在确认框与结果提示中说明。
- 路径中的无效编码字节以替换字符显示，工具提示显示转义形式；操作使用 Git 返回的原始路径。
- 不自动初始化仓库，不修改 Git 配置，不执行网络 Git 操作。
- 复制路径、提示与日志不得包含凭据值；路径与 Git 错误摘要可以显示。

## 验收判据

### 仓库根与四态

1. 给定项目根位于仓库子目录，当 Commit 读取成功时，数据根为仓库实际根，项目根之外的仓库变更同样显示，相对路径以仓库根为基准。
2. 给定无活跃项目，视图只显示 `选择一个项目以查看变更`，过滤输入框、刷新按钮与 ignored 开关禁用，无分组与列表。
3. 给定存在活跃项目且首次读取未返回，视图只显示 `加载中…`，不显示现有列表。
4. 给定项目根不在任何 Git 仓库内，视图只显示 `当前项目不是 Git 仓库`、原因与 `重试`，不显示列表，不出现统一归因文案。
5. 给定读取成功，`Changes (N)` 与 `Unversioned Files (N)` 两个分组标题同时出现；ignored 开关默认关闭时不出现已忽略分组。
6. 给定错误态，点击 `重试` 进入加载中；成功后进入就绪。
7. 给定切换活跃项目，上一项目条目立即消失，随后进入加载中，不出现上一项目数据的短暂闪现。

### 列表内容、计数与排序

1. 给定 added、modified、deleted、renamed、conflict、untracked 与 ignored 条目，ignored 默认不显示且不计数，其余按状态归入正确分组。
2. 给定无法识别的已跟踪状态，条目出现在 Changes，显示 `未知` 标签，工具提示含原始状态码。
3. 给定过滤文本，各组标题计数等于该组当前过滤后的条目数；折叠后计数不变。
4. 给定同一仓库在中文、英文与不同区域设置下查看，排序一致；排序键为完整相对路径、不区分大小写与重音，权重相同按原始字符串序数比较。
5. 给定 renamed 条目，只出现一行并显示新路径，工具提示含 `旧路径 → 新路径`。
6. 给定仓库根层文件，不显示父目录后缀；不同目录下的同名文件靠后缀区分。
7. 给定折叠组，行消失、标题保留；再次展开恢复；空组展开显示 `无变更文件`。
8. 每一行同时具有状态文字标签与语义色，不存在仅靠颜色区分状态的条目。
9. 给定 10,000 条目，列表可滚动、可键盘移动，连续滚动 5 秒无可感知卡顿（设计契约）。
10. 给定过滤文本，仅文件名或完整相对路径命中（不区分大小写）的行可见；renamed 按新路径匹配；各组计数等于过滤后条目数；清空后恢复全量。
11. 视图内按 `Ctrl+F` 聚焦过滤输入框并全选现有文本；按 `Esc` 清空过滤文本并保持焦点。
12. 给定过滤无匹配，各组标题计数为 `(0)`，展开显示 `无匹配文件`；切换项目后过滤文本清空。
13. 过滤不改变排序、折叠状态与底层数据。

### ignored 开关与分区

1. 默认状态下不出现 `已忽略` 分组标题，ignored 条目不显示、不计数，Changes 与 Unversioned Files 计数不受影响。
2. 开启 `显示已忽略` 后，Unversioned Files 之后出现 `已忽略（N）` 独立分区，N 为该分区当前过滤后的条目数，且不计入 Changes 或 Unversioned Files 的计数。
3. 已忽略分区中的条目只读：无回滚/删除菜单项，双击与 `Enter` 不打开面板，不提供 `在文件浏览器中显示`，提供 `复制路径` 且复制成功。
4. 头部过滤对已忽略分区生效；无匹配时显示 `无匹配文件`，无忽略条目时显示 `无已忽略文件`。
5. ignored 开关与已忽略分区折叠状态在切视图、换槽、隐藏、切换项目与应用重启后保留。
6. 关闭 ignored 开关后分区立即隐藏，过滤文本与其他分组计数、排序、折叠状态不变。
7. 已忽略分区包含目录条目时，以目录行显示且不递归展开；计数按条目计。

### 打开映射

1. 依次双击 added、untracked、deleted、modified、renamed、conflict 行，打开目标与面板标题后缀符合映射；added/untracked 经文件打开路由分派，Markdown 文件进入 Markdown 文档面板，其他文件进入编辑器面板，标题为普通标题且无后缀；deleted 为 GitShow，modified/renamed/conflict 为 Diff。
2. renamed 条目的 Diff 以旧路径读取 HEAD 内容，以新路径读取工作区内容。
3. 重复双击同一文件同一状态只聚焦已有面板，不新增面板。
4. 同一文件先打开 `(git diff)` 再双击其 added 行，出现 Diff 与无后缀普通面板两个独立面板；再次双击 added 行只聚焦已有普通面板。无后缀面板与带后缀面板互不复用。
5. 面板落在活跃项目的项目布局中当前聚焦的面板组；无面板组时创建第一个面板组。
6. 其他项目存在同路径面板时，仍在活跃项目内打开，不跨项目聚焦。
7. 文件已消失、目标内容不可读或面板创建失败时，出现可见错误提示并静默刷新，不静默。
8. unknown 状态双击：文件存在时经文件打开路由以普通标题打开；不存在时显示非阻塞提示 `文件不存在`，不创建面板，不出现 `(git unknown)` 后缀面板，并静默刷新。
9. ignored 行双击或按 `Enter` 不打开任何面板。
10. 单击行只设置焦点，不打开面板；`Enter` 与双击等效。

### 右键菜单与定位、复制

1. modified、deleted、renamed、conflict 行的菜单包含 `在文件浏览器中显示`、`复制路径` 与 `回滚`；added、untracked 行的菜单包含前两项与 `删除`；ignored 行只含 `复制路径`；unknown 行无上下文菜单。
2. 给定目标位于项目根内，选择 `在文件浏览器中显示` 后，文件浏览器可见，并按文件浏览器篇的定位契约选中目标行且滚动到可见区域。
3. 给定文件浏览器不可见，选择 `在文件浏览器中显示` 后文件浏览器恢复可见并完成定位。
4. 给定目标位于项目根外，`在文件浏览器中显示` 禁用并提示 `文件不在项目根内，无法在文件浏览器中显示`。
5. 给定目标为 deleted 状态，`在文件浏览器中显示` 禁用并提示 `文件已删除，无法在文件浏览器中显示`；给定其他工作区不存在的条目，禁用并提示 `文件不存在，无法在文件浏览器中显示`。
6. 给定工作区存在的条目，`复制路径` 复制其工作区绝对路径；renamed 复制新路径；deleted 复制由仓库根与 HEAD 记录路径拼出的绝对路径；复制成功显示 `已复制路径`。
7. 聚焦行上按 `Shift+F10` 或 `Menu` 可打开菜单；方向键移动、`Enter` 执行、`Esc` 关闭；关闭后焦点返回原行。
8. 点击菜单外任意位置关闭菜单；键盘菜单在屏幕边缘翻转且不越出屏幕。
9. 菜单打开后目标消失时，定位不执行并提示 `文件不存在`，列表静默刷新。

### 回滚与删除

1. 右键 modified、deleted、renamed、conflict 行出现 `回滚`；右键 added、untracked 行出现 `删除`；ignored 与 unknown 行无回滚/删除。
2. 确认框显示完整相对路径；取消后文件内容、Git 状态与列表均不变，也不触发刷新。
3. renamed 回滚后旧路径恢复为 HEAD 版本，新路径文件被删除，Unversioned Files 不新增残留条目。
4. added 删除先取消暂存，再移入系统回收站；取消暂存失败时磁盘文件保留；移入回收站失败时文件以未跟踪状态留存并出现部分成功提示。
5. 操作失败时出现非模态错误提示，包含操作、路径与原因；列表静默刷新后反映真实状态。
6. 确认后执行前状态已变化时，操作中止，提示 `文件状态已变化，请刷新后重试`，列表刷新。
7. 聚焦行上按 `Shift+F10` 或 `Menu` 可打开菜单；方向键移动、`Enter` 执行、`Esc` 关闭；焦点返回原行。
8. 一次破坏性操作执行期间，该行忙碌且不可再次操作或打开菜单；其他破坏性操作串行等待。
9. 回滚或删除成功后有非模态成功提示与读屏播报。
10. added 与 untracked 删除后文件出现在系统回收站；回收站不可用时永久删除，确认框与结果提示均说明回退方式。

### 项目切换与状态保留

1. 切换活跃项目后，列表与过滤文本清空、聚焦行清空、滚动置顶、菜单与确认框关闭，随后进入加载中；分组折叠、已忽略分区折叠与 ignored 开关保留。
2. 同一项目内切视图、换槽或隐藏后返回，滚动位置、过滤文本与聚焦行保留；聚焦路径消失时聚焦最近行。
3. 应用重启后，分组折叠、已忽略分区折叠与 ignored 开关恢复；滚动位置、过滤文本与聚焦行不恢复。
4. 活跃项目被移除且存在后继项目时加载后继项目；无后继项目时进入无根态；任何情况下都不显示被移除项目的数据。
5. 视图不可见期间数据根发生变化时，重新可见后清空并加载新项目，不显示上一项目数据。
6. 视图可见性、槽位与宽度变化不影响列表数据与视图内状态。

### 错误与恢复

1. 各读取错误分别显示对应主文案、原因详情与 `重试`，不出现统一归因文案。
2. 就绪态刷新失败时列表保留，显示 `刷新失败，列表可能已过期`、原因与 `重试`；下一次成功后警告消失。
3. 文件系统监听不可用时，就绪态出现 `自动刷新不可用，可手动刷新`，手动刷新仍可用。
4. 任何读取失败、刷新失败、操作失败或部分成功都有可见反馈，禁止仅记录日志。
5. 错误提示与日志不包含凭据值。

### 无障碍、平台与安全

1. `Tab` 可到达过滤输入框、刷新按钮、ignored 开关、各分组标题与各可见行列表；方向键可跨组移动行焦点。
2. 分组标题、行、菜单项与确认框具有可访问名称与角色；读屏可获知状态、完整路径、计数与展开状态。
3. 状态在颜色之外有文字标签；焦点环可见；对比度符合主题无障碍校验。
4. 中文、日文、韩文、组合字符与长路径正确显示；排序稳定。
5. 越出仓库根的路径不显示、不计数、不可操作；符号链接操作不跟随目标。
6. 视图内不存在暂存、提交、推送/拉取、分支、合并、历史、stash、冲突解决、子模块内部状态、自动 `git init`、多选或批量操作入口。
7. 过滤在 10,000 条目下即时生效且不阻塞前台（设计契约）。

## 关键决策与依据

- **数据根取仓库实际根**
  - 规则：Commit、文件浏览器、Diff、GitShow 统一使用活跃项目根所在的 Git 仓库实际根；项目根可为仓库子目录，列表覆盖整个仓库工作区。
  - 原因：项目根位于仓库子目录时仍能完整展示变更，并保证跨视图路径与仓库范围一致。
  - 边界：只从项目根向上定位，不自动初始化仓库；仓库根不可访问归入错误态。

- **只做单行操作**
  - 规则：保留单行回滚/删除；不提供多选、批量回滚/删除、框选与行拖拽。
  - 原因：破坏性批量操作风险高，安全优先于效率；单行确认与执行前重校验更容易保证结果可解释。
  - 边界：破坏性操作在视图内串行，执行中的行忙碌，其他行保持可见。

- **ignored 默认隐藏并新增显示开关**
  - 规则：默认不显示、不计数；开启后显示 `已忽略（N）` 独立分区，不计入变更总数，受头部过滤约束；忽略项只读，可复制路径，不回滚/删除、不打开面板、不在文件浏览器中定位；开关归侧栏视图状态持久化。
  - 原因：ignored 不属于变更，保持默认安静；同时提供可控的可见性，兼顾大仓库排查；全量文件查看仍归文件浏览器。
  - 边界：不改变文件浏览器的忽略文件显隐；忽略目录以目录行展示，不递归展开。

- **右键菜单新增定位与复制**
  - 规则：modified、deleted、renamed、conflict、added、untracked 行提供 `在文件浏览器中显示` 与 `复制路径`，ignored 行只提供 `复制路径`，unknown 行不提供上下文菜单；项目根内定位并选中，根外或已删除禁用并说明原因；复制工作区绝对路径，deleted 使用 HEAD 记录路径；`Shift+F10` / `Menu` 可用；保留既有回滚/删除。
  - 原因：从变更直接到达文件位置，减少在侧栏之间手动寻找；复制路径支持终端与外部工具复用。
  - 边界：定位失败提示 `文件不存在` 并刷新；不驱动文件浏览器的忽略显隐；不复制文件内容或凭据。

- **四态互斥与分类错误**
  - 规则：无根、加载中、错误、就绪互斥；错误按数据根不可访问、非 Git 仓库、未找到 Git、权限不足、仓库数据损坏、其他读取失败分类，均带原因与 `重试`。
  - 原因：统一文案无法定位问题，分类错误与重试提升可诊断性与恢复能力。
  - 边界：就绪态刷新失败不进入错误态，保留现有列表并显示行内警告。

- **打开映射与无来源后缀**
  - 规则：added、untracked、unknown 经文件打开路由，使用普通标题、无后缀；deleted 打开 GitShow `(git delete)`；modified、renamed、conflict 打开 Diff `(git diff)`；unknown 文件不存在时不创建面板，不产生 `(git unknown)`。
  - 原因：同一文件每项目只保留一个普通面板，避免提交来源污染标题与产生重复面板；Diff/GitShow 后缀用于区分只读 Git 内容。
  - 边界：面板标题后缀由各面板篇定义；本篇只拥有 Git 状态到面板类型与后缀的映射；落点与面板组创建归工作区外壳契约。

- **轻量过滤只作用于视图**
  - 规则：文件名与完整相对路径子串匹配、不区分大小写；计数随过滤；不改变数据、排序、折叠与滚动锚点；过滤文本为瞬态，项目切换清空，重启不保留。
  - 原因：大仓库中快速定位变更；过滤是观察手段，不应改变底层状态。
  - 边界：不支持通配符、正则与排除语法；不匹配状态标签与工具提示。

- **视图状态与瞬态状态分离**
  - 规则：分组折叠、已忽略分区折叠与 ignored 开关归侧栏视图状态持久化；滚动位置、过滤文本与聚焦行仅在会话内保留。
  - 原因：外观与显示偏好需要跨项目、跨重启稳定；滚动与过滤属于当下操作上下文，重启后恢复反而造成困惑。
  - 边界：视图可见性、槽位与宽度归侧栏框架篇，不写入设置。

- **刷新范围收敛、去抖与隐藏暂停**
  - 规则：仅仓库根内文件与 Git 元数据触发；尾部去抖 200 毫秒、最长 1000 毫秒；视图不可见时暂停监听与自动刷新；不轮询。
  - 原因：降低事件噪声与后台开销，同时保证可见时的最终一致。
  - 边界：监听不可用时降级为 `自动刷新不可用，可手动刷新`，手动刷新始终可用。

- **破坏性操作确认、重校验与回收站**
  - 规则：回滚/删除必须经模态确认；确认后执行前重读状态与路径；删除优先移入系统回收站，不可用时回退永久删除并在确认框与结果提示中说明。
  - 原因：防止状态漂移导致误操作，并尽量保留可恢复路径。
  - 边界：无应用内撤销；回收站不可用的回退必须明确告知；符号链接只操作链接项本身。
