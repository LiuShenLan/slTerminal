# Agent 全局文件

> 侧栏封闭视图：按内置 Agent 清单与用户自定义节点列出各 Agent 的全局配置目录，提供统一文件树浏览、过滤消费、打开/终端/复制、目录监听与刷新、错误反馈与状态保留。节点与运行时文件清单管理归 [设置中心](../panels/settings.md)；文件树的多选、批量删除、树内复制/剪切/粘贴与冲突处理继承 [文件浏览器](./explorer.md)；面板落点与标题例外登记见 [工作区外壳](../workspace/shell.md)。本视图不负责 Agent 安装、启动、状态监控、配置内容编辑与 Hooks 管理。

## 目标行为

### 视图定位与范围

- 本视图是侧栏封闭视图之一，属于应用级外壳，不属于任何项目布局；切换项目不改变其布局、状态或内容。
- 节点来源为两部分：内置 Agent 清单中声明了全局配置目录的 Agent，以及用户在设置中心 Agent 基础配置页登记的自定义节点。未声明全局配置目录且未自定义的内置 CLI 不出现。
- 本视图负责：Agent 节点列表与目录探测、Agent 根下的文件树浏览差异、显示过滤的消费、打开/终端/复制、目录监听与刷新、错误反馈、状态保留。
- 文件树通用能力（选中与多选、目录展开、文件与文件夹右键菜单、新建、重命名、删除、树内复制/剪切/粘贴、快捷键、Git 状态着色、确认弹窗与操作失败提示）继承 [文件浏览器](./explorer.md) 契约；本视图只定义 Agent 场景下的差异与落点。打开路由与编辑状态归 [编辑器](../panels/editor.md) 与 [工作区外壳](../workspace/shell.md)，设置编辑归 [设置中心](../panels/settings.md)。
- 不负责 Agent 的安装、启动、状态监控、配置内容编辑或 Hooks 管理。
- 不提供跨 Agent 搜索、对比、合并或跨项目拖拽。
- 多选选中集可以跨 Agent，但每次写入只落在目标项所属 Agent 根目录内，跨 Agent 选中不放宽写入边界。

### Agent 节点

- 节点顺序固定：内置节点按内置清单注册顺序在前，自定义节点按添加顺序在后；不提供节点排序、拖拽排序或用户自定义顺序。
- 节点行由折叠箭头、图标与显示名组成。内置节点显示品牌标识，自定义节点使用通用图标；图标均为装饰，不进入可访问名称。
- 内置清单包含 Claude Code 时，其显示名为「Claude Code」。
- 自定义节点由显示名与绝对目录构成，与内置节点同树，享有相同的展开、浏览、过滤、监听、打开与终端能力。显示名必填；目录必须是绝对路径。
- 首次安装后首次打开视图时全部节点折叠；此后打开或启动按状态保留规则恢复上次的展开集合。
- 点击节点行任意位置、按 Enter 或 Space 切换展开/收起；节点行不产生文件选中态，只显示键盘焦点环。
- 右键 Agent 节点或按 Shift+F10 打开节点菜单：复制全局目录路径、在文件管理器中显示、展开全部/收起全部。右键不改变展开状态。
- 内置节点的显示名与目录不可修改，内置节点不可删除。
- 自定义节点与运行时文件清单只在设置中心 Agent 基础配置页管理：自定义节点可添加、编辑、删除；运行时文件清单可按 Agent 增删并恢复默认。删除自定义节点只移除配置，不删除磁盘文件。本视图内不提供节点或清单管理入口。
- 当前过滤会隐藏至少一个根层条目时，节点行尾显示过滤指示；悬停提示 `过滤：<全部|自定义>；已隐藏 <N> 项；在设置中心调整`。指示不可点击，本视图不提供过滤编辑入口；隐藏数为 0、根未加载或根不可读时不显示。
- 内置与自定义节点均为空时，主体只显示空态「无可用 Agent」。

### 展开与目录探测

探测指解析 Agent 根目录的绝对路径（内置 Agent 的全局配置目录或自定义节点登记的目录），并判断其是否存在、是否可读。探测结果不持久化。

- 在以下时机重新探测：每次展开 Agent、视图从隐藏恢复显示、应用启动后首次显示、视图头「刷新」、错误态中点击「重试」。
- 展开时按探测结果进入对应状态：
  - 存在且可读：先显示「加载中…」，读取根层条目并启动目录监听；读取完成后显示文件树。
  - 不存在：显示「目录不存在」与「重试」；不加载文件树、不启动监听。
  - 存在但不可读：显示「无法读取目录」、错误摘要与「重试」；不得伪装为「目录不存在」。
- 视图存活期间目录状态变化无需用户关闭再打开视图：
  - 展开中的根被删除或变为不可读：转为「目录不存在」或「无法读取目录」，停止监听；重新展开、重试、视图头「刷新」或视图重新显示时重新探测。
  - 折叠期间根被创建：下次展开时探测到并加载，不需要重启应用或重开视图。
  - 根不存在时不监听其父目录；根创建后通过重新展开、重试、视图头「刷新」或视图重新显示恢复。
- 收起 Agent：停止监听，保留该 Agent 的展开目录集合，供再次展开与应用重启恢复。
- 节点菜单「展开全部」展开该 Agent 节点及其下当前可见的全部目录，按层读取并在后台执行；「收起全部」收起该 Agent 下当前可见的全部目录并停止未触发的读取。两者均以最新一次操作为准，过期结果丢弃。
- 自定义节点的显示名或目录在设置中心 Agent 基础配置页变更后，立即按新定义更新节点并以新目录重新探测；旧目录停止监听。
- 快速收起/展开、隐藏视图或过滤变更产生在途加载时，以最新一次探测/加载请求为准，丢弃过期结果，不闪回旧树。

### 文件树浏览

视图主体是一棵统一树：Agent 节点是顶层树项，展开后其全局配置目录的文件与目录作为子项缩进显示。整棵视图只有一个纵向滚动区，多 Agent 共享同一滚动区；不提供每个 Agent 独立滚动。

- 文件树的选中与多选、目录展开/收起、文件与文件夹右键菜单、新建文件、新建文件夹、重命名、删除（含批量删除与回收站）、树内复制/剪切/粘贴、快捷键、Git 状态着色、确认弹窗与操作失败提示，沿用 [文件浏览器](./explorer.md) 契约；本视图只定义下表差异。
- 多选沿用文件浏览器模型：Ctrl/Shift+单击、Ctrl+A、Shift+方向键与 Ctrl+Space；多选时 Enter 与双击不打开文件，行菜单只显示批量项。
- 批量删除一次聚合确认并逐项执行；删除移入系统回收站，回收站不可用时回退永久删除并说明；部分失败时成功项保留、失败项保持选中并汇总为一条错误横幅。
- 树内复制/剪切/粘贴使用应用内文件剪贴板，Ctrl+C/X/V 生效；粘贴目标必须位于 Agent 根内；复制源可来自文件浏览器或任一 Agent 根，剪切源必须位于 Agent 根内，不符合时拒绝粘贴并显示错误横幅；粘贴冲突按文件浏览器规则提供替换、跳过与取消；批量粘贴逐项执行，部分失败汇总。
- 批量操作与粘贴逐项限制在目标项所属 Agent 根目录内，不因跨 Agent 选中而放宽写入边界。
- 本视图与文件浏览器的差异如下：

| 能力 | 本视图目标 |
|---|---|
| 树根 | 对应 Agent 的根目录（内置或自定义）；没有项目根 |
| 多选与批量删除 | 沿用文件浏览器模型与聚合确认；选中集可包含不同 Agent 下的文件与目录，逐项在各自根目录内执行 |
| 树内复制/剪切/粘贴 | 沿用文件浏览器的剪贴板与冲突处理；粘贴目标须位于 Agent 根内，剪切源须位于 Agent 根内；当前项为文件夹时粘贴到该文件夹，为文件时粘贴到其父目录，无当前项时不执行粘贴 |
| 文件与文件夹右键菜单 | 沿用文件浏览器菜单结构与批量项；路径项为「复制绝对路径」 |
| 根级空白菜单 | 不提供；新建文件/文件夹与粘贴入口在文件夹行菜单，刷新入口在视图头与 F5 |
| 复制路径 | 菜单项为「复制绝对路径」，复制完整绝对路径；成功短暂提示（2 秒），失败错误横幅 |
| 面板标题 | 本篇拥有：文件名 + 最短可区分路径；跨 Agent 追加显示名；悬停显示绝对路径 |
| 展开记忆 | 每个 Agent 独立记忆已展开目录 |
| 在终端中打开 | 文件以所在目录为工作目录；文件夹以自身为工作目录 |
| 无活跃项目 | 打开文件与在终端中打开均提示「请先创建项目」 |

- 目录按需读取，每次只读取一层；已展开目录可复用缓存。折叠目录不预读内容。
- 自定义节点与内置节点使用同一树结构、只读边界与写操作规则。
- 根目录是 Git 仓库时显示 Git 状态着色；不是仓库时不显示、不报错。
- 文件操作写入限制在对应 Agent 根目录内；符号链接、联接点与越界路径按文件浏览器安全边界处理。
- 新建、重命名、删除与粘贴成功后刷新受影响目录，保留仍有效的展开状态与选中项。

### 显示过滤与运行时文件清单

过滤配置与运行时文件清单的唯一来源是 [设置中心](../panels/settings.md)，按 Agent 分别配置；本视图只消费配置，不内嵌编辑表单，不保存配置。

- 模式分「全部」与「自定义」；「全部」为默认。
- 运行时文件清单由内置默认清单与用户增删共同构成。内置 Agent 的默认清单来自内置能力清单（如会话、缓存、历史等根层名称）；自定义 Agent 没有内置默认清单，初始为空。用户在设置中心 Agent 基础配置页按 Agent 增删根层名称，并可恢复默认；恢复默认只清空用户增删，回到内置默认清单；自定义节点恢复默认后为空清单。
- 「全部」模式：显示根层全部条目，但「显示运行时文件」关闭时隐藏当前运行时文件清单中的根层条目；开启时一并显示。用户新增的条目与内置条目同等生效，用户移除的内置条目不再隐藏。
- 「自定义」模式：只显示名单中的根层条目；「显示运行时文件」开关置灰且不生效，但保留用户此前的开关值，切回「全部」后恢复作用。名单条目即使是运行时文件也显示。
- 名称匹配规则：根层条目的完整名称、不区分大小写、精确匹配；名单项不得包含路径分隔符，不支持通配符与多级匹配。运行时文件清单条目遵循与自定义名单相同的名称校验规则。
- 过滤只作用于根层：根层目录一旦显示，其子目录与文件不再按名单过滤；深层同名条目不会被单独隐藏，也不提供深层过滤。
- 被过滤的根层条目不在树中显示，不读取其内容、不展开、不启动监听；其内部变化不触发刷新。根层枚举仅用于判断显示与计算隐藏数。
- 自定义名单为空时，根层没有可显示条目，显示「当前过滤条件下无可见条目」，不得显示「空目录」。
- 设置中心 Agent 基础配置页变更过滤模式、名单、运行时文件清单或运行时开关后，文件树立即刷新：仍存在的展开目录保持展开；被过滤掉的展开路径从记忆与选中中移除。
- 过滤是纯展示行为：不移动、删除或修改磁盘文件，不改变 Git 状态。

### 打开、终端与复制

**落点与去重**

- 文件打开与终端新建的落点均为活跃项目布局中当前聚焦的面板组；项目布局尚无面板组时，按 [工作区外壳](../workspace/shell.md) 的新面板落点创建，不出现「无面板组」类错误。
- 双击文件、按 Enter 或右键「打开」：在活跃项目布局中打开编辑器面板。文件类型路由（Markdown、HTML 等）由 [编辑器](../panels/editor.md) 契约决定，本视图不另设预览形态。
- 同一绝对路径已在活跃项目布局中以相同打开形态存在时，聚焦已有面板，不重复打开。不同项目布局可以各自打开同一文件。
- 无活跃项目（项目列表为空，由 [导航树](../workspace/navigation.md) 定义）时，打开文件显示警告「请先创建项目」，不创建面板。
- 打开与终端操作不切换活跃项目，也不创建新项目。

**面板标题**

- 本视图拥有 Agent 全局文件面板的标题规则；该例外在工作区外壳与编辑器标题规则中登记，不对本视图套用相对活跃项目根的标题重算。
- 标题来源信息包括文件名、Agent 根内相对路径与 Agent 显示名。
- 标题格式：文件名 + 最短可区分路径（按需追加上级目录名）；同一面板组内仍冲突时继续向上追加；跨 Agent 时追加 Agent 显示名。悬停提示显示完整绝对路径。
- 同一面板组内不得出现无法区分的同名标题；显示名与路径仍无法区分时追加完整绝对路径。

**终端**

- 右键「在终端中打开」：在活跃项目布局中新建终端面板。
- 文件：终端工作目录为该文件所在目录。文件夹：终端工作目录为该文件夹自身。
- 无活跃项目时显示警告「请先创建项目」，不得静默失败。
- 终端面板不去重；每次操作新建一个终端面板。终端面板类型、PTY 生命周期与焦点由 [终端面板](../panels/terminal.md) 契约定义。

**复制**

- 右键「复制绝对路径」：将文件或文件夹的完整绝对路径写入剪贴板，目录不带末尾分隔符。多选时按可见行顺序每行一个绝对路径，以换行分隔。
- 复制成功显示短暂提示（2 秒）：单项为「已复制绝对路径」，多选为「已复制 N 个绝对路径」；失败显示错误横幅「复制路径失败: …」。
- 节点菜单「复制全局目录路径」：将该 Agent 根目录的完整绝对路径写入剪贴板，目录不带末尾分隔符；成功无提示，失败显示错误横幅「复制路径失败: …」。
- 节点菜单「在文件管理器中显示」：用系统文件管理器打开并定位该 Agent 根目录；根目录不存在或不可用时显示错误横幅「在文件管理器中显示失败: …」，不静默失败。
- 节点菜单的「展开全部」或「收起全部」：按当前节点展开状态显示其一，作用于该 Agent 下的当前可见目录。

### 目录监听与刷新

- 监听启用条件：视图可见、Agent 已展开、根目录存在且可读；任一条件不满足时停止监听。
- 监听范围是对应 Agent 的根目录，不依赖项目文件浏览器或项目根的监听。
- 文件系统变化合并后刷新：200 毫秒内的高频变化合并为一次刷新。
- 刷新重新读取根层与已展开目录，并刷新 Git 状态；保留展开集合；选中项仍存在时保留，已不存在时移到最近仍存在的祖先，祖先也不存在时清除；滚动位置尽量保持。
- 被过滤掉的根层目录内部发生变化时不读取、不刷新。
- 根目录被删除或变为不可读时，转为对应状态并停止监听。
- 监听建立失败或运行中失效时，显示非阻塞提示「自动刷新不可用」，保留当前文件树继续可浏览；通过收起再展开、视图重新显示、视图头「刷新」或错误态「重试」恢复。
- 视图隐藏、关闭、应用退出时停止监听并取消未触发的合并刷新计时。
- 视图隐藏期间不后台监听；重新显示时重新探测并加载所有已展开 Agent。
- 本视图触发的写操作成功后主动刷新受影响目录；与监听事件在合并窗口内合并，避免重复刷新。
- 视图头「刷新」：重新探测所有已展开 Agent，重新读取根层与已展开目录，并重建监听；刷新期间保留展开集合与仍有效的选中项。没有已展开 Agent 时按钮禁用。刷新只影响已展开 Agent，不展开折叠的节点。

### 状态保留与持久化

| 状态项 | 同面板组切换面板 | 切换项目 | 关闭视图后重开 | 应用重启 |
|---|---|---|---|---|
| Agent 节点展开集合 | 保留 | 保留 | 保留 | 保留（持久化） |
| 每个 Agent 的展开目录集合 | 保留 | 保留 | 保留 | 保留（持久化；失效路径丢弃） |
| 当前行 | 保留 | 保留 | 保留 | 不保留 |
| 多选选中集 | 保留 | 保留 | 保留 | 不保留 |
| 滚动位置 | 保留 | 保留 | 保留 | 不保留 |
| 树内剪贴板与剪切态 | 保留 | 保留 | 保留 | 不保留 |
| 错误横幅 | 保留至手动关闭或新错误替换 | 清空 | 保留 | 不保留 |
| 过滤配置与运行时文件清单 | 保留 | 保留 | 保留 | 保留（由设置中心 Agent 基础配置页持久化） |
| 自定义节点定义 | 保留 | 保留 | 保留 | 保留（由设置中心 Agent 基础配置页持久化） |
| 目录探测结果 | 保留 | 保留 | 重新探测 | 重新探测，不持久化 |

- 首次安装后首次打开视图，所有 Agent 折叠。此后启动恢复 Agent 展开集合与每棵树的展开目录集合。
- 持久化的展开路径在恢复时若已不存在、已不可读或被当前过滤隐藏，静默丢弃；持久化的 Agent 展开状态若根已不存在，仍恢复为展开并显示「目录不存在」，便于用户看到状态与重试。
- 自定义节点在设置中心 Agent 基础配置页删除后，其节点展开状态与目录展开集合一并丢弃；显示名或目录变更时按新定义重新探测，并保留仍有效的展开路径。
- 当前行、多选选中集、剪贴板、剪切态与滚动位置只在本次应用运行期间保留，不写入磁盘。
- 行内重命名输入的行内校验错误为瞬态，按文件浏览器契约处理焦点与取消，不跨应用重启；错误横幅保留至手动关闭、项目切换或成功重试。
- 目录探测结果不持久化；应用重启、视图重新显示、重新展开时重新探测。
- 视图是否打开、所在侧栏槽位与侧栏布局由 [侧栏框架](./framework.md) 持久化，不属于本视图内部状态。

## 交互规则

### 入口、出口与焦点

- 活动栏按钮：默认位于上槽末位，悬停名称为「Agent 全局文件」。点击打开到侧栏槽位，再次点击关闭；同槽打开其他视图会替换本视图；按钮可拖拽换区或同槽排序，位置以用户布局为准，槽位与拖拽规则由 [侧栏框架](./framework.md) 定义。
- 全局快捷键 `Ctrl+Shift+A` 打开/关闭本视图；全局优先级、冲突展示与「已是当前可见且聚焦视图时再次按下关闭」的行为由 [侧栏框架](./framework.md) 定义。
- 视图标题栏固定显示「Agent 全局文件」；右侧提供「刷新」与「全部收起/展开」按钮。全部收起/展开只作用于 Agent 节点，不递归展开或收起其下目录；按当前状态显示为「全部收起」或「全部展开」：存在已展开 Agent 时显示「全部收起」，否则显示「全部展开」。没有已展开 Agent 时「刷新」禁用；没有可展开或可收起的节点时该按钮禁用。
- 视图头按钮可通过 Tab 聚焦，并用 Enter 或 Space 触发；按钮提供可访问名称与悬停提示。
- 打开视图后焦点进入树：优先上次聚焦的树项，否则首个 Agent 节点。关闭视图或切走焦点时，未提交的行内操作按文件浏览器契约处理。
- 视图关闭时停止监听；再次打开时重新探测已展开 Agent，并恢复展开集合与目录展开集合。
- 视图宽度、槽位、显示/隐藏、键盘焦点在活动栏与视图间的移动，由 [侧栏框架](./framework.md) 定义。

### 鼠标

- 单击 Agent 节点行任意位置：切换展开/收起；悬停显示背景高亮。
- 单击文件或目录行：清空其他选中并选中该行；Ctrl+单击切换该行选中态；Shift+单击以锚点扩展连续选中区间；单击树空白处：清除文件选中，不折叠 Agent。
- 双击文件：仅单选时打开；双击目录：切换展开/收起；多选时双击不打开文件。
- 右键文件或目录：该行属于多选选中集时保持选中集不变，否则将其设为唯一选中项并更新锚点，然后打开上下文菜单。
- 右键 Agent 节点：打开节点菜单，不改变展开状态，也不产生文件选中态。
- 单击视图头「刷新」或「全部收起/展开」：执行对应操作。
- 悬停节点行的过滤指示：显示模式、隐藏数量与「在设置中心调整」提示。
- 滚轮：滚动统一树。
- 不提供文件或节点的鼠标拖拽排序、拖拽移动或拖入项目。

### 键盘与焦点

Agent 节点与文件树统一为一棵树，按树的标准键盘模型操作；选中与多选的完整规则沿用 [文件浏览器](./explorer.md) 契约，下表为默认键。

| 场景 | 键 | 行为 |
|---|---|---|
| 活动栏 | Enter / Space | 打开或关闭视图（由侧栏框架契约定义） |
| 树 | Up / Down | 移动到上一个/下一个可见项，并重置选中集 |
| 树 | Shift+Up / Shift+Down | 以锚点扩展或收缩连续选中区间 |
| 树 | Home / End | 移动到首个/末个可见项 |
| 树 | Right | Agent 或目录：展开；已展开则进入首个子项。文件：无操作 |
| 树 | Left | Agent 或目录：收起；已收起则移动到父项。文件：移动到父项 |
| 树 | Enter / Space | 文件：仅单选时打开；Agent 或目录：切换展开/收起；多选时 Enter 不打开文件 |
| 树 | Ctrl+A | 选中全部可见文件与目录条目 |
| 树 | Ctrl+Space | 切换当前行选中态 |
| 树 | Ctrl+C / Ctrl+X | 复制/剪切选中集到树内剪贴板 |
| 树 | Ctrl+V | 将树内剪贴板粘贴到当前目标目录 |
| 树 | F2 | 仅单选时重命名当前文件或目录 |
| 树 | Delete | 删除选中集，先聚合确认 |
| 树 | F5 | 刷新，等价于视图头「刷新」；无已展开 Agent 时与按钮同为禁用 |
| 树 | Shift+F10 或菜单键 | 打开当前选中集的上下文菜单（文件、目录或 Agent 节点） |
| 树 | Escape | 关闭上下文菜单；无浮层与内联输入时清除文件选中并取消剪切态 |
| 上下文菜单 | Up / Down / Home / End / Enter / Escape | 移动、执行、关闭 |
| 视图头 | Tab 聚焦后 Enter / Space | 执行「刷新」或「全部收起/展开」 |
| 视图内 | Tab / Shift+Tab | 在树与视图内其他可聚焦控件之间移动；顺序由侧栏框架焦点契约定义 |

- Agent 节点获得焦点时显示焦点环，不产生文件选中态；文件行保留选中态。Agent 节点不参与文件选中、批量操作、重命名与删除；焦点在 Agent 节点上时 F2、Delete 与 Ctrl+C/X/V 不作用于该节点。
- 视图头按钮提供可访问名称与状态；「全部收起/展开」的名称随当前操作变化。
- 焦点环与选中态不得只靠颜色区分，需满足对比度基线。
- 行内重命名支持 IME 与 CJK 输入；组合输入期间不触发树快捷键。
- 树向辅助技术暴露名称、层级、展开状态与选中状态；Agent 图标作为装饰不播报；过滤指示提供文本描述。
- 加载、空态、目录不存在、不可读、监听不可用等状态变化通过可访问性通知播报。
- 减少动效设置下取消展开/收起的非必要动画。

### 右键菜单

- 文件菜单：复制绝对路径、复制、剪切、打开、在终端中打开、重命名、删除。
- 文件夹菜单：复制绝对路径、复制、剪切、粘贴、展开/折叠、在终端中打开、新建文件、新建文件夹、重命名、删除。
- 多选行菜单：复制绝对路径、复制、剪切、删除；批量动作作用于整个选中集，不显示打开、在终端中打开、重命名、新建等单项动作。
- Agent 节点菜单：复制全局目录路径、在文件管理器中显示、展开全部/收起全部（按节点当前展开状态显示其一）。
- Agent 节点菜单不提供添加、删除、重命名或修改目录；这些操作只在设置中心 Agent 基础配置页。
- 不提供树空白区根级菜单；新建文件/文件夹与粘贴入口在文件夹行菜单，刷新入口在视图头与 F5；因此不提供在 Agent 根层直接新建或粘贴的入口。
- 剪贴板为空时「粘贴」禁用；剪切态下再次复制或剪切会替换剪贴板并清除旧剪切态。
- 菜单项的确认、错误、快捷键与键盘操作沿用 [文件浏览器](./explorer.md) 契约。
- 菜单在视口边缘自动翻转，不遮挡当前行。

### 反馈

- 打开文件：成功时在活跃项目布局中出现或聚焦面板，并把焦点交给该面板；失败时按 [编辑器](../panels/editor.md) 的打开路由契约提示。
- 在终端中打开：成功时出现终端面板，焦点进入终端；无活跃项目时显示「请先创建项目」警告。
- 复制绝对路径成功显示短暂提示（2 秒）；失败显示错误横幅「复制路径失败: …」。
- 复制全局目录路径：成功无提示；失败显示错误横幅「复制路径失败: …」。
- 在文件管理器中显示：成功不提示；失败显示错误横幅「在文件管理器中显示失败: …」。
- 视图头「刷新」：成功后不提示；单个 Agent 失败时按对应错误态显示，不清空其他 Agent 的文件树。
- 「全部收起/展开」与节点「展开全部/收起全部」：不弹提示。
- 树内写操作成功：刷新受影响目录，不弹成功提示。
- 树内写操作失败：错误横幅，保留至手动关闭、项目切换或成功重试；新错误替换旧文案。
- 批量删除或粘贴：成功与失败按数量聚合反馈；部分失败时成功项保留，失败项保持选中或剪切态，显示一条汇总错误横幅。
- 过滤设置变更：文件树立即刷新，不弹提示。
- 监听不可用：非阻塞提示，不打断浏览；恢复后提示消失。
- 所有警告与错误文案使用用户可理解的语言，不暴露内部实现细节。

| 当前状态 | 触发 | 目标状态 |

| 折叠 | 展开 Agent | 探测 → 加载中 → 可读（监听）/不存在/不可读 |

| 展开且可读 | 根变为不可读 | 「无法读取目录」，停止监听 |
| 不存在/不可读 | 重试、重新展开或视图重新显示 | 重新探测 |
| 展开且可读 | 视图隐藏/关闭 | 停止监听；重新显示时重新探测并加载 |
| 展开且可读 | 文件系统变化 | 合并后刷新，保持展开与有效选中 |
| 任意 | 视图头「刷新」 | 重新探测并加载已展开 Agent，保留展开集合与有效选中 |
| 存在已展开 Agent | 视图头「全部收起」 | 所有 Agent 收起，停止监听，保留展开目录集合 |
| 无已展开 Agent 且存在折叠 Agent | 视图头「全部展开」 | 所有 Agent 展开，按各自探测结果进入加载/可读/不存在/不可读 |

| 任意 | 无活跃项目时打开/终端 | 警告「请先创建项目」，状态不变 |

## 边界与错误

### 状态与错误反馈

| 状态 | 可观察结果 |
|---|---|
| 视图初次加载 | 主体显示「加载中…」，不显示文件行，不显示「空目录」 |
| 无可用 Agent | 空态图标与「无可用 Agent」 |
| 展开后根不存在 | 「目录不存在」与「重试」，无文件行 |
| 展开后根不可读 | 「无法读取目录」、错误摘要与「重试」，不得显示为不存在 |
| 文件树加载失败 | 「文件树加载失败」、错误详情与「重试」，与文件浏览器一致 |
| 空目录 | 「空目录」 |
| 过滤后无条目 | 「当前过滤条件下无可见条目」与前往设置中心的提示，不显示「空目录」 |
| 监听不可用 | 非阻塞提示「自动刷新不可用」，文件树继续可用 |
| 刷新失败（单个 Agent） | 该 Agent 显示对应错误态，其他已展开 Agent 保持可用 |
| 树内操作失败 | 错误横幅，保留至手动关闭、项目切换或成功重试；新错误替换旧文案 |
| 批量删除或粘贴部分失败 | 聚合错误横幅，成功项保留，失败项保持选中或剪切态 |
| 无活跃项目时打开/终端 | 警告「请先创建项目」，不创建面板 |
| 复制失败 | 错误横幅「复制路径失败: …」 |
| 在文件管理器中显示失败 | 错误横幅「在文件管理器中显示失败: …」 |
| 自定义节点被删除 | 节点与文件树移除，停止监听，不显示错误 |
| 加载中刷新/收起 | 取消在途加载或丢弃其结果，不出现闪烁的空态 |

- 错误横幅单行显示，超长省略；出现时占用视图头下方高度并压缩树区域。错误横幅不自动消失，保留至手动关闭、项目切换或成功重试后清除；新错误替换旧文案，悬停或聚焦可查看完整文本，读屏立即播报。
- 不同错误必须可区分：目录不存在、目录不可读、文件树加载失败、监听失败、刷新失败、复制失败、文件管理器定位失败分别有独立文案与可恢复动作。
- 错误摘要与日志只包含路径、操作与结果，不包含文件内容或凭据。

### 加载与恢复

- 自定义节点目录不存在或不可读时，与内置节点显示相同的错误态与重试入口。
- 设置中心 Agent 基础配置页删除当前展开的自定义节点后，节点与文件树立即移除并停止监听；不显示错误。
- 根目录为空：加载完成后显示「空目录」。
- 过滤后无条目：显示专用空态与设置中心提示，不与真实空目录混淆。
- 首次加载、展开目录、重新探测、过滤变更都先进入加载态；加载完成前不显示「空目录」或过期条目。
- 视图隐藏或 Agent 收起时取消在途加载与合并刷新计时；重新显示/展开时重新加载。
- 应用重启后恢复持久化的展开集合；失效路径丢弃，根不存在的 Agent 展开并显示「目录不存在」。

### 冲突与并发

- 同一绝对路径重复打开：在活跃项目布局内聚焦已有面板。
- 不同目录或不同 Agent 下的同名文件：通过标题来源消歧区分，悬停显示绝对路径。
- 已打开文件被外部删除或重命名：文件树按监听刷新；已打开面板由 [编辑器](../panels/editor.md) 契约处理外部变更，本视图不静默关闭面板。
- 自定义节点在设置中心 Agent 基础配置页被编辑或删除时，若视图正在展开该节点：按新定义重新探测或移除节点，并停止旧根监听。
- 树内粘贴名称冲突按文件浏览器契约处理：提供替换、跳过与取消；批量粘贴逐项执行，跨 Agent 粘贴同样先确认冲突。
- 快速连续展开/收起、视图隐藏/显示、过滤变更与监听事件并发：以最新探测/加载结果为准，过期结果丢弃，不闪回旧树。
- 本视图写操作与监听事件同时发生：在合并窗口内合并为一次刷新。
- 根目录删除与在途读取并发：以删除后的探测结果为准，进入不存在状态。

### 性能与资源

- 目录探测、目录读取与监听回调在后台执行，不阻塞前台交互。
- 每次展开只读取一层目录；不递归预读整棵树。「展开全部」按层后台读取，不一次性阻塞前台。
- 监听只在视图可见、Agent 展开、根可读时运行；视图隐藏、收起、关闭时释放监听与计时器。
- 高频文件系统变化合并为一次刷新；刷新不重建整棵视图，保留展开与滚动。
- 大目录或深树滚动时界面保持可交互，不因同步文件系统读取卡顿。
- 整棵视图只有一个纵向滚动区；不因 Agent 增多产生嵌套滚动。

### 安全、平台与权限

- 文件树只读取目录项名称与元数据，不读取文件内容；内容只在用户打开文件时由对应面板（编辑器或 Markdown）读取。
- 错误、日志与审计信息只包含操作、路径与结果，不包含文件内容或凭据。
- 所有写操作限制在对应 Agent 根目录（内置或自定义）内；跨 Agent 粘贴逐项校验源与目标所属根，粘贴目标与剪切源均须位于 Agent 根内，写入只落在目标根内；符号链接、联接点与路径穿越按文件浏览器安全边界处理，不写到根外。
- 自定义节点目录必须为绝对路径；不同节点指向同一目录时，按规范化绝对路径判定为同一存储范围。
- Windows 路径匹配与去重不区分大小写；同一路径按规范化绝对路径判定。
- 长路径、保留名、权限不足等平台错误显示为可读摘要，不崩溃、不伪装为目录不存在。
- Agent 配置目录可能包含敏感配置；本视图不做内容预览、不做后台扫描、不把文件内容写入日志。

### 无障碍与国际化

- 全功能键盘可达：打开/关闭视图、视图头刷新与全部收起/展开、节点展开、树导航与多选、打开、重命名、删除、树内复制/剪切/粘贴、节点与文件上下文菜单、错误关闭均无需鼠标。
- 视图头按钮可键盘聚焦与触发，具有可访问名称；自定义节点的通用图标为装饰，不播报。
- 树暴露层级、名称、展开/选中状态；多选变化时播报选中集数量；状态变化可被辅助技术播报。
- 焦点环可见且满足对比度；Git 状态、选中态与错误态不只依赖颜色。
- 行内重命名支持 IME/CJK；组合输入期间不触发快捷键。
- 文案支持中文与 CJK 路径显示；长名称截断时提供完整名称的悬停提示。
- 无障碍基线、错误分类与安全边界的跨组件规则见 [横切契约](../cross-cutting.md)。

## 验收判据

1. **入口与节点顺序**：Given 侧栏可见且存在可用 Agent，When 点击活动栏「Agent 全局文件」或按 `Ctrl+Shift+A`，Then 视图打开，标题固定为「Agent 全局文件」，内置节点按注册顺序、自定义节点按添加顺序显示；首次安装后首次打开时全部折叠；未声明全局配置目录且未自定义的 CLI 不出现。
2. **自定义节点**：Given 在设置中心 Agent 基础配置页登记显示名与绝对目录，When 打开视图，Then 该节点与内置节点同树显示且无品牌标识；展开后按对应目录加载；目录不存在时显示「目录不存在」与「重试」；显示名或目录编辑后按新定义重新探测；删除节点后节点与其展开状态消失，磁盘文件不受影响。
3. **内置节点边界**：Given 内置节点存在，When 打开其节点菜单，Then 不提供添加、删除、重命名或修改目录的入口；这些操作只在设置中心可见。
4. **空集合**：Given 内置清单与自定义节点均为空，When 打开视图，Then 只显示「无可用 Agent」空态，不显示文件行。
5. **探测三态**：Given Agent 根目录分别存在且可读、不存在、存在但不可读，When 展开节点，Then 可读时显示加载后文件树并启动监听；不存在时仅显示「目录不存在」与「重试」；不可读时显示「无法读取目录」、错误摘要与「重试」；不存在与不可读不得互相伪装，且后两者不启动监听。
6. **探测新鲜度**：Given 视图保持打开，When 根目录在折叠期间被创建或删除后重新展开，Then 无需关闭视图或重启应用即可反映最新存在状态。
7. **加载态与空目录**：Given 根层条目尚未读取完成，When 展开节点，Then 显示「加载中…」，不得短暂显示「空目录」；读取完成且确实无条目时才显示「空目录」。
8. **视图头按钮**：Given 多个 Agent 已展开且其下目录已展开，When 点击「全部收起」，Then 所有 Agent 收起并停止监听，但其下目录的展开记忆保留；When 点击「刷新」，Then 重新探测并加载已展开 Agent，展开集合与仍有效的选中项保留；没有已展开 Agent 时「刷新」禁用；存在已展开 Agent 时按钮显示「全部收起」，否则显示「全部展开」。
9. **节点菜单**：Given Agent 节点获得焦点或右键，When 打开节点菜单，Then 含复制全局目录路径、在文件管理器中显示、展开全部/收起全部；三项分别复制根目录绝对路径、在系统文件管理器中定位根目录、批量展开或收起该 Agent 下的可见目录；右键不改变展开状态。
10. **统一树共享滚动**：Given 两个 Agent 均已展开且条目超过视口，When 滚动文件树，Then 整棵视图只有一个纵向滚动条，两棵 Agent 树在同一滚动区连续滚动，不存在嵌套滚动区或每 Agent 独立滚动区。
11. **继承多选与批量删除**：Given Agent 根内存在多个条目，When 使用 Ctrl/Shift+单击选中多项并执行删除，Then 只弹一次聚合确认；确认后逐项移入系统回收站；部分失败时成功项删除、失败项保留并显示一条汇总错误横幅；多选时双击与 Enter 不打开文件。
12. **继承树内剪贴板**：Given Agent 根内存在文件与文件夹，When 使用 Ctrl+C/Ctrl+X 与 Ctrl+V 粘贴到另一目录，Then 按文件浏览器规则复制或移动；名称冲突时提供替换、跳过与取消；部分失败按数量汇总。
13. **剪贴板写边界**：Given 剪贴板中的剪切源不在任何 Agent 根内，When 在 Agent 树中粘贴，Then 拒绝粘贴并显示错误横幅；粘贴目标位于 Agent 根内时写入只落在该根内；跨 Agent 选中并批量粘贴时逐项校验各自根。
14. **右键菜单继承与差异**：Given 选中文件、文件夹或多选，When 右键，Then 菜单沿用文件浏览器结构与批量项，路径项为「复制绝对路径」；Agent 节点菜单为节点专用项；不出现树空白区根级菜单，根层新建/粘贴无入口。
15. **复制绝对路径**：Given 选中 Agent 根内任意文件或文件夹，When 执行「复制绝对路径」，Then 剪贴板内容为完整绝对路径且目录无末尾分隔符；单项成功显示「已复制绝对路径」，多选时按可见行顺序每行一个路径并显示「已复制 N 个绝对路径」；失败显示错误横幅。
16. **打开落点与去重**：Given 存在活跃项目 A，When 双击 Agent 文件，Then 在 A 的当前聚焦面板组打开编辑器面板；若 A 的项目布局尚无面板组，Then 自动创建并按新面板落点打开；同一绝对路径已在 A 中打开时聚焦已有面板，不新增面板。
17. **跨项目独立打开**：Given 项目 A 与项目 B 都存在，When 分别在 A、B 中打开同一 Agent 文件，Then 两个项目布局各自保留自己的面板；切换项目只改变显隐。
18. **无活跃项目**：Given 项目列表为空，When 双击 Agent 文件或执行「在终端中打开」，Then 显示警告「请先创建项目」，不创建面板，不切换或创建项目。
19. **标题消歧与归属**：Given 同一面板组内打开两个不同目录的同名文件，When 查看面板标题，Then 标题按最短可区分路径增补并可区分；跨 Agent 时带 Agent 显示名；悬停显示各自完整绝对路径；标题由本篇规则生成，不按活跃项目根重算。
20. **终端工作目录**：Given 存在活跃项目，When 对文件执行「在终端中打开」，Then 新终端工作目录为文件所在目录；When 对文件夹执行，Then 工作目录为该文件夹自身；每次操作新建终端，不去重。
21. **过滤默认行为**：Given 过滤为「全部」且「显示运行时文件」关闭，When 展开 Agent，Then 运行时文件清单中的根层条目不可见；在设置中心 Agent 基础配置页开启开关后，Then 这些条目立即出现，无需重开视图。
22. **自定义过滤**：Given 过滤切换为「自定义」且名单只含某根层目录名，When 展开 Agent，Then 根层只显示该目录，其余不读取、不展开、不监听；大小写不同的同名条目仍能命中；名单条目即使属于运行时文件也显示。
23. **过滤范围**：Given 自定义名单包含某名称，When 该名称只出现在已显示目录的深层，Then 深层内容不受影响；被过滤的根层目录内部变化不触发刷新；视图不提供深层过滤。
24. **过滤空态与指示**：Given 自定义名单为空，When 展开 Agent，Then 显示「当前过滤条件下无可见条目」，不得显示「空目录」；Given 当前过滤隐藏了至少一个根层条目，When 查看 Agent 节点行，Then 显示过滤指示，悬停可见模式与隐藏数量，且视图内没有过滤编辑表单。
25. **运行时清单编辑**：Given 过滤模式为「全部」且「显示运行时文件」关闭，When 在设置中心 Agent 基础配置页增删运行时文件名称，Then 隐藏集合立即按新清单变化；恢复默认后回到内置默认清单；自定义节点的默认清单为空，恢复默认后仍为空。
26. **过滤即时生效与状态保留**：Given 文件树有已展开目录，When 在设置中心 Agent 基础配置页修改过滤模式或名单，Then 树立即刷新，仍存在的展开目录保持展开，失效路径从记忆与选中中移除。
27. **监听刷新**：Given Agent 已展开且视图可见，When 根内新增文件，Then 200 毫秒内的高频变化合并为一次刷新，文件树出现该文件并刷新 Git 状态；收起 Agent 后修改目录，Then 不再自动刷新；重新展开后看到最新内容。
28. **刷新保留状态**：Given 已展开多个目录并选中一项，When 监听触发刷新，Then 展开目录保持展开、选中项仍存在时保持选中；选中项被删除时移到最近仍存在的祖先。
29. **监听失败与恢复**：Given 监听建立失败或运行中失效，When 浏览文件树，Then 显示非阻塞「自动刷新不可用」，树仍可操作；收起再展开、点击视图头「刷新」或视图重新显示后恢复。
30. **错误横幅**：Given 重命名、删除、复制、粘贴或文件管理器定位失败，When 操作结束，Then 显示错误横幅；横幅保留至手动关闭、项目切换或成功重试，不自动消失；新错误替换旧文案；目录不存在/不可读错误不被伪装为其他状态。
31. **状态保留**：Given 已展开 Agent 与若干目录并选中文件，When 同一面板组切换面板、切换项目、关闭再打开视图，Then 展开集合、目录展开集合、选中项、多选选中集、剪贴板、剪切态与滚动位置保留；When 重启应用，Then 展开集合与目录展开集合恢复，选中项、多选选中集、剪贴板、剪切态与滚动位置不恢复。
32. **键盘全可达**：Given 不使用鼠标，When 从活动栏进入视图，Then 可用 Tab 聚焦视图头并执行刷新与全部收起/展开，用方向键、Home/End、Enter/Space、Ctrl+A、Ctrl+Space 与 Shift+方向键导航和选择，用 Ctrl+C/X/V 复制、剪切与粘贴，F2 重命名、Delete 删除，F5 刷新，Shift+F10 或菜单键打开文件或 Agent 节点上下文菜单，Escape 关闭。
33. **辅助技术与焦点语义**：Given 使用辅助技术，When 浏览树，Then 可获知节点名称、层级、展开状态与选中状态；多选变化时播报选中数量；加载、错误与空态变化可被播报；Agent 节点获得焦点时不产生文件选中态，F2、Delete 与 Ctrl+C/X/V 不作用于节点。
34. **安全边界**：Given Agent 配置目录包含敏感文件，When 浏览文件树，Then 不读取或展示文件内容；所有写操作限制在 Agent 根内，错误与日志不含文件内容或凭据。
35. **性能**：Given 根目录条目很多或已展开深树，When 展开、滚动或接收高频文件变化，Then 界面保持可交互，变化合并为一次刷新，不递归预读未展开目录。

## 关键决策与依据

| 决策 | 规则 | 原因 | 边界 |
|---|---|---|---|
| Agent 全局文件为独立侧栏视图 | 属于应用级外壳，不属于任何项目布局；切换项目不改变内容与状态 | Agent 配置目录与项目无关，需要跨项目常驻入口 | 视图的打开状态、槽位与宽度归侧栏框架；项目活跃判定归导航树 |
| 统一树与单一滚动区 | 所有 Agent 共享一棵树与一个纵向滚动区，不提供每 Agent 独立滚动 | 避免嵌套滚动损害键盘、滚轮与焦点体验，保持统一树模型 | 以折叠、Home/End、视图头全部收起/展开与节点展开全部/收起全部缓解长树导航 |
| 每次展开重新探测 | 展开、视图重新显示、启动后首次显示、视图头刷新与重试都重新探测，并区分不存在与不可读 | 消除过期状态，支持目录创建/删除后的恢复，错误可诊断 | 探测结果不持久化；根不存在时不监听父目录，需经显式恢复动作重新探测 |
| 节点与运行时清单管理归设置中心 | 本视图只消费节点定义、过滤模式、名单与运行时清单，不提供管理入口 | 设置单点，避免视图内出现第二套配置编辑面 | 删除自定义节点只移除配置不删磁盘；内置节点不可修改、不可删除 |
| 过滤只作用于根层 | 名单按根层完整名称精确匹配，不支持通配符、路径与深层过滤 | 运行时噪音集中在根层；深层隐藏易造成文件丢失误解，且增加读取与刷新复杂度 | 被过滤的根层条目不读取内容、不展开、不监听；过滤为纯展示行为 |
| 过滤指示不可点击 | 节点行显示模式与隐藏数，悬停提示「在设置中心调整」 | 让用户判断条目为何不显示，同时维持配置入口单点 | 隐藏数为 0、根未加载或不可读时不显示；视图内无编辑表单 |
| 继承文件浏览器树操作 | 多选、批量删除、树内复制/剪切/粘贴、冲突处理与快捷键沿用文件浏览器契约 | 避免两套文件树行为分叉，降低学习与维护成本 | 写入逐项限制在目标项所属 Agent 根内；路径项改为「复制绝对路径」；无根层空白菜单 |
| 打开与终端落点为活跃项目布局 | 使用当前聚焦面板组；无面板组时按新面板落点创建；无活跃项目提示「请先创建项目」 | 与项目—项目布局—面板组—面板模型一致，避免静默失败 | 不切换或创建项目；同一路径在同一项目布局内去重，不同项目布局各自独立 |
| 标题由本篇拥有 | 文件名 + 最短可区分路径，跨 Agent 追加显示名，仍冲突时追加完整绝对路径，悬停显示绝对路径 | Agent 文件没有项目根作基准，需要按来源消歧 | 该例外在工作区外壳与编辑器标题规则中登记，不按活跃项目根重算 |
| 错误横幅持久且可恢复 | 不自动消失，保留至手动关闭、项目切换或成功重试；各类错误独立文案与恢复动作 | 静默失败不可接受；持久横幅便于诊断与重试 | 新错误替换旧文案；单行省略，悬停或聚焦查看全文；读屏立即播报 |
| 监听按可见性与展开状态启停 | 仅视图可见、Agent 展开、根可读时监听；隐藏、收起、关闭与退出时释放 | 控制资源占用，避免不可见视图的后台读取 | 隐藏期间不后台监听；重新显示时重新探测并加载所有已展开 Agent |
| 展开状态跨重启持久化 | Agent 展开集合与每 Agent 展开目录集合持久化；失效路径静默丢弃 | 长树恢复成本高，展开状态是用户上下文的一部分 | 选中项、多选集、剪贴板、剪切态与滚动位置只在运行期保留；根不存在的 Agent 恢复为展开并显示错误态 |
| 不提供节点排序、根层新建/粘贴与深层过滤 | 节点顺序固定为内置注册顺序加自定义添加顺序；根层无空白菜单；过滤仅根层 | 保持稳定产品顺序与统一树边界，避免增加低价值交互面 | 结构性边界；树模型与写入入口为目标态固定边界 |
