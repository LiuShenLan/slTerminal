# Agent 全局文件

> 拥有 AgentRoot 统一文件树、根层显示过滤、目录探测和视图状态；根注册与能力开关归设置中心，文件操作和终端 cwd 统一经过 PathPolicy。

## 节点与能力

- 本视图属于应用级侧栏，不随活跃项目改变根集合。节点由声明全局目录的内置 Agent 和用户自定义 AgentRoot 组成；未声明目录且未自定义的 CLI 不出现。
- 内置节点按注册顺序在前，自定义节点按添加顺序在后；不提供节点拖拽排序。显示名不是身份或授权依据。
- 同一真实目录只允许一个 AgentRoot，包括内置与自定义节点；不同词法路径、符号链接或目录联接别名不得形成重复能力或节点。
- 每个 AgentRoot 默认只读且禁止终端。“允许写入”和“允许终端 cwd”分别显式开启，读取不推导写入，写入不推导终端。
- 根和能力由 [设置中心](../panels/settings.md) 管理；本视图不提供添加、改名、改路径或删除入口。
- 删除根只移除配置，不删除磁盘文件；立即撤销该根的读取、写入和终端授权，停止监听并取消后续自动操作。其他有效根的授权不受影响。
- 已打开 Document 失去读取授权后保留内容并停止刷新；原地保存按能力并集重新判定，仍可按规则另存为。既有 PTY 不因根删除被强制终止。
- 修改根目录按撤销旧根并登记新根处理，不把旧路径能力自动延续到不同真实目录；显示名修改不影响授权。

## 展开与目录探测

- 首次使用全部节点折叠；节点行只表达展开和焦点，不参与文件多选、重命名或删除。
- 展开、重新可见、手动刷新和错误重试时重新探测真实根：可读则加载，缺失显示“目录不存在”，无权限显示“无法读取目录”，不得互相伪装。
- 根读取期间显示加载态，未完成前不显示空目录。收起节点停止其监听和未触发读取，保留声明的展开状态。
- 已展开根被删除、失去授权或不可读时立即转为对应状态并停止监听；重新可见或显式重试后才重新自动读取。
- 目录后来在磁盘创建，不通过监听父目录自动展开；用户重新展开、刷新或重试后可加载。
- “展开全部”按层后台读取当前可见目录，“收起全部”取消未触发读取；旧代结果不得覆盖新根、新过滤或新展开状态。
- 根暂时不可访问不自动删除配置或把节点改绑到其他目录。

## 统一文件树

- 所有 AgentRoot 共享一棵树和一个纵向滚动区。节点为顶层，根内文件与目录作为子项；不建立每根独立滚动容器。
- 选择、多选、目录展开、行构成、内联命名、删除、内部剪贴板、冲突对话框和键盘模型继承 [文件浏览器](explorer.md)；本节只声明差异。
- 多选可跨 AgentRoot，但每项授权和操作独立判定；跨根选中不扩大任何源或目标能力。
- 文件和文件夹菜单提供复制绝对路径、复制、剪切、打开、在终端中打开、重命名、删除及适用的粘贴／新建；无写能力时相应项禁用并说明。
- 不提供根级空白菜单，因此不能直接在 AgentRoot 根层新建或粘贴；可在根内已显示文件夹中执行获准操作。
- 内部剪贴板与 Explorer 共享。复制允许跨根，剪切仅限同一 AgentRoot 内；跨根剪切拒绝，其他合法项可按批量规则继续。
- 粘贴逐项校验源读、目标写、真实路径和链接目标；只读目标根拒绝。冲突替换、回收站和批量部分成功规则与 Explorer 相同。
- 新建、重命名、删除和粘贴只有在根写能力开启时才可执行；菜单显示不是授权，执行前必须重检。
- 过滤只是显示规则，不是授权边界；被隐藏条目不会因此被读取，其他合法入口的授权也不由过滤名单决定。
- 根属于 Git 仓库时可显示 Git 状态；非仓库不报错。状态颜色与文字遵循 Explorer，不在这里提供 Git 写操作。

## 根层显示过滤

- 展示模式、自定义名单和“显示运行时文件”按 CLI 配置；运行时文件清单按 AgentRoot 配置。设置中心是唯一编辑面。
- 内置节点在“全部”模式显示全部根层条目，运行时开关关闭时隐藏清单项；“自定义”模式只显示名单项，运行时开关保留但不生效。
- 自定义节点不归属 CLI，只消费自身运行时清单；清单项在根层隐藏。
- 名单只匹配根层完整名称，大小写不敏感，不支持路径、通配符或深层过滤。显示的目录内部不再按名单过滤。
- 被过滤条目不展开、不读取正文、不启动其私有监听；根层枚举仅用于显示和隐藏计数。
- 过滤后无条目显示“当前过滤条件下无可见条目”，与真实空目录区分；节点行可显示过滤模式和隐藏数量。
- 配置变化立即刷新受影响节点；仍有效的展开保留，被隐藏或失效路径从选择和展开记录移除。过滤不修改磁盘文件。

## 打开、终端与复制

- 打开和新建终端的落点均为活跃项目聚焦 PanelGroup，无组则创建首组；无活跃项目时提示“请先创建项目”，不创建项目或空 Panel。
- 双击、单选 `Enter` 或菜单“打开”使用统一文件路由。AgentRoot 是持久读取授权来源，因此不降级成根外会话授权，也不扩大 Markdown 相邻资源权限。
- 同一文件由 Document 按文件身份全局去重；不同项目可建立各自视图并共享实时文本、脏状态和冲突，不复制缓冲。
- 面板标题使用文件名和最短可区分根内路径，跨 Agent 冲突时追加 Agent 显示名；悬停显示完整绝对路径。标题不是 Document 或 ViewKey 身份。
- “在终端中打开”每次请求独立逻辑终端：文件使用父目录，目录使用自身。只有该 AgentRoot 已显式允许终端 cwd 时才可执行；失败不回退项目根或其他目录。
- “复制绝对路径”输出完整路径，多选按可见顺序每行一个；节点菜单可复制根路径。只写纯文本，不读取文件正文。
- 节点菜单“在文件管理器中显示”只打开已解析且仍获授权的根；失败可见。“展开全部／收起全部”只作用于该节点当前可见目录。

## 监听与刷新

- 只有视图可见、节点展开、根可读且读取授权仍有效时持有监听；任一条件不满足即释放并取消未触发计时。
- 文件事件按 200 毫秒合并，刷新根层和已展开目录；旧项目、旧根或旧过滤结果不得回填。
- 被过滤根层不因其内部变化触发读取。监听失败显示“自动刷新不可用”，保留当前树和手动刷新。
- 视图头刷新重新探测所有已展开根；无已展开根时禁用。单根失败不清空其他根。
- 显式文件操作已开始后可跨视图隐藏完成，逐项重检授权；关闭视图销毁 watcher，不取消必要的保存结果或审计。
- 目录读取、探测和监听回调均在后台执行，不递归预读折叠目录。

## 状态与隐私

| 状态 | 关闭视图后重开 | 应用重启 |
|---|---|---|
| Agent 节点展开、各根目录展开 | 按稳定根身份恢复 | 恢复同一状态并重新校验 |
| 当前行与滚动 | 恢复仍有效路径和位置 | 恢复同一状态并重新校验 |
| 多选、内联编辑、菜单、通知、错误和键盘焦点 | 清除 | 清除 |
| 内部文件剪贴板与剪切态 | 保留在应用会话 | 清除 |
| 根探测、树内容与 Git 状态 | 重新读取 | 重新读取 |
| 根定义、能力和过滤配置 | 从应用设置恢复 | 从应用设置恢复 |

- 显示名变化保留根状态；目录变化按新根处理并清除旧根的相对展开、当前行和滚动，不把旧路径状态自动套用到不同目录。
- 删除根在配置提交后清理其专属视图状态；其他根和共享内部剪贴板不因界面刷新被误删，失效源在操作时校验。
- 显式隐藏整个侧栏保留运行实例和现场；关闭重开与重启使用上述同一持久状态。
- 树只读取目录名称和元数据，正文只在用户显式打开后由 Document 路由读取。Agent 配置可能含秘密，不做后台内容扫描、内容预览或日志插值。
- 错误与审计只含操作、路径、来源、结果和必要指纹，不含凭据、文件正文、命令／目录历史正文或剪贴板。

## 验收判据

- **Given** 新 AgentRoot 未修改能力，**When** 浏览、写入或打开终端，**Then** 可读取，写入和终端分别拒绝并说明需显式开启。
- **Given** 写入开启但终端未开启，**When** 粘贴和“在终端中打开”，**Then** 粘贴可按其他校验执行，终端 cwd 仍拒绝且不回退。
- **Given** 两个根路径经链接指向同一真实目录，**When** 注册或显示，**Then** 不形成第二个 AgentRoot 或重复能力。
- **Given** 根删除后仍有打开 Document 和 PTY，**When** 授权重算，**Then** Document 保留内容并停止该根刷新，写操作按能力并集判定，既有 PTY 不被强制终止。
- **Given** 一个只读 AgentRoot 与另一可写根覆盖同一文件，**When** 保存，**Then** 另一根的写能力仍有效；删除该可写根后原地保存停止。
- **Given** 跨根复制和跨根剪切同时发起，**When** 粘贴，**Then** 复制按源读／目标写逐项执行，剪切拒绝且不扩大授权。
- **Given** 根层条目被过滤，**When** 浏览或刷新，**Then** 不读取其正文或展开内容；过滤不被当作安全授权。
- **Given** 同一文件在两个项目从 Agent 树打开，**When** 编辑任一视图，**Then** 两者引用同一 Document 和脏状态，Panel 与 ViewKey 状态仍分别保存。
- **Given** 展开、当前行和滚动已保存且多选与错误存在，**When** 关闭重开或重启，**Then** 两条路径恢复同一持久项并清除多选、错误、菜单和焦点。
- **Given** 根路径被改为不同目录，**When** 重新显示，**Then** 旧根授权与相对视图状态不自动套用，新根重新探测。
- **Given** 视图不可见或根收起，**When** 文件继续变化，**Then** 不保持该界面监听；重新可见或展开后合并复核，无过期结果回填。
