# Runtime v2

> 拥有本机自动化控制面的产品能力、安全边界与非交互语义；字段级协议只由随包参考文档和机器可读 schema 定义。

## 范围与协议边界

- Runtime 仅提供 v2，协议为本机 loopback 上的 JSON Lines 控制面；v1 方法、旧资源模型、旧发现格式和兼容层不进入产品。
- 资源名称统一为 Project、PanelGroup、Panel、Terminal、Agent；布局、终端与 Agent 行为复用工作区同一领域对象。
- 完整能力包括：发现与能力协商、状态快照、事件订阅、项目／布局／面板操作、终端输入／读取／执行／等待、Agent 会话操作和 Git 集成。
- 随包文档与 schema 是方法、参数、错误码、事件和发现格式的唯一真值；本规格不复制字段表，也不以其他文档另建协议版本。
- 仅监听 loopback，不提供远程控制、公网暴露或多实例共享控制面。

## 凭据与发现

- Runtime token 由凭据门面管理，真实值只存 Windows 凭据管理器；端点元数据与凭据分离。
- 普通端口文件、应用设置、布局、崩溃快照、备份、日志、错误和诊断包不得保存明文 token。
- 客户端经受支持的发现机制同时取得端点与认证材料；任何发现结果都不得把 token 扩散到普通状态文件。
- 设置界面只显示运行状态和非敏感端点信息，不回显 token；凭据读取、替换或删除失败必须可见。

## 调用语义

- Runtime 写命令复用交互操作同一 [PathPolicy](path-policy.md)、保存与关闭守卫、资源上限、命令目录和关闭状态机，不形成第二执行通道。
- 非交互调用不得偷弹模态框或抢占焦点。需要用户选择且调用方未提供策略时，返回结构化冲突或需要决定错误。
- 脏关闭未指定策略时返回冲突；调用方可显式选择保存或丢弃。保存失败返回失败并保持现场，不得自动转为丢弃。
- 破坏性 Git 与文件操作必须具有明确操作语义、执行前状态校验和审计；不得把模糊资源名或过期快照当作执行授权。
- 调用结果不明时返回可查询的操作状态与相关标识；调用方不得盲目重放，应用也不得把重复请求静默执行为两次破坏操作。
- 读取与订阅不得泄露凭据、剪贴板或未获授权的文件内容；终端读取只返回调用方有权访问的终端内容。

## 项目、路径与终端

- 未提供 cwd 的新终端使用目标项目根；显式 cwd 不存在、非目录或未授权时拒绝，不回退到活跃项目或另一目录。
- 指定 `project_root` 时只接受已登记项目；未指定时才按 cwd 的最深项目根匹配。cwd 不属于授权根时不改投活跃项目。
- 历史或启动恢复可按各自规则回退项目根并提示；该例外不适用于 Runtime 显式新建。
- 显式新建失败不留空 Panel；恢复失败保留 Panel、错误与重试。
- 打开文件或历史会话需要创建项目时必须由交互用户明确确认；Runtime 不隐式创建项目。
- 第二实例移交与 Runtime 使用相同项目、路径和关闭规则。

## 生命周期与事件

- Runtime 在面板或项目不可见时继续服务；应用进入关闭流程后按状态拒绝新写操作，并完成或明确终止在途请求。
- 事件按资源身份和单调代次投递；调用方取消订阅、资源销毁或应用退出后不得回填过期事件。
- 快照与事件使用同一资源模型；事件不得要求调用方依赖 v1 的 window／tab／pane 概念重建状态。
- 关闭服务不得留下监听端口、孤儿线程或失效发现记录。

## 验收判据

- **Given** v1 方法、旧资源或旧发现格式，**When** 客户端调用，**Then** 明确拒绝且不进入兼容执行路径。
- **Given** Runtime 请求关闭含脏 Document 的面板且未提供策略，**When** 处理请求，**Then** 返回冲突、所有 Panel 保留且不弹出模态框。
- **Given** Runtime 显式 cwd 越出授权根，**When** 新建终端，**Then** 请求失败且不创建空 Panel、不改投活跃项目。
- **Given** 一个破坏操作的状态校验失败，**When** 请求完成，**Then** 不执行写操作并返回可判定错误与审计结果。
- **Given** 请求执行结果暂时不明，**When** 客户端查询，**Then** 能按操作标识取得进行中、成功或失败状态，不要求盲目重放。
- **Given** 检查端点文件、设置、备份和诊断包，**Then** 均不存在明文 Runtime token。
- **Given** 面板隐藏或项目切换，**When** Runtime 持续订阅，**Then** 合法事件继续；资源销毁后不再收到其过期结果。
