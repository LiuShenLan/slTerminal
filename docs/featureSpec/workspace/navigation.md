# 导航树

> 定义侧栏导航树视图的目标行为：项目行、活跃与历史会话、项目创建/移除/重命名/排序、根目录重定位、历史删除及撤销、会话菜单、搜索、刷新与套餐余量页脚。不拥有项目与项目布局模型、焦点与关闭守卫（见 [工作区壳](shell.md)），不拥有终端面板内部行为（见 [终端面板](../panels/terminal.md)），不拥有侧栏壳与其他侧栏视图。

## 目标行为

### 视图定位与内容边界

- 导航树仅包含：项目行及其活跃会话行、历史会话节点与历史会话行；树底的「未归属会话」虚拟节点及其历史会话行。树只含这些行类型，不设额外层级行或操作入口。
- 项目模型、项目布局、面板组与面板的生命周期归 [工作区壳](shell.md)。导航树只触发项目切换、面板聚焦与已定义的会话操作，不改变面板内容或布局结构。
- 活跃会话归属其终端面板所在项目；历史会话按工作目录与项目根的最深前缀匹配归属；无法归属的历史会话进入「未归属会话」节点。
- 删除、改名、排序、重定位等操作失败必须可见，不得静默。

项目行：

- 主行：展开箭头、文件夹图标 <img src="../assets/preview/icons/folder.svg" width="14" height="14" alt="文件夹图标">（`../assets/icons/folder.svg`，14px，示意）、显示名、「当前」标签（仅活跃项目）、运行中会话数徽标（大于 0 时显示，超过 99 显示 `99+`）、根目录警示图标 <img src="../assets/preview/icons/alert-triangle.svg" width="15" height="15" alt="警示图标">（`../assets/icons/alert-triangle.svg`，15px，示意；不可访问时）。
- 副行：项目根路径，次要文本，单行截断。
- 悬停：完整显示名 + 完整根路径。
- 重命名允许显示名重复；创建时重名追加递增数字后缀；项目身份是稳定 `ProjectId`，根路径归一化后唯一，副行与悬停提示用于消歧。

活跃会话行：可选状态圆点、CLI 品牌图标 <img src="../assets/cli-svg/claude.svg" width="14" height="14" alt="CLI 品牌图标示例">（按 AgentKind 取 `../assets/cli-svg/<slug>.svg`，14px，设计契约）、会话标题、右侧迷你用量条（32×3 像素，设计契约）与用量百分比；无品牌资产时只显示标题。

历史会话节点行：展开箭头、时钟图标 <img src="../assets/preview/icons/history.svg" width="14" height="14" alt="时钟图标">（`../assets/icons/history.svg`，14px，示意）、「历史会话」、计数徽标（超过 99 显示 `99+`）。

历史会话行：状态圆点、CLI 品牌图标、标题、右侧相对时间。

「未归属会话」节点行：展开箭头、时钟图标、「未归属会话」、计数徽标。

未归属历史会话行：与历史会话行一致。

### 项目行与项目操作

**身份与不变量**

- 根路径归一化后唯一；同一根路径至多属于一个项目。
- 归一化：正斜杠与反斜杠等价、忽略大小写、去除重复分隔符与末尾分隔符（盘符根除外），按路径段边界比较。
- 允许嵌套根路径；历史归属取匹配最深前缀的项目。
- 重命名允许显示名重复；创建时重名追加递增数字后缀；显示名不参与身份与历史归属。
- 存在项目时恰好一个活跃项目。

**切换**

- 点击项目行非箭头区域，或聚焦项目行后按 `Enter`，激活该项目。
- 激活后主区显示该项目的项目布局；其他项目的项目布局隐藏但保持存活。
- 切换不终止终端、不卸载面板、不丢弃未保存修改、不改变各项目的布局与焦点。
- 活跃项目行显示「当前」标签与选中底色；点击展开箭头只切换展开状态。
- 启动时恢复上次活跃项目；不存在则取列表第一个；没有项目时无活跃项目。

**创建**

- 底部「添加项目」打开系统文件夹选择框，标题「选择项目文件夹」；只选择文件夹，不输入名称。
- 取消：导航树与工作区无变化。
- 根路径已存在：不新建；激活、展开并滚动到已有项目；通知「该项目已存在」。
- 新根路径：创建项目，显示名取文件夹名；文件夹名提取失败时使用完整路径；与现有项目显示名重名时追加递增数字后缀。项目布局按 [工作区壳](shell.md) 默认创建，终端默认目录为项目根。
- 新项目追加到项目列表末尾，成为活跃项目，展开并滚动到可见位置。
- 失败：通知「添加项目失败」及原因，导航树不变。
- 不因添加项目递归扫描或索引文件内容。

**重命名**

- 入口：项目行右键「重命名」，或项目行聚焦时按 `F2`。
- 显示名主行进入内联编辑，当前名称全选。
- `Enter` 提交；失焦提交；`Esc` 取消并恢复原名。
- 名称为空或仅含空白字符时拒绝：`Enter` 时保持编辑并显示行内错误「显示名不能为空」；失焦时视为取消并恢复原名。
- 最长 80 字符；超出部分不进入输入。
- 重命名允许显示名重复；提交后仅显示名变化，根目录、文件夹名、会话数据、面板标题、项目顺序与展开状态均不变。
- 提交立即持久化；写盘失败保留内存中的新显示名并显示错误指示（见 [设置与持久化](../settings-and-persistence.md)）。
- 编辑期间该行不响应拖拽；方向键移动文本光标，不移动树焦点。

**排序**

- 指针按住项目行非箭头区域并移动超过拖拽阈值后进入排序拖拽；仅项目行可拖拽。
- 拖拽期间显示插入指示线，标明释放后的位置；释放后项目移动到该位置并立即持久化。
- `Esc` 或释放在有效插入区域外取消，顺序不变。
- `Alt+Up` / `Alt+Down` 将焦点项目上移/下移一位；项目右键菜单提供「上移」「下移」；三者等价。
- 位于首位时「上移」禁用，位于末位时「下移」禁用；禁用项显示原因。
- 排序不改变活跃项目、展开状态与焦点；新项目始终追加到末尾。
- 排序写盘失败保留内存顺序并显示错误指示。

**项目右键菜单**

- 项目行右键菜单包含「重命名」「上移」「下移」「重新定位根目录」「移除项目」。
- 「移除项目」使用危险色；「上移」「下移」在边界禁用。
- 菜单在指针位置或焦点行处弹出；点击外部或按 `Esc` 关闭。

**重新定位根目录**

- 项目右键「重新定位根目录」打开系统文件夹选择框，标题「选择新的项目根目录」。
- 取消：项目与导航树无变化。
- 新根与当前根相同：视为无变化，不写盘。
- 新根与其他项目根相同：不提交，通知「该根目录已属于其他项目」。
- 成功：更新项目根并立即持久化；保留项目身份、显示名、列表顺序、项目布局、面板与展开状态。
- 既有终端继续使用原工作目录；新终端与文件浏览器使用新根。
- 立即按最新项目根集合重算历史归属：匹配新根的会话归入该项目；匹配其他项目根的归入对应项目；不再匹配任何项目根的进入「未归属会话」节点。
- 项目行副行与悬停提示立即更新；根目录不可访问警示按新根重新计算。
- 失败：通知「重新定位根目录失败」及原因，项目保持原状态。

**移除**

- 项目右键「移除项目」；导航树只触发移除请求，不自行弹出确认框或执行销毁。
- 确认框由 [工作区壳](shell.md) 拥有：列出将终止的终端数与脏面板标题，说明项目布局将关闭、未保存修改按关闭守卫处理；取消则不产生变化。
- 确认后由工作区壳关闭该项目布局并终止其终端，导航树移除项目行。
- 移除活跃项目后：激活列表中的下一个项目；没有下一个时激活上一个；都没有时进入无项目空态。
- 磁盘文件与历史会话记录不删除；重新添加同一根路径后历史会话重新归属。
- 不再匹配其他项目根的历史会话进入「未归属会话」节点。移除不提供撤销。

**根目录不可访问**

- 项目根不存在、无权限或不可访问时，项目行显示警示图标，悬停「项目根目录不可访问」。
- 项目仍可激活、重命名、排序、重新定位与移除。
- 历史归属仍按根路径字符串词法匹配，不因目录暂时不可访问而改变。

### 活跃会话

- 活跃会话 = 运行中的 CLI 会话；纯 shell 终端不建行。
- 归属其终端面板所在项目；所有项目的活跃会话都可显示，不限于活跃项目。
- 仅当项目展开时可见；项目收起时项目行徽标仍反映数量。
- 同一项目内按最近事件时间降序排列，变化时实时重排。
- 行内容：可选状态圆点、CLI 品牌图标（14×14 设计契约，未识别时不显示）、标题（实时跟随终端面板标题，空时「终端会话」）、迷你用量条（32×3 设计契约）与百分比。
- 百分比四舍五入并限制在 0–100；无数据时显示 `--`；用量条分四档（小于 50%、50%–69%、70%–89%、90%–100%），颜色取主题语义 token。
- 状态与用量必须有文本或标签，不得只靠颜色表达。
- 标题过长单行截断；悬停显示完整标题、CLI 名称与工作目录（可用时，缺失项省略）。
- 选中底色：焦点位于活跃项目的终端面板时，对应会话行；否则最近事件最新的活跃会话行。同一时刻最多一条。
- 点击或 `Enter`：若所属项目不是活跃项目，先激活；随后切换到终端面板所在面板组并聚焦该面板。连续点击以最后一次为准。
- 终端面板已不存在：移除该行、更新项目徽标、通知「会话已结束」。
- 会话结束、重启或从工作区移除时，行实时消失，项目徽标同步减少。

活跃会话右键菜单：

- 右键活跃会话行，或聚焦后按 `Shift+F10` / 菜单键，打开菜单。
- 「聚焦」：执行与点击行相同的激活与聚焦；面板不可定位时通知「会话已结束」并移除行。
- 「复制恢复命令」：CLI 支持生成恢复命令时可用；复制成功通知「恢复命令已复制」；命令为空时通知「无法生成恢复命令」；剪贴板失败通知「复制失败」；CLI 不支持时禁用并显示原因。
- 「关闭面板」：向工作区发起关闭请求，按 [工作区壳](shell.md) 的关闭守卫处理脏面板；取消则面板与会话保留；关闭后面板销毁、会话结束、行消失。
- 不提供「删除会话记录」；关闭面板不删除该 CLI 的历史会话记录。
- 菜单项支持方向键、Home/End、Enter；禁用项跳过；`Esc` 关闭；焦点返回会话行。

### 历史会话

**来源与归属**

- 历史会话来自各 CLI 提供的历史记录；本篇定义展示、搜索、恢复、分支、复制与删除契约，不定义各 CLI 的恢复命令内容。
- 工作目录按项目根归一化规则处理；等于项目根或位于其下均可归属，按路径段边界判断。
- 多个项目根匹配时归属最深前缀；工作目录为空、为相对路径或无法匹配任何项目根时进入「未归属会话」节点。
- 根路径重复的项目不存在；根目录暂时不可访问不改变词法归属。

**历史会话节点**

- 仅在所属项目展开且历史会话总数大于 0 时渲染；默认收起；点击节点行或箭头切换。
- 文案固定「历史会话」；计数徽标：无搜索时为该项目全部历史会话数，搜索时为当前可见匹配数（项目自身命中时为总数）。
- 无历史会话时不渲染，不显示占位。

**「未归属会话」节点**

- 固定位于全部项目行之后；仅当未归属历史会话总数大于 0 时渲染；默认收起。
- 点击节点行或箭头切换；计数徽标规则同上。
- 无未归属历史会话时不渲染，不显示占位。
- 工作目录为绝对路径且可访问的行支持恢复与分支；工作目录为空、为相对路径或不可访问的行仅支持复制恢复命令与删除，双击打开「会话目录不存在」对话框。
- 行内容、排序、状态、CLI 图标、标题、相对时间与悬停规则同历史会话行。
- 双击可恢复行时按普通恢复流程新建以该工作目录为根的项目；恢复完成后该行移入新项目。

**历史会话行**

- 按会话文件修改时间降序；时间无效的排最后。
- 状态圆点始终显示，三态：运行中（可靠关联到运行中 CLI 会话）、已完成（CLI 记录表明已结束）、未知（无法确认）。无法确认时不得显示为已完成；未知使用中性色。
- CLI 品牌图标识别时显示（14×14 设计契约）；标题取会话标题，缺失取会话 ID 前 8 位，ID 缺失显示「未知会话」。
- 相对时间六档：小于 1 分钟「刚刚」；小于 1 小时「N 分钟前」；小于 24 小时「N 小时前」；小于 7 天「N 天前」；同一年内「MM-DD」；其他「YYYY-MM-DD」；时间无效显示 `-`。
- 视图打开期间每 60 秒（设计契约）重算相对时间。
- 悬停按顺序显示可用项：完整标题（仅截断时）、CLI 名称、工作目录、首条提示词预览；缺失项省略。提示词预览超过 200 字符（设计契约）截断；工作目录按记录原值显示。
- 标题过长单行截断。
- 单击选中该行；`Ctrl+单击` 切换；`Shift+单击` 选择连续范围；树区聚焦时 `Ctrl+A` 全选可见历史会话行（含未归属节点下的行）；`Esc` 清除选中。
- 搜索词变化、切换项目、关闭导航树、相关行消失时清除选中。
- 多选仅限历史会话行；多选时右键菜单只提供「删除所选（N）」，复制与分支仅支持单行。
- 右键未选中行先选中该行；右键已处于多选中的行保持多选。
- 历史数据刷新后已不存在的行消失，计数更新，相关选中清除。

**双击行为**

| 行状态 | 结果 |
|---|---|
| 运行中且终端面板可定位 | 激活所属项目，切换到对应面板组并聚焦终端面板；不弹确认框 |
| 运行中但面板不可定位 | 对账并移除或更新行，通知「未找到运行中的会话」 |
| 工作目录缺失、不可访问或不是目录 | 打开「会话目录不存在」对话框 |
| 其他 | 执行恢复流程 |

**恢复流程**

- CLI 不支持恢复时，双击通知「该 CLI 不支持恢复会话」，不创建面板。
- 支持时按以下步骤执行：
  1. 以工作目录匹配项目根，取最深前缀项目。
  2. 无匹配项目（含从未归属节点发起）时，按 [工作区壳](shell.md) 创建项目：根为工作目录，显示名取目录最后一段，项目布局按默认创建。
  3. 激活目标项目，展开并滚动到可见位置。
  4. 由 [终端面板](../panels/terminal.md) 在目标项目的面板组中创建终端面板并分配编号；初始标题取历史标题，缺失取 ID 前 8 位。
  5. 终端就绪后注入该 CLI 的恢复命令并回车。
  6. 就绪等待按 [终端面板](../panels/terminal.md) 的恢复等待契约：PowerShell 系最长 10 秒（设计契约），cmd 约 0.5 秒（设计契约）；超时后仍尝试注入一次；注入失败按恢复失败处理。
- 恢复中该行显示「恢复中…」；同一行重复双击忽略；不同行可并发。
- 同一目标根路径的项目创建幂等，后到的恢复复用已创建项目。
- 失败通知「恢复会话失败」，含会话 ID 前 8 位与原因，并提供「重试」；不影响其他项目、面板或终端。
- 恢复失败保留已创建的项目与面板；重试复用，不重复创建。
- 恢复创建的项目、项目布局与终端面板按工作区规则持久化。

**分支恢复**

- 仅当前 CLI 支持分支恢复时，历史菜单显示「分支恢复」；不支持时不显示。
- 基于原会话创建新分支会话，原会话不变；按普通恢复流程打开终端面板并注入分支恢复命令。
- 工作目录缺失的孤儿行禁用并显示原因；运行中历史会话允许分支恢复。
- 失败通知「分支恢复失败」及原因。

**复制恢复命令**

- 仅单条历史会话行可用。
- CLI 支持且命令非空：写入剪贴板并通知「恢复命令已复制」。
- 不支持或命令为空：不写入剪贴板，通知「无法生成恢复命令」。
- 剪贴板写入失败：通知「复制失败」及原因。

**删除**

- 运行中的历史会话不可删除；菜单项禁用并显示原因；按 `Delete` 时通知「运行中的会话不可删除」。
- 单条删除：直接删除来源记录，不弹确认；行立即消失、计数更新，无需等待重新扫描；显示 5 秒（设计契约）撤销提示「已删除 1 个历史会话」，附「撤销」操作。
- 批量删除：多选后选择「删除所选（N）」，先弹确认框，标题「确认删除」，正文 `确定删除 N 条历史会话？删除后 5 秒内可撤销。`
- 选中行包含运行中会话时自动排除，并在确认框注明「M 条运行中会话已跳过」；全部为运行中时不打开确认框，通知「运行中的会话不可删除」。
- 确认后删除对应历史记录，行立即消失、计数更新；显示合并撤销提示「已删除 N 个历史会话」，附「撤销」。
- 删除失败：行保留或恢复，通知「删除会话失败」及原因。
- 撤销：恢复被删除的原记录与原顺序，计数与列表位置恢复；多选批量删除由一次操作恢复全部。
- 撤销窗口为 5 秒，自删除完成起算；提示遵循通知基线（悬停暂停倒计时、可关闭）。关闭提示即放弃撤销。
- 撤销窗口结束、关闭撤销提示、应用窗口关闭或应用退出后，删除永久化；撤销操作失败时通知「撤销删除失败」及原因，删除保持永久。
- 同一时刻只有一个未决撤销；新的删除替换当前撤销提示，先前删除立即永久化。
- 删除与撤销结果持久化；永久删除后刷新或重启不重新出现。
- 从「会话目录不存在」对话框删除同样按单条删除规则处理。

**「会话目录不存在」对话框**

- 标题「会话目录不存在」；正文显示会话标题或 ID 前 8 位，以及缺失的工作目录；工作目录为空时省略目录行。
- 操作：「复制恢复命令」（CLI 支持时可用）、「删除会话」、「关闭」。
- 按 `Esc` 或点击遮罩关闭；焦点返回原历史会话行。

**历史会话右键菜单**

| 操作 | 普通行 | 孤儿行 | 运行中行 |
|---|---|---|---|
| 复制恢复命令 | 可用 | 可用 | 可用 |
| 分支恢复 | CLI 支持时可用 | 禁用 | CLI 支持时可用 |
| 删除 | 可用 | 可用 | 禁用 |

- 未归属节点下的行按工作目录可用性适用同一矩阵。
- 菜单在指针位置或键盘焦点行处弹出；支持方向键、Home/End、Enter；禁用项灰显、跳过、悬停显示原因；危险项使用危险色；点击外部或 `Esc` 关闭。

### 搜索

- 输入即过滤；首尾空白忽略；纯空白等同未搜索；不区分大小写的子串匹配。
- 匹配范围：项目显示名、项目根路径；活跃会话标题；历史会话标题或其 ID 前 8 位、工作目录、首条提示词。未归属节点下的行同样匹配。
- 项目根路径与工作目录在匹配前做与查询词相同的斜杠归一化；大小写忽略。
- 不匹配文件内容、文件名或其他视图的数据。
- 输入法组合期间不触发过滤；组合结束后按最终文本过滤。

结果规则：

- 项目自身命中：显示项目行并派生展开；显示全部活跃会话；历史节点在总数大于 0 时显示，默认收起，可正常展开/收起并显示全部历史。
- 项目自身未命中但存在命中子项：显示项目行并派生展开，只显示命中的活跃/历史会话行。
- 活跃会话命中：项目派生展开，只显示命中活跃会话行。
- 历史会话命中：项目与历史节点派生展开，只显示命中历史行。
- 未归属节点仅在存在命中未归属历史行时显示并派生展开，只显示命中行。
- 项目、活跃会话、历史会话均未命中时隐藏项目。
- 命中链上的祖先节点自动展开且不可收起；项目自身命中时的历史节点除外（默认收起且可手动展开/收起）。
- 清空搜索后恢复搜索前的手动展开状态，包括未归属节点。
- 搜索期间历史与未归属计数徽标显示可见匹配数；项目自身命中时显示总数。项目行运行中会话数徽标始终反映实际运行数量，不随搜索过滤。

高亮：

- 项目显示名、项目行副行根路径、活跃会话标题、历史标题（或回退的 ID 前 8 位）中的命中子串全部高亮，不区分大小写。
- 工作目录与首条提示词仅在悬停提示中可见，提示中的命中子串同样高亮；根路径在副行与悬停提示中均高亮。
- 高亮使用主题搜索高亮语义 token，仅暗色；不改变文本、截断、匹配与排序结果；截断时高亮可见部分；标签标注该行命中。

行为约束：

- 搜索只过滤展示，不改变活跃项目、项目布局、面板、终端或历史数据。
- 搜索结果中的项目行与活跃会话行仍执行正常激活/聚焦。
- 搜索词在导航树关闭或应用重启时清空；切换项目、刷新数据期间保留；不写入持久化状态。
- 清除按钮保持焦点在搜索框。
- 搜索框聚焦时按 `Esc`：清空查询并将焦点移到活跃项目行；查询已空时只移回焦点。
- 树内按 `Ctrl+F` 聚焦搜索框；不抢占终端、编辑器等其他区域。
- 刷新或数据变化后结果实时更新；消失的选中行清除选中。
- 1,000 条项目/会话行规模下，输入到结果更新不大于 100 毫秒（设计契约）。

### 刷新与数据更新

**手动刷新**

- 顶部刷新按钮悬停「刷新导航数据」。
- 点击后：重新扫描全部历史来源并直接读取来源数据；刷新套餐余量全部来源；对活跃会话与工作区终端面板对账，移除已结束行。
- 不重新加载项目列表。
- 进行中按钮显示进度并禁用；再次点击忽略、不排队。
- 成功不弹通知；悬停提示显示「上次更新 HH:mm:ss」。
- 失败通知「刷新失败」及失败来源与原因；旧数据保留。
- 手动刷新始终可用，与自动扫描开关无关。
- 不改变展开状态、搜索词、活跃项目或面板焦点。

**自动扫描**

- 导航树打开期间按配置周期扫描历史来源；默认 3 秒，可配置 2–300 秒（设计契约）；配置入口见 [设置中心](../panels/settings.md)。
- 自动扫描禁用时只在手动刷新时扫描。
- 首次打开：立即显示上次扫描结果，并发起新扫描；关闭后停止周期扫描；再次打开先显示上次结果再扫描。
- 展开或收起节点不触发扫描。
- 自动扫描不阻塞交互，不显示全屏加载态。

**多来源与失败**

- 单一来源失败：该来源保留旧数据并标记过期，其他来源使用新数据。
- 全部来源失败：保留全部旧数据并显示错误指示。
- 无旧数据且扫描失败：项目展开区或未归属节点显示行内「历史会话加载失败，点击重试」。
- 自动扫描失败不重复弹通知，只在刷新按钮旁显示警示图标；悬停显示失败来源与原因。
- 后台扫描配置读取失败：仍执行首轮扫描与手动刷新，不启动周期扫描，显示配置错误指示。
- 警示图标在下次刷新成功后消失。
- 每次扫描后按最新项目根重新计算未归属与项目历史归属。

**活跃会话更新**

- 活跃会话由工作区终端事件实时更新，不依赖历史扫描或手动刷新。
- 会话结束、标题变化、状态变化、用量变化时对应行实时更新。

### 套餐余量页脚

- 显示条件：套餐余量后台任务启用且至少配置一个来源；页脚上方有分隔线。
- 后台任务禁用或来源为空时整个页脚隐藏；底部操作区分隔线保留。
- 每个来源一行：14×14（设计契约）品牌图标 + 一行文案；图标加载失败时隐藏图标只保留文案。套餐来源示例：DeepSeek <img src="../assets/cli-svg/deepseek.svg" width="14" height="14" alt="DeepSeek 图标">（`../assets/cli-svg/deepseek.svg`）、Kimi <img src="../assets/cli-svg/kimi.svg" width="14" height="14" alt="Kimi 图标">（`../assets/cli-svg/kimi.svg`）。
- 页脚不显示标题，不把来源名称作为可见文本；来源名称可出现在悬停提示中。
- 行有悬停高亮，可点击、可用键盘聚焦。

文案优先级：

1. 冻结：「已冻结」。
2. 有金额：货币符号 + 原始金额；人民币 `¥`，美元 `$`，其他显示原货币代码。
3. 有双窗用量：`5h xx% · 7d xx%`，xx 为已用百分比。
4. 其余：`--`。

悬停提示：

- 冻结：`{来源名称} 月限额触顶，已冻结`。
- 金额：`上次更新 HH:mm:ss`。
- 双窗：`5h 窗（重置时间）`、`7d 窗（重置时间）`、`上次更新 HH:mm:ss`；缺失的重置时间省略。
- 无数据：首次查询「查询中…」；失败「查询失败，点击重试」，有上次成功时间时追加；过期「数据可能过期」，有上次成功时间时追加。
- 上次更新时间为 0 或缺失时省略该段。

重置时间：小于 1 小时 `Xm 后重置`；小于 24 小时 `Xh Ym 后重置`（分钟为 0 时 `Xh 后重置`）；达到或超过 24 小时 `M月d日 HH:mm 重置`；已过期 `0m 后重置`。

刷新：

- 点击任意余量行或聚焦后按 `Enter`：立即刷新全部来源。
- 节流窗口 5 秒（设计契约），从上次实际发起刷新起算；窗口内不发起请求，行显示禁用态，悬停「刷新冷却中」。
- 刷新进行中行显示进度，期间点击忽略。
- 刷新失败保留旧值，行显示警示图标与失败原因，不弹阻塞通知。
- 初始拉取失败：仍显示已配置来源行，文案 `--`，警示图标与重试提示。
- 来源配置尚未加载完成时页脚隐藏；配置读取失败显示单行「余量配置读取失败，点击重试」，点击重新读取。
- 导航树关闭时页脚不可见；重新打开按上次结果显示。

显隐与结果保留：

- 后台任务禁用时保留最后一次结果；重新启用立即显示，不出现空白闪烁；结果超过 30 秒（设计契约）未更新时立即刷新。
- 导航树关闭期间保留最新结果；重新打开立即显示，超过 30 秒未更新时发起刷新。
- 后台任务在导航树关闭期间产生的新结果，打开时直接显示。

键盘与输入：余量行标签包含来源、状态、数值与操作提示；冻结、失败、过期不得只靠颜色表达。

### 行度量与状态保留

- 单行行高：节点行 28 像素，会话行 30 像素（设计契约）；项目行为双行，行高随两行内容与 DPI 缩放。
- 每级缩进 15 像素（设计契约），显示 1 像素层级引导线。
- 树区仅纵向滚动；长文本单行截断并悬停显示完整文本。
- 「当前」标签、运行中会话数徽标、历史与未归属计数徽标、相对时间固定在行右端。
- 顶部标题行、搜索区、套餐余量页脚、底部操作区不随树内容滚动。
- 悬停底色、选中底色、键盘焦点环可区分；危险项使用危险色；禁用项灰显；颜色全部引用主题语义 token，仅暗色。
- 尊重系统「减少动态效果」：进度旋转改为静态指示。
- 计数超过 99 显示 `99+`（设计契约）。

状态矩阵：

| 状态 | 同面板组切面板 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|

| 项目展开状态 | 保持 | 保持 | 保持 | 持久化恢复 |
| 历史节点展开状态 | 保持 | 保持 | 保持 | 持久化恢复 |
| 未归属节点展开状态 | 保持 | 保持 | 保持 | 持久化恢复 |
| 树区滚动位置 | 保持 | 保持 | 保持 | 持久化恢复 |
| 搜索词与结果 | 保持 | 保持 | 清空 | 清空 |
| 历史会话多选 | 保持 | 清空 | 清空 | 清空 |
| 未决删除撤销 | 保持 | 保持 | 保持（提示不随视图关闭消失） | 永久化 |

- 项目数据（显示名、根路径、顺序、活跃项目）自动持久化；写盘失败保留内存状态并显示错误指示。
- 异常退出后按最近一次成功持久化的状态恢复；写盘失败期间的变化可能丢失，并在下次启动显示错误指示。
- 项目布局按工作区壳契约持久化。
- 展开状态按项目、历史节点与未归属节点分别持久化；滚动位置按导航树单例持久化。
- 搜索词、多选、菜单、行内编辑、拖拽、对话框不持久化。
- 历史删除永久化后结果持久化；刷新后不重新出现。
- 恢复创建的项目、项目布局与终端面板按工作区规则持久化。

## 交互规则

### 入口与默认状态

- 默认配置下「导航树」位于活动栏上区第一个按钮，悬停「导航树」。
- 无已保存侧栏状态时启动默认打开；已保存状态优先。
- 视图注册、显隐、替换与视图快捷键 `Ctrl+Shift+N` 由 [侧栏框架](../sidebar/framework.md) 定义；本篇只定义导航树内容。
- 导航树关闭时停止周期扫描与相对时间定时器，保留展开状态与滚动位置，清空搜索词。

### 鼠标

- 单击项目行非箭头区域：激活项目；单击箭头：切换展开。
- 单击活跃会话行：激活所属项目并聚焦终端面板。
- 单击历史节点行或未归属节点行：切换展开。
- 单击历史会话行：选中。
- 双击历史会话行：按双击行为表执行。
- 右键项目行：项目菜单；右键活跃会话行：活跃会话菜单；右键历史会话行：历史会话菜单；右键节点行不打开菜单。
- 悬停行显示悬停底色；悬停截断文本显示完整提示。
- 滚轮纵向滚动树区。
- 点击菜单外部、另一行或按 `Esc` 关闭菜单。

### 键盘

树区为单一复合控件，只有一个 Tab 停靠点；搜索框、刷新按钮、添加项目按钮与每个余量行各自是独立 Tab 停靠点。

| 按键 | 行为 |
|---|---|
| `Tab` / `Shift+Tab` | 进入/离开树区；进入时聚焦上次聚焦行，否则活跃项目行，再否则第一个可见行 |
| `↑` / `↓` | 在可见行间移动焦点 |
| `→` | 节点收起时展开；已展开时移到第一个子行 |
| `←` | 节点展开时收起；已收起或无子行时移到父行 |
| `Home` / `End` | 第一个/最后一个可见行 |
| `Enter` | 项目行激活；活跃会话行聚焦；节点行切换展开；历史会话行恢复或聚焦 |
| `Space` | 项目行、历史节点、未归属节点切换展开；会话行无动作 |
| `Shift+F10` / 菜单键 | 当前行打开右键菜单 |
| `Ctrl+A` | 全选当前可见历史会话行（含未归属节点下的行） |
| `Shift+↑` / `Shift+↓` | 扩展或收缩历史会话多选范围 |
| `Delete` | 删除选中的历史会话；无选中时删除焦点历史行；焦点不在历史行且无选中时无动作；运行中行排除 |
| `Esc` | 关闭菜单/对话框；清除多选；搜索框聚焦时清空并返回树区；行内编辑时取消 |
| `Ctrl+F` | 焦点在导航树内时聚焦搜索框 |
| `F5` | 焦点在导航树内时刷新导航数据 |
| `F2` | 项目行进入内联重命名；非项目行无动作 |
| `Alt+Up` / `Alt+Down` | 焦点项目上移/下移一位；焦点不在项目行时无动作 |

- 菜单内：方向键移动，Home/End 首尾，Enter 执行，Esc 关闭；禁用项跳过。
- 对话框内：Tab 在按钮间循环，Enter 执行主操作，Esc 取消。
- 行获得焦点时显示焦点环；焦点环与选中底色可同时存在且可区分。
- 禁用行或禁用控件不进入 Tab 顺序。
- 行内编辑期间方向键与 Home/End 用于文本编辑；Enter 提交，Esc 取消。

### 焦点恢复

- 树区焦点离开再返回时恢复到上次聚焦行。
- 项目激活后焦点留在项目行；重命名提交或取消后焦点回到项目行；排序结束后焦点回到被移动的项目行。
- 活跃会话聚焦后，焦点按工作区壳契约移到终端面板。
- 恢复历史会话后，焦点按工作区壳契约移到新终端面板。
- 移除项目后，焦点移到相邻活跃项目行；没有项目时，有未归属节点则聚焦该节点，否则移到「添加项目」按钮。
- 删除历史会话后，焦点移到下一条可见历史行；没有时移到历史节点行；历史节点消失时移到项目行。
- 菜单关闭后焦点返回打开菜单的行；确认框取消后焦点返回原行。
- 搜索框按 `Esc` 清空后，焦点移到活跃项目行；不可见时移到第一个可见行。
- 输入法组合期间不移动焦点、不触发过滤。

### 右键菜单通用行为

- 指针右键在指针位置弹出；键盘在焦点行位置弹出。
- 菜单项执行后关闭；点击外部或按 `Esc` 关闭。
- 禁用项灰显、不可聚焦、点击无动作且不关闭菜单；悬停显示禁用原因。
- 危险项使用危险色；不提供子菜单。

### 拖拽排序

- 仅项目行参与排序拖拽；活跃会话行、历史会话行与节点行不可拖拽，也不可拖入工作区。
- 按住项目行非箭头区域并移动超过拖拽阈值开始拖拽；拖拽期间显示目标插入位置。
- 有效插入区域为项目行之间的间隙，以及末个项目与未归属节点之间；释放在插入指示位置完成移动，释放在其他位置或按 `Esc` 取消。
- 排序不改变活跃项目、展开状态、搜索词与历史会话多选状态。
- `Alt+Up` / `Alt+Down` 与菜单「上移」「下移」提供等价键盘操作；移动后焦点留在该项目行。
- 项目顺序立即持久化；新项目追加末尾；未归属节点始终位于末尾且不参与排序。

### 行内重命名

- `F2` 或项目菜单「重命名」进入；编辑框位于显示名主行，原名全选；同一时刻只有一个项目行处于编辑。
- `Enter` 提交；有效名称立即更新并持久化。名称为空或仅含空白字符时保持编辑并显示「显示名不能为空」。
- 失焦提交；有效名称提交，空或仅含空白字符的名称视为取消并恢复原名。
- `Esc` 取消并恢复原名。
- 最多 80 字符；超出输入被忽略。
- 显示名可重复；根目录、文件夹名、会话数据、面板标题不变。
- 编辑期间点击其他项目行：先按失焦提交规则处理，再执行点击目标。

### 删除撤销提示

- 单条删除与批量删除完成后显示撤销提示，文案分别为「已删除 1 个历史会话」「已删除 N 个历史会话」，附「撤销」操作。
- 提示停留 5 秒（设计契约）；使用工作区“可操作通知”变体（正文 + 撤销按钮），悬停或聚焦暂停倒计时，提供关闭按钮。
- 点击「撤销」恢复原记录与原顺序；提示消失，计数更新。
- 关闭撤销提示、应用窗口关闭或应用退出后删除永久化。
- 同一时刻只有一个未决撤销；新删除替换旧提示，旧删除立即永久化。
- 撤销失败显示错误通知，删除保持永久。
- 撤销操作可通过键盘访问；不因提示出现而抢占当前焦点。

### 跨区行为

| 触发 | 可感知结果 |
|---|---|
| 点击活动栏「导航树」按钮（已打开） | 视图关闭；周期扫描与相对时间停止；展开与滚动保留；搜索清空 |
| 点击其他侧栏视图按钮 | 导航树隐藏；周期扫描停止；展开与滚动保留；搜索清空 |
| 点击项目行 | 激活项目，主区显示该项目布局；其他项目布局隐藏但存活 |
| 点击项目箭头 | 仅切换展开，不改变活跃项目 |

| 活跃会话菜单「关闭面板」 | 走工作区关闭守卫；关闭后行消失、徽标减少；历史记录不受影响 |
| 项目「重新定位根目录」并选择新目录 | 身份、显示名、顺序、布局、展开不变；根更新；历史归属即时重算 |
| 项目「移除项目」并确认 | 工作区壳确认框列出终端数与脏面板；布局关闭、终端终止、行移除；磁盘与历史记录保留 |

| 双击工作目录不可用的历史行 | 打开「会话目录不存在」对话框 |
| 单条删除历史会话 | 直接删除；5 秒撤销提示；行消失、计数更新 |
| 批量删除历史会话并确认 | 合并撤销提示；一次撤销恢复全部 |
| 点击撤销提示 | 恢复原记录与原顺序 |
| 点击刷新 | 重扫历史、刷新余量、对账活跃会话；显示进度与失败状态 |
| 点击余量行 | 刷新全部余量来源；5 秒节流 |
| 搜索输入 | 树即时过滤、派生展开命中链并高亮；不改变活跃项目或终端状态 |
| 清空搜索 | 恢复搜索前手动展开状态 |
| 添加项目并选择文件夹 | 创建或激活项目；新项目成为活跃项目并展开 |

### 反馈

- 确认类：移除项目、批量删除历史会话使用模态确认框；单条删除不确认。
- 通知类：添加失败、重定位失败、复制成功/失败、删除失败、撤销失败、恢复失败（含重试）、分支失败、聚焦失败、刷新失败。
- 行内类：历史扫描进度/失败、余量查询/失败/过期、恢复中、搜索空态、重命名空白错误。
- 进度类：刷新按钮旋转、余量行进度、恢复行状态；减少动态效果时改为静态指示。
- 节流类：余量行禁用态与「刷新冷却中」。
- 不得静默失败；高频自动扫描失败使用非阻塞指示，避免重复通知。

## 边界与错误

### 空态

- 无项目且无未归属历史会话：树区显示「暂无项目，点击下方「添加项目」开始」；搜索框禁用；该空态优先于搜索无结果空态。
- 无项目但存在未归属历史会话：仅显示未归属节点；搜索框可用；不显示无项目空态。
- 有项目或存在未归属历史会话但搜索无命中：显示「没有找到匹配的项目 / 会话」。
- 项目展开后既无活跃会话也无历史会话：显示非交互提示「暂无会话」。
- 项目无历史会话：不渲染历史节点，不显示占位。
- 无未归属历史会话：不渲染未归属节点，不显示占位。
- 套餐余量无来源或后台任务禁用：页脚整体隐藏。
- 无活跃项目仅可能发生在没有项目时。

### 加载与进度

- 首次历史扫描：刷新按钮显示进度；已展开且无旧数据的项目或未归属节点显示行内「正在扫描历史会话…」；有旧数据时继续显示旧内容。
- 手动刷新：按钮进度，旧内容保持可见，不阻塞交互。
- 余量首次查询：行文案 `--`，行内查询指示，不隐藏页脚。
- 恢复会话：行显示「恢复中…」；终端面板创建后显示恢复命令注入过程。
- 添加项目：系统文件夹选择框为模态；选择完成后立即创建，不显示长时间加载态。
- 搜索无加载态，结果同步更新。
- 历史扫描、余量查询与恢复编排不提供用户取消入口；关闭导航树或退出应用时自动取消未完成操作。

### 错误

| 场景 | 表现 |
|---|---|
| 添加项目失败 | 通知「添加项目失败」及原因；树不变 |
| 重新定位失败或根路径冲突 | 通知「重新定位根目录失败」或「该根目录已属于其他项目」；项目根不变 |
| 显示名为空或仅含空白字符 | 行内错误「显示名不能为空」；不提交 |
| 显示名写盘失败 | 内存保留新显示名；错误指示 |
| 排序写盘失败 | 内存保留新顺序；错误指示 |
| 历史扫描失败且有旧数据 | 旧数据保留；刷新按钮警示图标；悬停显示失败来源与原因 |
| 历史扫描失败且无旧数据 | 行内「历史会话加载失败，点击重试」 |
| 历史来源部分失败 | 失败来源标记过期并保留旧数据；其他来源更新 |
| 后台扫描配置读取失败 | 执行首轮与手动刷新；不启动周期扫描；配置错误指示 |
| 余量初始查询失败 | 页脚显示来源行与 `--`、警示图标、点击重试 |
| 余量刷新失败 | 保留旧值；行警示图标与失败提示 |
| 余量配置读取失败 | 单行「余量配置读取失败，点击重试」 |
| 复制恢复命令失败或不支持 | 通知「复制失败」或「无法生成恢复命令」；不写入空字符串 |
| 删除历史会话失败 | 行保留或恢复；通知「删除会话失败」及原因 |
| 撤销删除失败 | 通知「撤销删除失败」及原因；删除保持永久 |
| 恢复会话失败 | 通知「恢复会话失败」，含 ID 前 8 位与原因，提供重试 |
| CLI 不支持恢复会话 | 通知「该 CLI 不支持恢复会话」；不创建面板 |
| 分支恢复失败 | 通知「分支恢复失败」及原因 |
| 运行中会话无法定位面板 | 通知「未找到运行中的会话」；对账并更新行 |
| 会话目录不存在 | 打开「会话目录不存在」对话框，不执行恢复 |
| 项目根目录不可访问 | 项目行警示图标与提示；仍可重命名、排序、重定位、移除 |
| 剪贴板不可用 | 通知「复制失败」及原因 |
| 活跃会话关闭面板被守卫取消 | 面板与会话保留，行保留；无错误通知 |

- 错误通知不得插入凭据值或敏感内容；失败后旧数据保留，除非已被确认删除。错误分类与键盘与输入见 [跨域约束](../cross-cutting.md)。

### 冲突与并发

- 添加已存在根路径：不新建，激活已有项目并通知。
- 重新定位到其他项目根路径：拒绝并通知；重新定位到当前根：无变化、不写盘。
- 手动刷新进行中：按钮禁用；自动扫描不重叠启动。
- 余量刷新进行中：显示进度，点击忽略；5 秒节流与进行中状态同时生效。
- 同一历史会话恢复进行中：重复双击忽略，行保持「恢复中…」；不同行允许并发。
- 同一新根路径的项目创建幂等，只创建一个项目。
- 恢复目标项目在恢复期间被移除：恢复失败并通知；不重建已移除项目。
- 恢复失败保留已创建的项目与面板；重试复用。
- 恢复期间项目根被重新定位：进行中的恢复按已解析目标继续；后续扫描按新根重算归属。
- 会话在聚焦前结束：通知「会话已结束」，移除或更新行。
- 历史记录在外部被删除：下次扫描后行消失，选中清除，不报错。
- 历史记录在恢复期间被删除：恢复失败并通知。
- 搜索或刷新导致选中行消失：清除对应选中。
- 余量后台任务在刷新期间被禁用：页脚隐藏，结果保留；重新启用后显示。
- 撤销窗口内再次删除：新删除替换撤销提示，先前删除永久化。
- 撤销时原记录已被外部改变或无法重建：撤销失败，删除永久化。
- 单窗口单实例，不存在跨窗口并发。

### 数据与路径

- 路径比较忽略大小写、分隔符差异与末尾分隔符，按路径段边界匹配。
- 支持盘符根与 UNC 路径；项目身份按 `ProjectId`；根路径按词法路径比较用于唯一性与历史归属；创建/重定位时记录项目根的真实路径，文件访问与包含性校验使用该真实路径；符号链接/目录联接按真实目标校验。
- 嵌套项目根：历史归属最深匹配项目。
- 根路径重复被阻止；数据异常出现重复时以先加入项目为准并显示错误指示。
- 显示名可重复；项目行副行与悬停提示以根路径消歧。
- 重新定位后必须满足根路径唯一；历史归属按新根重算。
- 工作目录为空、相对路径或无法解析：进入未归属节点；仅支持复制恢复命令与删除。
- 工作目录匹配项目根但目录缺失：历史行显示孤儿警示，双击进入「会话目录不存在」对话框。
- 会话 ID 不足 8 位显示全部字符；无 ID 显示「未知会话」。
- 标题为空：活跃会话「终端会话」；历史会话回退 ID 前 8 位。
- 提示词超过 200 字符（设计契约）截断；显示名、标题、路径过长单行省略并悬停完整显示。
- 计数超过 99 显示 `99+`；中文、组合字符与 emoji 按显示宽度截断，不产生乱码或半个字符。

### 性能与规模

- 1,000 条项目/会话行规模下搜索更新不大于 100 毫秒（设计契约）。
- 2,000 条历史会话行（设计契约）规模下纵向滚动与键盘导航保持响应。
- 相对时间定时器仅在视图打开时运行，每 60 秒（设计契约）一次。
- 历史周期扫描仅在视图打开时运行；关闭后停止。
- 导航树关闭期间余量只保留结果，不做界面更新。
- 扫描、恢复、余量请求不阻塞界面交互；长标题、长路径、长提示词不导致行布局抖动。

### 键盘与输入

- 状态与用量档位同时提供文本标签；搜索命中高亮提供文本说明。
- 所有鼠标操作均有键盘等价：激活、展开、聚焦、重命名、排序、删除、撤销、菜单与对话框。
- 菜单、确认框、「会话目录不存在」对话框、行内重命名与撤销提示均可完整键盘操作。
- 焦点环清晰可见，与选中底色、悬停底色可区分。
- 支持中文输入法组合输入；组合期间不过滤、不移动焦点。
- 支持 CJK 文本截断与完整文本提示；尊重系统「减少动态效果」；仅暗色。

### 平台与生命周期

- 目标平台 Windows 10/11；添加项目与重定位使用系统文件夹选择框，取消不产生变化。
- 路径大小写、分隔符与 UNC 规则按 Windows 语义处理；像素契约随 DPI 等比缩放。
- 剪贴板失败可见；历史来源、恢复命令与分支能力取决于各 CLI 集成，不支持的操作用禁用/隐藏表达原因。
- 视图打开时启动历史周期扫描与相对时间定时器；关闭时停止。
- 应用重启后恢复持久化状态，并重新扫描历史、拉取余量。
- 项目移除时关闭其项目布局并终止会话，不留下孤儿进程或句柄。
- 项目根重定位或移除后立即重算历史归属；既有终端继续使用原工作目录。
- 会话结束时实时移除活跃会话行；历史状态随数据更新。
- 应用退出时取消扫描、余量请求与未完成恢复，不阻塞退出；未决撤销永久化。
- 系统默认程序、文件锁、第三方 CLI 行为属于平台边界，不在本篇定义。

## 验收判据

### 结构与项目

- Given 无已保存侧栏状态，When 启动，Then 导航树默认打开。
- Then 分区自上而下为标题行、搜索区、树区、可选套餐余量页脚、添加项目按钮；固定区不随树滚动。
- Then 项目行默认收起；展开后显示活跃会话行与历史节点；无历史时不渲染历史节点。
- Given 多个项目且有无法归属的历史会话，Then 未归属节点位于全部项目行之后、默认收起；无未归属历史时不渲染。
- When 点击项目 A 再点击项目 B，Then 主区显示 B 的项目布局，A 的布局与终端保持存活。
- When 点击项目箭头，Then 仅切换展开，活跃项目不变。
- When 添加项目并取消，Then 项目列表不变。
- When 添加新文件夹，Then 新项目追加末尾、成为活跃项目、展开并滚动到可见；显示名取文件夹名，与现有项目重名时追加递增数字后缀。
- When 添加已存在根路径，Then 不新建，激活已有项目并通知「该项目已存在」。
- When 添加失败，Then 通知「添加项目失败」且树不变。
- When 移除项目，Then 导航树只触发请求；确认框由工作区壳列出终端数与脏面板标题。
- When 移除并确认，Then 布局关闭、终端终止、行消失；磁盘与历史记录保留；活跃项目回退到相邻项目；无撤销。
- Given 根目录不可访问，Then 项目行显示警示图标，仍可重命名、排序、重定位与移除。

### 根目录重定位

- When 重定位到新目录，Then 项目身份、显示名、顺序、项目布局与展开状态不变；根路径更新并持久化。
- Then 既有终端不重启并继续使用原工作目录；新终端与文件浏览器使用新根。
- Then 历史会话按最新项目根集合即时重算；不再匹配任何项目根的会话进入未归属节点。
- When 重定位到其他项目根路径，Then 拒绝并通知「该根目录已属于其他项目」，项目根不变。
- When 选择当前根路径，Then 视为无变化且不写盘。
- When 重定位失败，Then 通知「重新定位根目录失败」且项目保持原状态。

### 重命名与排序

- Given 项目行聚焦，When 按 `F2`，Then 显示名进入内联编辑且原名全选。
- When 输入新名称并按 `Enter`，Then 显示名更新并持久化；根目录、文件夹名、会话数据、面板标题不变。
- When 失焦且名称有效，Then 提交；失焦且名称为空或仅含空白字符，Then 取消并恢复原名；按 `Esc` 取消并恢复原名。
- When 提交空名或仅含空白字符的名称，Then 不提交，显示「显示名不能为空」。
- When 输入超过 80 字符，Then 超出部分不进入输入。
- Given 两个项目显示名相同，Then 两者均正常显示，副行与悬停提示以根路径消歧；重命名允许产生重名。
- When 拖拽项目到插入指示位置，Then 项目移动到该位置并持久化；活跃项目不变。
- When 按 `Alt+Up`/`Alt+Down` 或菜单「上移」「下移」，Then 顺序等价变化；边界项禁用。
- Then 新项目始终追加末尾；应用重启后顺序保持。
- When 排序写盘失败，Then 内存顺序保留并显示错误指示。

### 活跃会话

- Given 项目 A 与 B 都有运行中 CLI 会话，Then 两项目展开后都能看到各自会话；纯 shell 终端不建行。
- Then 会话按最近事件降序；项目行徽标显示运行中数量，超过 99 显示 `99+`。
- When 终端面板标题变化，Then 会话行标题同步。
- When 点击非活跃项目的活跃会话行，Then 激活该项目并聚焦对应终端面板。
- Given 面板已不存在，When 聚焦该会话，Then 通知「会话已结束」并移除行。
- When 右键活跃会话行，Then 菜单包含「聚焦」「复制恢复命令」「关闭面板」，不含「删除会话记录」。
- When 选择「关闭面板」，Then 走工作区关闭守卫；取消则会话保留，确认则面板销毁、行消失、项目徽标减少，历史记录不受影响。
- Given CLI 不支持恢复命令，Then「复制恢复命令」禁用并显示原因。
- Then 会话菜单支持方向键、`Shift+F10`、`Esc` 与焦点返回。

### 历史会话与未归属

- Given 根路径 `C:/root` 与 `C:/root/sub`，When 会话工作目录为 `C:/root/sub/x`，Then 只归属 `C:/root/sub`。
- Given 工作目录为空、相对路径或无法匹配，Then 会话进入未归属节点。
- When 双击未归属节点下可恢复行，Then 新建以该工作目录为根的项目并恢复；行随后归属新项目。
- When 双击工作目录不可用的行，Then 打开「会话目录不存在」对话框。
- Then 历史行按修改时间降序，始终显示三态状态圆点、CLI 图标、标题与相对时间；未知状态不显示为已完成。
- Then 相对时间按六档显示并每 60 秒（设计契约）更新；悬停按顺序显示可用项。
- When 双击普通历史行，Then 复用最深匹配项目或新建项目，打开终端面板并注入恢复命令。
- Given PowerShell 系终端 10 秒（设计契约）未就绪，Then 仍尝试注入一次；cmd 约 0.5 秒（设计契约）；失败通知并提供重试。
- Given CLI 不支持恢复，When 双击历史行，Then 通知且不创建面板。
- When 双击运行中历史行且面板存在，Then 直接聚焦，不弹确认框。
- Then 历史菜单矩阵按行状态生效；禁用项不执行动作。
- When 多选历史行并右键，Then 菜单只提供「删除所选（N）」。

### 删除与撤销

- When 删除单条历史会话，Then 不弹确认，行立即消失，显示 5 秒（设计契约）「已删除 1 个历史会话 [撤销]」。
- When 点击「撤销」，Then 原记录按原顺序恢复，计数与列表位置恢复。
- When 撤销窗口结束、关闭提示、应用窗口关闭或应用退出，Then 删除永久化，刷新与重启不重新出现。
- Given 撤销失败，Then 显示错误通知且删除保持永久。
- When 批量删除并确认，Then 一次操作删除全部选中记录并显示合并撤销提示「已删除 N 个历史会话」；一次撤销恢复全部原顺序。
- When 批量选中包含运行中会话，Then 确认框显示数量并注明跳过数；全部运行中时不弹确认框并通知「运行中的会话不可删除」。
- When 删除失败，Then 行保留或恢复并通知「删除会话失败」。
- Given 撤销提示未结束时再次删除，Then 新提示替换旧提示，先前删除永久化。

### 搜索

- When 输入大小写不同的查询，Then 结果一致；首尾空白忽略，纯空白等同未搜索。
- Then 匹配显示名、根路径、活跃会话标题、历史标题或 ID 前 8 位、工作目录、首条提示词。
- Then 命中链自动展开；清空搜索恢复搜索前手动展开状态。
- Given 仅项目显示名命中，Then 项目派生展开并显示全部活跃会话；历史节点显示、默认收起且可展开全部历史。
- Given 仅未归属历史行命中，Then 未归属节点显示、派生展开并只显示命中行。
- Then 搜索计数显示可见匹配数；项目自身命中显示总数；项目行运行中会话数徽标不随搜索变化。
- Then 显示名、副行根路径、活跃标题与历史标题中的命中子串高亮；悬停提示中的命中子串同样高亮。
- When 点击清除或搜索框按 `Esc`，Then 查询清空；`Esc` 同时把焦点移回树区。
- Then 无结果显示「没有找到匹配的项目 / 会话」；无项目且无未归属会话时显示无项目空态且搜索禁用。
- Then 搜索不改变活跃项目、项目布局、面板与终端状态。
- 设计契约：1,000 行规模下输入到结果更新不大于 100 毫秒。

### 刷新与余量

- When 点击刷新，Then 历史重扫、余量刷新、活跃会话对账；按钮显示进度并禁用。
- Then 刷新成功不弹通知、悬停显示上次更新时间；失败显示通知与失败来源。
- Then 自动扫描默认 3 秒、可配置 2–300 秒；禁用后手动刷新仍可用；关闭视图停止扫描；展开节点不触发扫描。
- Given 单一来源失败，Then 该来源保留旧数据并标记过期；无旧数据时显示行内重试提示。
- Given 后台任务启用且至少一个来源，Then 余量页脚显示；禁用或无来源时整体隐藏。
- Then 余量文案按冻结、金额、`5h xx% · 7d xx%`、`--` 的优先级显示；重置时间按四档格式。
- When 连续点击余量行，Then 5 秒（设计契约）内只发起一次请求；节流期间禁用并提示「刷新冷却中」。
- When 初始查询失败，Then 仍显示来源行与 `--` 并提供重试；配置读取失败显示「余量配置读取失败，点击重试」。
- When 重新启用后台任务或重新打开视图，Then 立即显示上次结果；超过 30 秒（设计契约）时刷新。

### 键盘、空态与错误

- When 按 `↑`/`↓`/`←`/`→`/`Home`/`End`，Then 焦点按键盘表移动与展开/收起。
- When 按 `Shift+F10` 或菜单键，Then 当前行菜单打开并可用方向键与 `Enter` 操作。
- When 按 `F2` 或 `Alt+Up`/`Alt+Down`，Then 分别进入重命名与移动项目。
- When 按 `Ctrl+A` 与 `Delete`，Then 可见历史行多选并触发删除规则。
- When 按 `Ctrl+F` 或 `F5`，Then 分别聚焦搜索框与刷新。
- Then 焦点环、选中底色、悬停底色可区分；状态与用量不只靠颜色表达；输入法组合期间不过滤。
- Given 无项目且无未归属历史会话，Then 显示「暂无项目，点击下方「添加项目」开始」且搜索禁用。
- Given 项目展开后无会话，Then 显示「暂无会话」。
- Given 搜索无命中，Then 显示「没有找到匹配的项目 / 会话」。
- Given 历史扫描无旧数据且失败，Then 显示行内「历史会话加载失败，点击重试」。
- Given 添加、重定位、删除、撤销或恢复失败，Then 显示对应错误通知；数据保持原状，删除保持永久。

### 状态保留

- When 同面板组切面板或切换项目，Then 展开、滚动、搜索、上次扫描结果与余量结果保持；切换项目时活跃项目更新。
- When 关闭并重开导航树，Then 展开与滚动保留，搜索与多选清空；未决撤销提示不随视图关闭消失。
- When 应用重启，Then 项目显示名、根路径、顺序、活跃项目、展开与滚动恢复；搜索清空；历史重扫、余量重新拉取；未决撤销永久化。
- Then 通过恢复创建的项目、项目布局与终端面板在重启后仍存在。
- When 项目数据处理写盘失败，Then 内存状态保留并显示错误指示。

## 关键决策与依据

| 规则 | 原因 | 边界 |
|---|---|---|
| 项目身份是稳定 `ProjectId`；根路径归一化后唯一；创建时重名追加后缀，重命名允许重名；根路径显示在项目行副行与悬停提示 | 根路径可因重定位变化，不能承担身份；显示名是展示层，重复文件夹名常见，不应强迫改名 | 根路径仍必须唯一并做真实路径查重；重名只影响展示，不影响归属与排序 |
| 重命名只改显示名，不触碰根目录、文件夹名、会话数据与面板标题 | 显示名是导航标签，不是数据身份；避免改名产生跨域副作用 | 空白拒绝；最长 80 字符；Enter/失焦提交，Esc 取消；写盘失败保留内存并提示 |
| 项目排序同时提供指针拖拽、`Alt+Up`/`Alt+Down` 与菜单上移/下移 | 拖拽高效，键盘等价保证键盘与输入与精确操作 | 仅项目行可排序；未归属节点固定末尾；活跃项目不变；新项目追加末尾 |
| 单条历史删除不确认但提供 5 秒撤销，批量删除先确认再合并撤销 | 单条误删成本可由短时撤销覆盖；批量影响大，需要事前确认 | 运行中会话不可删；撤销窗口结束、关闭提示或应用退出即永久；同一时刻只有一个未决撤销 |
| 撤销恢复原记录与原顺序 | 用户预期撤销回到删除前状态；顺序是历史列表语义的一部分 | 外部记录已变化导致无法重建时撤销失败，删除永久化 |
| 活跃会话菜单不含「删除会话记录」，关闭面板走工作区关闭守卫 | 会话记录属于历史域；关闭面板是工作区生命周期操作，不能绕过脏状态保护 | 取消关闭则会话保留；关闭后历史记录仍在；CLI 不支持恢复命令时禁用复制 |
| 未归属会话作为树底虚拟节点，固定位于所有项目之后 | 让无法归属的会话可发现、可恢复、可清理，同时不污染项目归属 | 仅在存在时渲染；不参与项目排序；工作目录不可用时只允许复制与删除 |
| 历史归属取最深前缀并采用词法路径比较 | 支持嵌套项目根；避免目录暂时不可访问导致归属漂移 | 项目身份按 `ProjectId`；根路径按词法路径用于归属；创建/重定位记录真实路径用于文件访问边界；空/相对/无匹配进入未归属 |
| 根目录重定位保留 `ProjectId`、显示名、顺序、布局与展开，并即时重算历史归属 | 避免目录移动后破坏性重建；项目身份与磁盘位置解耦 | 根路径唯一；与当前根相同不写盘；冲突拒绝；既有终端保持原工作目录 |
| 搜索只过滤展示，命中链派生展开，清空后恢复手动展开 | 搜索是可逆的查看状态，不应改写用户布局与工作区状态 | 项目自身命中时历史节点仍可手动展开/收起；搜索词不持久化 |
| 刷新范围包含历史、余量与活跃会话对账，自动扫描仅在视图打开时运行 | 三者共同决定导航树内容；关闭视图后继续轮询浪费资源 | 手动刷新始终可用；部分失败保留旧数据；自动失败不重复通知 |
| 套餐余量页脚只存在于导航树内 | 页脚是导航树的组成区域，不引入全局布局 | 关闭视图时结果保留；重新打开超过 30 秒则刷新 |
| 历史状态采用运行中/已完成/未知三态 | 无法确认时标为已完成会误导恢复与删除决策 | 未知使用中性色；状态不得只靠颜色表达 |
| 树区无横向滚动，右侧徽标固定，长文本截断并悬停完整显示 | 避免徽标与关键状态被内容挤出；保持行高稳定 | 截断按显示宽度处理 CJK 与 emoji；悬停提示显示完整文本 |
