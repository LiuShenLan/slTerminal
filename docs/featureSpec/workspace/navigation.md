# 导航树

> 拥有项目导航、活跃与历史会话展示、历史恢复、删除隔离区和套餐余量页脚；项目布局与关闭守卫、终端、PathPolicy、凭据和后台任务分别由各自所有者定义。

## 视图与项目

- 树只包含项目行、活跃会话行、历史会话节点、历史会话行和树底“未归属会话”虚拟节点。顶部为标题、刷新与搜索，底部为“添加项目”；套餐页脚位于树区与底部操作区之间。
- 项目行默认收起，展开后先显示活跃会话，再显示历史节点；未归属节点固定在所有项目之后，不参与排序。
- 项目身份为稳定 `ProjectId`，显示名可重复，根路径按 [PathPolicy](../path-policy.md) 的词法规则唯一并用于历史归属；创建与重定位还须真实路径查重。
- 点击项目或按 `Enter` 激活项目；点击箭头只展开或收起。切换项目不销毁布局、面板、终端或未保存修改，隐藏项目不得抢焦。
- 添加项目只选择目录；取消无变化，重复根聚焦已有项目，新根追加到列表末尾并成为活跃项目。添加不递归索引文件内容。
- `F2` 或右键进入内联重命名，`Enter`／失焦提交，`Esc` 取消；空白名称拒绝，最长 80 字符。重命名不改根目录、磁盘文件、会话、面板标题或项目身份。
- 项目可拖拽排序，也可用 `Alt+Up`／`Alt+Down` 或菜单上移、下移；排序不改变活跃项目、展开状态或会话数据。
- 根重定位保留 `ProjectId`、布局、Panel 和 Document，既有 PTY cwd 不变；新终端和文件浏览器使用新根。历史归属立即按最新项目根重算。
- 根重定位前按 PathPolicy 检查新根冲突与 Hooks Project／Local 草稿；草稿未处理或必要状态提交失败时不改变根关联。
- 移除项目只向 [工作区壳](shell.md) 发起请求。工作区统一列出脏 Document、Hooks 草稿和运行中终端，完成保存／丢弃决定及状态提交后才终止 PTY 和删除项目状态；导航树不自行销毁资源。
- 项目移除不删除磁盘文件或历史会话，不提供项目级撤销。移除活跃项目后激活下一个，没有下一个则激活上一个。
- 根不可访问时保留项目并显示警示；词法历史归属不因此漂移。项目仍可激活、重命名、排序、重定位和移除。

## 活跃会话

- 活跃会话是运行中的已注册 CLI 会话，纯 Shell 终端不建行；归属终端 Panel 所在项目，所有项目均可显示。
- 同项目按最近事件时间降序；行包含状态、CLI 图标、实时标题和可用的会话用量。未知或过期用量显示 `--`，不回退套餐余量。
- 点击或按 `Enter` 激活所属项目并聚焦对应终端 Panel；Panel 已不存在时对账移除该行并提示。
- 右键或 `Shift+F10` 提供“聚焦”“复制恢复命令”“关闭面板”。关闭走统一守卫，不删除 CLI 历史记录；复制失败和不支持均可见。
- 会话结束、标题、状态和用量变化实时更新；项目徽标始终表示实际运行数量，不受搜索过滤影响。

## 历史会话

### 来源与归属

- 历史来自各 CLI 已存在的本地历史记录；应用不借展示、搜索或删除建立另一份长期会话正文库。
- cwd 使用 PathPolicy 词法规则匹配项目根；嵌套根取最深匹配。空、相对或无匹配 cwd 进入未归属节点，目录暂时不可访问不改变归属。
- 历史按来源修改时间降序，无效时间排后；状态固定为运行中、已完成、未知，无法确认时不得显示已完成。
- 标题缺失时使用会话 ID 前 8 位，再缺失则显示“未知会话”；相对时间按“刚刚、分钟、小时、天、月日、完整日期”分档，并在视图可见时每 60 秒更新。
- 悬停可显示完整标题、CLI、cwd 和首条提示词预览；预览最长 200 字符。正文和提示词不得进入日志、备份或诊断。
- 单击选择，`Ctrl+单击` 切换，`Shift+单击` 选择范围，`Ctrl+A` 选择全部可见历史行；多选只包含历史行。
- 搜索变化、切换项目、关闭视图或相关行消失时清除多选；右键未选中行先单行选中，右键已选集合保持多选。

### 恢复与分支

- 双击运行中且可定位的会话直接聚焦既有终端，不新建 PTY；其他可恢复会话进入恢复流程。CLI 不支持恢复时明确提示且不创建 Panel。
- cwd 匹配已登记项目时复用该项目；未归属会话需要创建项目时，先显示目标根并由用户明确确认，再创建项目和默认布局。
- 保存 cwd 失效时，可在已确定目标项目内回退项目根并明确提示；项目根也无效则恢复失败。未归属且 cwd 不可用的会话不创建项目，打开“会话目录不存在”对话框。
- 恢复在目标项目创建终端并注入经 CLI 能力校验的恢复命令；不得在创建可用终端前留下空 Panel。命令注入失败时保留已创建的 Panel、错误和重试，重试不重复创建项目或逻辑终端。
- 等待 Shell 就绪：PowerShell 系最长 10 秒，cmd 约 0.5 秒；超时后仍尝试一次注入，失败可见。等待和注入随 Panel 关闭或应用退出取消。
- 同一行重复恢复去重，同一目标根的项目创建幂等；不同会话可并发。目标项目在恢复期间被移除时本次失败，不自动重建。
- CLI 支持时可从单条历史创建分支，原会话不变；分支复用同一 cwd、授权、项目确认和失败语义。
- 单条会话可复制恢复命令；命令为空、不支持或剪贴板失败时不写入空内容并提示。

### 双击与菜单

| 行状态 | 双击结果 |
|---|---|
| 运行中且 Panel 可定位 | 激活项目并聚焦既有终端 |
| 运行中但 Panel 不可定位 | 对账并更新行，提示未找到运行中会话 |
| 已匹配项目但保存 cwd 失效 | 提示后尝试目标项目根；根也无效则失败 |
| 未归属且 cwd 不可用 | 打开“会话目录不存在”对话框 |
| 其他 | 恢复；需要新建项目时先确认目标根 |

- 单行菜单按 CLI 能力提供复制、分支和删除；运行中会话不可删除。多选菜单只提供“删除所选（N）”。
- “会话目录不存在”对话框提供复制恢复命令、删除和关闭；不执行恢复，不静默改用其他目录。

## 删除隔离区与撤销

- 删除先把来源记录移入应用管理的隔离区，再从导航结果隐藏；永久删除发生在该次操作的撤销期限之后。隔离区不属于备份，不进入日志或诊断。
- 单条删除不弹确认；批量删除先确认并自动排除运行中会话。每次确认后的删除操作形成独立隔离批次，保存原始位置、顺序、来源指纹和绝对撤销截止时间。
- 每批撤销期限为删除完成起 5 秒。提示悬停、聚焦或保持打开只影响提示显示，不暂停或延长绝对期限；关闭提示、关闭视图、关闭窗口或应用退出也不提前永久化。重启后对账未到期批次并继续保留撤销能力。
- 新删除不替换或提前永久化旧批次。期限分别计算；过期清理由各批次独立执行，不因应用退出或另一批删除而提前。
- 顶部标题区在存在可撤销或待处理批次时提供“已删除会话”入口。列表按批次显示数量、剩余期限和“撤销”；撤销提示只是快捷入口，不是唯一恢复通道。
- 撤销以批次为单位恢复该批全部已隔离记录及其原始位置和列表顺序；未成功隔离且仍在原位置的项不属于恢复集合。执行时重新检查绝对期限、批次状态和隔离记录，再检查目标位置与来源指纹。到期、已永久化或记录不完整时明确失败，不伪装成功；外部新增、修改或同位置已有内容时不得覆盖。
- 撤销失败保留完整隔离数据，标记待处理并提供“重试”“导出隔离记录”和错误原因。此类数据不因期限到达而自动物理删除；只能成功恢复、成功导出后由用户明确永久删除，或由用户直接明确永久删除。
- 来源移动与批次登记按可恢复事务处理：先持久化批次清单，再逐项写入并校验隔离副本，副本完整后才移除来源，最后提交完成状态与撤销截止时间。移入失败时不隐藏对应原行；部分失败时列出失败项，不把整批伪装为成功。
- 异常启动先按批次清单对账来源与隔离副本，再呈现普通历史。已完整隔离的项目继续隐藏并纳入原批次；未完成项目保留或恢复来源。无法确认状态或缺少完成时间的批次保留全部可用副本并标记待处理，不自动永久删除，也不得同时丢失来源与隔离副本。
- 永久化失败保留隔离数据和错误，可重试；刷新、重启或重新扫描不得使已完整隔离且仍可撤销的记录重新出现在普通历史列表。
- 隔离区只保存用户明确删除的历史材料，不主动扫描或复制其他 CLI 数据；清理只依据各批次自身期限和待处理状态。

## 搜索

- 输入即过滤，忽略首尾空白和大小写，IME 组合期间不触发；只匹配项目名与根、活跃标题、历史标题或 ID 前缀、cwd 和首条提示词，不搜索项目文件内容。
- 项目自身命中时显示其全部活跃会话，历史节点可手动展开；只有子项命中时只显示命中行，并派生展开命中链。
- 清空搜索恢复搜索前的手动展开状态；搜索不改变活跃项目、布局、终端或历史数据。
- 命中子串在可见文本与悬停提示中高亮，使用主题语义 token；高亮不改变文本、排序和匹配结果。
- `Ctrl+F` 仅在导航树上下文聚焦搜索；`Esc` 清空并还焦树区。搜索词、结果和派生展开均为瞬态。
- 大列表只渲染可见行，过滤复用已加载索引；扫描和过滤不得阻塞前台输入。性能验收使用固定数据规模与实机测量，不设无环境前提的时延承诺。

## 刷新与失败

- 手动刷新重扫全部历史来源、对账活跃会话，并刷新已配置套餐来源；不重新加载项目列表，不改变展开、搜索或焦点。
- 刷新进行中按钮禁用，不重复排队；单来源失败保留该来源旧数据并标记过期，其他来源正常更新。无旧数据时提供行内重试。
- 历史自动扫描默认开启，周期 3 秒，可配置 2–300 秒；仅在导航树可见时调度，隐藏后停止，重新可见先显示上次结果再扫描。
- 展开节点不触发扫描；自动失败使用非阻塞警示，不重复弹通知。历史扫描、恢复和刷新不阻塞前台交互。
- 历史记录被外部删除时下次扫描移除对应行并清除选择；恢复过程中来源消失则本次失败。
- 历史来源读取失败不得被当成空历史，也不得因此永久化隔离区记录。

## 套餐余量页脚

### 来源与凭据

- 只支持应用内置套餐来源，每来源最多一份启用配置；不提供自定义 Provider、模型管理或连接测试。
- 每个来源使用用户专门提供的查询 token，只存 Windows 凭据管理器；不得读取 CLI 配置、环境变量或其他 CLI 凭据来代替。
- token 设置后不回显，错误、日志、备份和诊断不得包含其值。目标机器缺少 token 时要求用户重新配置。
- 后台查询默认启用，周期 60 秒，可配置 30–3600 秒；导航树隐藏时仍按调度查询，应用退出后不保留系统后台任务。
- 页脚在后台查询启用且至少一个来源已配置时显示；禁用或无来源时整体隐藏，最后结果保留用于重新启用后的首次展示。

### 展示与刷新

- 每来源一行，可聚焦和点击；文案优先级为“已冻结”→ 金额 → `5h xx% · 7d xx%` → `--`。冻结、失败和过期均有文本或图标，不只靠颜色。
- 悬停显示来源、最后成功时间、可用的重置时间和状态；缺失数据不伪造为 0，双窗用量不回退为金额。
- 点击任一行或按 `Enter` 手动刷新全部来源；从上次实际发起手动刷新起 5 秒内忽略重复触发并显示冷却。
- 刷新或查询失败保留旧值并显示失败与最后成功时间；首次失败显示 `--` 和重试。单来源失败不影响其他来源。
- 过期由调度器依据当前周期、计划执行时间和来源响应状态判定，不使用固定 30 秒：已错过一个完整调度周期且仍无新成功结果时标记过期；请求尚未达到自身超时且未错过该周期时保持查询状态。
- 调度周期改变后以下一次计划执行为准；失败结果不推进最后成功时间。手动刷新成功与后台成功使用同一状态和时效规则。
- 导航隐藏期间不执行界面更新，只更新最后结果；重新可见立即展示，不强制重新查询或清空。应用重启后按当前调度重新拉取。

## 状态与生命周期

| 状态 | 关闭视图后重开 | 应用重启 |
|---|---|---|
| 项目元数据、活跃项目、展开状态、树滚动 | 恢复 | 恢复 |
| 搜索词、派生展开、多选、内联编辑、菜单、通知、错误和焦点 | 清除 | 清除 |
| 历史结果 | 保留上次结果并重新扫描 | 重新扫描 |
| 套餐结果 | 立即显示缓存，按调度查询 | 按调度重新拉取 |
| 隔离批次与撤销截止时间 | 保留 | 保留并继续对账 |
| 撤销提示与临时倒计时界面 | 清除，可从“已删除会话”进入 | 清除，可从“已删除会话”进入 |

- 项目、布局、终端和视图状态分别由其所有者持久化；导航不另存第二份布局或终端映射。
- 视图隐藏时停止历史周期扫描和相对时间定时器；套餐调度不随视图隐藏停止。所有 watcher、请求和计时器均有显式关闭路径。
- 退出先提交必要的项目、导航和隔离区状态，再取消扫描、恢复和查询；不得为了退出提前永久删除未到期批次。

## 键盘与反馈

- 树区是单一 Tab 停靠点；方向键移动与展开，Home／End 到首尾，`Enter` 激活，`Space` 展开节点，`Shift+F10` 打开菜单。
- `F2` 重命名项目，`Alt+Up/Down` 排序，`Delete` 删除选中历史，`F5` 刷新，`Ctrl+F` 聚焦搜索；各命令进入统一命令目录。
- 删除后焦点移到下一条可见历史行，其次历史节点或项目行；菜单和对话框关闭后返回触发位置。
- 项目行与节点行无横向滚动，长文本截断并提供完整提示；CJK、组合字符和 emoji 按显示宽度处理。
- 节点行高 28 像素、会话行 30 像素、每级缩进 15 像素，均为随 DPI 缩放的逻辑像素；减少动效时进度使用静态指示。

## 验收判据

- **Given** 项目含脏 Document、Hooks 草稿和运行终端，**When** 从导航移除，**Then** 工作区统一守卫成功并提交删除意图后才移除项目；取消或保存失败时项目及资源保留。
- **Given** 根重定位目标属于其他项目或存在未处理 Hooks 草稿，**When** 提交，**Then** 根关联不变；成功后既有 PTY cwd 不变，历史归属按新根重算。
- **Given** 嵌套项目根和暂时不可访问的根，**When** 历史归属计算，**Then** 使用词法最深匹配且不根目录可访问性漂移。
- **Given** 未归属历史需要新建项目，**When** 双击恢复，**Then** 先确认目标根；取消不创建项目、Panel 或 PTY。
- **Given** 已匹配项目的历史 cwd 失效，**When** 恢复，**Then** 可提示后回退该项目根；命令注入失败保留 Panel 与重试，不重复创建逻辑终端。
- **Given** 连续两次删除且第二批在第一批提示消失前后发生，**When** 任一批次期限尚未到达，**Then** 两批均可独立撤销，第二批不提前永久化第一批。
- **Given** 撤销提示被悬停或聚焦至期限之后，**When** 点击撤销，**Then** 执行时重新检查期限与批次状态；已到期或已永久化明确失败，不显示恢复成功。
- **Given** 删除后立即重启且期限未到，**When** 打开“已删除会话”，**Then** 批次与剩余期限恢复并可撤销；普通历史列表仍不显示该记录。
- **Given** 来源已移动但完成状态尚未提交时异常退出，**When** 再次启动，**Then** 先对账清单、来源与隔离副本；完整隔离项不回到普通历史，状态不明批次保留副本并标为待处理，不自动永久删除。
- **Given** 撤销目标已有外部新增或修改，**When** 撤销，**Then** 不覆盖目标，隔离数据保留并可重试或导出；到期清理不删除该待处理批次。
- **Given** 套餐 token 只配置在 Windows 凭据管理器，**When** 查询、刷新、导出或诊断，**Then** 不读取 CLI token 替代，且任何持久材料与错误均不含 token。
- **Given** 后台周期为 60 秒且导航隐藏，**When** 到达调度时间，**Then** 查询继续；应用退出后不再执行。
- **Given** 查询失败且已错过完整调度周期，**When** 查看页脚，**Then** 保留旧值、标记过期并显示最后成功时间；不使用固定 30 秒清空或过期。
- **Given** 搜索、多选、菜单或临时错误存在，**When** 关闭重开或重启，**Then** 这些瞬态均清除；项目、展开、滚动和未到期隔离批次按各自规则恢复。
