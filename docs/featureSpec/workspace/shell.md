# 工作区壳：项目、项目布局、面板组与面板

> 定义项目、项目布局、面板组与面板的模型和生命周期，以及面板类型封闭集、布局操作、焦点、脏状态与关闭守卫、标题、通知、单实例、批量保存并关闭和 `Ctrl+,` 全局命令；不拥有项目改名与排序、活动栏菜单、侧栏与各面板内部行为。

## 目标行为

### 模型与不变量

工作区层级固定为：**项目 → 项目布局 → 面板组 → 面板**。

- **项目**：顶层容器，对应一个根目录，恰好拥有一个项目布局。项目列表持久化。
- **项目布局**：项目对应的整个网格面板布局，由按水平或垂直方向递归划分的面板组组成；多个项目的布局同时存活，切换项目只改变可见性。
- **面板组**：项目布局内部的页签组，拥有独立页签栏；可多个、可拆分、可合并、可调整尺寸。
- **面板**：面板组内的一个页签条目，是工作区可承载的最小 UI 单元；面板组同一时刻显示其中一个激活面板。

不变量：

- 项目集合非空时恰好有一个活跃项目；没有项目时不存在活跃项目。
- 每个项目恰好有一个项目布局；每个含面板的项目布局至少有一个面板组；每个非空面板组恰好有一个激活面板；每个含面板的项目布局恰好有一个聚焦面板组。
- 切换项目不重建项目布局：目标项目的布局显示，其他项目的布局隐藏但保持存活；不卸载、不重建、不重启其中的面板与终端。
- 面板实例在关闭或随项目移除前始终存活；切换面板、面板组或项目只改变可见性、激活态与键盘焦点。
- 面板不跨项目移动；跨项目使用同一文件时，各项目分别持有自己的面板实例。
- 仅 Windows 桌面、单窗口、单实例、仅暗色、GPU 加速渲染为产品约束，不属于可配置项。

### 项目生命周期

- **创建**：从导航树创建项目，仅选择文件夹作为项目根。创建时显示名取所选文件夹名；与现有项目显示名重名时追加递增数字后缀（如 `demo 2`）。新项目拥有空项目布局，没有面板组与面板，显示项目空态；创建成功后自动成为活跃项目。项目显示名的重命名与排序由 [navigation.md](navigation.md) 定义。
- **激活与切换**：点击导航树项目行，或打开属于该项目的会话/文件，使该项目成为活跃项目。切换只改变布局可见性、激活态与键盘焦点，不迁移面板状态。
- **活跃项目回退**：项目集合非空时始终存在活跃项目。移除活跃项目后，按导航树顺序激活下一个项目；没有下一个时激活上一个；没有其他项目时主区空白、标题栏中段为空。
- **移除**：移除项目必须经过确认框。确认框由工作区壳拥有，导航树只触发移除请求。确认框标题为 `移除项目`，正文包含项目名、将终止的终端数量，并声明该项目全部面板与终端进程将终止、选择放弃将丢失未保存修改、磁盘文件与历史会话记录不受影响；存在需保存面板或前台运行进程的终端时列出其标题与进程信息。确认后销毁项目、项目布局、全部面板与终端进程；取消则不做任何变更。移除不可撤销。
- **项目根**：项目根目录是该项目内文件打开、文件浏览器、Commit 与新建终端默认工作目录的基准。项目根支持重定位；重定位不重建项目布局与面板实例，文件型面板按新根重新计算相对路径，终端默认工作目录随之更新。项目根路径设置失败时通知 `项目根路径设置失败，文件操作可能被拒绝`，不阻断项目加载与切换。
- **项目数据**：项目列表、根目录、显示名、项目布局与活跃项目标识持久化；启动时恢复全部项目，不按需懒加载。持久化细节见 [settings-and-persistence.md](../settings-and-persistence.md)。

### 面板组与布局操作

- 项目布局采用网格划分：面板组按水平或垂直方向划分，可嵌套；每个面板组拥有独立页签栏。
- 布局操作：
  - 将面板页签拖到面板组左、右、上、下边缘：显示落点预览；释放后按对应方向创建新面板组，并把该面板放入新面板组。
  - 将面板页签拖入另一个面板组的页签栏：按落点位置插入并移动面板；目标面板组成为聚焦面板组，被移动面板成为激活面板。
  - 在同一页签栏内拖动：调整面板顺序，不改变激活面板。
  - 拖动面板组分隔线：调整相邻面板组尺寸，布局变化进入自动保存。
- 面板组最后一个面板被关闭或被拖出后，该面板组自动移除；项目布局没有剩余面板组时显示项目空态。不存在保留的空面板组。
- 面板组可用尺寸下限为 120×80px（契约）；可用空间不足以容纳该尺寸时，拆分操作不执行并保持原布局。
- 不提供浮动面板组、弹出为独立窗口、跨项目拖拽或将面板移出主区的路径。
- 每个面板组头部右侧提供 `+` 钮：视觉尺寸 22×22px、点击区域不小于 24×24px（契约），悬停显示次级背景色并提示 `新建终端`；点击后在该面板组内新建终端面板。
- 新建面板的默认落点是当前聚焦面板组；项目布局没有面板组时，新建面板创建第一个面板组。
- 键盘等价入口：面板页签菜单提供 `拆分到右侧`、`拆分到下方`、`移动到下一个面板组`，效果与对应拖拽操作一致。面板组分隔线可键盘聚焦，聚焦后方向键每次调整 10px（契约）。

### 面板类型封闭集

面板类型为封闭集，只有下表类型可被创建与恢复。类型集合由本篇维护；新增类型须修订本规格，其他规格不得私增。

| 面板类型 | 职责 | 脏状态 | 生命周期要点 |
|---|---|---|---|
| 终端 | 运行 shell 或编码 CLI；一个面板对应一个 PTY | 无 | 关闭面板即终止该 PTY；项目隐藏时继续运行 |
| 编辑器 | 编辑文本文件；`.html`/`.htm` 以源码形式编辑，不渲染 | 有 | 未保存修改进入脏状态；关闭前经关闭守卫 |
| Markdown 文档 | Markdown 源码态与渲染态两态，打开默认渲染态 | 有（源码态修改） | 渲染态只读；形态作为面板参数持久化 |
| Diff | 差异对照；工作区侧可编辑 | 有（工作区侧修改） | 只读对照模式无脏状态 |
| GitShow | 只读展示 HEAD 内容 | 无 | 关闭后重新读取 |
| 设置中心 | 应用配置页容器 | 有（Hooks 手动保存） | 每个项目一个；共享全局配置；Hooks 的 Project/Local 层绑定所属项目；重复打开聚焦已有面板 |

- `.html`/`.htm` 文件只进入编辑器并显示可编辑源码，不渲染、不执行脚本，也不存在 HTML 预览面板类型。编辑器右上角提供悬浮按钮，单击以系统默认程序打开磁盘上的该文件，行为与在资源管理器中双击一致；存在未保存修改时不提示、不保存，直接打开磁盘版本。按钮细节见 [panels/editor.md](../panels/editor.md)。
- 面板生命周期：创建 → 激活或隐藏 → 关闭或随项目移除而销毁；应用退出时统一销毁。关闭与项目移除是仅有的销毁路径。
- 面板隐藏状态包括：同面板组切换到其他面板、所在面板组失去聚焦、所在项目不是活跃项目。三种隐藏均不销毁面板。
- 终端面板只对应一个 PTY，面板内部不再拆分；并排终端通过项目布局内的多个面板组实现。
- 面板关闭前执行关闭守卫；关闭后释放该面板的资源：终端终止 PTY，编辑器与 Markdown 文档关闭文件句柄，Diff/GitShow 释放缓存；具体资源释放见各面板规格。
- 布局恢复只接受上表类型；持久化数据中的其他类型被忽略并丢弃。若某项目全部面板均被丢弃，该项目显示空态，应用不崩溃。
- 每个面板独立错误隔离：面板渲染失败时，仅该面板区域显示 `面板渲染出错`、说明文字、`重试` 钮与可折叠错误详情；同项目其他面板不受影响。`重试` 清除错误态并重新渲染该面板。
- 应用顶层、标题栏、主区、通知区域各自具备区域级错误边界；顶层错误显示全屏 `应用渲染错误` 与错误信息，避免单区域崩溃拖垮整个界面。

### 面板标题与页签呈现

**标题规则**

- 终端面板默认标题为 `terminal-N`。编号按项目持久计数，从 0 开始；关闭面板不复用编号，重启按布局恢复编号、不重算，新终端从当前计数继续递增。
- 编辑器、Markdown 文档、Diff、GitShow 的文件型面板默认标题为文件名。编辑器标题不追加 Git 状态后缀；不存在按 Commit 来源区分的后缀视图。
- 同一项目内出现同名文件时，相关面板页签改用相对项目根的路径；文件不在项目根内时按所属面板契约使用规范化绝对路径或仓库相对路径。路径比较按 Windows 大小写不敏感规则处理。
- 例外：Agent 全局文件面板标题由 [sidebar/agent-files.md](../sidebar/agent-files.md) 定义，采用文件名加最短可区分上级路径；该标题规则不适用本节的同名文件回退规则。
- 关闭同名文件面板之一后，剩余面板重新计算标题，可能恢复为纯文件名。
- Diff 默认模式面板在文件名或相对路径后追加状态后缀：已修改、已重命名、冲突为 `(git diff)`；冲突快照模式标题由 Diff 篇定义。GitShow 面板标题为 `文件名(git delete)`。
- 终端自定义标题随布局持久化，重启后保留；自定义标题优先于自动标题。文件另存为成功后，标题按新路径重新计算。
- 设置中心面板标题为 `设置中心`。
- 标题过长时单行省略，完整标题通过悬停提示提供。

**页签呈现**

- 终端页签可显示状态圆点，颜色语义：工作=绿色、注意=黄色、完成=灰色、错误=红色。状态圆点必须同时提供可达文本（悬停提示与无障碍名称），不得仅以颜色传达。
- 终端绑定编码 CLI 会话后显示该 CLI 的品牌图标 <img src="../assets/cli-svg/claude.svg" width="16" height="16" alt="CLI 品牌图标示例">，尺寸 16×16px（契约），可与状态圆点并存；按 AgentKind 取 `../assets/cli-svg/<slug>.svg`，完整映射见 [资产清单](../assets/README.md)。无品牌资产的 CLI 不显示图标。
- 文件型面板显示按扩展名着色的文件图标 <img src="../assets/preview/icons/file-generic-typed.svg" width="14" height="14" alt="文件图标">（`../assets/icons/file-generic-typed.svg`，14px，示意），不显示终端状态圆点或 CLI 图标。
- 聚焦面板组的激活面板页签底部显示 2px 强调色指示条（契约）；非聚焦面板组不显示。
- 脏状态面板在页签标题旁显示未保存标记；标记同时提供无障碍名称“未保存”。
- 关闭按钮 `×` 默认不可见，鼠标悬停或键盘聚焦页签时显现；悬停按钮时显示按钮底色，页签宽度不因悬停跳动。关闭图标 <img src="../assets/preview/icons/close.svg" width="14" height="14" alt="关闭图标">（`../assets/icons/close.svg`，14px，示意）。
- 页签栏溢出时横向滚动，并提供溢出下拉列表，列出当前面板组全部面板及状态；面板页签最小宽度 80px（契约）；关闭按钮与图标保持可见，完整标题通过悬停提示提供。

**去重与聚焦**

- 同一项目内同一规范化真实路径只有一个编辑器面板；再次打开该文件时聚焦已有编辑器面板，不新建。
- 编辑器面板与同文件的 Git Diff/GitShow 面板视为不同面板，互不替代。
- Diff 与 GitShow 按面板类型与各自去重键去重：Diff 使用项目 + 规范化工作区路径，GitShow 使用项目 + 仓库相对路径（大小写不敏感）；再次打开同类型同键时聚焦已有面板。
- 设置中心每个项目一个；重复打开时聚焦已有面板。
- 终端面板不去重，每次新建均创建独立终端。
- 编辑器去重键为项目 + 规范化真实路径；同一文件可在不同项目各有一个编辑器面板。

### 布局持久化与恢复

每个项目持久化其项目布局，包含：

- 面板组划分、方向、嵌套结构与相对尺寸。
- 每个面板组内的面板顺序与激活面板。
- 项目的聚焦面板组。
- 面板参数：Markdown 形态、编辑器自动换行等由面板声明的参数。
- 终端自定义标题与终端编号计数。
- 面板身份与重建所需的文件路径或资源标识。

保存与恢复规则：

- 项目布局在页签增删、拆分/合并、面板拖动、尺寸变化后立即写入内存，并按 2 秒去抖自动写入磁盘（契约）；Diff 面板参数包含在内。其他配置域的去抖与存储细节见 [settings-and-persistence.md](../settings-and-persistence.md)，侧栏布局见 [sidebar/framework.md](../sidebar/framework.md)。
- 正常关闭应用时，先冲刷设置与布局的待执行自动保存，再保存项目数据，不等待自动保存计时；关闭链见后文。
- 启动时读取全部项目与全部项目布局，恢复面板组结构、面板顺序、激活面板、聚焦面板组与面板参数；只显示上次活跃项目。
- 上次活跃项目无法定位时，激活导航树顺序中的第一个项目；没有项目时主区空白。
- 单个项目的布局无法解析时，该项目按空项目布局处理，其他项目不受影响；应用不崩溃。启动完成后以一条聚合警告通知说明受影响的项目与面板。
- 布局恢复过程只读取持久化数据；恢复产生的程序化布局变化不写回，避免以恢复结果反向覆盖原有数据。
- 布局中的未知面板类型被丢弃；若项目全部面板被丢弃，显示项目空态。丢弃结果并入启动时的聚合警告，不逐项弹窗。
- 浮动面板组、弹出窗口与跨项目面板不在持久化范围内，也不会被恢复。
- 隐藏项目的状态不单独持久化；项目可见性由活跃项目推导。
- 布局数据只按本规格的模型解析；结构不兼容时按无法解析处理。
- 快捷键覆盖、活跃项目标识等用户配置由统一设置存储持久化，细节见 [settings-and-persistence.md](../settings-and-persistence.md)。

### 焦点模型

键盘焦点按层归属：**活跃项目 → 聚焦面板组 → 激活面板 → 面板内焦点落点**。

- 每个项目记住其运行期最后聚焦的面板组与面板；焦点记忆只在应用运行期内有效，不跨重启恢复。
- 点击面板页签：激活该面板及其面板组，并把键盘焦点送入该面板的焦点落点。
- 点击面板内容：该面板成为激活面板，其面板组成为聚焦面板组，焦点进入面板。
- 交互式新建或打开面板：面板创建后，键盘焦点进入该面板的焦点落点。焦点动作在面板就绪后执行；执行前面板已被切走或所在面板组失去聚焦时取消。
- 打开文件命中已有面板时，不新建面板，直接聚焦已有面板；该路径不产生新的焦点意图。
- 切换项目：主区显示目标项目的布局；恢复该项目运行期最后聚焦的面板组与面板，并把键盘焦点送入该面板的焦点落点；目标项目没有焦点记忆时停留在工作区层级。
- 布局恢复：不产生焦点意图，不触发面板激活事件；重启后没有面板自动获得键盘焦点。
- 关闭获得焦点的面板后，焦点转移到同面板组的下一个面板；没有下一个时转移到上一个；同面板组没有其他面板时，转移到相邻面板组的激活面板；没有其他面板组时，焦点停留在工作区层级。
- 面板组获得聚焦后，其激活面板成为焦点落点；非聚焦面板组保留自己的激活面板，但不接受键盘焦点。
- 切换项目后按键只进入目标项目的焦点落点，不落入隐藏项目的面板。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 在活跃项目的全部面板间按面板组顺序与页签顺序循环焦点；终端与编辑器不拦截该组合，作为焦点逃逸路径。

焦点落点：

| 面板类型 | 焦点落点 |
|---|---|
| 终端 | 终端输入区 |
| 编辑器 | 编辑区 |
| Markdown 文档 | 渲染态显式打开或点击时可聚焦；源码态聚焦编辑区；布局恢复不自动聚焦 |
| Diff | 工作区可编辑侧；只读对照模式显式打开或点击时可聚焦，布局恢复不自动聚焦 |
| GitShow | 只读内容区；显式打开或点击时可聚焦，布局恢复不自动聚焦 |
| 设置中心 | 面板内容容器 |

- 显式打开或激活面板时，键盘焦点按上表送入该面板的焦点落点。
- 大文件只读浏览形态在显式打开或点击时可获得焦点，但布局恢复不自动聚焦。
- 面板控件可用键盘到达；焦点环可见。

### 脏状态与关闭守卫

**脏状态定义**

- 面板可以声明脏状态，表示存在尚未写入磁盘的用户修改。终端、GitShow 不声明脏状态；编辑器、Markdown 源码态、Diff 默认模式的工作区侧、设置中心声明脏状态；Diff 冲突快照模式无脏状态。
- 关闭守卫的“需保存”集合包括：声明脏状态的面板，以及存在待写或失败自动保存的设置中心面板。
- 设置中心仅 Hooks 层采用手动保存；其余设置项自动保存，自动保存失败以独立失败标识呈现，不据此在页签声明脏状态；但待写或失败自动保存进入关闭守卫的“需保存”集合。细节见 [panels/settings.md](../panels/settings.md)。
- 面板内容修改后进入脏状态；保存、另存或显式还原后清除脏状态。
- 脏状态随面板实例存活，跨同面板组切换与项目切换保留；面板关闭后丢弃。
- 脏状态在面板页签上显示未保存标记，并提供无障碍名称“未保存”。

**单个面板关闭**

关闭路径统一进入关闭守卫：页签悬停 `×`、`Ctrl+W`、鼠标中键点击页签、页签右键菜单的关闭项。

- 面板非脏：立即关闭。
- 面板脏：弹出确认框。标题 `未保存的修改`；正文 `面板「<标题>」有未保存的修改，关闭将丢弃这些修改。`；按钮 `取消`、`保存并关闭` 与 `丢弃并关闭`（危险样式）。面板不具备保存能力时不显示 `保存并关闭`。
- 自动保存开启的编辑器面板：关闭时先请求一次自动保存；成功则直接关闭，不显示确认框；失败或进入保存冲突则保留面板并进入上述确认框，提供 `保存并关闭`、`丢弃并关闭` 与 `取消`。
- 面板不脏但存在待写或失败自动保存的设置中心面板：先尝试冲刷；成功则关闭；失败则弹出确认框，提供 `取消`、`保存并关闭` 与 `丢弃并关闭`。
- 选择 `保存并关闭`：先保存面板内容，保存成功后关闭；保存失败时通知 `保存失败，面板未关闭`，面板保持打开且脏状态不变。
- 选择 `丢弃并关闭`：清除脏状态并关闭面板。选择 `取消`、按 `Escape` 或点击遮罩：面板保持打开，脏状态不变。
- 鼠标中键关闭被命中的面板，不要求该面板已激活；中键按在 `×` 上同样关闭该面板。
- 没有激活面板时，`Ctrl+W` 不关闭任何内容，也不关闭窗口；按键不被工作区消费。

**终端关闭守卫**

- 关闭终端面板前检查是否存在前台运行进程；存在时弹出确认框，标题 `关闭运行中的终端`，正文列出进程信息，按钮 `取消` 与 `终止并关闭`（危险样式）；不存在前台进程时直接关闭。
- 批量关闭、移除项目与窗口关闭包含有前台运行进程的终端时，在同一聚合确认中列出这些终端，不额外弹窗。

**批量关闭**

- `关闭其他`、`关闭全部` 的作用范围是当前面板组；`关闭其他` 的目标是当前激活面板之外的全部面板，`关闭全部` 的目标是该面板组的全部面板。
- 批量关闭前收集本次将被关闭的面板中的需保存面板与有前台运行进程的终端，弹出一次确认框；正文列出需保存面板标题与运行中终端。
- 存在需保存面板时，确认框提供 `保存全部并关闭`、`放弃全部并关闭`（危险样式）与 `取消`：
  - `保存全部并关闭`：按布局顺序逐个保存本次将被关闭的需保存面板；全部成功后关闭目标面板。任一保存失败则中止关闭，保留全部面板，已保存面板清除脏状态并保持打开，其他面板保持原状，并以一条错误通知列出失败项。
  - `放弃全部并关闭`：清除脏状态并关闭目标面板，终止其中运行中的终端。
  - `取消`：整批不关闭，脏状态与运行中终端保持不变。
- 不存在需保存面板但存在前台运行进程的终端时，确认框提供 `关闭`（危险样式）与 `取消`；`关闭` 终止这些终端并关闭目标面板。
- 目标面板中没有需保存面板且没有前台运行进程时直接关闭，无额外确认。
- 批量保存失败时不得终止任何运行中的终端。

**项目移除与窗口关闭**

- 移除项目使用项目移除确认框；导航树只触发移除请求。存在需保存面板或有前台运行进程的终端时在正文列出，不再逐个弹出面板级确认。
- 项目移除确认框在存在需保存面板时提供 `保存全部并关闭`、`放弃全部并关闭` 与 `取消`：
  - `保存全部并关闭`：逐个保存该项目全部需保存面板；全部成功后移除项目。任一失败中止移除，项目、全部面板与运行中终端保持，已保存面板清除脏状态，并以错误通知列出失败项。
  - `放弃全部并关闭`：丢弃未保存修改并移除项目。
  - `取消`：不移除，项目与面板保持原状。
- 项目移除不存在需保存面板时仍必须确认，提供 `取消` 与 `移除项目`；存在前台运行进程的终端时在正文列出，移除时终止。
- 关闭窗口时，若存在任何项目的需保存面板或有前台运行进程的终端，弹出一次聚合确认框；存在需保存面板时标题为 `未保存的修改`，否则标题为 `关闭窗口`；正文列出全部需保存面板标题与运行中终端，声明退出将终止终端进程、选择放弃将丢弃未保存修改。
- 窗口关闭确认框在存在需保存面板时提供 `保存全部并关闭`、`放弃全部并关闭` 与 `取消`：
  - `保存全部并关闭`：按项目顺序与布局顺序逐个保存全部项目的需保存面板；全部成功后进入关闭清理链。任一失败中止关闭，窗口保持打开，全部面板与运行中终端保留，已保存面板清除脏状态，并以错误通知列出失败项。
  - `放弃全部并关闭`：丢弃未保存修改并进入关闭清理链。
  - `取消`：中止关闭流程，窗口保持打开。
- 仅存在运行中终端、没有需保存面板时，窗口关闭确认框提供 `取消` 与 `关闭并退出`；确认后进入关闭清理链。
- 没有需保存面板且没有前台运行进程时，窗口关闭不弹确认。
- 非活跃项目的需保存面板与运行中终端同样计入窗口关闭确认，不因项目隐藏而遗漏。

### 设置中心入口与 `Ctrl+,`

- `Ctrl+,` 是全局命令，默认键为 `Ctrl+,`，可重绑。焦点位于终端、编辑器或其他面板时同样生效。
- 按下 `Ctrl+,`：若活跃项目尚无设置中心面板，在当前聚焦面板组创建；项目布局没有面板组时创建第一个面板组。设置中心面板成为激活面板并获得焦点。
- 若活跃项目已有设置中心面板，则激活其所在面板组与该面板并把焦点送入面板内容容器；不新建第二个设置中心。
- 没有活跃项目时，通知 `请先创建项目`，不创建项目、不创建设置中心，不改变活跃项目状态。
- `Ctrl+,` 不改变活跃项目；活跃项目为项目 B 时，设置中心只在项目 B 中打开或聚焦。
- 设置中心打开失败时通知 `设置中心打开失败：项目尚未就绪，请重试`。
- 活动栏底部配置钮触发与 `Ctrl+,` 相同的打开/聚焦请求；配置钮的呈现、提示与激活态由 [sidebar/framework.md](../sidebar/framework.md) 与 [panels/settings.md](../panels/settings.md) 定义。
- 重绑、可重绑命令的冲突与回退在设置中心快捷键页可见；面板内部固定键的上下文冲突见对应面板篇。细节见 [panels/settings.md](../panels/settings.md)。

### 窗口、标题栏与单实例

- 应用单窗口、单实例。进程启动时先执行单实例检查；已有实例时激活并前置已有窗口，本次启动结束，不创建新窗口。
- 单实例约束避免多个进程同时写同一项目数据。
- 默认窗口尺寸 1200×800（契约），无系统标题栏与系统边框，仅暗色外观。
- 自绘标题栏高度 34px，左右内边距 12px，字号 12px（契约）；文字不可选择。
- 标题栏自左向右：
  - 左段：应用标识 <img src="../assets/brand/app-icon.png" width="16" height="16" alt="slTerminal 应用图标">（`../assets/brand/app-icon.png`，示意 16px）与文字 `slTerminal`。
  - 中段：活跃项目显示名。没有活跃项目时为空。
  - 右段：最小化、最大化/还原、关闭钮。
- 左段与中段共同构成拖拽区，高度撑满标题栏；右段不参与拖拽。
- 中段标题单行省略；没有活跃项目时仍保留全高拖拽区。
- 窗口控制钮尺寸 38×26px、图标 12px、间距 2px、圆角 4px（契约）。最小化钮提示 `最小化`；最大化/还原钮按窗口实际状态显示 `最大化` 或 `还原`；关闭钮提示 `关闭`，悬停使用危险色，其余钮悬停使用次级背景色。窗口控制图标（12px）：最小化 <img src="../assets/preview/icons/window-minimize.svg" width="12" height="12" alt="最小化图标">（`../assets/icons/window-minimize.svg`）、最大化 <img src="../assets/preview/icons/window-maximize.svg" width="12" height="12" alt="最大化图标">（`../assets/icons/window-maximize.svg`）、还原 <img src="../assets/preview/icons/window-restore.svg" width="12" height="12" alt="还原图标">（`../assets/icons/window-restore.svg`）；关闭钮使用 `../assets/icons/close.svg`。
- 最大化状态由窗口状态事件回查，不依赖按钮本地翻转；双击拖拽区、系统贴靠、拖动边框等路径产生的结果一致。
- 窗口横向分为活动栏、侧栏区与主区。活动栏与侧栏区的尺寸、显隐、分隔线与内部布局由 [sidebar/framework.md](../sidebar/framework.md) 定义；主区占剩余宽度，最小 200px（契约），承载活跃项目的项目布局。
- 主区没有项目级页签栏，项目切换入口在导航树。其他项目的布局隐藏但保持存活。
- 确认框与通知浮层为固定定位覆盖层，不参与横向分区布局；面板页签菜单与终端重命名弹窗同样是覆盖在主区之上的浮层。
- 应用没有全局欢迎页，没有应用级状态栏，也没有原生菜单栏；操作入口由活动栏、侧栏、面板组头部、面板页签菜单与快捷键承载。

### 启动与关闭

**启动**

- 进程启动时先执行单实例检查；已有实例时激活并前置已有窗口，本次启动结束。
- 显示启动加载界面：全屏暗色背景与 `slTerminal 启动中…`，不显示标题栏与工作区，无进度条或骨架屏。
- 加载用户设置与各配置域；单个配置域失败不阻断启动，使用该域默认值并记录警告。配置文件损坏时通知 `配置已损坏，已回退默认值`，继续启动。
- 加载项目数据：
  - 成功：继续。
  - 失败：显示项目数据错误界面，阻断进入工作区。界面包含错误信息、`重试` 与 `以空状态继续`，并显示自绘标题栏以保留窗口控制。
  - `重试` 重新加载；`以空状态继续` 显式选择带空项目进入工作区，此后允许保存项目数据。
- 恢复全部项目与项目布局，恢复上次活跃项目；上次活跃项目无法定位时回退到第一个项目。
- 恢复布局不触发焦点意图，不抢键盘焦点。
- 检测到上次异常退出且存在恢复快照时，以一次聚合提示询问恢复或丢弃；恢复过程不产生焦点意图。恢复范围与快照清理见 [settings-and-persistence.md](../settings-and-persistence.md)。
- 数据就绪后渲染标题栏、工作区与通知区域；确认框与通知浮层挂在应用根部。
- 启动期间产生的通知先进入队列；界面挂载后，未超过自动消失时长的通知照常显示。

**关闭**

标题栏关闭钮、系统关闭命令、任务栏关闭等路径统一发起窗口关闭请求，不立即销毁窗口。关闭流程依次执行：

- 若存在需保存面板或有前台运行进程的终端，执行聚合关闭确认；取消则中止关闭，窗口保持打开。
- 冲刷设置与布局的待执行自动保存，而不是取消计时器，最多等待 3 秒（契约）；保存失败记录日志并通知 `设置保存失败，重启后将丢失`。冲刷失败是否阻断关闭按设置守卫的统一规则处理，见 [settings-and-persistence.md](../settings-and-persistence.md)。
- 并发终止所有已注册终端的 PTY，最多等待 3 秒（契约）；失败项汇总记录日志。
- 保存全部项目数据（含当前完整布局与上次活跃项目标识），最多等待 3 秒（契约）。
- 销毁窗口并结束进程。

- PTY 终止与项目数据保存失败只记录日志，不阻止窗口关闭；PTY 由系统进程树终止兜底，不留孤儿进程。设置冲刷失败的处理见上，按设置守卫的统一规则执行。
- 关闭链依次执行设置与布局冲刷、PTY 终止、项目数据保存，各有 3 秒上限（契约）；极端情况下最坏总等待约 9 秒。
- 关闭时不逐个询问面板；脏状态与运行中终端由一次聚合确认处理。

### 通知与确认框

**通知浮层**

- 固定在窗口右上角，多条纵向堆叠，单条最大宽度 320px（契约）。
- 自动消失时长：成功 3 秒、警告 4 秒、错误 5 秒（契约）。
- 不阻塞交互，不打断当前操作；内容为纯文本，类型通过背景色、边框色与文字颜色区分。
- 通知以状态角色与礼貌播报供辅助技术感知，新通知可被读屏发现。
- 通知正文不可点击、不可拖动；每条通知提供关闭按钮，关闭按钮可键盘聚焦，无障碍名称为 `关闭通知`。
- 可操作通知变体：用于短时撤销等场景，在正文右侧提供一个操作按钮（如 `撤销`）；按钮可键盘聚焦，`Enter`/`Space` 触发；悬停或聚焦时暂停倒计时；关闭按钮或倒计时结束即放弃操作。可操作通知的正文仍不可点击。
- 鼠标悬停在通知上时暂停自动消失倒计时，移出后继续计时；手动关闭立即移除该通知。
- 通知在项目切换、面板切换与布局恢复期间保持可见；通知不随项目切换清空。
- 启动期间产生的通知进入队列，界面挂载后按自动消失规则显示。

**确认框**

- 阻塞式模态：全屏遮罩覆盖界面，必须确认、取消、按 `Escape` 或点击遮罩后才能继续。
- 单次只能存在一个确认框；已有确认框挂起时发起新请求，先前请求按取消处理。
- 默认按钮为 `确认` 与 `取消`；调用方可自定义标题、正文、按钮文案与危险样式。
- 弹出后默认焦点由调用方指定；危险操作默认落在安全按钮（`取消`）。`Tab`/`Shift+Tab` 在按钮间循环，不逃出弹窗；`Enter` 提交当前聚焦按钮。
- 点击确认返回确认；点击取消、按 `Escape`、点击遮罩空白处返回取消；关闭后焦点回到发起控件。
- 危险操作按钮使用错误红色底，普通操作使用强调色底。
- 确认框在项目切换时保持挂起；其目标对象由发起时确定，不随可见项目变化。

**系统通知**

- 系统通知与任务栏闪烁仅在窗口失焦且收到编码 CLI 状态事件时发生；窗口聚焦时不发送。
- 类别为 `任务完成`、`等待输入`、`权限请求`、`错误`，类别由对应 CLI 的能力声明决定。
- 正文格式为 `<项目名> · <类别> · <时间>`；无法反查项目名时项目名部分为空。
- 同一事件按事件键去重；去重缓存超过 200 条时裁剪为最近 100 条（契约）。
- 系统通知无点击跳转能力；所有类别均触发任务栏闪烁，闪烁是唯一回窗引导，窗口重新获得焦点后停止。
- 通知权限在首次需要时请求一次；未注册或没有状态事件能力的 CLI 不产生系统通知。

**本篇范围内的通知与确认框触发点**

- 通知：项目根路径设置失败、设置保存失败、项目数据保存失败、面板保存并关闭失败、批量保存失败、配置损坏、布局恢复聚合警告、无项目时打开设置中心（`请先创建项目`）、设置中心打开失败、终端后端回退（细节见 [panels/terminal.md](../panels/terminal.md)）。
- 确认框：关闭需保存面板（单个或批量）、关闭有前台运行进程的终端、关闭窗口存在需保存面板或运行中终端、移除项目、批量删除历史会话、删除文件或文件夹、Commit 回滚或删除。侧栏与面板内部触发的细节由对应规格定义。

### 状态保留

维度固定为：同面板组切面板 / 切换项目 / 关闭后重开 / 应用重启。

| 状态对象 | 同面板组切面板 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|
| 终端 PTY 与终端内容 | 保留 | 保留（项目仅隐藏） | 不保留；关闭即终止，重开创建新终端 | 不保留；重新创建 |
| 终端编号 | 保留 | 保留 | 保留计数；新终端继续递增 | 保留计数；重启不重算，新终端继续递增 |
| 终端自定义标题 | 保留 | 保留 | 不保留；新终端无自定义标题 | 保留 |
| 编辑器缓冲、撤销历史、光标与滚动 | 保留 | 保留 | 不保留；按磁盘内容重新打开 | 不保留；按磁盘内容重新打开 |
| Markdown 源码草稿与形态 | 保留 | 保留 | 草稿不保留；形态不保留，重开为默认渲染态 | 形态保留；草稿不保留 |
| Diff 工作区与滚动 | 保留 | 保留 | 不保留；重新计算差异 | 不保留；重新计算差异 |
| GitShow 内容、滚动与搜索 | 保留 | 保留 | 不保留；重新读取 HEAD | 不保留；重新读取 HEAD |
| 设置中心未保存修改 | 保留 | 保留（项目仅隐藏） | 关闭前经关闭守卫；保存成功则重开无未保存修改，放弃则丢弃 | 不保留 |
| 项目布局结构、面板顺序、激活面板与聚焦面板组 | 保留 | 保留 | 关闭面板会改变布局并持久化；重开按当前聚焦面板组落位 | 保留 |
| 面板参数（Markdown 形态、自动换行等） | 保留 | 保留 | 不保留；新面板默认参数 | 保留 |
| 键盘焦点 | 不适用；激活面板获得焦点 | 恢复目标项目上次聚焦面板的焦点落点 | 不适用；关闭时焦点转移到相邻面板，重开不恢复先前焦点 | 不恢复；恢复过程不抢焦 |
| 活跃项目 | 不适用 | 更新为被切换项目 | 不适用 | 保留上次活跃项目 |
| 侧栏布局、宽度与开关 | 不适用 | 保留 | 不适用 | 保留（由侧栏框架定义） |

- 异常退出后重启时，编辑器与 Markdown 源码态的未保存文本按恢复快照聚合询问恢复或丢弃；正常重启不恢复。终端内容、Diff 工作区侧与设置中心未保存修改不在崩溃恢复范围内。细节见 [settings-and-persistence.md](../settings-and-persistence.md)。

## 交互规则

### 项目与导航入口

- 点击导航树项目行：该项目成为活跃项目；前一项目布局隐藏；目标项目布局显示；不重建任何面板；恢复目标项目运行期最后聚焦的面板组与面板，并把键盘焦点送入其焦点落点。
- 点击导航树中的活跃会话行：切换到该终端所属项目，激活该终端所在面板组与面板，并把焦点送入终端输入区。
- 恢复历史会话：按会话工作目录匹配最深的项目根；匹配到则在对应项目内新建终端面板并恢复会话，工作目录为该会话工作目录。无法归属时在导航树的 `未归属会话` 节点显示并恢复，恢复时按该工作目录新建项目。
- 新建项目：仅选择文件夹；显示名取文件夹名，重名追加数字后缀；创建后自动成为活跃项目并显示空态。导航树细节见 [navigation.md](navigation.md)。
- 项目根重定位：入口由导航树提供；重定位只更新项目根，不重建项目布局与面板实例，文件型面板按新根重新计算相对路径。
- 移除项目：导航树只发起移除请求，确认框内容由工作区壳拥有；按前述确认与回退规则执行；移除非活跃项目不改变活跃项目。
- 活动栏底部配置钮：在活跃项目内打开或聚焦设置中心；没有项目时通知 `请先创建项目`，不切换项目。配置钮的呈现、提示与激活态见 [sidebar/framework.md](../sidebar/framework.md) 与 [panels/settings.md](../panels/settings.md)。
- 主区没有项目级页签栏；项目切换只经导航树与会话入口发生。

### 布局与面板组操作

- 拖动面板页签到当前面板组左、右、上、下边缘：显示落点预览；释放后按对应方向创建新面板组，并把该面板放入新面板组。
- 拖动面板页签到另一个面板组的页签栏：按落点位置插入并移动面板；目标面板组成为聚焦面板组，被移动面板成为激活面板。
- 在同一页签栏内拖动：调整面板顺序，不改变激活面板。
- 面板组最后一个面板被关闭或被拖出：该面板组移除；相邻面板组尺寸按剩余空间重新归一。
- 项目布局没有面板组：显示项目空态；点击空态 `新建终端` 创建第一个面板组与终端面板。
- 点击面板组头部 `+`：在该面板组新建终端面板；新终端成为激活面板并获得焦点。
- 页签右键菜单 `新建终端`：在右键面板所属面板组新建终端。
- 拖动面板组分隔线：调整相邻面板组尺寸；布局变化进入自动保存。分隔线支持键盘聚焦，聚焦后方向键每次调整 10px（契约）。
- 非法拖放：拖到窗口外、拖到隐藏项目的布局、跨项目拖拽、拖到不可见区域，均不产生布局变化，不显示有效落点预览。
- 不提供浮动面板组、弹出窗口或将面板拖出主区的路径。

### 面板页签

- 单击面板页签：激活该面板与该面板组，焦点进入面板焦点落点。
- 鼠标中键点击面板页签：关闭被命中面板，不改变其他面板的激活状态；命中 `×` 时同样关闭该面板。
- 鼠标悬停页签：标题变亮，关闭按钮显现；页签布局宽度不变。
- 右键菜单在鼠标位置显示：
  - 通用项：`新建终端`、`关闭`、`关闭其他`、`关闭全部`。
  - 文件型面板首部额外显示 `复制相对路径`，复制内容相对所属项目根。
  - 终端面板额外显示 `重命名`；该终端正在运行编码 CLI 会话时置灰不可点击。
  - `关闭其他` 与 `关闭全部` 的作用范围是当前面板组。
  - 点击菜单项、点击菜单外区域或按 `Escape` 关闭菜单；项目切换时清空菜单。
- `复制相对路径` 对项目根外的文件使用规范化绝对路径；复制失败时提示错误通知。
- 重命名终端：
  - 弹窗预填当前标题，自动聚焦并全选。
  - 提交时去除首尾空白；为空或纯空白时行内显示 `名称不能为空`，弹窗保持打开。
  - 超过 128 字符时行内显示 `名称过长`，弹窗保持打开。
  - `Enter` 确认；`Escape`、点击遮罩或 `取消` 关闭且不修改标题。
  - 确认后页签立即改名并随布局持久化。
- 键盘页签导航：页签栏内 `←`/`→` 移动焦点，`Enter` 或 `Space` 激活；`Ctrl+W` 关闭当前激活面板；关闭按钮可单独聚焦并触发。
- 键盘拆分与移动：页签菜单包含 `拆分到右侧`、`拆分到下方`、`移动到下一个面板组`，效果与对应拖拽操作一致。
- 页签栏溢出时横向滚动，并提供溢出下拉列表，列出当前面板组全部面板及状态；选择列表项激活对应面板。滚动不改变激活面板；完整标题通过悬停提示提供。

### 焦点与快捷键

- 点击面板内容使该面板获得焦点；若其所在项目不是活跃项目，先经导航或会话入口切换活跃项目；面板内容不可见时无法点击。
- 新建面板的焦点意图为一次性；消费后失效。面板容器未就绪时，待就绪后补执行；执行时面板已被切走或所在面板组失去聚焦则跳过。
- 打开文件命中已有面板时，不新建面板，直接聚焦已有面板；该路径不产生新的焦点意图。
- 大文件只读浏览、Markdown 渲染态、Diff 只读侧与 GitShow 在显式打开或点击时可获得焦点，但布局恢复不自动聚焦；HTML 文件进入编辑器后按编辑器焦点规则执行。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 在活跃项目的全部面板间循环焦点；终端与编辑器不拦截该组合，作为焦点逃逸路径。
- 切换项目后，恢复目标项目运行期最后聚焦的面板组与面板，并把键盘焦点送入该面板的焦点落点；启动恢复不产生焦点意图。
- 输入法合成期间不匹配任何命令；未命中的按键正常送入当前聚焦控件。中文输入法出字不受影响。
- 没有激活面板时，`Ctrl+W` 不消费按键，也不关闭窗口。

### 设置中心入口

- `Ctrl+,`：打开或聚焦活跃项目的设置中心；无活跃项目时通知 `请先创建项目`，不创建项目；可重绑。
- 设置中心已存在于活跃项目：激活其所在面板组与该面板，焦点进入面板内容容器；不新建第二个。
- 设置中心不存在：在当前聚焦面板组创建；项目布局没有面板组时创建第一个面板组；新面板成为激活面板并聚焦。
- `Ctrl+,` 不改变活跃项目；只作用于当前活跃项目。
- 活动栏底部配置钮使用相同语义；配置钮的呈现、提示与激活态见 [sidebar/framework.md](../sidebar/framework.md) 与 [panels/settings.md](../panels/settings.md)。
- 重绑、可重绑命令的冲突与回退在设置中心快捷键页可见；面板内部固定键的上下文冲突见对应面板篇。细节见 [panels/settings.md](../panels/settings.md)。
- 设置中心打开失败时通知 `设置中心打开失败：项目尚未就绪，请重试`。

### 浮层

- 通知浮层在项目切换、面板切换与布局恢复期间保持可见；通知不随项目切换清空。
- 确认框在项目切换时保持挂起；其目标对象由发起时确定，不随可见项目变化。
- 面板页签菜单、终端重命名弹窗在项目切换时关闭。
- 确认框打开期间，背景界面的鼠标与键盘操作被遮罩阻止。
- 系统通知只在窗口失焦时出现；窗口聚焦时不打扰用户。

## 边界与错误

### 空态

- **无项目**：主区空白，标题栏中段为空；导航树按自身空态显示；应用不显示全局欢迎页或全局“创建项目”引导。此时按 `Ctrl+,` 或点击配置钮通知 `请先创建项目`。
- **有项目但活跃项目布局无面板**：显示项目空态：15px 线性图标 <img src="../assets/preview/icons/empty-box.svg" width="15" height="15" alt="空态图标">（`../assets/icons/empty-box.svg`，15px）、13px 文案 `打开终端或编辑器开始工作`（契约）与 `新建终端` 按钮。点击按钮创建第一个面板组与终端面板。
- **面板组为空**：面板组自动移除，不显示空页签栏；不存在保留的空面板组。
- **项目空态不是面板**：不出现在任何页签栏中，不参与去重、关闭守卫或布局持久化。
- **布局恢复失败或全部面板被丢弃**：对应项目显示项目空态，不自动创建终端。
- **通知浮层无通知、确认框无请求**：不渲染任何内容。

### 加载

- 启动加载界面全屏显示 `slTerminal 启动中…`，无标题栏与工作区；无进度条或骨架屏。
- 配置域并行加载；项目数据在配置加载后加载。
- 布局恢复在主区就绪时完成，无全局加载遮罩；各面板内部数据加载形态由面板规格定义。
- 项目切换不产生加载态：所有项目布局已在内存，切换只改变可见性与焦点。
- 新建面板同步创建容器；面板内部的重内容加载由面板规格处理。

### 错误

| 场景 | 可感知行为 |
|---|---|
| 单实例检查发现已有实例 | 激活并前置已有窗口，不创建新窗口 |
| 用户设置读取失败 | 使用默认设置继续启动，记录警告 |
| 用户设置损坏 | 通知 `配置已损坏，已回退默认值`，使用备份值或默认值继续 |
| 项目数据损坏但可回退 | 通知 `配置已损坏，已回退默认值`，使用备份值或默认值继续启动 |
| 项目数据加载失败 | 显示项目数据错误界面，提供 `重试` 与 `以空状态继续`，阻断进入工作区 |
| 项目根路径设置失败 | 通知 `项目根路径设置失败，文件操作可能被拒绝`，不阻断项目切换 |
| 单个项目布局无法解析 | 该项目显示空态，其他项目不受影响；启动后以一条聚合警告说明受影响的项目与面板 |
| 未知面板类型被丢弃 | 面板不出现；项目无剩余面板时显示空态；丢弃结果并入启动聚合警告，不逐项弹窗 |
| 单个面板渲染出错 | 该面板区域显示 `面板渲染出错`、`重试` 与可折叠错误详情；其他面板可用 |
| 应用整体渲染出错 | 全屏 `应用渲染错误`，显示用户可读错误与可折叠诊断详情；诊断不得包含凭据、文件内容或终端输出 |
| 无项目时打开设置中心 | 通知 `请先创建项目`，不创建项目，不切换项目 |
| 设置中心打开失败 | 通知 `设置中心打开失败：项目尚未就绪，请重试` |
| 批量保存失败 | 中止关闭，保留全部面板，以错误通知列出失败项 |
| PTY 终止或项目数据保存失败 | 记录日志，继续关闭窗口；不留下终端进程；设置冲刷失败按设置守卫统一规则处理 |
| 项目数据保存失败（非关闭链） | 通知 `项目数据保存失败`；不自动重试，记录日志 |
| 面板保存并关闭失败 | 通知 `保存失败，面板未关闭`；面板保持打开且脏状态不变 |
| 终端后端回退到系统控制台 | 通知 `终端已回退到系统控制台,鼠标滚轮转发不可用`；细节由终端规格定义 |
| 终端启动失败 | 由终端面板显示错误与重试入口，终端规格定义细节 |

- 所有错误消息不插值凭据、密钥或文件内容。
- 错误边界只隔离受影响区域；面板错误不导致同项目其他面板卸载。

### 并发、恢复与数据安全

- 多项目同时运行；各终端 PTY 独立运行，后台项目继续接收输出。隐藏项目的渲染停止，输出可合并缓冲；切回时补齐当前可见状态。
- 布局自动保存与关闭冲刷可能并发：保存期间的新变更合并到下一次写入；关闭冲刷以最新内存状态为准。
- 移除项目时，其终端 PTY 与面板资源按关闭流程终止；若 PTY 正在启动，终止后不再产生回调更新界面。
- 应用异常退出时，已落盘布局最多回退到最近一次自动保存。
- 编辑器与 Markdown 源码态的未保存文本按固定间隔写入恢复快照。下次启动检测到上次异常退出时，以一次聚合提示询问恢复或丢弃；选择丢弃后清理快照。恢复仅还原文本缓冲，不还原光标与滚动位置。正常关闭后清理恢复快照，不提示恢复。终端内容、Diff 工作区侧与设置中心未保存修改不在崩溃恢复范围内。细节见 [settings-and-persistence.md](../settings-and-persistence.md)。
- 单实例约束避免多个进程同时写同一项目数据。
- 持久化写入不得产生半写文件；存储实现细节见 [settings-and-persistence.md](../settings-and-persistence.md)。

### 性能与资源

- 项目切换为可见性切换，不重建项目布局与面板；切换耗时不随项目内面板数量线性增长。
- 隐藏项目不持续渲染；终端输出仍可接收，界面更新可节流，切回时以当前终端状态重绘。
- 打开的面板保持实例，内存随面板与 PTY 数量增长；关闭面板与移除项目后资源必须释放。
- 面板组数量与嵌套深度没有业务上限，受窗口可用尺寸与资源限制；空间不足时拒绝拆分，不产生不可用布局。
- 页签栏溢出使用横向滚动并提供溢出下拉列表，不压缩到不可读；完整标题通过悬停提示提供。
- 布局写入使用 2 秒合并窗口（契约），避免高频拖动产生写放大；正常关闭强制冲刷。

### 无障碍基线

- 所有交互控件可用键盘到达与操作；焦点顺序为活动栏 → 侧栏 → 主区页签栏 → 激活面板 → 浮层。
- 焦点环始终可见，且在暗色背景下满足对比度要求；焦点环不得被面板内容裁切。
- 面板页签栏具备页签列表语义，提供选中状态、面板关联与标题；关闭按钮名称为 `关闭 <面板标题>`；脏面板的未保存标记可被读屏识别。
- 面板组分隔线可聚焦，方向键调整尺寸；拆分与移动面板提供键盘可达的菜单入口，不要求必须拖拽。
- 确认框具备焦点陷阱、初始焦点、`Escape` 取消与按钮循环；关闭后焦点回到发起控件。
- 通知使用礼貌播报；错误通知不得被静默丢弃；通知关闭按钮可键盘到达并有明确无障碍名称。颜色不是唯一信息通道：终端状态、脏状态、错误与焦点均有文本或形状辅助。
- 尊重系统“减少动效”设置；面板切换、面板组拆分与通知动画在减少动效下取消或缩短。
- 中文输入法合成期间不触发命令；CJK 文本不因省略、换行或焦点逻辑被截断为不可读。
- 图标按钮提供无障碍名称；纯图标窗口控制钮的提示文字同时作为无障碍名称。

### 平台与系统边界

- 仅支持 Windows 10/11 桌面；使用 Windows 原生 shell 与编码 CLI，不通过 WSL。
- 单窗口、单实例、仅暗色、GPU 加速渲染为产品边界。
- 终端鼠标与滚轮输入按前台程序声明的鼠标跟踪与交替屏幕状态自动路由；不提供输入模式配置页面或配置键。
- 自绘标题栏的拖动、双击最大化与系统贴靠交给操作系统窗口能力；应用只维护按钮状态与拖拽区命中。
- 路径比较使用 Windows 大小写不敏感规则；同名文件判断基于规范化绝对路径。
- 文件锁、权限拒绝、路径长度与外部程序行为属于操作系统边界；对应错误由编辑器、文件浏览器或 Markdown 文档规格呈现，不得静默丢失用户修改。
- HTML 文件的外部打开使用系统默认程序，参数以单一路径传递，不经过 shell 字符串拼接；细节见 [panels/editor.md](../panels/editor.md)。
- 触摸优先布局、多窗口、多实例协同、跨平台与移动端不在范围内。

### 安全边界

- 持久化的布局与项目数据只包含路径、面板参数与标题，不包含凭据、密钥或文件内容。
- 崩溃恢复快照只包含编辑器与 Markdown 源码态的未保存文本，不包含凭据、终端输出或 Diff 工作区侧；正常关闭后清理。
- 错误通知、日志与确认框不插值凭据或敏感文件内容。
- 项目根路径与文件操作限制由文件浏览器与编辑器规格定义；面板不得绕过项目作用域直接写入其他项目根。
- 外部程序启动、文件打开与路径穿越防护由对应面板规格定义；本篇要求入口参数以结构化路径传递。

## 验收判据

### 模型与项目

- **Given** 两个项目各有运行中的终端 **When** 在导航树切换项目 **Then** 两个终端均保持运行，切回时内容连续，没有重新创建 PTY。
- **Given** 项目 A 为活跃项目 **When** 移除项目 A 且存在项目 B **Then** 确认框列出终端数量与脏面板标题；确认后项目 B 自动成为活跃项目；若没有其他项目，主区空白且标题栏中段为空。
- **Given** 通过选择文件夹创建项目 **When** 文件夹名为 `demo` 且已存在显示名 `demo` 的项目 **Then** 新项目显示名为 `demo 2`，自动成为活跃项目并显示项目空态，不自动创建终端。
- **Given** 项目根为目录 A **When** 将项目根重定位到目录 B **Then** 文件型面板按 B 重新计算相对路径，项目布局与面板实例不重建，终端默认工作目录更新。
- **Given** 没有项目 **When** 按 `Ctrl+,` 或点击活动栏配置钮 **Then** 通知 `请先创建项目`，不创建项目，不打开设置中心。
- **Given** 活跃项目内已有设置中心面板 **When** 再次按 `Ctrl+,` **Then** 聚焦已有面板，该项目内不出现第二个设置中心。
- **Given** 项目没有面板组 **When** 查看主区 **Then** 显示项目空态；点击 `新建终端` 创建第一个面板组与终端面板。
- **Given** 项目 A 的项目布局包含两个面板组 **When** 切换到项目 B 再切回 **Then** 两个面板组及其面板整体隐藏后恢复，不迁移到项目 B，面板实例不重建。

### 空态

- **Given** 没有项目 **When** 查看主区 **Then** 主区空白，标题栏中段为空，不显示全局欢迎页或创建项目引导。
- **Given** 活跃项目布局没有面板 **When** 查看主区 **Then** 显示项目空态，包含 `打开终端或编辑器开始工作` 与 `新建终端`；项目空态不出现在页签栏中。
- **Given** 面板组最后一个面板被关闭或拖出 **When** 查看布局 **Then** 该面板组被移除，不显示空页签栏。
- **Given** 布局恢复失败或全部面板被丢弃 **When** 查看该项目 **Then** 显示项目空态，不自动创建终端。
- **Given** 没有通知且没有确认请求 **When** 查看浮层 **Then** 不渲染任何内容。

### 布局与面板组

- **Given** 一个项目内有两个面板组 **When** 关闭其中一个面板组的最后一个面板 **Then** 该面板组被移除，剩余面板组重新占满空间。
- **Given** 项目内没有面板组 **When** 点击项目空态 `新建终端` **Then** 创建第一个面板组与终端面板，空态消失。
- **Given** 一个终端面板 **When** 在面板内寻找拆分入口 **Then** 不存在面板内窗格拆分；并排终端只能通过新建面板组获得。
- **Given** 面板页签被拖到另一个面板组 **When** 释放 **Then** 面板移动并合并到目标面板组，源面板组为空时自动移除。
- **Given** 拖动面板到隐藏项目的布局或窗口外 **When** 释放 **Then** 布局不变，不产生跨项目面板。
- **Given** 可用空间不足以容纳 120×80px 的面板组 **When** 执行拆分 **Then** 拆分不执行，原布局保持。
- **Given** 面板组分隔线获得焦点 **When** 按方向键 **Then** 相邻面板组尺寸按 10px 步进调整（契约）。
- **Given** 面板页签菜单 **When** 选择 `拆分到右侧`、`拆分到下方` 或 `移动到下一个面板组` **Then** 效果与对应拖拽操作一致。
- **Given** 面板组页签溢出 **When** 打开溢出下拉列表 **Then** 列表包含该面板组全部面板及状态；选择列表项激活对应面板。
- **Given** 点击面板组头部 `+` **When** 终端面板出现 **Then** 新终端成为激活面板并获得焦点。

### 面板类型、标题与去重

- **Given** 布局数据包含未知面板类型 **When** 启动恢复 **Then** 该面板被丢弃，项目其余面板正常；若全部被丢弃则显示项目空态，应用不崩溃，并出现一条聚合警告。
- **Given** 项目内依次新建两个终端 **When** 查看标题 **Then** 标题为 `terminal-0`、`terminal-1`；关闭 `terminal-0` 后再新建，标题为 `terminal-2`，编号不复用。
- **Given** 项目内已有 `terminal-0` 与 `terminal-1` **When** 重启并新建终端 **Then** 新终端标题为 `terminal-2`，编号不因重启重算。
- **Given** 两个项目各自新建终端 **When** 查看标题 **Then** 每个项目均可从 `terminal-0` 开始。
- **Given** 同一项目打开两个不同目录下的同名文件 **When** 查看页签 **Then** 两个标题均包含相对项目根的路径；关闭一个后，另一个恢复为纯文件名。
- **Given** 同一文件已在项目中打开 **When** 再次打开该文件 **Then** 聚焦已有编辑器面板，不新建；编辑器与同文件的 Git Diff/GitShow 分别独立。
- **Given** 项目内已打开某文件 **When** 从不同 Commit 来源再次打开 **Then** 仍只有一个编辑器视图，不产生来源后缀视图。
- **Given** Commit 视图打开 added/untracked 文件 **When** 经文件打开路由分派 **Then** 使用普通文件名标题，不追加 `(git add)` 或 `(git not add)`；modified/renamed/conflict 打开 Diff 并显示 `(git diff)`，deleted 打开 GitShow 并显示 `(git delete)`。
- **Given** 设置中心已打开 **When** 再次打开设置中心 **Then** 聚焦已有面板，该项目内不出现第二个设置中心。
- **Given** 终端自定义标题 **When** 重启 **Then** 自定义标题保留；无自定义标题的终端编号随项目持久，重启不重算，之后新建终端继续递增。
- **Given** 打开 `.html` 文件 **When** 面板出现 **Then** 显示可编辑源码，不渲染、不执行脚本；右上角悬浮按钮以系统默认程序打开磁盘上的文件，存在未保存修改时不提示、不保存。
- **Given** 打开 Markdown 文档 **When** 查看形态入口 **Then** 只有源码与渲染两态，默认渲染态；不存在编辑预览分栏或分栏比例设置。
- **Given** 打开终端面板 **When** 查看页签 **Then** 终端面板不去重，每次新建均创建独立终端。
- **Given** 脏面板 **When** 查看页签 **Then** 显示未保存标记；读屏名称为“未保存”。
- **Given** 聚焦面板组的激活面板 **When** 查看页签 **Then** 底部显示 2px 强调色指示条；非聚焦面板组不显示。

### 焦点

- **Given** 点击面板组头部 `+` **When** 终端面板出现 **Then** 可直接输入字符，无需再次点击终端区域。
- **Given** 从文件浏览器双击文件打开编辑器 **When** 编辑器出现 **Then** 编辑区获得焦点，可直接输入。
- **Given** 应用重启并恢复布局 **When** 启动完成 **Then** 没有面板自动获得焦点，按键不会误输入到面板。
- **Given** 布局恢复包含 Markdown 渲染态、Diff 只读侧、GitShow 或大文件只读面板 **When** 启动完成 **Then** 这些面板均不自动获得焦点。
- **Given** 显式打开 Markdown 渲染态、Diff 只读侧、GitShow 或大文件只读面板 **When** 面板出现或点击内容区 **Then** 可获得键盘焦点；Markdown 切换到源码态后编辑区可聚焦。
- **Given** 关闭获得焦点的面板 **When** 同面板组还有其他面板 **Then** 焦点转移到下一个面板；没有下一个则转移到上一个。
- **Given** 同面板组没有其他面板 **When** 关闭获得焦点的面板 **Then** 焦点转移到相邻面板组的激活面板；没有其他面板组时停留在工作区层级。
- **Given** 目标项目此前聚焦过某面板 **When** 切换项目 **Then** 恢复该面板为激活面板，并把键盘焦点送入其焦点落点。
- **Given** 终端或编辑器获得焦点 **When** 按 `Ctrl+Tab` / `Ctrl+Shift+Tab` **Then** 焦点循环到活跃项目的下一个/上一个面板，不输入到前台程序或编辑器缓冲。
- **Given** 点击面板内容 **When** 面板成为激活面板 **Then** 其所在面板组成为聚焦面板组，焦点进入面板。

### 脏状态与关闭

- **Given** 编辑器有未保存修改 **When** 查看页签 **Then** 显示未保存标记；读屏名称为“未保存”。
- **Given** 脏面板 **When** 点击页签 `×`、按 `Ctrl+W`、中键点击或使用右键 `关闭` **Then** 均弹出 `未保存的修改` 确认框；取消后面板仍在，选择 `丢弃并关闭` 后关闭且修改丢弃。
- **Given** 有保存能力的脏面板 **When** 选择 `保存并关闭` **Then** 保存成功后关闭；保存失败时通知 `保存失败，面板未关闭`，面板保持打开且仍为脏状态。
- **Given** 设置中心存在待写或失败自动保存 **When** 关闭设置面板、移除项目或关闭窗口 **Then** 该面板进入需保存集合；保存失败时中止关闭并保留面板与失败状态。
- **Given** 同一面板组多个脏面板 **When** 执行 `关闭其他` 或 `关闭全部` **Then** 只弹一次确认框并列出将被关闭的脏面板标题；取消则整批不关闭。
- **Given** 终端存在前台运行进程 **When** 关闭该终端面板 **Then** 弹出确认框并列出进程信息；取消后终端保持运行，确认后终止 PTY 并关闭。
- **Given** 终端空闲 **When** 关闭该终端面板 **Then** 不弹确认，直接关闭。
- **Given** 项目存在脏面板或有前台运行进程的终端 **When** 从导航树移除项目 **Then** 确认框列出终端数量、脏面板与运行中终端；取消不移除，确认后按选择保存或放弃并移除。
- **Given** 窗口内存在脏面板 **When** 关闭窗口 **Then** 弹出一次聚合确认；取消则窗口保持打开，确认后按选择保存或放弃并进入清理链。
- **Given** 非活跃项目存在脏面板 **When** 关闭窗口 **Then** 聚合确认仍列出该面板，不因项目隐藏而遗漏。
- **Given** 窗口内存在前台运行进程的终端 **When** 关闭窗口 **Then** 聚合确认列出运行中终端；取消则窗口保持打开，确认后终止进程并进入清理链。
- **Given** 没有脏面板且没有前台运行进程 **When** 关闭窗口 **Then** 不弹确认，直接进入清理链。
- **Given** 没有激活面板 **When** 按 `Ctrl+W` **Then** 不关闭任何面板，也不关闭窗口。
- **Given** 设置中心 Hooks 存在未保存修改 **When** 执行项目切换 **Then** 设置中心随项目隐藏但保持存活，未保存修改保留；关闭时进入关闭守卫。

### 批量保存并关闭

- **Given** 同一面板组有多个脏面板 **When** 执行 `关闭其他` 或 `关闭全部` 并选择 `保存全部并关闭` **Then** 逐个保存将被关闭的脏面板，全部成功后关闭目标面板。
- **Given** 批量保存中任一脏面板保存失败 **When** 选择 `保存全部并关闭` **Then** 中止关闭，全部面板保持打开，已保存面板清除脏状态，并以一条错误通知列出失败项。
- **Given** 批量保存失败 **When** 查看运行中终端 **Then** 终端未被终止，仍在原面板组运行。
- **Given** 批量关闭确认框 **When** 选择 `放弃全部并关闭` **Then** 丢弃全部未保存修改并关闭范围内目标面板。
- **Given** 批量关闭确认框 **When** 选择 `取消` **Then** 整批不关闭，脏状态与运行中终端保持不变。
- **Given** 项目存在多个脏面板 **When** 移除项目并选择 `保存全部并关闭` **Then** 逐个保存，全部成功后移除项目。
- **Given** 项目移除时任一脏面板保存失败 **When** 选择 `保存全部并关闭` **Then** 中止移除，项目与全部面板保持，错误通知列出失败项。
- **Given** 窗口内多个项目存在脏面板 **When** 关闭窗口并选择 `保存全部并关闭` **Then** 逐个保存全部项目的脏面板，全部成功后进入关闭清理链。
- **Given** 窗口关闭批量保存失败 **When** 选择 `保存全部并关闭` **Then** 中止关闭，窗口保持打开，全部面板保留，错误通知列出失败项。
- **Given** 无脏面板但存在运行中终端 **When** 关闭窗口 **Then** 确认框只提供 `取消` 与 `关闭并退出`；确认后进入关闭清理链。
- **Given** 已保存的面板 **When** 批量保存后续面板失败 **Then** 已保存面板保持打开且不再显示未保存标记。

### `Ctrl+,`

- **Given** 活跃项目没有设置中心 **When** 按 `Ctrl+,` **Then** 在当前聚焦面板组创建设置中心并聚焦；项目布局没有面板组时创建第一个面板组。
- **Given** 活跃项目已有设置中心且位于非聚焦面板组 **When** 按 `Ctrl+,` **Then** 激活该面板组与设置中心，不新建第二个。
- **Given** 没有项目 **When** 按 `Ctrl+,` **Then** 通知 `请先创建项目`，不创建项目，不打开设置中心。
- **Given** 活跃项目为项目 B **When** 按 `Ctrl+,` **Then** 设置中心只在项目 B 中打开或聚焦，活跃项目不变。
- **Given** 终端或编辑器获得焦点 **When** 按 `Ctrl+,` **Then** 设置中心打开或聚焦，按键不送入终端或编辑器。
- **Given** 用户把 `Ctrl+,` 重绑到合法新键 **When** 使用新键 **Then** 设置中心打开或聚焦；默认 `Ctrl+,` 不再触发；冲突与回退在设置中心快捷键页可见。

### 单实例与窗口

- **Given** 已有一个应用实例 **When** 再次启动 **Then** 不创建新窗口，已有窗口被激活并前置。
- **Given** 启动完成 **When** 查看窗口顶部 **Then** 存在 34px（契约）自绘标题栏，中段显示活跃项目名，右侧有最小化、最大化/还原、关闭钮。
- **Given** 在标题栏左段或中段拖动 **When** 移动鼠标 **Then** 窗口移动；双击切换最大化/还原。
- **Given** 终端有前台运行进程 **When** 关闭窗口并确认 **Then** 关闭链依次执行设置与布局冲刷、并发终止 PTY、保存项目数据，每阶段最多 3 秒（契约），随后窗口关闭。
- **Given** 关闭链各阶段均达到超时上限 **When** 关闭窗口 **Then** 最坏总等待约 9 秒（契约），窗口仍然关闭，不留下终端进程。
- **Given** 关闭过程中 PTY 终止或项目数据保存失败 **When** 查看结果 **Then** 失败被记录，窗口仍然关闭，不留下终端进程；设置冲刷失败是否阻断关闭按设置守卫的统一规则处理。
- **Given** 关闭前有未落盘的设置变更 **When** 关闭窗口 **Then** 待保存变更被冲刷，而不是被取消。
- **Given** 应用启动与运行 **When** 观察窗口 **Then** 无系统标题栏与系统边框，仅暗色外观。

### 通知与系统通知

- **Given** 触发成功、警告、错误通知 **When** 观察右上角 **Then** 三条纵向堆叠，并分别在 3/4/5 秒后消失（契约）；悬停时倒计时暂停，移出后继续；关闭按钮可移除通知。
- **Given** 通知浮层出现 **When** 切换项目 **Then** 通知保持可见，不清空。
- **Given** 确认框打开 **When** 按 `Tab` / `Shift+Tab` / `Enter` / `Escape` **Then** 焦点在按钮间循环、提交当前按钮、取消并返回发起控件。
- **Given** 窗口失焦时收到编码 CLI 状态事件 **When** 观察系统 **Then** 出现系统通知并闪烁任务栏；类别覆盖任务完成、等待输入、权限请求与错误；回窗后停止闪烁；重复事件不重复通知。
- **Given** 窗口聚焦时收到编码 CLI 状态事件 **When** 观察系统 **Then** 不发送系统通知，不闪烁任务栏。
- **Given** 启动期间产生通知 **When** 界面挂载完成 **Then** 未超过自动消失时长的通知照常显示。

### 恢复与状态保留

- **Given** 某项目拆成两个面板组并放置多个面板 **When** 正常关闭后重启 **Then** 面板组结构、页签顺序、激活面板与聚焦面板组恢复。
- **Given** 终端自定义标题 **When** 重启 **Then** 自定义标题保留；无自定义标题的终端编号随项目持久，重启不重算，之后新建终端继续递增。
- **Given** Markdown 文档处于源码态 **When** 正常重启 **Then** 形态恢复为源码态；未保存源码内容不恢复。
- **Given** 上次活跃项目存在 **When** 启动 **Then** 只显示该项目布局，其他项目已恢复但不可见。
- **Given** 某项目布局数据损坏 **When** 启动 **Then** 该项目显示空态，其他项目正常，应用不崩溃；启动后出现一条聚合警告。
- **Given** 布局数据结构不兼容 **When** 启动 **Then** 该项目按空项目布局处理，应用不崩溃。
- **Given** 关闭前刚调整布局 **When** 正常关闭并重启 **Then** 最近布局保持，不等待自动保存计时。
- **Given** 编辑器面板有未保存修改与撤销历史 **When** 同面板组切到另一面板再切回 **Then** 面板实例未重建，内容、撤销历史、光标与滚动保持。
- **Given** 设置中心打开且存在未保存修改 **When** 切换到其他项目再切回 **Then** 设置中心仍在原项目布局内，未保存修改保持，不自动关闭。
- **Given** 布局恢复丢弃了未知面板 **When** 启动完成 **Then** 出现一条聚合警告，说明受影响的项目与面板，不逐项弹窗。
- **Given** 上次异常退出且有未保存文本 **When** 启动 **Then** 聚合提示恢复或丢弃；选择恢复后还原编辑器与 Markdown 源码态文本缓冲，不还原光标与滚动位置。
- **Given** 正常关闭应用 **When** 下次启动 **Then** 不提示恢复，恢复快照已清理。
- **Given** 非活跃项目的终端正在运行 **When** 该项目保持隐藏 **Then** 终端继续运行，切回时内容连续。

### 键盘与无障碍

- **Given** 键盘用户 **When** 使用 `Tab` 进入页签栏 **Then** 可用方向键移动页签焦点，`Enter`/`Space` 激活，关闭按钮可单独聚焦。
- **Given** 面板组分隔线获得焦点 **When** 按方向键 **Then** 尺寸按 10px 步进调整（契约）。
- **Given** 脏面板 **When** 使用读屏 **Then** 未保存状态被播报，关闭按钮名称包含面板标题。
- **Given** 系统启用减少动效 **When** 切换面板或项目 **Then** 不播放或缩短动画。
- **Given** 任意面板 **When** 观察焦点 **Then** 焦点环可见且未被裁切。
- **Given** 通知浮层出现 **When** 使用键盘 **Then** 可聚焦并触发通知的关闭按钮。
- **Given** 中文输入法合成中 **When** 按下组合键 **Then** 不触发应用命令，输入法正常出字。

## 关键决策与依据

- **模型层级**：规则：项目 → 项目布局 → 面板组 → 面板；每个项目恰好一个项目布局；面板组是项目布局内的页签组。原因：项目是工作单元，布局与项目一一对应，减少层级与心智负担。边界：面板只属于一个项目，禁止跨项目移动；跨项目使用在目标项目重新打开。
- **多项目并存**：规则：多项目布局同时存活，切换只改变可见性、激活态与焦点。原因：保持终端与面板状态连续，切换无加载态。边界：隐藏项目不持续渲染，PTY 继续运行；焦点记忆仅运行期。
- **面板类型封闭**：规则：只有终端、编辑器、Markdown 文档、Diff、GitShow、设置中心。原因：恢复可判定、错误可隔离。边界：未知类型恢复时丢弃并聚合警告；新增类型须修订本规格。
- **设置中心单例**：规则：每个项目一个设置中心；重复打开聚焦已有面板。原因：避免同一项目多份配置视图与状态冲突。边界：设置中心随项目隐藏，不自动关闭。
- **空面板组移除**：规则：最后一个面板被关闭或拖出后移除面板组；无面板组时显示项目空态。原因：空组无可用内容，避免空壳堆积。边界：项目空态不是面板，不进入页签栏、去重、关闭守卫或布局持久化。
- **焦点恢复策略**：规则：活跃项目 → 聚焦面板组 → 激活面板 → 面板内落点；启动与布局恢复不产生焦点意图；显式打开与切换项目按落点聚焦。原因：避免启动误输入，同时保证显式操作可立即输入。边界：焦点记忆仅运行期；只读视图显式打开或点击可聚焦。
- **脏状态统一守卫**：规则：编辑器、Markdown 源码态、Diff 工作区侧、设置中心（Hooks）声明脏状态；单个关闭提供保存、丢弃与取消。原因：防止静默丢失修改。边界：终端与 GitShow 无脏状态；保存失败保留面板与脏状态。
- **批量保存全有或全无**：规则：批量关闭、项目移除、窗口关闭在存在需保存面板时列出需保存面板，提供保存全部、放弃全部与取消；逐个保存，任一失败中止关闭并保留全部面板与失败项；全部成功才关闭、移除或退出。原因：部分成功会让关闭结果不可预测，全有或全无保证数据安全与可解释性。边界：失败时已保存面板保持打开并清除脏状态；运行中终端不被终止。
- **`Ctrl+,` 全局入口**：规则：打开或聚焦活跃项目的设置中心；无活跃项目提示 `请先创建项目`，不创建项目；可重绑。原因：提供键盘可达的统一设置入口。边界：不改变活跃项目；设置中心已存在时不新建；冲突在设置中心快捷键页可见。
- **单实例单窗口**：规则：进程级单实例；第二次启动激活并前置已有窗口。原因：避免多进程并发写同一项目数据，符合产品定位。边界：不提供多窗口或多实例协同。
- **通知策略**：规则：通知浮层悬停暂停、可关闭；系统通知仅在窗口失焦且收到 CLI 状态事件时发送并去重。原因：保持操作连续，减少噪声。边界：通知正文不可点击；系统通知无跳转；任务栏闪烁为唯一回窗引导。
- **布局去抖与冲刷**：规则：布局变更立即写内存，2 秒去抖落盘；关闭先冲刷再保存项目数据。原因：避免拖动写放大，同时不丢失最近变更。边界：恢复只读取、不写回；无法解析的布局按空布局处理并聚合警告。
- **标题规则**：规则：文件面板默认文件名，同名用相对路径消歧；编辑器不因 Commit 来源加后缀；Diff/GitShow 使用状态后缀；终端编号在项目内持久且关闭不复用。原因：标题稳定可识别，避免同一文件多视图歧义。边界：Agent 全局文件标题由 Agent 文件规格定义；项目根外文件使用规范化绝对路径。
- **关闭链有界**：规则：设置与布局冲刷、PTY 终止、项目数据保存依次执行，各最多 3 秒，最坏约 9 秒。原因：退出有界，同时给数据落盘机会。边界：PTY 终止与项目数据保存失败只记录日志，不阻止关闭；设置冲刷失败按设置守卫规则。
