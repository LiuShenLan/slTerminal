# 工作区壳

> 拥有项目布局、面板组、面板实例、焦点、关闭状态机和单实例意图；项目导航、Document、终端及设置内容由各自所有者定义。

## 模型与布局

- 层级固定为 Project → ProjectLayout → PanelGroup → Panel。每个项目恰好一个布局，多项目布局同时存活；存在项目时恰好一个活跃项目。
- 面板属于一个项目，禁止跨项目移动；不同项目可创建引用同一 Document 的独立视图。
- PanelGroup 是页签容器，可水平或垂直拆分、合并和调整尺寸；空组自动移除，没有面板组时显示项目空态。
- `PanelId` 仅属于存活实例；关闭销毁实例。`ViewKey` 与持久视图状态独立保留，重新打开同一逻辑视图可分配新 `PanelId`。
- 面板类型封闭为 Terminal、Editor、Markdown、Diff、GitShow、Settings；未知类型恢复时过滤并聚合警告，不创建替代面板。
- 页签可拖入同项目其他组或边缘拆分，也可通过菜单执行拆分与移动；空间不足以容纳 120×80px 的新组时拒绝拆分。
- 分隔线可键盘聚焦并以方向键调整；所有布局操作均有非拖拽入口。布局变化按持久化规则合并保存。

## 项目生命周期

- 创建项目只选择目录；成功真实路径查重后生成 `ProjectId`，默认显示名取目录名，重名追加递增后缀，并自动成为活跃项目。创建不自动生成终端。
- 项目显示名可重命名且允许重名；顺序可调整并持久化。根路径不是项目身份。
- 项目根不可访问时保留项目、布局和错误状态；根重定位只按 [PathPolicy](../path-policy.md) 改关联，不重建布局、Panel 或 Document。
- 移除活跃项目后按导航顺序激活下一个，没有下一个则激活上一个；移除全部项目后进入无项目状态。
- 项目移除必须执行与窗口关闭同源的保存／丢弃／取消守卫，不再默认丢弃。提交项目删除与关闭意图后才终止其 PTY、删除布局及 `ViewKey` 状态；失败保留项目与全部面板。
- 项目移除不删除磁盘文件或历史会话，不取消其他项目的应用设置保存，也不删除仍被其他项目引用的 Document 恢复材料。

## 面板与页签

- 新面板默认落在当前项目的聚焦组；无组时创建首组。显式新建失败不得留下空面板，恢复失败则保留面板与重试。
- 同项目普通 Document、Diff、GitShow 和 Settings 按各自 `ViewKey` 去重；Terminal 每次显式新建均为独立逻辑终端。
- 文件页签默认显示文件名，同名时用路径消歧；Diff 使用 `(git diff)`，GitShow 使用 `(git delete)`。标题不是身份。
- 终端默认显示 `terminal-N`；编号只是项目内显示序号，不是 `PanelId` 或持久终端身份。
- 页签显示共享 Document 脏标记、CLI 状态和关闭入口；状态同时使用文本或形状，不只靠颜色。
- 页签栏溢出时横向滚动并提供完整列表；关闭其他／全部只作用于当前组，并进入统一批量守卫。
- 单个面板错误只隔离该区域并提供重试，不卸载同项目其他面板。

## 焦点与浮层

- 焦点层级为活跃项目 → 聚焦组 → 激活面板 → 面板内落点。显式打开或激活按面板类型送焦；启动与布局恢复不抢焦。
- 切换项目只改变可见性，并恢复该项目运行期最后聚焦位置；隐藏项目的输出或事件不得抢焦。
- `Ctrl+Tab`／`Ctrl+Shift+Tab` 在活跃项目全部面板间循环，终端与编辑器不得截获。
- 关闭聚焦面板后依次尝试同组下一个、上一个、相邻组激活面板和工作区容器。
- 应用内通知不抢焦，可关闭；悬停或控件聚焦暂停自动消失。通知、菜单和错误均为瞬态，关闭重开与重启不恢复。
- 模态确认一次只存在一个，危险操作默认聚焦安全动作；焦点约束与还焦链按 [跨域约定](../cross-cutting.md)。

## 设置入口

- `Ctrl+,` 与活动栏配置按钮使用同一命令：有活跃项目时打开或聚焦该项目唯一 Settings 面板；无项目时打开应用设置浮层。
- 无项目浮层提供全部应用级设置：快捷键、后台任务、外观、终端、应用、Agent 基础和 Hooks User；诊断、备份与更新不依赖项目。项目级 Hooks 与项目专属内容隐藏。
- 项目在浮层打开期间被激活时，浮层不自动关闭，继续共享应用设置并保留 Hooks User 草稿；用户关闭后，下次打开才使用当前项目的 Settings 面板。
- 设置浮层或面板显式关闭时，Hooks 草稿按保存／丢弃／取消守卫处理；全局待写应用设置不随某个视图关闭而取消。

## 统一关闭状态机

### 守卫集合

- Document 按最后引用判定，而不是按单个页签判定；关闭非最后引用只销毁 Panel。
- 批量关闭、项目移除和退出按 Document 去重；关闭集合外仍有引用时不得丢弃其缓冲。
- Hooks 草稿、运行中终端和必要的应用设置待写状态也进入对应守卫；Runtime 调用按非交互冲突规则处理，不弹模态框。

### 交互关闭

1. 收集受影响对象并一次列出脏 Document、Hooks 草稿和运行中终端。
2. 用户选择保存、丢弃或取消。保存按 Document 去重执行，可部分成功；任一失败取消本次关闭，保留全部 Panel，成功项保持干净。
3. 用户显式丢弃时，只处理关闭集合内最后引用；不得借批量操作丢弃集合外仍使用的 Document。
4. 全部保存或丢弃决定完成后，提交设置、布局、逻辑终端记录和关闭意图。
5. 必要状态提交成功后，才终止相关 PTY、删除已提交的恢复材料和销毁 Panel。
6. 最后提交正常退出状态并销毁窗口；项目移除与批量面板关闭不伪造全局正常退出标记。

- 自动保存可在守卫中先尝试；失败或冲突后仍由用户选择，不自动强制关闭。
- 每阶段有界等待，超时按失败处理并保留现场，不自动进入破坏阶段。用户可修复重试，或再次明确丢弃。
- 最终状态提交失败时提供重试；也可显式选择“退出且不保存本次窗口状态”，但必须提示旧布局与快照可能恢复。
- OS 强杀不经过该状态机，不属于正常关闭保证。

## 单实例与外部意图

- 第二实例不创建窗口，激活并前置既有窗口；结构化意图包括仅聚焦、打开项目、打开文件和新建终端。
- 外部打开或新建意图不隐式创建项目；历史恢复确需创建时须由用户明确确认。
- `NewTerminal` 指定 `project_root` 时只接受已登记项目；未指定才按 cwd 最深匹配。cwd 不属于授权根时不改投活跃项目。
- 未提供 cwd 时使用目标项目根；显式 cwd 不存在、非目录或未授权时拒绝，不回退。只有历史／启动恢复可按各自规则回退项目根并提示。
- 新终端落目标项目聚焦组，无组则建首组；达到 PTY 上限、路径校验失败或正在关闭时拒绝且不留空 Panel。
- 单实例与 [Runtime v2](../runtime.md) 共用授权、保存、上限和关闭语义。

## 启动与恢复

- 启动恢复全部项目元数据和布局，只显示上次活跃项目；上次活跃项目不存在时回退到首个项目。
- 先恢复布局，再处理 Document 快照、授权占位和终端懒启动；不得为同一逻辑视图创建重复 Panel。
- 单个项目布局损坏按统一损坏分流处理；未知面板过滤后聚合提示，不影响其他项目。
- 恢复过程不回写由解析产生的布局，不自动聚焦，也不把旧持久状态复制成第二份。

## 验收判据

- **Given** 多项目均含面板和 PTY，**When** 切换项目，**Then** 只改变可见性，实例与进程不重建，隐藏事件不抢焦。
- **Given** 同一 Document 在两个项目有视图，**When** 关闭一个视图，**Then** 不触发内容守卫；关闭最后视图才要求保存／丢弃／取消。
- **Given** 批量保存一项失败，**When** 关闭流程结束，**Then** 全部 Panel 与 PTY 保留，已成功项干净，用户可重试或再次明确丢弃。
- **Given** 项目移除含脏 Document、Hooks 草稿和运行终端，**When** 选择保存，**Then** 全部成功并提交删除意图后才终止 PTY 和删除项目状态；任一失败不移除。
- **Given** 无项目设置浮层有 Hooks User 草稿，**When** 外部意图激活项目，**Then** 浮层和草稿保留，不自动切换宿主。
- **Given** `NewTerminal` 的显式 cwd 未授权，**When** 移交，**Then** 拒绝且不改投活跃项目、不留下空 Panel。
- **Given** 最终退出状态提交失败，**When** 用户选择不保存状态退出，**Then** 明确提示旧布局与快照可能恢复。
- **Given** 异常启动存在布局和快照，**When** 恢复，**Then** 先布局后对账，无重复 Panel 或重复 PTY。
