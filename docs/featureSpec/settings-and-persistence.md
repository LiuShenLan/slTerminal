# 设置与持久化

> 拥有应用设置单例、保存队列、持久对象、损坏分流和 Document 崩溃快照；设置页控件归设置中心，关闭状态机归工作区，加密备份归独立所有者。

## 应用设置与保存队列

- 应用级设置只有一份运行状态和一个保存队列；所有项目中的设置视图及无项目浮层订阅同一状态。关闭任一设置面板不取消全局待写值。
- 多视图修改同一字段时同步最新生效值；自动保存立即作用于运行期，停止操作 2 秒后写盘。失败保留生效值，并明确“本次运行生效、重启可能丢失”。
- Hooks 草稿不属于应用级设置单例，按“面板＋CLI＋层级”持有并手动保存；外部修改时拒绝覆盖，不自动合并。
- 后台任务提交、导入、恢复默认等显式动作立即写入，不等待去抖；失败不改变磁盘内容，并保留用户草稿。
- 恢复默认只改变已注册应用设置，不修改 Hooks、外部 CLI 文件、工作区状态或 Windows 凭据；未注册 CLI 命名空间不因恢复默认被清除。

## 持久对象

| 对象 | 保存规则 |
|---|---|
| 应用设置、快捷键、主题选择与非敏感 Agent 配置 | 单例状态；自动域 2 秒去抖，显式动作立即提交 |
| 项目列表、布局、面板顺序与激活项 | 变更合并，2 秒去抖；破坏动作前提交必要状态 |
| `ViewKey` 视图状态 | 关闭重开与重启共用一份；随所属项目生命周期管理 |
| 侧栏布局、活动栏与视图状态 | 500 毫秒去抖；隐藏侧栏不取消保存 |
| 逻辑终端编号、标题与 cwd | 300 毫秒去抖；显式关闭先提交记录删除 |
| 窗口几何 | 按机器保存，不随工作区跨机恢复 |
| Document 崩溃快照 | 按 `DocumentId` 只保留最新快照，不经布局或设置保存 |

- 一切持久化写盘采用完整内容原子替换或等效事务；不得出现半写状态。设置写只经统一设置通道，安全写事件进入审计。
- 同一进程内同一对象写入串行；跨线程结果经有界通道回到所有者，不用共享可变状态绕过队列。
- 单个设置载荷上限 1 MiB；超限拒绝写入并可见提示，不静默截断。

## 损坏与不兼容分流

| 情况 | 行为 |
|---|---|
| 确认文件缺失 | 视为首次使用；采用默认值，首次写入时创建。 |
| 权限、锁或 I/O 失败 | 保留原数据，进入只读与重试；不隔离、不当作首次使用。 |
| 当前版本结构损坏 | 隔离损坏数据，优先恢复有效备份；无有效备份才使用默认值并明确提示。 |
| 数据来自更高版本 | 只读，不降级、不隔离、不覆盖原数据。 |
| 单字段非法 | 仅该字段回退并聚合提示；保留其他字段及未注册 CLI 命名空间。 |
| 结构化状态库异常 | 先经事务日志恢复，再尝试有效备份；仍失败才隔离并以空工作区继续，且明确提示。 |
| 快照损坏 | 排除加载并提示；不直接物理删除，不阻止其他快照恢复。 |

- 有效备份损坏或与原数据版本不兼容时不得视为可恢复备份。
- 设置导出与备份只收已登记为非敏感的应用字段；未知命名空间可在本地原样保留，但不得因此被当作安全字段导出。

## 设置导入、导出与恢复默认

- 普通设置导出只包含应用设置，不含工作区、主题包、Hooks、任意 CLI 文件、凭据、历史学习数据、终端输出或崩溃快照。
- 导出采用原子写；口令不适用于普通设置导出。文件格式带版本，导入只接受支持的当前版本，未知或更高版本拒绝。
- 导入流程为选择文件、完整校验、预览影响域、确认、保留上一代有效备份、原子提交；任一预检失败零写入。
- 导入不得引入凭据字段或绕过设置校验；失败保持原设置与运行状态可恢复。
- 自定义主题导入与加密备份分别由其所有者定义，不借普通设置导出形成旁路。

## Document 崩溃快照

- 快照只保存未保存 Document 的恢复所需文本与元数据，按 `DocumentId` 每个文档只留最新一份；Editor、Markdown 与可编辑 Diff 共用同一机制，不再按 Panel 分裂。
- 单个快照文本上限 64 MiB，总配额 256 MiB。不得为写新快照静默驱逐仍打开且脏的 Document 快照；无法写入时立即警告并保留编辑现场。
- 快照不包含终端输出、AI 会话正文、剪贴板或凭据；只读快照与 GitShow 不参与。
- 保存成功、撤销回干净基线或最后视图按已提交意图关闭后，删除对应快照；删除必须发生在必要状态提交之后。
- 启动写入运行中标记，最终关闭状态提交成功后写正常退出标记。异常启动先恢复布局，再按 `DocumentId` 对账快照，不创建重复 Panel；OS 强杀不属于正常关闭保证。
- 有主快照恢复未保存文本但不自动写盘；磁盘版本冲突按 Document 规则处理。
- 无主快照不自动归入活跃项目：用户选择目标项目与落点或确认删除；无项目时保留。仅无主材料适用 7 天保留期。
- 正常退出后的遗留快照按过期清理；清理不得误删异常启动尚未对账的快照。
- “Document 崩溃恢复”开关统一控制 Editor、Markdown 与 Diff 的新快照写入；关闭不影响既有快照的显式恢复或删除。

## 关闭提交失败

- 正常关闭先提交设置、布局、终端记录与关闭意图，再执行 PTY 终止和快照删除等破坏动作。
- 最终状态提交失败时保留可恢复现场并提供重试；用户也可显式选择“退出且不保存本次窗口状态”，但必须提示旧布局和快照可能在下次启动恢复。
- 不得以 best-effort 为由静默完成一个已知状态提交失败的正常退出。

## 验收判据

- **Given** 两个项目和一个无项目浮层同时修改应用设置，**When** 关闭其中一个设置视图，**Then** 其余视图同步最新值且全局待写队列不被取消。
- **Given** 设置权限失败、当前版本结构损坏、更高版本与单字段非法，**When** 分别启动，**Then** 严格按分流表处理，不互相混用隔离、默认或只读路径。
- **Given** 状态库事务日志与备份均无法恢复，**When** 启动，**Then** 隔离后以空工作区继续并明确提示，不反复覆盖损坏数据。
- **Given** 多个脏 Document 且快照总配额不足，**When** 写新快照，**Then** 不驱逐打开脏 Document 的既有快照，并立即警告写入失败。
- **Given** 异常启动同时存在布局与快照，**When** 对账，**Then** 原布局面板恢复未保存文本，不新建重复 Panel，也不先用磁盘覆盖。
- **Given** 快照失去项目归属，**When** 没有活跃项目，**Then** 材料保留；只有用户选择目标或确认删除后才处置。
- **Given** 最终窗口状态提交失败，**When** 用户选择不保存状态退出，**Then** 已明确提示旧布局与快照可能恢复。
- **Given** 普通设置导入包含未知版本或凭据字段，**When** 预检，**Then** 拒绝且零写入。
