# 设置与持久化

> 负责设置数据模型、保存模式、持久化对象、去抖、原子写、备份、失败重试、导入导出、关闭冲刷与崩溃恢复；不负责设置中心各页面的布局与控件细节。

## 目标行为

### 设置归属与作用域

- 设置中心是项目内的普通面板，每个项目最多一个；除 Hooks 的 Project/Local 层外，设置内容为应用级共享配置，不按项目分叉。
- 左导航顶部显示“所属项目”，用于标明 Hooks 的 Project/Local 作用域；不新增项目配置组。
- Hooks 的 Project 与 Local 配置绑定所属项目根；切换项目只隐藏设置面板，不关闭、不改变未保存内容。
- 后台定时任务配置为应用级；任务页的显式提交与 Hooks 保存走同一持久化纪律，但不受自动保存去抖影响。

### 保存模型

设置按域分为三种保存模式：

| 模式 | 适用域 | 行为 |
|---|---|---|
| 自动保存 | 快捷键、外观、终端、Agent 基础配置、应用 | 控件变更立即作用于运行期；停止操作 2 秒后写入；显示保存状态；失败保留修改并提供重试。 |
| 手动保存 | Hooks | 编辑产生未保存状态；用户点击保存后写入；写入期间相关控件禁用；失败保留编辑态与脏状态。 |
| 提交即保存 | 后台定时任务提交、导入、恢复默认 | 用户点击提交/确认后立即写入；写入期间相关控件禁用；失败保留编辑态与脏状态。 |

- 自动保存型修改在本次运行中始终生效，即使写盘失败；失败提示必须明确“修改仅在本次运行中生效”。
- 手动保存与提交即保存失败不改变磁盘内容，不丢失编辑态；错误提示包含可操作的失败原因，不包含文件内容或凭据。
- 侧栏默认布局不属于应用设置：其控制面写入状态库 sidebar facet，500 毫秒去抖；导入、导出与恢复所有默认不触碰侧栏布局与视图状态。
- 保存成功后清除对应保存状态；保存失败保留失败徽标与重试入口，直到成功或用户放弃修改。
- 设置中心关闭前若有手动保存的未保存修改，进入工作区关闭守卫；自动保存修改在窗口关闭前强制冲刷。

### 持久化对象与去抖

| 持久化对象 | 去抖 | 所有者 |
|---|---|---|
| 应用设置：外观、快捷键、终端、Agent 基础配置、应用 | 2 秒 | 设置与持久化 |
| 后台任务配置 | 显式提交立即写 | 设置与持久化 |
| 项目布局：面板组结构、面板顺序、激活面板、聚焦面板组、面板参数（含 Diff 视图模式/自动换行/同步滚动/列宽/折叠侧/交换、编辑器语言覆盖） | 2 秒 | 工作区壳 |
| 侧栏布局与视图状态：宽度、比例、槽位、视图状态、Commit ignored 开关、活动栏按钮顺序/分区/显隐 | 500 毫秒 | 侧栏框架；状态库 sidebar facet，不属于应用设置 |
| 终端簿：最近工作目录、编号、自定义标题 | 最近 cwd 与编号 300 毫秒；自定义标题立即 | 终端；状态库 `project_terminals` 的 `TerminalBook` |
| 项目列表、显示名、项目顺序 | 操作完成后进入保存队列；关闭前强制冲刷 | 导航树 |
| 编辑器与 Markdown 崩溃恢复快照 | 周期快照；编辑停止后尽快更新 | 编辑器、Markdown |

- 去抖窗口内合并同一对象的连续变更，避免写放大；显式提交、导入、恢复默认、关闭冲刷不等待去抖。
- 关闭链顺序与阶段时限由 [工作区壳](workspace/shell.md) 定义；本文件负责各阶段中设置与布局冲刷的内容与失败处理。
- 侧栏隐藏时其布局变更仍持久化；项目切换不触发额外写盘，只更新活跃项目标记。
- 终端自定义标题、编号与最近 cwd 只由 `TerminalBook`/`project_terminals` 持久化；项目布局 `layout_json` 不保存这些字段，也不保存编号计数。

### 原子写、备份与损坏恢复

- 所有持久化写入必须原子化：磁盘上只出现完整旧内容或完整新内容，不得出现半写状态。
- 应用设置保留上一代完整备份；备份失败时中止写入，不得用损坏内容覆盖备份。
- 结构化工作区状态（项目、布局、终端簿、侧栏、视图状态）以单库事务提交；不要求逐事务保留上一代备份。状态库在正常关闭时生成可恢复备份；进程崩溃由事务日志恢复。
- 读取时若文件缺失、解析失败、根结构非法或版本高于当前支持版本，按损坏/不兼容处理：不覆盖原文件，进入只读、隔离或默认恢复路径，并给出可见提示。
- 设置文件载荷超过 1 MiB 时，加载进入只读模式；写入被拒绝并提示。该上限是契约数值，不随窗口或项目变化。
- 应用强制单实例，不处理多实例并发写；同一进程内的写入串行执行，避免同一对象的写入互相覆盖。

### 导入、导出与恢复默认

- 导出只包含应用设置，不包含 Hooks、CLI 配置文件、凭据、终端输出、剪贴板内容或崩溃快照。
- 导出文件包含 `schema_version`（当前为 1）；导入只接受当前版本，缺失、未知或更高版本拒绝并提示。导入前必须校验格式与版本，预览将要修改的域；校验失败不写盘。
- 导入前自动保留上一代备份；导入以原子写提交；导入失败保持原设置不变。
- 恢复默认支持“恢复本页默认”和“恢复全部默认”；两者均需二次确认；恢复默认只作用于应用设置域，不触碰 Hooks 与 CLI 配置文件。
- Hooks 页没有“恢复本页默认”，因为 Hooks 属于 CLI 配置文件，不属于应用设置域。

### 关闭冲刷与崩溃恢复

- 正常关闭窗口前，先冲刷设置 JSON 与状态库全部 dirty facet；冲刷失败必须可见，并按工作区关闭守卫处理。项目移除确认后丢弃未保存修改、只提交项目相关状态库事务；批量关闭只冲刷被关闭面板的待写自动保存；两者都不触发全局设置与布局冲刷。
- 关闭守卫的受守卫集合为设置 JSON 与状态库全部 dirty facet，任一失败中止关闭；最终终端簿/布局事务为 best-effort，失败只记录并继续。
- 崩溃恢复只保存编辑器与 Markdown 的未保存文本缓冲；不保存终端输出、回滚、选区、剪贴板、凭据或 CLI 会话内容。
- 启动时若发现崩溃恢复快照，提示恢复或丢弃；恢复只重建文本缓冲，不自动写回原文件。
- 正常关闭与重启不保留编辑器/Markdown 草稿；崩溃快照不是自动保存，不改变显式保存语义。
- 恢复存储统一配额：单文件文本上限 64 MiB，总配额 256 MiB，保留 7 天；快照键为 `(ProjectId, PanelId)`；项目移除删除其快照；损坏快照隔离并排除提示。编辑器与 Markdown 共用同一恢复存储与聚合恢复提示。

### 数据形态边界

- 不提供布局、设置或会话数据的迁移通道；无法识别的记录按损坏或未知数据处理，不阻止启动。
- 新安装与版本升级从目标态数据形态开始；不提供兼容过渡层。
- 目标态使用独立的新状态根（详细文件名由详细设计定义）；旧 `settings.json`、`session.json` 及其备份不读、不删、不视为损坏。
- 应用设置存放在用户漫游数据目录；项目布局、项目数据、崩溃恢复快照、隔离区、终端补全数据、更新状态、日志、审计与崩溃现场存放在机器本地数据目录，并提供应用页一键清理入口。窗口几何为迁移后能力，迁移完成后同样落本地根；规格内关闭链不冲刷几何。
- 项目根路径是机器相关事实，工作区状态不随漫游配置跨机复制；跨机只共享应用设置。
- 项目身份持久化使用稳定 `ProjectId`；根路径是位置，不是身份。持久化键与恢复对账均以 `ProjectId` 为准。
- 业务写入与应用托管写入的根范围、例外与审计归 [cross-cutting.md](cross-cutting.md)；本文件只记录持久化对象，不另立写入根规则。

## 交互规则

### 保存状态与失败重试

- 自动保存期间行内显示“保存中”；成功后显示“已保存”；失败显示“保存失败”徽标与重试入口，并提示“设置保存失败，修改仅在本次运行中生效”。
- 手动保存与提交即保存期间保存按钮显示“保存中…”并禁用；成功后清除脏状态；失败保留编辑态、脏状态与错误提示。
- 重试只重试失败对象；不重复写入已成功的对象。
- 关闭冲刷失败时，关闭流程中止并提示失败对象；用户可重试或取消关闭。

### 导入导出交互

- 导入流程：选择文件 → 校验 → 预览受影响域 → 确认 → 备份 → 原子写 → 结果提示。
- 校验失败、版本不兼容或预览取消时，不修改任何设置。
- 导出流程：选择目标路径 → 写入完整应用设置 → 结果提示；导出失败不留下半写文件。

### 关闭与冲刷

- 单面板关闭：脏面板提供“保存并关闭 / 丢弃并关闭 / 取消”。
- 窗口关闭与批量关闭：确认框列出脏面板，提供“保存全部并关闭 / 放弃全部并关闭 / 取消”；逐个保存，任一失败中止关闭、保留全部面板并列出失败项。项目移除按工作区确认后丢弃未保存修改，只提交项目相关状态库事务，不进入保存链，也不触发全局设置/布局冲刷。
- 单面板关闭时，先尝试完成该面板产生的待写自动保存；只有窗口关闭才冲刷全部自动保存设置与布局。手动保存的未保存修改按脏面板处理。

## 边界与错误

- 设置文件缺失：按默认值启动，首次写入时创建；不阻止启动。
- 设置文件损坏：不覆盖原文件；进入只读或默认恢复；提示用户备份/恢复。
- 设置文件版本过高：进入只读模式，提示当前版本无法写入；不降级覆盖。
- 备份失败：中止写入；原文件与旧备份保持不变。
- 磁盘满、权限不足、路径被占用：保存失败可见；保留内存修改与重试入口；不丢失编辑态。
- 导入文件格式错误、版本不兼容、载荷过大：拒绝导入；不修改设置。
- Hooks 文件被外部修改：中止保存并提示重新加载；不自动合并、不自动保存。
- 崩溃快照损坏：丢弃并提示；不阻止启动，不覆盖原文件。
- 应用退出时冲刷超时：按关闭链时限处理；已成功写入的对象不回滚，未写入对象在下次启动时按默认值或缺省处理，并给出可见提示。

## 验收判据

- **Given** 修改外观设置并停止操作 2 秒，**When** 去抖窗口结束，**Then** 设置写入完成并显示“已保存”。
- **Given** 设置写入失败，**When** 用户继续操作，**Then** 修改仍在本次运行中生效，界面显示失败徽标与重试入口。
- **Given** 关闭窗口时存在多个脏面板，**When** 选择“保存全部并关闭”且其中一个保存失败，**Then** 关闭中止，所有面板保留，失败面板被列出。
- **Given** 导入一个格式错误的设置文件，**When** 校验失败，**Then** 不写盘、不改变任何设置。
- **Given** 导入合法设置文件，**When** 确认导入，**Then** 先备份、再原子写，失败时原设置保持不变。
- **Given** 设置文件损坏，**When** 启动应用，**Then** 不覆盖损坏文件，进入只读或默认恢复并提示。
- **Given** 崩溃恢复快照存在，**When** 启动应用，**Then** 提示恢复或丢弃，恢复不自动写回原文件。
- **Given** 项目布局与 Diff 参数变更，**When** 等待 2 秒或关闭窗口，**Then** 参数随布局持久化；关闭重开恢复默认，应用重启保留。
- **Given** 终端 cwd、编号或自定义标题变化，**When** 等待对应去抖或立即写入，**Then** 由 `TerminalBook`/`project_terminals` 持久化；项目布局不保存这些字段，重启后编号不重算、cwd 失效回退项目根并提示。
- **Given** 侧栏布局或视图状态变化，**When** 等待 500 毫秒，**Then** 状态库 sidebar facet 持久化；隐藏侧栏不阻止保存；导入、导出与恢复默认不触碰该 facet。
- **Given** Hooks 文件被外部修改，**When** 用户尝试保存，**Then** 保存中止并提示重新加载，不自动合并。

## 关键决策与依据

- **按域三模式**：自动保存 2 秒去抖，Hooks 手动保存，后台任务提交即保存。原因：外观/终端/应用等即时预览需要低摩擦，Hooks 与任务提交涉及外部文件或不可逆动作，需要明确确认。边界：自动保存失败仍在本次运行中生效；手动保存与提交即保存失败不写盘。
- **原子写与备份分层**：应用设置保留上一代备份且备份失败即中止；结构化工作区状态以单库事务保证原子性，正常关闭时生成可恢复备份。原因：设置是单文件启动依赖，需要旧代回退；工作区状态是关系数据，逐事务复制整库不现实。边界：不提供多代备份历史；状态库损坏时隔离整库并提示，用户可用加密备份或文件系统自行备份。
- **关闭前冲刷**：窗口关闭时设置与布局先于 PTY 终止写入；项目移除确认后丢弃未保存修改、只提交项目相关状态库事务，批量关闭只冲刷被关闭面板的待写自动保存。原因：终端终止可能带走尚未落盘的 cwd/编号/字号；先冲刷可避免关闭期间丢失，但项目移除与批量关闭不应扩大为全局写盘。边界：各阶段限时，超时按关闭链处理。
- **崩溃快照只收文本**：只保存编辑器与 Markdown 未保存文本，不保存终端输出、剪贴板或凭据。原因：终端输出与剪贴板可能含敏感信息，恢复旧输出也会与新会话混淆。边界：快照不是自动保存，正常关闭不保留。
- **导入导出只限应用设置**：Hooks 与 CLI 文件由各自页面和 CLI 管理。原因：跨文件写入需要不同的校验与权限边界，混入导入会扩大破坏面。边界：Hooks 页不提供恢复默认，导入不触碰 Hooks。
- **不提供数据迁移**：目标态数据形态直接定义终态。原因：允许 breaking change，无法识别的格式不构成兼容义务。边界：无法识别的记录按损坏或未知数据处理，不阻止启动。
