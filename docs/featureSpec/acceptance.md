# 验收与豁免

> 负责验收原则、跨域验收、明确不做、平台与第三方边界、不可自动化面；各功能篇的本域验收判据不在此重复。

## 验收原则

- 验收判据必须可观察、可判定、可复现；优先自动化，无法自动化的面必须登记根因与兜底层级。
- 每条功能需求至少有一个验收判据；跨篇契约由所有者篇给出判据，其他篇只验证集成行为。
- 验收以用户可见行为为准，不以内部实现、文件结构或日志文本为准。
- 契约数值（超时、容量、阈值、尺寸）变更时，验收判据同步更新。
- 未登记豁免的不可自动化面视为未完成；豁免只保留给操作系统、第三方程序、真实输入法、视觉观感等不可消除边界。

## 跨域验收

| 场景 | 验收要点 |
|---|---|
| 工作区模型 | 项目 → 项目布局 → 面板组 → 面板层级正确；每项目一个项目布局；多项目同时存活；空面板组自动移除；跨项目移动被拒绝。 |
| 项目生命周期 | 新建项目自动成为活跃项目；显示名可重命名且允许重名，根路径消歧；项目顺序可拖拽并持久化；移除项目列出终端与脏面板。 |
| 项目身份 | 稳定 `ProjectId`；根路径词法唯一并做真实路径查重；根重定位保留 `ProjectId`、布局与面板实例。 |
| 应用页与无项目浮层 | 有项目时设置中心全局组含应用页；无项目时配置钮/`Ctrl+,` 打开仅含应用页的浮层；通知与诊断可用，范围外节显示只读占位或禁用态；浮层含导入/导出/恢复所有默认，项目激活后自动关闭；诊断一键清理需二次确认。 |
| 崩溃恢复 | 快照键 `(ProjectId, PanelId)`；单文件 64 MiB、总配额 256 MiB、保留 7 天；聚合恢复提示；项目移除清理。 |
| Commit 与 Explorer 范围 | Commit 覆盖仓库实际根，Explorer 只覆盖项目根；根外条目只读、不可定位/回滚/删除/在终端打开。 |
| 文件打开路由 | `.md/.markdown` 进 Markdown；`.html/.htm` 进编辑器源码并可交系统程序打开；其他文本进编辑器；二进制/不支持走错误；每项目每路径单一视图。 |
| Git 仓库根 | Commit、Diff、GitShow、文件浏览器使用项目根所在仓库实际根；项目根为仓库子目录时行为正确；非仓库进入错误态，不自动初始化。 |
| 焦点 | 布局恢复不抢焦；显式打开/激活聚焦；`Ctrl+Tab`/`Ctrl+Shift+Tab` 循环；切项目恢复上次聚焦面板；启动不抢焦。 |
| 脏状态与关闭 | 单面板“保存并关闭”；批量“保存全部并关闭”任一失败中止并保留全部面板；关闭链各阶段不超过 3 秒。 |
| 持久化 | 设置 2 秒、项目布局 2 秒、侧栏 500 毫秒、终端 cwd/编号 300 毫秒；关闭前冲刷；写盘失败可见且保留修改。 |
| 快捷键 | 快捷键矩阵中的命令在对应上下文生效；冲突在设置中心可见；侧栏视图快捷键优先于终端输入；可重绑命令生效。 |
| 通知 | 悬停暂停、关闭按钮、同类去重；终端任务通知仅在窗口失焦时发送。 |
| 单实例 | 第二次启动激活并前置已有窗口，不创建第二窗口；可携带仅聚焦/打开项目/打开文件/新建终端意图；目标不存在时提示，不自动创建项目。 |
| 键盘与输入 | 核心流程键盘可达；焦点环可见；IME/CJK 不被打断；减少动效生效。 |
| 安全边界 | 凭据不入盘/日志/快照；危险协议、脚本、根外写入与自动打开、后台 OSC 52 写入被拒绝；Markdown 显式链接、Commit/Diff 的根外只读打开为受控例外；删除进回收站。 |

## 明确不做

以下能力不进入目标态。理由是实现边界或产品边界，不是待办；不得在实现中偷偷加入。

### 终端

| 项 | 边界与原因 |
|---|---|
| 终端搜索 | 不提供搜索框、正则/整词搜索与结果跳转；终端选区与 AI CLI 全屏 TUI 的输入/鼠标语义冲突，复制通过选区完成。 |
| 滚动条、滚动锁定 | 不提供可见滚动条或暂停跟随；终端交互面保持最小，回滚通过鼠标滚轮与 `Shift+滚轮` 完成。 |
| 内容右键菜单、扩展选区、全选、`Ctrl+End` | 不提供终端内容菜单、双击/三击/Shift 扩展选区、`Ctrl+Shift+A` 全选与 `Ctrl+End`；避免与 TUI 鼠标跟踪和终端输入冲突。 |
| 字号快捷键、光标样式 | 不提供 `Ctrl+=`/`Ctrl+-` 等字号快捷键与块状/下划线光标；字号经 `Ctrl+滚轮` 与设置中心调整，光标固定竖线并仅允许闪烁开关。 |
| 原地重启 | 不提供“重新启动会话”；会终止运行中的 AI CLI 上下文，关闭重开已覆盖。 |
| 终端配色方案 | 不提供独立终端调色板；配色由主题 ANSI 调色板单点拥有，保证配色与界面一致性。 |
| 文件拖入、命令块 | 不提供拖文件插入路径、按命令块跳转或复制命令输出；与面板拖拽、TUI 交互和终端网格模型冲突。 |
| 输出导出、自动重连 | 不提供会话录制、输出导出、崩溃后输出恢复或自动拉起新 Shell；敏感输出落盘风险高，自动重连会掩盖失败并丢失上下文。 |
| 终端内分屏、输入模式页 | 一个终端面板仅一个 PTY；并排终端通过面板组实现；鼠标与滚轮按前台程序状态自动路由，不提供手动输入模式开关。 |

### Markdown

| 项 | 边界与原因 |
|---|---|
| 代码块复制/语言标签、公式源码复制、图片放大/复制路径 | 代码块、公式、图片本身可渲染；不提供这些内容操作，保持渲染态只读与极简。 |
| 渲染态右键菜单 | 不提供自定义内容菜单、标题快速跳转或链接列表导航。 |
| WYSIWYG、三态分栏 | 只保留源码/渲染两态；渲染态只读，编辑统一进源码态，不恢复同屏混合布局。 |
| Mermaid 渲染 | 首版不渲染，按源码显示；保留渲染接口与扩展点。 |
| HTML 渲染、PDF/图片/Office 预览 | HTML 只进编辑器源码并由系统程序打开；面板类型封闭，不新增预览类型。 |
| 远程资源自动加载、Mermaid 渲染 | 远程图片默认不加载；Mermaid 首版按源码显示，不渲染、不响应图内点击、跳转、脚本或外部资源。 |

### 文件树与 Commit

| 项 | 边界与原因 |
|---|---|
| Type-ahead、树内拖拽移动、框选 | 不提供首字母跳转、树内拖拽移动/复制、框选或拖入终端；拖入编辑器由编辑器拖文件打开承接；移动由树内剪贴板覆盖。 |
| 长操作进度条、监听失效轮询兜底 | 批量删除/复制/粘贴完成后一次性反馈；文件监听不可用时显示警告并提示手动刷新，不自动轮询。 |
| 文件内容搜索、多根/根外浏览、地址栏 | 文件树只提供名称过滤；根固定为活跃项目根；不提供内容搜索、多根、根外浏览或地址栏。 |
| `Shift+Delete`、应用内删除撤销 | 删除统一进系统回收站；回收站不可用时回退永久删除并说明；不提供永久删除快捷键或应用内撤销。 |
| Commit 批量操作 | 只提供单行聚焦与单行操作；破坏性批量回滚/删除缺少配套撤销机制。 |
| Commit 完整 Git 工作流 | 不提供暂存/取消暂存入口、提交、推送/拉取、分支、合并、冲突解决、历史、stash、子模块内部状态或网络 Git 操作；写工作流由终端承担。唯一例外：删除 added 文件时先取消暂存以保持索引一致，确认框明确披露该索引变更。 |

### Agent 全局文件

| 项 | 边界与原因 |
|---|---|
| 根层空白区新建/粘贴 | 新建与粘贴入口只在文件夹行菜单；统一树不设根级空白菜单，避免与节点行冲突。 |
| 节点排序、独立滚动、深层过滤 | 内置按注册顺序、自定义按添加顺序；所有 Agent 共用统一树与单一滚动区；过滤只作用于根层完整名称，避免嵌套滚动与“文件丢失”误解。 |
| Agent 安装/启动/状态/配置/Hooks 管理 | 本视图只做文件浏览；节点与运行时清单管理在设置中心，Agent 生命周期由终端与 Hook 体系负责。 |
| 跨 Agent 搜索、对比、合并、拖拽 | Agent 根是独立写入边界；不提供跨根操作。 |

### 工作区、编辑器与设置

| 项 | 边界与原因 |
|---|---|
| 额外层级 | 不设项目与面板之间的额外层级；职责并入项目。 |
| 跨项目移动面板、浮动面板、应用外窗口 | 面板作用域、终端 cwd 与文件路径按项目隔离；工作区只支持网格布局与单窗口。 |
| 项目级页签栏、全局欢迎页、应用级状态栏、原生菜单栏 | 入口由导航树、活动栏、标题栏与面板承载；保持自绘暗色界面。 |
| 多窗口、多实例、浅色/跟随系统 | 产品定位为 Windows 单窗口单实例、仅暗色；不做多窗口协同、浅色主题或跟随系统。 |
| 既有数据/既有布局的迁移 | 目标态数据形态直接定义终态；无法识别的记录按损坏或未知数据处理，不提供兼容迁移。 |
| 编辑器小地图、编辑器分栏、Commit 来源后缀视图 | 不提供小地图与编辑器内分栏；每项目每路径单一编辑器视图，Commit 来源不产生后缀视图。 |
| 设置独立窗口/模态、运行期配置页管理、文件拖入导入 | 设置中心是项目内普通面板；配置页注册表启动时固定；导入需显式选择、校验与预览，拖入不作为导入。 |
| Hooks 导入导出、自动合并、多代备份 | 导入导出只限应用设置；Hooks 外部修改中止保存并提示重新加载；只保留上一代备份。 |
| 用户自定义主题、浅色主题、自定义 Shell 参数注入 | 仅内置暗色主题；不做对比度准入校验，明显不可读时提示用户调整；自定义 Shell 只接受可执行文件路径，避免命令注入。 |
| 外部文件拖入 | 不支持；仅文件浏览器内部拖到编辑器面板组。 |
| 无障碍专用能力 | 不提供屏幕阅读器/ARIA/读屏播报/WCAG 校验/高对比度/大字体适配；保留键盘、焦点、IME/CJK、减少动效。 |
| Image/Merge 面板 | 不进入目标面板封闭集；图片/二进制走系统默认程序；Git 冲突处理由终端承担。 |

### 范围外

- Runtime API、更新链、托盘、开机启动、AI Providers/助手、加密备份、补全、终端增强（vi/补全/数学/AI 修复条）、界面语言等属于迁移能力；featureSpec 只定义应用页位置、节序、保存纪律与安全红线，不承诺其行为验收。
- 终端录制、云同步、遥测、远程协作、移动端与跨平台不在本规格范围。

## 平台与第三方边界

| 边界 | 行为与兜底 |
|---|---|
| `cmd` 无完整 Shell 集成 | 无命令边界、自动标题、四态与目录跟踪；历史恢复使用固定等待。根因是第三方 Shell 能力，不伪造。 |
| Windows 10 早期版本控制台能力不足 | 回退系统控制台并一次性提示；基本输入输出保留，滚轮转发等增强不可用。根因是操作系统版本。 |
| 文件锁、权限不足、路径被占用 | 保存/删除/重命名失败可见，保留重试或系统程序打开路径；不静默覆盖。 |
| 路径大小写不敏感、符号链接 | 按真实路径校验；根外与路径穿越被拒绝；不假设大小写敏感。 |
| 系统默认浏览器/邮件程序/文件管理器/回收站 | 由操作系统决定；启动失败时提示，不静默无响应；回收站不可用时回退永久删除并说明。 |
| Git 可用性与仓库状态 | 非仓库进入错误态并提示手动初始化；不自动 `git init`；不执行网络 Git 操作；不修改 Git 配置。 |
| CLI 未声明配置编辑器能力 | Hooks 页显示“该 CLI 未提供配置编辑器”，不提供编辑入口。 |
| GPU/渲染能力 | 渲染不可用时静默降级软件渲染，功能不变；不向用户暴露渲染器；性能持续不达标时一次性提示。 |

## 不可自动化面

以下面无法用自动化测试完整覆盖；实现阶段必须在测试豁免登记表中登记根因与兜底层级，未登记视为未完成。

| 面 | 根因 | 兜底层级 |
|---|---|---|
| 终端中文输入法 | 依赖真实系统输入法与组合态，合成输入无法覆盖候选窗、确认与回车语义。 | 键盘隔离与输入路由自动化测试 + 实机输入法人工核验。 |
| Markdown 视觉渲染质量 | 公式、代码高亮与排版的观感依赖真实渲染与字体。 | 结构/文本/安全断言自动化 + 人工视觉核验。 |
| Diff 行对与滚动同步的视觉观感 | 几何对齐可断言，最终视觉舒适度需人眼判断。 | 几何与滚动位置断言 + 人工视觉核验。 |
| 活动栏/项目拖拽手感 | 拖拽状态机可断言，插入指示与手感需人工判断。 | 状态迁移与持久化自动化 + 人工拖拽核验。 |
| 系统默认程序与回收站集成 | 依赖操作系统外壳与用户环境。 | 边界适配层单测/模拟 + 实机冒烟。 |
| GPU/字体渲染差异 | 依赖显卡、驱动与字体环境。 | 结构与布局断言 + 多环境人工抽检。 |

## 验收判据

- **Given** 任一功能篇的验收判据，**When** 执行验收，**Then** 判据可观察、可判定，且不依赖内部实现细节。
- **Given** 明确不做清单中的能力，**When** 检查实现与文档，**Then** 不存在入口、快捷键或隐藏配置；文档在 `acceptance.md` 有边界与原因。
- **Given** 平台/第三方边界场景，**When** 触发降级，**Then** 行为符合表内兜底，错误可见且不伪造能力。
- **Given** 不可自动化面，**When** 交付验收，**Then** 已在测试豁免登记表登记根因与兜底层级，并有对应人工核验记录。
- **Given** 跨域场景，**When** 执行本文件“跨域验收”表，**Then** 各场景通过，且与所有者篇判据一致。
- **Given** 新增或修改功能，**When** 更新规格，**Then** 同步更新功能篇验收、跨域验收与本文件明确不做清单，不留下未登记豁免。

## 关键决策与依据

- **明确不做也是需求**：把不恢复项写成带原因的边界，防止实现阶段反复试探或偷偷加入。原因：目标态边界必须可追溯，明确边界比未定项更稳定。边界：产品定位、明确产品要求与范围外能力不在功能能力范围内。
- **豁免必须带兜底**：不可自动化面不能以“无法测试”结束，必须有自动化兜底与人工核验。原因：未登记豁免会成为质量黑洞。边界：豁免只保留给真实输入法、视觉观感、操作系统/第三方集成等不可消除面。
- **验收以用户行为为准**：不以内部文件、日志文本或实现结构作为通过条件。原因：实现可替换，用户可见契约才是需求。边界：安全与持久化可用外部可观察副作用验证。
- **跨域场景单表**：工作区、路由、Git 根、焦点、关闭、持久化、快捷键等跨篇契约在一张表内验收。原因：单篇验收容易漏掉集成缺口。边界：具体行为细节仍由所有者篇判据覆盖。
