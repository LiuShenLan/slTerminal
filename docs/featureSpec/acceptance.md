# 验收与豁免

> 拥有验收规则、跨域集成场景、最终排除项和平台边界；各功能的详细判据由所有者文档给出，不在此复制。

## 验收规则

- 判据必须可观察、可判定、可复现，优先验证用户行为与外部副作用，不依赖内部模块、表结构或日志文案。
- 修改功能时同步所有者需求与判据；跨域场景只验证集成，不形成第二份契约或数值表。
- 改动的可自动化部分必须覆盖正常、边界、失败、并发与恢复路径；不可自动化部分须在 [测试豁免登记](../../.claude/docs/testing/exemptions.md) 记录根因和兜底，未登记视为未完成。
- 容量、超时、去抖和资源上限属于契约数值；性能数值必须同时给出硬件、系统、数据规模、测量方法和统计口径，否则不得作为验收承诺。
- 结构验收应证明隐藏任务停止、旧代结果失效、实例与句柄有所有权、持久状态单一来源；不得以“看起来流畅”替代。
- 所有测试与文档只使用假凭据；验收敏感边界时检查实际产物，不把“未记录正文”仅建立在代码审查上。

## 跨域验收

| 场景 | 必须观察到的集成结果 |
|---|---|
| Document 全局身份 | 同一文件经不同项目或别名打开时按文件身份复用 Document；实时文本、脏状态、撤销和冲突只有一份。 |
| 跨项目视图 | 两个项目的 Panel 可引用同一 Document；项目、视图类型和阅读状态仍按各自 `ViewKey` 独立恢复。 |
| 视图身份 | 关闭销毁 Panel 或侧栏实例后，重开可按 `ViewKey` 恢复持久状态；关闭重开与重启口径一致，瞬态均清除。 |
| 侧栏显隐 | 同槽替换销毁旧实例；隐藏整个侧栏保留实例；隐藏按钮只移除入口，三者不得混用。 |
| PathPolicy 能力并集 | 只读根不授予写入，也不抹除另一有效根的写能力；写入、终端 cwd 和资源读取分别判定。 |
| 链接与文件身份 | 支持稳定身份时合并硬链接别名；链接重定向后保存、删除或粘贴重新校验，不继承旧授权。 |
| 会话级授权恢复 | 正常重启时，无持久读授权的 Panel 显示重新授权占位且不读取磁盘；异常启动的有主快照仍恢复未保存文本，但不恢复磁盘授权。 |
| 根重定位 | `ProjectId`、布局、Panel 和 Document 不重建；既有 PTY cwd 不变，Diff 与 GitShow 不改绑新仓库。 |
| 最后引用关闭 | 关闭非最后 Document 视图只销毁 Panel；最后视图才进入保存／丢弃／取消守卫。 |
| 批量关闭 | 按 Document 去重；任一保存失败取消本次关闭并保留全部 Panel，成功项保持干净，集合外引用不受影响。 |
| 项目移除与退出 | 必要设置、布局和关闭意图先提交，再终止 PTY、删除恢复材料；最终提交失败可重试或显式承担旧状态恢复后果。 |
| 崩溃恢复 | 快照按 `DocumentId` 对账，先恢复布局再恢复文本，不新建重复 Panel；无主材料由用户选择落点或删除。 |
| 快照配额 | 配额不足时不静默驱逐打开脏 Document 的快照；写入失败立即警告，编辑现场保留。 |
| 终端恢复 | 所有未关闭逻辑记录恢复；符合条件的可见终端启动、隐藏懒启动、已退出不自动运行新 Shell。 |
| PTY 上限 | 只按存活进程计数；达到上限的恢复或懒启动保留 Panel 与重试，显式新建失败不留空 Panel。 |
| 新建 cwd | 未提供 cwd 使用目标项目根；显式非法或未授权 cwd 拒绝，不回退活跃项目或另一目录。 |
| 单实例与 Runtime | 两者复用项目、授权、上限和关闭语义；不隐式创建项目，不形成第二执行通道。 |
| Runtime 非交互关闭 | 脏关闭未提供策略时返回结构化冲突且不弹模态框；结果不明时可查询操作状态，不要求盲目重放。 |
| Runtime 凭据 | token 只在凭据域与受支持发现链路中流动；普通端点状态、设置、备份、快照、日志和诊断不含明文。 |
| 补全可信边界 | 备用屏、TUI 或不可信行镜像不补全、不采集；接受候选只改输入，旧代结果不回填，不为候选访问网络。 |
| 本地学习数据 | 命令与目录历史可独立停用、清空；清空取消待写且不影响 Shell 自身历史，数据不进入备份或诊断。 |
| 终端搜索 | 只读当前回滚与画面，上一处／下一处和计数可用，搜索字节不进入 PTY，搜索状态不持久化。 |
| Commit 回滚 | 仅放弃未暂存变化并从索引恢复工作区；staged 内容保留，纯 staged、staged rename 和冲突不执行通用回滚。 |
| Git 与 Document | 回滚前处理打开的脏 Document；Diff 使用共享工作区文本，GitShow 固定创建时版本。 |
| 历史删除撤销 | 每批隔离记录有独立持久期限；重启和后续删除不提前永久化，撤销不得覆盖外部变化，失败材料可重试或导出。 |
| 套餐凭据 | 未配置专用 token 时不读取 CLI 配置或环境变量；token 不回显、不入备份，手动刷新复用查询链并报告验证结果。 |
| 套餐调度 | 导航隐藏仍按当前周期查询，退出后停止；失败保留旧值，按调度和响应状态标记过期并显示最后成功时间。 |
| 自定义主题 | 完整暗色语义 token 与 ANSI 映射校验通过才导入；非法主题零写入，删除使用中主题前必须另选。 |
| Markdown 与 Mermaid | 源码与渲染共享 Document；Mermaid 最终静态显示，失败显示源码和错误，无脚本、外部资源或图内交互。 |
| 设置单例 | 项目内 Settings 与无项目浮层共享应用设置；浮层提供全部应用级页面，激活项目不自动关闭。 |
| 加密备份 | 只含两个获准类别；预检失败零写入，恢复有点和回滚，凭据及永久排除项不入包，跨机工作区先重定位。 |
| 更新 | 资产精确匹配并校验完整哈希；下载不等于安装，安装先确认并完成统一关闭，不绕过脏状态与 PTY 守卫。 |
| 通知与任务栏 | 系统通知总开关不关闭应用内反馈；任务栏按错误、等待、工作、清除排序，不伪造百分比。 |
| 语言 | System 无法匹配和缺译时使用 English，不显示内部键名；切换不重建工作区或丢失修改。 |
| 诊断与清理 | 白名单预览和脱敏生效；活跃快照、恢复点、历史隔离区、凭据和进行中任务文件不进入普通清理。 |

## 最终排除项

以下均是产品边界，不是待办或迁移占位。

### 终端与补全

- 不提供正则、整词、跨终端搜索，命令块导航、终端输出导出、会话录制或输出持久化。
- 不提供终端内分屏、浮动终端、多 PTY 共用一面板；并排终端只通过 PanelGroup。
- 不提供 vi／输入模式页、数学覆盖层、AI 修复条、独立终端配色或光标形状设置。
- 不提供终端内容右键菜单、文件拖入、滚动锁定或自动拉起已退出 Shell；退出后的手动重新连接不属于自动重连。
- 不通过 WSL 获取候选，不执行项目脚本来补全，不为补全访问网络，也不接受候选后自动执行命令。
- 不伪造 cmd 或未知 Shell 的复杂语法、命令边界和 CLI 状态。

### 文档与 Git

- 不提供 WYSIWYG、同一 Markdown Panel 的同屏分栏、完整 HTML 应用容器或渲染态自定义内容菜单。
- Mermaid 不提供图内点击、跳转、脚本或外部资源；静态渲染本身是最终能力，不在排除项。
- 不提供 Image、Merge、PDF、Office 面板；图片和二进制按各所有者规则使用系统默认程序。
- 不提供编辑器内分栏、小地图、跨项目内容搜索或文件树地址栏；项目文件树不扩展为任意多根浏览，AgentRoot 的声明根集合按其专属规则工作。
- Commit 不提供暂存、提交、推拉、分支、合并、stash、历史浏览、子模块内部操作或网络 Git 工作流；staged added 删除前的取消暂存是唯一披露的例外。
- 不提供纯 staged、staged rename 或冲突状态的通用回滚，也不提供 Commit 批量破坏操作。
- 文件树删除不提供应用内撤销；系统回收站是恢复边界。历史会话隔离区撤销属于另一独立能力。

### 工作区与设置

- 不提供多窗口、多实例、多项目面板拖拽、浮动面板、第二侧栏或侧栏换边。
- 不提供浅色主题、跟随系统主题、对比度校验／提示／自动回退或自定义 Provider。
- 不提供 AI Providers、模型管理、AI 助手、自定义套餐来源或连接测试。
- 不读取 CLI 配置或环境变量中的认证材料替代 Runtime token 或套餐专用 token。
- 不提供自定义 Shell 参数注入；只接受可执行文件路径。
- 不恢复 Runtime v1、旧资源模型、旧发现格式、兼容层或既有数据迁移通道。
- 不把普通设置导出、崩溃快照或诊断包当作加密备份的旁路。
- 不提供专用无障碍能力，包括读屏播报、ARIA／WCAG 适配、高对比度或专用大字体模式；普通键盘、焦点、IME／CJK 和减少动效仍属于需求。

### 产品边界

- 不提供云同步、遥测、远程协作、移动端、macOS／Linux 版本或远程 Runtime 监听。
- 不在应用退出后保留套餐轮询、文件监听或其他系统后台服务；登录自启只按系统集成规则工作。
- 不承诺识别用户文件、命令、终端输出、AI 会话或剪贴板中的所有秘密。

## 平台与第三方边界

| 边界 | 产品行为 |
|---|---|
| Windows 与 ConPTY 能力 | 按实际系统能力建立终端；能力缺失时明确降级或报错，不伪造命令边界、Shell 集成或 PTY 存活。 |
| Shell 与 CLI 能力 | cmd、未知 Shell 和未注册 CLI 只提供其声明能力；不支持恢复、分支或 Hooks 时禁用或提示，不猜测。 |
| 文件锁、权限和路径 | 失败分类可见并保留现场；不绕过锁、不静默覆盖、不把权限错误当成文件缺失。 |
| 链接、UNC 与文件身份 | 使用 Windows 路径语义和真实目标校验；无法确定身份或授权时拒绝相应操作，不宣称识别所有别名。 |
| 系统默认程序与回收站 | 浏览器、邮件、文件管理器和回收站由 OS 提供；启动失败可见，永久删除回退必须再次明确确认。 |
| Git | 非仓库、Git 缺失、索引锁和仓库损坏分别处理；应用 Git 集成不自动初始化、修改配置或访问网络。 |
| 凭据管理器 | Windows 凭据管理器不可用时相关功能显示失败，不把 token 降级写入普通设置或文件。 |
| 更新与安装 | 操作系统安装器、架构和签名／哈希能力决定可安装性；失败保留可用旧版本并提供重试。 |
| GPU、字体与 DPI | GPU 不可用时允许软件渲染且功能不变；字体和 DPI 差异不得改变数据、授权或关闭语义。 |
| 真实输入法与视觉质量 | 真实 IME、拖拽手感、字体和渲染观感需要实机人工核验；自动化覆盖输入路由、结构、几何与安全断言。 |

## 总验收判据

- **Given** 任一所有者判据，**When** 执行验收，**Then** 结果可观察、可复现，且没有依赖实现内部状态代替用户契约。
- **Given** 最终排除项，**When** 检查产品入口、命令、设置和文档，**Then** 不存在隐藏实现或迁移占位；Mermaid 静态渲染、终端搜索和自定义暗色主题不得被误列为排除项。
- **Given** 跨域场景，**When** 执行集成验收，**Then** 结果与所有者契约一致，尤其不出现第二缓冲、第二授权通道或第二关闭通道。
- **Given** 平台或第三方能力缺失，**When** 触发边界，**Then** 按表降级或失败，不伪造成功、不静默扩大权限。
- **Given** 不可自动化面，**When** 交付，**Then** 豁免登记、自动化兜底和人工核验记录齐全。
