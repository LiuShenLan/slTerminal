# 加密备份与恢复

> 拥有加密备份类别、导出、整包恢复、恢复点和指纹撤回；普通设置导入导出与崩溃快照不属于本文。

## 备份类别

导出时用户可选择以下类别，至少选择一类：

| 类别 | 包含 |
|---|---|
| 应用设置与主题 | 应用设置、快捷键、Agent 非敏感配置、更新／通知／语言／补全配置、自定义暗色主题 |
| 工作区与界面状态 | 项目元数据、布局、统一 `ViewKey` 状态、侧栏、终端编号／标题／cwd、窗口几何；不含终端输出 |

以下内容永不入包：任何凭据及其明文表示、任意 CLI 配置与 Hooks、终端输出与回滚、AI 会话正文、剪贴板、崩溃快照、日志与审计、更新下载、命令历史与目录历史等学习数据。

- 套餐来源的非敏感配置可按应用设置导出，专用 token 与 Runtime token 永不入包；目标机器缺少凭据时只显示需要重新配置。
- 未注册或无法证明非敏感的字段不按应用设置导出；本地保留不等于允许入包。
- 备份是显式迁移与恢复能力，不是持续云同步，也不读取其他机器的数据目录。

## 加密导出

- 备份格式带版本，使用口令派生密钥与认证加密；整包真实性与完整性必须可验证，不能只校验单个明文片段。
- 口令只用于当前导出或恢复操作，不持久化、不写入日志，也不得出现在错误消息中。
- 导出先完整构造并校验，再原子写入用户选择的目标；失败不得留下看似有效的半包。
- 导出前显示所选类别与排除项；不得在预览中展示凭据或不存在的“秘密扫描保证”。

## 整包恢复

- 恢复先验证格式、口令、整包鉴权、版本、类别和全部条目；任一预检失败零写入。
- 只有全量校验通过后才能进入写入。写前为所有受影响对象创建恢复点并记录恢复日志，暂停可能竞争的相关写入与 Runtime 写命令。
- 写入中途失败或进程异常后，使用恢复点回滚到恢复前可用状态；不得把部分恢复报告为成功。
- 恢复只影响包内类别，未包含的类别保持原状；恢复结果与任何回滚失败逐项可见。
- 跨机器工作区须先重定位项目根；完成重定位与授权前，不自动读取正文、不启动恢复 PTY，也不按旧机器路径执行文件操作。
- 备份恢复不修改本机 Windows 凭据；缺少凭据的来源保持不可用，直到用户显式配置。

## 恢复点与撤回

- 恢复点与恢复日志跨重启保留，直到用户显式删除或完成符合规则的撤回；一键诊断清理不得删除它们。
- 撤回前比较当前对象指纹与恢复后记录指纹。仍匹配的项可回到恢复前状态；后续被修改的项必须标记冲突并保留当前内容，不得静默覆盖。
- 撤回结果逐项报告成功、冲突与失败；失败项保留恢复点和重试材料，不删除唯一可恢复副本。
- 恢复日志只记录操作、来源、结果与必要指纹，不记录口令、凭据或文件正文。

## 验收判据

- **Given** 导出只选择工作区类别，**When** 检查包内容，**Then** 不含应用设置类别及任何永久排除内容，尤其不含终端输出与学习历史。
- **Given** 包内任一条目被篡改或口令错误，**When** 恢复预检，**Then** 整包拒绝且现有数据零写入。
- **Given** 恢复写入中途失败或异常终止，**When** 恢复流程结束或再次启动，**Then** 可从恢复点回到恢复前状态，不保留部分成功假象。
- **Given** 恢复后用户又修改了某对象，**When** 撤回恢复点，**Then** 指纹冲突项保留当前内容并明确报告，不被旧值覆盖。
- **Given** 在另一机器恢复工作区，**When** 尚未重定位项目根，**Then** 不读取旧路径正文、不启动 PTY，只提供重定位与授权流程。
- **Given** 目标机器没有套餐或 Runtime 凭据，**When** 恢复完成，**Then** 非敏感配置可恢复但对应能力要求重新配置 token，不从包内提取凭据。
