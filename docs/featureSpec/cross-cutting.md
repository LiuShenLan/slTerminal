# 跨域约定

> 负责错误与反馈、键盘与输入、性能与资源、安全与隐私、平台与第三方边界，以及跨组件不变量；具体功能行为由各功能篇定义。

## 目标行为

### 错误与失败

- 所有影响用户数据、终端状态、设置持久化或安全边界的失败必须可见，不得静默吞掉。
- 错误按影响面选择反馈层级：

| 层级 | 适用场景 | 行为 |
|---|---|---|
| 行内 | 字段校验、保存状态、过滤输入 | 紧邻控件显示原因；不阻塞其他操作。 |
| 面板横幅 | 外部冲突、文件过期、Agent 错误、Hooks 外部修改 | 保留在面板内直到解决、关闭或重试成功；提供明确动作。 |
| 通知 | 后台任务完成、短操作结果、非阻断失败 | 悬停或通知内控件聚焦时暂停自动消失；提供关闭按钮；同类通知去重。 |
| 对话框 | 危险操作确认、关闭守卫、导入预览、项目移除 | 模态；列出影响对象；提供取消；破坏性动作需明确确认。 |

- 错误分类至少区分：路径不存在、权限不足、文件被占用、格式/解析失败、版本不兼容、外部冲突、资源上限、平台能力缺失、第三方程序失败。
- 错误消息面向用户，包含可操作的原因；不插值凭据、token、文件内容、终端输出或剪贴板内容。
- 失败后保留用户可恢复的状态：编辑缓冲、脏状态、未保存设置、可重试入口；不得以失败为由清空用户输入。

### 键盘与输入

- 所有核心流程提供键盘路径：面板切换、焦点循环、侧栏显隐、活动栏菜单、视图快捷键、文件树操作、Diff 导航、设置页导航、对话框确认与取消。
- 焦点环始终可见；焦点顺序与视觉顺序一致；模态面打开后焦点进入面内，关闭后回到触发控件；不得出现键盘陷阱。
- 输入法组合期间零命令匹配：单键、组合键、功能键都不进入命令派发，不打断组合、不误提交；CJK 文本的搜索、过滤、标题省略与焦点行为与拉丁文本一致。
- 尊重系统“减少动态效果”设置；动画不得承载唯一信息；加载与进度必须有文本或结构替代。

### 性能与资源

- 前台 UI 不得被阻塞 I/O、网络、子进程等待或大计算卡住；长操作在后台执行，结果回前台更新状态并重绘。
- 大文件、大树、多终端、多面板场景必须有明确降级：虚拟化、按需加载、只读、折叠或禁用重计算；不得无界占用内存或无限后台任务。
- 资源上限由所有者篇定义并在本规格中保持单一来源：终端 PTY 上限 64；终端回滚默认 10000 行、可配 1000–100000；编辑器 10MB 提示、50MB 只读；Diff 按字节 1MiB 警告、10MiB 只读；Markdown 5MB/100k 行降级源码、50MB 不渲染；GitShow 1,000,000/10,000,000 字节分级；设置载荷 1MiB。状态库单载荷与总大小上限由详细设计定义；超限时必须拒绝写入并可见提示。
- 面板关闭、项目切换、视图不可见（其槽位打开了其他视图，或侧栏实际隐藏）后，相关监听、定时器、计算任务必须停止或取消；不得留下孤儿任务。“隐藏视图”只隐藏活动栏按钮，不停止仍可见内容的监听。
- 渲染不可用时允许静默降级；性能持续不达标时给出一次性提示，不反复打扰。

### 安全与隐私

- 真实凭据不得写入任何 git 追踪文件、设置、布局、日志、错误消息或崩溃快照；测试与文档只使用假值占位符；凭据不进入终端输出、剪贴板或恢复快照。
- 外部链接按来源分表：终端 OSC 8 只接受 `http`、`https`、`mailto`；Markdown 渲染态接受 `http`、`https`、`mailto`、`tel` 与项目内本地路径；共同底线是 `javascript:`、`data:`、`blob:`、`file:` 等协议忽略或无动作；外部 URL 交系统默认程序打开，不在应用内嵌浏览器。
- 文档内容按不可信输入处理：不执行脚本、事件、表单、内嵌框架、对象与嵌入元素；原始 HTML 只解析安全子集；远程图片默认不加载、点击后单次加载且不带 Cookie/凭据；远程字体、样式、脚本永不加载。
- 文件读取允许根为项目根、项目根所在 Git 仓库实际根、已登记 Agent 全局目录；业务写入允许根仅为项目根与已登记 Agent 全局目录。项目根的真实路径用于包含性校验，项目身份按 `ProjectId`，根路径按词法路径比较用于唯一性与归属。项目根外、仓库根内的文件以只读方式打开；仓库根外、设备路径、盘符相对路径拒绝自动打开与写入；UNC 仅在允许根内允许；符号链接与目录联接按真实目标路径校验，根外目标拒绝读写。系统“另存为”对话框是显式写入例外，用户选定路径后该文档可保存到该路径。Markdown 文档中的显式本地链接可只读打开允许根外的单个本地文件，不加载其根外资源；UNC 与设备路径仍按允许根规则处理；该例外不适用于文件树、Commit、GitShow 或编辑器自动打开。
- 应用托管写入限定在应用数据目录、系统临时目录、备份/隔离/日志目录与 Hooks/CLI 配置文件；Hooks/CLI 配置是用户显式编辑的第三方配置，遵循各自权限边界。
- Markdown 本地资源允许项目根与已登记 Agent 根内真实路径；可写根内链接走可编辑打开，资源读取允许 AgentRoot 真实路径；根外链接以根外只读打开，根外资源拒绝；设备路径、盘符相对路径显示占位或被拒绝；UNC 仅在允许根内时允许；符号链接按真实路径校验，防止路径穿越。
- 终端链接只接受程序声明的 OSC 8，协议限 `http`、`https`、`mailto`；OSC 52 只写不读，仅聚焦终端默认可写，后台写入需显式开启且限活跃项目，上限 1MB 并提示；粘贴含控制字符或超过 50 行需确认，超过 10MB 拒绝。
- 终端工作目录与应用发起的路径限项目根与已登记 Agent 全局目录；UNC 仅在允许根内允许；越界失败，不继承应用当前目录；自定义 Shell 只接受可执行文件路径，不提供参数注入。
- 文件删除统一进系统回收站；回收站不可用时回退永久删除并说明；不提供 `Shift+Delete` 快捷方式；`.git` 目录或文件在文件树任何层级都不显示。
- 导入导出只处理应用设置；不导出 Hooks、CLI 配置、凭据、终端输出、剪贴板或崩溃快照；导入前校验、预览、备份、原子写。

### 平台与第三方边界

- 仅 Windows 10/11 桌面；单窗口、单实例；仅暗色；使用 Windows 原生 shell 与 CLI，不走 WSL；不支持 macOS/Linux、移动端或跨平台。
- 默认 Shell 解析链为 PowerShell 7 → Windows PowerShell 5.1 → `cmd.exe`；用户可在设置中心覆盖。
- `cmd` 不提供完整 Shell 集成：无命令边界、自动标题、四态与目录跟踪；历史恢复使用固定等待。根因是第三方 Shell 能力限制，不静默伪造。
- Windows 10 早期版本缺少所需控制台能力时，回退系统控制台并一次性提示；基本输入输出保留，滚轮转发等增强不可用。根因是操作系统版本。
- 文件锁、权限不足、路径大小写不敏感、文件被其他程序占用属于操作系统边界：失败必须可见，保留重试或系统程序打开路径。
- 系统默认浏览器/邮件程序、文件管理器、回收站、CLI 配置编辑器能力由操作系统或第三方程序决定；应用只负责分派与错误呈现。
- Git 操作依赖本机 Git 可用性与仓库状态；非仓库进入错误态并提示手动初始化，不自动执行初始化；不执行网络 Git 操作，不修改 Git 配置。

### 跨组件不变量

- 面板类型与侧栏视图均为封闭集；未知面板类型恢复时丢弃并聚合警告，未知侧栏视图静默丢弃；新增类型只能在单一注册点登记。
- 每项目每路径只有一个编辑器视图；文件打开统一经文件打开路由；Commit 来源不产生后缀视图。
- Commit、Diff、GitShow、文件浏览器统一使用项目根所在的 Git 仓库实际根；允许项目根为仓库子目录。
- Commit 覆盖整个仓库、Explorer 只覆盖项目根是有意产品决策，不是数据不一致；项目根外、仓库根内的 Commit 条目只读，不可在 Explorer 定位、不可回滚/删除、不可在终端打开。
- 焦点、脏状态、关闭守卫、通知、单实例与持久化去抖由 `workspace/shell.md`、`settings-and-persistence.md` 单点定义；其他篇引用，不另立规则。
- 颜色、尺寸、间距、字体与状态样式来自主题/设置体系；组件不硬编码颜色；终端跟随主题 ANSI 调色板，不提供独立配色。
- 错误通道、审计通道与凭据域是安全单点；领域不得自建第二套日志、错误信封或凭据存取通道。

## 交互规则

### 反馈层级选择

- 用户正在输入的字段错误用行内提示；不要用模态框打断输入。
- 影响当前面板但可继续工作的失败用横幅；横幅保留到解决或手动关闭。
- 短操作结果与后台完成用通知；通知不抢焦点，悬停或通知内控件聚焦时暂停，提供关闭。
- 可能丢失数据、影响多个面板、改变外部文件或不可撤销的操作必须用对话框确认，并列出影响对象。

### 键盘与焦点

- 菜单、对话框、通知、横幅关闭按钮均可键盘到达；`Esc` 关闭最上层临时界面；`Enter` 激活默认动作；`Tab`/`Shift+Tab` 在面内循环。
- 焦点离开面板时保存必要的编辑状态；重新聚焦时恢复光标与滚动锚点；只读视图可聚焦但不进入编辑。
- 全局命令与面板命令冲突时，按固定派发层序裁定：临时面 > 系统键 > 面板固定键/保留键 > 面板命令 > 侧栏视图快捷键 > 全局命令 > 终端输入；不按最近焦点历史裁定。冲突在设置中心快捷键页可见；侧栏视图快捷键全局生效并优先于终端输入。

### 危险操作

- 删除、回滚、批量关闭、移除项目、恢复默认、导入设置必须二次确认或提供短时撤销；确认框说明影响范围与是否可撤销。
- 删除历史会话提供 5 秒撤销；删除文件走系统回收站；Diff 不提供 Git 写操作，Commit 仅保留项目根内文件级回滚/删除，唯一例外为删除 added 前取消暂存；完整 Git 工作流由终端承担。
- 关闭运行中终端且存在前台进程时按工作区关闭守卫确认；批量关闭任一保存失败则中止并保留全部面板。

## 边界与错误

- 错误消息过长时截断并提供详情入口；详情不得包含文件内容、凭据或终端输出。
- 通知风暴：同类通知合并或去重；后台扫描失败只在视图内显示警示，手动刷新失败才通知。
- 减少动效下布局不重叠、关键按钮不被裁切；无法满足时优先保证键盘可达与文本可读。
- 第三方程序启动失败（浏览器、文件管理器、默认编辑器）时提示失败原因，不静默无响应。
- 安全边界拒绝（路径越界、协议不允许、脚本内容）时给出明确说明，不提供“仍然执行”的绕过入口。

## 验收判据

- **Given** 仅使用键盘，**When** 完成面板切换、侧栏显隐、活动栏菜单、文件树操作、Diff 导航与设置页导航，**Then** 所有核心流程可达，焦点环可见，无键盘陷阱。
- **Given** 输入法处于组合状态，**When** 输入 CJK 文本或触发单键快捷键，**Then** 组合不被打断，快捷键不误触发。
- **Given** 终端或编辑器字号调整为 8–32，**When** 查看对应面板与状态条，**Then** 内容可滚动或换行，关键操作不被截断。
- **Given** 发生保存失败、外部冲突或后台任务失败，**When** 用户继续操作，**Then** 错误按层级可见，用户输入与可恢复状态保留。
- **Given** 文档包含脚本、事件、内嵌框架、外部资源或危险链接，**When** 渲染或点击，**Then** 脚本不执行、外部资源不自动加载、危险协议无动作。
- **Given** 终端输出包含 OSC 52 写入或粘贴超限内容，**When** 非聚焦终端或超限粘贴，**Then** 按安全策略拒绝或确认，不静默写入。
- **Given** 文件路径在允许根外、设备路径、盘符相对路径或 `.git` 条目，**When** 尝试打开或显示，**Then** 被拒绝或隐藏并说明原因；UNC 仅在真实目标位于允许根外时拒绝。
- **Given** 运行环境为 `cmd` 或 Windows 10 早期版本，**When** 使用 Shell 集成或控制台增强，**Then** 按平台边界降级并一次性提示，不伪造能力。
- **Given** 关闭窗口时存在运行中终端与脏面板，**When** 确认关闭，**Then** 依次执行 Guarding（收集与确认）→ Saving（面板保存与设置/状态库冲刷）→ 终止 PTY → 最终项目数据提交，各阶段不超过 3 秒。
- **Given** 面板类型或侧栏视图记录未知，**When** 恢复布局，**Then** 未知面板类型丢弃并聚合警告，未知侧栏视图静默丢弃，应用不崩溃。

## 关键决策与依据

- **错误必须可见**：影响数据、终端状态、持久化或安全的失败不得静默。原因：静默失败会让用户误以为操作成功，造成数据丢失或安全问题。边界：不影响用户目标的内部重试可静默，但最终失败必须呈现。
- **按影响面分层反馈**：行内/横幅/通知/对话框。原因：统一用模态框会打断工作，统一用通知会漏掉需要处理的问题。边界：危险操作与关闭守卫必须用对话框。
- **安全默认拒绝**：路径越界、危险协议、脚本内容、后台剪贴板写入、自动网络请求默认拒绝。原因：文档与终端输出均为不可信输入，默认允许会扩大攻击面。边界：用户显式点击的远程图片单次加载、聚焦终端 OSC 52 写入等受控例外按各篇规则执行。
- **平台边界显式降级**：`cmd`、Windows 10 早期控制台、文件锁、默认程序失败均给出可见降级与根因，不伪装成功。原因：第三方与操作系统能力不可控，静默绕过会制造更难排查的故障。边界：核心输入输出必须保留。
- **契约单点**：面板类型、文件路由、Git 仓库根、焦点、脏状态、关闭链、持久化去抖只在所有者篇定义。原因：跨篇复制会漂移。边界：其他篇只能引用，不能另立数值或例外。
