# 跨域约定

> 拥有错误反馈、命令目录、焦点与输入、后台生命周期、安全隐私和可验证资源约束；具体功能与数值由所有者文档定义。

## 错误与反馈

- 影响用户数据、终端状态、设置持久化或安全边界的失败必须可见；内部重试可静默，最终失败不得静默。
- 字段校验用行内错误；面板级冲突用非模态横幅；短操作结果用通知；危险操作与关闭守卫用模态确认。
- 错误区分不存在、权限、占用、格式、版本、外部冲突、资源上限、平台能力与第三方失败，并提供可执行的重试或恢复路径。
- 失败后保留用户输入、编辑缓冲、脏状态和可重试现场；不得以失败为由清空内容或把部分成功报告为全部成功。
- 错误与日志默认不记录文件正文、终端输出、AI 会话正文或剪贴板，不插值 token、key 等凭据。

## 命令目录与键盘

- 唯一命令目录统一管理命令上下文、默认键、替换绑定、额外绑定和冲突；文件树动作与补全动作同样纳入，不设隐藏的第二套快捷键配置。
- 除产品明确保留的按键外，公开命令允许替换、解绑或增加绑定。终端 `Ctrl+C` 永远保留为中断并透传 PTY，可另增中断键，但不得用复制绑定取代它。
- 命令按确定上下文派发：模态临时面优先，其次是当前面板、侧栏与全局命令，最后才是终端输入；不得按最近焦点历史猜测。冲突在设置中可见并说明生效上下文。
- 默认复制为 `Ctrl+Shift+C`；有选区时复制，无选区不把它转为中断。
- 所有核心流程均有键盘路径。非模态操作栏出现时不抢焦，但必须提供键盘入口；模态框约束焦点，关闭后按“触发控件 → 逻辑父容器 → 当前面板默认落点 → 工作区”链还焦。
- IME 组合期间不派发命令、不打断组合或误提交；CJK 搜索、过滤、换行和标题截断与拉丁文本采用一致的交互语义。
- 尊重系统减少动效；动画不得承载唯一信息。

## 后台与可见性

以下工作不因面板或项目不可见而停止：存活 PTY 与输出解析、Runtime、单实例服务、保存与快照、显式文件操作、更新任务、CLI hooks 信号、Agent 状态事件，以及用户显式启用的套餐余量后台任务。

以下工作仅服务可见界面，不可见时暂停：Explorer／Commit／Agent 树监听、Hooks 页监听、GitShow 后台复核、纯 Diff 展示重算和其他界面轮询。

- 隐藏 Document 可暂停刷新，重新可见时合并复核一次；保存前始终实时校验。
- 重新可见时合并为一次刷新，不补放中间帧或累积执行错过的界面任务。
- 视图销毁后取消其私有任务；项目切换、输入变化或重新请求产生的过期结果不得回填。
- 进行中的显式保存、删除、恢复等操作可继续完成并保留结果提示；不得因界面隐藏而半途破坏数据。
- 所有 watcher、线程和任务都有明确所有者与停止路径；重复创建和销毁后不得遗留孤儿任务或持续增长资源。

## 安全与隐私

- 真实凭据值禁止写入任何 git 追踪文件——代码、测试夹具、文档、脚本一律不行；测试与文档仅允许假值占位符（`sk-test` 形态）。真实凭据只存 Windows 凭据管理器；token/key 不出凭据域，日志/错误消息禁插值。
- 专用套餐查询 token 与 Runtime token 都属于凭据；CLI 自己管理模型与 CLI 认证，应用不读取其配置或环境变量中的 token。
- 用户文件、命令历史、终端输出、AI 会话和剪贴板可能含秘密；应用不承诺识别所有秘密。相应数据是否采集、导出或清理必须由各所有者明确声明。
- 崩溃快照可包含用户文本，必须限制为当前用户可访问、按恢复规则保留，并排除于备份与诊断包。
- 安全写事件与哈希对账只经 `tracing` target `audit`；事件字段只含 `operation/path/source/result` 与 `expected/actual` 指纹，禁插值凭据值或文件内容。
- 文档、Markdown、SVG、Mermaid、终端转义序列和外部链接均按不可信输入处理；脚本、危险协议和未授权网络加载默认拒绝，受控例外由功能篇列出。
- 路径与文件操作统一经过 [PathPolicy](path-policy.md)，任何 UI、Runtime 或第二实例入口都不得绕过。

## 外观与资源

- 仅暗色。颜色由主题语义 token 单点提供，终端 ANSI 也映射到主题；组件不得硬编码颜色。
- 自定义主题与内置主题遵守同一完整 token 合同；不做对比度校验、提示或自动回退。
- 前台不得执行阻塞 I/O、网络、子进程等待或无界大计算；后台工作必须可取消或具有明确完成所有权。
- 大列表与大文本采用虚拟化、分页或只读降级；具体容量、体积与调度数值只在所有者文档定义。
- 性能验收采用结构断言和可复现实机场景，不写无基准的毫秒承诺。新增性能数值必须同时给出硬件、系统、数据规模、测量方法与统计口径。

## 验收判据

- **Given** 文件树动作或补全命令被重绑，**When** 在对应上下文触发，**Then** 唯一命令目录给出一致结果并显示冲突；终端 `Ctrl+C` 始终仍为中断。
- **Given** 非模态操作栏出现，**When** 用户继续输入或仅用键盘操作，**Then** 焦点不被偷走且操作栏可经键盘到达。
- **Given** 模态框的触发控件在关闭前已销毁，**When** 关闭模态框，**Then** 焦点按统一链落到可用父级而不是丢失。
- **Given** 视图不可见后又重新可见，**When** 期间发生多次文件事件，**Then** 只合并复核一次；销毁后的过期结果不回填。
- **Given** 保存或显式文件操作在视图隐藏后完成，**When** 查看结果，**Then** 操作状态与错误仍可查询，现场未被半途销毁。
- **Given** 日志、错误、备份和诊断内容，**When** 检查敏感数据边界，**Then** 不含凭据及被禁止的正文、终端输出或剪贴板。
- **Given** 性能需求评审，**When** 检查数值判据，**Then** 每个数值都有明确类型与测量条件，或属于所有者定义的契约调度／容量数值。
