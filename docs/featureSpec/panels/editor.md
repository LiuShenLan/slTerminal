# 编辑器面板

> 拥有文本编辑、编码、查找替换、语言与大文件阅读体验；Document 身份、共享缓冲、保存和关闭守卫由 [Document](document.md) 统一拥有。

## 面板与编辑能力

- Editor 显示普通文本与 HTML 源码，不提供应用内 HTML 渲染。HTML 面板可通过悬浮按钮用系统默认程序打开磁盘版本；该操作不保存当前修改。
- 空文件显示空白编辑区。显式打开在建立可读文本前失败时不留空 Panel；既有 Document 重读或解码失败保留面板、路径、原因与重试，不创建可保存的空缓冲。
- 可编辑状态支持键入、删除、选择、复制、剪切、粘贴、撤销／重做、括号匹配、当前行、行号、缩进、基于当前文档标识符的补全；不依赖外部语言服务。
- 标准文本编辑菜单只提供文本操作；文件级操作由文件树或 Document 命令承担。不支持小地图和编辑器内分栏。
- 普通文档面板可通过显式视图切换命令改为 Markdown；扩展名变化不自动切换，身份与状态按 Document 规则保留。

## 编码与行尾

- 支持 UTF-8、带 BOM 的 UTF-8、UTF-16 LE/BE，以及可检测的常见本地编码，至少包括 GB18030／GBK。
- 打开时先识别 BOM 与合法 UTF-8，再进行本地编码检测；无法判定时提供“以编码重新打开”和系统打开，不以乱码建立编辑基线。
- 前 8192 字节含 NUL 的文件按二进制处理，不进入文本编辑；提供系统默认程序打开。
- 行尾默认取文件首个 CRLF 或 LF；用户切换行尾属于一次 Document 修改，保存时统一为所选行尾。新建文件默认 CRLF，末尾换行策略保持原文件。
- 状态条显示语言、编码／BOM、行尾和只读原因；编码重读若有脏修改须先确认，行尾切换写入共享 Document。

## 查找、替换与折叠

- `Ctrl+F` 打开面板内查找；支持大小写、整词和正则选项，默认不区分大小写、整词关闭、正则关闭。
- 查找增量更新当前匹配、计数和高亮；`Enter`／`F3` 与 `Shift+Enter`／`Shift+F3` 前后导航并回绕。大文件查找后台扫描，显示进度并可取消。
- 替换当前匹配或全部替换；全部替换先确认并作为单个撤销步骤。正则替换支持捕获组，非法正则只显示行内错误。
- 只读状态可查找，不可替换。`Ctrl+Alt+G` 接受从 1 开始的行号，越界时说明实际范围并夹取。
- 代码折叠按当前语言结构提供；折叠只改变显示，不修改 Document。内容变化使区域失效时自动展开。
- 查找、跳转和折叠命令进入统一命令目录；搜索词、选项、当前匹配、折叠状态和查找栏开关均为瞬态。

## 语言与显示

- 高亮语言按扩展名或固定文件名选择，Editor、Diff、GitShow 与 Markdown 代码块共用同一语言注册表。未知类型使用纯文本。
- 支持的映射为：JavaScript（`js/jsx/mjs/cjs`）、TypeScript（`ts/tsx`）、Python（`py/pyw`）、Rust（`rs`）、JSON（`json/jsonc`）、HTML（`html/htm`）、CSS（`css/scss/less`）、Markdown（`md/markdown`）、XML（`xml/svg`）、Shell（`sh/bash/zsh`）、PowerShell（`ps1/psm1`）、Go、Java、C/C++、C#、SQL、YAML（`yml/yaml`）、TOML、INI（`ini/cfg`）、Diff（`diff/patch`）、Dockerfile 与 Makefile。
- 语言选择器提供“自动”和已注册语言；手动覆盖只影响高亮，不改扩展名、Document 内容或保存行为。
- 语言覆盖与自动换行属于 `ViewKey` 持久状态，关闭重开与重启均恢复；路径变化不自动清除手动覆盖。
- 编辑器字号全局共享，默认 14px、范围 8–32px；`Ctrl+滚轮` 逐级调整，不重建 Document。
- 自动换行按视图独立，`Alt+Z` 切换；新视图默认值来自外观设置，已有持久状态优先。

## 只读与大文件

| 文件大小 | 行为 |
|---|---|
| 不超过 10,000,000 字节 | 正常编辑 |
| 大于 10,000,000 且不超过 50,000,000 字节 | 可编辑，显示非阻塞大文件提示，关闭文档内自动补全 |
| 大于 50,000,000 字节 | 分页只读浏览，不建立完整可编辑缓冲 |
| 只读内容大于 200,000,000 字节 | 关闭语法高亮并说明，保留分页阅读与查找 |

- 只读浏览支持行号、选择、复制、查找、换行和折叠；不提供编辑、替换、Git 行标或原地保存。
- 已打开 Document 因外部增长超限时：干净状态切为只读；脏状态保留可编辑文本与保存出口，不用新阈值销毁用户内容。
- 手动只读只在可编辑且干净时开启；不覆盖授权、大文件或错误导致的只读。手动只读是瞬态，关闭重开与重启均清除。
- 失去原地写授权的已加载 Document 可按 Document 规则另存为；只读冲突快照和 GitShow 不因此获得保存能力。

## Git 行标

- 可编辑文本左侧可显示相对 HEAD 的新增、修改和删除标记；颜色取主题 token，形状同时区分语义。
- 标记在打开、保存、重载、撤销／重做和编辑去抖后后台重算；过期结果不得覆盖新文本。
- 非 Git 仓库或读取失败时不显示标记，不用无关错误打断编辑。
- 单击标记打开或聚焦同文件 Diff，并定位对应差异块；Editor 与 Diff 继续引用同一 Document。
- 大文件只读和未获持久 Git 读取授权的内容不显示行标；手动只读不妨碍查看 Diff。

## 外部变化与恢复

- 外部修改、删除、重命名、链接重定向和保存冲突全部按 [Document](document.md) 处理；所有引用视图共享结果。
- 隐藏时可暂停监听，重新可见时合并复核；保存前始终实时检查磁盘版本和真实目标。
- 异常恢复只通过 Document 快照；Editor 不另建按 Panel 的草稿。恢复快照不恢复撤销、搜索、手动只读或焦点。
- 语言覆盖、自动换行与滚动位置按 `ViewKey` 恢复，关闭重开与重启共用同一状态；光标、选区、搜索、折叠、手动只读、临时提示和焦点均不恢复。

## 标题与焦点

- 页签默认显示文件名；同项目同名文件用项目相对路径消歧，根外使用规范绝对路径。标题由位置重新计算，不作为持久事实。
- 显式打开或激活时焦点进入编辑区或只读查看器；布局恢复不抢焦。
- `Ctrl+S` 保存当前 Document；`Ctrl+Tab`／`Ctrl+Shift+Tab` 离开编辑器并循环面板焦点；`Tab` 在编辑区内用于缩进。
- 冲突横幅和 HTML 悬浮按钮均可键盘到达，出现时不得抢焦。

## 验收判据

- **Given** 同一 Document 同时显示在 Editor 与 Diff，**When** 在 Editor 编辑或保存，**Then** Diff 立即观察同一文本与基线，不产生独立工作区缓冲。
- **Given** HTML 有未保存修改，**When** 点击系统打开，**Then** 打开磁盘版本且不隐式保存。
- **Given** GBK 文本、非法编码与含 NUL 文件，**When** 分别打开，**Then** 分别按检测编码编辑、提供编码重开、按二进制拒绝文本缓冲。
- **Given** 全部替换包含多处匹配，**When** 确认后撤销一次，**Then** 整次替换被回滚。
- **Given** 文件跨过 50,000,000 字节阈值，**When** Document 干净或为脏，**Then** 分别切换只读或保留脏缓冲，不静默丢失文本。
- **Given** 设置语言覆盖、换行和滚动位置后关闭重开及应用重启，**Then** 两者均按同一 `ViewKey` 状态恢复；搜索、折叠、光标和焦点不恢复。
- **Given** 文件从 `.md` 改名为 `.txt`，**When** 外部事件到达，**Then** 原 Panel 不自动换类型，仅更新位置和显示。
- **Given** 点击 Git 行标，**When** Diff 打开，**Then** 两个视图引用同一 Document 并定位到对应差异。
