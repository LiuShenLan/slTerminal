# 编辑器面板

> 本文是文件打开路由与编辑器面板状态契约的唯一所有者；不拥有 Markdown 文档面板、Diff、GitShow、设置中心、工作区关闭链与布局操作，相关契约见 `../workspace/shell.md`、`markdown.md`、`diff.md`、`gitshow.md`、`settings.md`。

## 目标行为

### 面板形态与运行模式

- 编辑器是面板类型封闭集中的一个类型，位于所属项目布局的面板组内。每个项目恰好拥有一个项目布局；多项目布局同时存活，切换项目只改变可见性。
- 编辑器面板始终绑定恰好一个文件路径；不存在无路径草稿缓冲，也不提供面板内的“新建文件”“打开文件”入口。
- 面板内容区占满面板，不设面板内标题栏、工具栏或保存按钮。可见元素为：编辑区（等宽字体、行号、当前行高亮、代码折叠标记、Git 变更标记、按需滚动条）、顶部搜索面板（默认隐藏）、冲突或删除横幅、只读信息条、底部轻量状态条，以及仅 `.html`/`.htm` 文件显示的右上 HTML 悬浮按钮。
- 不提供小地图。
- 运行模式分为可编辑、只读浏览、根外只读、文件已移出允许根与错误态；手动只读是叠加在可编辑模式上的用户锁，不产生新的面板类型。
  - 可编辑：路径位于项目根或已登记 Agent 全局目录内，或经系统另存为显式选择了根外路径；字节数不超过 50,000,000，且未开启手动只读。
  - 只读浏览：路径范围同上，字节数超过 50,000,000。
  - 根外只读：路径位于项目根与已登记 Agent 全局目录之外且不是当前运行期的另存为目标；包括经 Markdown 显式链接、Commit 视图或布局恢复打开的根外文件；顶部信息条标注 `项目根外`；不提供保存；不因该打开动作加入文件浏览器、Commit 视图或终端默认目录。另存为授权只绑定当前文档与当前运行期，重启后根外路径一律按本模式重新判定。
  - 文件已移出允许根：可编辑文档在应用外被重命名或移动至项目根与 Agent 目录之外后进入的脱离状态；保留缓冲、编辑能力与脏状态，禁用原地保存，提供另存为；移回允许根内后恢复普通可编辑与原地保存。
  - 错误态：读取失败、二进制、编码无法判定或文件不存在；不建立可编辑缓冲，不提供保存。
- 空文件打开后显示空白可编辑区域与首行光标，不显示占位文案、欢迎页或“未打开文件”引导。
- 文件读取期间编辑区为空白；读取超过 150ms（设计契约）显示轻量加载指示；大于 10,000,000 字节（设计契约）显示读取进度。
- Markdown 文件（含项目根外目标）由 Markdown 面板承接，不进入编辑器，见 `markdown.md`。HTML 文件进入编辑器并显示源码，不渲染、不执行脚本。

### 文件打开路由

编辑器由统一文件打开链路创建或聚焦。链路输入为：项目、文件路径、来源上下文。

| 入口 | 触发方式 | 结果 |
|---|---|---|
| 文件浏览器 | 双击文件行；或选中文件后按 `Enter` | 按扩展名分派；编辑器承接非 Markdown 文本文件 |
| 拖放 | 从文件浏览器拖文件到编辑器面板组 | 同标准路由；已打开则聚焦，否则在目标面板组新建面板 |
| Commit 视图 | 双击 added 或 untracked 文件 | 按标准路由分派；编辑器按每项目每路径唯一视图打开或聚焦 |
| Markdown 面板链接 | 点击指向本地非 Markdown 文件的相对链接 | 按标准路由分派 |
| Markdown 面板根外链接 | 点击解析后位于项目根外的本地非 Markdown 链接 | 编辑器以根外只读模式打开并标注 `项目根外` |
| 布局恢复 | 应用启动或项目布局恢复 | 按保存的路径与根外只读标记重新读取磁盘并打开 |

扩展名分派规则，大小写不敏感：

| 扩展名 | 目标面板 |
|---|---|
| `.html`、`.htm` | 编辑器（源码可编辑；右上 HTML 悬浮按钮） |
| `.md`、`.markdown` | Markdown 面板（见 `markdown.md`） |
| 其余扩展名、无扩展名、以点开头的隐藏文件 | 编辑器 |

- 目录不是打开目标；文件浏览器对目录执行展开或折叠，不调用文件打开链路。
- 自动打开限项目根、仓库实际根与已登记 Agent 全局目录；项目根外、仓库根内的文件以根外只读模式打开；仓库根外仅允许经 Markdown 显式链接以根外只读模式打开。系统另存为对话框是显式写入例外，选择的任意本地路径纳入项目外文件监听并成为该文档的保存目标；授权不写入布局、不跨重启。
- 打开请求归属请求来源所在的项目。文件浏览器与 Commit 视图的请求归属活跃项目；Markdown 面板链接归属该面板所在项目。
- 去重键为“项目 + 规范化真实路径”；根外只读视图同样适用。命中去重键时，激活对应项目、面板组与面板并聚焦，不创建新面板或新文档缓冲。
- 每项目每路径只有一个编辑器视图与一个文档缓冲。Commit 来源不产生后缀视图，不改变编辑器身份；Commit 状态只在 Commit 视图展示。
- 同一路径在不同项目中各自拥有独立视图与文档缓冲，互不共享。
- 打开失败（文件不存在、无权限、路径失效）时仍创建编辑器面板并进入错误态，保留路径，提供 `重试` 与 `用系统默认程序打开`；布局恢复遇到同一情况同样进入错误态，不丢弃面板。
- 没有活跃项目时，打开请求不产生面板，提示 `请先创建项目`。
- 活跃项目的布局没有可落位的面板组时，由工作区按 `../workspace/shell.md` 创建后再落位。
- 布局恢复只恢复路径、根外只读标记、自动换行与语言手动覆盖等面板参数，不恢复文本、脏状态、光标、滚动或搜索状态；恢复时按当前磁盘内容重新读取并重新判定运行模式。布局恢复不产生焦点意图，不抢键盘焦点。

### 拖文件打开

- 拖拽来源仅限文件浏览器中的文件；目录不触发打开。拖拽目标为包含至少一个编辑器面板的面板组。外部操作系统文件拖入不支持；拖入无动作或一次性提示 `请从文件浏览器拖动文件`。
- 指针进入有效目标面板组时，该面板组高亮；离开或取消拖拽后高亮消失，不产生任何打开动作。非编辑器面板组不高亮、不接受打开。
- 释放后按标准文件打开路由在目标面板组打开：Markdown 目标进入 Markdown 面板，HTML 与其他文本目标进入编辑器，二进制与不支持类型走现有错误态。
- 文件已在该项目中打开时，聚焦已有面板，不新建面板、不复制缓冲。
- 打开不替换目标面板组中当前激活的脏面板；需要新增时在同一面板组新增页签。
- 拖拽打开不修改文件内容、不改变任何面板的脏状态、不触发保存。
- 打开请求归属活跃项目。

### 文档身份与路径变化

- 文档身份使用规范化真实路径：绝对路径、统一分隔符、Windows 下大小写不敏感、解析符号链接与目录联接后的目标路径。显示路径可保留项目相对形式。
- 文档按“项目 + 规范化真实路径”唯一；同一项目内同一路径只有一个编辑器视图与一个文档缓冲。
- 另存为改变文档身份、路径、保存目标与布局中记录的路径，视图随文档迁移到新路径。
- 文件在应用外被重命名且文件监听器报告旧路径到新路径的映射时，编辑器跟随重命名：更新文档路径与页签标题，保留文本、脏状态、撤销历史与光标。新路径已被打开时，按“另存为目标已打开”处理。
- 可编辑文档移动到项目根与 Agent 目录之外后进入“文件已移出允许根”的脱离状态：保留缓冲、编辑能力与脏状态，禁用原地保存，提供另存为与关闭；移回允许根内后恢复普通可编辑与原地保存。根外只读文档保持根外只读标记。
- 路径扩展名跨分派类别变化（例如 `.md` 改为 `.html`）时，面板类型随路由重新判定：编辑器与 Markdown 面板之间转换，`PanelId`、页签位置、文本、脏状态、撤销、光标、选择与滚动保留；转换后的 Markdown 形态按“脏缓冲或原形态为源码时保持源码态，否则渲染态”处理。目标路径已有同类型面板时暂停转换，显示 `目标文件已打开`，提供 `取消` / `替换`；替换前对目标脏缓冲要求保存/丢弃确认。转换后仍为脏则保持脏状态，不触发保存或关闭守卫。
- 文件在磁盘上被删除不改变文档身份；按外部修改规则显示删除横幅，缓冲保留。
- 文档身份变化后，页签标题重新计算；侧栏与 Commit 视图按文件事件刷新；HTML 悬浮按钮按新扩展名显示或隐藏。

### 编辑、语言高亮与脏状态

- 可编辑模式支持：键入、删除、选中、复制、粘贴、剪切、全选、撤销、重做、括号匹配、当前行高亮、行号、自动补全、`Tab` / `Shift+Tab` 缩进。
- 自动补全基于当前文档中的标识符，不依赖外部语言服务；文件大于 10,000,000 字节（设计契约）时关闭自动补全，语法高亮、搜索与 Git 标记保留。
- 文本编码支持 UTF-8、带 BOM 的 UTF-8、带 BOM 的 UTF-16 LE/BE，以及检测出的常见本地编码（至少包括 GB18030/GBK，设计契约）。打开时先按 BOM 与合法 UTF-8 判定；未命中时对常见本地编码做启发式检测，结果显示在状态条。保存按当前选定的编码与 BOM 策略写回，默认解释仍为 UTF-8。无法判定编码的文本不进入编辑缓冲，显示错误态，提供 `以编码重新打开` 与 `用系统默认程序打开`。
- 二进制文件（前 8192 字节内出现 NUL 字节，设计契约）不进入编辑缓冲，显示二进制错误态与文件大小，提供 `用系统默认程序打开`。
- 行尾风格默认按文件首个行尾确定：CRLF 或 LF。用户可经状态条切换行尾，切换按一次文档修改计入脏状态，保存时按选定行尾写入。混合行尾在保存时统一为选定行尾。新建文件在 Windows 上使用 CRLF；文件末尾是否有换行符按原文件保持。
- 语言高亮按扩展名选择，普通编辑器、Diff、GitShow 共用同一映射：

| 扩展名 | 高亮语言 |
|---|---|
| `.js`、`.jsx`、`.mjs`、`.cjs` | JavaScript |
| `.ts`、`.tsx` | TypeScript |
| `.py`、`.pyw` | Python |
| `.rs` | Rust |
| `.json`、`.jsonc` | JSON |
| `.html`、`.htm` | HTML |
| `.css`、`.scss`、`.less` | CSS |
| `.md`、`.markdown` | Markdown |
| `.xml`、`.svg` | XML |
| 其他或无扩展名 | 纯文本 |

- 路径变化导致语言变化时，在原文档缓冲上热切换语法规则，不重建缓冲，不丢失文本、脏状态、光标或撤销历史。
- 文档文本发生任何修改即进入脏状态；光标移动、选区变化、滚动、搜索、自动换行切换、字号变化、代码折叠、语言选择不改变脏状态。撤销回到最近一次载入或保存的内容时，脏状态自动清除。
- 撤销与重做按文档维护；撤销历史在面板存活期间保留，关闭文档或应用重启后不保留。
- 首行缩进风格按文件现有内容推断：以制表符开头的行占多数时使用制表符，否则使用空格；空格宽度取文件中常见的 2、4 或 8，默认 4（设计契约）。`Enter` 自动延续上一行缩进。
- 输入法组合输入期间不打断组合状态；组合结束后按一次文本修改计入撤销与脏状态。CJK 字符按实际显示宽度排版。

### 代码折叠

- 编辑区 gutter 显示代码折叠标记；可折叠区域按当前语言的语法结构确定，纯文本与无法识别结构的文件不显示折叠标记。
- 折叠后隐藏该区域内容，起始行显示折叠标记与折叠行数（形如 `⋯ N 行`）；再次点击标记或执行展开命令恢复显示。
- 快捷键：`Ctrl+Shift+[` 折叠当前块，`Ctrl+Shift+]` 展开当前块；`Ctrl+Alt+[` 全部折叠，`Ctrl+Alt+]` 全部展开。以上命令可重绑；焦点不在编辑器时不生效。
- 折叠状态是面板状态：同面板组切面板、切换项目时保留；关闭面板重开或应用重启后不保留，也不随布局持久化。
- 文档内容变化后，不再存在的折叠区域自动展开；新出现的可折叠区域默认展开。
- 代码折叠只改变显示，不修改文档内容，不改变脏状态，不进入撤销历史。
- 可编辑、只读浏览与根外只读模式均可折叠；手动只读同样可用。
- 折叠标记与 Git 变更标记是 gutter 内独立命中区：点击 Git 标记打开 Diff，点击折叠标记执行折叠或展开，点击空白不触发动作。

### 语言选择器

- 状态条语言项可点击，打开语言菜单，选项为“自动（按扩展名）”与受支持语言。受支持语言为高亮映射中的编辑器语言与纯文本；Markdown 文件由 Markdown 面板承接，不作为编辑器手动选项。
- 手动选择语言后，语法高亮立即热切换，文本、光标、选区、滚动、撤销历史与脏状态保持不变。
- 手动覆盖是面板参数，随项目布局持久化：切换面板、切换项目与应用重启后保留；面板关闭后重开恢复为“自动（按扩展名）”。
- 手动覆盖只影响语法高亮，不修改文件内容、不修改扩展名、不改变保存行为或保存目标。
- 选择“自动（按扩展名）”恢复扩展名映射；此后路径或扩展名变化按新扩展名热切换语言。
- 手动覆盖后，文件重命名不自动清除覆盖，只有显式选择“自动”才恢复扩展名判定。
- 可编辑、只读浏览、根外只读与手动只读模式下均可用；错误态不显示状态条，因而不提供语言选择。

### 自动保存

- 设置中心外观页提供“自动保存”开关，默认关闭，全局生效。入口见 `settings.md`。
- 开启后，可编辑文档在停止输入 1 秒后若仍为脏则保存；每次文本修改重置计时。
- 焦点离开编辑器面板或窗口失焦时，若缓冲为脏且可保存，立即保存，不等待 1 秒。
- 关闭单个编辑器面板前，若缓冲为脏且自动保存开启，按 `../workspace/shell.md` 关闭守卫的自动保存例外先保存一次；保存成功则关闭，失败或进入保存冲突则保留面板并进入标准确认框。未开启自动保存时按标准关闭守卫执行。批量关闭、项目移除与窗口关闭按工作区聚合保存流程执行。
- 以下情形暂停自动保存：外部修改冲突横幅显示期间、保存冲突对话框打开期间、只读浏览、根外只读、手动只读、二进制或其他错误态。错误态没有缓冲，不产生保存请求。
- 保存冲突按显式保存的冲突流程处理：显示 `保存冲突` 对话框并暂停自动保存；用户取消后保留脏状态，自动保存在下一次文本修改后恢复。
- 自动保存失败沿用 `保存失败：<原因>` 提示并保留脏状态；暂停至下一次文本修改或手动保存，同一原因的连续失败合并显示，不按 1 秒周期重复弹错。
- 自动保存成功执行与显式保存相同的后续动作：清除脏状态、删除崩溃恢复备份、重算 Git 标记、通知侧栏与 Commit 视图刷新；不显示保存成功提示。
- 自动保存只作用于编辑器面板，不作用于 Markdown 源码态与 Diff；Diff 的保存行为见 `diff.md`。
- 自动保存开关本身不改变文件的编码、BOM、行尾与末尾换行策略。

### 查找与替换

- `Ctrl+F` 在编辑区顶部打开搜索面板，焦点进入搜索输入框；`Esc` 关闭搜索面板并把焦点返回编辑区。
- 搜索面板提供查找输入、替换输入、大小写敏感、整词匹配、正则表达式三个选项。默认大小写不敏感、整词关闭、正则关闭。
- 搜索为增量执行：输入变化后立即更新匹配高亮、当前匹配与计数 `当前/总数`；无匹配时显示 `无结果`。再次打开搜索面板时保留上次搜索词与选项。
- 当前匹配滚动到可见区域并高亮，其余匹配以弱高亮显示。
- 匹配导航：`Enter`、`F3` 或 `Ctrl+G` 跳到下一个；`Shift+Enter`、`Shift+F3` 或 `Ctrl+Shift+G` 跳到上一个；到达末尾后回绕。
- 替换行为：
  - `替换` 替换当前匹配并跳到下一个。
  - `全部替换` 先显示确认 `替换全部 N 处？`；确认后一次替换全部匹配。整个替换操作是单个撤销步骤，可一次撤销。
  - 正则替换支持捕获组引用；非法正则显示内联错误，不执行替换。
- 只读浏览、根外只读与手动只读模式提供查找，不提供替换。查找以流式扫描执行，显示进度与 `取消`。
- 跳转到行：`Ctrl+Alt+G` 打开行号输入，接受 1 起始的行号；越界时跳到首行或末行并提示实际范围。
- 搜索状态按面板保存：搜索词、选项、当前匹配位置与面板开关在切面板、切项目时保留；关闭面板重开与应用重启后重置。
- 搜索与跳转不修改文档内容，不改变脏状态。
- `Ctrl+F` 是编辑器保留键，任何用户快捷键覆盖都不能占用。搜索与跳转键由编辑器内部处理，不在快捷键设置中提供重绑。

### 保存、脏状态与关闭守卫

- 脏状态表示文档缓冲内容与最近一次成功载入或保存的磁盘内容不同。页签显示未保存圆点，渲染位置与样式由 `../workspace/shell.md` 统一。
- `Ctrl+S` 保存当前聚焦编辑器对应的文档；焦点不在任何编辑器时不派发。每项目每路径只有一个视图，保存直接作用于该文档缓冲。
- 保存为原子写，不做非原子降级；替换失败时保留原文件并显示错误。
- 保存保持当前选定的编码、BOM、行尾风格与末尾换行状态。
- 保存成功后清除脏状态，页签未保存圆点消失，对应崩溃恢复备份删除；重新计算 Git 变更标记；通过文件事件通知侧栏与 Commit 视图刷新，合并窗口约 300ms（设计契约）；若路径因另存为或重命名变化，更新页签标题与布局路径。不显示保存成功提示。
- 保存冲突：保存前比较磁盘版本（大小、修改时间、文件标识）与文档基线版本。磁盘版本已变化且缓冲为脏时，显示 `保存冲突` 对话框，正文说明磁盘文件已被外部修改；按钮为 `覆盖磁盘`、`另存为`、`取消`，默认焦点在 `取消`。
  - `覆盖磁盘`：以当前缓冲覆盖磁盘并清除脏状态。
  - `另存为`：进入另存为流程。
  - `取消`：不写盘，保留脏状态与缓冲。
  - 缓冲为干净时不进入保存冲突，按外部修改规则自动重载。
- 另存为使用系统文件对话框，默认目录为当前文件所在目录，默认文件名为当前文件名，筛选器为“所有文件”。用户显式选择的任意本地路径均允许写入，这是根外写入的唯一例外；另存为到项目根外后，该文档在当前运行期成为可编辑文档并保存到新路径；授权只绑定当前文档与当前运行期，不写入布局，重启后根外路径按根外只读重新判定。根外只读模式不提供另存为，文件已移出允许根的脱离缓冲提供另存为。成功后更新文档身份、路径、保存目标、页签标题与布局路径。
- 另存为目标路径已在该项目中打开时，显示 `目标文件已打开`，按钮为 `取消`、`替换`。替换后当前缓冲覆盖目标路径的既有文档，原目标视图关闭，当前视图迁移到该路径并进入脏状态，不静默丢弃。
- 保存时磁盘文件已不存在：显示 `文件已不存在` 对话框，按钮为 `另存为`（默认）、`保存到原路径（重新创建）`、`取消`。
- 保存失败（权限、磁盘满、文件被锁定、目标文件系统不支持原子替换）时显示 `保存失败：<原因>`，保留脏状态与缓冲，不刷新 Git 标记，不通知侧栏。
- 只读保存：只读浏览模式提示 `只读浏览模式不可保存`，根外只读模式提示 `根外只读模式不可保存`，手动只读提示 `手动只读模式不可保存`；均不写盘。
- 关闭守卫由 `../workspace/shell.md` 统一：关闭脏文档视图时显示单面板关闭确认，提供 `保存并关闭`、`丢弃并关闭`、`取消`。`保存并关闭` 先执行保存，成功后关闭；保存失败或进入保存冲突时保留面板、缓冲与脏状态，不关闭。自动保存开启时按工作区关闭守卫的自动保存例外执行。关闭项目、批量关闭与关闭窗口按工作区规则聚合确认。
- 关闭时首次保存进入保存冲突，不再弹普通关闭确认，直接显示保存冲突对话框；`覆盖磁盘`/`另存为` 成功后关闭，`取消` 中止关闭并保留脏状态。批量、项目移除或窗口关闭保存全部遇冲突时中止批量并提示冲突文件，不在模态内嵌套模态。
- 终端、GitShow 与根外只读视图无脏状态，不呈现 `保存并关闭`；文件已移出允许根的脱离缓冲可脏，关闭时进入关闭守卫，`保存并关闭` 通过另存为完成。

### 手动只读

- 状态条提供锁按钮。仅当运行模式为可编辑且缓冲干净时允许开启；缓冲为脏时按钮不可用，并提示 `保存或撤销后才能开启手动只读`。
- 开启后不可编辑、不可保存、不提供替换；状态条只读原因显示 `手动只读`，锁按钮呈开启状态。
- 查找、代码折叠、语言选择、选区复制、字号调整、自动换行与 Git 标记保持可用；点击 Git 标记仍可在 Diff 面板打开差异。
- 按 `Ctrl+S` 提示 `手动只读模式不可保存`，不写盘。
- 自动保存暂停；重新开启编辑后，在下一次文本修改时恢复自动保存计时。
- 再次点击锁按钮关闭手动只读，恢复自动判定：路径与大小允许时回到可编辑，否则保持对应的自动只读模式。
- 手动只读不覆盖大文件只读、根外只读与二进制错误态等自动判定；自动判定为只读时锁按钮不可用，不能借此获得编辑或保存能力。
- 手动只读不改变文档内容与脏状态，不进入撤销历史。
- 手动只读是运行期面板状态：切换面板、切换项目时保留；关闭面板重开或应用重启后重置，不随布局持久化。

### 外部修改

编辑器对已打开文档持续感知磁盘变化，通道为：

- 项目范围的文件监听器，覆盖项目根内文件；通过另存为、Commit 视图或根外链接打开的项目根外文件监听其父目录。
- 应用窗口重新获得焦点时，对全部已打开文档做一次版本复核，按约 1s（设计契约）节流。
- 面板激活时对当前文档做一次版本复核。
- 监听事件积压时，对全部已打开文档执行一次全量复核。

版本基线由文件大小、修改时间与文件标识组成。自身保存产生的文件事件按写入后版本匹配并忽略，不保留按路径的长期抑制条目。

- 干净文档被外部修改：自动重载磁盘内容，按行锚点尽量保持光标与滚动位置，显示约 2s（设计契约）的轻量提示 `已从磁盘重新加载`，不弹模态框。
- 脏文档被外部修改：在编辑区顶部显示非模态冲突横幅 `文件已被外部修改`，按钮为 `重载`、`保留我的修改`、`查看差异`。横幅不抢焦点，以提醒语义暴露给用户。
  - `重载`：读取磁盘并整体替换缓冲，清除脏状态与撤销历史，更新基线。
  - `保留我的修改`：保留缓冲与脏状态，关闭横幅；磁盘内容再次变化时重新显示。之后保存按保存冲突规则处理。
  - `查看差异`：在 Diff 面板以只读冲突快照模式打开当前磁盘版本与当前缓冲的差异并定位到首个差异块；两侧只读、不可保存，快照不属于项目文件，不进入文件打开路由，关闭 Diff 面板或冲突消解后清理。查看差异不改变冲突状态、缓冲与脏状态。Diff 契约见 `diff.md`。
- 外部修改使文件超过可编辑上限而文档为脏：保留可编辑缓冲，显示横幅 `文件已超过可编辑上限，保存后重新打开将进入只读浏览`，允许继续编辑与保存。
- 外部修改使文件超过可编辑上限而文档为干净：切换到只读浏览模式，保留顶部可见行。
- 外部删除文件：显示横幅 `文件已从磁盘删除`，按钮为 `另存为`、`保存到原路径（重新创建）`、`关闭`。缓冲保留；保存到原路径时重新创建文件。只读浏览模式、根外只读模式与手动只读模式仅提供 `重试` 与 `关闭`，不提供保存动作。
- 外部重命名且监听器提供旧路径到新路径映射：跟随重命名，不弹确认；新路径在允许根外时进入“文件已移出允许根”的脱离状态；新路径已打开时按 `目标文件已打开` 处理。
- 外部修改与保存并发：保存前检查版本，写入完成前再次检查目标版本；版本变化则中止本次保存并进入保存冲突，不写入半新半旧内容。
- 重载读取失败：显示非模态横幅 `无法读取外部修改`，按钮为 `重试`、`保留当前内容`；不静默丢弃错误，也不自动清空缓冲。
- 只读浏览、根外只读与手动只读模式的外部修改：文件事件命中后立即重新读取；窗口聚焦与面板激活复核以大小、修改时间与文件标识判断是否变化。内容刷新时更新信息条并尽量保持顶部行，全过程静默，不弹确认；读取失败时保留最后一次成功内容并显示轻量错误提示。
- 冲突状态属于文档：横幅在文档唯一视图的编辑区顶部显示，页签按工作区规范显示冲突提示点。

### 大文件分级

本节阈值只属于编辑器；Diff 与 GitShow 使用各自规格定义的阈值，不引用本节数值。

文件打开前读取元数据取得真实字节数，按大小选择运行模式：

| 字节数 | 模式 | 用户反馈 |
|---|---|---|
| ≤ 10,000,000 | 可编辑 | 无提示 |
| 10,000,000 < 字节数 ≤ 50,000,000 | 可编辑 | 非阻塞提示 `已打开大文件（约 X MB），编辑与补全可能降速`，约 5s（设计契约）后自动消失 |
| > 50,000,000 | 只读浏览 | 顶部信息条，不弹确认 |

- 上述阈值均为设计契约。恰好 50,000,000 字节仍可编辑；50,000,001 字节进入只读浏览。
- 根外只读模式不受可编辑阈值影响：文件即使不超过 50,000,000 字节也保持只读；超过 200,000,000 字节时同样关闭语法高亮。
- 超过 10,000,000 字节时关闭自动补全；大文件提示不阻塞输入，提示消失不改变模式。
- 可编辑大文件使用虚拟化渲染与按需载入，界面只渲染可见行；编辑、撤销与保存保持目标性能。
- 只读浏览模式：
  - 顶部信息条固定可见、不随内容滚动，文字不可选中；显示 `只读浏览（<大小>），可编辑上限 50MB`。
  - 支持行号、当前行高亮、选区、复制、查找、自动换行、代码折叠与字号调节。
  - 语法高亮按可见区域惰性计算；文件超过 200,000,000 字节（设计契约）时关闭语法高亮，信息条追加 `已关闭语法高亮以保持流畅`。
  - 不显示 Git 变更标记栏；不提供编辑、撤销、替换或保存。
  - 固定按可见窗口虚拟化渲染，不整份载入编辑缓冲；滚动与查找不阻塞编辑区交互，查找显示进度与 `取消`。
  - 字号与行高跟随全局编辑器字号，`Ctrl+滚轮` 同样生效。
  - 部分内容读取失败时，已成功读取的内容继续显示，信息条显示 `部分内容读取失败`；失败区域以空白占位，不阻塞其他区域滚动。
- 大小展示规则（设计契约）：小于 10MB 时显示一位小数 MB；10MB 到 1000MB 显示整数 MB；1000MB 及以上显示一位小数 GB；元数据读取失败时显示 `…`。
- 元数据读取失败时不建立正文基线；外部修改复核在窗口聚焦或面板激活时重试元数据。
- 运行模式在以下时机重新判定：打开、外部修改导致大小变化、关闭后重开、应用重启。
- 可编辑文件因外部修改增长超过 50,000,000 字节且缓冲干净时，自动切换到只读浏览并保留顶部行；缓冲为脏时保持可编辑并显示横幅。
- 只读文件因外部修改缩小到 50,000,000 字节及以下时，自动切换到可编辑模式并保留顶部行。
- 自动保存在大文件只读时暂停；大文件可编辑时仍按自动保存规则执行。
- 手动只读不能把只读浏览文件切换为可编辑。

### Git 行标与 gutter Diff

- 编辑区行号右侧有固定 9px（设计契约）宽的 Git 变更标记栏；无标记时也保留宽度，文本不因标记出现或消失而横向移动。
- 标记表达工作区内容与 HEAD 的差异，不表达暂存区状态：
  - 新增行：实心竖条，颜色取自主题的新增语义色。
  - 修改行：空心竖条，颜色取自主题的修改语义色。
  - 删除：向上三角，颜色取自主题的删除语义色，显示在删除位置相邻的行上。
- 差异块计算规则：
  - 纯新增块：新增的每一行显示新增标记。
  - 纯删除块：在删除位置相邻的行显示删除标记；删除位置在文件末尾时显示在最后一行。
  - 修改块：新旧行数取较小值，逐行显示修改标记；新文件行数更多时，多出的行显示新增标记；旧文件行数更多时，在块末显示删除标记。
- 新增、修改、删除同时以形状区分，不单独依赖颜色传达含义。
- 标记在以下时机异步重算：文件打开、保存成功、外部重载、撤销或重做，以及最后一次编辑后约 300ms（设计契约）的防抖窗口。
- 编辑过程中标记随文本位置即时平移；防抖重算完成后与当前内容一致。大量编辑期间允许短暂滞后，不长期保持过期状态。
- 非 Git 仓库、无法确定仓库根、Git 读取失败时不显示标记，也不弹错误提示；下一次触发时自动重试。
- 单击某行的 Git 标记（新增、修改、删除均可），在 Diff 面板打开该文件并定位到对应差异块；删除标记定位到删除行所属差异块。编辑器面板与缓冲不关闭。标记栏空白区域点击不触发，不提供悬停菜单。Diff 的打开入口与行为见 `diff.md`。
- 只读浏览模式与根外只读模式不显示 Git 变更标记栏；手动只读仍显示标记栏，并可经标记打开 Diff。
- 标记颜色来自主题语义 token，不硬编码；主题切换时颜色即时更新，形状与位置不变。

### 字号与自动换行

- 编辑器字号是全局设置，所有编辑器面板（含只读浏览、根外只读与手动只读）共享同一值。默认 14px，可调范围 8–32px（设计契约）。
- 在编辑区按住 `Ctrl` 滚动滚轮：上滚放大 1px，下滚缩小 1px；到达边界后不再变化。非修饰键滚轮保持正常滚动。
- 字号变化只重配显示，不重建文档缓冲，不丢失文本、光标、选区、滚动或撤销历史。
- 字号变化后约 2s（设计契约）写入应用设置；重启后恢复保存值。加载时越界值收拢到 8–32，非法值回退 14；设置文件损坏时按应用统一策略提示 `配置已损坏，已回退默认值`，字号使用 14。
- 字号持久化失败时提示 `设置保存失败，重启后将丢失`。
- 行高为字号的 1.5 倍（设计契约），四舍五入到整数像素。
- 终端字号与编辑器字号相互独立。
- 自动换行按面板独立，默认关闭；关闭时长行不换行并出现横向滚动，开启时在视口宽度处软换行，长单词按字符断开。
- `Alt+Z` 切换当前聚焦编辑器的自动换行；只改变显示，不修改内容、不改变脏状态。只读浏览、根外只读与手动只读同样可用。
- 自动换行状态在切面板、切项目时保留，并随项目布局持久化到应用重启；面板关闭后重开恢复为设置中的默认值，新建面板采用该默认值（默认关闭）。
- `Alt+Z` 是快捷键设置中的可重绑命令，默认 `Alt+Z`，可解绑；没有聚焦编辑器时不生效。
- 设置中心外观页提供编辑器字号数值输入与步进（8–32px），以及“新面板默认换行”开关；默认值只影响之后打开的编辑器面板，已有面板保持自身换行状态。入口契约见 `settings.md`。

### 主题与配色

- 编辑器背景、正文、选区、当前行、搜索匹配、Git 标记、折叠标记、冲突横幅与错误态颜色全部来自主题语义 token；应用仅提供暗色方案，禁止硬编码颜色。
- 主题在运行期切换时，所有已打开编辑器立即使用新配色，不重建缓冲、不改变内容、不改变脏状态、不触发保存。
- 未打开的编辑器在下次打开时使用当时激活的主题。
- 主题切换入口与配色方案定义见 `settings.md`；编辑器只消费语义 token。
- 语法高亮颜色与 Git 标记颜色使用主题语义 token；删除、新增、修改的区分同时依赖形状，不依赖对比度准入校验。

### 页签标题

- 编辑器页签标题默认显示文件名。
- 同一项目内打开多个同名但路径不同的文件时，相关标题改为相对项目根的路径；路径不在项目根下时使用规范化绝对路径，根外只读视图同样如此。路径分隔符统一显示为 `/`。
- Agent 全局文件面板的标题不适用本节规则，由 `../sidebar/agent-files.md` 定义；工作区壳与编辑器不覆盖该例外。
- 未保存状态只用页签圆点表达，不在标题文本中追加 `*`、`(未保存)` 等文字；只读状态也不写入标题。
- 另存为、文件重命名、关闭同名冲突视图后，按当前项目内全部编辑器视图重新计算标题。
- 布局只保存文档路径，不保存标题文本；恢复时按路径重新计算。
- HTML 文件的标题规则与普通编辑器一致。

### 焦点与键盘

- 焦点层级为：活跃项目 → 聚焦面板组 → 激活面板 → 面板内输入区，详见 `../workspace/shell.md`。
- 显式打开（文件浏览器、Commit 视图、Markdown 链接、拖放）或显式激活（点击页签、切换到该面板）编辑器时，焦点进入编辑区，可直接键入；只读浏览、根外只读与手动只读模式下焦点进入只读查看器，支持键盘滚动、选择与查找。布局恢复不抢焦点，也不使只读视图自动获得焦点。
- 点击编辑区文本位置，焦点进入编辑区并定位光标。
- `Ctrl+F` 打开搜索面板后焦点进入搜索输入框；`Esc` 关闭并返回编辑区。焦点位于搜索输入框或冲突横幅按钮时仍属于当前编辑器面板，`Ctrl+S` 仍作用于该文档。
- 冲突横幅出现时不抢焦点；用户可用键盘聚焦横幅按钮并执行重载、保留或查看差异。
- 编辑器内 `Tab` 插入缩进，不移动焦点；`Ctrl+Tab` / `Ctrl+Shift+Tab` 为工作区焦点逃逸键，焦点在编辑器内时仍生效，按活跃项目各面板组的面板顺序循环。
- 编辑器快捷键：

- HTML 悬浮按钮可通过键盘聚焦与触发。

### 轻量状态条

- 状态条固定在面板底部，横跨面板宽度，不随编辑区滚动；仅在文档成功载入的可编辑、只读浏览、根外只读与手动只读模式显示，错误态不显示。
- 从左到右显示：语言、编码（含 BOM 信息）、行尾（CRLF/LF）、只读原因；右侧显示手动只读锁按钮。
- 语言项可点击，按“语言选择器”执行；手动覆盖时显示所选语言并标注“手动”，自动模式显示按扩展名判定的语言。
- 编码项点击打开编码菜单：列出 UTF-8、带 BOM 的 UTF-8、UTF-16 LE/BE 与检测出的常见本地编码；选择编码执行 `以编码重新打开`。缓冲为脏时先确认丢弃本地修改；重读成功后更新编码、缓冲与状态条，重读失败保留原缓冲并提示。
- 行尾项点击在 CRLF 与 LF 之间切换；切换覆盖文件首个行尾推断，按一次文档修改计入脏状态，保存时按选定行尾写入，不立即改写编辑缓冲。
- 只读原因项只展示：只读浏览显示 `只读：文件超过 50MB`，根外只读显示 `项目根外`，手动只读显示 `手动只读`。
- 锁按钮按“手动只读”执行；自动判定为只读时按钮不可用，状态条仍显示自动只读原因。
- 状态条文本使用主题语义 token，用户可见；点击区域有标签，键盘可聚焦并触发。
- 状态条不提供保存、Git 分支或光标位置信息。

### 崩溃恢复备份

- 自动保存是可选写盘行为，不替代崩溃恢复备份。为防止进程崩溃、断电或强制结束导致未保存内容丢失，对脏的可编辑文档周期性写入恢复备份；备份只存在由应用托管的恢复存储，绝不自动写回项目文件。
- 恢复备份只包含文档文本、编码、BOM、行尾、保存目标路径与快照时间；不包含凭据、终端输出或剪贴板。备份仅存在由应用托管的恢复存储，绝不自动写回项目文件。不备份干净文档、只读浏览文档、根外只读文档、手动只读文档与错误态；文件已移出允许根的脏脱离缓冲仍备份。
- 快照时机：脏缓冲自最后一次修改起约 2s（设计契约）写入一次；持续编辑时刷新间隔最长 30s（设计契约）。备份失败不阻塞编辑，按应用统一错误策略提示一次并继续重试。
- 恢复存储配额：单文件文本上限 64 MiB，总配额 256 MiB，保留 7 天；超出总量按快照时间从旧到新淘汰，不淘汰当前面板最新快照；单文件超限不写快照并提示一次。快照键为 `(ProjectId, PanelId)`；项目移除时删除该项目全部快照。
- 文档保存成功、撤销回干净状态、关闭文档或正常退出应用后删除对应备份；正常退出前按工作区关闭守卫处理全部脏文档，退出完成后恢复区为空。
- 下次启动时若发现恢复备份，显示恢复提示，逐项列出所属项目、路径与快照时间，提供 `恢复` 与 `丢弃`；另提供 `全部恢复` 与 `全部丢弃`。
  - `恢复`：在所属项目中创建编辑器视图并载入备份文本，标记为脏，保存目标为备份记录的路径；恢复不写盘。若磁盘文件已不存在，保留缓冲并在保存时进入 `文件已不存在` 流程；若磁盘内容与备份时不同，显示冲突横幅。
  - `丢弃`：删除该备份，不改变磁盘文件；若布局同时恢复了该路径，按磁盘内容重新读取。
  - 恢复提示未处理前不自动载入任何备份内容，也不得以备份覆盖布局中的磁盘内容。
- 备份所属项目已不存在时，恢复到当前活跃项目；无活跃项目时提示 `请先创建项目` 并保留备份，不静默丢弃。
- 恢复备份不恢复光标、选区、滚动、搜索状态或撤销历史；恢复后的文档按当前磁盘内容重新建立外部修改基线。
- 恢复区中的备份不参与文件打开路由、去重、搜索与 Git 标记计算，直到用户选择恢复。
- 设置中心不设独立编辑器页：编辑器字号、自动保存与新面板默认换行由外观页承载；入口契约见 `settings.md`。

### 与 Diff、GitShow 的边界

- 编辑器面板与 Diff、GitShow 面板互不替代：打开 Diff 或 GitShow 不关闭、不替换编辑器；打开编辑器不关闭 Diff 或 GitShow。
- 语言高亮映射、主题语义 token 与外部修改处理约定由本文定义，Diff 与 GitShow 引用；文件大小阈值只属于编辑器，Diff 与 GitShow 使用各自规格定义的阈值。
- 编辑器不提供内嵌差异预览，也不提供版本历史；单击 Git 标记在独立 Diff 面板打开差异，不构成内嵌预览。
- Diff 工作区侧的脏状态与关闭守卫按工作区统一规则；GitShow 无脏状态。两者与编辑器文档缓冲不共享内容。
- 自动保存不作用于 Diff；Diff 的保存冲突与状态持久化见 `diff.md`。

### 文件系统与平台约束

- 应用面向 Windows 10/11，单窗口、仅暗色模式。
- 路径同时接受 `/` 与 `\` 作为分隔符；身份比较忽略大小写；支持长路径、UNC 路径与网络驱动器，但仅在允许根内可用。
- 符号链接与目录联接按真实目标建立文档身份；Markdown 链接解析后的真实目标位于项目根外时，仅以根外只读模式显式打开，不获得编辑或写入能力。
- 文件被其他程序独占锁定时，读取或保存失败按错误态处理，提供重试与用系统默认程序打开；不静默重试覆盖。
- 网络驱动器上的文件监听可能不可靠；以窗口聚焦复核与面板激活复核兜底。网络文件系统不支持原子替换时，保存失败并提示，不降级为非原子写。
- `用系统默认程序打开` 使用操作系统文件关联，路径作为单个参数传递，不经过命令解释器；无关联或文件不存在时显示错误提示。
- 外部修改检测的正常目标时延为 1s 以内（设计契约）；监听器不可用时，最迟在窗口重新聚焦或面板激活时感知。

## 交互规则

### 入口、出口与状态迁移

| 操作 | 结果 |
|---|---|
| 文件浏览器双击或 `Enter` | 按路由创建或聚焦面板；焦点进入编辑区或只读查看器 |
| 从文件浏览器拖文件到编辑器面板组 | 目标面板组高亮；释放后按路由打开或聚焦，不替换脏面板 |
| Commit 视图双击 added/untracked | 按路由分派；编辑器按每项目每路径唯一视图创建或聚焦，不追加后缀 |
| Markdown 链接点击 | 按路由在所属项目内打开；根外链接以根外只读模式打开并标注 `项目根外` |
| 启动时存在恢复备份 | 显示恢复提示；选择恢复进入脏态且不写盘，选择丢弃按磁盘内容处理 |
| 点击编辑器页签 | 激活面板、聚焦面板组、焦点进入编辑区或只读查看器 |
| `Ctrl+W`、页签关闭按钮、中键点击页签 | 按工作区关闭流程执行；关闭脏文档视图触发确认，可选择 `保存并关闭` |
| `Ctrl+S` | 可编辑且非手动只读时保存；只读时提示不可保存；无聚焦编辑器时不派发 |
| `Ctrl+F` | 打开搜索面板并聚焦输入框 |
| `Esc` | 关闭搜索面板并返回编辑区；未打开搜索时不消费 |
| `Alt+Z` | 切换当前编辑器自动换行 |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | 折叠或展开当前块 |
| `Ctrl+Alt+[` / `Ctrl+Alt+]` | 全部折叠或全部展开 |
| 外部修改（干净） | 自动重载并显示短暂提示 |
| 外部修改（脏） | 显示冲突横幅；可重载、保留或查看差异 |
| 外部删除 | 显示删除横幅；缓冲保留 |
| 保存冲突 | 保存冲突对话框；取消为默认动作 |
| 另存为成功 | 文档身份与标题更新，布局路径更新 |
| 文件重命名被感知 | 路径、标题更新；跨类别时面板类型转换 |
| 文件读取失败 | 错误态面板；提供重试与外部打开 |

- 状态迁移：`打开中 → 可编辑 / 只读浏览 / 根外只读 / 错误态`；`可编辑 + 外部移出允许根 → 文件已移出允许根`；`干净 ⇄ 脏`；`干净 + 外部变化 → 自动重载`；`脏 + 外部变化 → 冲突横幅 → 重载 / 保留 / 查看差异`；`脏 + 保存 → 保存成功 / 保存冲突 / 保存失败`；`可编辑 + 手动只读开启 ⇄ 手动只读关闭`。
- 错误态面板保留文件路径与页签，不自动关闭；重试成功后原位进入可编辑、只读浏览或根外只读模式。
- 只读浏览与可编辑模式之间切换不改变面板身份、页签位置或焦点归属；切换后保持顶部可见行。

### 鼠标与键盘

- 双击文件行与 `Enter` 等价；单击只选择，不打开。
- 编辑器内单击定位光标；拖动选择文本；双击选中词；三击选中行。只读浏览、根外只读与手动只读同样支持选择与复制。
- `Ctrl+滚轮` 调整全局编辑器字号，仅在指针位于编辑区时生效。
- 搜索面板内 `Enter` / `Shift+Enter` 导航匹配；`Tab` 在输入框与选项之间移动焦点；`Esc` 关闭。
- 冲突横幅按钮按 `Tab` 可达；`Enter` 或空格触发；横幅出现不改变当前文本输入焦点。
- 只读查看器支持方向键、`PageUp` / `PageDown`、`Home` / `End` 滚动；`Ctrl+C` 复制选区。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 在编辑器内由工作区处理，焦点离开编辑器并循环到相邻面板；编辑器保留文本、脏状态与光标。
- 代码折叠标记与 Git 标记可仅用鼠标点击触发；键盘用户使用折叠快捷键与 Diff 快捷键。
- 不提供编辑器自定义右键菜单；使用系统标准文本编辑菜单。
- HTML 悬浮按钮可点击或键盘触发，打开磁盘版本，不触发保存或确认。

### 反馈与对话框

- 信息提示：打开大文件提示约 5s（设计契约）自动消失；外部干净重载提示约 2s（设计契约）；均为非阻塞。
- 错误提示：保存失败、设置保存失败、用系统默认程序打开失败使用错误提示，持续到用户关闭或约 8s（设计契约）；同一原因的重复错误合并显示。
- 冲突横幅：非模态、位于编辑区顶部、不遮挡当前行；冲突状态属于文档，`查看差异` 打开冲突快照 Diff，不改变缓冲。
- 模态对话框仅用于：保存冲突、另存为目标已打开、文件已不存在、全部替换确认、崩溃恢复提示。
- 对话框默认焦点放在安全动作：保存冲突默认 `取消`，全部替换默认 `取消`，文件已不存在默认 `另存为`，崩溃恢复提示默认 `恢复`。
- 任何错误都不清空缓冲、不自动关闭面板、不静默改写磁盘。

## 边界与错误

### 空、加载与读取

- 空文件：可编辑空白区域，光标位于首行，不显示占位文字；保存空文件写入 0 字节。
- 文件读取超过 150ms（设计契约）显示加载指示；超过 10,000,000 字节（设计契约）显示进度。加载期间不显示旧文件内容。
- 文件不存在、路径失效、无读取权限：错误态面板，显示路径与原因，提供 `重试`、`用系统默认程序打开`。
- 非 UTF-8 且无 BOM 的文本先尝试常见本地编码检测；检测成功则按检测编码打开，检测失败进入错误态，提供 `以编码重新打开` 与 `用系统默认程序打开`。非法 UTF-16 与二进制文件进入错误态，不创建可编辑缓冲，不允许保存。
- 元数据读取失败：不进行大小门控，直接进入错误态。
- 文件在打开过程中增长并越过可编辑上限：读取完成后重新判定；可编辑缓冲尚未建立时直接进入只读浏览。
- 文件在打开过程中被删除或替换：以最后一次成功读取的版本为准；若版本已不一致，进入外部修改流程。

### 外部修改、保存与并发

- 干净文档的外部修改自动重载；重载失败显示可重试横幅，保留当前内容。
- 脏文档的外部修改显示横幅；用户保留后再次保存时，磁盘版本仍不同则进入保存冲突。
- 外部修改连续发生：冲突横幅保持显示，重载总是读取最新磁盘版本；保留动作只关闭当前横幅，下一次变化重新显示。
- 保存与外部写入并发：保存前与写入完成前均检查版本；版本变化则中止保存并进入保存冲突；不允许静默覆盖。
- 自身保存事件按写入后版本匹配忽略；匹配失败时按普通外部事件处理，宁可多一次重载提示，不吞掉真实修改。
- 文件被外部删除后保存：按 `文件已不存在` 对话框处理，不静默重建。
- 文件被重命名到写入允许根外：若监听器报告映射，跟随并更新路径，同时进入“文件已移出允许根”的脱离状态、保留缓冲与脏状态并禁用原地保存；未报告时，保存前发现路径不存在，进入 `文件已不存在` 流程。
- 同一路径在同一项目内只有一个视图与一个文档缓冲；重复打开只聚焦已有视图，不复制全文或撤销历史。
- 同一路径在多个项目中打开：独立文档缓冲；一侧保存后另一侧按外部修改处理，不静默覆盖。
- 另存为目标路径已打开：必须显式确认替换；不静默丢弃目标文档。
- 监听器溢出或不可用：执行全量复核；网络驱动器以窗口聚焦复核兜底。
- 目标文件系统不支持原子替换：保存失败；不回退为原地截断写。
- 自动保存开启时，外部冲突、保存冲突、只读与手动只读期间不写盘；恢复可保存状态后，在下一次文本修改时重新计时。

### 大文件与性能

- 打开 10,000,000 字节文件不提示，直接可编辑；打开 50,000,000 字节文件可编辑并显示大文件提示；50,000,001 字节进入只读浏览。
- 只读浏览按可见窗口渲染，滚动不得触发整文件读入内存；查找以流式扫描执行，可取消。
- 只读文件超过 200,000,000 字节时关闭语法高亮，信息条说明原因。
- 只读文件因外部修改缩小到可编辑范围时自动切回可编辑；可编辑文件增长超过上限时按脏状态决定保留或切换。
- 多编辑器同时打开时，每个文档的文本、编码、行尾与撤销历史独立维护，切面板或切项目不复制、不丢失。
- 大文件提示不阻塞输入；提示消失不改变模式。
- 性能目标（设计契约，本机 SSD）：≤10,000,000 字节文件从打开到可编辑不超过 300ms；50,000,000 字节只读文件首次可见不超过 1s；滚动与输入不因后台 Git 计算或语法计算卡顿。
- 文件监听事件风暴按约 300ms（设计契约）合并；Git 重算与语法高亮不阻塞编辑区交互。

### 只读与手动只读

- 只读浏览、根外只读与手动只读均不写盘；`Ctrl+S` 分别提示对应的不可保存原因。
- 文件已移出允许根的脱离缓冲：`Ctrl+S` 打开另存为；取消则不保存并保留脏状态。
- 只读浏览与根外只读不提供替换；查找、复制、自动换行、代码折叠与字号调整可用。
- 根外只读不提供另存为，不显示 Git 标记；只读浏览不显示 Git 标记。
- 手动只读仅在自动判定为可编辑且缓冲干净时可开启；脏缓冲、只读浏览、根外只读与错误态均不可开启。
- 手动只读关闭后恢复自动判定；自动判定为只读时不能通过关闭手动只读获得编辑能力。
- 手动只读不随布局持久化；关闭面板重开或应用重启后重置。
- 只读文件因外部修改缩小到可编辑范围时，只读浏览自动切回可编辑；根外只读保持根外只读。
- 只读浏览与根外只读的文件外部变化时静默刷新；读取失败保留最后一次成功内容并显示轻量错误提示。

### 平台与文件系统

- 仅 Windows 10/11；路径大小写不敏感；长路径、UNC、网络驱动器与符号链接按文件系统与平台约束处理。
- 文件锁、权限、磁盘满、只读介质、杀毒软件占用均以可见错误呈现，不静默失败。
- `用系统默认程序打开` 依赖操作系统文件关联；无关联、文件已删除或关联程序启动失败时提示错误，不阻塞编辑器。
- HTML 悬浮按钮不保存、不提示未保存修改，始终打开磁盘版本。
- 正常退出后应用重启不恢复未保存内容；异常退出按崩溃恢复备份提示恢复或丢弃。退出前的脏文档按工作区关闭守卫处理。
- 单窗口、仅暗色模式；不提供多窗口共享同一文档视图。

## 验收判据

### 打开路由与单一视图

- **Given** 活跃项目中存在 `a.txt`，**When** 双击该文件，**Then** 创建编辑器面板，页签显示 `a.txt`，内容与磁盘一致，焦点进入编辑区。
- **Given** `a.txt` 已打开，**When** 再次双击，**Then** 聚焦已有面板，不新增面板。
- **Given** `a.md` 文件，**When** 双击，**Then** 打开 Markdown 面板而不是编辑器。
- **Given** `a.html` 文件，**When** 双击，**Then** 打开编辑器并显示源码，右上角出现 HTML 悬浮按钮，不出现渲染视图。
- **Given** Commit 视图中 added 文件 `a.ts`，**When** 双击，**Then** 页签标题为 `a.ts`，不追加来源后缀；再次双击聚焦同一视图。
- **Given** 同一文件已有普通编辑器，**When** 从 Commit 视图打开 added 文件，**Then** 聚焦已有编辑器视图，不新增视图，脏状态保持不变。
- **Given** 同一路径在两个项目中打开，**When** 在一个项目中编辑，**Then** 两个项目各自保留独立缓冲，互不共享。
- **Given** 没有活跃项目，**When** 触发打开请求，**Then** 不创建面板并提示 `请先创建项目`。
- **Given** 布局中保存的文件已被删除，**When** 应用重启，**Then** 编辑器面板恢复并显示错误态，提供重试，不自动关闭。
- **Given** 文件无读取权限，**When** 打开，**Then** 显示错误态与原因，提供 `重试` 与 `用系统默认程序打开`，不创建可编辑占位缓冲。

### 根外只读与 HTML

- **Given** Markdown 面板中的相对链接指向项目根外本地文件，**When** 用户显式点击，**Then** 编辑器以根外只读模式打开并标注 `项目根外`；文件不因该打开动作加入文件浏览器、Commit 视图与终端目录。
- **Given** 根外只读文件已打开，**When** 按 `Ctrl+S`，**Then** 不写盘并提示 `根外只读模式不可保存`。
- **Given** 项目根外文件小于 50,000,000 字节，**When** 经 Markdown 链接显式点击，**Then** 仍以根外只读模式打开，不转为可编辑。
- **Given** HTML 文件存在未保存修改，**When** 点击右上悬浮按钮，**Then** 不提示、不保存，直接用系统默认程序打开磁盘版本，编辑器脏状态保持。
- **Given** HTML 文件被重命名为 `.txt`，**When** 重命名被感知，**Then** HTML 悬浮按钮隐藏；反向重命名后重新显示。
- **Given** 非 HTML 文件，**When** 打开编辑器面板，**Then** 不显示 HTML 悬浮按钮。

### 保存、关闭与自动保存

- **Given** 文档有未保存修改，**When** 按 `Ctrl+S`，**Then** 磁盘内容更新，脏圆点消失，无成功提示，Git 标记重算，侧栏刷新。
- **Given** 保存失败（磁盘满、权限或文件锁定），**When** 操作完成，**Then** 显示 `保存失败：<原因>`，缓冲与脏状态保留，Git 标记与侧栏不刷新。
- **Given** 文档脏，**When** 选择 `保存并关闭`，**Then** 保存成功后关闭；保存失败或进入保存冲突时面板、缓冲与脏状态保留，不关闭。
- **Given** 文档脏且磁盘已被外部修改，**When** 按 `Ctrl+S`，**Then** 显示 `保存冲突`，默认焦点在 `取消`；选择 `覆盖磁盘` 后写盘并清脏，选择 `取消` 后不写盘且保留脏状态。
- **Given** 保存时原文件已被删除，**When** 按 `Ctrl+S`，**Then** 显示 `文件已不存在`，默认动作为 `另存为`，不静默重建。
- **Given** 另存为到新路径成功，**When** 保存完成，**Then** 页签标题、文档身份与布局路径更新；重启后按新路径恢复，根外路径按根外只读重新判定，不保留写授权。
- **Given** 另存为到已打开路径，**When** 确认替换，**Then** 目标文档被当前缓冲覆盖并进入脏状态，不静默丢弃。
- **Given** 自动保存开关默认关闭，**When** 编辑后停止输入 1 秒，**Then** 不自动写盘。
- **Given** 开启自动保存，**When** 编辑后停止输入 1 秒，**Then** 自动保存，脏状态清除，对应崩溃恢复备份删除。
- **Given** 开启自动保存且缓冲为脏，**When** 焦点离开编辑器面板或窗口失焦，**Then** 立即保存，不等待 1 秒。
- **Given** 开启自动保存，**When** 关闭脏编辑器面板，**Then** 先立即保存，成功后关闭；保存失败或保存冲突时保留面板与脏状态。
- **Given** 自动保存开启且出现外部冲突横幅、只读或手动只读，**When** 等待超过 1 秒，**Then** 不写盘。
- **Given** 自动保存失败，**When** 失败发生，**Then** 显示保存失败提示并保留脏状态；不按 1 秒周期重复弹错，下一次文本修改后重试。
- **Given** Diff 面板存在脏修改，**When** 自动保存开启并停止输入，**Then** 自动保存不作用于 Diff。
- **Given** 编辑文件但不保存，**When** 同一面板组切到其他面板再切回，**Then** 文本、脏状态、光标与撤销历史保留。
- **Given** 编辑文件但不保存，**When** 切换到其他项目再切回，**Then** 文本、脏状态、光标与撤销历史保留。

### 编码、大文件与只读

- **Given** GBK 编码且无 BOM 的文本文件，**When** 打开，**Then** 按检测出的编码解析并可编辑，状态条显示该编码；保存按该编码写回。
- **Given** 已打开的文本文件，**When** 从状态条选择其他编码执行 `以编码重新打开`，**Then** 按新编码重读并更新缓冲与状态条；缓冲为脏时先确认丢弃本地修改。
- **Given** 打开二进制文件，**When** 读取完成，**Then** 显示二进制错误态，不出现可编辑文本，提供 `用系统默认程序打开`。
- **Given** 打开 10,000,000 字节文件，**When** 打开完成，**Then** 可编辑，不显示大文件提示。
- **Given** 打开 30,000,000 字节文件，**When** 打开完成，**Then** 可编辑，显示约 5s 的非阻塞大文件提示；自动补全关闭。
- **Given** 打开 50,000,001 字节文件，**When** 打开完成，**Then** 进入只读浏览，信息条显示 `只读浏览（<大小>），可编辑上限 50MB`，无可编辑光标。
- **Given** 只读文件超过 200,000,000 字节，**When** 打开，**Then** 语法高亮关闭，信息条说明原因，滚动仍可用。
- **Given** 只读浏览模式，**When** 按 `Ctrl+F`，**Then** 可查找并显示进度与取消，不提供替换。
- **Given** 只读文件外部修改后缩小到可编辑范围，**When** 变化被感知，**Then** 自动切回可编辑，保留顶部行。
- **Given** 可编辑文件外部修改后增长超过 50,000,000 字节且缓冲干净，**When** 变化被感知，**Then** 切换到只读浏览并保留顶部行。
- **Given** 缓冲干净且自动判定为可编辑，**When** 点击状态条锁按钮，**Then** 手动只读开启，不可编辑与保存，状态条显示 `手动只读`。
- **Given** 缓冲为脏，**When** 尝试开启手动只读，**Then** 按钮不可用并提示 `保存或撤销后才能开启手动只读`。
- **Given** 文件处于只读浏览或根外只读，**When** 查看状态条锁按钮，**Then** 锁按钮不可用，不能切换为可编辑。
- **Given** 手动只读已开启，**When** 按 `Ctrl+S`，**Then** 不写盘并提示 `手动只读模式不可保存`。
- **Given** 手动只读已开启，**When** 再次点击锁按钮，**Then** 恢复自动判定，自动判定可编辑时可继续编辑。
- **Given** 手动只读已开启，**When** 关闭面板后重新打开或应用重启，**Then** 手动只读重置，按自动判定决定编辑能力。

### 外部修改与 gutter Diff

- **Given** 干净文档被外部修改，**When** 文件事件到达，**Then** 内容自动更新，光标与滚动位置尽量保持，显示约 2s 的 `已从磁盘重新加载` 提示。
- **Given** 脏文档被外部修改，**When** 文件事件到达，**Then** 顶部出现非模态横幅，不抢焦点；选择 `重载` 后丢弃本地修改，选择 `保留我的修改` 后保留。
- **Given** 脏文档冲突横幅显示，**When** 点击 `查看差异`，**Then** Diff 面板打开磁盘快照与当前缓冲的差异并定位首个差异块；编辑器缓冲、脏状态与横幅不变。
- **Given** 用户已选择保留，**When** 磁盘内容再次变化，**Then** 横幅重新出现。
- **Given** 文档脏且磁盘已被外部修改，**When** 保存，**Then** 进入保存冲突，不静默覆盖。
- **Given** 文件在应用外被删除，**When** 变化被感知，**Then** 显示删除横幅，缓冲保留；选择 `保存到原路径` 后重新创建文件。
- **Given** 文件在应用外被重命名，**When** 监听器报告映射，**Then** 路径、标题更新，缓冲与光标保留，不弹确认。
- **Given** 监听器队列溢出，**When** 溢出被处理，**Then** 全部已打开文档执行复核，干净文档重载、脏文档按冲突流程处理。
- **Given** 应用从后台重新获得焦点，**When** 文件已在外部变化而事件丢失，**Then** 复核发现变化并执行重载或冲突流程。
- **Given** 打开相对 HEAD 有新增、修改、删除的文件，**When** 标记计算完成，**Then** 行号旁出现实心条、空心条与向上三角，形状与颜色均可区分。
- **Given** 相对 HEAD 有修改的文件，**When** 单击行号旁的 Git 标记，**Then** Diff 面板打开该文件并定位到对应差异块，编辑器面板与缓冲不关闭。
- **Given** 保存使文件与 HEAD 一致，**When** 保存完成，**Then** 全部 Git 标记消失。
- **Given** 非 Git 仓库中的文件，**When** 打开，**Then** 不显示标记且无错误提示。
- **Given** 只读浏览模式或根外只读模式，**When** 查看行号旁，**Then** 不显示 Git 标记栏；手动只读模式仍显示。

### 代码折叠与语言选择器

- **Given** 打开含可折叠代码块的 `.js` 文件，**When** 光标位于块内并按 `Ctrl+Shift+[`，**Then** 该块折叠并显示折叠标记与行数；按 `Ctrl+Shift+]` 后展开。
- **Given** 文件含多个可折叠区域，**When** 按 `Ctrl+Alt+[`，**Then** 全部折叠；按 `Ctrl+Alt+]` 后全部展开。
- **Given** 已折叠若干区域，**When** 切换到其他面板或项目再切回，**Then** 折叠状态保留。
- **Given** 已折叠若干区域，**When** 关闭面板重开或应用重启，**Then** 折叠状态不保留，全部展开。
- **Given** 纯文本文件，**When** 查看 gutter，**Then** 不显示折叠标记。
- **Given** 折叠区域内的文本被删除，**When** 内容变化，**Then** 该折叠状态自动失效并展开。
- **Given** `.txt` 文件，**When** 点击状态条语言项并选择 JavaScript，**Then** 语法高亮切换为 JavaScript，文件内容、扩展名与脏状态不变。
- **Given** 已手动选择语言，**When** 切换项目或重启应用，**Then** 手动选择保留；关闭面板重开后恢复为“自动（按扩展名）”。
- **Given** 已手动选择语言，**When** 选择“自动（按扩展名）”，**Then** 恢复按扩展名判定，路径扩展名变化时继续热切换。
- **Given** 只读浏览或手动只读模式，**When** 点击状态条语言项，**Then** 可选择语言并改变显示，不改变只读与保存能力。

### 拖文件、崩溃恢复与状态条

- **Given** 编辑器面板组可见，**When** 从文件浏览器拖动 `a.ts` 经过该面板组，**Then** 面板组高亮；释放后打开编辑器面板并按路由聚焦。
- **Given** `a.ts` 已在该项目打开，**When** 将同一文件拖到编辑器面板组，**Then** 聚焦已有面板，不新增面板。
- **Given** 目标面板组当前激活面板为脏，**When** 拖入另一文件并释放，**Then** 在新页签打开，不替换脏面板，不触发保存。
- **Given** 拖入 `a.md`，**When** 释放，**Then** 在目标面板组打开 Markdown 面板而不是编辑器。
- **Given** 拖入二进制文件，**When** 释放，**Then** 显示现有二进制错误态，提供 `用系统默认程序打开`。
- **Given** 拖拽过程中按 `Esc` 或拖出有效目标，**When** 释放，**Then** 不打开任何文件。
- **Given** 文档脏且进程异常结束，**When** 下次启动，**Then** 显示恢复提示；选择 `恢复` 后文档以备份文本打开并标记为脏，磁盘文件不被改写；选择 `丢弃` 后按磁盘内容打开。
- **Given** 文档未保存修改在异常退出前已成功备份，**When** 保存成功、撤销回基线、关闭文档或正常退出，**Then** 对应备份被删除，后续启动不再提示。
- **Given** 备份所属项目已不存在，**When** 选择恢复，**Then** 恢复到当前活跃项目；无活跃项目时提示 `请先创建项目` 并保留备份。
- **Given** 打开可编辑文件，**When** 查看面板底部，**Then** 状态条显示语言、编码与行尾；只读浏览时显示 `只读：文件超过 50MB`，根外只读时显示 `项目根外`。
- **Given** 打开 LF 文件，**When** 点击行尾项切换到 CRLF，**Then** 页签出现未保存圆点，保存后磁盘文件使用 CRLF。
- **Given** 打开同名文件 `a/main.ts` 与 `b/main.ts`，**Then** 两者标题显示相对路径；关闭其中一个后另一个恢复为 `main.ts`。
- **Given** 显式打开编辑器，**When** 面板出现，**Then** 焦点进入编辑区，可直接键入。
- **Given** 布局恢复多个编辑器，**When** 应用启动或项目布局恢复，**Then** 不抢键盘焦点，只读视图也不自动聚焦。
- **Given** 从其他项目切回本项目，**When** 切换完成，**Then** 焦点恢复到该项目上次聚焦面板，编辑器文本与脏状态不变。
- **Given** 编辑器聚焦，**When** 按 `Ctrl+Tab` 或 `Ctrl+Shift+Tab`，**Then** 焦点按活跃项目各面板组的面板顺序循环到相邻面板，编辑器文本、脏状态与光标保留。

## 关键决策与依据

- **每项目每路径单一编辑器视图。** 规则：去重键为项目 + 规范化真实路径，Commit 来源不产生后缀视图。原因：避免多个缓冲互相覆盖、页签噪声与保存歧义。边界：不同项目各自独立，不共享缓冲。
- **根外文件只读承接。** 规则：经 Markdown 显式链接、Commit 视图或布局恢复以根外只读打开，不提供编辑、保存或另存为；由允许根移出的可编辑文档进入独立脱离状态，保留缓冲与脏状态并仅可另存为；另存为授权只绑定当前文档与当前运行期，不跨重启。原因：保留外链可读性，同时防止越界写入，又不丢弃用户已编辑内容。边界：根外只读不因该打开动作加入文件浏览器、Commit 视图或终端默认目录。
- **自动打开范围限定。** 规则：自动打开限项目根、实际 Git 仓库根与已登记 Agent 全局目录；项目根外、仓库根内以根外只读打开，写入仅经系统另存为对话框。原因：明确文件边界与监听范围。边界：根外文件不获得原地写入能力。
- **显式保存为默认，自动保存默认关闭。** 规则：自动保存由外观页开关启用，停止输入 1 秒或失焦时保存，冲突与只读时暂停。原因：保持可预期的写盘时机，同时提供可选便利。边界：仅编辑器，不作用于 Diff；失败保留脏状态。
- **崩溃恢复备份绝不自动写回。** 规则：仅备份脏可编辑文档，启动时由用户选择恢复或丢弃。原因：覆盖异常退出造成的丢失，又不以旧内容覆盖磁盘。边界：干净、只读与手动只读文档不备份。
- **大文件分级采用软提示与只读浏览。** 规则：超过 10,000,000 字节提示，超过 50,000,000 字节只读浏览，超过 200,000,000 字节关闭语法高亮。原因：在可编辑能力与流畅性之间给出明确分界。边界：根外只读不受可编辑阈值影响。
- **保存前版本检查与非模态冲突横幅。** 规则：脏文档外部变化只提示不打断，保存时再检查版本并进入保存冲突。原因：减少打断，同时不静默覆盖外部修改。边界：干净文档自动重载；冲突横幅属于文档。
- **代码折叠是会话内面板状态。** 规则：折叠状态跨面板与项目切换保留，关闭重开或重启不保留。原因：折叠是临时阅读状态，不属于布局参数。边界：不改变内容与脏状态。
- **语言手动覆盖是布局持久化面板参数。** 规则：只影响语法高亮，不改内容、扩展名或保存行为，随项目布局持久化。原因：允许用户纠正误判语言而不污染文件。边界：关闭重开恢复自动判定。
- **手动只读仅在缓冲干净时可开启且不覆盖自动只读。** 规则：用户锁只叠加在可编辑模式上，自动只读优先。原因：避免用户误解锁并丢失未保存内容。边界：关闭重开与重启重置，不随布局持久化。
- **拖文件走标准路由且不替换脏面板。** 规则：仅文件浏览器来源，目标面板组高亮，已打开则聚焦。原因：统一打开语义，防止拖放造成数据丢失。边界：非编辑器面板组不接受拖放打开。
- **Git 标记打开独立 Diff。** 规则：单击标记在 Diff 面板打开并定位差异块，编辑区不内嵌差异。原因：缩短从标记到差异的路径，同时保持编辑器专注。边界：只读浏览与根外只读不显示标记；手动只读仍可用。
- **状态条集中呈现语言、编码、行尾与只读原因。** 规则：语言可选择，编码可重开，行尾可切换，只读原因只展示。原因：提升数据契约可见性与可发现性。边界：错误态不显示状态条。
