# GitShow 面板

> 拥有固定 Git 版本内容的只读查看；创建时绑定仓库、提交和路径，不跟随项目根重定位或 HEAD 移动。

## 创建与身份

- 唯一入口为 Commit 中 deleted 文件行。创建时捕获仓库身份、当时 HEAD 的提交版本和仓库相对路径；三者共同组成持久 `ViewKey` 的领域部分。
- 同一项目同一“仓库＋版本＋路径”最多一个 GitShow；重复入口聚焦，不重新读取。Editor、Markdown 与 Diff 不参与该去重。
- 无项目、仓库不可用或路径无效时，显式创建失败不留空 Panel；恢复失败保留面板、错误与重试。
- 标题为 `文件名(git delete)`，同名时用路径消歧；标题由当前视图集合重新计算，不作为身份。
- 根重定位不移动文件、不改绑 GitShow；即使新项目根属于另一仓库，也继续读取原固定版本，原仓库不可用时显示错误。

## 内容与刷新

- 内容只来自固定提交中的文件，不读取工作区、索引或后续 HEAD；不可编辑、不可保存、无脏状态。
- 手动刷新只重新读取同一固定版本，可用于显式复核或失败重试；不会前进到新提交。
- HEAD 移动、分支切换、提交和工作区变化不把已显示内容标记为过期，也不自动替换。需要另一版本时必须从新的 deleted 入口创建不同 `ViewKey`。
- 读取与刷新后台执行，只采纳最新请求代次；关闭面板后取消读取，过期结果不得回填。
- `Ctrl+S` 被消费并提示只读，不写盘。文本选择、复制、查找和滚动保持可用。

## 文本、查找与显示

- 常规文本显示行号和共享语言高亮；空文件显示空白只读视图，非 UTF-8 字节用替换字符并显示正文外提示。
- `Ctrl+F` 按字面量、不区分大小写查找，显示当前／总数；`Enter`／`Shift+Enter` 与 `Ctrl+G`／`Ctrl+Shift+G` 导航，`Esc` 关闭并还焦。
- `Alt+Z` 切换自动换行，`Ctrl+滚轮` 调整共享编辑器字号，范围 8–32px。
- 固定仓库、版本、路径和面板位置持久化；内容重新读取。自动换行、滚动、查找、已加载区段和焦点为瞬态，关闭重开与重启均清除。
- 布局恢复不抢焦；显式打开或激活时焦点进入只读内容，错误态焦点进入重试。

## 大文件与二进制

| 固定版本内容字节数 | 行为 |
|---|---|
| 不超过 1,000,000 | 常规只读文本 |
| 大于 1,000,000 且不超过 10,000,000 | 常规文本并显示大文件提示 |
| 大于 10,000,000 | 分页简化只读，不高亮，查找和复制后台执行且可取消 |

- 体积只按固定版本字节数判定；提示和错误横幅不参与正文复制或行号。
- 前 8 KiB 含 NUL 时优先按二进制处理，显示类型与固定版本字节数，不显示文本查找或换行控件。
- 二进制系统打开只在当前用户可写的系统临时位置生成带原扩展名的只读中转文件，不写工作区或仓库；关闭与退出时清理，失败项在 24 小时后按过期临时材料清理。
- 区段读取失败保留已加载内容并提供重试；复制或查找取消不得改变剪贴板原内容或阅读位置。

## 验收判据

- **Given** deleted 文件位于当前 HEAD，**When** 创建 GitShow 后 HEAD 前进或项目根重定位，**Then** 面板仍显示创建时提交与路径的内容，不使用后续 HEAD 或新仓库。
- **Given** 同一固定版本已有 GitShow，**When** 再次打开，**Then** 聚焦且不重读；不同提交版本可形成不同逻辑视图。
- **Given** 手动刷新已成功显示的内容，**When** 固定版本仍可读取，**Then** 只重读同一版本，不显示“后续 HEAD”内容。
- **Given** 固定提交或对象已不可用，**When** 初始读取、恢复或刷新，**Then** 保留面板与明确错误，可重试，不回退读取工作区。
- **Given** 大文件或二进制固定版本，**When** 打开，**Then** 按字节阈值与 NUL 规则降级，系统打开不写工作区。
- **Given** 关闭重开或重启，**Then** 固定身份与布局恢复，内容重读，搜索、滚动和焦点清除。
