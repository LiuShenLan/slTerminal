# GitShow 面板

> 定义从 Commit 已删除文件入口只读查看 HEAD 版本的目标态：唯一入口、标题、HEAD 读取、刷新与过期提示、只读查看、大文件与二进制处理。入口状态分派归 [sidebar/commit.md](../sidebar/commit.md)，Git 仓库根契约归 [sidebar/commit.md](../sidebar/commit.md) 与 [sidebar/explorer.md](../sidebar/explorer.md)，面板生命周期与焦点归 [workspace/shell.md](../workspace/shell.md)。

## 目标行为

### 面板定位与只读边界

- GitShow 是封闭面板类型之一，位于活跃项目的项目布局中，作为某个面板组的一个面板存在；面板生命周期、拖拽、拆分、合并与布局持久化遵循 [workspace/shell.md](../workspace/shell.md)。
- 面板只读：不可编辑、不可保存、不产生脏状态；关闭不弹确认，不参与任何脏状态聚合。
- 内容源固定为文件在 HEAD 提交中的版本，不展示工作区、索引、暂存区、其他分支或其他提交的版本。
- 不提供编辑、保存、另存为、格式转换、差异对比、blame、历史、提交信息、分支切换或暂存操作，也不提供这些能力对应的入口。
- 面板头部为紧凑单行：左侧固定 `HEAD` 标识，右侧刷新按钮，悬停提示 `刷新 (F5)`；除刷新外无其他工具栏、状态栏或操作入口。

### 唯一入口与去重

- 唯一入口：在 Commit 视图的变更列表中双击状态为 `deleted` 的文件行。Git 状态到面板类型的入口分派由 [sidebar/commit.md](../sidebar/commit.md) 拥有。
- 不提供未知、未跟踪、已修改等其他状态的 GitShow 入口，不新增其他入口。
- 面板在活跃项目当前聚焦的面板组中打开；具体落点遵循 [workspace/shell.md](../workspace/shell.md) 的面板打开规则。双击即打开，无确认步骤。
- 同一项目内同一仓库相对路径只保留一个 GitShow 面板，路径比较忽略大小写。命中已有面板时，激活其所在面板组与面板，不新建、不重新读取，也不因去重显示提示。
- 同一文件已由编辑器或 Diff 面板打开时，仍打开独立的 GitShow 面板，三者互不替代、互不影响。
- 不同项目中的同一路径文件各自独立，不互相去重。
- 创建失败（无活跃项目、仓库不可用、路径无效）时不创建面板，显示非阻塞错误提示，不得静默结束。

### 标题

- 面板标题为 `文件名(git delete)`：文件名与后缀直接拼接，中间无空格；后缀固定英文，不随界面语言变化。
- 同一项目内存在多个同名文件的 GitShow 面板时，标题改用相对路径拼接后缀；冲突出现或消失时自动重算。冲突判定忽略大小写。
- 冲突消歧优先使用相对项目根的路径；文件不在项目根下时使用规范化绝对路径。标题悬停显示仓库内完整路径。
- 面板图标按文件扩展名显示 <img src="../assets/preview/icons/file-generic-typed.svg" width="14" height="14" alt="带类型标识的文件图标">（`../assets/icons/file-generic-typed.svg`，14px，示意）；未知扩展名显示通用文件图标 <img src="../assets/preview/icons/file-generic.svg" width="14" height="14" alt="通用文件图标">（`../assets/icons/file-generic.svg`，14px，示意）。
- 标题不持久化，恢复时按当前同项目同名冲突重新计算。

### HEAD 内容读取

- 内容源固定为文件在 HEAD 提交中的内容（文本或二进制字节）；所有形态均不使用工作区磁盘文件。
- 仓库根使用项目根所在的 Git 仓库实际根，与 Commit、Diff、文件浏览器统一；项目根可为仓库子目录。文件按相对实际仓库根的路径解析，不把项目根当作仓库根。仓库根契约见 [sidebar/commit.md](../sidebar/commit.md) 与 [sidebar/explorer.md](../sidebar/explorer.md)。
- 打开面板与手动刷新时读取。读取成功进入内容态；读取失败进入错误态，规则见「边界与错误」。
- 面板内容是最近一次成功读取时的 HEAD 快照，不与工作区内容或其他版本混合。

### 内容形态

- 常规形态为只读文本视图：显示行号，按扩展名启用语法高亮，未知扩展名按纯文本显示。
- 空文件读取成功时进入内容态，显示带行号的空白视图，不显示“文件为空”之类占位；头部仍标识 `HEAD`。
- 非 UTF-8 内容按文本解码，无法解码的字节显示替换字符；内容上方显示常驻横幅 `文件包含无法解码的字节，已以替换字符显示。`。横幅不属于正文，不参与选择、复制与行号。
- 二进制判定：文件前 8 KiB 内含 NUL 字节即视为二进制，不再按文本解码。内容区居中显示 `二进制文件` 占位，标注类型（按扩展名判断，未知类型显示 `未知类型`）与 HEAD 字节数，并提供 `用系统默认程序打开` 入口。
- 系统打开将 HEAD 内容写入系统临时目录的临时文件后交给默认程序，不写入工作区、索引或仓库。临时文件使用唯一名称并保留原扩展名，仅当前用户可读写；启动时清理超过 24 小时的旧文件；面板关闭或退出时尝试删除，失败登记下次清理；日志只记操作与结果。二进制形态不显示替换字符正文、非 UTF-8 横幅、行号、查找、自动换行与字号调整。
- 长行默认不自动换行，可横向滚动；正文可纵向滚动。
- 文本可选择、复制，光标可移动；键入、粘贴、删除等修改操作无效。
- 主题跟随当前配色方案；切换配色方案时热切换，不重建面板、不重置文本与滚动位置。

### 只读查看能力

- 查找：`Ctrl+F` 打开内容区顶部查找框；按字面量、不区分大小写匹配，不支持正则、替换或匹配选项。匹配项高亮，当前匹配使用区分样式，显示 `当前/总数`。`Enter` / `Shift+Enter` 与 `Ctrl+G` / `Ctrl+Shift+G` 前后跳转；`Esc` 关闭查找框并把焦点还给内容区。无匹配时显示 `0/0`。
- 自动换行：`Alt+Z` 切换；默认关闭；面板实例独立；切换不重置光标、滚动位置与查找状态。
- 全局编辑器字号：指针位于内容区时 `Ctrl+滚轮` 调整，每格 1px，范围 8–32px，到达边界后不再变化。该字号与编辑器面板共享，所有编辑器与 GitShow 同步；最后一次调整约 2 秒后持久化，持久化契约见 [settings-and-persistence.md](../settings-and-persistence.md)。行高随字号同比缩放。
- 复制与全选：`Ctrl+C` 复制选区，`Ctrl+A` 全选。大文件形态下复制超长选区为异步操作，显示进度且可取消；取消或失败时剪贴板保持原内容。
- `Ctrl+S` 被面板消费：不写盘、不产生脏状态；显示短暂轻提示 `只读视图，无法保存`，不进入脏状态聚合。
- 查找、自动换行与字号调整在加载态、错误态与二进制占位态没有正文时不可用；在大文件形态下均可用。
- 只读不阻止选择、复制、查找、光标移动与键盘滚动；所有修改文本的操作均无效果。

### 大文件分级

- 唯一判定口径为 HEAD 内容的字节数。GitShow 使用自身按字节的分级，阈值为 `1,000,000` 与 `10,000,000` 字节；该分级由本面板独立判定，与编辑器的文件体积阈值相互独立，外部阈值变化不影响本面板。
- `≤ 1,000,000` 字节：常规只读文本视图，无额外提示。
- `> 1,000,000` 且 `≤ 10,000,000` 字节：常规只读文本视图，内容上方显示警告横幅 `文件较大（X.X MB），只读查看；语法高亮与搜索可能影响性能。`；横幅不属于正文，不影响行号与复制。
- `> 10,000,000` 字节：不创建完整文本视图，进入简化只读浏览：
  - 内容上方显示信息条 `HEAD · 简化只读浏览 · X.X MB`。
  - 正文按行显示，不启用语法高亮；按需加载，滚动到未加载区域时显示短暂占位，不出现整页加载遮罩。
  - 支持纵向滚动、横向滚动、自动换行、查找、字号调整、选择复制与键盘滚动。
  - 查找异步扫描整个 HEAD 文本，显示进度并可按 `Esc` 取消；扫描中显示 `n/…`，匹配随扫描逐步可用，完成后显示 `n/m`。
  - 区段加载失败时保留已加载内容，信息条追加 `部分内容加载失败` 与重试入口，可展开查看具体错误；重试只重读失败区段。
- 阈值边界：恰好 `1,000,000` 字节不显示警告；恰好 `10,000,000` 字节仍为常规文本视图并显示警告；`10,000,001` 字节起进入简化只读浏览。
- 二进制判定优先于文本体积分级：文件前 8 KiB 内含 NUL 字节时，无论体积进入哪一档，均显示二进制占位而不创建文本视图；大小仍按 HEAD 字节数显示。
- 所有形态显示的文件大小均来自同一 HEAD 字节数，单位与精度一致，不混用工作区大小。

### 刷新与过期

- 面板创建后文件路径与仓库范围固定；刷新是唯一的重读触发，不存在查询参数变化。
- 常规、简化与二进制形态均支持手动刷新：点击头部刷新按钮，或面板聚焦时按 `F5`。
- 刷新重新读取当前 HEAD。成功后替换内容；滚动位置保留并在新内容长度内收敛；自动换行、字号与查找关键词保留，查找按新内容重新执行。
- 刷新期间已有内容保持可见与可操作，头部显示进行中状态，刷新入口禁用。刷新失败时保留原内容，在内容上方显示 `刷新失败：<原因>` 与重试入口，不切换到整页错误态。
- 初始加载失败使用整页错误态，规则见「边界与错误」。
- 同一时刻只采纳最后一次读取请求的结果；旧结果晚到不覆盖新结果。
- 不做自动刷新：已显示内容不因工作区文件、提交、回滚、分支切换或仓库元数据变化而自动替换；不因工作区文件内容变化重新读取，无轮询、定时刷新或自动重载。
- 面板存活期间检测 HEAD 与目标文件在 HEAD 中的内容变化。最近一次成功读取之后检测到变化时进入过期状态：内容上方显示非阻塞横幅 `内容已过期，点击刷新` 与刷新入口；正文、滚动位置、自动换行与查找保持原样，不自动替换。
- 过期状态仅在刷新成功后清除；刷新失败时保留正文，失败横幅替代过期横幅，重试成功后一并清除。面板隐藏期间检测到变化时只更新过期状态，不抢焦点。
- 初始读取失败不建立过期基线；重试成功后开始检测。
- 去重聚焦已有面板不重新读取。
- 关闭后重开、应用重启均重新读取当前 HEAD。
- 面板隐藏（同面板组切面板、切换项目）不取消进行中的读取；读取完成后更新面板且不抢焦点。
- 关闭面板时中止进行中的读取、停止 HEAD 变化检测并丢弃结果。

### 焦点与激活

- 焦点落点为只读内容区；简化浏览内容区与二进制占位态同样可聚焦，错误态焦点落在 `重试` 入口。
- 显式打开（双击 Commit 的 `deleted` 行）或显式激活（点击面板、去重聚焦）时，面板成为激活面板，键盘焦点进入只读内容区。焦点迁移在面板完成激活后执行；执行前面板已被切走或不再激活时取消。
- 初始加载中，焦点可落在面板容器；内容就绪后按上一条规则补入内容区，且仅在面板仍为激活面板、焦点未被用户移走时执行。
- 点击正文将焦点移入内容区；点击查找框进入查找输入；二进制占位态中点击系统打开入口直接触发。
- 布局恢复与启动恢复不产生焦点意图，不自动激活面板，不自动聚焦只读内容区，也不抢占键盘焦点。全局焦点层级、面板激活与关闭后的焦点迁移遵循 [workspace/shell.md](../workspace/shell.md) 的焦点模型。
- 刷新、刷新失败、过期状态出现与区段重试不移动当前焦点。
- 面板隐藏期间完成读取或检测到 HEAD 变化只更新状态，不抢焦点。

### 状态保留与持久化

- 随布局持久化：面板类型、仓库相对文件路径、面板组归属、面板组尺寸与面板顺序；布局细节由 [workspace/shell.md](../workspace/shell.md) 与 [settings-and-persistence.md](../settings-and-persistence.md) 统一持久化。
- 面板标题不持久化，恢复时按当前同项目同名冲突重新计算。
- 不持久化：HEAD 内容、滚动位置、查找框与关键词、自动换行开关、简化浏览已加载区段、键盘焦点。
- 全局编辑器字号独立持久化，不属于面板状态。
- 面板在关闭前始终存活；同面板组切面板、切换面板组、切换项目只改变显隐与激活，不销毁、不重读。

状态保留矩阵：

| 状态对象 | 同面板组切面板 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|
| HEAD 内容 | 保留 | 保留 | 丢弃并重新读取 | 丢弃并重新读取 |
| 滚动位置 | 保留 | 保留 | 重置 | 重置 |
| 查找框与关键词 | 保留 | 保留 | 重置 | 重置 |
| 自动换行 | 保留 | 保留 | 恢复默认关闭 | 恢复默认关闭 |
| 简化浏览已加载区段 | 保留（区段可重新加载） | 保留（区段可重新加载） | 丢弃并重新读取 | 丢弃并重新读取 |
| 全局编辑器字号 | 保留 | 保留 | 保留 | 保留 |
| 文件路径 | 保留 | 保留 | 保留 | 随布局恢复 |

## 交互规则

### 打开、去重与关闭

- 双击 `deleted` 文件行即打开，无确认步骤。
- 同项目内命中同路径 GitShow 面板时，仅激活并聚焦已有面板；不创建新面板、不重读 HEAD、不因去重显示提示。
- 同文件已存在编辑器或 Diff 面板时，GitShow 独立创建；三者互不影响。
- 新面板落在活跃项目的聚焦面板组；落点规则遵循 [workspace/shell.md](../workspace/shell.md)。
- 入口条件不满足或创建失败时，显示非阻塞错误提示，不产生面板。
- 关闭路径：面板关闭按钮、`Ctrl+W`、中键、面板菜单；无保存确认。关闭后内容与界面状态丢弃。
- 面板拖拽、拆分、合并与排序遵循 [workspace/shell.md](../workspace/shell.md)；面板不得跨项目移动。
- 同项目 GitShow 面板集合变化（打开、关闭）时重算同名冲突标题。

### 鼠标

- 单击正文：将焦点移入内容区并放置光标。
- 拖拽：选择文本；选择可跨可见区域滚动扩展。
- `Ctrl+C` 复制选区；`Ctrl+A` 全选。
- 滚轮：纵向滚动；`Shift+滚轮` 横向滚动；指针位于内容区时 `Ctrl+滚轮` 调整全局字号。
- 单击头部刷新按钮：触发刷新；初始加载或刷新进行中时按钮禁用。
- 单击过期横幅、刷新失败横幅或错误态中的刷新/重试入口：重新读取。
- 单击二进制占位中的 `用系统默认程序打开`：交给系统默认程序打开。
- 查找框内点击、选择与输入遵循标准文本输入行为；不提供替换、区分大小写或正则开关。

### 键盘

| 按键 | 上下文 | 行为 |
|---|---|---|
| `Ctrl+F` | GitShow 面板聚焦且有正文 | 打开查找框并聚焦输入 |
| `Enter` / `Shift+Enter` | 查找框聚焦 | 跳到下一个 / 上一个匹配 |
| `Ctrl+G` / `Ctrl+Shift+G` | 内容区或查找框聚焦 | 跳到下一个 / 上一个匹配 |
| `Esc` | 查找框聚焦 | 关闭查找框，焦点返回内容区 |
| `Esc` | 简化浏览查找扫描进行中 | 取消扫描，保留已显示内容与当前滚动位置 |
| `Alt+Z` | GitShow 面板聚焦且有正文 | 切换自动换行 |
| `F5` | GitShow 面板聚焦 | 刷新 HEAD 内容 |
| `Ctrl+C` | 内容区聚焦且有选区 | 复制选区 |
| `Ctrl+A` | 内容区聚焦 | 全选 |
| `Ctrl+S` | GitShow 面板聚焦 | 被消费，不保存、不标脏；显示短暂轻提示 `只读视图，无法保存` |
| `Up` / `Down` / `PageUp` / `PageDown` / `Home` / `End` | 简化浏览内容区聚焦 | 键盘滚动 |
| `Ctrl+W` | 全局 | 关闭当前面板，遵循工作区契约 |

- 面板级快捷键仅在 GitShow 面板聚焦时生效；全局命令优先级与保留键遵循 [workspace/shell.md](../workspace/shell.md)。
- 查找框输入支持输入法组合；组合期间不触发查找跳转。
- 简化浏览的查找取消使用 `Esc`；取消后保留已显示内容与当前滚动位置。

### 查找

- 查找框位于内容区顶部、面板头部下方；打开时占据内容区上方一行，不覆盖正文。
- 查找为字面量匹配，不区分大小写，不解析正则。
- 匹配高亮，当前匹配使用区分样式；计数显示 `当前/总数`；大文件扫描期间显示 `n/…`。
- 输入变化后即时更新匹配；正文滚动到当前匹配并尽量居中。
- 关闭查找框后清除高亮，保留原滚动位置。
- 查找状态在面板存活期间保留，跨同面板组切面板与切换项目不重置。
- 加载态、错误态与二进制占位态没有正文，`Ctrl+F` 不打开查找框。

### 刷新

- 刷新入口为头部按钮与 `F5`，两者行为一致。
- 刷新期间头部显示进行中状态；已有内容仍可选择、复制、查找与滚动。
- 刷新成功后替换内容并清除过期状态；滚动位置收敛到新内容长度，查找按当前关键词重新执行。过期横幅中的刷新入口与头部按钮、`F5` 等效。
- 刷新失败时保留原内容，失败横幅替代过期横幅；重试再次读取 HEAD，成功后一并清除过期状态。
- 初始加载中刷新入口禁用；错误态下头部刷新与错误态重试入口等效。
- 连续触发刷新时合并请求，只采纳最后一次结果。
- 刷新不移动键盘焦点，不改变自动换行与字号。

### 反馈

- 初始加载：内容区居中显示 `加载中...`，灰暗色文字、面板背景；不显示骨架屏、进度条、取消按钮或重试入口。
- 错误态：内容区居中显示错误文案与 `重试` 按钮，使用错误语义色；可展开查看详情。
- 刷新失败：内容上方横幅 `刷新失败：<原因>` 与 `重试` 入口，保留正文。
- 内容过期：内容上方横幅 `内容已过期，点击刷新` 与刷新入口，保留正文、滚动位置与查找状态；不自动替换内容。
- 二进制内容：内容区居中显示类型与 HEAD 字节数占位，提供 `用系统默认程序打开` 入口，不显示文本正文。
- 大文件警告、非 UTF-8 提示、区段加载失败均使用内容上方横幅，不覆盖正文、不参与复制。
- 入口创建失败：非阻塞错误提示，不产生面板。
- 所有反馈不使用模态对话框；可感知加载、错误、过期与重试状态。

### 键盘与焦点

- 面板内所有功能键盘可达：刷新、查找、跳转、自动换行、字号调整、滚动、重试、过期提示的刷新入口、二进制占位态的系统打开入口与关闭；入口的键盘可达性由 [sidebar/commit.md](../sidebar/commit.md) 拥有。
- 内容区、查找框、刷新按钮、过期横幅刷新入口、系统打开入口与重试按钮均提供可见焦点环。
- 字号范围 8–32px；行高随字号缩放。
- 简化浏览支持方向键、翻页键、Home 与 End 键盘滚动。
- 仅暗色模式。
- 加载动画遵循减少动效设置；关闭动效时使用静态加载文案。
- 查找输入支持输入法与中日韩文字，不因组合输入误触发跳转。
- 键盘与输入约定见 [cross-cutting.md](../cross-cutting.md)。

## 边界与错误

### 空内容

- HEAD 文件为空时进入内容态，显示带行号的空白视图，不显示占位文案。
- 面板没有“未打开文件”空态；面板始终由入口携带文件路径创建。
- 空内容下查找显示 `0/0`，不报错。

### 加载

- 首次读取显示居中 `加载中...`；面板仍可切换、关闭与拖拽。
- 加载期间正文区域无内容交互；查找、自动换行与字号快捷键不生效。
- 不设读取超时与取消按钮；用户可关闭面板中止读取。
- 关闭面板时中止请求，结果不再回写。
- 切换项目或同面板组切面板不取消读取；面板隐藏期间完成读取时只更新状态，不抢焦点。

### 错误

- 错误分类与文案：
  - 仓库不可用或不是 Git 仓库：`无法读取仓库`。
  - 仓库尚无提交：`仓库尚无提交`。
  - 文件不在 HEAD 中：`该文件不在 HEAD 中`。
  - 其他读取失败（权限、路径校验、读取失败等）：`读取 HEAD 内容失败`，可展开查看详情。
- 初始读取失败显示整页错误态，包含错误文案与 `重试`；重试重新读取并回到加载态。
- 刷新失败保留已有内容，显示失败横幅与 `重试`；不得用错误态替换可读内容。
- 错误态持续到重试成功、刷新成功或面板关闭；不做自动重试。
- 面板创建失败（无活跃项目、仓库不可用、路径无效）不创建面板，显示非阻塞提示。
- 用系统默认程序打开二进制失败时显示非阻塞错误提示，二进制占位与入口保持可用。
- 单个面板的错误不影响其他面板、项目或工作区。
- 错误详情不包含凭据或敏感信息；文件路径按界面需要显示。

### HEAD 与工作区

- 工作区文件修改、删除或还原不影响已显示内容；Git 状态变化同样不自动更新，也不触发过期提示。
- 入口为 `deleted` 文件时，工作区通常已无该文件；所有体积形态仍能读取 HEAD 内容。
- HEAD 中的文件被移除、重命名或仓库改写后，刷新进入相应错误；刷新前保持旧快照。
- 分支切换、提交、回滚等仓库变化仅在手动刷新后反映到正文；检测到 HEAD 变化时显示过期横幅，不自动替换内容。
- 恢复布局时若保存路径已不在 HEAD，面板保留并显示错误与重试，不自动删除面板。

### 大文件边界

- 阈值按 HEAD 内容字节数判定，多字节字符按真实字节计入。
- 恰好 `1,000,000` 字节为常规形态；`1,000,001` 字节起显示警告；恰好 `10,000,000` 字节仍为常规文本视图；`10,000,001` 字节起进入简化浏览。
- 简化浏览不设额外体积上限；读取耗时随体积增加，用户可关闭面板中止。
- 区段加载失败：保留已加载内容，显示 `部分内容加载失败` 与重试；重试成功后继续按需加载。
- 大文件查找异步进行，显示扫描进度，可按 `Esc` 取消；取消后保留当前内容与滚动位置。
- 大文件全选复制为异步操作；取消或失败时剪贴板保持原内容。
- 非 UTF-8 内容在大文件形态同样显示替换字符与提示横幅。
- 超长单行在关闭自动换行时横向滚动；开启自动换行后按可视宽度折行。
- 二进制内容按文件前 8 KiB 内是否含 NUL 字节判定，优先于体积分级；判定为二进制时显示类型与大小占位及系统打开入口，不按文本解码，不显示行号、查找、自动换行与字号调整。
- 系统打开将 HEAD 内容写入系统临时目录的临时文件后交给默认程序；打开失败时保留占位并显示非阻塞错误提示。

### 并发与生命周期

- 多个刷新请求并发时只采纳最后一次结果；旧请求结果丢弃。
- 关闭面板中止所有进行中的读取、查找扫描与复制操作，并停止 HEAD 变化检测。
- 刷新成功后到达的旧 HEAD 变化通知被丢弃，不把新内容误标为过期。
- 刷新期间切换项目或切面板不取消读取；完成后更新隐藏中的面板。
- 同一文件快速重复双击只产生一个面板；后续操作聚焦已有面板，不触发第二次读取。
- 不同项目中的同路径面板独立读取、独立刷新。
- 查找扫描期间刷新时，取消旧扫描并在新内容上重新查找。
- 标题冲突计算随面板打开与关闭更新；面板存活期间文件路径不变。

### 恢复

- 启动或布局恢复时按保存的仓库相对路径恢复 GitShow 面板。
- 恢复先显示 `加载中...`，再读取当前 HEAD；成功显示最新内容，失败显示对应错误与重试。
- 恢复不产生焦点意图，不自动激活面板，不自动聚焦只读内容区，不抢占键盘焦点。
- HEAD 内容、滚动位置、查找状态、自动换行与已加载区段不随布局恢复。
- 项目根不可访问时，面板仍恢复并显示错误；项目行状态由 [workspace/navigation.md](../workspace/navigation.md) 处理。
- 保存路径无效或越出仓库范围时显示读取错误与重试，不读取任意磁盘路径。
- 未知面板类型由工作区在恢复时丢弃，GitShow 不处理未知类型。

### 平台与安全

- 仅 Windows 10/11 原生、单窗口、暗色模式；不涉及多窗口、多实例或亮色主题。
- 路径去重与同名冲突判定忽略大小写；路径展示遵循平台习惯。
- 只读取 HEAD 中的文件内容，不写入工作区、索引或仓库；二进制系统打开仅经系统临时目录中转；无保存、暂存、回滚能力。
- 恢复路径必须位于项目根所在 Git 仓库的实际根内；项目根可为仓库子目录。不存在任意路径读取通道。
- 查找使用字面量匹配，不执行正则或脚本。
- 错误与提示不插值凭据或敏感内容。

### 性能

- 内容读取异步执行，不阻塞工作区交互、其他面板或终端。
- 常规内容在加载完成后可流畅滚动、查找与选择；大文件按需加载，滚动到未加载区域时短暂占位。
- 大文件查找与全选复制异步执行，提供进度与取消，不冻结界面。
- 面板存活期间保留已加载状态；关闭后释放内容与区段缓存。
- 简化浏览允许在面板存活期间按需淘汰区段缓存；滚动回已淘汰区域时重新读取并短暂占位，面板、滚动位置与阅读状态不重置。
- 不做后台轮询或定时刷新；窗口重新聚焦或面板激活时复核一次 HEAD 指纹，只用于更新过期提示；正文替换只在用户显式刷新时发生。
- 多个 GitShow 面板同时存在时互不阻塞。

## 验收判据

### 入口与标题

- Given 活跃项目 A 且 Commit 的变更列表存在 `deleted` 文件 `a.ts`，When 双击该行，Then 在 A 的聚焦面板组打开 GitShow 面板，标题为 `a.ts(git delete)`，先显示 `加载中...`，随后显示 HEAD 内容。
- Given 项目 A 已有 `a.ts` 的 GitShow 面板，When 再次双击同一 `deleted` 行，Then 聚焦已有面板，不新增面板、不重新读取。
- Given 同一文件已在编辑器或 Diff 面板打开，When 双击 `deleted` 行，Then 仍打开独立的 GitShow 面板。
- Given 两个项目分别打开同一路径文件，When 各自双击 `deleted` 行，Then 各项目内独立存在 GitShow 面板。
- Given 同项目同时打开 `src/a.ts` 与 `lib/a.ts` 的 GitShow 面板，Then 两个标题均包含相对路径与 `(git delete)`；关闭其中一个后，剩余标题恢复为 `a.ts(git delete)`。
- Given 同一仓库内项目根外存在两个同名文件，When 分别打开 GitShow，Then 两个标题均使用规范化绝对路径消歧并追加 `(git delete)`；关闭其中一个后，剩余标题恢复为 `a.ts(git delete)`。
- Given 没有活跃项目或仓库不可用，When 双击 `deleted` 行，Then 不产生面板，并显示非阻塞错误提示。
- Given GitShow 面板已打开，When 通过面板关闭按钮、`Ctrl+W`、中键或面板菜单关闭，Then 无保存确认，面板销毁。

### HEAD 只读

- Given 工作区文件内容与 HEAD 不同，When 打开 GitShow，Then 正文显示 HEAD 内容，不显示工作区内容。
- Given 文件已从工作区磁盘删除，When 打开 GitShow，Then 仍显示 HEAD 内容，不出现磁盘缺失错误。
- Given HEAD 中的文件为空，When 打开，Then 显示带行号的空白视图，无“文件为空”占位；查找显示 `0/0`。
- Given HEAD 内容包含非 UTF-8 字节，When 打开，Then 无法解码的字节显示替换字符，并显示非 UTF-8 提示横幅。
- Given 内容已显示，When 键入、粘贴或删除，Then 文本不变；When 按 `Ctrl+S`，Then 不写盘、不标脏、不进入脏状态，并显示短暂轻提示 `只读视图，无法保存`。
- Given 内容已显示，When 切换配色方案，Then 正文配色热切换，文本与滚动位置不重置。
- Given HEAD 中不存在该文件，When 打开或刷新，Then 显示 `该文件不在 HEAD 中` 与 `重试`；点击 `重试` 重新读取。
- Given 仓库没有提交，When 打开，Then 显示 `仓库尚无提交` 与 `重试`。
- Given 仓库不可用或不是 Git 仓库，When 打开，Then 显示 `无法读取仓库` 与 `重试`。

### 查找与查看

- Given 内容已显示，When 按 `Ctrl+F` 并输入关键词，Then 显示查找框，匹配高亮并显示 `当前/总数`。
- Given 查找有多个匹配，When 按 `Enter`、`Shift+Enter`、`Ctrl+G` 或 `Ctrl+Shift+G`，Then 在匹配间前后跳转；When 按 `Esc`，Then 关闭查找框并清除高亮，焦点返回内容区。
- Given 内容未换行，When 按 `Alt+Z`，Then 切换自动换行且不重置滚动位置；再次按下恢复。
- Given 字号为 20px，When 在内容区 `Ctrl+滚轮` 向上滚动一格，Then 字号变为 21px；连续调整时保持在 8–32px。
- Given 调整字号，Then 其他编辑器面板同步变化，并在约 2 秒后持久化。
- Given 大文件形态，When 使用 `Ctrl+F`、`Alt+Z`、`Ctrl+滚轮` 或键盘滚动，Then 均生效。
- Given 大文件查找进行中，When 按 `Esc`，Then 取消扫描，保留当前内容与滚动位置。
- Given 大文件中全选复制进行中，When 取消，Then 剪贴板保持原内容。

### 大文件与二进制

- Given HEAD 文本为 `1,000,000` 字节，When 打开，Then 使用常规文本视图且无警告横幅。
- Given HEAD 文本为 `1,000,001` 字节，When 打开，Then 使用常规文本视图并显示大文件警告横幅。
- Given HEAD 文本为 `10,000,000` 字节，When 打开，Then 使用常规文本视图并显示警告横幅。
- Given HEAD 文本为 `10,000,001` 字节，When 打开，Then 进入简化只读浏览，显示 `HEAD · 简化只读浏览 · X.X MB`，不创建完整文本视图。
- Given 超过 `10,000,000` 字节的文件已从工作区磁盘删除，When 打开，Then 简化浏览仍显示 HEAD 内容，不因磁盘缺失出现空白或读取失败。
- Given 简化浏览的某个区段加载失败，Then 已加载内容继续显示，信息条出现 `部分内容加载失败` 与重试；重试只重读失败区段。
- Given 大文件警告横幅存在，Then 横幅不属于正文，不参与选择、复制与行号。
- Given HEAD 内容前 8 KiB 含 NUL 字节，When 打开，Then 显示 `二进制文件` 占位、类型与 HEAD 字节数，并提供 `用系统默认程序打开`，不显示替换字符正文。
- Given 二进制占位已显示，When 按 `Ctrl+F` 或 `Alt+Z`，Then 无效果；When 使用系统打开且默认程序不可用，Then 显示非阻塞错误提示，占位保持可用。

### 刷新与过期

- Given 面板已显示 HEAD 内容，When 外部产生新提交且用户按 `F5` 或点击刷新按钮，Then 正文更新为当前 HEAD 内容。
- Given 刷新前滚动到中部，When 刷新成功且新内容足够长，Then 滚动位置保留；新内容较短时收敛到末尾。
- Given 刷新前自动换行开启且查找框有关键词，When 刷新成功，Then 自动换行保持开启，查找按新内容重新执行。
- Given 面板已显示内容，When 外部提交、回滚或切换分支但不刷新，Then 正文保持不变，并显示 `内容已过期，点击刷新` 横幅。
- Given 面板已显示内容，When 外部修改工作区文件，Then 正文与过期状态均不变，不显示过期横幅。
- Given 已显示过期横幅，When 刷新成功，Then 正文更新且过期横幅消失；When 刷新失败，Then 失败横幅替代过期横幅并保留正文，重试成功后过期状态清除。
- Given 面板隐藏期间检测到 HEAD 变化，When 切回面板，Then 显示过期横幅，不抢焦点。
- Given HEAD 变化后去重聚焦已有面板，Then 不重新读取，仅显示过期横幅；用户手动刷新后才更新。
- Given 刷新失败，Then 原内容保留，显示 `刷新失败：<原因>` 与 `重试`，不切换到整页错误态。
- Given 快速连续触发两次刷新，Then 只采纳最后一次结果，不出现旧内容覆盖新内容。
- Given 同面板组切面板或切换项目再返回，Then 内容、滚动、查找与自动换行保留，不重新读取。
- Given 关闭后重新打开同一文件，Then 新建面板并重新读取当前 HEAD，状态重置。
- Given 应用重启后恢复布局，Then 面板重新读取当前 HEAD，不抢焦点，滚动、查找与自动换行重置为默认。

### 错误与恢复

- Given 初始读取遇到权限错误，When 打开，Then 显示 `读取 HEAD 内容失败` 与 `重试`，可展开查看详情。
- Given 初始读取失败，When 点击 `重试`，Then 回到加载态并重新读取；失败后不自动重试。
- Given 保存路径在恢复时已不在 HEAD，Then 面板保留并显示错误与重试，不自动删除面板。
- Given 保存路径越出仓库范围，Then 显示读取错误与重试，不读取任意磁盘路径。
- Given 项目根不可访问，Then 面板恢复并显示错误，不影响其他面板。

### 焦点与键盘

- Given 用户双击 `deleted` 行打开面板且内容读取成功，When 内容出现，Then 焦点位于只读内容区，无需再次点击即可使用 `Ctrl+F` 与 `Alt+Z`。
- Given GitShow 面板已打开但未聚焦，When 点击其面板或去重命中已有面板，Then 面板激活且焦点进入只读内容区。
- Given 打开超过 `10,000,000` 字节的文件，When 简化浏览就绪，Then 焦点进入简化浏览内容区，可用方向键、翻页键、Home 与 End 滚动。
- Given 打开二进制文件，When 占位就绪，Then 焦点位于只读内容容器，`Tab` 可到达并触发 `用系统默认程序打开` 入口。
- Given 初始读取失败，Then 焦点可到达 `重试` 按钮；点击后重新读取。
- Given 应用重启或布局恢复，Then 没有 GitShow 面板抢占键盘焦点，也不自动聚焦只读内容区。
- Given 面板处于内容态、过期态、二进制占位态、查找打开或错误态，When 使用键盘 `Tab` 导航，Then 可到达刷新按钮、过期横幅刷新入口、系统打开入口（二进制态）、查找框（打开时）与重试入口（错误态），并有可见焦点环。
- Given 查找框使用输入法组合输入，Then 组合期间不触发匹配跳转，提交后正常查找。

## 关键决策与依据

- **规则**：唯一入口为 Commit 中 `deleted` 文件行，同项目按仓库相对路径去重。
  **原因**：GitShow 只服务已删除文件的 HEAD 查看；项目级去重避免同一路径产生多个只读副本。
  **边界**：编辑器与 Diff 的同路径面板不参与去重；不同项目互不去重；其他 Git 状态不提供入口；无活跃项目或仓库不可用时不创建面板并提示。

- **规则**：所有形态只读 HEAD，不读工作区磁盘。
  **原因**：已删除文件通常不在工作区；统一内容源可避免同一面板混入非 HEAD 内容。
  **边界**：工作区修改、删除、还原均不改变正文；二进制系统打开也以 HEAD 内容生成临时文件；不写入工作区、索引或仓库。

- **规则**：仓库根取项目根所在 Git 仓库的实际根。
  **原因**：项目根允许为仓库子目录，按实际仓库根解析路径才能与 Commit、Diff、文件浏览器一致。
  **边界**：路径必须位于实际仓库根内；不自动初始化仓库；恢复时越界路径按读取错误处理，不读取任意磁盘路径。

- **规则**：标题固定 `文件名(git delete)`，同名时项目根内改用项目相对路径，根外改用规范化绝对路径。
  **原因**：后缀直接表达内容来源；稳定英文后缀便于跨界面语言识别。
  **边界**：后缀不翻译；冲突判定忽略大小写；项目根内标题使用相对项目根路径，根外使用规范化绝对路径；标题不持久化。

- **规则**：手动刷新为唯一重读触发，HEAD 变化只显示过期横幅。
  **原因**：避免内容静默过期，同时不打断阅读；自动替换会让用户失去当前阅读位置。
  **边界**：无轮询、定时刷新或工作区自动重载；工作区文件变化不触发过期；去重聚焦不重读；刷新失败保留正文并显示失败横幅。

- **规则**：初始加载失败用整页错误态，刷新失败保留正文。
  **原因**：初始错误没有可保留内容；刷新错误时已有可读快照，整页替换会造成不必要的信息损失。
  **边界**：错误分为仓库不可用、无提交、文件不在 HEAD、其他读取失败；均提供重试；不做自动重试。

- **规则**：以 HEAD 字节数作为体积唯一口径，阈值 `1,000,000` 与 `10,000,000`，并与编辑器阈值独立。
  **原因**：多字节字符按真实体积处理；统一口径避免警告、信息条与大小显示不一致。
  **边界**：恰好 `1,000,000` 不警告；恰好 `10,000,000` 仍为常规视图；`10,000,001` 起简化浏览；二进制判定优先于体积分级。

- **规则**：大文件警告与非 UTF-8 提示使用正文外横幅。
  **原因**：不污染原文，不移动行号，不被误复制。
  **边界**：横幅不参与选择、复制与行号；简化浏览信息条同理；区段加载失败信息追加在信息条并保留已加载内容。

- **规则**：二进制内容显示占位、类型、HEAD 字节数，并提供系统默认程序打开。
  **原因**：二进制按文本解码无意义；系统打开满足查看需求且不引入写仓库能力。
  **边界**：前 8 KiB 含 NUL 即判定；不显示行号、查找、自动换行与字号调整；系统打开经系统临时目录中转；打开失败保留占位并提示。

- **规则**：`Ctrl+S` 被消费并显示轻提示。
  **原因**：只读面板不能保存，静默消费会让用户误以为已保存。
  **边界**：不写盘、不标脏、不进入脏状态聚合；提示短暂且不打断操作。

- **规则**：面板关闭前始终存活，切换面板、面板组或项目只改变显隐与激活。
  **原因**：保留阅读状态，避免无谓重读；与项目布局多项目同时存活的模型一致。
  **边界**：关闭后重开与应用重启重新读取 HEAD；HEAD 内容、滚动、查找、自动换行与已加载区段不持久化；全局编辑器字号独立持久化。

- **规则**：显式打开或激活时聚焦只读内容区，布局恢复与启动恢复不抢焦。
  **原因**：键盘用户打开后应能直接操作；恢复场景不打断用户当前焦点。
  **边界**：焦点迁移可因面板切走而取消；隐藏期间完成读取不抢焦；刷新、过期提示与重试不移动焦点；简化浏览与二进制占位可聚焦，错误态聚焦重试。
