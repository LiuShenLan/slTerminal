# 设置中心

> 拥有设置视图、配置页交互、快捷键编辑、主题管理、Agent 与 Hooks 配置界面；应用设置单例、持久化、Document、PathPolicy、备份、Runtime 和系统集成的底层契约由各自所有者定义。

## 视图模型与入口

- Settings 是封闭面板类型之一，归属于一个项目布局；每个项目最多一个，可在该项目内拆分、合并和排序，禁止跨项目移动。
- `Ctrl+,` 与活动栏配置按钮使用同一命令。有活跃项目时打开或聚焦该项目唯一 Settings；无项目时打开应用设置浮层，不隐式创建项目或面板。
- 无项目浮层提供全部应用级页面：快捷键、后台任务、外观、终端、应用、Agent 基础配置和 Hooks User；项目级 Hooks 与项目专属内容隐藏。
- 浮层与项目内面板订阅同一应用设置单例，不建立第二份生效值或保存队列。浮层打开期间项目被激活时不自动关闭；下次打开才使用项目内 Settings。
- 重复入口只聚焦既有视图，不重置选中页或 Hooks 草稿。设置中心是其所在组当前面板时，配置按钮保持激活；被其他页签覆盖或位于非活跃项目时不激活。
- 恢复发现同项目重复 Settings 时保留首个、移除其余并聚合提示，不产生第二份 Hooks 草稿。

## 导航与页面状态

- 左导航宽 180 逻辑像素，顺序固定为全局组与 Agent 组。全局组依次为快捷键、后台定时任务、外观、终端、应用。
- 每个已注册 CLI 的 Agent 分节包含“基础配置”和“Hooks”；分节标题只折叠，不是页面。没有 Agent 页面时整组隐藏。
- 左导航可按页面标题、CLI 名和分组名过滤；大小写不敏感，`Esc` 清空。搜索只过滤导航，不改变选中页或配置值。
- 底部提供“导入设置”“导出设置”“恢复所有设置默认”；普通页提供“恢复本页默认”，Hooks 不提供页级恢复默认。
- 选中页和已声明页内视图参数属于 Settings 的 `ViewKey` 状态，关闭重开与应用重启均恢复；无项目浮层使用独立应用级逻辑视图键。
- 未知或已失效选中页回退到第一个可用页面并提示；不创建空白页面。项目级页面在无项目浮层中不可选，但不改写项目内 Settings 的持久选择。
- 快捷键录制、菜单、通知、临时错误、焦点、未提交输入草稿和行内校验为瞬态，关闭重开与重启均清除。切换配置页会卸载原页，未提交输入草稿不保留；已经生效的应用设置不受影响。
- Hooks 草稿例外：按“面板＋CLI＋层级”持有，切页、切层、关闭或根重定位必须经保存／丢弃／取消守卫，不得按普通输入草稿丢弃。
- Hooks 当前层级与编辑模式均为运行期界面状态，重新创建视图后回到 User 与 JSON；关闭重开和重启采用相同规则。

## 保存与关闭

| 页面或操作 | 保存方式 |
|---|---|
| 快捷键、外观、终端、Agent 基础、应用 | 立即生效，停止操作 2 秒后统一保存 |
| 后台任务、导入、恢复默认、清理 | 显式提交，立即执行 |
| Hooks | 手动保存，保留草稿直到成功或显式丢弃 |

- 所有页面统一显示保存中、已保存或保存失败与重试；自动保存失败明确“本次运行生效、重启可能丢失”。失败不阻塞继续编辑，也不只写控制台。
- 关闭任一 Settings 不取消全局应用设置待写队列；其他设置视图仍同步最新值。关闭时不把全局待写失败伪装成该面板的本地脏草稿。
- Hooks 草稿参与工作区统一关闭守卫。保存失败或取消时保留相关面板与草稿；显式丢弃只影响关闭集合中的草稿，不影响其他项目或层级。
- 应用退出先冲刷设置并提交最终状态；失败按 [工作区壳](../workspace/shell.md) 与 [设置与持久化](../settings-and-persistence.md) 处理，不自动强退或静默丢失。
- 权限、锁、I/O、损坏、高版本和字段错误严格按持久化分流；设置中心不得把读取失败显示成首次使用，也不得在更高版本数据上覆盖写入。

## 快捷键页

- 页面从 [统一命令目录](../cross-cutting.md) 生成，按全局、终端、编辑器、文件浏览器与补全上下文分组；本文不维护第二份命令清单。
- 文件树动作、终端回滚搜索、补全接受与导航均进入目录；固定键参考只读展示，不进入录制或冲突检测。
- `Ctrl+C` 在终端输入上下文永久保留为中断；该保留不阻止文件树等非终端上下文重绑自己的复制命令。默认复制仍为 `Ctrl+Shift+C`。
- 每行显示默认键、用户覆盖、额外绑定或“未绑定”；点击行或按 `Enter`／`Space` 进入录制，`Esc` 取消，`Backspace`／`Delete` 解绑，复位按钮恢复默认。
- 录制期间暂停普通命令派发；只按修饰键和 IME 组合按键不形成绑定。录制结束、页面卸载、面板失活或关闭后必须恢复派发。
- 命中当前上下文的保留键时拒绝并继续录制；同上下文冲突允许保存但必须显示冲突命令与实际派发优先级。不得用复制或其他绑定取代终端 `Ctrl+C`。
- 非法、未知命令或越界覆盖不生效并进入可见修复清单，可逐条或全部恢复默认；不得静默删除坏值。
- 键名按 Ctrl、Shift、Alt、Meta 与符号键的稳定顺序显示；显示格式与持久格式由统一命令目录转换。

## 后台定时任务页

- 页面异步读取统一任务清单；读取失败显示错误与重试，不用空清单伪装失败。

| 任务 | 默认状态 | 默认周期 | 范围 |
|---|---|---|---|
| 套餐余量查询 | 启用 | 60 秒 | 30–3600 秒 |
| 会话历史刷新 | 启用 | 3 秒 | 2–300 秒 |

- 启用开关立即提交；频率只接受整数，在失焦或 `Enter` 时提交。非法输入保留草稿并显示范围，不写盘。
- 提交期间防止同页并发写入；成功后用返回清单刷新，失败保留提交前生效值和用户输入。恢复本页默认经确认后一次提交，部分失败不得报告成功。
- 套餐查询在导航隐藏时仍按调度运行，应用退出后停止；历史扫描只在导航可见时运行。周期修改从下一次调度生效。
- 手动刷新始终可用，不因自动任务停用而失效；套餐页脚是否显示仍按导航规格判定。

## 外观页

### 主题与界面

- 仅暗色。默认内置主题为 `Linear`；内置主题不可重命名或删除。
- 支持导入、选择、重命名和删除自定义暗色主题。导入通过系统文件选择器取得本次读取授权，完整解析与校验成功后才加入主题集合；非法文件零写入并保留原选择。
- 自定义主题与内置主题都必须提供完整语义 token 和 ANSI 映射；缺项、未知色值、非法结构或危险外部引用均拒绝，不生成部分主题。
- 主题重命名只改显示名，不改变稳定主题身份或既有选择。删除未使用主题需确认；删除当前使用主题前必须先选择另一主题，不自动替选。
- 主题切换立即重绘全部视图，不重载 Document、不重启 PTY。仅暗色，不做对比度校验、提示或自动回退，也不因透明度、材质或密度组合改写主题。
- 自定义主题包不进入普通设置导出；加密备份是否包含主题由 [备份与恢复](../backup-and-recovery.md) 定义。
- 窗口材质提供无、Mica、Mica Alt、Aero、Acrylic，默认无；平台不支持时禁用并说明。材质不改变语义 token。
- 界面密度为紧凑、标准、宽松，默认标准；所有颜色引用主题 token。

### 字体、侧栏与文档

- 终端与编辑器分别选择等宽字体族和 8–32 的整数字号；非法输入不提交。字体不可用时回退默认等宽字体并提示，字号变化不重启终端。
- 侧栏默认布局控件与活动栏共享同一状态，可调整按钮显隐、排序和上下槽归属；恢复默认只重置这些组织项，不改变侧栏可见性、宽度、比例或项目布局。
- “新面板默认自动换行”默认关闭，只影响之后创建的视图；已有 `ViewKey` 的换行状态不被覆盖。
- Diff 重算间隔默认 300 毫秒，范围 100–2000 毫秒；只改变后续调度。
- “Document 自动保存”默认关闭，统一覆盖 Editor、Markdown 源码与可编辑 Diff。触发与冲突规则由 [Document](document.md) 拥有，不另设面板级开关或计时器。
- “Document 崩溃恢复”默认开启，统一控制新快照写入；关闭不影响既有快照的显式恢复或删除。

## 终端页

- 默认 Shell 为自动、显式候选或自定义路径；自动链为 `pwsh.exe` → `powershell.exe` → `cmd.exe`。显式或自定义失败不静默换 Shell。
- 自定义路径必须为存在的可执行文件绝对路径；非法输入行内提示且不提交。默认 Shell 与回滚容量只影响之后新建的逻辑终端。
- 回滚默认 10,000 行，可配置 1,000–100,000 行；非法输入保留且不提交。
- 非聚焦 OSC 52 写入默认关闭；开启也只作用于活跃项目内获准终端，隐藏项目始终拒绝。
- 光标闪烁默认开启；系统减少动效时默认关闭，用户可显式覆盖。光标形状固定竖线。

### 补全与本地历史

- 补全默认开启，形态为 Inline、Popup、Hybrid；修改立即作用于后续候选，不中断当前输入。
- 命令历史与目录历史采集可分别停用和清空，并明确披露只来自可信 Shell 输入行；关闭补全显示不隐含关闭采集，关闭采集也不改变既有 Shell／CLI 历史。
- 清空操作需确认，同时取消待写并清除内存数据；失败保留可见错误，不报告已清空。
- 历史只存本机且有界淘汰，不进入普通设置导出、加密备份、日志或诊断。设置页不展示历史正文，也不提供秘密扫描承诺。
- 补全详细可信行、方言、候选来源和快捷键语义由 [终端面板](terminal.md) 拥有。

## 应用页

应用页为单页分节，全部可用，不设置迁移占位。

- **界面语言**：`System`、`English`、`简体中文`，默认 `System`；切换即时生效，系统语言无法匹配或缺译时使用 English。
- **更新**：显示版本与检查状态；自动检查默认开、后台下载默认关，手动检查常驻。下载、校验、确认安装与统一关闭按 [系统集成](../system-integration.md) 执行。
- **托盘与开机启动**：分别显示应用设置与 Windows 实际启动项状态；关闭窗口始终退出，静默启动只用于登录自启且依赖托盘。
- **通知**：桌面通知总开关和任务栏闪烁开关；不提供按类别开关或免打扰时段。总开关不关闭应用内错误与提示。
- **Runtime API**：只读显示 v2 运行状态、非敏感端点和随包文档入口；不提供远程监听或 token 回显。凭据读取、替换或删除失败必须可见。
- **诊断**：提供版本、数据与日志目录、配置健康、复制诊断、打开目录、通知与环境自检、白名单诊断包和分类清理；预览、脱敏与清理边界由系统集成拥有。
- **备份与恢复**：提供加密导出、恢复和恢复点撤回入口，具体类别、口令、预检、回滚与指纹规则由备份规格拥有。
- 应用页不显示真实凭据，不保存代理凭据，不把文件正文、终端输出、历史正文或剪贴板放入诊断。

### 套餐来源

- 只列出内置套餐来源，每来源最多一份配置；不提供自定义 Provider、模型、连接测试或 AI 助手设置。
- 每来源可设置、替换或删除专用查询 token。输入只用于本次凭据写入，保存后清空并不回显；已配置状态不显示 token 片段。
- token 只经凭据门面存 Windows 凭据管理器，不写应用设置、CLI 文件、普通导出、快照、备份、日志或诊断；不得从 CLI 配置或环境变量自动读取替代。
- “刷新并验证”调用导航的同一查询链路，不另设连接测试。凭据写入与查询结果分别反馈；查询失败不伪装已验证，也不自动删除凭据。
- 删除凭据是显式操作并需确认；备份恢复、恢复默认和普通设置导入不得静默创建、替换或删除凭据。
- 来源缺少 token 时显示“需要配置查询 token”，不发起匿名猜测或读取其他认证材料。

## Agent 基础配置页

- 展示模式、自定义名单、CLI 别名和“显示运行时文件”按 CLI 保存；运行时文件清单按 AgentRoot 保存；自定义 AgentRoot 是全部 CLI 页面共享的应用级集合。
- 展示模式为全部或自定义。全部模式可按运行时清单隐藏根层条目；自定义模式只显示名单中的根层完整同名条目，运行时开关禁用但保留值。
- 名单和运行时清单只接受单个名称：非空、不含 `/` 或 `\`、在同一清单内大小写不敏感唯一；不支持路径、通配符或深层匹配。
- 别名添加后立即用于 CLI 识别；非空、最长 32 字符，不含空白、引号或反引号，不以 `-` 开头。全部 CLI 的内置命令与别名在 Windows 大小写规则下共享唯一命名空间。
- 未注册 CLI 的既有设置原样保留，不因页面未显示、恢复默认或设置写回而删除。

### AgentRoot 管理

- 内置根不可删除或改路径；自定义根可添加、编辑显示名或目录、删除。所有根都具有稳定身份，显示名不是授权依据。
- 添加或改路径时必须完成真实目标查重；同一真实目录只允许一个 AgentRoot，包括内置根与不同词法别名。无法完成查重时拒绝且保留原配置。
- 每个 AgentRoot 默认只读且禁止终端；“允许写入”和“允许终端 cwd”是两个独立显式开关，读取授权不推导其他能力。
- 修改目录按撤销旧根并登记新根处理：新根校验与必要状态提交成功后才替换，旧根监听和授权撤销；失败保留旧根。不得把旧路径授权静默延续到不同真实目录。
- 删除只移除根配置，不删除磁盘文件；确认后立即撤销读取、写入和终端授权并停止监听。已打开 Document 按 PathPolicy 保留内容、停止刷新；既有 PTY 不因此被强制终止。
- 自定义根删除后清理其视图状态；未注册或暂时不可访问的既有根保留配置与错误状态，不自动改绑其他目录。
- 盘符根、Windows 目录和 System32 不允许作为自定义 AgentRoot；路径必须为绝对目录。
- 运行时清单恢复默认只重置当前 AgentRoot 的清单；页级恢复默认只复位当前 CLI 的展示配置、别名和内置根清单，不清除其他 CLI 或共享自定义根。

## Hooks 页

### 范围与草稿

- 每个声明配置编辑能力的 CLI 提供 Hooks 页；未声明时显示明确空态。Claude Code 的内置层级为 User、Project、Local，优先级为 Local > Project > User。
- User 编辑该 CLI 的用户级设置文件，Project／Local 编辑当前 Settings 所属项目根下的对应文件；切活跃项目不改变面板所属项目。
- 无项目浮层只提供 User；项目根不可访问时 Project／Local 禁用并显示原因，User 仍可用。
- 只修改目标文件的 hooks 子树，其他字段原样保留。文件不存在或没有 hooks 时按空配置进入编辑；JSON 损坏、权限或锁失败进入分类错误，不当作空文件。
- 草稿按“面板＋CLI＋层级”隔离。切层、外部重载、关闭、项目移除和根重定位均须经保存／丢弃／取消守卫；不得用一层草稿覆盖另一层。
- Hooks 声明的文件目标是受限的外部配置读写能力，只覆盖该文件所需操作，不派生目录浏览、任意写入或终端授权；实际访问仍经 PathPolicy。

### GUI 与 JSON

- 默认 JSON，可切 GUI；两种模式编辑同一草稿并同步。JSON 或 schema 非法时保留最后合法模型、禁用 GUI 与保存，并显示首条诊断和完整诊断入口。
- JSON 模式提供事件导航、语法与 schema 诊断；GUI 提供事件树、matcher 组和 handler 编辑。未知但 schema 合法的字段必须容错保留。
- 添加事件只列目录中未配置项；不支持 matcher 的事件明确显示全匹配。删除事件、matcher 或 handler 立即更新草稿，不额外确认。
- handler 类型为 command、http、mcp_tool、prompt、agent；事件目录声明各自可用类型与字段。GUI、JSON schema 与保存校验使用同一能力目录，不存在隐藏可写子集。
- Claude Code 事件目录覆盖 SessionStart、SessionEnd、Setup、UserPromptSubmit、UserPromptExpansion、PreToolUse、PermissionRequest、PermissionDenied、PostToolUse、PostToolUseFailure、PostToolBatch、Notification、MessageDisplay、SubagentStart、SubagentStop、TaskCreated、TaskCompleted、TeammateIdle、PreCompact、PostCompact、Stop、StopFailure、ConfigChange、CwdChanged、FileChanged、InstructionsLoaded、DirectoryAdded、WorktreeCreate、WorktreeRemove、Elicitation、ElicitationResult。
- 含 slTerminal 注入标识的托管 handler 在 GUI 中只读，包含它的 matcher 与事件不得经 GUI 删除；不得借普通编辑静默移除托管内容。

### 保存与外部修改

- 保存仅在存在草稿且 JSON 与 schema 合法时可用。User 保存前明确警告 hooks 可执行任意命令；Project／Local 按统一显式保存流程执行。
- 写前重新读取并解析目标，比较外部版本，取得对应操作锁并创建上一代有效备份；任一步失败均不写目标。
- 只替换 hooks 子树并原子写，父目录按需创建；原文件不得出现半写。保存成功后清除草稿并提示重启对应 CLI 会话生效。
- 外部修改、锁冲突、备份失败或写失败均保留草稿和重试，不自动合并或覆盖外部内容。
- 当前页可见且所属项目活跃时监听当前层文件；变化只显示“已外部修改”和重新加载，不自动覆盖草稿。隐藏时停止监听，重新可见合并复核一次。
- 项目根重定位前必须处理 Project／Local 草稿；成功后按新根重新取得授权，不把旧根草稿写回旧路径或自动带到新路径。

### 注入与卸载

- 注入状态为查询中、已注入、未注入、版本过旧或查询失败；失败提供重试，不把未知显示成未注入。
- 注入可安装 slTerminal 托管 handler、脚本和状态行桥接；用户原有可疑下载或任意执行命令命中时先暂停并显示确认条，未确认前设置文件零写入。命令原文只显示在确认界面，不进入日志。
- 卸载只移除 slTerminal 托管内容，保留同组用户 handler，并按备份恢复或移除状态行桥接。
- 注入与卸载以用户级设置文件提交为边界：提交前失败回滚准备材料；提交后清理失败保留已提交事实并提供重试清理，不伪装成整体未执行。
- 目标 JSON 损坏时卸载失败并保留脚本与信号材料，避免形成配置残留但执行体已删除的悬空状态。
- 完成后刷新状态并重读 User；若存在 User 草稿，重读前仍走外部修改守卫。注入只影响之后启动的 CLI 会话。

## 导入、导出与恢复默认

- 普通导出只含登记为非敏感的应用设置，不含自定义主题包、工作区、Hooks、任意 CLI 文件、凭据、历史学习数据、终端输出或快照；采用原子写。
- 导入依次完整校验版本与结构、预览影响域、确认、保留上一代有效备份、原子提交；预检失败零写入。凭据字段或未知版本直接拒绝。
- 恢复所有默认只重置已注册应用设置，不修改 Hooks、CLI 文件、项目布局、ViewKey、侧栏状态或 Windows 凭据；未注册 CLI 命名空间保留。
- 自定义主题导入和加密备份不走普通设置导入通道；恢复默认不等于删除自定义主题包，当前主题选择按主题规则单独处理。

## 状态与验收

| 状态 | 关闭重开 | 应用重启 |
|---|---|---|
| 选中页与声明的页内视图参数 | 按 `ViewKey` 恢复 | 按同一 `ViewKey` 恢复 |
| 已保存应用设置与主题、Agent 配置 | 恢复 | 恢复 |
| Hooks 已保存文件 | 重新读取 | 重新读取 |
| Hooks 未保存草稿 | 守卫后关闭；不持久化 | 不恢复 |
| 录制态、菜单、通知、错误、焦点、普通未提交输入 | 清除 | 清除 |
| Hooks 当前层级与模式 | User／JSON | User／JSON |

- **Given** 无项目浮层已有 Hooks User 草稿，**When** 外部意图激活项目，**Then** 浮层不自动关闭，草稿与全局设置队列均保留。
- **Given** Settings 选择某页并关闭重开或重启，**When** 恢复，**Then** 两条路径恢复同一选中页；搜索、录制、临时错误和焦点清除。
- **Given** 两个项目和一个浮层修改应用设置，**When** 关闭任一视图，**Then** 其他视图同步生效值，全局待写队列不被取消。
- **Given** 录制终端中断或文件树复制，**When** 检查保留键，**Then** 终端 `Ctrl+C` 永不被替换，文件树命令可在自身上下文重绑。
- **Given** 导入完整和缺 token 的自定义主题，**When** 校验，**Then** 完整主题可用，缺项主题零写入；删除使用中的主题前必须另选。
- **Given** 自动保存开启，**When** 在 Editor、Markdown 或 Diff 修改共享 Document，**Then** 三者遵循同一 Document 自动保存，不存在 Markdown 独立草稿开关。
- **Given** 套餐来源已有 CLI 凭据但未配置专用 token，**When** 查询，**Then** 不读取 CLI 配置或环境变量，界面要求专用 token；保存后不回显。
- **Given** 后台周期设置为 30 或 3600 秒，**When** 提交并隐藏导航，**Then** 新周期从下次调度生效且套餐继续查询；退出后停止。
- **Given** 两个自定义根以别名指向同一真实目录，**When** 登记或改路径，**Then** 拒绝重复；根删除后授权立即撤销且磁盘文件不变。
- **Given** AgentRoot 默认配置，**When** 新建、粘贴或以其为终端 cwd，**Then** 写与终端分别因未显式开启而拒绝，读取仍可用。
- **Given** Hooks User 草稿存在外部修改，**When** 保存或重载，**Then** 不覆盖外部内容或静默丢弃草稿；用户选择后才有对应写入。
- **Given** Hooks 注入提交后清理失败，**When** 查看结果，**Then** 显示已提交事实与重试清理，不回滚成虚假未注入状态。
- **Given** 普通设置导入含凭据字段或更高版本，**When** 预检，**Then** 零写入并拒绝；恢复默认不删除凭据或 Hooks。
