# 设置中心

> 负责设置中心面板的归属、入口与激活态、左导航与搜索、配置页目录与顺序、各配置页的用户契约，以及导入导出、恢复默认、保存状态与失败重试。不拥有设置数据模型与持久化机制（见 [settings-and-persistence.md](../settings-and-persistence.md)）、全局命令派发（见 [workspace/shell.md](../workspace/shell.md)）与侧栏默认布局的视图语义（见 [sidebar/framework.md](../sidebar/framework.md)）。

## 目标行为

### 面板归属与唯一性

- 设置中心是面板类型封闭集成员，是项目布局中的普通面板；每个项目最多一个设置中心面板。
- 设置中心不是模态框、独立窗口或侧栏视图；关闭面板即离开设置中心。
- 面板页签标题固定为 `设置中心`；入口按钮的提示与名称统一为 `设置中心`。
- 设置中心可被拖到同项目的其他面板组、与其他面板合并页签、在同面板组内排序，也可被关闭；禁止跨项目拖拽。关闭后不保留占位。
- 设置中心可位于任意面板组，不强制固定位置；移除项目时，面板随项目布局关闭。
- 布局恢复若在同一项目发现多个设置中心面板，保留第一个并静默关闭其余实例；该过程不产生未保存状态与关闭确认。

### 入口与激活态

- 常驻入口为活动栏底部的配置钮。该钮不是侧栏视图，不参与活动栏视图的拖拽、排序与持久化。
- `Ctrl+,` 为全局打开/聚焦命令；其命令派发、重绑与优先级由 [workspace/shell.md](../workspace/shell.md) 定义，设置中心只提供入口与激活态。
- 没有项目时，点击配置钮或按 `Ctrl+,`：打开仅含「应用」页的全局设置浮层；不创建项目、面板组或面板，不改变主区与活跃项目。
- 有活跃项目时：打开或聚焦活跃项目的设置中心；不切换活跃项目，不创建第二个设置中心面板。
- 设置中心已存在但未激活时：激活其页签、聚焦所在面板组，并把键盘焦点落到面板根容器；不重置选中页，不丢弃未保存修改。
- 设置中心不存在时：放入活跃项目当前聚焦的面板组；项目布局内没有任何面板组时，先创建第一个面板组。落点规则由 [workspace/shell.md](../workspace/shell.md) 统一约束。
- 重复点击配置钮或重复执行 `Ctrl+,` 不增加面板数量；面板已激活时只重新聚焦。
- 激活态规则：活跃项目内，设置中心是其所在面板组的当前面板时，配置钮显示持续激活态并高亮，不论该面板组是否聚焦；面板被其他页签覆盖，或设置中心位于非活跃项目布局时，不高亮。
- 无项目设置浮层是应用根部模态覆盖层：仅渲染应用页和底部 `导入设置`、`导出设置`、`恢复所有设置默认`；遮罩阻止背景交互，`Esc`、关闭按钮或取消关闭；重复触发只聚焦，不叠加。
- 浮层与项目内设置中心复用同一设置模型与应用页组件，不产生第二套保存状态；项目激活后浮层自动关闭，`Ctrl+,`/配置钮转为项目内设置中心，不自动打开项目设置中心。

### 项目作用域

- 左导航顶部显示不可点击的项目上下文 `所属项目：<项目名>`。
- 全局组与 Agent 基础配置属于应用级配置，作用于全部项目；Hooks 的 Project 与 Local 层属于项目级配置，作用于设置中心所属项目。
- 配置页页头以 `应用` / `项目` 作用域标识区分；Hooks 在 Project/Local 层同时显示所属项目名。

### 左导航与配置页目录

- 面板内部由左导航与右侧配置页槽位组成。左导航固定宽 180px（逻辑像素，随系统缩放），不可拖拽调整；内容超出时纵向滚动。右侧槽位占据剩余宽度。
- 左导航组序固定：先 `全局`，后 `Agent`；不新增独立的项目组。
- `全局` 组依次为：快捷键、后台定时任务、外观、终端、应用。
- `Agent` 组按已注册 CLI 分节：
  - 每个分节显示 CLI 品牌 logo <img src="../assets/cli-svg/claude.svg" width="14" height="14" alt="CLI 品牌 logo 示例">（按 AgentKind 取 `../assets/cli-svg/<slug>.svg`，14×14）与显示名称；无品牌资产的 CLI 只显示名称。
  - 分节标题不是配置页入口；点击只折叠或展开该分节，不改变选中页。
  - 分节下缩进显示该 CLI 的配置页：`基础配置` 与 `Hooks` 恒有；`Hooks` 在未声明配置编辑器能力时显示提示态。
  - 没有任何 Agent 配置页时，Agent 组整组不渲染。
- 左导航不提供运行期新增、删除、重命名或重排配置页的入口。
- 左导航顶部提供搜索框：按配置页标题、CLI 显示名与分组名过滤，大小写不敏感；`Esc` 清空；无结果时显示 `无匹配配置页`。搜索只过滤导航，不改变配置页目录、选中页或配置页状态。
- 左导航底部提供 `导入设置`、`导出设置` 与 `恢复所有设置默认`。每个配置页页头右侧提供 `恢复本页默认`；Hooks 页不提供该项。
- 配置页目录在应用启动时确定，运行期不变；安装或移除 CLI 后需重启应用才更新配置页目录。
- 同一配置页标识被重复提供时只显示一条，后提供者生效。目标顺序：全局组为快捷键 → 后台定时任务 → 外观 → 终端 → 应用；每个 CLI 分节内为基础配置 → Hooks。
- 没有任何配置页时，右侧居中显示 `暂无配置页`，左导航不渲染任何组。
- 导航项是按钮：选中项使用选中底色；有手动未保存修改时右侧显示 7px 中性色圆点；自动保存失败时显示独立的失败徽标。
- 左导航完全键盘可达：方向键在导航项间移动，Home/End 跳到首/末项，Enter/Space 激活；分节标题可聚焦并用 Enter/Space 折叠或展开；焦点环使用主题语义 token。折叠状态只在本次面板生命周期内保留。
- 分组折叠时，若组内存在手动未保存或保存失败的配置页，组标题显示聚合状态标识。
- 同一面板组切换到其他页签、切换项目、把面板拖到同项目其他面板组，都不卸载设置中心；未保存修改与选中页保留。
- 在设置中心内部切换配置页会重新挂载目标页内容；离开的配置页的页内临时状态（快捷键录制态、后台任务输入草稿、终端页输入与行内错误、Agent 输入与行内错误、Hooks 层级/模式/未保存编辑）按保存与关闭守卫处理，返回时不恢复。
- 关闭设置中心面板或应用重启才销毁面板本身与其中未持久化的页内临时状态。

### 选中页与面板参数

- 面板创建时读取已保存的选中页：目标页已注册时直接选中；缺失、失效、未注册或属于已移除 CLI 时，回退到全局组第一页；全局组没有页时，回退到第一个已注册配置页；没有任何配置页时选中页为空，右侧显示空态。
- 正常用户入口不携带初始配置页；程序化打开可携带一个可选初始页，目标页已注册时选中，否则按回退规则处理。
- 外部更新面板参数中的选中页时，目标页已注册则同步切换；未注册的标识被忽略，不弹提示。
- 切换配置页不改变面板的打开状态、所在面板组或所属项目。
- 用户切换配置页后，选中页写入面板参数；各配置页的页内参数独立保存、合并写入，不覆盖其他配置页的参数。
- 选中页与页内参数随项目布局持久化，不写入应用设置。切换配置页、写入页内参数会立即更新面板参数并触发一次布局保存；布局保存失败按 [workspace/shell.md](../workspace/shell.md) 处理，设置中心不另设提示。
- 关闭设置中心面板会把它从项目布局中移除；重新打开是新建面板，不恢复上次选中页与页内参数，按回退规则选择第一个可用配置页。
- 应用重启时若面板仍在项目布局中，按保存的选中页与页内参数恢复；指向未知配置页的标识与未知页参数被忽略。

### 保存模式与未完成状态

- 设置中心采用按域三模式：自动保存、手动保存与提交即保存。每页页头声明保存模式，不统一为全显式或全自动。
- 保存模式：
  - 快捷键、外观、终端、Agent 基础配置、应用：`自动保存`。
  - Hooks：`手动保存`。
  - 后台定时任务：`提交即保存`。
- 三种模式统一显示 `保存中`、`已保存` 或 `保存失败` 及重试入口；失败不得只记录到控制台。
- 设置中心区分两种未完成状态：

| 状态 | 产生条件 | 导航标识 | 切换配置页 | 关闭面板 | 应用重启 |
|---|---|---|---|---|---|
| 手动未保存（dirty） | Hooks 页存在未保存编辑 | 7px 圆点 | 需确认丢弃 | 需确认丢弃 | 不保留 |
| 自动保存未完成或失败 | 自动保存配置已生效但尚未保存，或保存失败 | 失败徽标 | 不丢弃，继续保留并重试 | 先尝试完成待写保存；失败时进入关闭守卫 | 不保留内存值 |

- 手动未保存状态只在确认丢弃或保存成功时清除；面板隐藏、切换配置页时取消、切换项目都不清除。
- 当前配置页有手动未保存修改时点击其他配置页：
  - 弹出确认框，标题 `未保存的修改`，正文 `当前配置页有未保存的修改，切换将丢弃这些修改。`
  - 按钮为 `取消` / `丢弃修改`。确认后清除当前页未保存状态与圆点并切换；取消则保持当前页、修改与圆点不变，不写入面板参数。
- 当前配置页没有手动未保存修改时直接切换；自动保存未完成或失败不阻止切换配置页。
- Hooks 页切换层级时，当前层有未保存修改：确认框正文 `当前层有未保存的修改，切换层级将丢弃这些修改。`；确认后切换并重新读取，取消保持当前层与修改。
- Hooks 页因外部修改重载时，有未保存修改：确认框正文 `配置文件可能已被外部修改。重载将丢弃当前未保存的修改。`；确认后覆盖当前编辑，取消保持现状。
- 关闭设置中心面板时，手动未保存状态与待写/失败自动保存登记参与工作区统一关闭守卫；单个关闭确认中，设置中心的正文为 `设置中心有未保存的修改，关闭将丢弃这些修改。`
- 批量关闭（关闭其他、关闭全部）按面板组聚合，一次确认；设置中心与其他未保存面板一起列出标题，取消则全部不关闭。跨项目聚合确认以 `设置（<项目名>）` 区分。
- 切换项目不关闭、不确认设置中心面板；面板随所属项目布局隐藏，未保存状态、保存失败状态、选中页与页内状态全部保留，切回时恢复。
- 移除项目时，工作区聚合确认列出该项目内的未保存面板标题；设置中心若存在未保存修改或保存失败，参与列出。确认后项目布局关闭，未保存修改丢弃，不再逐面板二次确认。
- 关闭应用时，工作区统一聚合确认；设置中心的未保存修改与保存失败参与守卫。关闭前的待写设置冲刷由 [settings-and-persistence.md](../settings-and-persistence.md) 定义。
- 关闭设置中心面板时，先尝试完成该面板产生的待写自动保存：成功则直接关闭；失败则进入关闭确认，取消则保留面板与失败状态。
- 面板被激活（新打开、页签被选中、配置钮聚焦已有面板）时，键盘焦点落到面板根容器；根容器不在 Tab 顺序中，按 Tab 进入左导航。根容器没有可见输入框，聚焦后直接键入不会改动任何配置。
- 确认弹窗关闭后的短暂焦点回归不会再次触发同一确认框；弹窗打开期间重复触发被忽略。
- 设置文件损坏时，面板顶部显示警示条 `设置文件已损坏，已从备份/默认值恢复`，右侧 `×` 可关闭；关闭后本次面板生命周期内不再显示，且不阻塞配置操作。重新打开面板会重新检查加载结果。

### 快捷键页

- 配置页按分组展示全部可重绑命令，分组顺序固定：全局 → 终端 → 编辑器 → 文件浏览器。
- 命令目录以工作区全局命令表为准，包含切换侧栏、聚焦活动栏、侧栏视图快捷键与设置中心打开命令；焦点循环在固定键参考中只读展示；不包含终端搜索、Diff 的 F6/F7 与面板内固定键。

- 焦点循环 `Ctrl+Tab`/`Ctrl+Shift+Tab` 是固定系统键：不进入可重绑目录、不写入快捷键覆盖，始终由焦点协调器在面板固定键层之前消费；终端与编辑器不得拦截。
- 派发优先级从高到低：临时面（对话框/菜单/内联编辑）→ 系统键 → 面板固定键/保留键 → 面板命令 → 侧栏视图快捷键 → 全局命令 → 终端输入。快捷键录制与输入法组合是前置门控：录制期间命令派发整体暂停；组合态零命令匹配。
- 系统键指操作系统窗口管理键（如 `Alt+F4`、`F10`）与焦点循环 `Ctrl+Tab`/`Ctrl+Shift+Tab`；操作系统已消费的键不进入应用派发。
- 终端上下文 `Ctrl+Shift+A` 为选区全选，优先于同和弦的全局“显示/隐藏 Agent 文件”；焦点不在终端时后者生效。该冲突由固定层序裁决，不进入可重绑冲突警告。

- 侧栏视图快捷键在当前视图已可见且聚焦时再次按下，关闭该视图；由 [sidebar/framework.md](../sidebar/framework.md) 定义显隐迁移。
- 快捷键页显示采用用户符号键名格式：修饰键固定按 Ctrl、Shift、Alt、Meta 的顺序，末段用符号键名，例如 `Ctrl+W`、`Ctrl+Shift+C`、`Alt+Z`、`Ctrl+,`、`Ctrl+Shift+[`；内部存储与测试使用物理键名（`Ctrl+KeyW` 等），两者按固定映射转换，未知标点回退物理键名。
- 每行显示当前生效键：
  - 无用户覆盖：显示默认键，普通颜色，不显示复位按钮与默认键小字。
  - 有用户覆盖：生效键用强调色显示，显示 `↺` 复位按钮与默认键小字；复位按钮提示 `恢复默认键`。
  - 用户解绑：显示 `未绑定`；`↺` 仍显示，点击恢复默认键。
- 行内没有单独的编辑按钮；点击整行或聚焦行后按 Enter/Space 进入录制态，行内显示 `按下新键位…Esc 取消`。
- 录制期间：
  - 应用全局快捷键暂停消费，录制按键不会触发对应命令；录制结束、取消、配置页卸载、面板关闭或面板失活（切换到其他面板、切换项目、焦点移出设置中心）后恢复。
  - 按 `Esc` 取消录制，不写入任何绑定。
  - 按 `Backspace` 或 `Delete` 解绑该命令，行变为 `未绑定`。
  - 只按修饰键（Ctrl、Shift、Alt、Meta）被忽略，保持录制等待下一键。
  - 输入法组合态中的按键被忽略，不视为录制按键；组合结束后按键按正常规则处理。
  - 命中保留键：行内显示红字 `保留键 <键名> 不可绑定`，不写入并保持录制，等待下一个按键。
  - 命中同一上下文内其他命令的生效键：允许写入，行内显示警告 `与「<命令名>」冲突，生效按优先级派发`；警告保持显示到下一次开始录制。
  - 合法按键：写入覆盖并退出录制。
- 点击 `↺` 清除该命令的覆盖或解绑状态，回退默认键，且不会误进入录制。
- 保留键集合：
  - 终端上下文：`Ctrl+KeyC`、`Ctrl+KeyV`、`Ctrl+KeyX`、`Ctrl+KeyZ`、`Ctrl+KeyA`。
  - 编辑器上下文：`Ctrl+KeyF`、`Ctrl+KeyZ`、`Ctrl+KeyY`、`Ctrl+Shift+KeyZ`、`Tab`、`Shift+Tab`。
  - 全局上下文：上述保留键集合的并集。
- `终端中断` 的默认键 `Ctrl+C` 是保留键，不属于用户可写覆盖；终端上下文中的 `Ctrl+C` 始终透传为中断信号，快捷键派发不消费该键；用户仍可将该命令改绑到其他非保留键。
- 同一上下文键位冲突不在写入时拦截；运行期按固定派发层序决定实际生效者，面板命令高于侧栏视图快捷键与全局命令。
- 覆盖层改动在 2 秒无后续操作后保存；保存期间行内显示 `保存中`，成功后显示 `已保存`，失败时显示 `保存失败` 与重试入口，并提示 `设置保存失败，修改仅在本次运行中生效`。
- 启动加载或运行期重新建立快捷键绑定时，用户覆盖若绑定到保留键、格式非法或指向未知命令：
  - 该覆盖不生效，命令使用默认键。
  - 快捷键页顶部显示修复横幅 `检测到 <N> 条无效快捷键覆盖`，列出命令与原始值。
  - 提供 `全部恢复默认` 与逐条 `恢复默认`；修复后保存并清除横幅。
  - 无效值不得静默消失或仅记录到控制台。
- 配置页重新挂载时录制态与行内提示重置；覆盖层保存在全局设置状态中，跨配置页切换、切换项目与面板隐藏保留。

### 后台定时任务页

- 配置页向应用任务调度器读取任务清单与当前生效配置，每个任务一行：
  - 标题与启用勾选框。
  - 频率输入框，标签为 `<任务标题>频率（秒）`。
  - 范围提示 `<最小值>–<最大值> 秒`，只写范围，不写默认值。
- 任务与设计契约：

| 任务 | 默认状态 | 默认频率 | 允许范围 |
|---|---|---|---|
| 套餐余量查询 | 启用 | 10 秒 | 10–3600 秒 |
| 会话历史刷新 | 启用 | 3 秒 | 2–300 秒 |

- 勾选或取消勾选立即提交；提交期间该行控件禁用并显示 `保存中`，不做乐观更新；提交成功后用返回的完整清单刷新所有行，提交失败时界面保持提交前的值并显示 `设置失败：<错误信息>`。
- 频率输入在失焦或按 Enter 时提交；提交前去除首尾空白。合法值必须是整数且落在该任务允许范围内。
- 非法输入（空串、非数字、小数、越界）在行下方显示红字范围提示（如 `10–3600 秒`），不提交、不弹提示，输入内容保留供修改。
- 调度器拒绝提交时显示 `设置失败：<错误信息>`；频率输入保留用户输入，不重置。
- 提交成功不弹提示；成功提交任何一种配置（勾选或频率）后，用返回清单刷新所有行，并在清单包含套餐余量任务时额外触发一次套餐余量刷新。
- 套餐余量任务由应用轮询：停用后停止后续执行，已有快照保留，导航树中的套餐余量区整块隐藏；重新启用后重新开始并显示最后快照；频率修改在下一次调度按新间隔执行。
- 会话历史刷新由视图订阅触发：视图未打开或任务停用时只记录配置，不启动计时器；视图打开且任务启用时按配置执行并立即执行一轮；停用后停止后续刷新，已有历史列表保留。
- 任务配置属于应用级设置；任务页提交是显式动作，不经过去抖，立即保存。
- `恢复本页默认` 二次确认后将全部任务的启用状态与频率写回默认值，作为提交即保存立即写盘；失败不部分落地，保留提交前值并显示错误。
- 配置页挂载后异步读取任务清单：读取期间显示 `加载中…`；读取失败显示 `任务配置读取失败` 与 `重试`，不保留空白行区；任务清单为空时显示 `暂无后台任务`。

### 外观页

- 外观页提供暗色主题、字体、侧栏默认布局、编辑器与 Diff 行为、自动保存与 Markdown 草稿恢复配置；不提供浅色主题或跟随系统选项。
- 每套主题方案提供完整的语义 token 映射；透明度、壁纸、密度组合不做对比度校验、不提示、不自动回退。
- 主题方案：
  - 提供多套暗色主题方案，内置默认方案为 `Linear`。
  - 每套方案定义完整的语义 token 映射；切换立即生效并触发界面重绘。
  - 方案列表按内置注册顺序展示；不提供运行期新增用户主题。
- 字体：
  - 终端与编辑器分别设置字体族与字号。
  - 字体族从系统已安装的等宽字体中选择，并保留当前值；当前字体不可用时回退默认等宽字体并显示提示。
  - 字号为整数，范围 8–32；非法或越界输入在输入框下方显示红字范围提示，不提交，输入保留。
  - 字号变更立即作用于新绘制与既有视图；终端按新字号重新计算行列。
- 侧栏默认布局：
  - 展示活动栏各视图的默认布局控件：逐视图的显示/隐藏开关、排序控件（上移/下移或指针拖拽）、上区/下区归属选择，以及 `恢复默认侧栏布局`。
  - 每个区最多一个视图；排序、换区、显隐与视图状态的语义由 [sidebar/framework.md](../sidebar/framework.md) 定义，外观页只提供入口与控件，不建立第二套布局状态。
  - 隐藏的视图可从该页重新显示，也可通过该视图的全局快捷键恢复。
  - `恢复默认侧栏布局` 二次确认后恢复内置顺序、槽位归属与全部视图按钮可见；不改变侧栏可见性意图、宽度、分割比例、项目布局与面板内容。
- 透明度：
  - 提供窗口透明度滑块，范围 80%–100%，默认 100%。
  - 透明度调整不做对比度判断，不提示、不自动回退、不改写用户设置。
- 壁纸：
  - 提供 `选择壁纸` 与 `清除壁纸`，支持常见图片格式。
  - 壁纸仅作为窗口背景；终端与编辑器内容区保持主题背景，不做对比度准入校验。
  - 图片读取失败时保留原壁纸并显示 `壁纸加载失败`。
- 界面密度：提供 `紧凑` / `标准` / `宽松` 三档，默认 `标准`；即时作用于间距与行高。
- 编辑器与 Diff 行为：
  - `新面板默认自动换行` 开关，默认关闭；只影响之后打开的编辑器面板，已有面板保持自身换行状态。
  - `实时差异重算间隔` 数值输入，默认 300ms，范围 100–2000ms；只影响之后的重算调度，不改变已排队的计算。
  - `自动保存` 开关，默认关闭；与 [editor.md](editor.md) 一致。开启后编辑器在停止输入 1 秒后保存，失焦或关闭前立即保存；外部冲突、只读、二进制与大文件只读时暂停自动保存；保存失败保留未保存状态并沿用保存失败提示。该开关只作用于编辑器面板，不作用于 Markdown 源码态与 Diff。
  - `Markdown 草稿崩溃恢复` 开关，默认开启；关闭后 Markdown 编辑器不再写入草稿快照，应用异常退出后不提供草稿恢复提示。已有快照的恢复与清理按 [markdown.md](markdown.md) 执行。
- 外观页所有配置属于自动保存操作：立即作用于运行期状态，按域去抖保存；保存状态与失败重试按本文保存模型执行。页头显示 `自动保存`，不产生手动未保存状态。
- 打开配置页时读取应用设置状态，不重复读盘。

### 终端页

- 配置页包含 `启动与显示` 与 `交互` 两个配置节；所有配置按各项声明作用于此后新建的终端面板或运行中的终端视图。
- 默认 Shell：
  - 模式单选：`自动` / `显式` / `自定义路径`；默认 `自动`。
  - `自动`：按 [terminal.md](terminal.md) 的默认回退链选择（`pwsh.exe` → `powershell.exe` → `cmd.exe`），不指定具体 Shell。
  - `显式`：固定候选 `pwsh`、`powershell`、`cmd` + `自定义路径`；固定候选不可用时仍可选，创建失败显示具体原因；其他 Shell 走自定义路径并明确不承诺集成能力。
  - `自定义路径`：路径输入框与 `浏览…` 按钮；路径必须是绝对路径并指向存在的可执行文件。
  - 默认 Shell 只影响之后新建的终端面板；已有面板不重启、不切换 Shell。
- 回滚容量：
  - 整数输入，单位行，默认 10000，允许范围 1000–100000。
  - 在失焦或按 Enter 时提交；非法值（空串、非数字、小数、越界）在输入框下方显示红字 `1000–100000`，不提交、输入保留。
  - 只影响之后新建的终端面板；已有面板保持创建时的回滚容量。
- `允许非聚焦终端写入剪贴板` 开关，默认关闭：关闭时仅聚焦终端可经 OSC52 写入剪贴板；开启后活跃项目内的非聚焦终端也可写入，隐藏项目与后台非聚焦终端始终拒绝。单次写入上限与其余安全约束按 [terminal.md](terminal.md) 执行。开关即时作用于活跃项目内的终端面板。
- `光标闪烁` 开关，默认开启；系统启用减少动效时默认关闭，用户仍可显式开启：即时作用于全部终端面板；光标形状固定为竖线，不随该开关变化。
- 自定义 Shell 路径校验（输入先去首尾空白）：

| 条件 | 错误文案 |
|---|---|
| 空 | `路径不能为空` |
| 不是绝对路径 | `路径必须是绝对路径` |
| 文件不存在 | `Shell 路径不存在` |
| 不是可执行文件 | `Shell 路径不是可执行文件` |

- 终端页不提供终端配色方案、终端搜索、光标样式与终端输入模式页；这些能力不属于目标范围。
- 上述配置属于自动保存操作：开关与模式选择立即作用于运行期状态，回滚容量在合法提交后生效；按域去抖保存。页头显示 `自动保存`，不产生手动未保存状态。
- 打开配置页时读取应用设置状态，不重复读盘。

### 应用页

- 应用页是全局组最后一页，作用域为应用级，不按项目分叉；有活跃项目时在设置中心内访问，无活跃项目时在全局设置浮层中访问。
- 单页分节，顺序固定：界面语言、更新、托盘与开机启动、通知、Runtime API、AI Providers 与助手、诊断、备份与恢复、终端增强。
- 尚未迁移的节显示节标题与只读说明 `该能力由迁移版本提供`，不提供半成品控件；迁移完成后替换为完整控件，节序不变。
- 迁移前交付状态：

| 节 | 规格范围状态 | 迁移后状态 |
|---|---|---|
| 界面语言 | 只读说明 | 三档语言切换与即时生效 |
| 更新 | 只读说明 | 检查/下载开关、手动检查与更新入口 |
| 托盘与开机启动 | 只读说明 | 托盘开关与 Startup 快捷方式开关 |
| 通知 | 可用 | 保持 |
| Runtime API | 只读状态显示运行中/不可用，不提供开关 | 运行状态、端点与文档入口 |
| AI Providers 与助手 | 只读说明 | Provider 管理、助手配置与凭据门面 |
| 诊断 | 可用 | 保持，并接入迁移服务状态 |
| 备份与恢复 | 只读说明 | 导出、恢复、撤回与恢复点 |
| 终端增强 | 禁用态 `尚未启用` | 四个增强开关与补全形态 |
- 界面语言：`System` / `English` / `简体中文`，默认 `System`；语言切换即时作用于界面文案，保存失败时保留本次运行中的新语言并提示 `设置保存失败，修改仅在本次运行中生效`。该能力属于迁移能力，首版按只读说明显示。
- 更新：显示当前版本与检查状态；跟随系统代理；提供 `自动检查更新` 开关（默认开）与 `后台下载更新包` 开关（默认关）；手动“检查更新”按钮常驻；不提供 `仅手动检查` 独立开关，不提供应用内代理凭据配置。
- 托盘与开机启动：托盘开关；开机启动开关以 Startup 快捷方式实际存在为准，切换是显式平台动作；关闭窗口始终退出应用，托盘不改变退出语义。
- 通知：桌面通知总开关与任务栏闪烁开关；类别语义由 CLI 能力与工作区通知契约拥有，不提供按类别开关或免打扰时段。
- Runtime API：只读显示运行状态、端口与端点；不提供总开关，不显示 token；外部调用方经随包 CLI 或环境变量获取能力。
- AI Providers 与助手：Provider 列表、默认模型、base URL、忽略退出码等非敏感配置；密钥、token、cookie 只存 Windows 凭据管理器；导入导出、快照、日志与诊断不包含真实值。
- 诊断：版本/构建、数据目录、日志目录、配置健康、复制诊断信息、打开目录/日志、通知自检、导出诊断包、运行环境自检，以及 `一键清理日志/审计/更新下载/崩溃现场`。诊断包导出前显示内容预览与脱敏结果，只含白名单类别；自检异步显示通过/失败/不可用与原因，可重跑。清理前二次确认并列出将删除的范围；清理失败逐项可见。诊断信息默认脱敏，绝对路径替换为 `%USERPROFILE%` / `%PROJECT_ROOT%` / `%AGENT_ROOT%`，保留需显式勾选。
- 备份与恢复：导出加密备份、恢复备份、恢复点撤回；导出只含应用设置与选定类别，凭据、Hooks、CLI 配置、终端内容、剪贴板、崩溃快照不进入备份；口令只用于本次操作，不持久化。
- 终端增强：vi 模式、终端补全、数学覆盖层、AI 修复条开关；迁移前置灰并标注 `尚未启用`，迁移完成后启用。
- 保存模式为自动保存：开关与选择立即作用于运行期，停止操作 2 秒后写入；失败显示 `保存失败` 与重试。清理动作为显式动作，确认后立即执行，不进入去抖。
- 应用页不显示凭据值；所有错误与日志不插值凭据、token、配置文件内容或终端输出。

### Agent 基础配置页

- 配置页包含 `侧栏展示内容`、`CLI 别名`、`自定义 Agent 节点`、`运行时文件清单` 四个配置节，配置存储于应用级、不随项目变化；展示模式、自定义名单、显示运行时文件与 CLI 别名按 CLI 分域；运行时文件清单按 Agent；自定义 Agent 节点为应用级集合。
- 侧栏展示内容：
  - 展示模式单选：`全部` / `自定义`；默认 `全部`。
  - 选择 `自定义` 时展开自定义名单：
    - 名单项以 chip 展示，每项带 `×` 删除按钮；删除无确认，可重新添加。
    - 名单为空时显示 `名单为空——视图中不展示任何条目`。
    - 添加行包含输入框（占位 `输入文件/目录名`）与 `添加` 按钮；按 Enter 等价于点击 `添加`。
    - 添加成功后清空输入与错误；编辑输入即清除错误。
  - `显示运行时文件` 开关：默认关闭；仅 `全部` 模式下可操作；`自定义` 模式下置灰禁用但值保留，切回 `全部` 后恢复。
  - `全部` 模式下若该 Agent 的运行时文件清单非空，开关下方显示 `运行时文件：<名单>`；清单为空时不显示该行。
- 侧栏展示配置只作用于当前 CLI 在 `Agent 全局文件` 侧栏视图中的根层分组：按名称匹配，大小写不敏感，仅根层完全同名；目录内部内容随根层是否展示而展示或隐藏；其他 CLI 分组按各自的展示配置过滤。
  - `自定义` 模式：仅展示名单内的根层条目；运行时文件开关不参与判断。
  - `全部` 模式：展示全部根层条目；`显示运行时文件` 关闭时排除运行时文件清单内的条目。
- CLI 别名：
  - 顶部只读展示该 CLI 的内置命令 chip，下方提示 `内置命令已占用命名空间，不可配置为别名`；内置命令不可删除。没有内置命令时不显示该区域。
  - 别名 chip 带 `×` 删除按钮；删除无确认，可重新添加。
  - 无别名时显示 `暂无别名`。
  - 添加行包含输入框（占位 `输入启动命令别名`）与 `添加别名` 按钮；按 Enter 等价于点击。
- 所有操作即时生效，无手动未保存暂存；变更在 2 秒无后续操作后保存。保存成功显示 `已保存`；失败显示 `保存失败` 与重试入口，并提示 `设置保存失败，修改仅在本次运行中生效`。
- 自定义名单校验（输入先去首尾空白）：

| 条件 | 错误文案 |
|---|---|
| 空名称 | `名称不能为空` |
| 含 `/` 或 `\` | `名称不能包含路径分隔符` |
| 与已有名单项大小写不敏感重名 | `名称已存在` |

- 名单项只接受名称，不接受路径，不允许通过名单递归指定目录内部条目。失败时行内红字、输入保留；成功时加入名单并清空输入。
- CLI 别名校验（输入先去首尾空白）：

| 条件 | 错误文案 |
|---|---|
| 空 | `别名不能为空` |
| 超过 32 个字符 | `别名过长（最多 32 个字符）` |
| 含空白 | `别名不能包含空格` |
| 含单引号、双引号或反引号 | `别名不能包含引号或反引号` |
| 以 `-` 开头 | `别名不能以 - 开头` |
| 与本 CLI 已有别名重复 | `别名「<别名>」已存在` |
| 撞本 CLI 内置命令 | `「<别名>」是本 CLI 的内置命令` |
| 撞其他 CLI 内置命令 | `「<别名>」是「<CLI 显示名>」的内置命令` |
| 撞其他 CLI 的别名 | `「<别名>」已被「<CLI 显示名>」的别名使用` |

- 别名唯一性判定在 Windows 上不区分大小写（`cc` 与 `CC` 视为同一别名），覆盖全部 CLI 的命名空间与内置命令。
- 输入框失焦不提交、不清空草稿、不清除错误；使用真实鼠标点击 `添加` 按钮时，先发生的输入框失焦不会破坏随后的提交。
- 别名添加成功后在内存中即时生效：下一次命令行首 token 匹配即把该命令识别为对应 CLI，无需等待保存。
- `显示运行时文件` 的值按 CLI 保存；在 `自定义` 模式下虽然禁用，但仍会被保存，切回 `全部` 后直接使用该值。
- 当前 CLI 未注册（防御场景）时，CLI 别名区显示 `未知 CLI` 占位；侧栏展示内容区仍按默认配置渲染。
- 自定义 Agent 节点：
  - 管理面按添加顺序列出全部自定义节点；每行显示显示名与绝对目录，提供 `编辑` 与 `删除`。内置节点不出现在管理面，不可编辑或删除。
  - 添加行包含显示名输入框、目录输入框、`浏览…` 按钮与 `添加` 按钮；按 Enter 等价于点击 `添加`。
  - 编辑在行内展开并预填原值；`保存` 提交，`取消` 退出编辑且不改变原值。编辑中的行不显示删除入口，需先保存或取消编辑。
  - 删除二次确认，正文 `删除后仅移除节点配置，不会删除磁盘文件。`；确认后节点从 `Agent 全局文件` 视图移除，原目录停止监听，磁盘文件不变。
  - 目录不存在或不可读不阻止添加或编辑；节点在 `Agent 全局文件` 视图中显示对应错误态与重试。
  - 多个自定义节点可指向同一目录，按规范化绝对路径判定为同一存储范围，节点仍在树中独立显示。
  - 节点在生命周期内保持稳定身份，用于展开状态恢复；自定义节点没有品牌标识，与内置节点同树。
  - 显示名或目录变更后立即按新定义重新探测，原目录停止监听。
  - 自定义 Agent 节点为应用级集合，在所有已注册 CLI 的基础配置页显示同一份全局清单，任一处编辑即时同步；展示模式、自定义名单与 `显示运行时文件` 不跨 CLI 共享。
- 自定义 Agent 节点校验（输入先去首尾空白）：

| 条件 | 错误文案 |
|---|---|
| 显示名为空 | `名称不能为空` |
| 显示名含 `/` 或 `\` | `名称不能包含路径分隔符` |
| 显示名与内置 Agent 或已有自定义节点重名（大小写不敏感） | `名称已存在` |
| 目录为空 | `目录不能为空` |
| 目录不是绝对路径 | `目录必须是绝对路径` |
| 目录为盘符根、`%WINDIR%` 或 `System32` | `目录不可用于自定义 Agent 节点` |

- 运行时文件清单：
  - 按 Agent 分组，每个内置 Agent 与每个自定义节点各占一行，显示 Agent 显示名与当前清单 chip；每项带 `×` 删除按钮。
  - 添加行包含名称输入框与 `添加` 按钮；按 Enter 等价于点击。
  - 内置 Agent 的 `恢复默认` 清空用户增删并回到内置默认清单；自定义节点的 `恢复默认` 清空清单（自定义节点没有内置默认清单）。
  - 增删与恢复默认即时生效；`Agent 全局文件` 视图按新清单立即刷新隐藏集合。
  - 清单项校验与 `侧栏展示内容` 自定义名单一致：空名称、含路径分隔符、与已有清单项大小写不敏感重名分别显示对应错误文案；失败时输入保留。
  - 该清单与 `显示运行时文件` 开关共同决定 `全部` 模式下隐藏的根层条目；`自定义` 模式下清单不参与判断。
  - 运行时文件清单按 Agent 分组：每个内置 Agent 与每个自定义节点各自一份，不跨 CLI 或节点共享；内置 Agent 的清单在其 CLI 基础页编辑，自定义节点的清单在该节点行编辑。
  - 自定义节点不归属任何 CLI，不应用按 CLI 的 `显示运行时文件` 开关；其根层始终按节点自身运行时清单隐藏条目。
- `恢复本页默认` 只复位当前 CLI 的侧栏展示内容（模式与自定义名单）、`显示运行时文件`、CLI 别名与该 CLI 内置 Agent 的运行时文件清单；不清除其他 CLI 的配置，也不清除自定义 Agent 节点及其清单。
- 配置页重新挂载时，未提交的自定义名单输入、别名输入、节点输入、运行时清单输入与行内错误全部丢失。

### Hooks 页

- Hooks 页始终显示；未声明配置编辑器能力时内容为 `该 CLI 未提供配置编辑器`，不提供编辑控件；声明时显示配置界面。Hooks 配置写入 CLI 自己的设置文件，不写入应用设置。
- 每个声明能力的 CLI 提供自己的设置文件路径、事件目录与 handler schema；Claude Code 是首个内置实现，其他 CLI 按同一能力注册契约接入。下表为 Claude Code 的内置路径；其他 CLI 使用各自清单中的路径。

#### 三层配置与层级切换

- 配置页编辑所属 CLI 设置文件的 hooks 子树，提供三层：

| 按钮 | 作用域 | 文件 | 优先级 |
|---|---|---|---|
| `User` | 用户级，全局生效 | `~/.claude/settings.json` | 最低 |
| `Project` | 项目级，所属项目生效 | `<项目根>/.claude/settings.json` | 中 |
| `Local` | 本地级，所属项目生效 | `<项目根>/.claude/settings.local.json` | 最高 |

- 工具栏固定显示优先级提示 `优先级：Local > Project > User`；初始层级为 User。
- Project 与 Local 使用设置中心所属项目的根目录，不使用当前活跃项目；设置中心面板始终有所属项目，因此 Project/Local 始终可选（项目根不可访问时除外）。
- 所属项目根不可访问时，Project 与 Local 按钮禁用并显示 `项目根不可访问`；User 层仍可用。正在查看不可访问层时回退到 User 并重新读取。
- 切换层级时重新读取该层的 hooks 子树；读取期间编辑区被 `加载中...` 占位替代。轻量重读（外部修改检测）保留原内容直到新数据到达。
- 当前层有未保存修改时切换层级，按保存与关闭守卫处理。
- 读取文件失败（JSON 损坏、权限不足等）显示错误态 `配置文件损坏，请先修复`，不进入编辑界面；若同目录存在上一代备份，提供 `从备份恢复` 动作，恢复前二次确认。
- 文件不存在或没有 hooks 内容时按空配置处理，正常进入编辑界面。
- 配置页只读写目标文件中的 hooks 子树；文件中的其他字段（权限、环境变量、`$schema` 等）原样保留。
- 所属项目根不因切换项目而变化（面板归属固定）；项目根被移动或不可访问时按上述错误处理。

#### 双模式编辑

- Hooks 页提供 `GUI` 与 `JSON` 两种编辑模式，工具栏按钮切换；默认 JSON。
- GUI 与 JSON 编辑同一份 hooks 配置，并实时同步：
  - GUI 编辑后切到 JSON，JSON 文本立即包含改动。
  - JSON 合法且通过 schema 校验后切到 GUI，事件树与详情立即反映改动。
- JSON 模式：
  - 左侧是 190px 宽的事件导航，按分组列出事件；点击事件名在右侧 JSON 中定位并选中该事件键。
  - 右侧为 JSON 编辑器，提供语法错误与 schema 违规的波浪线与悬停提示。
  - JSON 语法非法时保留最后一次合法快照，不更新配置模型；schema 违规时同样保留最后一次合法快照，不把非法内容应用到模型。两种情况均禁用 `GUI` 切换与保存。
  - 工具栏显示单行错误提示 `JSON 存在错误，无法切换 GUI：<首条诊断>`；完整诊断挂在悬停提示中。
- GUI 模式：
  - 左侧事件树展示已配置事件（按分组），右侧为详情区。
  - 添加事件：下拉列出目录中尚未配置的事件；添加后自动选中新事件。
  - 事件详情显示事件名、所属分组与 matcher 目标提示；支持 matcher 的事件显示 matcher 输入框（留空 = 全匹配），不支持 matcher 的事件显示 `全匹配（该事件不支持 matcher）` 并省略输入框。
  - matcher 组与 handler 均可增删；删除当前选中项后详情回退到合适的空态。
  - 添加 handler 时，类型下拉按事件支持的 handler 类型集合过滤。
- 模式切换不丢失当前编辑内容；JSON 非法时不能切到 GUI。
- GUI 中删除事件、matcher 组或 handler 立即更新 JSON 侧内容，没有额外确认。
- GUI 中字段的必填缺失以红色标签与 `此字段为必填` 提示；JSON 数组/对象类字段（参数、请求头、输入参数）非法输入时保留草稿，不向上更新模型。
- 切换 handler 类型时保留通用字段与适用于新类型的字段，清除不适用字段。
- JSON 中的未知事件、未知字段按 schema 结果判定；合法时保留原始内容，GUI 转换对未知字段做容错保留，并在保存时原样写回。
- 当前配置页重新挂载后模式重置为 JSON；未保存编辑按未保存状态守卫处理。
- 事件树为空时显示 `尚未配置任何事件，使用上方下拉添加`；选中事件没有 matcher 组时显示 `该事件没有 matcher 组，点击“添加 matcher 组”开始配置`。

#### 事件与 handler 目录

- Hooks 页使用所属 CLI 的事件目录。下表为 Claude Code 的目标目录，按分组排列：

| 分组 | 事件 |
|---|---|
| 会话生命周期 | SessionStart、SessionEnd、Setup |
| 用户交互 | UserPromptSubmit、UserPromptExpansion |
| 工具调用 | PreToolUse、PermissionRequest、PermissionDenied、PostToolUse、PostToolUseFailure、PostToolBatch |
| 通知与消息 | Notification、MessageDisplay |
| 子代理与任务 | SubagentStart、SubagentStop、TaskCreated、TaskCompleted、TeammateIdle |
| 上下文管理 | PreCompact、PostCompact |
| 停止与错误 | Stop、StopFailure |
| 配置与文件变更 | ConfigChange、CwdChanged、FileChanged、InstructionsLoaded、DirectoryAdded |
| 工作树 | WorktreeCreate、WorktreeRemove |
| 启发式交互 | Elicitation、ElicitationResult |

- handler 类型与字段：

| 类型 | 必填 | 可选 |
|---|---|---|
| command（命令） | 命令 | 参数、异步模式、异步重新唤醒、Shell 解释器 |
| http（HTTP 请求） | URL | 请求头、允许的环境变量 |
| mcp_tool（MCP 工具） | MCP Server、工具名 | 输入参数 |
| prompt（提示词） | 提示词 | 模型、阻塞时继续 |
| agent（子代理） | 提示词 | 模型 |

- 所有 handler 共享通用字段：条件过滤器（仅工具事件求值）、超时（秒）、状态消息。
- 每个事件在目录中声明其支持的 handler 类型集合；类型下拉按集合过滤。支持集合为：全部类型；command、http、mcp_tool；command、mcp_tool。
- GUI 事件目录、JSON schema 与保存校验使用同一份事件与 handler 能力清单，不存在仅 JSON 可写而 GUI 不可见的事件，也不存在仅保存校验可接受的隐藏子集。DirectoryAdded 与其余目录事件一样在 GUI 中可见。
- slTerminal 托管条目：
  - handler 的命令文本包含 slTerminal 注入脚本标识时，GUI 中显示 `slTerminal 托管` 徽标。
  - 该 handler 的全部字段只读，删除按钮禁用。
  - 包含托管 handler 的 matcher 组与事件的删除按钮禁用。
- GUI 只展示目录中的事件；目录外事件不能通过 GUI 添加，也不能通过 JSON 保存。

#### 保存

- 保存按钮仅在“有未保存修改且 JSON 合法且通过 schema 校验”时可用；保存进行中按钮禁用并显示 `保存中…`，其他会修改同一文件的控件（层级切换、注入、卸载）同时禁用。
- 保存前依次校验：
  - 配置必须是 JSON 对象。
  - 必须通过同一事件与 handler 目录驱动的 schema 校验（事件名、handler 结构、必填字段、额外属性限制）。
- 校验失败：显示错误提示（`hooks 配置必须是 JSON 对象` 或 schema 诊断首条），不写入文件，未保存状态保留。
- 校验通过后：
  - User 层：弹出二次确认框，标题 `确认写入用户级 hooks 配置`，正文 `hooks 可执行任意命令`；确认才写入，取消保持未保存状态。
  - Project 与 Local 层：不弹二次确认，直接写入。
- 写入流程：
  - 读取目标文件最新内容并解析；解析失败时中止，提示 `配置文件损坏，请先修复`，不写入。
  - 与上次读取时的文件状态比较；若文件已被外部修改，中止并提示 `文件已被外部修改，请先重新加载`，提供 `重新加载` 动作。
  - 同一目标文件同时最多一个保存、注入或卸载操作；无法取得文件锁时中止并提示 `文件被其他程序占用，请稍后重试`。
  - 若目标文件存在，先创建上一代备份；备份失败则中止，不写入。
  - 只替换目标文件中的 hooks 子树，其他字段保留；父目录不存在时自动创建。
  - 写入失败时原文件保持不变，不产生半截文件。
- 保存成功后：未保存状态清除，导航圆点消失，工具栏显示重启提示 `hooks 改动需重启 claude 会话生效`；下一次编辑或重新加载后提示消失。
- 保存失败（校验拒绝、锁冲突、外部修改、备份失败、写入错误）：未保存状态保留，工具栏显示 `保存失败：<原因>` 与 `重试`，不得静默或仅记录到控制台。
- 保存成功后更新最后读取快照；保存按钮恢复可用状态。
- 保存校验与 schema 完全一致，不存在仅保存校验可接受的隐藏子集；schema 合法的配置均可保存。

#### 注入与卸载

- 工具栏显示注入状态：初始查询完成前为 `注入状态：--`；查询完成后显示 `注入状态：已注入`、`注入状态：未注入` 或 `注入状态：版本过旧`。
- 注入状态查询失败时显示 `注入状态查询失败` 与 `重试`；若已有上次已知值，显示 `注入状态：<值>（状态未知）`，不得只记录到控制台。
- 待确认态不以状态条文案呈现：注入命中可疑命令时，状态条保持进入前的值，另以工具栏下方的内联确认条表达待确认态。
- 提供 `注入 Hooks` 与 `卸载 Hooks` 按钮；操作进行中两者均禁用，按钮显示 `注入中…` 或 `卸载中…`。
- 注入：
  - 通常直接完成并显示已注入。
  - 若用户原有状态行命令命中可疑模式（下载器或 PowerShell 任意执行类命令），暂停注入：设置文件零写入，工具栏下方出现内联确认条，显示 `检测到可疑 statusline 命令，注入已暂停：` 与命令原文，并提供 `确认注入` `取消`。
  - `确认注入` 发起第二次注入并完成；`取消` 清空待确认态，保持点击前的注入状态。
- 卸载：移除 slTerminal 注入的 handler（同组内的用户 handler 保留）、删除注入脚本目录与状态行备份文件、清空信号目录；若状态行仍是 slTerminal 桥接，则还原到注入前的备份，备份缺失时移除状态行配置。
- 注入与卸载以用户级设置文件的写入为提交点：
  - 提交前失败：设置文件不变，已准备的脚本与备份回滚，不产生半截配置。
  - 提交后清理失败：显示可见警告与 `重试清理`，设置文件保持已提交状态，不把清理失败伪装成注入或卸载失败。
- 注入或卸载完成后刷新注入状态，并自动重读 User 层配置；若当前在其他层，则切换到 User 层（切换的未保存状态守卫照常生效）。若当前已在 User 层且有未保存修改，重读前按外部修改守卫确认；取消则保留编辑并标记配置可能已变化。
- 注入或卸载失败时在工具栏显示行内错误：
  - `注入失败，请检查 ~/.claude/settings.json`
  - `确认注入失败，请检查 ~/.claude/settings.json`
  - `卸载失败，请检查 ~/.claude/settings.json`
- 失败时不刷新注入状态、不重读配置，当前编辑内容保留。
- 待确认期间不写入、不重读配置；取消或确认后待确认条消失。
- 注入状态查询只返回已注入、未注入或版本过旧；待确认只作为注入操作的返回结果出现。
- `版本过旧` 可能来自脚本内容与内置模板不一致（版本或哈希不匹配），也可能来自 hooks 配置存在但状态行桥接缺失。
- 卸载时若目标设置文件不是合法 JSON，操作失败且脚本目录、信号目录全部保留，避免产生“配置残留但脚本已删”的悬空状态；错误提示中提供 `打开文件位置`，存在上一代备份时提供 `从备份恢复`。文件恢复为合法 JSON 前无法完成卸载。
- 注入会改写用户级设置文件并影响之后启动的 CLI 会话；已运行会话需要重启才按新配置执行。

#### 外部修改检测

- 设置中心面板重新可见时触发轻量重读：应用窗口从后台恢复、最小化恢复、切回所属项目、设置中心面板页签被激活。触发条件必须同时满足：面板是其面板组的当前面板、所属项目是活跃项目、面板所在面板组与所属项目布局可见。
- 面板内点击、窗口移动或缩放、仅应用失焦但面板仍可见，都不触发重读。
- 若当前有未保存修改，重读前弹确认框，正文 `配置文件可能已被外部修改。重载将丢弃当前未保存的修改。`；确认才覆盖当前编辑，取消保持现状。
- 确认框打开期间及其关闭后的短暂窗口内，回归触发不会再次弹窗。
- 重读不显示整页加载遮罩，保留原内容直到新数据到达。
- 重读失败进入 `配置文件损坏，请先修复` 错误态；已有上一代备份时提供恢复动作。
- 切换层级与项目根不可访问恢复同样触发重读，遵循相同的未保存状态守卫。
- 设置中心面板位于非活跃项目或非当前页签时不重读。
- 外部修改检测只比较读取结果并覆盖编辑模型，不自动保存或合并。
- 面板可见期间持续监听当前层级目标文件；触发条件与上述重读可见性条件一致，面板隐藏、非激活或项目不活跃时停止监听。
- 监听检测到文件变化时显示 `配置文件已在外部修改` 横幅与 `重新加载` 动作；有未保存修改时先走重载确认。连续变化合并为一次提示，不逐次弹窗。
- 可见期间实时监听与保存前的外部修改检测并存；监听提示不自动覆盖编辑模型，保存时冲突仍按保存规则中止并提示重新加载。

### 导入导出与恢复默认

- `导出设置` 导出应用设置 JSON，不含 Hooks 与 CLI 配置文件。
- 侧栏布局与视图状态不属于应用设置域；导入、导出与恢复所有默认不触碰侧栏布局与视图状态。
- `导入设置`：
  - 导出文件包含 `schema_version`（当前为 1）；导入只接受当前版本，缺失、未知或更高版本拒绝并提示。
  - 先做 `schema_version` 与 schema 校验并显示将要修改的域；校验失败不写入。
  - 用户取消则不写入。
  - 提交前自动生成一份可恢复备份；备份失败则中止导入。
  - 导入提交失败时原设置保持不变，不产生半截文件。
  - 导入成功后，当前可见配置页重新读取生效值。
- `恢复所有设置默认`：二次确认后把全部应用设置域恢复默认值；不触碰 Hooks、CLI 配置文件、项目布局、项目内容、侧栏布局与视图状态。
- `恢复本页默认`：二次确认后只复位当前配置页所属应用设置域；Hooks 页不提供该项；Agent 基础页只复位当前 CLI 的配置，不清除其他 CLI 与自定义 Agent 节点。
- 导入、导出与恢复默认都不改变面板打开状态、所在面板组或所属项目。
- 设置中心不接受把文件拖入面板作为配置导入；外部文件拖入不支持，无动作或一次性提示 `请从文件浏览器拖动文件`。

## 交互规则

### 打开与聚焦

- 配置钮单击即生效，无二次确认。
- 没有项目时打开仅含应用页的全局设置浮层；不隐式创建项目，不创建面板组。
- 有活跃项目时：
  - 面板不存在：在活跃项目当前聚焦的面板组创建；没有面板组时创建第一个面板组。
  - 面板存在但未激活：激活其页签、聚焦所在面板组、聚焦面板根容器；不重置选中页。
  - 面板已激活：只把焦点落到面板根容器，不重新加载配置页。
- `Ctrl+,` 与配置钮等效地打开或聚焦活跃项目的设置中心；具体命令派发与重绑见 [workspace/shell.md](../workspace/shell.md)。
- 打开设置中心不改变活跃项目；若触发时活跃项目刚发生变化，以触发时的活跃项目为准。
- 在活跃项目内，设置中心是其所在面板组的当前面板时，配置钮保持高亮，不论该面板组是否聚焦；面板被其他页签覆盖，或设置中心位于非活跃项目布局时取消高亮。
- 面板页签可被拖拽到同项目其他面板组、与其他面板合并、在同面板组内排序；不允许拖到其他项目。
- 设置中心不接受把文件拖入面板作为配置导入。

### 导航与搜索

- 点击当前已选中的导航项不产生变化，也不重复写入面板参数。
- 点击其他导航项立即切换；当前页有手动未保存修改时先进入确认流程。
- 分节标题点击只折叠或展开，不切换配置页；折叠状态不写入布局。
- 左导航支持方向键移动、Home/End 首尾、Enter/Space 激活；分节标题支持 Enter/Space 折叠或展开。
- 左导航项右键不提供上下文菜单；配置页运行期不提供新增、删除、重命名、重排入口。
- 左导航顶部搜索框输入即过滤导航项，`Esc` 清空并恢复完整导航；搜索不改变选中页；无结果时显示 `无匹配配置页`。
- 左导航底部提供 `导入设置`、`导出设置` 与 `恢复所有设置默认`；每个配置页页头提供 `恢复本页默认`。这些操作不改变面板打开状态、所在面板组或所属项目。
- `导入设置` 在提交前显示将修改的域；用户取消则不写入。导入或恢复默认成功后，当前可见配置页重新读取生效值。

### 配置页操作与保存反馈

- 每个配置页页头声明保存模式：快捷键、外观、终端、Agent 基础配置、应用为 `自动保存`；Hooks 为 `手动保存`；后台定时任务为 `提交即保存`。三种模式均统一显示 `保存中`、`已保存` 或 `保存失败` 与重试入口。
- 配置页内的开关、单选、chip 增删、外观选择、终端配置、Agent 节点与运行时清单编辑、快捷键录制属于自动保存操作：立即作用于运行期状态，按所属域去抖保存。
- Hooks 属于手动保存：编辑产生未保存状态，保存按钮提交；User 层保存前二次确认，Project/Local 直接保存。
- 后台定时任务属于提交即保存：勾选与频率提交立即保存，成功后刷新清单，失败回显错误并恢复提交前的显示值。
- 保存状态在配置页内可见：`保存中`、`已保存`、`保存失败`；失败必须提供重试，不得只写控制台。
- 保存失败不阻止用户继续操作；失败状态保留到重试成功、下一次改动或关闭确认。
- 配置页重新挂载时，未提交的输入草稿与行内错误丢失；自动保存已生效的值保留在全局状态中。

### 关闭、切换与确认

- 设置中心关闭路径：面板页签关闭按钮、`Ctrl+W`、鼠标中键关闭、面板页签右键菜单 `关闭`。
- 单个关闭：有手动未保存时直接进入工作区统一关闭确认；有自动保存待写或失败时先冲刷，冲刷失败进入统一关闭确认；无未完成状态时直接关闭。
- 批量关闭按当前面板组聚合；多个未保存面板只弹一次确认，正文列出待关闭面板标题；取消则全部不关闭。
- 移除项目按工作区流程处理；设置中心的未保存修改与保存失败参与列出，不再逐面板确认。
- 关闭应用按工作区窗口关闭确认聚合；关闭前的设置冲刷与失败处理由 [settings-and-persistence.md](../settings-and-persistence.md) 定义。
- 切换项目：不关闭面板，不弹确认；面板随项目布局隐藏，切回时恢复选中页、未保存状态与保存失败状态。
- 切走面板组或页签：面板保持挂载，不触发确认。
- 确认框取消后，焦点返回触发前的控件；确认丢弃后，焦点进入目标配置页页头或关闭后的下一个面板，具体落点遵循 [workspace/shell.md](../workspace/shell.md) 的焦点规则。

### 键盘与焦点

- 面板激活时焦点落到面板根容器；根容器不在 Tab 顺序中，按 Tab 进入左导航。
- 左导航内部使用方向键移动，不要求逐个 Tab；Tab 从导航离开后进入右侧配置页内容。
- 配置页切换后，焦点进入目标页页头（程序化可聚焦），提示页标题；随后 Tab 进入第一个控件。
- `Esc` 在快捷键录制中取消录制；在确认框中取消；在普通配置页不关闭面板。
- 对话框打开时焦点限制在对话框内，默认焦点落在 `取消`；Enter 触发当前聚焦按钮。
- 快捷键录制期间全局快捷键暂停消费；录制结束、取消、配置页卸载或面板关闭后必须恢复，不得遗留暂停状态。
- 输入法组合态不触发录制、不触发添加、不触发校验提交；组合结束后按正常输入处理。

### 拖放与右键

- 面板拖放遵循工作区规则：同项目内拆分、合并、排序；跨项目拖拽被拒绝。
- 左导航项、配置页控件、快捷键行不支持拖拽重排。
- 面板页签右键菜单提供工作区标准项（关闭、关闭其他、关闭全部）；设置中心不额外增加页签菜单项。
- 配置页内文本输入使用标准编辑上下文菜单（剪切、复制、粘贴、全选）。
- chip 的 `×` 是删除入口；不提供右键删除或拖拽排序。
- Hooks 事件树与 matcher 组不提供拖拽排序；顺序由 JSON 结构决定。

### 状态迁移

| 对象 | 迁移 |
|---|---|
| 手动未保存 | 编辑 → 未保存；保存成功或确认丢弃 → 干净；面板隐藏不改变 |
| 自动保存 | 改动 → 保存中 → 已保存 / 保存失败；失败后重试或下次改动重试 |
| 后台任务提交 | 空闲 → 提交中 → 成功刷新 / 失败恢复并提示 |
| Agent 节点编辑 | 空闲 → 校验 → 提交 / 行内错误；提交后即时同步到 Agent 全局文件视图 |
| 运行时文件清单编辑 | 空闲 → 校验 → 提交 / 行内错误；提交后即时刷新隐藏集合 |
| Hooks 注入 | 未注入 → 注入中 → 已注入 / 待确认 / 失败；待确认 → 确认注入 / 取消 |
| Hooks 卸载 | 已注入或版本过旧 → 卸载中 → 未注入 / 失败 |
| 快捷键录制 | 空闲 → 录制中 → 写入 / 取消 / 解绑 / 保留键拒绝 |

## 边界与错误

### 空态

- 没有项目：配置钮与 `Ctrl+,` 打开应用设置浮层。
- 没有配置页：右侧 `暂无配置页`，左导航无组。
- Agent 组没有配置页：整组不渲染。
- 后台任务清单为空：`暂无后台任务`。
- Agent 自定义名单为空：`名单为空——视图中不展示任何条目`。
- Agent 别名列表为空：`暂无别名`。
- 自定义 Agent 节点为空：`暂无自定义 Agent 节点`。
- 运行时文件清单为空：`运行时文件清单为空`；自定义节点恢复默认后同样显示。
- Hooks 所属 CLI 没有配置编辑器：`该 CLI 未提供配置编辑器`。
- Hooks 事件树没有已配置事件：`尚未配置任何事件，使用上方下拉添加`。
- Hooks 选中事件没有 matcher 组：`该事件没有 matcher 组，点击“添加 matcher 组”开始配置`。
- 快捷键页始终有可显示命令；单条命令解绑后显示 `未绑定`。
- 配置页目录不为空但选中页失效时，按回退规则选择第一个可用配置页，不显示空态；目录为空时显示 `暂无配置页`。

### 加载与异步

- 设置中心壳本身没有加载遮罩；同步配置页立即渲染。
- 后台任务页挂载后异步读取任务清单：显示 `加载中…`；读取失败显示 `任务配置读取失败` 与 `重试`。
- Hooks 首次加载、切换层级、项目根不可访问恢复时显示 `加载中...`；轻量重读保留原内容。
- 注入状态查询异步进行；查询完成前显示 `注入状态：--`；查询失败显示可见失败与重试。
- 快捷键、外观、终端、Agent 基础配置、后台任务生效配置来自应用启动时已加载的设置状态；配置页挂载时不重复读盘。
- 保存操作在后台执行，配置页显示 `保存中`；不阻塞前台交互。

### 错误与恢复

- 设置文件损坏：按 [settings-and-persistence.md](../settings-and-persistence.md) 隔离、备份恢复或使用默认值；启动提示与面板警示条同时存在时不重复弹出多个对话框。
- 设置文件读取失败或只读：显示只读警示，禁止写入，提供 `重试`；不把读取失败当作文件不存在后写入默认值。损坏恢复、只读判定与更高版本处理见 [settings-and-persistence.md](../settings-and-persistence.md)。
- 设置保存失败：配置页显示失败状态与重试；原文件保持完整；关闭时进入关闭守卫。
- 后台任务读取失败：可见错误与重试，不显示空白行区。
- 后台任务提交被拒绝：`设置失败：<错误信息>`，显示值恢复到提交前。
- 快捷键覆盖非法：修复横幅；受影响命令按默认键工作；坏值不得静默消失。
- Hooks 文件损坏：`配置文件损坏，请先修复`；不进入编辑界面；存在上一代备份时提供恢复。
- Hooks 保存校验失败：`hooks 配置必须是 JSON 对象` 或 schema 诊断首条；不写入文件。
- Hooks 写入失败、锁冲突、外部修改、备份失败：`保存失败：<原因>` 与重试；未保存状态保留。
- Hooks 注入或卸载失败：显示对应行内错误；失败不刷新状态、不重读配置。
- Hooks 卸载遇到损坏文件：整体失败，脚本与信号目录保留；提供打开文件位置与备份恢复。
- 终端自定义 Shell 路径非法：行内红字，输入保留，不提交。
- Agent 名单、别名、自定义节点与运行时文件清单校验失败：行内红字，输入保留。
- 当前 CLI 未注册：`未知 CLI` 防御占位。
- 所属项目根不可访问：Project/Local 层禁用并提示；项目行自身按 [workspace/navigation.md](../workspace/navigation.md) 显示警示。

### 并发与冲突

- 设置保存串行执行；不同配置页的改动合并，不互相覆盖。
- Hooks 每个目标文件同时最多一个保存、注入或卸载操作；操作进行中禁用同一页的写入操作与层级切换。
- Hooks 保存前检测外部修改；冲突时中止并提示重新加载，不以内存值覆盖外部修改。
- 注入与卸载以用户级设置文件写入为提交点；提交前失败不改变设置文件，提交后清理失败可见并可重试。
- 后台任务页一次只处理一个提交；提交期间任务控件禁用，避免清单刷新乱序。
- 关闭应用或关闭面板时若存在进行中的保存，等待其完成或失败，不超过 [settings-and-persistence.md](../settings-and-persistence.md) 规定的冲刷上限。
- 应用为单实例；不处理多个应用实例并发修改同一设置文件。

### 数据完整性与备份

- 应用设置的备份、损坏隔离、写入完整性与关闭冲刷由 [settings-and-persistence.md](../settings-and-persistence.md) 定义；设置中心只显示用户可见状态并禁止只读状态下的写入。
- Hooks 目标文件在写入前创建上一代备份；备份失败中止写入。备份保留一代，不提供多代历史。
- Hooks 写入只替换 hooks 子树，其他字段原样保留；写入失败时原文件完整，不产生半截文件。
- 导入设置提交前自动生成可恢复备份；备份失败中止导入。
- 未注册 CLI 的配置在应用设置写回时保留，不得因 CLI 未注册而丢失。
- Hooks 文件不设硬上限；超过 1MB 时配置页显示性能提示，诊断异步执行。

### 性能

- 设置中心面板打开、配置页切换不执行阻塞 I/O；异步读取与保存后台完成。
- 自动保存按所属域合并短时间连续改动，不逐键写入。
- 后台任务停用或视图未打开时不得保留运行中的轮询或计时器；会话历史刷新只在视图打开且任务启用时计时。
- Hooks JSON 诊断在停止输入后 200ms 内更新；1MB 以内配置文件输入保持可响应。
- 外部修改轻量重读只读目标 hooks 子树，不整页遮罩、不重建编辑器。
- Hooks 可见期间监听只在当前层级文件上运行；面板隐藏、非激活或项目不活跃时停止监听；连续变化合并为一次重读提示。
- 左导航配置页目录在启动时确定，不随配置页切换变化。

### 键盘与焦点

- 左导航、配置页控件、对话框全部键盘可达；焦点顺序与视觉顺序一致。
- 焦点环使用主题语义 token，始终可见；选中、未保存或保存失败同时提供文本或形状线索。
- 未保存圆点、保存失败徽标、注入状态、任务状态均有标签。
- 快捷键录制开始、取消、保留键拒绝、冲突警告通过状态文本提示；输入法组合态被忽略。
- 开关、单选、输入框均有显式标签；错误文案与控件关联。
- 对话框标题与正文可读；默认焦点在 `取消`。
- 支持系统 DPI 缩放；设计契约尺寸为逻辑像素。
- 尊重系统减少动效设置；设置中心不依赖动画传达状态。
- 中文与 CJK 输入法在名单、别名、节点显示名与目录、运行时清单、Hooks 文本、快捷键等输入中正常工作。
- 外观页主题方案、透明度、壁纸、密度组合保持可读；不只靠颜色区分配置项状态。
- 终端页的 Shell 模式单选、路径校验错误与回滚容量范围提示可读；Agent 节点与运行时清单的增删按钮有名称。

### 平台边界

- 仅支持 Windows 10/11；不提供 macOS/Linux 行为。
- 应用设置的存放位置、只读目录处理与读取失败恢复见 [settings-and-persistence.md](../settings-and-persistence.md)。
- Hooks User 层路径展开到当前用户主目录；Project/Local 使用设置中心所属项目根。
- Windows 文件系统与 CLI 别名唯一性均不区分大小写，避免同一命令的不同大小写写法指向不同 CLI。
- 文件被其他程序占用时，Hooks 写入等待或失败并提示；不绕过文件锁强行覆盖。
- 路径含空格、Unicode、长路径时按操作系统能力处理；超过系统限制时显示错误。
- 文件权限不足、磁盘已满、写入失败均走可见错误路径，不产生半截文件。

### 安全与隐私

- 设置中心不存储凭据；真实 token/key 不得写入应用设置、Hooks 文件或注入脚本。
- 日志只记录操作、路径与错误类别，不记录配置文件内容或 handler 命令文本；可疑 statusline 命令只在确认 UI 中展示。
- 自定义名单、运行时文件清单与自定义 Agent 节点显示名拒绝路径分隔符；自定义节点目录必须是绝对路径，避免通过配置进行路径穿越。
- 自定义节点删除只移除配置，不删除磁盘文件；节点目录的读写边界由 [sidebar/agent-files.md](../sidebar/agent-files.md) 执行。
- Hooks User 层保存前二次确认，明确提示 hooks 可执行任意命令。
- 注入脚本、信号目录与状态行备份限制在由应用托管的数据目录。
- slTerminal 托管条目在 GUI 中只读且不可删除；JSON 中修改托管标识后按普通条目处理。
- 注入与卸载不修改用户其他 handler；卸载只清理 slTerminal 托管内容。
- 设置导入必须校验 schema、显示将要修改的域、自动备份并安全提交；导出不得包含 Hooks 文件与 CLI 配置文件。

## 验收判据

### 面板唯一性与入口

- Given 没有项目，When 点击配置钮或按 `Ctrl+,`，Then 打开仅含应用页的全局设置浮层，不创建项目、面板组或设置中心面板。
- Given 活跃项目没有设置中心面板，When 点击配置钮，Then 面板出现在当前聚焦的面板组（没有面板组时创建第一个），页签标题为 `设置中心`，焦点在面板根容器。
- Given 活跃项目的设置中心在背景页签或另一面板组，When 点击配置钮，Then 激活该面板页签并聚焦其面板组，面板数量不增加。
- Given 项目 A 与项目 B 各有设置中心面板，When 在项目 B 触发入口，Then 只聚焦项目 B 的面板，项目 A 的面板保持隐藏与原状态。
- Given 设置中心面板已激活，When 连续触发配置钮与 `Ctrl+,`，Then 面板数量不变，选中页与未保存修改不变。
- Given 活跃项目内设置中心面板为所在面板组的当前面板，Then 配置钮显示持续激活态，不论该面板组是否聚焦；When 该面板组切换到其他页签，Then 激活态消失；When 切换到其他项目，Then 原项目配置钮取消高亮。
- Given `Ctrl+,` 被重新绑定到其他键，When 按下新键，Then 仍打开或聚焦活跃项目的设置中心；原键不再触发。
- Given 设置中心面板，When 拖到同项目另一面板组，Then 移动成功；When 拖向另一项目，Then 不移动。
- Given 应用重启时项目布局含设置中心，Then 面板恢复并恢复选中页；Given 面板关闭后退出，Then 重启不重新打开。
- Given 布局恢复发现同一项目两个设置中心，Then 只保留一个。

### 导航与配置页

- 新打开设置中心时，全局组第一页为 `快捷键`；全局组依次为 `快捷键`、`后台定时任务`、`外观`、`终端`、`应用`，Agent 组在其下。
- Agent 分节标题显示 logo 与 CLI 名称；点击标题只折叠或展开，不切换配置页；子页缩进显示。
- Agent 分组内依次显示 `基础配置` 与 `Hooks`；Hooks 始终存在，未声明配置编辑器能力时显示提示态。
- 同一配置页标识重复出现时只显示一条。
- 选中页失效时显示全局组第一页；没有全局页时显示第一个可用配置页；没有配置页时显示 `暂无配置页`。
- 在面板内切到 `后台定时任务`，切到其他面板页签再切回，选中页仍为 `后台定时任务`；关闭面板再打开，回到 `快捷键`。
- 切换配置页再切回，原页的录制态、输入草稿、Hooks 层级/模式与未保存编辑按守卫重置或丢弃。
- 左导航宽度为 180px；方向键可移动、Home/End 可跳转、分节标题可折叠；焦点环可见。
- 左导航顶部显示 `所属项目：<项目名>`。
- 在左导航搜索框输入 CLI 名、分组名或配置页标题，只显示匹配项；按 `Esc` 清空并恢复；无匹配时显示 `无匹配配置页`，选中页不变。
- 分组折叠且组内有未保存或保存失败页时，组标题显示聚合状态标识。

### 快捷键页

- 点击 `保存文件` 行进入录制，显示 `按下新键位…Esc 取消`；按 Esc 退出且绑定不变。
- 录制 `复制选区` 时按 `Ctrl+C`，显示 `保留键 Ctrl+KeyC 不可绑定`，保持录制且不写入。
- 录制时按 Backspace，命令显示 `未绑定`；`↺` 仍显示，点击后恢复默认键。
- 录制一个与同分组其他命令相同的键，出现 `与「<命令名>」冲突，生效按优先级派发` 警告但绑定写入成功；运行期按优先级与焦点上下文派发。
- 有覆盖的行显示强调色生效键、默认键小字与 `↺`；点击 `↺` 后恢复默认键且不进入录制。
- 录制期间按 `Ctrl+Shift+C` 不执行复制；录制结束、取消、面板失活或关闭面板后全局快捷键恢复。
- 覆盖改动约 2 秒后保存；保存失败显示 `保存失败` 与重试，提示 `设置保存失败，修改仅在本次运行中生效`。
- 设置中存在绑定到保留键或格式非法的覆盖时，命令按默认键工作，快捷键页显示修复横幅，可逐条或全部恢复默认；坏值不得静默留存。
- 输入法组合态按键不被录制；只按修饰键不结束录制。
- 快捷键页包含 `切换侧栏`、`聚焦活动栏`、四个侧栏视图快捷键与 `打开设置中心`（`Ctrl+,`）；焦点循环只在固定键参考中只读展示；不出现终端搜索与 Diff 的 F6/F7。

### 后台定时任务页

- 打开配置页看到任务行，默认均启用，频率分别为 10 与 3，范围提示分别为 `10–3600 秒` 与 `2–300 秒`。
- 取消勾选 `套餐余量查询` 后立即提交；成功后勾选态更新，导航树套餐余量区隐藏，已有快照保留；重新启用后显示最后快照。
- `会话历史刷新` 频率改为 15 并失焦，提交成功后输入框规范回显 `15`；视图打开且任务启用时立即执行一轮，视图关闭或任务停用时不启动计时器。
- 输入 `5` 给套餐余量任务并失焦，行内出现 `10–3600 秒`，不提交、不弹提示，输入保持 `5`。
- 任务调度器拒绝时出现 `设置失败：...`，输入保持用户所填内容，勾选状态回到提交前值。
- 成功提交任一配置后，所有行用返回清单刷新，并触发一次套餐余量刷新。
- 读取期间显示 `加载中…`；读取失败显示 `任务配置读取失败` 与 `重试`；空清单显示 `暂无后台任务`。
- `恢复本页默认` 二次确认后全部任务回到默认启用状态与频率，立即写盘；失败时不部分落地，保留提交前值并显示错误。

### 外观页

- 默认主题方案为 `Linear`；切换到其他暗色方案立即生效；不提供浅色或跟随系统选项。
- 仅提供内置暗色主题；透明度、壁纸、密度组合不做对比度校验、不提示、不自动回退。
- 终端与编辑器可分别设置字体族与字号；字号输入 8–32 外的值显示范围提示，不提交且输入保留。
- 修改字号后既有终端与编辑器按新字号重绘；终端行列按新字号重新计算。
- 侧栏默认布局可逐视图显示/隐藏、排序、切换上区/下区归属；修改后侧栏按新的显隐、顺序与槽位显示；隐藏视图可通过该页开关或该视图全局快捷键恢复。
- `恢复默认侧栏布局` 二次确认后恢复内置顺序、槽位归属与全部视图按钮可见，不改变侧栏可见性意图、宽度、分割比例、项目布局与面板内容。
- `自动保存` 开关默认关闭；开启后编辑器停止输入 1 秒保存，失焦或关闭前立即保存；关闭后不再自动保存；Markdown 源码态与 Diff 不受影响；保存失败保留未保存状态；开关状态在重启后保持。
- 调整透明度滑块与界面密度立即生效；密度在 `紧凑` / `标准` / `宽松` 间切换。
- 选择壁纸后窗口背景更新；清除壁纸后恢复主题背景；图片读取失败时保留原壁纸并提示 `壁纸加载失败`。
- `Markdown 草稿崩溃恢复` 默认开启；关闭后修改 Markdown 草稿并强制结束进程，重启不提示恢复且显示磁盘内容；重新开启后恢复写草稿快照。
- 外观改动约 2 秒后保存；保存失败显示 `保存失败` 与重试，提示 `设置保存失败，修改仅在本次运行中生效`。
- 外观页不产生手动未保存状态；关闭面板不单独弹未保存确认，待写配置先冲刷，冲刷失败进入统一关闭确认。

### 终端页

- 默认 Shell 模式为 `自动`；切换到 `显式` 后从检测到的 Shell 列表选择，之后新建终端使用该 Shell，已有终端不重启。
- 切换到 `自定义路径` 并输入不存在的路径，行内显示 `Shell 路径不存在`，不提交且输入保留；输入相对路径显示 `路径必须是绝对路径`。
- 回滚容量默认 `10000`；输入 `999` 或 `100001` 显示范围提示 `1000–100000`，不提交且输入保留；输入合法值并失焦后，之后新建终端使用新容量。
- `允许非聚焦终端写入剪贴板` 默认关闭；关闭时非聚焦终端的 OSC52 写入被忽略，开启后活跃项目内的非聚焦终端写入生效；隐藏项目与后台非聚焦终端始终拒绝；单次上限按 [terminal.md](terminal.md) 不变。
- `光标闪烁` 默认开启；系统启用减少动效时默认关闭；用户显式开启后覆盖减少动效。关闭后现有与新建终端光标停止闪烁，光标形状仍为竖线。
- 终端页不出现终端配色、终端搜索、光标样式或终端输入模式页。
- 终端配置改动约 2 秒后保存；保存失败显示 `保存失败` 与重试，提示 `设置保存失败，修改仅在本次运行中生效`。
- 终端页不产生手动未保存状态；关闭面板不单独弹未保存确认，待写配置先冲刷，冲刷失败进入统一关闭确认。

### Agent 基础配置页

- 默认模式为 `全部`，`显示运行时文件` 为关。
- 切到 `自定义` 后 `显示运行时文件` 置灰且值保留；切回 `全部` 后恢复可用且值不变。
- 添加名称 `docs` 成功；再添加 `DOCS` 失败并显示 `名称已存在`。
- 添加含 `/` 或 `\` 的名称失败并显示 `名称不能包含路径分隔符`；空名称显示 `名称不能为空`。
- 添加别名 `cc` 后立即在终端中执行 `cc ...` 能被识别为对应 CLI；再加 `CC` 被视为同一别名并提示已存在。
- 添加内置命令名或其他 CLI 已占用别名时显示对应冲突文案，且不写入。
- 别名超过 32 个字符、含空格、含引号或反引号、以 `-` 开头时显示对应错误，输入保留。
- 输入框失焦后草稿与错误仍保留，点击 `添加` 按钮能正常提交。
- `自定义` 模式下 `Agent 全局文件` 根层只显示名单内条目；`全部` 模式关闭运行时文件后排除运行时文件清单。
- 添加自定义节点（显示名与绝对目录）后，`Agent 全局文件` 视图立即出现同树节点，无品牌标识；目录不存在时节点显示 `目录不存在` 与 `重试`。
- 自定义节点显示名为空、含路径分隔符、与内置 Agent 或已有节点重名时，分别显示 `名称不能为空`、`名称不能包含路径分隔符`、`名称已存在`；目录为空、非绝对路径时分别显示 `目录不能为空`、`目录必须是绝对路径`。
- 编辑自定义节点目录后，视图按新目录重新探测，原目录停止监听；删除节点需二次确认，确认后节点移除且磁盘文件保留。
- 在运行时文件清单中增删名称后，`Agent 全局文件` 隐藏集合立即按新清单刷新；内置 Agent 恢复默认回到内置默认清单，自定义节点恢复默认清空清单。
- 保存失败显示 `保存失败` 与重试；配置页切换后未提交草稿与错误丢失，已生效配置保留。
- 未注册 CLI 显示 `未知 CLI` 占位；其设置在写回时保留。

### Hooks 页

- Hooks 页始终显示；未声明配置编辑器能力时显示 `该 CLI 未提供配置编辑器`。
- 有项目时 User/Project/Local 均可用；项目根不可访问时 Project/Local 禁用并提示，User 仍可用。
- 初始层级为 User；工具栏显示 `优先级：Local > Project > User`。
- 在 User 层编辑后不保存直接点 Project，弹层级切换确认；取消后仍停留 User 且修改保留。
- 目标文件 JSON 损坏时显示 `配置文件损坏，请先修复`；存在上一代备份时可恢复。
- 默认进入 JSON 模式；GUI 新增事件后切回 JSON，文本包含该事件；JSON 合法修改后切到 GUI，事件树反映改动。
- JSON 非法时保留最后一次合法快照，`GUI` 与保存按钮禁用，工具栏显示 `JSON 存在错误，无法切换 GUI：<首条诊断>`；schema 违规同样不应用到模型。
- GUI 中 matcher 组与 handler 增删即时反映到 JSON；删除无额外确认；必填缺失显示 `此字段为必填`。
- 事件目录包含 DirectoryAdded；GUI 可见事件与 schema、保存校验一致；不存在仅保存校验可接受的隐藏子集。
- 含 slTerminal 注入脚本标识的 handler 显示 `slTerminal 托管` 徽标，字段不可编辑、删除按钮禁用；其所在组与事件的删除按钮禁用。
- 不支持 matcher 的事件不显示 matcher 输入框，显示 `全匹配（该事件不支持 matcher）`。
- 无修改时保存按钮禁用；合法修改后可用；保存进行中按钮禁用且显示 `保存中…`。
- 输入非对象 JSON 或 schema 违规内容时保存被拒并显示错误，文件不变。
- User 层保存弹二次确认；取消不写入且修改保留；Project/Local 保存不弹确认。
- 保存成功后显示 `hooks 改动需重启 claude 会话生效`，未保存状态清除；再次编辑后提示消失。
- 保存后目标文件的其他字段保持不变；写入前生成上一代备份；外部修改冲突时中止并提示重新加载；锁冲突时提示稍后重试。
- 写入失败时未保存状态保留，工具栏显示 `保存失败：<原因>` 与重试，不静默。
- 未注入时状态条显示 `注入状态：未注入`；注入成功后变为 `已注入`，并自动重读 User 层。
- 原有状态行命令含可疑下载或执行模式时，点击注入后出现待确认条与命令原文，设置文件不变；取消后条消失；确认注入后状态变为已注入。
- 点击卸载后状态刷新为未注入，注入脚本与信号目录被移除；设置文件非法 JSON 时卸载失败并显示错误，目录保留，提供打开文件位置与备份恢复。
- 从后台切回且无未保存修改时重新读取；有未保存修改时出现重载确认，取消后编辑内容保持；面板隐藏时不重读；确认框打开期间不重复弹框。
- 面板可见期间外部修改当前层级文件时，显示 `配置文件已在外部修改` 横幅与 `重新加载`；有未保存修改时先走重载确认；面板隐藏、非激活或项目不活跃时不监听、不弹提示。

### 应用页

- 有项目时设置中心全局组依次为快捷键、后台定时任务、外观、终端、应用；应用页为单页分节。
- 无项目时配置钮或 `Ctrl+,` 打开仅含应用页的全局设置浮层，底部提供导入/导出/恢复所有默认；遮罩阻止背景交互，`Esc`/关闭按钮关闭；项目激活后浮层自动关闭。
- 尚未迁移的节显示节标题与 `该能力由迁移版本提供` 只读说明，不提供可操作控件。
- Runtime API 只读显示状态、端口与端点，不显示 token，不提供总开关。
- 通知只有桌面通知总开关与任务栏闪烁开关，无按类别开关或免打扰时段。
- 诊断节提供版本/构建、数据目录、日志目录、配置健康、复制诊断信息、打开目录/日志、通知自检、导出诊断包、运行环境自检，以及一键清理日志/审计/更新下载/崩溃现场；诊断包导出前预览与脱敏；清理前二次确认并列出范围，失败逐项可见。
- 备份与恢复节提供导出/恢复/撤回；导出不含凭据与 Hooks；恢复前预览并二次确认。
- 终端增强开关迁移前置灰并标注 `尚未启用`。
- 应用页保存失败显示 `保存失败` 与重试；清理动作确认后立即执行，不进入去抖。

### 导入导出与恢复默认

- 导出设置生成不含 Hooks 与 CLI 配置文件的 JSON。
- 导入非法 schema 时不写入并显示校验错误；导入提交前显示将要修改的域；用户取消不写入。
- 导入提交失败时原设置保持不变；提交前自动生成可恢复备份，备份失败则中止导入。
- 导入成功后当前可见配置页重新读取生效值。
- `恢复本页默认` 二次确认后只复位当前页所属应用设置域；Agent 基础页只复位当前 CLI 的展示配置、`显示运行时文件`、别名与该 CLI 内置 Agent 的运行时清单，不清除其他 CLI、自定义节点及其清单；Hooks 页没有该项。
- `恢复所有设置默认` 复位全部应用设置域，不触碰 Hooks 与 CLI 配置文件、项目布局与项目内容。
- 导入、导出与恢复默认都不改变面板打开状态、所在面板组或所属项目。

### 保存、失败与关闭

- 当前页产生手动未保存修改后，导航项出现 7px 圆点；点击其他页弹 `未保存的修改` 确认，取消后圆点与当前配置页不变。
- 确认丢弃后切到目标页，原页圆点消失。
- 有未保存修改的设置中心面板点关闭，出现 `设置中心有未保存的修改，关闭将丢弃这些修改。`；取消保留面板，确认关闭。
- 批量关闭含多个未保存面板时只弹一次确认，正文列出全部标题；取消则全部保留。
- 切换项目时设置中心面板自动隐藏但不关闭；切回后未保存状态、选中页与保存失败状态保留。
- 移除项目时聚合确认列出设置中心标题；确认后项目布局关闭，不逐面板二次确认。
- 自动保存失败时配置页显示 `保存失败` 与重试；关闭面板或应用时先尝试冲刷，失败出现未保存确认；取消后失败状态保留。
- When 保存失败后点击重试且保存成功，Then 失败徽标消失并显示 `已保存`；When 重试再次失败，Then 保留失败状态与重试入口。
- Hooks 保存失败后重试成功时，`保存失败：<原因>` 消失、未保存状态清除，并显示重启提示。
- 关闭面板前自动保存成功时不出现额外确认；冲刷失败时出现确认。

## 关键决策与依据

- **每项目一个设置中心面板**：规则：面板归属于项目布局，可在任意面板组，但同一项目最多一个。原因：设置中心承载该项目的项目级作用域，重复实例会产生冲突的 Hooks 上下文。边界：布局恢复发现多个实例时保留第一个；切换项目不关闭面板。
- **设置中心是普通面板**：规则：不是模态框、独立窗口或侧栏视图。原因：统一面板模型，复用拆分、合并、排序与关闭守卫。边界：禁止跨项目拖拽；关闭后不保留占位。
- **配置钮加 `Ctrl+,` 双入口**：规则：活动栏配置钮常驻，`Ctrl+,` 为全局打开/聚焦命令。原因：鼠标入口保持可发现性，键盘入口提升可达性。边界：无项目时只提示；命令派发与重绑归 [workspace/shell.md](../workspace/shell.md)。
- **激活态与面板组焦点解耦**：规则：只要设置中心是其面板组的当前面板，配置钮即高亮。原因：激活态表达“设置中心已打开”，不表达“该面板组有焦点”。边界：被其他页签覆盖或位于非活跃项目时不亮。
- **左导航显示项目上下文，不设项目组**：规则：顶部显示所属项目，全局组与 Agent 组保持应用级。原因：避免项目作用域在导航中被重复建模。边界：Hooks 的 Project/Local 层显示所属项目名。
- **配置页目录启动时固定**：规则：运行期不新增、删除、重命名或重排配置页。原因：避免注册变化与未保存编辑、面板参数冲突。边界：安装或移除 CLI 后重启生效。
- **搜索只过滤导航**：规则：按标题、CLI 名与分组名过滤，`Esc` 清空。原因：提供定位手段，不引入额外状态。边界：不改变选中页、配置页状态与配置页目录。
- **按域三模式保存**：规则：自动保存配置按 2 秒去抖写入，Hooks 手动保存，后台任务提交即保存；每页页头声明模式并统一显示保存状态与重试。原因：即时配置需要低摩擦，Hooks 可执行任意命令需要显式确认。边界：自动保存失败不阻止切页；手动未保存只在确认丢弃或保存成功时清除。
- **自动保存按域去抖**：规则：自动保存配置在最后一次改动后短暂去抖保存，不逐键写入。原因：合并连续编辑，降低写入频率。边界：显式提交的配置页立即保存；去抖与冲刷细节归 [settings-and-persistence.md](../settings-and-persistence.md)。
- **快捷键覆盖冲突可见、允许写入**：规则：同上下文冲突允许保存并显示警告，运行期按优先级派发；保留键拒绝。原因：保留键承载终端与编辑器核心语义，其他冲突应交由用户与运行期裁决。边界：无效覆盖不生效但保留可修复入口。
- **快捷键录制暂停全局命令**：规则：录制期间全局快捷键不消费按键，录制结束或面板失活立即恢复。原因：避免录制被命令截获，也避免隐藏面板长期暂停全局命令。边界：输入法组合态与纯修饰键不写入。
- **外观仅暗色、不做对比度判断**：规则：只提供内置暗色主题；透明度、壁纸、密度组合以文字可读为优先，但不做对比度校验、不提示、不因对比度拒绝或自动回退。原因：产品仅暗色，主题是内置目录。边界：不静默改写用户设置。
- **自动保存开关默认关闭**：规则：外观页提供编辑器自动保存开关，默认关闭。原因：磁盘写入策略应由用户显式选择。边界：只作用于编辑器，不作用于 Diff；外部冲突、只读与大文件时暂停。
- **侧栏默认布局单点**：规则：外观页提供显隐、排序、上下区归属与恢复默认控件，语义由 [sidebar/framework.md](../sidebar/framework.md) 定义；控件写入状态库 sidebar facet，外观页只是同一 `SidebarLayout` 的控制面。原因：避免设置中心与侧栏各存一套布局状态。边界：恢复默认只改默认布局，不改项目布局与面板内容；导入、导出与恢复所有默认不触碰侧栏布局与视图状态。
- **终端页限定配置范围**：规则：只提供默认 Shell、回滚容量、非聚焦 OSC52 写入与光标闪烁。原因：终端配色、搜索、光标样式与输入模式页不属于目标范围。边界：默认 Shell 与回滚容量只影响新终端，其余即时作用于活跃项目内的终端面板；隐藏项目始终拒绝后台 OSC52。
- **Agent 配置按 CLI 与 Agent 分域**：规则：展示模式、自定义名单、`显示运行时文件` 与 CLI 别名按 CLI 各一份；运行时文件清单按 Agent（内置 Agent 与自定义节点各一份）；自定义 Agent 节点为应用级集合。原因：页面按 CLI 组织，清单与节点有各自归属；全局单例会让页级恢复默认语义失真。边界：配置存储于应用级、不随项目分叉；恢复本页默认只复位当前 CLI 的四项与该 CLI 内置 Agent 的清单，不清除其他 CLI 与自定义节点。
- **Hooks 单一能力目录**：规则：GUI、schema 与保存校验使用同一事件与 handler 清单。原因：避免仅某一通道可见或可写的隐藏子集。边界：目录外事件既不能经 GUI 添加，也不能经 JSON 保存。
- **Hooks 显式保存与 User 层确认**：规则：Hooks 不自动保存；User 层保存前二次确认，Project/Local 直接保存。原因：hooks 可执行任意命令，用户级影响全部项目。边界：保存失败保留未保存状态与重试入口。
- **Hooks 写入前备份、冲突中止**：规则：写前生成上一代备份，保存前检测外部修改与文件锁冲突，失败时原文件不变。原因：用户可能在外部编辑同一配置文件，静默覆盖会造成数据丢失。边界：写入只替换 hooks 子树，其他字段保留。
- **注入与卸载以设置文件写入为提交点**：规则：提交前失败回滚已准备内容，提交后清理失败可见并可重试。原因：避免出现配置与脚本不一致的半完成状态。边界：卸载遇到损坏文件时整体失败并保留脚本目录。
- **Hooks 可见期间监听外部修改**：规则：面板可见且项目活跃时监听当前层级文件，变化显示横幅与重新加载；保存前仍做冲突检测。原因：减少保存时才发现冲突。边界：监听不自动合并或覆盖编辑模型。
- **面板参数随项目布局持久化**：规则：选中页与页内参数随项目布局保存，不写入应用设置；关闭重开按新面板处理。原因：面板参数属于布局状态，应用设置属于全局配置。边界：未知选中页回退到第一个可用页；未知参数被忽略。
- **导入导出与恢复默认的作用域**：规则：导出不含 Hooks 与 CLI 文件；导入校验、预览、备份后提交；恢复默认不触碰 Hooks、CLI 文件、项目布局与项目内容。原因：应用设置与项目/CLI 数据边界清晰，避免误操作扩大影响面。边界：Hooks 页没有页级恢复默认；Agent 页只复位当前 CLI。
