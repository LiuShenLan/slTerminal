# Markdown 文档面板

> 拥有 Markdown 源码／渲染两态、渲染安全、链接资源、公式、Mermaid 和阅读状态；共享文本与保存由 [Document](document.md) 拥有。

## 两态与共享 Document

- 首次打开 `.md`／`.markdown` 默认进入渲染态；源码与渲染互斥，不提供 WYSIWYG 或同屏分栏。
- 两态始终使用同一 Document。源码修改立即成为渲染源，切换形态不读盘；Editor、Markdown 与 Diff 的引用不会产生独立草稿。
- 源码态复用编辑器的编辑、编码、查找替换和字号能力；不提供独立语言覆盖、代码折叠或 HTML 系统打开按钮。
- 渲染态只读，可选择、复制、滚动、缩放、查找和激活链接；任务列表等文档控件不反向修改源码。
- 形态、标题大纲开关、渲染缩放和阅读位置属于 `ViewKey` 持久状态，关闭重开与重启均恢复；大文档降级优先于持久形态。
- 查找栏、搜索词、缩放提示、菜单、大纲浮层的临时展开状态和焦点为瞬态，两条恢复路径都清除。

## 渲染能力

- 支持 CommonMark 与 GFM：标题、段落、强调、列表、引用、分隔线、代码、链接、图片、表格、删除线、任务列表和自动链接。
- 支持 GitHub 提示块、脚注和文档开头 YAML front matter；未知提示标记按普通引用，缺失脚注按普通文本，front matter 解析失败按正文显示。
- 标题锚点由标题文本与重名序号稳定生成；文档内链接、大纲和脚注共用锚点。
- 代码块使用共享语言注册表与别名归一，未知语言按纯文本；长代码和宽表格在块内横向滚动，不撑破面板。
- 正文、代码、公式、链接和图片使用当前暗色主题语义 token；主题切换不读盘、不改变 Document。
- 渲染后台执行，旧代结果不得覆盖新草稿；源码编辑时不做不可见渲染，切回渲染态再计算。整篇失败可重试并查看源码，单块失败降级为该块源码。

## 安全 HTML、公式与 Mermaid

- 原始 HTML 仅解析安全子集：`br`、`hr`、`sub`、`sup`、`kbd`、`a`、`img`、`picture`、`source`、`details`、`summary`；属性只允许经校验的 `href`、`src`、`srcset`、`alt`、`title`、`width`、`height`、`open`。
- 脚本、样式、事件、表单、框架、`object`、`embed`、未知或危险内容不执行；按转义文本或安全占位显示。
- 支持 `$...$` 行内公式与 `$$...$$` 块级公式，避免把普通货币文本误判为公式；失败时显示公式源码和错误，不中断其他内容。公式不得产生链接或外部请求。
- `mermaid` 围栏支持静态图渲染；失败时显示 Mermaid 源码与错误。不得执行脚本、加载外部资源或响应图内点击、跳转和其他交互。
- 不提供代码块复制按钮、语言标签控件、公式源码复制、图片放大、复制路径或应用自定义渲染右键菜单；普通文本选择复制仍可用。

## 链接分派

| 目标 | 行为 |
|---|---|
| `#fragment` | 定位当前文档锚点；空 `#` 回顶部 |
| `http`、`https` | 交系统默认浏览器 |
| `mailto`、`tel` | 交系统默认处理程序 |
| 本地相对或绝对路径 | 经 PathPolicy 校验后按统一文件路由打开 |
| `javascript:`、`data:`、`blob:`、`file:` 及其他协议 | 无动作或显示策略拒绝提示 |

- 相对路径以当前 Markdown 文件目录为基准；`?query` 不参与文件路径，`#fragment` 可用于目标 Markdown 锚点。
- 有持久读授权的目标可自动打开；根外文件仅在用户显式点击后获得该文件的会话级只读授权，不扩大资源、文件树或终端权限。
- 目录、不存在或不可读目标不创建面板，显示非阻塞原因。链接悬停或聚焦提示只做元数据检查，不读正文、不发起网络请求。
- 显式本地链接、资源读取和恢复分别按 [PathPolicy](../path-policy.md) 判定，不用“可写根”代替全部读授权。

## 本地与远程资源

- 支持 png、jpg、jpeg、gif、webp、avif、bmp、ico 和静态 SVG；SVG 清洗脚本、事件、外部引用、`foreignObject` 与可执行内容，清洗失败显示占位。
- 每个本地资源独立取得持久读取授权；根外文档或根外链接不扩大资源边界。
- 单资源上限 20 MB，解码缓存上限 128 MB，按最近使用淘汰；图片按视口附近懒加载，缓存身份包含位置与版本。
- `data:image/...` 按同一大小与安全规则处理，非图片 data 内容忽略。
- 远程 `http`／`https` 图片默认不加载，显示占位和“加载”。用户点击后仅请求该图片一次，不携带 Cookie、凭据或 Referer；单图 20 MB、超时 10 秒，失败保留重试。
- 远程字体、样式、脚本和 Mermaid 外部资源永不加载。资源失败保留 alt、路径与简短原因，不阻断文档。

## 大纲、查找与阅读位置

- 渲染态大纲按标题层级显示，激活条目滚动到锚点；无标题显示空态。大纲浮层不常驻挤占内容区。
- `Ctrl+F` 只搜索渲染后可见文本，不搜索源码、URL、图片 alt 或原始 HTML；按字面量匹配，显示当前／总数，`Enter` 与 `Shift+Enter` 导航。
- 渲染缩放范围 25%–400%，`Ctrl+滚轮` 按 1.1 倍步进，重置回 100%；缩放不改变源码字号。
- 阅读位置以顶部最近标题或块锚点及块内偏移恢复；锚点消失时按比例回退，最后收敛到有效边界。
- 重渲染、关闭重开与重启都按同一阅读状态恢复；恢复缩放时不显示临时缩放提示。
- 键盘可完成形态切换、滚动、链接、大纲、查找和重置；减少动效时取消平滑滚动与非必要动画。

## 大文档与外部变化

- 超过 5 MB 或 100,000 行时默认强制源码态，显示原因并允许用户显式“仍要渲染”；选择后渐进渲染且可取消。
- 超过 50 MB 时按编辑器大文件规则只读，禁止渲染且不提供“仍要渲染”。
- 外部修改、冲突、删除和重命名由 Document 统一处理；渲染源只在共享 Document 更新后变化。
- 自动保存与崩溃恢复均按 Document 执行，不再存在独立 Markdown 草稿开关或按 Panel 快照。
- 失去读授权时保留当前渲染与源码并停止刷新；失去写授权后可按 Document 规则另存为。

## 验收判据

- **Given** Markdown 在源码态修改后切到渲染，**Then** 不读盘且立即渲染共享 Document 最新文本；Editor 与 Diff 同时看到该文本。
- **Given** 设置源码态、大纲、缩放和阅读位置，**When** 关闭重开或重启，**Then** 两种路径均恢复这些持久状态；查找栏与焦点清除。
- **Given** 文档含脚本、危险 HTML、远程字体或带外部引用的 SVG，**When** 渲染，**Then** 不执行、不加载，其他安全内容继续显示。
- **Given** 文档含有效和无效 Mermaid，**When** 渲染，**Then** 有效图静态显示，无效块显示源码与错误，均无图内交互或外部请求。
- **Given** 远程图片未获点击授权，**When** 打开文档，**Then** 不发起请求；点击单图加载后不携带 Cookie、凭据或 Referer。
- **Given** 根外 Markdown 引用相邻图片，**When** 显式打开该文档，**Then** 文件可读不等于资源获批，未授权图片只显示占位。
- **Given** 大文档超过渲染阈值，**When** 关闭重开或重启，**Then** 大文档降级优先于持久渲染形态。
- **Given** 自动保存开启，**When** Markdown 共享 Document 停止修改 1 秒，**Then** 按 Document 规则保存，不再使用独立草稿机制。
