# Markdown 文档面板

> 定义 Markdown 面板的源码/渲染两态与默认渲染、渲染管线、链接分派、本地与远程资源、安全 HTML 子集、Mermaid 源码显示与渲染接口、查找与大纲、扩展语法、冲突差异摘要、草稿快照恢复、保存并关闭、外部修改与重命名、键盘与输入、大文档分级。文件打开路由与 HTML 文件的源码视图及系统打开悬浮按钮归[编辑器](editor.md)；面板生命周期、焦点、标题与关闭守卫归[工作区](../workspace/shell.md)。本篇不拥有工作区、设置持久化、Diff 与终端行为。

## 目标行为

### 面板归属与两态

- Markdown 面板只处理 `.md`、`.markdown` 文件，扩展名不区分大小写；每个项目内每个路径只保留一个 Markdown 面板。
- `.html`、`.htm` 不在应用内渲染，进入编辑器显示源码，并在内容区右上角提供系统打开悬浮按钮，行为归[编辑器](editor.md)。
- 面板状态为互斥二值，默认渲染：

| 状态 | 内容 | 可编辑 |
|---|---|---|
| 渲染 | 当前草稿的渲染结果；只读；可滚动、缩放、选择文本、激活链接 | 否 |
| 源码 | 全宽的 Markdown 源码编辑视图；可编辑草稿、保存、撤销 | 是 |

- 新建面板、关闭后重开、保存的形态值非法或缺失时，进入渲染态。
- 形态作为面板参数随项目布局持久化：面板组内切换面板、切换项目、应用重启后保留上次形态；持久化机制见[设置与持久化](../settings-and-persistence.md)。
- 形态切换不重新读取磁盘；两态始终使用同一份面板内存草稿。渲染源永远是草稿，不直接读取磁盘。
- 源码态是编辑器能力在 Markdown 面板内的编辑视图。保存、脏状态、外部修改与外部重命名、撤销历史、光标、选择、查找替换、自动换行、字号、编码与换行符遵循[编辑器](editor.md)契约；本篇只定义其与渲染态的关系。
- 源码态继承白名单：编辑、撤销/重做、光标/选择/滚动、查找替换、自动换行、字号、编码/BOM、行尾、外部修改/重命名、保存冲突、关闭守卫、只读浏览分级；不继承语言选择器、代码折叠、Git 行标、HTML 悬浮按钮与编辑器自动保存开关。
- 源码态修改即时写入内存草稿；草稿与磁盘内容不一致时面板为脏，保存成功或重新加载磁盘内容后转为干净。
- 从源码态切到渲染态时立即按当前草稿渲染，不等待输入停止计时；从渲染态切到源码态时显示当前草稿，并保留上次源码态的撤销历史、光标、选择与滚动位置。
- 脏状态附着于面板，渲染态与源码态共用同一脏标记；只有源码态产生修改。
- 根外只读打开的 Markdown 面板不产生可保存草稿与脏状态；源码态只读，不可编辑、不可保存。
- 文件已移出允许根：可编辑 Markdown 文档被外部重命名或移动到项目根与 Agent 目录之外后进入脱离状态；保留内存草稿、脏状态与形态，禁用原地保存，提供另存为；移回允许根内后恢复普通可编辑与原地保存。

### 渲染能力

#### 语法与结构

- 渲染 CommonMark 核心语法与 GFM 扩展：标题、段落、强调、列表、引用、分隔线、围栏与缩进代码块、行内代码、链接、图片、表格、删除线、任务列表、自动链接。
- 任务列表以只读勾选状态显示，点击不修改源码草稿。
- 支持 GitHub 提示块：引用块首行为 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` 时渲染为对应类型的提示块；未知标记按普通引用显示。
- 支持脚注：`[^标识]` 引用与 `[^标识]: 定义` 渲染为文内引用链接与文末脚注列表，引用与脚注条目可互相跳转；缺失定义的引用按普通文本显示。
- 支持位于文档开头、由 `---` 包围的 YAML front matter：内容解析为元数据，不进入正文渲染；解析失败时按普通文本显示。源码态始终保留原文。
- 为每个标题生成稳定锚点：由标题文本归一化得到，同名标题追加序号；锚点在重渲染后保持不变，供文档内链接、大纲与脚注使用。

#### 排版、代码与主题

- 正文排版使用当前暗色主题的语义令牌；正文、标题、引用、表格、行内代码、代码块、链接与分隔线不得硬编码颜色。
- 正文段落最大行宽 900px；表格、代码块与图片可占满内容区宽度；内容区左右内边距由主题排版令牌定义。
- 表格按列对齐；宽表格在表格内部横向滚动，不撑破面板。
- 代码块按语言语法高亮；长行默认不折行，代码块内部横向滚动。
- 内置高亮语言至少包含：JavaScript、TypeScript、JSON、HTML、XML、CSS、SCSS、Bash、Shell、PowerShell、Python、Rust、Go、Java、C、C++、C#、SQL、YAML、TOML、INI、Diff、Markdown、Dockerfile、Makefile。
- 语言别名归一：`js`、`node`、`jsx` 归一 JavaScript；`ts`、`tsx` 归一 TypeScript；`sh`、`zsh`、`console` 归一 Shell；`py`、`python3` 归一 Python；`ps1`、`pwsh` 归一 PowerShell；`yml` 归一 YAML；`md` 归一 Markdown。未知语言按纯文本显示。
- 图片显示宽度不超过内容宽度，小图不放大；渲染态整体缩放时图片随内容一起缩放。
- 主题切换后，渲染态按新语义令牌立即重渲染，不重新读取磁盘。

#### 安全 HTML 子集

- 原始 HTML 按不可信内容处理：不执行脚本、事件属性、表单、框架类标签、`object`、`embed` 或外部资源；仅解析无交互的安全子集，其余标签按转义文本显示。
- 安全子集至少包含 `br`、`hr`、`sub`、`sup`、`kbd`、`a`、`img`、`picture`、`source`、`details`、`summary`。
- 安全子集属性仅允许 `href`、`src`、`srcset`、`alt`、`title`、`width`、`height`、`open`，且经过链接分派与本地资源策略校验。
- `script`、`style`、框架类标签、`object`、`embed`、`form` 等标签不解析；危险或未知标签按文本显示。
- 原始 HTML 中的链接与图片分别进入链接分派与本地资源策略。
- `details`/`summary` 可展开与收起；展开状态仅存在于当前渲染，不写回源码。

#### 公式与 Mermaid

- 公式支持 `$...$` 行内公式与 `$$...$$` 块级公式；识别时避免把货币金额等非公式文本误判。
- 公式渲染失败时在原文位置显示公式源码并标记错误样式，不中断整篇渲染。
- 公式不得生成可点击链接或外部资源引用。
- Mermaid 围栏代码块首版不渲染，按普通代码块显示源码；保留渲染接口与扩展点，后续可接入静态图渲染。
- Mermaid 源码不执行脚本、不加载外部资源；不提供图内点击、跳转或交互。

#### 内容操作边界

- 代码块、公式与图片本身正常渲染：代码块按语言语法高亮，公式排版显示，图片内联显示。
- 不提供代码块复制按钮与语言标签控件，不提供公式源码复制操作，不提供图片放大或复制路径操作。
- 渲染态不提供应用自定义右键菜单；文本选择与复制使用平台默认行为。
- 不提供超出键盘与输入约定的额外增强，约定见「键盘与输入」。
- 不提供渲染态直接编辑、同屏编辑与预览分栏、HTML 渲染、PDF 与 Office 等独立预览面板、独立图片查看器、独立预览窗口、画中画或浮出面板；渲染内容只在当前面板内显示。
- 不提供远程资源自动加载；Mermaid 首版不渲染，不提供图内交互。

#### 渲染调度

- 渲染在后台完成，前台保持可交互；过期渲染结果丢弃，不覆盖较新的草稿。
- 首次渲染耗时超过 100ms 时，显示居中 `渲染中...`；首次渲染完成后，后续重渲染期间保留上一版内容，不回退到占位。
- 渲染态可见期间，草稿只可能因外部修改重载而变化；外部重载后恢复阅读位置。
- 源码态编辑期间不触发渲染；切回渲染态时立即渲染一次。

### 链接分派

渲染态中的可点击链接统一由 Markdown 面板分派；源码态中的链接文本由编辑器按普通文本处理。

| 链接形态 | 行为 |
|---|---|
| `#fragment` | 在当前渲染文档内定位到对应标题锚点；空 `#` 回到顶部；锚点不存在时无动作 |
| `http`、`https` | 交给系统默认浏览器打开；应用不内嵌打开 |
| `mailto`、`tel` | 交给系统默认处理程序 |
| Windows 盘符绝对路径 | 解析为本地路径后走本地文件打开规则 |
| 相对路径 | 以 Markdown 文件所在目录为基准解析；无磁盘路径时以项目根为基准 |
| `data:`、`blob:`、`javascript:`、`file:` 及其他协议 | 忽略，无动作 |

本地文件打开规则：

- 路径先做分隔符归一、百分号解码与 `..` 归一，再做项目根边界校验。
- 解析后位于项目根内的本地文件，走与文件浏览器一致的应用内打开链路；同一项目内已打开则聚焦已有面板，不新建。
- 目标为 `.md`、`.markdown` 时打开 Markdown 面板并默认渲染态；目标面板已存在时保持其原有形态。
- 目标为 `.html`、`.htm` 时打开编辑器面板并显示系统打开悬浮按钮，路由归[编辑器](editor.md)。
- 目标为其他文件类型时打开编辑器面板；编辑器无法处理的类型显示编辑器自身的错误。
- 本地链接可携带 `#fragment`：目标为 Markdown 文件时，打开或聚焦后定位到对应锚点；锚点不存在时停在顶部。
- 本地链接中的 `?query` 不参与文件路径解析，忽略；`#fragment` 只用于文档内定位。
- 目标不存在、不可读或为目录时，不创建面板，显示非阻塞提示 `链接目标不存在`、`链接目标不可读` 或 `链接目标是目录`。
- 解析后位于项目根外的本地路径，由用户显式点击后应用内只读打开，面板标注 `项目根外`；同一项目内同一规范化路径已打开则聚焦已有面板；不加入项目文件树、不参与 Commit、不改变终端工作目录。
- 根外 `.md`、`.markdown` 打开 Markdown 面板并保持渲染态；源码态只读，不可编辑、不产生草稿与脏状态。
- 根外 `.html`、`.htm` 与其他文件类型打开编辑器面板并只读显示；HTML 同样显示系统打开悬浮按钮，行为归编辑器。
- 根外只读打开不扩大本地资源读取边界；面板内的图片等本地资源仍按项目根规则显示占位。
- UNC 路径仅在真实目标位于项目根内时可用；设备路径与盘符相对路径不应用内打开，按不可用链接处理。
- 外部链接地址原样交给系统；地址无法解析时忽略并显示非阻塞提示。
- 渲染态链接在悬停或键盘聚焦时显示目标提示：外部地址显示完整 URL；本地路径显示归一化路径、目标类型与存在性（存在、不存在、不可读、目录）；`#fragment` 显示当前文档与锚点名。提示只做元数据检查，不读取目标内容，不发起网络请求。

### 本地与远程资源

- 渲染态支持 Markdown 图片语法与安全子集中的 `img`、`picture`、`source` 引用；`picture` 按候选顺序选择首个可读取资源。
- 相对资源以 Markdown 文件所在目录为基准；无磁盘路径时以项目根为基准。Windows 盘符绝对路径可直接使用。
- 资源路径经归一与边界校验后，仅允许读取项目根内的本地文件；符号链接、目录联接等解析后的真实路径必须仍在项目根内。
- 支持格式：png、jpg、jpeg、gif、webp、avif、bmp、ico、svg。
- SVG 按静态图片渲染，渲染前去除脚本、事件属性、外部引用、`foreignObject` 与可执行内容；清洗失败时显示占位。
- 单个资源上限 20MB；已解码图片缓存上限 128MB，按最近使用淘汰；超出缓存的图片可重新读取。
- 内嵌 `data:image/...` 图片按同一大小上限处理；非图片 data 内容忽略。
- 图片按视口懒加载：进入视口附近才读取与解码；同一资源在缓存有效期内不重复读取。
- 资源缓存键包含真实路径、修改时间与文件大小；磁盘文件变化后重新读取。
- 读取失败、格式不支持、超出大小上限、位于项目根外、SVG 清洗失败时，显示固定尺寸占位：保留 alt 文本与原始路径，显示简短原因，不弹出阻断式错误。
- 远程 `http`、`https` 图片默认不加载、不发起网络请求；显示占位、URL 与 `加载` 操作，原因文案为 `远程资源未加载`。
- 用户点击 `加载` 后，仅对该图片发起一次请求，不自动加载其他远程资源；每次点击只加载该图片，失败后保留 `加载` 供再次触发。
- 远程图片加载仅接受 `http`、`https` 地址与图片内容类型；单图上限 20MB，超时 10 秒，不携带 Cookie 或凭据。远程 SVG 按本节的静态清洗规则处理。
- 远程图片加载成功后原位显示并纳入同一解码缓存（以 URL 为键），遵循同一缓存上限；超时、超限、非图片、解码失败或清洗失败时显示占位与对应原因。
- 远程字体、样式与脚本永不加载。

### 缩放、滚动与阅读位置

- 渲染态支持 `Ctrl+滚轮` 缩放：上滚放大、下滚缩小；每累计 100px 滚轮增量步进一档，每档乘以或除以 1.1。
- 缩放范围 25%–400%；到达边界后继续滚动不再变化。
- 每次实际缩放变化时，面板右上角显示缩放提示：取整百分比与 `重置` 按钮；最后一次变化后 3 秒自动消失，期间再次变化续期。
- 点击 `重置` 立即回到 100%，并立即隐藏提示；相同缩放值重复上报不续期、不显示提示。
- 缩放按面板保存：面板组内切换面板、切换项目、应用重启后保留；关闭后重开的新面板从 100% 开始。
- 源码态的字号缩放遵循编辑器契约，不使用渲染态缩放。
- 渲染态为单一大垂直滚动容器；宽表格、代码块在各自内部横向滚动。
- 滚动位置在形态切换、面板组内切换面板、切换项目期间保留。
- 重新渲染后按阅读位置恢复：记录视口顶部最近的标题或块锚点及块内偏移；重渲染后优先恢复该锚点，锚点不存在时按滚动比例回退，最后做边界收敛。
- 应用重启后恢复渲染态的滚动锚点与缩放；文件内容变化导致锚点消失时按比例回退，再不存在时回到顶部。
- 重渲染与应用重启恢复缩放时不显示缩放提示；提示只反映用户主动缩放变化。
- 关闭面板后重开不恢复滚动位置，从顶部开始。
- 渲染态支持键盘滚动：方向键、PageUp、PageDown、Home、End、Space、Shift+Space；减少动效设置开启时不做平滑滚动动画。
- 缩放与滚动不写入文档文件，按面板参数持久化。

### 标题大纲与查找

- 渲染态右上角提供标题大纲开关，默认关闭；开关值作为面板参数随项目布局持久化。
- 开启后显示浮层，按标题层级缩进列出当前渲染文档的全部标题；无标题时显示 `无标题`。
- 点击或键盘激活条目后，滚动到对应标题锚点；条目按文档顺序排列。
- 浮层不常驻占用版面；开关关闭即隐藏；`Esc` 关闭浮层并同步关闭开关。
- 源码态隐藏大纲开关；切回渲染态恢复此前的开关值。
- 重渲染后大纲按新标题更新。
- 渲染态 `Ctrl+F` 打开面板内查找栏并聚焦输入框；查找栏已打开时再次 `Ctrl+F` 只聚焦输入框。
- 输入即时匹配当前渲染文本；全部匹配显示高亮，当前匹配使用区别高亮并滚入视口；计数显示 `当前/总数`，无匹配显示 `0/0`。
- `Enter` 移动到下一个匹配，`Shift+Enter` 移动到上一个匹配。
- `Esc` 关闭查找栏、清除高亮，并将焦点返回渲染内容滚动容器。
- 仅搜索渲染后可见文本；不搜索 Markdown 源码、链接地址、图片 alt 与原始 HTML 标签。匹配为纯文本，不提供正则、全词匹配或替换。
- 草稿重渲染后重新计算匹配与计数；查找栏不持久化。
- 源码态的查找替换遵循编辑器契约，不使用渲染态查找栏。

### 安全边界

- 文档内容按不可信输入处理；任何文档内容不得在应用内执行脚本、事件处理器、表单逻辑或外部程序。
- HTML 文件只在编辑器中显示源码，不在应用内渲染或执行。
- Markdown 原始 HTML 仅按安全子集解析；未知或危险标签按文本显示。
- 渲染态不自动发起网络请求；仅当用户点击远程图片的 `加载` 操作时，对单个 `http`、`https` 图片发起一次请求，不携带 Cookie 或凭据。远程字体、远程样式与远程脚本永不加载。
- 本地资源读取限制在项目根内；路径穿越、符号链接逃逸、项目根外的 UNC 路径与设备路径均被拒绝。
- 项目根外链接仅按用户显式点击只读打开，不加入项目文件树、不参与 Commit、不改变终端工作目录，也不扩大本地资源读取边界。
- SVG 按静态内容处理，不执行脚本、不响应点击跳转、不加载外部资源；Mermaid 首版按源码显示，不执行内容。
- 公式不得生成链接或外部资源引用。
- 链接只按白名单分派；`javascript:`、`data:`、`blob:`、`file:` 等协议不执行。
- 错误消息只包含路径与原因，不包含文档正文或敏感内容；公式错误可在界面显示对应公式源码；日志不记录文档全文。

## 交互规则

### 入口、去重与焦点

- 文件浏览器打开 `.md`、`.markdown` 文件时，在活跃项目的聚焦面板组创建 Markdown 面板，默认渲染态。
- 文件浏览器打开 `.html`、`.htm` 文件时，按[编辑器](editor.md)契约创建编辑器面板并显示系统打开悬浮按钮，不创建 Markdown 面板。
- Markdown 渲染态中的本地链接按「链接分派」打开目标文件，复用同一打开链路与去重规则。
- 同一项目内同一文件已存在对应面板时，聚焦已有面板，不新建；已有面板的形态、草稿、滚动与缩放保持不变。
- 显式打开或激活面板时，键盘焦点进入面板容器；渲染态不自动把焦点送入渲染内容区或查找输入框，源码态按编辑器焦点落点进入源码编辑器输入区。
- 布局恢复不产生焦点意图，不抢键盘焦点；恢复后的面板不自动获得焦点。
- 面板关闭路径、`Ctrl+W`、中键、页签菜单与批量关闭遵循[工作区](../workspace/shell.md)契约；脏面板先走关闭守卫。
- 面板标题、同名文件相对路径消歧遵循工作区契约；外部重命名后更新文件路径与页签标题。

### 形态切换

- 面板右上角显示两段式切换控件：`渲染`、`源码`；当前形态高亮，另一段可点击。
- 切换控件在文件加载成功后显示；文件读取失败时不显示。
- 点击非当前段立即切换；点击当前段无动作。
- 切换控件可用 Tab 聚焦，Enter 或 Space 激活；焦点环可见。
- 渲染态切到源码态：焦点进入源码编辑器，光标停在草稿中上一源码态的位置；首次进入时停在文档开头。
- 源码态切到渲染态：焦点回到面板容器，不自动进入渲染内容区；若存在未渲染修改，立即渲染。
- 切换形态不重新读取磁盘，不改变草稿，不重置滚动锚点与缩放；源码态撤销历史、光标与选择保留。
- 形态切换不使用会阻塞交互的过渡动画；减少动效设置开启时立即切换。

### 渲染内容交互

- 渲染文本可选择、复制；`Ctrl+C` 复制选区。
- 链接单击激活，按「链接分派」处理；指针悬停显示手型，获得焦点时显示焦点环。
- 链接悬停或键盘聚焦时显示目标提示；提示不抢占焦点，不发起网络请求。
- 脚注引用与回链按当前文档内锚点处理，不进入外部链接分派。
- 远程图片占位中的 `加载` 可点击，也可通过键盘聚焦激活；加载成功后按钮消失。
- `Ctrl+滚轮` 缩放；无修饰键滚轮滚动文档。
- 缩放提示中的 `重置` 可点击，也可通过键盘聚焦激活。
- 任务列表勾选状态只读，不响应点击修改。
- 安全子集中的 `details`/`summary` 可展开与收起；展开状态仅存在于当前渲染，不写回源码。
- 公式与已加载图片不响应点击；Mermaid 代码块按普通代码块显示，不提供图内跳转；远程图片仅占位中的 `加载` 响应点击。
- 渲染态不提供应用自定义右键菜单；文本选择与复制使用平台默认行为。
- 点击渲染内容空白处将焦点移入渲染内容滚动容器。

### 键盘与焦点

- 渲染态内容可聚焦；聚焦后方向键、PageUp、PageDown、Home、End、Space、Shift+Space 滚动文档。
- Tab 与 Shift+Tab 在文档内可聚焦元素之间移动；链接按文档顺序进入焦点序列，Enter 激活。
- 渲染态 `Ctrl+F` 打开查找栏并聚焦输入框；查找栏内 `Enter` 下一个、`Shift+Enter` 上一个、`Esc` 关闭并清除高亮。源码态 `Ctrl+F` 遵循编辑器查找契约。
- 标题大纲开关与大纲条目按 Tab 顺序聚焦，Enter 或 Space 激活；`Esc` 关闭大纲浮层。
- 渲染态不存在表单输入、可编辑区域或脚本焦点陷阱；`Ctrl+W` 在任何渲染内容焦点下都能关闭当前面板。
- 源码态 `Ctrl+S` 保存；渲染态 `Ctrl+S` 不执行保存，避免对未编辑内容产生隐式写盘。
- 源码态输入法组合期间不触发形态切换、链接激活或全局命令；组合结束后恢复正常。
- 缩放提示中的 `重置` 在提示可见时进入 Tab 顺序，提示消失后移出。
- 焦点环宽度 2px，颜色使用主题焦点令牌；不做对比度准入校验。

### 状态保留

| 状态对象 | 面板组内切换面板 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|
| Markdown 形态（渲染/源码） | 保留 | 保留 | 不保留，默认渲染 | 保留 |
| 源码草稿 | 保留 | 保留 | 不保留，关闭前走脏守卫 | 不保留，崩溃时按草稿快照恢复 |
| 文件已移出允许根的脱离草稿 | 保留 | 保留 | 关闭守卫；另存为成功或丢弃 | 崩溃快照可提示恢复 |
| 源码撤销历史、光标、选择 | 保留 | 保留 | 不保留 | 不保留 |
| 渲染滚动锚点 | 保留 | 保留 | 不保留，从顶部开始 | 保留 |
| 渲染缩放比例 | 保留 | 保留 | 不保留，100% | 保留 |
| 标题大纲开关 | 保留 | 保留 | 不保留，默认关闭 | 保留 |
| 渲染态查找栏 | 瞬态 | 瞬态 | 不保留 | 不保留 |
| 缩放提示显隐 | 瞬态 | 瞬态 | 不保留 | 不保留 |
| 崩溃草稿快照 | 保留 | 保留 | 正常关闭时清理 | 检测到快照时提示恢复或丢弃 |
| 外部冲突横幅 | 保留 | 保留 | 不保留 | 不保留 |
| 外部删除横幅 | 保留 | 保留 | 不保留 | 不保留 |

- 项目隐藏期间，Markdown 面板不卸载；外部修改与草稿状态继续保留，重新显示时不抢焦点。
- 未保存草稿不写入设置或布局；正常重启后从磁盘重新读取文件；崩溃恢复只读取草稿快照。标题大纲开关随项目布局持久化，查找栏不持久化。

### 保存与关闭

- 保存成功不弹提示，脏标记清除；保存失败显示非阻塞提示 `保存失败：{message}`，脏标记保留。
- 关闭脏面板时，工作区确认框标题为 `未保存的修改`，按钮为 `取消`、`保存并关闭` 与 `丢弃并关闭`。
- 选择 `保存并关闭` 先保存草稿，保存成功后关闭；保存失败时通知 `保存失败，面板未关闭`，面板保持打开，草稿、脏状态与 `保存失败：{message}` 提示保留；取消后面板与草稿保持原状。
- 批量关闭、项目移除与窗口关闭按[工作区](../workspace/shell.md)的批量保存与关闭契约处理；任一保存失败中止关闭并保留全部面板与脏状态。
- 根外只读面板没有脏状态，关闭不触发保存确认；文件已移出允许根的脱离草稿保留脏状态并进入关闭守卫，`保存并关闭` 通过另存为完成。

### 反馈

- 本地链接目标不存在、不可读或为目录时，显示对应非阻塞提示，不创建面板。
- 图片失败显示内联占位与原因，不弹阻断式对话框。
- 远程图片默认显示 `远程资源未加载` 占位与 `加载`；加载失败显示占位与原因，保留 `加载` 供再次触发。
- 公式失败显示内联源码与错误样式。
- 外部修改冲突在面板顶部显示非模态冲突横幅 `文件已被外部修改`，提供 `重载`、`保留我的修改` 与 `查看差异`；横幅不抢焦点。
- 外部删除显示面板顶部常驻横幅 `文件已从磁盘删除`。
- 渲染整体失败显示 `渲染失败` 状态，提供 `重试` 与 `查看源码`。
- 大文档降级显示顶部横幅与 `仍要渲染` 操作。
- 缩放提示、保存失败、外部变更、渲染失败与远程图片加载结果通过状态提示，避免重复提示。

## 边界与错误

### 空态与加载

- 空文件或仅含空白的 Markdown 文件：渲染态显示居中 `空文档` 提示与 `切换到源码` 操作；源码态显示正常空编辑器。
- 文件读取期间显示居中 `加载中...`；形态切换控件与缩放提示不显示。
- 文件读取失败显示居中 `加载失败: {message}`，提供 `重试` 与 `关闭` 操作。
- 首次渲染超过 100ms 显示 `渲染中...`；首次渲染完成后不因后续重渲染回退到该文案。
- 文件读取完成后，渲染态立即开始首次渲染；源码态直接显示源码。
- 应用重启恢复面板时，文件从磁盘重新读取；文件已不存在时显示 `加载失败: 文件不存在`，不恢复草稿。

### 渲染降级

- 未知代码语言按纯文本显示，保留代码块边框与横向滚动。
- 公式语法错误显示原始公式源码与错误样式，同一文档其余内容继续渲染。
- 图片缺失、越界、超限、格式不支持或解码失败显示占位，原因文案与原始路径可见。
- 远程图片未加载、超时、超限、非图片或加载失败时显示占位与对应原因，不阻塞其余内容。
- 未知提示块标记按普通引用显示；脚注缺失定义按普通文本显示；front matter 解析失败按普通文本显示。
- 原始 HTML 的危险标签与未知标签按转义文本显示，不执行、不加载。
- 单个块渲染失败时按块降级为源码文本；整篇渲染失败时显示 `渲染失败` 状态，保留 `查看源码` 入口。
- 异步渲染结果过期时丢弃；不出现旧结果覆盖新草稿的闪烁。
- 表格列数过多或单元格内容过长时，表格内部横向滚动，不挤压面板布局。

### 外部变更与冲突

- 无未保存修改时，磁盘文件被修改或原子替换：自动重新读取并刷新；渲染态恢复阅读位置，源码态按编辑器契约重载并显示轻量提示 `已从磁盘重新加载`。
- 有未保存修改时，磁盘文件被修改：面板顶部显示非模态冲突横幅 `文件已被外部修改`，按钮为 `重载`、`保留我的修改` 与 `查看差异`；横幅不抢焦点，以提醒语义暴露给用户。
- `查看差异`：按[编辑器](editor.md)契约以磁盘版本创建临时只读快照，在[Diff](diff.md)面板以只读冲突快照模式打开该快照与当前草稿的差异并定位到首个差异块；两侧只读、不可保存，查看差异不改变草稿、脏状态与冲突横幅。
- 选择 `重载`：丢弃草稿，读取磁盘内容，脏标记清除，关闭横幅；渲染态重新渲染并恢复阅读位置。
- 选择 `保留我的修改`：草稿保持脏，关闭横幅；磁盘内容再次变化时横幅重新显示；之后保存按编辑器保存冲突规则处理并显示 `保存冲突` 对话框。
- 磁盘文件被删除：面板顶部显示常驻横幅 `文件已从磁盘删除`，提供 `保留内容` 与 `关闭面板`；内容保留，可继续编辑。
- 外部删除后保存：按编辑器契约显示 `文件已不存在` 对话框并提供另存为与重新创建路径；重新创建失败时显示 `保存失败：{message}`，删除横幅保留。
- 外部重命名或移动且文件监听器提供旧路径到新路径映射时，面板跟随重命名：更新文件路径与页签标题，保留草稿、脏状态、形态、滚动与缩放，不弹确认。新路径仍位于项目根或已登记 Agent 全局目录内时保持可编辑；移动到这些允许根之外时进入“文件已移出允许根”的脱离状态，保留草稿与脏状态，禁用原地保存，提供另存为与关闭；无法关联到新路径时按删除处理。新路径已在同一项目内打开时，按编辑器契约的 `目标文件已打开` 处理。
- 重命名导致扩展名跨分派类别变化（例如 `.md` 改为 `.html`）时，面板类型按编辑器契约转换，文本与脏状态保留。转为编辑器面板时显示源码与系统打开悬浮按钮；转为 Markdown 面板时，脏缓冲或原形态为源码则保持源码态，否则进入渲染态；原编辑器缓冲作为面板草稿，脏状态保留。目标路径已有同类型面板时按编辑器的 `目标文件已打开` 流程处理，显式确认替换，不静默覆盖。
- 外部重载读取失败时保留旧内容，显示非模态横幅 `无法读取外部修改`，提供 `重试` 与 `保留当前内容`；不自动清空草稿，下一次文件事件到达时仍可重试。
- 项目隐藏期间发生外部修改时，状态在内存中更新；冲突横幅延迟到项目重新显示时出现，不抢焦点。
- HTML 文件的外部修改、冲突、删除与重命名遵循编辑器契约；系统打开悬浮按钮不改变这些行为。

### 大文档分级

- Markdown 文件超过 5MB 或超过 100,000 行时，默认进入源码态，顶部显示 `文档较大，已使用源码模式` 与 `仍要渲染` 操作。
- 用户选择 `仍要渲染` 后，渲染按块渐进完成，图片懒加载，滚动保持可交互；可随时切回源码态。
- Markdown 文件超过 50MB 时，渲染态不提供 `仍要渲染`；源码态按编辑器大文件契约只读打开，显示 `文档过大，已只读打开`。
- 1MB 以内文档打开后 1 秒内首屏可读，滚动与形态切换无明显卡顿。
- 渲染、语法高亮、公式与图片解码不得阻塞前台交互；长任务可分块并响应取消。
- 宽表格、超长代码行与大量图片不撑破面板；内容区保持独立滚动。

### 草稿恢复

- 正常退出后应用重启恢复面板布局、Markdown 形态、渲染缩放、标题大纲开关与滚动锚点；草稿不恢复，文件从磁盘读取。
- 关闭后重开 Markdown 面板视为新面板：默认渲染态、100% 缩放、顶部位置、无草稿、标题大纲默认关闭。
- 文件在应用退出期间被删除：恢复时显示加载失败，不自动创建空文件。
- 文件在应用退出期间被修改：恢复后显示磁盘内容；滚动锚点不存在时按比例回退。
- Markdown 草稿在编辑期间周期性写入本地草稿快照；正常保存、关闭面板或正常退出时清理对应快照。快照不是自动保存，不写入文档文件。
- 设置中心的“自动保存”只作用于编辑器面板，不作用于 Markdown 源码态；Markdown 使用显式保存与草稿快照。
- 应用启动恢复面板时，若检测到未恢复的 Markdown 草稿快照，显示 `恢复未保存的草稿` 提示，提供 `恢复` 与 `丢弃`；恢复后对应面板进入源码态，草稿标脏，不自动写盘；丢弃后清理快照并从磁盘读取。
- 草稿崩溃恢复由[设置中心](settings.md)外观页的编辑器/Diff 行为节中的 `Markdown 草稿崩溃恢复` 开关控制，默认开启；关闭后不写草稿快照。快照只含草稿文本与面板文件路径，不写入设置、布局或审计。
- 草稿快照与编辑器共用同一恢复存储与配额：单文件 64 MiB、总配额 256 MiB、保留 7 天；快照键为 `(ProjectId, PanelId)`；项目移除删除其快照；损坏快照隔离并排除提示。
- 渲染器崩溃或异常不导致应用退出；面板显示渲染失败状态，可切到源码态继续工作。

### 键盘与输入

- 标题大纲浮层提供列表结构与标题层级；渲染态查找栏提供输入框、匹配计数与当前匹配状态。
- 所有交互可用键盘完成：形态切换、链接激活、滚动、缩放重置、标题大纲开关与条目、渲染态查找、错误重试。
- 焦点顺序符合视觉顺序；焦点环可见且不被面板边界裁剪。
- 减少动效设置开启时，平滑滚动、淡入淡出与动画图片播放降级为静态或瞬时行为。
- CJK 文本按语言规则换行，避免逐字断行；字体回退覆盖中文、日文、韩文与常见符号。
- 源码态输入法组合、候选窗与光标定位正常；渲染态中文选择与复制正常。
- 缩放至 400% 时内容可重排并可滚动，不出现不可达的横向内容。

### 平台与运行环境

- 仅 Windows 10/11 桌面，单窗口、单实例、仅暗色主题。
- 路径分隔符 `/` 与 `\` 均可识别；路径比较不区分大小写；盘符绝对路径可用。
- 项目根外的 UNC 路径、设备路径、盘符相对路径不用于本地资源读取或应用内链接打开。
- 长路径使用系统支持的路径接口；超出系统限制时显示读取失败。
- 外部程序可能锁定文件；随后保存失败时按「错误与提示」显示错误，不循环重试。
- 高 DPI 下渲染文字、图标与占位图保持清晰；缩放百分比不受系统 DPI 影响。
- 渲染态默认不访问网络；仅用户点击远程图片 `加载` 时访问该图片。系统代理、离线与网络错误不影响文档打开与渲染，远程加载失败按占位处理。

## 关键决策与依据

### 两态互斥与默认渲染

- **规则**：Markdown 面板只有源码与渲染两态，互斥显示，默认渲染；不提供渲染态直接编辑与同屏编辑/预览分栏。
- **原因**：AI CLI 文档以阅读为主，默认渲染减少打开成本；单一内容区避免混合布局的状态与比例持久化复杂度。
- **边界**：源码态保留完整编辑能力；渲染态只读；形态仅两个取值。

### 内存草稿作为唯一渲染源

- **规则**：两态共用面板内存草稿，形态切换不读盘；源码修改立即进入草稿，切回渲染立即渲染。
- **原因**：保证视图与草稿一致；切换无磁盘 I/O 与输入停止延迟。
- **边界**：外部修改经重载更新草稿；根外只读面板没有可保存草稿；文件已移出允许根的脱离草稿保留。

### 源码态纳入脏状态与关闭守卫

- **规则**：源码态修改产生面板级脏状态，两态共用；单面板关闭提供 `保存并关闭`；保存失败保留面板、草稿与脏状态。
- **原因**：未保存内容需要确认与保存出口；与编辑器、工作区的脏状态契约一致。
- **边界**：渲染态不产生修改；根外只读无脏状态；文件已移出允许根的脱离草稿可脏并进入关闭守卫；批量关闭按工作区批量保存契约。

### HTML 不渲染

- **规则**：`.html`、`.htm` 只在编辑器显示可编辑源码，内容区右上角提供系统打开悬浮按钮；应用内不渲染、不执行。
- **原因**：不引入文档执行环境；安全边界按不可信输入收敛。
- **边界**：Markdown 中的 HTML 本地链接同样走编辑器；按钮行为、只读与外部变更归编辑器契约。

### 安全 HTML 子集

- **规则**：仅解析白名单标签与属性；脚本、事件、表单、框架类标签、`object`、`embed` 与外部资源不解析；未知或危险标签按转义文本显示。
- **原因**：Markdown 来源不可信，需阻止脚本执行与隐式外部请求。
- **边界**：白名单含 `br`、`hr`、`sub`、`sup`、`kbd`、`a`、`img`、`picture`、`source`、`details`、`summary`；链接与图片仍受分派与资源策略约束。

### 链接白名单与根外只读

- **规则**：按协议与形态白名单分派链接；项目根外本地路径仅在用户显式点击后应用内只读打开并标注 `项目根外`。
- **原因**：统一文件打开链路；允许查看根外材料，同时不把根外路径纳入项目边界。
- **边界**：不加入文件树、不参与 Commit、不改变终端目录、不扩大资源读取边界；项目根外的 UNC 路径、设备路径与盘符相对路径不应用内打开。

### 本地资源限项目根

- **规则**：资源路径归一与真实路径校验后仅读取项目根内文件；SVG 清洗后按静态图片渲染；失败显示带原因的占位。
- **原因**：阻止路径穿越与符号链接逃逸；资源失败可见且不中断文档。
- **边界**：单资源 20MB、解码缓存 128MB；根外资源不读取；非图片 data 内容忽略。

### 远程图片手动单次加载

- **规则**：渲染态默认不发起网络请求；远程图片显示占位与 `加载`，用户点击后仅对该图发起一次请求。
- **原因**：把网络访问交给用户显式授权，保证隐私与离线可靠性。
- **边界**：仅 `http`、`https` 图片；单图 20MB、超时 10 秒、不携带 Cookie 或凭据；远程字体、样式与脚本永不加载。

### Mermaid 源码显示与渲染接口

- **规则**：`mermaid` 围栏首版不渲染，按普通代码块显示源码；不执行脚本、不加载外部资源；保留渲染接口与扩展点。
- **原因**：先保证安全与可用，后续按需接入静态图渲染。
- **边界**：不提供图内点击、跳转或交互；未来扩展不改变面板接口。

### 大文档分级

- **规则**：超过 5MB 或 100,000 行默认源码并提供 `仍要渲染`；超过 50MB 不渲染，源码态按编辑器大文件契约只读。
- **原因**：控制渲染成本与内存；先保证可打开与可编辑，再由用户决定是否渲染大文档。
- **边界**：渐进渲染可取消；1MB 内文档 1 秒内首屏可读；大文档仍保持前台可交互。

### 大纲可选、查找限渲染文本

- **规则**：标题大纲为默认关闭的可选开关，随项目布局持久化；渲染态查找只搜索可见文本，不提供正则、全词匹配与替换。
- **原因**：大纲不常驻占版面，按需展开；查找结果与用户所见一致，避免命中源码与元数据造成困惑。
- **边界**：源码态查找替换归编辑器；查找栏与缩放提示为瞬态，不持久化。

### 冲突差异摘要

- **规则**：脏冲突横幅提供 `查看差异`，以磁盘版本创建临时只读快照，在 Diff 面板以只读冲突快照模式与当前草稿比较并定位首个差异块。
- **原因**：为保留或重载提供依据；与编辑器外部变更契约保持一致。
- **边界**：查看差异不改变草稿、脏状态与横幅；快照生命周期与 Diff 行为归 Diff 契约。

### 草稿周期快照恢复

- **规则**：编辑期间周期性写本地草稿快照；下次启动提示恢复或丢弃；快照不是自动保存，默认开启且可在设置中心关闭。
- **原因**：崩溃时保护未保存草稿，同时避免隐式写回文档。
- **边界**：快照只含草稿文本与文件路径；正常保存、关闭或退出时清理；恢复后标脏且不自动写盘；快照不进入设置、布局或审计。

### 外部重命名跟随

- **规则**：监听器提供旧路径到新路径映射时，更新面板路径与标题，保留草稿、脏状态、形态、滚动与缩放；跨分派类别按编辑器契约转换面板类型。
- **原因**：避免重命名被误判为删除并重建，保护未保存内容与阅读状态。
- **边界**：无映射按删除处理；新路径已打开时按编辑器 `目标文件已打开` 处理。

### 键盘与输入边界

- **规则**：提供键盘可达、焦点环、减少动效、CJK 换行与输入法支持；不提供标题快速跳转快捷键、链接列表导航或专用模式。
- **原因**：覆盖操作可达与内容可读，保持交互面收敛。
- **边界**：标题大纲是普通可选功能；Mermaid 首版按源码显示。

### 内容操作边界

- **规则**：代码块、公式与图片正常渲染；不提供代码块复制按钮与语言标签控件、公式源码复制、图片放大或复制路径、渲染态应用右键菜单。
- **原因**：保持渲染态只读与交互面收敛，避免为单类内容引入额外操作通道。
- **边界**：平台默认文本选择与复制仍可用；公式错误与界面仍可显示或暴露公式源码。

### 阅读位置与缩放持久化

- **规则**：滚动位置按锚点优先恢复、比例回退、边界收敛；缩放与大纲开关按面板持久化；关闭后重开重置为默认。
- **原因**：保证长文档阅读连续性；关闭重开视为新面板，避免陈旧状态影响新阅读。
- **边界**：重渲染与重启恢复缩放不显示提示；锚点消失时按比例回退，再不存在时回顶部。

### 渲染调度

- **规则**：渲染在后台执行，过期结果丢弃；首次渲染超过 100ms 才显示 `渲染中...`，后续重渲染保留上一版内容。
- **原因**：避免阻塞前台交互，并减少快速渲染时的占位闪烁。
- **边界**：源码态编辑期间不渲染；切回渲染态立即渲染一次；旧结果不得覆盖新草稿。
