# Document 与文档生命周期

> 拥有应用级 Document、共享实时缓冲、保存与另存为、自动保存、外部修改和最后引用关闭守卫；编辑器、Markdown 与 Diff 只扩展各自视图能力。

## 身份与视图引用

- Document 是应用级可编辑聚合，使用稳定 `DocumentId`。路径是位置与授权输入，不是身份；项目也不是 Document 的所属边界。
- 同一文件身份在全应用最多一份实时 Document。多个项目中的 Editor、Markdown 或 Diff 视图可引用它，并共享文本、脏状态、撤销、编码与行尾、冲突及外部修改状态；不得创建隐式缓冲分支。
- 同一项目同一 Document 的每种普通视图类型最多一个面板；Editor 与 Markdown 可并存，Diff 与 GitShow 是独立视图，不参与普通面板去重。普通文档 `ViewKey` 包含 `ProjectId`、`DocumentId` 和视图类型。
- `PanelId` 只标识存活实例。显式切换 Editor／Markdown 视图保留 `PanelId` 与 Document；关闭后重开可分配新 `PanelId`，按 `ViewKey` 恢复持久视图状态。
- 冲突对比和大文件只读对比使用独立只读快照，不接管可编辑 Document；GitShow 使用固定版本的只读内容，也不创建可编辑缓冲。

## 打开与视图路由

- 扩展名只决定首次打开的默认视图：`.md`／`.markdown` 进入 Markdown，`.html`／`.htm` 进入 Editor 源码，其他文本进入 Editor；二进制或不支持类型显示错误，并可交系统默认程序。
- 已有 Panel 不因改名、外部重命名或另存为自动转换 Editor／Markdown；用户显式切换视图时才转换，且保留 Document 与 `PanelId`。
- 文件打开经 [PathPolicy](../path-policy.md) 判定；落点必须是已登记项目。没有项目时返回错误，不隐式创建项目；历史恢复的项目创建按导航的显式确认规则处理。
- 显式打开失败不留空 Panel，错误与重试由发起方呈现；恢复失败保留面板或授权占位，不创建重复视图。
- 重新打开已持久化的 Document 前必须对账路径与文件身份；能识别为另一文件时，不得仅因路径相同继承旧 Document、正文或视图状态。

## 保存与另存为

- 保存始终针对 Document 的当前完整文本，所有引用视图观察同一结果。单文件保存采用原子替换，不支持原子替换时失败，不降级为截断写。
- 写前重新解析真实目标并比较磁盘基线；外部版本变化时提供覆盖、另存为或取消。覆盖前再次校验，取消保留全部文本和脏状态。
- 保存成功后更新磁盘基线并清除共享脏状态；撤销回到基线同样清脏。保存失败保留所有视图、文本与脏状态。
- 批量保存按 Document 去重，可部分成功且不回滚；成功项保持干净，失败项保留脏状态并聚合错误。
- 另存为写入用户选定的新位置，原文件不变；成功后同一 Document 及全部视图重绑新位置，`DocumentId` 不变。
- 另存为目标已关联其他打开的 Document 时，在写前拒绝；不得提供“替换目标 Document”的隐式数据丢失路径。目标仅是未打开的磁盘文件时，须确认覆盖。
- 根外另存为授权仅属于当前 Document 和运行期；原子保存或替换不改变已打开 `DocumentId`。

## 自动保存

- 自动保存是应用级 Document 开关，默认关闭，覆盖 Editor、Markdown 源码和可编辑 Diff 工作区侧；只读快照与 GitShow 不参与。
- 开启后，Document 在停止修改 1 秒后保存；焦点离开该 Document 的所有编辑视图时立即保存；最后视图关闭和应用退出前也必须按统一守卫处理。
- 任一视图继续聚焦或编辑都属于该 Document 仍活跃，不得因另一个视图失焦重复保存。
- 外部冲突、位置冲突、失去写授权、只读或错误状态暂停自动保存；自动保存不得自动选择覆盖或另存为。
- 保存失败保留脏状态并聚合提示，不按计时周期反复弹错；下一次修改或显式保存可重试。

## 外部修改与位置变化

- 干净 Document 外部修改后自动重载，全部视图共享新文本并尽量保留各自阅读位置。
- 脏 Document 外部修改后进入共享冲突状态；重载、保留本地或查看差异由任一视图触发，结果对所有引用一致。冲突快照只读，不改变原 Document。
- 外部删除保留已加载文本；有写授权时可经显式确认重新创建，否则只能另存为或关闭。
- 外部改名只更新位置与显示，不重建 Panel、不转换视图、不清空撤销。无法确认位置或链接重定向导致授权变化时，进入位置冲突并暂停原地保存。
- 隐藏 Document 可暂停文件监听与重载，但重新可见时合并复核一次；保存前始终实时检测，不依赖缓存事件。

## 关闭与恢复

- 关闭非最后一个 Document 视图只关闭 Panel，不弹内容守卫、不清空 Document。
- 关闭最后视图才提供保存／丢弃／取消；批量关闭、项目移除和退出按 Document 去重。只要关闭集合外仍有引用视图，就不得丢弃缓冲。
- 批量保存任一失败即取消本次关闭并保留所有 Panel；已成功保存的 Document 保持干净。用户可修复后重试，或再次明确选择丢弃。
- 丢弃意图和关闭状态持久化成功后，才删除恢复材料并销毁最后引用；内容保存失败不阻止用户显式丢弃，但不得默认代为选择。
- 正常重启按持久布局与授权重新读取磁盘，不恢复未保存正文；异常启动按 [持久化与崩溃恢复](../settings-and-persistence.md) 先布局、后快照对账，不新建重复 Panel。
- 项目移除删除其 `ViewKey` 状态，但不得删除仍被其他项目引用的 Document 内容或恢复材料。

## 验收判据

- **Given** 同一 Document 在两个项目的 Editor 与 Diff 中打开，**When** 任一视图编辑，**Then** 文本、脏状态、撤销与冲突在其他引用中一致，不产生第二份实时缓冲。
- **Given** 同一项目已有普通文档面板，**When** 再次从其他入口打开，**Then** 聚焦既有视图；Diff 与 GitShow 仍可独立存在。
- **Given** 已打开文件改名跨 Markdown 与文本扩展名，**When** 事件被处理，**Then** Panel 与视图类型不自动转换，Document 内容保持。
- **Given** 另存为目标已关联另一打开 Document，**When** 用户提交，**Then** 写前拒绝且两个 Document 均不变；目标仅为未打开文件时要求覆盖确认。
- **Given** 自动保存开启且一个 Document 有多个编辑视图，**When** 只有一个视图失焦，**Then** 不触发失焦保存；全部编辑视图失焦后才保存。
- **Given** 批量关闭中部分 Document 保存成功、一个失败，**Then** 本次关闭取消、所有 Panel 保留，成功项干净且失败项仍为脏。
- **Given** 待关闭集合外仍有同一 Document 的视图，**When** 用户确认批量丢弃，**Then** 不丢弃该 Document 缓冲。
- **Given** 根重定位或外部改名，**When** 既有面板继续显示，**Then** 不按相对路径重建 Document、Panel 或视图类型。
