# Diff 面板

> 定义 Diff 面板如何对比一个文件的 HEAD 与工作区内容：视图模式、行标记与占位、键盘导航、交换与折叠、滚动同步、编辑保存与冲突、外部修改与重命名跟随、参数持久化；不拥有编辑器通用能力、GitShow、Commit 列表、项目布局与关闭守卫。

## 目标行为

### 定位与入口

- Diff 是面板类型封闭集中的一个类型。默认模式下每个 Diff 面板绑定一个 Git 仓库实际根内的工作区文件，比较该文件的 HEAD 版本与工作区版本；项目根内工作区侧可编辑，项目根外、仓库根内工作区侧只读。另有一个只读的冲突快照对比模式，见「冲突快照对比」。
- 默认模式比较范围固定为 HEAD 与工作区：不提供暂存区对比、任意提交对比、分支间对比，不执行任何 Git 写操作。完整 Git 工作流由终端承担；Commit 仅保留项目根内文件级回滚/删除；GitShow 只读。已删除条目由 GitShow 承载，见 [Commit 视图](../sidebar/commit.md) 与 [GitShow 面板](gitshow.md)。冲突快照模式不是 Git 版本对比，仅比较磁盘快照与当前缓冲。
- 默认模式入口只有两条：
  - Commit 视图双击状态为已修改、已重命名或冲突的条目。
  - 编辑器 gutter 单击新增、修改或删除行标记；删除标记定位到删除行所属差异块；gutter 的显示条件与命中行为归 [编辑器面板](editor.md)。
- 打开规则：
  - 面板标题为 `<文件名>(git diff)`；重命名条目使用重命名后的当前文件名。
  - 同一项目内同一工作区路径只存在一个 Diff 面板。再次从任一入口打开同一文件时，聚焦已有面板并定位到目标差异块，不新建面板。已有面板干净时，从 gutter 打开用当前编辑器缓冲替换工作区侧，从 Commit 打开重新读盘并刷新 HEAD；已有面板脏时不静默覆盖，只定位并提示，提供显式 `用编辑器内容替换` 或 `重新加载磁盘内容`，二次确认丢弃 Diff 修改。
  - 不同项目中的相同路径是不同面板，各自解析所在项目的 Git 仓库实际根。
  - Diff 面板与同文件的编辑器面板、GitShow 面板互不复用、互不替代。
  - 重命名条目：HEAD 侧读取旧路径在 HEAD 中的内容，工作区侧在项目根内读写当前路径；项目根外、仓库根内工作区侧只读。两栏列头分别显示 `HEAD · <旧路径>` 与 `工作区 · <当前路径>`。
  - 冲突条目：工作区侧显示含冲突标记的文本，面板标题或列头显示 `冲突` 徽标；行标记仍按 HEAD 与工作区文本计算，冲突标记作为普通文本行参与差异。冲突标记区间高亮并显示冲突计数，不自动合并或改写文本。
- 初始内容：
  - 从 Commit 打开时，工作区侧取磁盘内容。
  - 从编辑器 gutter 打开时，工作区侧取编辑器当前缓冲，包含未保存修改；缓冲与磁盘不同时面板以脏状态打开并提示 `已带入编辑器的未保存修改`。此后两个面板独立，通过保存、外部修改检测与保存冲突规则衔接。
- 默认模式面板参数为项目根、工作区路径与 HEAD 路径；冲突快照模式参数为源面板标识与快照代次，不持久化。除外部重命名跟随外，默认模式面板存活期间文件绑定固定；需要比较另一个文件时关闭当前面板并从对应入口新建，不把现有面板改绑到另一文件。
- 布局恢复只恢复默认模式面板：按参数重新解析 Git 仓库实际根并读取当前 HEAD，不冻结打开时的 HEAD 版本。项目根可为仓库子目录：HEAD 路径按仓库实际根解析；工作区写操作约束在项目根内，项目根外、仓库根内路径以只读对比模式打开。冲突快照面板不随布局恢复。
- 新面板落点遵循 [工作区壳](../workspace/shell.md) 的新面板落点契约。

### 冲突快照对比

- 入口仅来自编辑器或 Markdown 冲突横幅的 `查看差异`；不提供手动创建入口。
- 左侧为冲突检测时的磁盘版本只读快照，右侧为打开时当前缓冲的只读快照；两侧均不可编辑、不可保存、无脏状态，不执行 Git 写操作。
- 标题为 `<文件名>(冲突差异)`；同一项目内同一源面板的同一快照代次只保留一个面板；源面板关闭、冲突解决或再次点击 `查看差异` 时关闭旧面板并按新快照新建。
- 不读取 HEAD，不随 HEAD、磁盘或缓冲变化自动刷新；面板显示 `快照不会自动更新`；重新点击 `查看差异` 生成新快照。
- 支持并排/行内、行标记、滚动同步、自动换行、查找、`F6`/`F7` 导航、交换与单侧折叠；不支持保存、暂存、回滚或任何 Git 写操作。
- 面板与快照不持久化；关闭后重开或应用重启不恢复；关闭面板时清理快照。快照只存在运行期，关闭后不保留；不写项目文件、不扩大文件读写边界。
- 快照模式不参与编辑器与 Markdown 的保存冲突处理；解决冲突仍在源面板完成。
- 快照模式下，本文其余章节的 `HEAD` 侧对应磁盘快照，`工作区` 侧对应当前缓冲；只读、行标记、滚动同步与键盘导航规则同样适用。

### 视图模式

- 并排视图为默认模式：HEAD 与工作区在左右两栏并置，两栏共享同一行对坐标。
- 行内视图为单列统一视图：差异行只出现一次，删除行以虚拟行插入对应位置；行号槽同时显示旧行号与新行号——未变更行两侧行号相同，新增行只有新行号，删除行只有旧行号。
- 行内视图中，项目根内工作区侧内容可编辑，项目根外、仓库根内工作区侧只读；HEAD 侧始终只读。编辑与保存作用于完整工作区文档，与并排视图一致。
- 行内视图保留两侧焦点语义：`F6`/`Shift+F6` 在 HEAD 只读上下文与工作区上下文之间切换；HEAD 上下文只允许浏览、选择与复制，项目根内工作区上下文可编辑，项目根外工作区上下文只读。`F7`/`Shift+F7` 在统一视图中逐处导航差异。
- 行内视图隐藏交换、单侧折叠与列宽控件，分隔线不可拖动；这些控件对应的参数保留，切回并排后恢复生效。自动换行在行内视图同样生效；同步滚动在行内视图无作用对象，开关置灰。
- 视图模式由工具栏切换，作为面板参数持久化。切换视图模式不重建文档，不改变文本与脏状态；光标、选择与滚动位置尽量保留。

### 左右交换与单侧折叠

- 左右交换仅在并排视图可用，由工具栏触发：交换 HEAD 与工作区的显示顺序，不改变两侧角色、可编辑性与保存目标。交换后工作区侧仍可编辑，HEAD 侧仍只读。
- 单侧折叠仅在并排视图可用：可把 HEAD 或工作区侧折叠为窄条，另一侧扩展到剩余宽度。窄条显示所属侧名称与展开动作，点击窄条或对应工具栏控件即可展开。
- 同一时刻最多折叠一侧；折叠期间保留原有列宽比例，展开后按可用宽度夹取恢复。
- 折叠工作区侧时工作区不可编辑、不可保存；若折叠前存在未保存修改，脏状态保留并继续参与关闭守卫，展开后恢复编辑。
- 折叠状态下仍可左右交换：折叠条随所属侧换位，展开侧保持占满剩余宽度。
- 折叠侧与左右交换作为面板参数持久化；行内视图不应用交换与折叠，控件隐藏，参数保留并在切回并排时恢复。
- `F6`/`Shift+F6` 跳过折叠侧；`F7`/`Shift+F7` 仍逐处导航差异并滚动展开侧。

### 面板结构与列宽

- 面板主体默认左右各占 50%，中间为 1px 视觉分隔线；分隔线拖动命中区不小于 6px。每栏最小宽度 240px，双击分隔线恢复 50/50。
- 面板总宽不足以容纳两栏最小宽度时，两栏按可用宽度等分、各自横向滚动，拖动分隔线仍受最小宽度约束；面板变宽后恢复用户设定的比例。
- 每栏包含固定列头、行号槽、行标记槽与内容视口。列头显示来源与路径，并显示新增与删除行数统计；路径过长时截断并提供完整路径提示。
- 行标记槽始终保留固定宽度，不因当前有无标记而变化，避免正文横向跳动。
- 两栏各自横向滚动，长行不改变列宽分配；行号槽与行标记槽固定在视口左侧，不随正文横向滚出。
- 面板级提示条横跨两栏，用于差异不可用、HEAD 刷新等全局信息；栏级提示条位于对应列头下方，用于外部修改、大文件、只读降级等信息。提示条出现时内容区整体下移，不压缩或覆盖正文。
- 面板菜单提供 `折叠未变更区域` 开关，默认关闭。开启后折叠连续未变更行并显示展开入口；折叠不改变行号、差异计算、查找与保存内容。
- 加载中与初始错误态不显示双栏，只显示整面板状态区；部分内容可用时仍显示双栏，并在对应栏或面板级提示条说明缺失原因。

### 行标记与占位

两侧行标记语义一致，颜色由主题语义 token 提供，不硬编码：

| 差异类型 | HEAD 侧 | 工作区侧 |
|---|---|---|
| 新增行 | 等高空白占位 | 新增竖条 |
| 删除行 | 删除三角 | 等高空白占位，并在占位处显示删除三角 |
| 修改行 | 修改竖条 | 修改竖条 |

- 左栏标记按 HEAD 行号映射，右栏标记按工作区缓冲行号映射；标记始终对应真实文本行，不受任何提示影响。差异为空时两侧不显示任何标记与占位。
- 对齐以逻辑行对为单位：
  - 未变更行左右一一配对。
  - 新增行与左栏空白占位配对。
  - 删除行与右栏空白占位配对。
  - 修改行按行一一配对；行数不等时，多出的行与另一侧空白占位配对。
- 每一行对的高度取左右两侧该行实际渲染高度的较大值，空白占位补足到该高度，使后续行在两侧保持同一纵向位置。
- 字号、自动换行、列宽变化后立即重新布局并重算行对高度，不存在延迟到下一次保存才对齐的窗口。
- 单个差异块由连续的新增、删除或修改行组成；多个差异块落在同一行对位置时，占位只补足高度，不累加额外空行。
- 空白占位无行号、无文本、不可选择、不可复制、不参与查找、不响应鼠标命中与右键菜单、不参与编辑与保存，不属于文档内容。
- 行内视图不显示占位，以虚拟删除行与双行号表达对齐，不插入可编辑的空白行。

### 差异计算与实时重算

- 差异以行级差异块计算，比较对象是当前 HEAD 内容与工作区当前缓冲；工作区未保存的编辑同样参与计算，不需要先保存。
- 工作区侧编辑后，在停止输入后按配置间隔重算。间隔范围 100–2000ms，默认 300ms，可在 [设置中心](settings.md) 外观页的编辑器/Diff 行为节配置。
- 保存成功、外部重载成功、HEAD 刷新成功后立即重算，不受重算间隔影响。
- 差异计算不阻塞正文浏览与继续输入。计算期间保留上一份行标记与占位，并显示不打断操作的 `差异更新中` 状态。
- 差异计算失败时正文继续可用，保留上一份结果并显示 `差异可能过时`；没有上一份结果时不显示行标记与占位，仅显示正文。下一次成功计算清除该状态并替换标记与占位。
- 先发后至的过期结果不得覆盖新结果；以最近一次稳定缓冲的计算为准。
- 行尾符差异（CRLF 与 LF）不产生行标记；文件末尾换行符的有无不作为独立差异块。文本按 UTF-8 解码，无法解码的字节以替换字符显示；含 NUL 字节的文件按二进制处理。
- 冲突快照模式使用打开时生成的两侧快照，不参与实时重算、HEAD 刷新或外部修改检测；重新点击 `查看差异` 生成新快照。
- 面板菜单提供 `忽略行尾空白` 与 `忽略全部空白` 两个开关，默认关闭，仅影响差异判定，不改写两栏文本，也不改变保存内容。
- 列头的新增与删除行数统计随差异重算更新。页脚显示差异导航计数：`第 N / M 处差异`；无差异时显示 `无差异`。

### 滚动同步

- 默认开启垂直滚动同步：任一侧通过滚轮、滚动条、键盘或触控板纵向滚动时，另一侧跟随到相同逻辑行对位置。
- 同步以逻辑行对为基准，不以原始像素偏移为基准；配合等高行对，两侧对应内容在视觉上保持同一水平线。
- 仅同步垂直方向，两栏横向滚动互相独立。同步过程消除回环，不出现两侧互相推动的抖动。
- 面板菜单提供 `同步滚动` 开关；开关状态作为面板参数持久化。
- 只读大文件视图只要参与同一差异行对模型，同样参与同步。
- 差异不可用、某一侧无内容、二进制或读取失败时，同步停用，两侧各自滚动。
- 面板重新加载、文件参数变化、视图模式切换或布局恢复后重新建立同步关系。

### 编辑、保存与冲突

- 工作区侧可编辑：支持撤销、重做、查找、`Tab` 缩进、输入法输入与保存。HEAD 侧只读，可聚焦、选择、复制、查找，不能编辑、不能保存。
- 脏状态定义为工作区当前内容与最近一次加载、保存或显式重载得到的磁盘基线不一致。撤销回到基线内容时脏状态自动清除。
- 脏状态通过面板标题的未保存标记呈现，并纳入 [工作区壳](../workspace/shell.md) 的统一关闭守卫：面板关闭、`Ctrl+W`、中键关闭、批量关闭、项目移除与窗口关闭均遵循统一确认契约。
- 焦点位于任一侧时，`Ctrl+S` 均保存工作区侧当前完整缓冲；HEAD 侧只读，不提供独立保存对象。
- 保存成功时磁盘内容整体等于工作区完整缓冲；保存失败时磁盘保持原内容，不出现部分写入的中间状态。
- 保存成功后：清除脏状态；立即重算差异并刷新行标记、占位与对齐；通知文件浏览器与 Commit 视图刷新；不弹成功提示；不移动光标、不重置滚动位置。
- 保存失败时显示 `保存失败：<原因>`，保留脏状态与工作区内容，不刷新差异，不通知文件浏览器与 Commit 视图刷新。常见原因包括权限不足、文件只读、目标被占用、磁盘空间不足与父目录不存在。
- 保存冲突：
  - 保存前比较磁盘基线与当前磁盘内容；未变化则直接保存。
  - 磁盘已变化时显示 `文件已被外部修改`，提供 `覆盖保存`、`重新加载`、`取消`；默认焦点在 `取消`；用户选择前不写盘。
  - `覆盖保存` 以工作区内容为准写入并更新基线；`重新加载` 丢弃本地修改并载入磁盘内容；`取消` 保留本地修改与脏状态。
  - 外部程序在保存过程中同时写入时，以本面板本次写入完成后的磁盘状态为基线；随后的变化按外部修改规则处理，不产生重复冲突提示。
- 工作区侧只读降级（含项目根外只读、冲突快照模式）或处于单侧折叠时，保存命令不可用，`Ctrl+S` 不执行任何操作，也不显示错误提示。
- 保存只写工作区完整文档；不提供另存为、部分保存、差异块级保存或 Git 暂存。

### HEAD 刷新

- HEAD 侧内容随当前 HEAD 变化自动刷新，触发条件：
  - 仓库元数据（HEAD、当前分支引用、索引、打包引用等）变化后 300ms 内去抖刷新。
  - 面板激活时，若距上次刷新超过 10 秒则刷新一次。
  - 每 10 秒一次的周期复核作为兜底，用于变化通知可能缺失或网络驱动器不可靠的情况。
- 刷新读取面板 HEAD 路径对应的当前 HEAD 内容；重命名条目的 HEAD 侧始终读取打开时捕获的原路径，工作区侧的路径随重命名更新。
- 刷新成功后比对内容：未变化则不更新视图、不移动光标、不改变选择；变化则替换 HEAD 侧内容，并尽量按顶部可见行锚定滚动位置。
- 刷新同时立即重算差异，更新行标记、占位与对齐；工作区内容、脏状态、光标与滚动位置不受影响。
- HEAD 中已不存在该路径时，HEAD 侧进入 `该文件已不在 HEAD 中` 空态，工作区全部行按新增行显示，不保留旧 HEAD 内容。该文件之后重新出现在 HEAD 中时，HEAD 侧自动恢复。
- 仓库不可用或 HEAD 读取失败时，HEAD 侧显示 `无法读取 HEAD：<原因>` 与 `重试`；工作区侧保持可编辑，差异标记暂停更新并显示 `差异可能过时`。
- HEAD 刷新不显示全屏加载态；超过 500ms 未完成时在面板级提示条显示 `正在刷新 HEAD…`，完成后自动消失。
- HEAD 刷新不撤销、不覆盖、不询问工作区侧未保存修改。

### 工作区外部修改

外部修改经以下通道检测：

- 工作区文件变化：匹配当前工作区路径的修改、创建、删除或重命名，去抖 200ms。
- 面板激活复核：面板重新成为激活面板时读取磁盘内容并比对。
- 周期复核：每 10 秒一次，比较文件大小、修改时间与内容。

处理规则：

- 本面板自身保存产生的变化按路径与本次写入内容忽略一次，不触发外部修改流程。仅访问或读取元数据不改变文件内容，不触发重载。
- 磁盘内容与基线一致：不做任何视觉变化。
- 磁盘内容变化且工作区侧干净：静默重载工作区内容，更新磁盘基线，立即重算差异；尽量按顶部可见行锚定滚动位置；清除外部修改提示。
- 磁盘内容变化且工作区侧有未保存修改：显示栏级提示条 `文件已被外部修改`，提供 `重新加载` 与 `保留本地`。
  - `重新加载`：丢弃本地修改，载入磁盘内容，清除脏状态与提示，重算差异。
  - `保留本地`：保留本地修改，提示条收起；同一份磁盘内容不再重复提示，磁盘再次变化时重新出现。
- 文件被外部删除且工作区侧干净：工作区侧显示 `文件已从磁盘删除` 空态，编辑与保存暂时不可用；提供 `重新创建`（用最近基线内容写回磁盘）与 `关闭面板`。
- 文件被外部删除且工作区侧有未保存修改：提供 `重新创建`（保存当前缓冲并重建文件）、`丢弃并关闭` 与 `取消`。
- 删除态下检测到文件重新出现时，即使内容与基线一致也退出删除态并恢复显示。
- 读取失败：显示 `无法读取工作区文件：<原因>` 与 `重试`；不替换当前内容，不丢弃脏状态。
- 外部修改重载总是整份替换，不做合并，不做三方冲突解决。
- 只读大文件视图检测到变化时静默重载，按滚动比例保持浏览位置；读取部分失败时在栏级提示条显示 `部分内容读取失败` 并提供重试。
- 外部修改提示属于非模态反馈，不阻塞继续编辑、切换面板或切换项目；提示状态在面板存活期间保留，关闭后重开清除。

### 外部重命名跟随

- 工作区文件在同一 Git 仓库实际根内被重命名或移动时，面板跟随新路径：
  - 更新面板的工作区路径参数并随项目布局持久化。
  - HEAD 侧保留打开时捕获的原路径，不随重命名改变。
  - 新路径在项目根内时保持可编辑；新路径在项目根外、仓库根内时切换为只读对比；未保存缓冲、脏状态、光标、选择与滚动位置保留，立即重算差异。
  - 面板标题使用当前文件名，并附重命名来源标注（原文件名）；列头更新为 `HEAD · <原路径>` 与 `工作区 · <新路径>`。
- 重命名后 HEAD 侧仍按原路径刷新；原路径在 HEAD 中不存在时进入 HEAD 空态。
- 文件移出 Git 仓库实际根时，面板显示 `文件已移出仓库`，工作区侧不可读写；提供 `关闭面板` 与 `重新打开`。`重新打开` 按当前文件位置重新解析：文件已回到仓库根内时重新加载，否则显示无法打开的具体原因并保留关闭入口。
- 移出态下工作区侧不可编辑、不可保存；若存在未保存修改，关闭确认不提供 `保存并关闭`，只提供放弃与取消。
- 项目根外、仓库根内的只读对比同样不可保存；若存在未保存修改，关闭确认不提供 `保存并关闭`，只提供放弃与取消；移回项目根内后恢复可编辑与保存。
- 重命名变化无法关联到新路径（目标不存在、变化通知缺失或目标在根外）时，按工作区文件删除处理，进入删除态并提供 `重新创建` 与 `关闭面板`。
- 新路径已被另一 Diff 面板占用时，当前面板不跟随，按工作区文件删除态处理并提示路径已占用；同一项目同一工作区路径只保留一个 Diff 面板。
- 文件名大小写变化按 Windows 路径规则视为同一路径，仅更新显示与路径参数，不重建面板。

### 大文件与二进制

大小按该侧内容的磁盘字节数判定：HEAD 侧取 Git 对象的字节大小，工作区侧取文件字节大小；两侧独立判定。

| 条件 | 行为 |
|---|---|
| 不大于 1 MiB | 正常编辑器视图 |
| 大于 1 MiB 且不大于 10 MiB | 正常编辑器视图；栏级提示条显示 `大文件（约 N.N MB），编辑可能影响性能`；工作区侧仍可编辑与保存 |
| 大于 10 MiB | 该侧改为虚拟化只读视图；栏级提示条显示 `只读浏览（约 N.N MB），可编辑上限 10 MiB` |

- 1 MiB = 1,048,576 字节，10 MiB = 10,485,760 字节；界面中的 N.N MB 按字节数除以 1,048,576 保留一位小数显示。
- Diff 使用自身的按字节分级，不引用编辑器的 10MB/50MB 分级。
- 大文件提示条不属于文档内容：不插入注释前缀，不计入行号，不参与保存，不参与 HEAD 内容比对，不随保存写回磁盘。
- 只读虚拟化视图按需加载内容，内存占用不随文件大小线性增长；支持纵向滚动、选择、复制、查找、字号调整与自动换行；不提供编辑、保存与脏状态。
- 只读视图参与行对对齐与滚动同步，前提是差异计算完成。差异计算超过 2 秒或不可用时，先显示正文，栏级提示 `差异计算超时，未显示行标记`；不显示行标记与占位，两栏独立滚动。计算完成后自动补上标记、占位与同步。
- 任一侧超过 10 MiB 时该侧不可编辑；工作区侧超过 10 MiB 时不存在未保存状态，关闭面板不触发未保存确认。
- 二进制判定：文件前 8 KiB 内含 NUL 字节即视为二进制。任一栏判定为二进制时，不显示行标记与占位，工作区侧不可编辑、不可保存；该侧显示 `二进制文件，无法进行文本比较` 与 `用默认程序打开`，另一侧仍可浏览。
- `用默认程序打开` 只用于外部查看：工作区侧打开当前文件，HEAD 侧以 HEAD 内容的外部只读查看打开；不作为 Diff 的编辑或保存通道。
- 超长单行文件不截断；横向滚动或自动换行均可使用。查找、复制与选择在大文件视图内仍可用。
- 文件大小无法取得时，按已读取内容的字节数估算并标注“约”，不因大小未知而拒绝打开。
- 只读降级不改变文件参数、列宽、字号、同步与换行设置，另一侧不受影响。

### 焦点与键盘导航

- 显式打开（Commit 双击、gutter 单击）或面板激活时，焦点进入工作区可编辑侧；工作区侧只读降级时焦点进入 HEAD 侧只读视图；两侧都不可聚焦时焦点停在面板容器。
- 从编辑器 gutter 打开时，工作区可编辑则把光标放在被点击差异块对应的行；从 Commit 打开时放在第一个差异块的第一行。
- 点击某一栏或行内视图的某一上下文使其获得焦点，并显示可见焦点环。
- 面板聚焦时，`F6`/`Shift+F6` 在左右栏之间切换焦点；行内视图在 HEAD 只读上下文与工作区可编辑上下文之间切换。焦点切换保留各侧上次的光标、选择与滚动位置。
- 单侧折叠时，`F6`/`Shift+F6` 跳过折叠侧，只在可聚焦的展开侧内切换；没有可切换目标时保持当前焦点。该跳过规则只适用于并排视图，行内视图不应用折叠。
- 面板聚焦时，`F7`/`Shift+F7` 跳到下一处/上一处差异，并同步滚动两侧；单侧折叠时仍导航并滚动展开侧；行内视图滚动统一视图。差异首尾循环。`F7` 定位不受 `同步滚动` 开关影响，两侧都滚动到目标差异块。
- 当前差异块高亮显示，页脚更新为 `第 N / M 处差异`；无差异时页脚显示 `无差异`，`F7` 不移动。
- 布局恢复不主动抢焦点；只读对照侧不因布局恢复自动聚焦，仅在显式打开、`F6` 或鼠标点击时获得焦点。切换项目时的焦点策略遵循工作区统一契约。
- 字号为全局编辑器设置：范围 8–32px，默认 14px；在任一侧按住 `Ctrl` 滚动滚轮按方向逐级调整 1px，越界不再变化，未按 `Ctrl` 的滚轮保持正常滚动。字号变化作用于两栏与行内视图，并持久化到应用设置。

### 面板参数与状态持久化

面板参数随项目布局持久化，由 [设置与持久化](../settings-and-persistence.md) 的布局保存契约统一落盘：

| 参数 | 默认值 | 同面板组切面板 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|---|
| 视图模式 | 并排 | 保留 | 保留 | 恢复并排 | 保留 |
| 自动换行 | 关 | 保留 | 保留 | 恢复关 | 保留 |
| 同步滚动 | 开 | 保留 | 保留 | 恢复开 | 保留 |
| 列宽比例 | 50/50 | 保留 | 保留 | 恢复 50/50 | 保留 |
| 折叠侧 | 无 | 保留 | 保留 | 恢复无折叠 | 保留 |
| 左右交换 | 关 | 保留 | 保留 | 恢复不交换 | 保留 |
| 文件参数 | 由入口给定 | 保留 | 保留 | 重新给定 | 按布局恢复 |

- 布局恢复时，列宽比例按可用宽度夹取，任一栏不小于 240px；可用宽度不足 480px 时两栏等分并各自横向滚动，面板变宽后按存储比例恢复并继续受 240px 约束。
- 关闭面板后重新打开视为新建面板，恢复上表默认值；项目切换只改变可见性，重启按项目布局恢复面板参数。
- 面板实例内的临时状态在面板存活期间保留，不随布局持久化：光标、选择、滚动位置、当前高亮差异块、外部修改与 HEAD 刷新提示、删除态、移出态、`忽略行尾空白`、`忽略全部空白`、`折叠未变更区域`。关闭后重开或应用重启后这些状态重置。
- 全局字号属于应用设置，不属于面板参数，跨面板、项目与重启保留。

## 交互规则

### 打开与关闭

- Commit 双击：打开或聚焦面板，定位到该条目对应的差异块；已有同一文件面板时聚焦并定位。
- 编辑器 gutter 单击：打开或聚焦面板，定位到被点击的差异块，并把工作区光标放到对应行。
- 面板关闭入口：面板关闭按钮、`Ctrl+W`、中键关闭、批量关闭、项目移除、窗口关闭。脏状态按统一关闭守卫处理。
- 面板不提供“在编辑器中打开”“在 GitShow 中打开”等替代出口；同文件其他面板由各自入口独立打开。
- 拖入文件、拖出面板、跨项目移动面板均不支持。

### 工具栏与菜单

- 工具栏提供视图模式切换（并排/行内）、左右交换与单侧折叠。行内视图隐藏交换、折叠与列宽控件；单侧折叠时对应控件变为展开动作。
- 面板菜单提供 `重新加载`、`同步滚动`、`自动换行`、`忽略行尾空白`、`忽略全部空白`、`折叠未变更区域` 与 `复制路径`。
- `重新加载` 在工作区侧有未保存修改时先走脏状态确认；确认后重新读取 HEAD 与工作区并重算差异。
- `复制路径` 复制当前工作区路径；重命名跟随后复制新路径。
- HEAD 侧右键菜单提供选择、复制、查找与 `复制路径`；工作区侧右键菜单沿用编辑器通用编辑菜单。
- 面板标题右键菜单沿用工作区统一菜单，至少包含关闭、关闭其他、关闭全部与复制路径。
- 面板级菜单中的 `同步滚动` 在行内视图置灰；`折叠未变更区域` 与空白忽略开关始终可用。

### 鼠标与拖拽

- 单击列头或正文区域使该栏获得焦点；行内视图单击 HEAD 上下文或工作区上下文获得对应焦点。
- 拖动中间分隔线调整列宽，拖动到任一侧最小宽度后停止；双击分隔线恢复 50/50。行内视图不提供分隔线拖动。
- 单击行标记或差异块：定位并高亮该差异块，两侧滚动到该块；再次单击取消高亮。该操作不改变文本内容与光标位置，除非用户随后在工作区侧定位到行。
- 单击折叠条展开对应侧；折叠条不获得文本焦点，`F6` 不进入折叠侧。
- 空白占位不响应鼠标命中、选择与右键菜单。

### 键盘

| 命令 | 默认键 | 上下文 | 行为 |
|---|---|---|---|
| 切换栏焦点 | `F6` / `Shift+F6` | 面板聚焦 | 左右栏切换；行内视图切换 HEAD 与工作区上下文；跳过折叠侧 |
| 下一处/上一处差异 | `F7` / `Shift+F7` | 面板聚焦 | 逐处导航并同步滚动；首尾循环 |
| 保存工作区内容 | `Ctrl+S` | 面板聚焦 | 保存工作区完整缓冲；工作区只读或折叠时不可用 |
| 切换自动换行 | `Alt+Z` | 面板聚焦 | 两栏或行内视图同时切换 |
| 查找 | `Ctrl+F` | 聚焦侧 | 在聚焦侧查找；行内视图在统一视图中查找 |
| 调整字号 | `Ctrl+滚轮` | 面板聚焦 | 全局字号逐级增减 1px |
| 关闭面板 | `Ctrl+W` | 全局 | 遵循关闭守卫 |

- 工作区侧 `Tab` 插入缩进，`Shift+Tab` 减少缩进；HEAD 侧只读内容不接受文本输入，`Tab` 按全局焦点导航离开。
- 查找框打开时，`Enter` 与 `Shift+Enter` 在匹配项之间移动，`Esc` 关闭查找框并把焦点还给原侧。
- 输入法组合输入期间不触发导航命令；组合结束后按普通编辑处理。
- 面板内命令使用面板级优先级；与全局快捷键冲突时以工作区快捷键契约裁决。设置中心快捷键页列出的面板命令可查看并重绑；`F6`/`F7` 等面板内固定键不承诺重绑。

### 焦点迁移

- 面板打开、面板激活、从 Commit 或 gutter 定位进入时，按焦点落点规则选择工作区侧或 HEAD 侧。
- 在栏内点击、选择、查找不改变另一栏焦点；`F6` 切换后目标栏保留各自上次的光标与滚动位置。
- 面板被隐藏（切换项目或同面板组内切换面板）时不产生焦点迁移；切回时遵循工作区激活契约。
- 面板关闭时焦点归属由工作区关闭契约决定。

### 反馈与状态迁移

- 加载：整面板状态区显示 `加载中…`；超过 500ms 仍显示同一文案，不叠加进度条。
- 保存成功：无提示，只清除脏标记并刷新差异。
- 保存失败：栏级提示条 `保存失败：<原因>`，可重试。
- 差异失败：面板级提示条 `差异可能过时`；内容仍可读可编辑。
- HEAD 刷新：成功静默；失败在 HEAD 侧或面板级提示 `无法读取 HEAD：<原因>` 并提供 `重试`。
- 外部修改：栏级提示条，提供明确动作，不使用阻塞对话框；保存冲突确认除外，它在保存动作内阻塞等待用户选择。
- 大文件：栏级提示条，不插入文档前缀。
- 二进制：该侧内容区居中提示，并提供 `用默认程序打开`；不提供文本编辑。
- 所有提示条均不遮挡正文，不使用仅靠颜色传达状态；颜色遵循主题语义 token。

| 当前状态 | 触发 | 目标状态 | 用户可感知结果 |
|---|---|---|---|
| 加载中 | 两侧读取成功 | 就绪 | 显示双栏、内容与差异 |
| 加载中 | 一侧可用、一侧失败 | 部分就绪 | 显示双栏，失败侧显示错误占位，另一侧可用 |
| 加载中 | 两侧都失败 | 错误 | 显示具体错误与可用的重试动作 |
| 就绪 | 工作区编辑 | 脏 | 面板出现未保存标记，差异去抖更新 |
| 脏 | 保存成功 | 就绪 | 脏标记清除，差异立即刷新 |
| 脏 | 保存失败 | 脏 | 错误提示，内容与脏状态保留 |
| 脏 | 外部修改且选择保留本地 | 脏 | 本地内容保留，提示收起 |
| 脏 | 外部修改且选择重新加载 | 就绪 | 本地内容丢弃，载入磁盘内容 |
| 脏 | 保存冲突且覆盖或重载成功 | 就绪 | 冲突解除，基线更新 |
| 就绪 | 外部修改 | 就绪 | 静默重载并刷新差异 |
| 就绪 | HEAD 变化 | 就绪 | HEAD 侧更新并刷新差异 |
| 就绪 | HEAD 路径消失 | 部分就绪 | HEAD 空态，工作区全部行按新增显示 |
| 就绪 | 工作区文件被外部删除 | 删除态 | 显示删除提示与重新创建、关闭动作 |
| 就绪 | 工作区文件移出 Git 仓库 | 移出态 | 显示 `文件已移出仓库` 与关闭、重新打开动作 |
| 任意 | 重命名跟随成功 | 状态不变、路径更新 | 标题与列头更新，内容与脏状态保留 |
| 任意 | 某侧超过 10 MiB | 只读降级 | 该侧变为虚拟化只读视图 |
| 任意 | 关闭且脏 | 等待确认 | 统一未保存确认，提供取消、保存并关闭与丢弃并关闭 |
| 等待确认 | 保存并关闭且保存成功 | 关闭 | 磁盘等于工作区缓冲，面板销毁 |
| 等待确认 | 保存并关闭且保存失败 | 脏 | 面板保留，显示保存失败，内容与脏状态保留 |
| 任意 | 确认丢弃 | 关闭 | 面板销毁，缓冲丢弃 |

## 边界与错误

### 空态与无差异

- 两侧内容相同：两栏照常显示正文，无行标记、无占位；列头或面板级轻量显示 `与 HEAD 无差异`，页脚显示 `无差异`，不弹出提示，不使用阻塞性空态。
- 文件为空且 HEAD 中为空：两栏显示空文档，行号槽为空。
- 工作区为空但 HEAD 有内容：HEAD 侧全部行按删除行显示，工作区侧对应位置为空白占位。
- HEAD 路径不存在但工作区文件存在：不进入整面板错误，HEAD 侧显示 `该文件已不在 HEAD 中`，工作区全部行按新增行显示；工作区侧可编辑、可保存。
- 两侧都为空：显示双栏空文档，不显示行标记。
- 面板没有独立于文件内容的空白状态。

### 读取与差异错误

| 条件 | 行为 |
|---|---|
| 初始加载 | 整面板 `加载中…`，不显示双栏、标记或提示条 |
| 两侧读取成功 | 显示双栏；差异异步计算，期间显示 `差异更新中` |
| HEAD 读取失败 | HEAD 侧 `无法读取 HEAD：<原因>` 与 `重试`；工作区侧仍可用 |
| 工作区读取失败 | 工作区侧 `无法读取工作区文件：<原因>` 与 `重试`；HEAD 侧仍可浏览 |
| 两侧都读取失败 | 整面板错误态，列出两侧原因，提供 `重试` |
| 差异计算失败 | 正文可见，面板级 `差异可能过时`；保留上一份标记与占位 |
| 差异计算超时 | 正文可见，栏级 `差异计算超时，未显示行标记`；两栏独立滚动，完成后自动补标记 |
| 保存失败 | 栏级 `保存失败：<原因>`；脏状态保留 |
| 只读大文件部分读取失败 | 栏级 `部分内容读取失败` 与 `重试`；已读取部分可浏览 |
| 面板参数无效 | 整面板 `无法打开文件：<原因>`；不读取项目根之外的路径 |
| 权限不足 | 按具体读取或保存动作显示原因，不合并为统一文案 |
| 文件被独占锁定 | 读取失败显示原因；保存失败显示 `保存失败：文件被占用`，磁盘内容不变 |

- 所有可恢复错误提供 `重试`；不可恢复错误说明原因并保留关闭入口。
- 重试不改变工作区未保存内容；重试 HEAD 只刷新 HEAD 侧，重试工作区在工作区脏时先走外部修改确认。
- 加载中允许切换面板、切换项目或关闭；关闭不需要确认。

### 保存与冲突

- 项目根外、仓库根内的 Diff 以只读对比模式打开：工作区侧不可编辑、不可保存、无脏状态；标题或列头标注 `项目根外 · 只读`；查看、查找、键盘导航、交换/折叠/行内切换仍可用。
- 保存前检测基线；磁盘已变化时必须在 `覆盖保存`、`重新加载`、`取消` 中选择，未选择前不写盘。
- `覆盖保存` 以工作区缓冲写入完整文档并更新基线；`重新加载` 丢弃本地修改，载入磁盘内容并清除脏状态；`取消` 保留本地修改与脏状态，随后可继续编辑或再次保存。
- 保存失败时磁盘保持原内容，工作区内容与脏状态保留，差异不刷新，文件浏览器与 Commit 视图不刷新。
- 工作区侧只读（含项目根外只读、冲突快照模式）、折叠或降级时，`Ctrl+S` 不执行保存，不显示错误。
- 保存成功后不弹提示，不清空选择，不重置滚动，不重建视图。
- 多次连续保存每次都生成新的磁盘基线并重算差异，不累积提示。

### 文件与路径

- 工作区路径按 Git 仓库实际根解析；项目根内可读写，项目根外、仓库根内只读对比，仓库根外拒绝。HEAD 路径按 Git 仓库实际根解析。符号链接与目录联接只允许指向仓库根内部，指向外部时按越界错误处理。
- Windows 路径大小写不敏感；同一文件的不同大小写写法视为同一路径，复用同一面板。
- 文件在面板打开期间变为目录或不可读：对应侧进入读取错误态。
- 网络驱动器或变化通知不可靠的位置：变化可能未被察觉，依靠面板激活复核与周期复核兜底；不保证实时响应，但保证最终一致。
- 超长路径按平台能力处理；无法打开时显示具体原因。
- 重命名跟随只发生在仓库实际根内；项目根外新路径保持只读；移出仓库根按移出仓库处理，不把面板转移到另一项目。

### 并发

- 工作区编辑与差异计算并发：以最近一次稳定缓冲计算，过期结果不得覆盖新结果。
- 保存与外部修改并发：保存前检查基线；保存后重新读取磁盘内容并更新基线；保存过程中检测到外部变化时，保存完成后按新的磁盘状态提示，不重复冲突。
- HEAD 刷新与保存并发：两者互不阻塞；HEAD 刷新只更新 HEAD 侧，保存只更新工作区侧与磁盘基线。
- 外部修改与重新加载并发：以用户最后一次明确选择为准；后续新变化重新提示。
- 反复保存与反复外部修改不累积提示：同一份磁盘内容最多提示一次，新的磁盘变化重新提示。
- 项目移除或窗口关闭与保存并发：遵循工作区生命周期契约；未完成的保存必须先完成或明确失败，再销毁面板。
- 不提供自动合并、三方合并或差异块级冲突解决。

### 大文件与性能

- 阈值按磁盘字节判定，不按字符数；多字节字符不会导致提前降级。
- 大文件差异计算可取消或忽略过期结果；界面保持可滚动、可切换面板。
- 只读视图按需加载，不一次性把整个文件读入内存；滚动到未加载区间时显示短暂的 `正在加载…` 占位。
- 超长单行不截断、不静默省略；横向滚动或自动换行可用。
- 大文件视图中的查找在已加载区间内进行，并向未加载区间继续，查找不阻塞滚动。
- 差异计算或查找超过 2 秒时显示进行中状态，不冻结界面；用户可继续滚动或关闭面板。
- 两侧都为大文件只读时，差异仍按规则计算；计算超时或不可用时降级为无标记模式，两栏仍可独立浏览。

### 生命周期与恢复

- 同面板组内切换面板、切换项目：面板不销毁、不重新读盘、不丢失脏状态、光标、选择、滚动、视图模式、换行、同步、列宽、折叠与交换状态。
- 关闭后重开：重新读取 HEAD 与工作区，面板参数恢复默认，脏状态、光标、选择、滚动、临时提示与删除/移出态全部重置。
- 应用重启：按项目布局恢复面板参数并重新加载；布局恢复不抢焦点，只读对照侧不自动聚焦；不恢复未保存修改、光标、选择、滚动与临时提示。
- 布局恢复时原工作区文件已删除：工作区侧进入删除态，HEAD 侧仍尝试读取 HEAD；面板保留，不自动关闭。
- 布局恢复时原工作区路径不存在：工作区侧进入删除态；若恢复期间检测到该文件已移出 Git 仓库，则显示 `文件已移出仓库` 与关闭、重新打开动作；项目根外、仓库内路径按只读对比打开。
- 布局恢复时原 HEAD 路径已不存在：HEAD 侧进入空态，工作区侧正常加载。
- 项目被移除：面板随项目布局销毁；脏状态按统一守卫处理，确认后全部丢弃。
- 窗口关闭：所有项目的脏 Diff 面板参与一次聚合确认；确认后按生命周期清理，不留下后台读取或后台监视任务。

### 键盘与焦点

- 行标记提供文本等价：`新增行`、`修改行`、`删除行`、`空白占位`；页脚差异计数可读。
- 仅用键盘可完成打开、切栏、差异导航、查找、编辑、保存、切换换行、调整字号与关闭。
- 焦点环清晰可见；自动换行、字号与列宽变化保持光标、选择与滚动锚点。
- 支持输入法与中日韩字符；占位对齐按实际字形高度计算。
- 动画与提示过渡遵循减少动效设置；关闭动效不影响功能。

### 平台

- 仅 Windows 原生、单窗口、暗色模式；不描述多窗口、多实例、跨平台或触摸手势。
- 文件路径、大小写、符号链接、文件锁与默认程序行为遵循 Windows 平台能力。
- 系统默认程序只用于二进制等外部查看场景，不作为 Diff 的编辑或保存通道。
- 不依赖外部 Git 命令行输出的本地化文案；错误信息由应用呈现，不直接拼接不稳定的外部文本。

## 验收判据

### 视图与结构

- Given 打开 Diff 面板，Then 默认并排，两栏各占 50%，中间显示 1px 分隔线；拖动分隔线可调整比例，每栏不小于 240px，双击恢复 50/50。
- Given 已打开同一文件的 Diff 面板，When 再次从 Commit 或 gutter 打开同一文件，Then 不新增面板，聚焦已有面板并定位到目标差异块。
- Given 两个项目包含相同相对路径的文件，When 分别打开 Diff，Then 产生两个独立面板，互不复用。
- Given 编辑器缓冲存在未保存修改，When 从 gutter 打开 Diff，Then 工作区侧包含这些修改，面板以脏状态打开并提示 `已带入编辑器的未保存修改`。
- Given 冲突条目，When 打开 Diff，Then 显示 `冲突` 徽标，冲突标记区间高亮并显示冲突计数。
- Given 面板总宽不足 480px，Then 两栏按可用宽度等分并各自横向滚动，正文不重叠。
- Given 在工具栏切换到行内视图，Then 显示单列统一视图，行号槽同时显示旧行号与新行号，工作区侧可编辑，HEAD 侧只读，交换、折叠与列宽控件隐藏。
- Given 行内视图，Then `F6`/`Shift+F6` 与 `F7`/`Shift+F7` 仍然有效。
- Given 在行内视图编辑并保存，Then 保存的是完整工作区文档；切回并排后内容与脏状态一致。
- Given 仅新增若干行，Then HEAD 侧在对应位置出现等高空白占位，后续内容与工作区侧视觉对齐。
- Given 仅删除若干行，Then 工作区侧在对应位置出现等高空白占位并显示删除三角。
- Given 修改块两侧行数不等，Then 行数少的一侧出现等高占位。
- Given 字号、自动换行或列宽变化，Then 行对高度与占位立即重新对齐，不需要保存或重开面板。
- Given 空白占位，Then 无行号、不可选择、不可复制、不参与查找与编辑，保存后不写入磁盘。
- Given 开启 `折叠未变更区域`，Then 连续未变更行折叠并显示展开入口，行号、查找与保存内容不受影响。
- Given 在任一侧按 `Alt+Z`，Then 两栏或行内视图同时切换自动换行。
- Given 在任一侧 `Ctrl+滚轮`，Then 字号按 1px 逐级变化，到达 8px 或 32px 后不再变化；应用重启后保留。
- Given 自动换行已开启，When 关闭面板后重新打开，Then 自动换行恢复关闭。

### 冲突快照对比

- Given 编辑器或 Markdown 冲突横幅，When 点击 `查看差异`，Then 打开标题为 `<文件名>(冲突差异)` 的 Diff 面板，左侧为磁盘快照、右侧为当前缓冲快照，两侧只读且不可保存。
- Given 快照面板，When 再次点击 `查看差异`，Then 关闭旧快照面板并按当前缓冲生成新快照；不读取 HEAD、不自动刷新。
- Given 快照面板，When 按 `Ctrl+S`、关闭后重开或应用重启，Then 不保存、不恢复面板与快照，快照被清理。
- Given 快照面板，Then 行标记、并排/行内、查找、`F6`/`F7`、交换与折叠可用，任何 Git 写操作入口不可用。

### 键盘导航

- Given 面板聚焦，When 按 `F6`，Then 焦点切换到另一栏并显示可见焦点环；`Shift+F6` 反向切换。
- Given 存在多处差异，When 按 `F7`，Then 高亮并滚动到下一处差异，两侧同步滚动；在末处再按 `F7` 回到首处。
- Given 在第一处差异，When 按 `Shift+F7`，Then 跳转到末处差异。
- Given 面板存在差异，Then 页脚显示 `第 N / M 处差异`，并随导航更新。
- Given 两侧内容相同，Then 页脚显示 `无差异`，`F7` 与 `Shift+F7` 不移动。
- Given 行内视图，When 按 `F6`，Then 焦点在 HEAD 只读上下文与工作区可编辑上下文之间切换；`F7` 在统一视图中逐处导航。
- Given 工作区侧被折叠，When 按 `F6`，Then 焦点不进入折叠侧；`F7` 仍导航差异并滚动展开侧。
- Given 焦点不在 Diff 面板，Then `F6` 与 `F7` 不触发本面板命令。

### 交换与折叠

- Given 并排视图，When 执行左右交换，Then 两栏显示顺序对调，HEAD 与工作区角色不变，工作区侧仍可编辑。
- Given 左右交换已开启，When 切换到行内视图，Then 交换控件隐藏且不产生视觉影响；切回并排后交换状态保留。
- Given 折叠 HEAD 侧，Then HEAD 侧变为窄条，工作区侧扩展到剩余宽度；单击窄条可展开 HEAD 侧。
- Given 工作区侧被折叠，Then 工作区侧不可编辑，`Ctrl+S` 不执行保存；脏状态仍参与关闭守卫。
- Given 并排视图单侧折叠，Then `F6` 跳过折叠侧，`F7` 仍可逐处导航。
- Given 折叠、交换或列宽已调整，When 切换项目后再切回或重启应用，Then 对应状态保留。
- Given 关闭面板后重新打开同一文件，Then 恢复并排、自动换行关、同步开、50/50、无折叠、无交换。

### 参数持久化

- Given 分别修改视图模式、自动换行、同步滚动、列宽比例、折叠侧与左右交换，When 切换项目再切回，Then 上述参数全部保留。
- Given 上述参数修改后重启应用，Then 按项目布局恢复全部参数。
- Given 记录非 50/50 的列宽比例，When 以较窄宽度恢复，Then 按可用宽度夹取且每栏不小于 240px；面板变宽后恢复记录比例。
- Given 布局恢复，Then 不抢当前焦点，只读对照侧不自动聚焦。
- Given 关闭后重开，Then 临时状态（光标、选择、滚动、高亮差异块、提示、删除态、移出态、空白忽略开关、未变更区域折叠）重置。

### 外部重命名

- Given 工作区文件在项目根内被重命名，Then 面板跟随新路径，工作区侧读写新路径，HEAD 侧保留原路径，标题标注重命名来源，列头显示原路径与新路径。
- Given 工作区文件在项目根外、仓库内被重命名，Then 面板跟随新路径并切换为只读对比，工作区侧不可保存。
- Given 重命名发生时项目根内工作区侧有未保存修改，Then 未保存缓冲、脏状态、光标与滚动位置保留，保存写入新路径。
- Given 重命名后 HEAD 中仍存在原路径，Then HEAD 侧继续显示原路径在 HEAD 中的内容并正常刷新。
- Given 文件被移出 Git 仓库，Then 面板显示 `文件已移出仓库`，提供 `关闭面板` 与 `重新打开`，工作区侧不可读写。
- Given 重命名变化无法关联到新路径，Then 按工作区文件删除处理，提供 `重新创建` 与 `关闭面板`。
- Given 新路径已被另一 Diff 面板占用，Then 当前面板不跟随，按删除态处理并提示路径已占用。

### 差异计算与刷新

- Given 工作区侧编辑后停止输入达到配置间隔，Then 行标记与占位按当前缓冲更新，无需先保存。
- Given 未修改重算间隔设置，When 停止输入达到 300ms，Then 按默认间隔重算。
- Given 在设置中心把重算间隔改为 100–2000ms 内的其他值，When 停止输入达到新间隔，Then 按新间隔重算。
- Given 保存成功、外部重载成功或 HEAD 刷新成功，Then 差异立即重算，不等待重算间隔。
- Given 差异计算失败，Then 正文仍可编辑，面板级显示 `差异可能过时`，上一份标记保留。
- Given 差异计算超过 2 秒，Then 显示 `差异计算超时，未显示行标记`，两栏独立滚动，计算完成后自动补上标记、占位与同步。
- Given 两栏仅行尾符或末尾换行不同，Then 不产生行标记。
- Given 开启 `忽略全部空白`，When 两栏仅空白不同，Then 不产生差异标记；关闭后恢复标记。
- Given 文件存在新增与删除行，Then 列头统计随差异重算更新。
- Given 仓库 HEAD 变化，Then HEAD 侧在 300ms 去抖后更新并立即刷新差异；内容未变化时不重建正文、不移动光标与选择。
- Given HEAD 中该路径被删除，Then HEAD 侧显示 `该文件已不在 HEAD 中`，工作区全部行按新增显示，不保留旧内容。
- Given HEAD 读取失败，Then HEAD 侧显示具体错误与 `重试`，工作区侧继续可编辑。
- Given 文件与 HEAD 完全一致，Then 两侧无任何行标记与占位，页脚显示 `无差异`。

### 滚动同步

- Given 开启同步滚动，When 在一侧纵向滚动，Then 另一侧跟随到相同逻辑行对位置，且无来回抖动。
- Given 开启同步滚动，When 在一侧横向滚动，Then 另一侧横向位置不变。
- Given 关闭 `同步滚动`，Then 两侧独立滚动；重新开启后恢复同步。
- Given 某一侧为二进制、读取失败或无内容，Then 同步停用，两侧独立滚动。
- Given 某一侧为只读大文件视图且差异可用，When 滚动另一侧，Then 只读视图同步到相同逻辑行对。

### 保存与冲突

- Given 工作区侧已编辑，When 按 `Ctrl+S`，Then 磁盘内容等于完整缓冲，脏标记清除，差异立即刷新，无成功提示。
- Given 焦点在 HEAD 侧，When 按 `Ctrl+S`，Then 仍保存工作区侧内容。
- Given 编辑后撤销回磁盘基线，Then 脏状态自动清除，关闭不再确认。
- Given 保存失败，Then 显示 `保存失败：<原因>`，磁盘内容不变，工作区内容与脏状态保留。
- Given 磁盘在面板打开后被外部修改且工作区侧有未保存修改，When 按 `Ctrl+S`，Then 显示 `文件已被外部修改`，提供覆盖保存、重新加载与取消，选择前不写盘。
- Given 选择 `覆盖保存`，Then 磁盘等于工作区缓冲，基线更新，差异刷新，不出现重复冲突提示。
- Given 选择 `重新加载`，Then 本地修改丢弃，载入磁盘内容，脏状态清除。
- Given 选择 `取消`，Then 本地修改与脏状态保留，面板不关闭。
- Given 保存过程中外部程序同时写入，Then 保存完成后按新的磁盘状态处理，不出现重复冲突提示。
- Given 工作区侧只读或折叠，When 按 `Ctrl+S`，Then 不执行保存、不显示错误。
- Given 脏面板关闭，Then 出现统一未保存确认；选择保存并关闭但保存失败时，面板保留并显示失败原因。

### 外部修改与错误分类

- Given 工作区侧干净，When 外部程序修改文件，Then 正文静默更新并刷新差异，无确认框。
- Given 工作区侧有未保存修改，When 外部程序修改文件，Then 出现非模态提示 `文件已被外部修改`，提供重新加载与保留本地。
- Given 选择保留本地，Then 本地修改保留，同一份磁盘内容不再重复提示；磁盘再次变化时提示重新出现。
- Given 选择重新加载，Then 正文变为磁盘内容，脏状态清除，差异刷新。
- Given 文件被外部删除且工作区侧干净，Then 工作区侧显示删除态，提供重新创建与关闭面板；选择重新创建后磁盘恢复最近基线内容。
- Given 文件被外部删除且工作区侧有未保存修改，Then 提供重新创建、丢弃并关闭与取消。
- Given 删除态下文件重新出现，Then 退出删除态并恢复显示。
- Given HEAD 路径缺失，Then 显示 HEAD 空态而不是错误，工作区侧可编辑保存。
- Given HEAD 读取失败与工作区读取失败，Then 错误文案分别指向对应侧，并提供各自的重试动作。
- Given 两侧都读取失败，Then 整面板错误态列出两侧原因并提供重试。
- Given 面板参数越出项目根，Then 显示 `无法打开文件：<原因>`，不读取根外路径。
- Given 权限不足或文件被占用，Then 显示包含具体原因的保存或读取失败，不合并为统一文案。

### 大文件与二进制

- Given 某侧字节数大于 1 MiB 且不大于 10 MiB，Then 显示大文件提示条，正文不含提示前缀，工作区侧仍可编辑保存。
- Given 某侧字节数大于 10 MiB，Then 该侧为虚拟化只读视图，支持滚动、选择、复制、查找、字号与换行，不支持编辑与保存。
- Given 两侧都超过 10 MiB，Then 两栏均为只读视图，不进入整面板错误。
- Given HEAD 侧超过 10 MiB，Then 只读视图读取 HEAD 内容，而不是工作区文件。
- Given 工作区侧超过 10 MiB，Then 关闭面板不触发未保存确认。
- Given 文件前 8 KiB 含 NUL 字节，Then 该侧显示 `二进制文件，无法进行文本比较` 与 `用默认程序打开`，不显示行标记，工作区侧不可编辑。
- Given 大文件提示条出现，Then 保存前后文件内容、行号与行标记位置不因提示条改变。
- Given 文件大小无法取得，Then 按已读取字节数估算并标注约，允许打开。

### 焦点与生命周期

- Given 从 Commit 打开面板，Then 焦点进入工作区侧，光标位于第一个差异块第一行。
- Given 从 gutter 打开面板，Then 光标位于被点击差异块对应的行。
- Given 工作区侧只读降级，When 显式打开面板，Then 焦点进入 HEAD 侧只读视图。
- Given 应用重启或布局恢复，Then 不抢焦点，只读对照侧不自动获得焦点。
- Given 同面板组内切换面板或切换项目，Then 面板不重建，未保存修改、光标、选择、滚动、视图模式、换行、同步、列宽、折叠与交换状态保留。
- Given 关闭后重开或应用重启，Then 重新加载内容，未保存修改、光标、选择、滚动与临时提示不恢复。
- Given 项目移除或窗口关闭，Then 脏 Diff 面板纳入聚合确认，确认后销毁且不留下后台读取或后台监视任务。

### 键盘与焦点

- Given 仅使用键盘，Then 可完成打开、切栏、差异导航、查找、编辑、保存、切换换行、调整字号与关闭。
- Given 焦点在任一侧，Then 焦点环清晰可见。

## 关键决策与依据

| 规则 | 原因 | 边界 |
|---|---|---|
| 固定比较 HEAD 与工作区，不增加暂存区、任意提交或分支对比 | 保持一个面板只表达一对明确来源，避免入口与状态膨胀 | 需要其他比较对象时另立面板类型或由 Commit、GitShow 承载 |
| 实时差异以当前缓冲计算，间隔 100–2000ms、默认 300ms 且可配置 | 行标记应反映用户眼前内容；不同文件规模与机器需要不同频率 | 保存、重载、HEAD 刷新后立即重算；过期结果不得覆盖新结果 |
| 行级差异配合等高行对占位 | 两侧共享纵向坐标，滚动同步与逐块导航才有稳定基准 | 行内视图改用虚拟删除行与双行号，不插入可编辑空白 |
| 滚动同步基于逻辑行对而非像素偏移 | 字号、折行与列宽变化后仍能保持对应内容同视线 | 仅同步垂直方向；二进制、缺失侧或差异不可用时停用 |
| 提供 `F6`/`F7` 键盘切栏与差异导航 | 键盘可完整操作，焦点与当前位置明确，避免仅鼠标可达 | 仅在面板聚焦时生效；`F6`/`F7` 为面板内固定键，不承诺重绑 |
| 并排与行内双模式，行内保留工作区可编辑 | 宽面板适合对照，窄面板适合聚焦编辑，避免为查看差异放弃编辑能力 | 行内隐藏布局类控件；交换、折叠与列宽参数保留并在切回时恢复 |
| 左右交换只改变显示顺序，不改变 HEAD 与工作区角色 | 显示习惯可变，但可编辑性、保存目标与差异语义必须稳定 | 仅并排可见；行内不生效但保留参数 |
| 支持单侧折叠为窄条 | 在窄面板中为编辑或阅读腾出空间，同时保留另一侧随时展开 | 仅并排；折叠侧不可编辑，`F6` 跳过，`F7` 仍导航 |
| 面板参数随项目布局持久化，关闭重开恢复默认 | 项目切换与重启需要还原阅读布局；新建面板不应继承旧实例状态 | 各参数按可用宽度夹取，栏最小 240px |
| 工作区文件在根内重命名时跟随，HEAD 保留原路径 | 重命名不应让面板失效或丢失未保存修改，同时差异来源仍可追溯 | 移出项目根但仍在仓库内进入只读对比；移出仓库进入移出态；无法关联按删除处理 |
| 保存前检测外部修改，冲突时由用户选择 | 静默覆盖会丢失他人改动，自动合并超出面板职责 | 覆盖、重新加载、取消三选一；只读与折叠状态下不保存 |
| Diff 使用自身按字节的 1 MiB/10 MiB 分级，提示在文档外 | 按字符判定会误伤多字节文本；文档内前缀会写盘并错位行号 | 阈值按磁盘字节；HEAD 侧按 Git 对象大小；二进制按 NUL 判定 |
| 外部修改使用非模态提示 | 频繁模态确认会打断编辑，且多数变化不需要立即决策 | 保留本地只抑制同一份磁盘内容，新变化重新提示 |
| 不提供合并、暂存区比较、差异块级回滚或任何 Git 写 | 面板职责是只读对比与编辑工作区文件，Git 写归 Commit 视图 | 外部修改整份重载替换，不做三方合并 |
| HEAD 刷新采用去抖、激活复核与周期复核组合 | 变化通知在网络驱动器等位置可能丢失，需要最终一致 | 刷新不覆盖工作区修改，不询问、不移动光标 |
