# Diff 面板

> 拥有固定来源对比、差异展示、导航和只读快照；工作区文本是共享 [Document](document.md)，不建立第二份可编辑缓冲。

## 对比模型与入口

- 默认 Diff 比较绑定仓库中的 HEAD 路径与工作区 Document；不提供暂存区、任意提交或分支间对比，不执行 Git 写操作。
- 入口为 Commit 的 modified／renamed／conflict 条目和 Editor 的 Git 行标。deleted 由 GitShow 承载，added／untracked 由普通文档视图承载。
- 同一项目同一 Document 最多一个默认 Diff；重复入口聚焦并定位。Editor、Markdown 与 Diff 可同时存在并共享工作区文本、脏状态、撤销和冲突。
- 从 Commit 打开时，如果 Document 已打开则直接引用其实时文本，而不是重新读盘形成副本；未打开时按统一 Document 路由加载。
- renamed 条目保留创建时 HEAD 旧路径与工作区当前位置；conflict 条目把冲突标记作为普通文本显示并计数，不自动合并。
- 默认 Diff 记录仓库身份、HEAD 路径和工作区 Document。项目根重定位不得把它改绑到新仓库同相对路径 HEAD；原绑定不可用时显示错误。
- 工作区写能力由 PathPolicy 判定；RepoRoot 只读范围不妨碍另一有效根授予的写能力。

## 只读快照

- 冲突横幅的“查看差异”创建磁盘版本与当前缓冲的只读快照；两侧不可编辑、不可保存、不参与自动保存，也不读取 HEAD。
- 大于 10 MiB 的脏 Document 在 Diff 中以只读未保存缓冲快照显示；源 Document 不因打开 Diff 被强制保存或转为只读。
- 快照不自动刷新，重新执行“查看差异”生成新代；源冲突解决或源视图销毁后清理。
- 快照是临时恢复辅助材料，不进入文件路由、普通 Diff 去重或持久布局；其内容不写入崩溃快照、备份或诊断。

## 视图与对齐

- 默认并排显示 HEAD 与工作区；行内模式用统一列和双行号表达新增、删除与修改，工作区编辑语义不变。
- 并排支持列宽调整、左右交换和单侧折叠；交换只改变显示顺序，折叠只改变可见性，均不改变 Document 或保存目标。
- 行内模式隐藏交换、折叠和列宽控件，保留参数供切回并排恢复；同步滚动在行内无作用。
- 新增、删除和修改通过行对及等高空白占位对齐；占位无行号、不可选择、不参与查找、编辑或保存。
- 行内使用虚拟删除行，不插入真实空行。字号、换行和列宽变化后重新计算行对高度。
- 可折叠连续未变更区域；折叠不影响差异计算、查找或保存内容。

## 差异计算与 HEAD 刷新

- 差异按行计算，工作区编辑无需先保存；停止编辑后按应用设置的重算间隔后台计算，默认 300 毫秒，可配置 100–2000 毫秒。
- 保存、外部重载和 HEAD 刷新后立即重算；只采纳最新文本代次，失败保留正文并说明差异可能过期。
- 可配置忽略行尾空白或全部空白；空白选项只影响差异，不改写文本。CRLF／LF 与文件末尾换行本身不形成独立差异块。
- HEAD 在绑定仓库内刷新；可见时响应仓库元数据变化并在重新可见时合并复核，不可见时暂停后台刷新与纯展示重算。
- HEAD 路径不存在时显示空侧，工作区按新增处理；HEAD 读取失败保留工作区编辑能力并显示可重试错误。
- HEAD 刷新不得覆盖工作区 Document、改变其脏状态或移动各视图光标。

## 编辑、保存与外部变化

- HEAD 侧始终只读；工作区侧在授权和大小允许时可编辑，修改直接写入共享 Document。
- `Ctrl+S` 保存工作区 Document，所有 Editor／Markdown／Diff 引用共享保存结果；失去写授权时可按 Document 规则另存为。
- 自动保存按 Document 统一触发，Diff 不另设计时器。只读快照不参与；折叠某一侧不创建独立保存或自动保存规则。
- 外部修改与保存冲突由 Document 统一拥有；Diff 不自动合并、不做三方合并、不按差异块保存或回滚。
- 外部改名只更新 Document 位置，不重建 Panel；HEAD 旧路径保持。文件移出绑定仓库或失去读取授权时保留已加载内容、停止相应刷新并显示原因。

## 滚动与键盘

- 并排默认同步垂直滚动，以逻辑行对而非原始像素对齐；横向滚动独立并消除同步回环。差异不可用或一侧无内容时停用同步。
- `F6`／`Shift+F6` 在 HEAD 与工作区上下文间切换，跳过折叠侧；`F7`／`Shift+F7` 在差异块间循环并滚动到目标。
- 页脚显示当前差异序号与总数，无差异时明确显示；当前差异不只靠颜色表达。
- `Ctrl+F` 在聚焦上下文查找，`Alt+Z` 切换换行，`Ctrl+滚轮` 调整共享编辑器字号。
- 显式打开优先聚焦可编辑工作区，否则聚焦只读内容；布局恢复不抢焦。所有命令进入统一命令目录并支持 IME 组合隔离。

## 大文件与二进制

| 任一侧真实字节数 | 行为 |
|---|---|
| 不超过 1 MiB | 正常文本视图 |
| 大于 1 MiB 且不超过 10 MiB | 显示大文件提示，工作区仍可编辑 |
| 大于 10 MiB | 该侧分页只读，支持滚动、选择、复制与查找 |

- 体积按 HEAD 对象或工作区真实字节分别判定，不引用 Editor 阈值；提示条不进入正文或保存内容。
- 长差异计算可取消，过期结果丢弃；差异不可用时先显示正文并允许两侧独立滚动。
- 前 8 KiB 含 NUL 的一侧按二进制处理，不显示文本差异；可提供系统默认程序外部查看，但不形成编辑或保存通道。

## 持久状态

- `ViewKey` 持久保存视图模式、自动换行、同步滚动、列宽、折叠侧、左右交换、空白忽略和未变更区域折叠；关闭重开与重启均恢复。
- 文件绑定按仓库、HEAD 路径和 Document 对账恢复；根重定位不重新解释为新仓库。
- 光标、选区、滚动、当前差异高亮、搜索、临时错误、删除提示和焦点为瞬态，两条恢复路径均清除。
- 只读冲突与大文件快照不持久化；正常重启不恢复未保存正文，异常恢复按 Document 快照处理。

## 验收判据

- **Given** Editor 中 Document 有未保存修改，**When** 从 Commit 打开同文件 Diff，**Then** Diff 直接显示该共享文本，不读盘生成第二份缓冲。
- **Given** 在 Diff 工作区侧编辑，**When** 切到同 Document 的 Editor 或 Markdown，**Then** 文本、撤销和脏状态一致。
- **Given** 项目根重定位到另一仓库，**When** 查看既有 Diff，**Then** 不读取新仓库同相对路径 HEAD；原绑定不可用时显示错误。
- **Given** 根外只读范围与另一可写根同时覆盖工作区，**When** 保存，**Then** 按能力并集处理，不只读化整个 Document。
- **Given** 修改视图模式、交换、折叠、空白忽略等参数，**When** 关闭重开或重启，**Then** 均恢复；搜索与临时提示清除。
- **Given** 冲突快照打开后源文本继续变化，**Then** 快照不自动更新、不可保存，重新查看才生成新代。
- **Given** HEAD 在隐藏期间多次变化，**When** Diff 重新可见，**Then** 合并复核一次且旧计算不覆盖新结果。
- **Given** 任一侧超过 10 MiB 或含 NUL，**Then** 分别进入分页只读或二进制占位，另一侧仍按自身状态可用。
