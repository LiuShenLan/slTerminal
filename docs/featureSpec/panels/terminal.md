# 终端面板

> 终端面板承载单个 PTY 会话，是项目内运行 Shell 与 AI CLI 的唯一终端载体；本篇不拥有工作区焦点与关闭链、设置中心页面布局、设置持久化去抖机制。

## 目标行为

### 面板模型与归属

- 一个终端面板对应一个 PTY 会话；一个 PTY 只属于一个终端面板。面板内容区只呈现该会话。
- 并排终端通过项目布局内的多个面板组承载；面板组的拆分、合并、拖拽与尺寸归[工作区壳契约](../workspace/shell.md)。
- 每个项目恰好一个项目布局；终端面板属于且仅属于一个项目。跨项目拖动终端面板被拒绝。
- 项目内跨面板组拖动终端时，PTY 会话、画面与回滚内容不重建。
- 终端编号以项目为范围；PTY 上限以应用为范围。
- 多项目布局同时存活；切换项目只改变可见性，不销毁终端。
- 不变量：终端内容不写入磁盘；运行期状态不跨应用重启恢复；一个终端面板任何时刻最多一个活动 PTY；所有项目中的终端可同时运行。
- 产品边界：Windows 10/11、单窗口、单实例、仅暗色模式。焦点、关闭守卫与布局持久化由[工作区壳契约](../workspace/shell.md)拥有；明确不做项统一登记于[验收文档](../acceptance.md)，本篇不展开。

### 面板构成与页签

- 内容区占满面板可用空间，只显示终端画面；没有常驻工具栏、新建/关闭按钮或常驻状态栏。
- 按需出现的覆盖层包括连接遮罩与底部操作栏（进程退出或启动失败时）。
- 面板页签显示标题、可选 CLI 图标 <img src="../assets/cli-svg/claude.svg" width="16" height="16" alt="CLI 图标示例">（按 AgentKind 取 `../assets/cli-svg/<slug>.svg`，16px，见 [资产清单](../assets/README.md)）与可选状态圆点；无品牌资产时不显示 CLI 图标。页签顺序、溢出与拖拽由工作区壳契约定义。
- 标题优先级：用户自定义标题 > 运行中的 CLI 会话标题 > 历史会话标题 > `terminal-N`。
- 终端编号在项目内独立分配，从 0 开始；创建时分配，关闭不重排、不复用；项目计数器随项目布局持久化；应用重启按布局恢复编号，不重新计算；不同项目可出现相同编号。
- 历史会话恢复创建的终端同样分配项目编号，初始显示历史会话标题；无标题时显示会话 ID 前 8 位。
- 标题超长时省略显示；悬停显示完整标题、被自定义标题覆盖的 CLI 会话标题与编号。
- CLI 图标在识别到已注册 CLI 会话时显示；会话结束或进程退出后移除。
- 状态圆点：工作=绿、注意=黄、完成=灰、错误=红；无状态时不显示。圆点具有悬停文本与名称，不以颜色作为唯一信息。
- 终端画面使用可配置等宽字体，缺字体时回退主题等宽字体栈；光标为闪烁竖线；回滚缓冲默认 10000 行。
- 配色取自当前暗色主题的 ANSI 调色板，不硬编码颜色。
- 终端面板没有空态；终端程序清屏后的空白属于终端内容。

### 新建入口与落点

| 入口 | 目标项目 | 落点面板组 | 工作目录 |
|---|---|---|---|
| 面板组页签栏「+」 | 面板组所属项目 | 按钮所在面板组 | 同项目最近聚焦终端目录；无则项目根 |
| 终端面板页签右键「新建终端」 | 面板所属项目 | 被右键面板所在面板组 | 被右键终端的已知目录；无则项目根 |
| 文件浏览器「在终端中打开」 | 文件所属项目 | 该项目聚焦面板组；回退规则见工作区壳契约 | 文件所在目录；文件夹为文件夹自身 |
| Agent 全局文件「在终端中打开」 | 活跃项目；无活跃项目时提示先打开项目 | 活跃项目聚焦面板组 | 文件所在目录；须在允许根内 |
| 历史会话恢复 | 会话目录匹配的项目；无则由导航树契约创建或选择 | 该项目聚焦面板组 | 历史会话记录目录；失效回退项目根并提示 |

- 所有入口每次创建独立终端，不复用已有会话。
- 新建成功后终端输入区获得键盘焦点；布局恢复不抢焦点。
- PTY 达到上限时不创建空面板，直接显示错误提示。
- 文件夹入口打开文件夹自身，不取父目录。
- Commit 视图没有「在终端中打开」入口；其条目按版本控制状态打开编辑器、Diff 或 GitShow 面板。导航树契约见[导航树](../workspace/navigation.md)，文件树入口见[文件浏览器](../sidebar/explorer.md)，Agent 全局文件入口见[Agent 文件](../sidebar/agent-files.md)，Commit 视图见[Commit](../sidebar/commit.md)。

### Shell 选择与工作目录

- 设置中心「终端」页提供「默认 Shell」：自动（`pwsh.exe` → `powershell.exe` → `cmd.exe`）、PowerShell 7、Windows PowerShell、cmd、自定义可执行文件。设置中心页面布局见[设置中心](settings.md)；终端语义由本篇拥有。
- 自动模式按固定顺序逐个尝试，使用第一个成功创建 PTY 且未立即退出的 Shell；全部失败时创建失败并列出各候选的失败原因。
- 显式选择缺文件或启动失败时创建失败，不静默切换到其他 Shell；错误包含路径与原因，并提供「改用自动探测重试」。
- PowerShell 会话不跳过用户 profile，profile 中的环境初始化正常生效；同时注入 Shell 集成以提供命令边界、标题、状态与目录跟踪。cmd 没有 Shell 集成。
- 工作目录优先级：入口显式指定 > 同项目最近聚焦终端的最近已知目录（若在允许根内；页签右键新建时取被右键终端）> 项目根。
- 应用发起的目录必须位于项目根或已登记的 Agent 全局目录内；越界、缺失或非法时创建失败并提示原因。
- Shell 内部 `cd` 不受应用限制；应用只跟踪并记录，用于新终端继承与重启恢复。
- 文件夹入口使用文件夹自身；文件入口使用文件所在目录。
- 历史会话恢复使用会话目录；目录不可用时回退项目根并提示。
- 项目根不可用时创建失败并给出原因，不继承应用自身工作目录。
- 每个终端持久化最近已知工作目录，去抖 300ms；重启恢复时校验，失效回退项目根并提示。
- Shell 集成能力降级：cmd 或自定义 Shell 无命令边界时，标题、状态与目录跟踪按可用能力降级，但不得阻止输入输出。

### 输出、渲染与滚动缓冲

- PTY 输出始终按顺序解析进终端缓冲，与项目是否可见、面板是否聚焦无关；隐藏项目与不可见面板只暂停绘制，不暂停进程，不丢弃字节。
- 面板重新可见时立即呈现最新缓冲状态，不补放中间帧。
- 可见终端不超过 256 字节的输出在下一帧内呈现；突发输出按帧合并，最长 16ms 提交一次；同一帧内的网格变更原子呈现，不出现撕裂。
- 输出洪峰时暂停读取 PTY，待缓冲消化后继续；任何情况下不丢字节。
- 跨输出块的多字节 UTF-8 字符不得乱码或错位。
- 尺寸变化顺序：已接收但未解析的输出按变化前的网格解析；随后应用新尺寸并通知 PTY；不丢弃变化前尺寸下的输出。新尺寸生效后的输出按新网格呈现。
- 回滚缓冲默认 10000 行，可在设置中心「终端」页配置 1000–100000 行；超出时丢弃最旧行。交替屏幕内容不进入回滚缓冲。
- 宽度变化时软换行内容重排；硬换行不重排。
- 切换面板或项目时保留各面板滚动位置；原本在底部则切回后继续跟随新输出，否则保持位置。
- 渲染优先使用硬件加速；不可用时自动降级为软件渲染，功能不变，不向用户暴露渲染器。持续低于性能目标时一次性非阻塞提示「终端渲染性能可能下降」。
- 全屏 TUI 使用同一输出与尺寸路径；改变尺寸后应完整重绘，无错位、残影或撕裂。
- 终端程序清屏后的空白属于终端内容，不是应用空态。
- 终端内容与选区状态不写入磁盘。

### 键盘输入、选区与剪贴板

| 快捷键 | 作用 |
|---|---|
| 任意可打印字符、控制键、方向键、功能键 | 编码后发送到 PTY |
| `Ctrl+Shift+C` | 复制当前选区；无选区时不复制，但按键被消费 |
| `Ctrl+Shift+V` / `Shift+Insert` | 从系统剪贴板粘贴 |
| `Ctrl+Enter` | 向 PTY 写入 LF（0x0A），等价 `Ctrl+J`；接收方语义由前台程序决定 |
| `Ctrl+C` | 页签为「工作」时改为「注意」，随后发送 0x03；重复触发幂等 |
| `Ctrl+W` | 关闭当前面板；工作区快捷键，见[工作区壳契约](../workspace/shell.md) |
| `Esc` | 发送 ESC 到 PTY |
| `F2` | 面板页签获得焦点时进入重命名（CLI 会话运行中禁用）；终端输入区聚焦时发送给前台程序 |
| `Ctrl+滚轮` | 字号加 1 或减 1 |

- 保留键不可被用户覆盖绑定：`Ctrl+C`、`Ctrl+V`、`Ctrl+X`、`Ctrl+Z`、`Ctrl+A`。仅设置中心快捷键页列出的命令可重绑；面板内固定键（选区、滚动、`F2` 等）不承诺可重绑。
- 点击终端内容区或切换到面板时，键盘焦点进入终端输入区；新建终端自动聚焦；布局恢复不抢焦点。
- 输入法合成期间不触发终端快捷键；合成文本正常进入终端。合成中按 Enter 确认合成，不触发终端快捷键。该路径依赖真实系统输入法。
- 前台程序请求增强键盘协议时，终端按其能力编码差异化按键；应用不主动启用。
- 鼠标滚轮默认滚动回滚缓冲；前台程序启用鼠标跟踪时滚轮事件交由程序处理；按住 `Shift` 滚轮强制本地回滚。
- 鼠标与滚轮始终按前台程序声明的鼠标跟踪与交替屏幕状态自动路由，新建与已打开终端行为一致，无手动切换入口。
- 拖拽选择文本；开始输入清除选区。软换行按连续文本复制，硬换行保留换行。
- 粘贴优先使用前台程序支持的括号粘贴；内容按原样发送，不自动追加 Enter。
- 粘贴安全：剪贴板包含除制表、回车、换行外的 C0 控制字符，或包含 C1 控制字符时，弹出确认「粘贴内容包含控制字符，可能执行命令」；超过 50 行时弹出确认并显示行数；超过 10MB 时拒绝并提示。确认框按钮为「粘贴」「取消」。
- 复制、粘贴失败时显示非阻塞提示；日志不得包含剪贴板内容或终端内容。

### 链接与终端剪贴板序列

**OSC 8 链接**

- 只有程序声明为 OSC 8 的链接可点击；普通 URL 文本不会自动识别为链接。
- 悬停时显示下划线、指针与工具提示；工具提示包含完整 URL 与「Ctrl+单击打开」。
- `Ctrl+单击` 打开链接：`http`、`https` 交给系统默认浏览器，`mailto` 交给系统默认邮件程序；其他 scheme 忽略并提示「不支持的链接类型」。
- URL 长度超过 8KB 时忽略。
- 打开链接异步执行，不阻塞终端输入输出；打开失败显示非阻塞提示。
- 不按 `Ctrl` 单击只移动光标或建立选区，不打开链接。

**OSC 52 剪贴板写入**

- 仅支持写入，永不响应读取请求（`?`）。
- 仅接受系统剪贴板选择器：空选择器或 `c`；忽略 `p` 与 `q`。
- 默认仅当终端输入区具有键盘焦点且所属项目为活跃项目时接受；否则忽略，不改变剪贴板。
- 设置中心「终端」页提供「允许非聚焦终端写入剪贴板」，默认关闭；开启后活跃项目内未聚焦终端可写入，隐藏项目中的终端始终不可写入。
- 单条负载超过 1MB 时整体忽略，不截断写入。
- 负载按 UTF-8 解码后写入系统剪贴板；非法 base64 或非法 UTF-8 时静默忽略。
- 写入成功显示非阻塞提示「已复制到剪贴板（终端）」；提示与日志不包含剪贴板内容。
- 序列处理后从画面消费，不显示控制序列。
- OSC 52 与 `Ctrl+Shift+C` 共用同一剪贴板写入通道；写入失败显示非阻塞提示。

### 尺寸、字号与光标

- 初始创建时等待容器尺寸就绪，最长 500ms；期间不可用则先以 80×24 网格创建，容器尺寸就绪后立即适配并通知 PTY。
- 运行时行数变化（高度变化）立即适配并通知 PTY；列数变化（宽度变化）合并 100ms 内的连续变化后适配一次；行列均无变化时不执行操作。
- 每次适配先更新本地网格，再向 PTY 发送尺寸变化。
- 普通屏幕与交替屏幕使用同一适配路径。
- 容器尺寸为 0 时不适配；重新可见后测量并适配，已接收输出按原顺序处理。
- 重连使用当前容器尺寸；当前尺寸不可用时以 80×24 兜底。
- 非法网格值被丢弃，不发送给 PTY；尺寸适配失败只记录日志，不影响输入输出。
- 字号变化只改变显示与 PTY 尺寸，不重启或影响已运行进程。
- 终端字号全局共享，范围 8–32，默认 14；所有终端立即同步，编辑器字号独立。
- 调整入口：`Ctrl+滚轮` 与设置中心外观页。
- 字号变化立即触发网格适配与 PTY 尺寸通知，不受列变化去抖影响。
- 字号与字体家族属于外观设置，变更去抖 2 秒后写入；关闭窗口时强制冲刷，最近一次变更不得丢失。
- DPI 缩放变化时重新测量并立即适配，不出现闪烁或错位。
- 光标为闪烁竖线；设置中心「终端」页默认开启闪烁，系统启用「减少动效」时默认关闭，用户可显式开启覆盖。
- 字体家族可在设置中心外观页选择，缺字体时回退主题等宽字体栈；所有终端立即同步。

### 标题、状态与 CLI 识别

- 自定义标题通过面板页签右键「重命名」或页签聚焦时 `F2` 设置。弹窗标题「重命名终端」，预填当前标题并选中全部文本；`Enter` 确认，`Esc`、点击遮罩或「取消」取消；空或纯空白提交显示行内错误「名称不能为空」并保持弹窗；超过 128 字符显示「名称过长」。CLI 会话运行中禁止重命名；未运行时可重命名。
- 自定义标题立即持久化；CLI 标题不得覆盖自定义标题，CLI 会话标题在悬停提示中显示。
- 未自定义标题时，PowerShell 命令开始且首 token 精确命中已注册 CLI 命令或用户别名（Windows 上不区分大小写），标题切换为该 CLI 的固定标题，状态置为「注意」，显示 CLI 图标。
- 命令结束时，标题按优先级恢复为自定义标题、历史会话标题或 `terminal-N`；状态圆点与 CLI 图标清除。
- 普通命令不改变标题与状态。
- 运行中的 CLI 会话标题按「AI 标题 > 摘要 > 首个提示词 > 会话 ID 前 8 位」刷新，最多每 5 秒一次。
- 运行中的 CLI 会话由 agent 事件驱动四态：工作（绿）、注意（黄）、完成（灰）、错误（红）。未知 CLI 或无对应能力的事件被忽略。
- `Ctrl+C` 本地中断只把「工作」改为「注意」，不产生文字提示；当前不是工作态时不改变状态。
- 会话结束事件只清除状态圆点与 CLI 图标，不恢复标题；命令结束或进程退出才恢复标题。
- 任务完成或等待输入时：仅当应用窗口未聚焦，发送系统通知并闪烁任务栏；窗口聚焦时不发送系统通知。系统通知类别包含任务完成、等待输入、权限请求与错误，规则以[工作区通知契约](../workspace/shell.md)为准；同类事件在去重窗口内只通知一次。
- cmd 没有命令边界，不会自动切换标题；会话开始/结束事件仍可按 CLI 能力更新状态。
- 面板页签的标题、状态圆点与 CLI 图标实时同步到导航树活跃会话行；导航树细节见[导航树](../workspace/navigation.md)。激活活跃会话行直接切换到对应项目并聚焦该终端面板，无提示与确认流程。
- 状态圆点与 CLI 图标具有名称；CLI 图标的名称为 CLI 名称。
- 状态、图标、运行中标题与会话元数据仅存在于运行期，不持久化。

### 进程生命周期与重连

状态迁移：

- 连接中 → 运行中：首个非空 PTY 输出到达。
- 连接中 → 启动失败：会话创建失败。
- 运行中 → 已退出：进程退出。
- 启动失败 → 连接中：用户重试。
- 已退出 → 连接中：用户重新连接。
- 任一状态 → 结束：关闭面板、关闭面板组、关闭项目或关闭窗口。

行为：

- 连接中显示居中遮罩「正在连接...」；首个非空输出到达时立即隐藏。1500ms 后仍未就绪则隐藏遮罩，改为顶部非阻塞状态「正在连接...」，避免永久遮挡。
- 连接中就绪前键入的内容按序缓存，最多 4096 字节；会话就绪后按序发送；创建失败时丢弃缓存。
- 进程退出时保留最终输出；若检测到 CLI 会话，先清除状态圆点与 CLI 图标并按优先级恢复标题，再显示底部操作栏「进程已退出（退出码 N）」；退出码不可用时显示 `?`。操作栏提供「重新连接」「关闭面板」。终端聚焦时，按 `Enter` 执行重新连接。
- 进程退出后保持已退出状态，直到用户执行重新连接或关闭面板；应用不自行创建新会话。
- 重新连接使用当前容器尺寸创建新 PTY，工作目录取最近已知目录、失效时项目根；原进程状态与内存不保留。已有回滚内容保留，并插入一条「新会话」分隔标记。
- 启动失败时显示底部操作栏「终端启动失败：<原因>」与「重试」「关闭面板」；同一失败事件只弹一次非阻塞提示，持续失败只更新操作栏，不重复弹提示。
- 重新连接或重试请求在连接中重复触发时合并为一次；新的失败或退出会重新启用操作。
- 输入发送连续失败 3 次时显示非阻塞提示「终端输入发送失败：<原因>」；成功一次后计数清零。
- 关闭面板终止对应 PTY，回滚内容丢失，不可撤销。运行中终端的关闭确认由工作区关闭守卫统一处理（见[工作区壳契约](../workspace/shell.md)）；终端向守卫提供是否存在前台进程。关闭面板组或项目时，其中运行中的终端同样由工作区关闭守卫处理。
- 连接中关闭面板时取消创建；已创建的子进程必须终止，不留孤儿。
- 删除项目时终止该项目全部 PTY；项目删除确认由工作区壳契约拥有。
- 窗口关闭流程中，终端侧先完成设置与布局冲刷，再并发终止所有 PTY，与工作区壳关闭链顺序一致；优雅终止等待 2 秒，超时强制终止，终端清理阶段不超过 3 秒。清理失败只记录日志，不阻止关闭；子进程树由操作系统兜底终止。
- 应用异常崩溃时由操作系统终止子进程树；不保证布局与设置冲刷。
- PTY 上限为 64 个/应用。创建前原子检查上限；达到上限时不创建面板，提示「会话数已达上限（64），请关闭其他终端」；已有会话不受影响。
- 布局恢复时若终端数超过上限，按布局顺序连接前 64 个；其余显示启动失败状态，关闭其他终端后可重试。
- 隐藏项目中的终端继续运行并解析输出，不因不可见而暂停进程。

### 历史会话恢复

- 导航树契约确定目标项目、落点面板组、工作目录、CLI 与历史会话 ID；终端侧负责创建面板、分配编号、设置初始标题并注入恢复命令。
- 初始标题为历史会话标题；无标题时取会话 ID 前 8 位。该标题是运行期标题，不写入自定义标题。
- 就绪判定优先使用 Shell 集成的提示符标记；PowerShell 系最长等待 10 秒，超时仍尝试注入；cmd 固定等待约 0.5 秒。
- 就绪后注入恢复命令并回车；普通恢复与分支恢复的命令差异由导航树会话契约提供，终端只保证注入时机与输入通道。会话 ID 注入前校验格式，禁止任意文本注入。
- 等待注入期间显示非阻塞「正在恢复会话...」状态；首个终端输出正常呈现。
- 超时仍执行注入；若注入通道不可用，或注入后仍无终端输出与提示符，按失败处理并提示。
- 恢复失败时：应用在前台则显示非阻塞提示；应用不在前台则发送系统通知「恢复会话失败」，正文包含会话 ID 前 8 位与失败原因。其他终端不受影响，不自动重试。
- 面板在注入前关闭或进程退出时，取消待注入命令。
- PTY 达到上限时不创建面板，导航树显示对应错误。
- 恢复后的会话标题在应用重启后不保留；无自定义标题时回落为 `terminal-N`。

### 状态保留与持久化

| 状态 | 同面板组切面板 | 切换项目 | 关闭后重开 | 应用重启 |
|---|---|---|---|---|
| PTY 进程 | 保留 | 保留 | 终止，新建进程 | 新建进程 |
| 画面与回滚内容 | 保留 | 保留 | 丢失 | 丢失 |
| 滚动位置 | 保留 | 保留 | 重置到底部 | 重置到底部 |
| 工作目录 | 保留 | 保留 | 按入口；无显式入口时继承聚焦终端目录或项目根 | 恢复保存目录；失效回项目根 |
| 自定义标题 | 保留 | 保留 | 无 | 恢复 |
| 终端编号 | 保留 | 保留 | 项目计数器分配新号 | 按布局恢复 |
| 未自定义标题 | 保留并更新 | 保留并更新 | 新 `terminal-N` 或历史会话标题 | 历史会话标题不保留，回落 `terminal-N` |
| 状态圆点与 CLI 图标 | 保留并实时更新 | 保留并实时更新 | 无 | 不恢复，直至再次识别到 CLI 会话 |
| CLI 会话元数据 | 保留 | 保留 | 无 | 不持久化 |
| 终端字号与字体 | 全局共享 | 全局共享 | 不变 | 恢复 |
| 键盘焦点 | 遵循工作区壳契约 | 遵循工作区壳契约 | 新终端聚焦 | 不抢焦点 |

- 随项目布局保存的终端面板数据：所属项目、终端编号、自定义标题、最近已知工作目录。
- 应用设置中的终端数据：字号、字体家族（外观页）；回滚行数、默认 Shell、非聚焦终端 OSC 52 写入开关、光标闪烁（终端页）。
- 保存时机：自定义标题立即保存；终端编号与工作目录去抖 300ms；字号与字体家族去抖 2 秒；关闭窗口前强制冲刷，最近一次变更不得丢失。持久化机制见[设置与持久化](../settings-and-persistence.md)。
- 不持久化：终端画面、回滚内容、选区、滚动位置、状态圆点、CLI 图标、运行中标题、CLI 会话元数据、待注入命令。
- 应用重启：恢复布局并为每个终端创建新 PTY；恢复编号、自定义标题与工作目录；目录失效时在项目根启动并提示；隐藏项目中的终端同样创建并运行。
- 设置文件损坏时回退默认值并提示；保存失败时提示；设置中心细节见[设置中心](settings.md)。
- 终端内容仅存在于内存：关闭面板、关闭项目或应用退出后不可恢复；这是隐私边界。

## 交互规则

### 焦点与切换

- 新建终端成功后焦点进入终端输入区；布局恢复不主动抢占焦点。
- 显式打开或激活面板（点击面板页签、点击终端内容区、导航树激活、通用切换面板快捷键）时，终端输入区获得焦点；通用快捷键见[工作区壳契约](../workspace/shell.md)。
- 切换项目后恢复该项目上次聚焦的面板；若该面板是终端，输入区获得焦点。
- 终端快捷键只作用于聚焦终端；无聚焦终端时按工作区壳契约处理，不转发到其他终端。
- 隐藏项目中的输出、状态变化与命令完成不得抢占焦点，不得自动切换到该项目。
- 退出操作栏或错误操作栏出现时，终端仍保持输入焦点；`Enter` 在终端聚焦时执行重连，在按钮聚焦时触发按钮。
- 键盘焦点环可见；操作栏均可键盘操作；`Esc` 从操作栏返回终端。

### 鼠标与键盘

- 单击终端内容区聚焦并清除选区；拖拽建立选区。
- 滚轮默认滚动本地回滚；前台程序启用鼠标跟踪时滚轮交给程序；`Shift+滚轮` 强制本地滚动。
- `Ctrl+单击` OSC 8 链接；不按 `Ctrl` 的单击不打开链接。
- 终端面板页签可拖拽到同项目其他面板组；跨项目拖拽被拒绝并显示提示。拖拽过程中 PTY 保持运行。
- 终端输入区聚焦时，`F2` 发送给前台程序；只有页签本身获得焦点时 `F2` 才进入重命名，CLI 会话运行中不进入重命名。
- `Ctrl+W` 关闭当前面板；终端不额外拦截或改写该快捷键。
- 退出操作栏与错误操作栏出现时，终端输入焦点仍保留在内容区。

### 面板页签菜单与重命名

- 终端面板页签右键菜单：「新建终端」「重命名」「关闭」「关闭其他」「关闭全部」。
- 「新建终端」落点与工作目录按「新建入口与落点」执行。
- 「重命名」在 CLI 会话运行中禁用；未运行时可重命名。
- 「关闭」「关闭其他」「关闭全部」只作用于当前面板组内的面板；运行中终端的确认由工作区关闭守卫统一处理。
- 重命名弹窗行为按「标题、状态与 CLI 识别」执行；确认后标题立即更新并保存。
- 关闭路径包括页签关闭按钮、`Ctrl+W`、鼠标中键与右键菜单；所有路径共用同一关闭守卫。

### 复制与粘贴

- 有选区时 `Ctrl+Shift+C` 复制；无选区时消费按键但不改变剪贴板。
- `Ctrl+Shift+V` 或 `Shift+Insert` 粘贴。
- 粘贴使用括号粘贴（前台程序支持时）；不自动追加回车。
- 触发粘贴安全确认时，确认框显示行数与警告，不显示剪贴板内容；取消后不向终端发送任何字节。
- 复制失败、粘贴失败、剪贴板读取失败均显示非阻塞提示，不静默失败。

### 链接与剪贴板反馈

- 悬停 OSC 8 链接显示下划线与工具提示；工具提示包含完整 URL 与操作提示。
- `Ctrl+单击` 打开允许的 scheme；不支持的 scheme 显示「不支持的链接类型」，不调用系统处理程序。
- OSC 52 写入成功显示「已复制到剪贴板（终端）」；默认策略下非聚焦或隐藏项目中的写入被忽略且不显示提示，避免泄露后台程序行为；开启后台写入后，活跃项目内非聚焦终端可写入并显示提示。
- OSC 52 负载超限且终端聚焦时显示「终端剪贴板内容超过 1MB，已忽略」。
- 链接打开失败显示「无法打开链接」；不得阻塞终端输入输出。

### 尺寸与字号

- 拖动窗口、调整侧栏、调整面板组比例、切换项目、DPI 变化均触发尺寸适配。
- 行变化立即生效；列变化在 100ms 合并窗口后生效一次；字号变化立即生效。
- `Ctrl+滚轮` 被终端消费，不触发界面缩放或回滚。
- 字号达到 8 或 32 后继续调整不越界；所有终端同步变化。
- 字号、字体家族与回滚行数修改后进入设置保存流程；关闭窗口时冲刷。
- 编辑器字号不受终端字号影响（见[编辑器](editor.md)）。

### 退出与重连

- 进程退出或启动失败时显示底部操作栏；终端输入焦点仍在终端内容区，`Enter` 执行重试/重连。
- 「重新连接」只在已退出或启动失败状态可用；连接中重复触发被忽略。
- 重连后插入「新会话」分隔标记；已有回滚内容保留，但不恢复原进程。
- 进程退出后保持已退出状态，直到用户执行重连或关闭面板。
- 关闭面板、关闭项目或关闭窗口时，待处理的重连请求取消。

### 反馈与状态呈现

- 加载使用遮罩与顶部状态；失败使用底部操作栏；短暂结果使用非阻塞提示。
- 相同提示在 5 秒内不重复弹出；持续错误只更新底部操作栏。
- 状态圆点与 CLI 图标实时反映运行期状态；不以颜色作为唯一信息。
- 退出码、启动失败原因、输入发送失败原因必须可见，不得只记录日志。
- 安全策略忽略的序列（后台 OSC 52、非法 OSC 8 scheme）不向终端程序回显，也不在画面中显示控制序列。
- 日志可记录操作、路径与错误原因，不得记录终端内容、剪贴板内容或凭据。

## 边界与错误

### 空态

- 不存在空面板组：最后一个面板关闭或移出后，面板组由工作区壳自动移除；终端侧不提供面板组级空态入口。
- 项目内没有任何面板时显示项目空态；项目空态由工作区壳契约拥有，终端侧不提供空态入口。
- 终端面板没有空态：连接中显示遮罩，失败显示操作栏，程序清屏后的空白属于终端内容。

### 加载

- 新建与重连显示居中遮罩「正在连接...」；首个非空输出到达时立即隐藏。
- 1500ms 后仍未就绪时隐藏遮罩，改为顶部「正在连接...」状态，终端区域可见但输入进入队列。
- 创建失败在遮罩隐藏前发生时，立即切换为底部错误操作栏。
- 历史会话注入等待期间显示「正在恢复会话...」，不阻塞用户查看已有输出与输入。
- 布局恢复时各终端并行进入连接中；界面在全部会话就绪前保持可交互。

### 错误

| 场景 | 用户可见结果 | 恢复动作 |
|---|---|---|
| 会话创建失败 | 底部操作栏「终端启动失败：<原因>」；首次弹一次提示 | 「重试」「关闭面板」；自动探测模式下提供「改用自动探测重试」 |
| 进程退出 | 底部操作栏「进程已退出（退出码 N）」；不可用时显示 `?` | 「重新连接」「关闭面板」；`Enter` 重连 |
| 输入连续失败 3 次 | 非阻塞提示「终端输入发送失败：<原因>」 | 成功一次后计数清零 |
| 工作目录越界、不存在或无权访问 | 创建失败，原因包含目录与限制 | 修正目录、权限或改用项目根 |
| 项目根不可用 | 创建失败，不继承应用工作目录 | 恢复项目目录或移除项目 |
| Shell 不可用或启动失败 | 创建失败，原因包含 Shell 路径；自动模式列出各候选的失败原因 | 显式选择时修改默认 Shell 或改用自动探测；自动模式检查路径与权限 |
| PTY 达到上限 | 提示「会话数已达上限（64），请关闭其他终端」 | 关闭其他终端后重试 |
| 历史会话恢复失败 | 前台非阻塞提示；后台系统通知「恢复会话失败」 | 导航树重新恢复；其他终端不受影响 |
| 链接打开失败 | 非阻塞提示「无法打开链接」 | 复制链接后手动打开 |
| 剪贴板复制/粘贴失败 | 非阻塞提示 | 重试 |
| OSC 52 超限 | 聚焦时提示已忽略（1MB 上限） | 程序减小负载 |
| 恢复时保存目录失效 | 在项目根启动并提示 | 手动 `cd` 到目标目录 |
| 设置损坏或保存失败 | 提示并回退默认值（细节见[设置中心](settings.md)） | 重新设置 |
| 渲染持续低于性能目标 | 一次性非阻塞提示「终端渲染性能可能下降」 | 关闭部分终端或降低回滚行数 |
| Windows 10 早期版本缺少控制台能力 | 启动时一次性提示；基本输入输出可用，滚轮转发等增强能力不可用 | 升级系统 |

- 错误提示不得包含剪贴板内容、终端输出内容或凭据值。
- 同一错误持续存在时不重复弹提示；状态变化后重新计一次。

### 并发与竞争

- 连接中关闭面板：取消创建，终止已启动子进程，丢弃输入队列与待注入命令。
- 重复重连/重试：连接中只保留一次请求；新失败或退出后重新启用。
- 重连期间尺寸变化：新 PTY 创建后按最新容器尺寸适配一次。
- 退出与关闭同时发生：进入关闭流程后不再显示退出操作栏。
- 历史会话注入等待期间切换项目：注入继续；面板隐藏不取消；面板关闭才取消。
- 多个终端的 OSC 52 写入：按到达顺序串行写入剪贴板，最后一次成功写入生效。
- 并发创建终端：上限检查原子化，任何时刻活动 PTY 不超过 64。
- 窗口关闭期间新建终端：拒绝创建，进入关闭流程。

### 恢复与失效

- 应用重启后恢复布局、编号、自定义标题与工作目录；终端内容、选区、滚动位置、状态与 CLI 元数据不恢复。
- 保存目录失效时回退项目根并提示；项目根也失效时该面板显示启动失败，不静默使用应用目录。
- 布局中的终端数超过 PTY 上限时，前 64 个连接，其余显示失败状态；关闭其他终端后可重试。
- 历史会话恢复失败不影响已打开终端；待注入命令在面板关闭后取消。
- 崩溃后不保证保存最新布局与设置；下次启动按最后一次成功保存的状态恢复，子进程由操作系统清理。
- 终端内容不回放、不持久化、不提供崩溃后的输出恢复。
- 设置损坏时使用默认字号、回滚行数与默认 Shell 自动探测。

### 性能与资源

- 终端 I/O、解析、渲染不得阻塞界面交互；切换项目与面板在任何输出速率下保持可响应。
- 可见终端的小段输出在下一帧内呈现；突发输出合帧不超过 16ms；全屏 TUI 无撕裂。
- 隐藏项目只暂停绘制，仍解析全部输出；输出洪峰时暂停读取 PTY，不丢字节。
- 回滚缓冲内存受行数上限与内容行宽共同约束；所有终端的回滚总量随终端数与配置增长。
- 布局恢复时终端并行连接，界面在全部就绪前可操作。
- PTY 上限 64，防止失控创建；达到上限时明确失败，不拖垮应用。
- 关闭窗口时终端清理不超过 3 秒；不得因单个 PTY 无响应而无限等待。

### 键盘与输入法

- 状态不仅以颜色表达：圆点提供「工作/注意/完成/错误」文本；错误栏提供文字原因。
- 终端操作可仅用键盘完成：切换面板、复制、粘贴、重连、关闭；字号可经设置中心外观页调整。
- 焦点顺序合理，焦点环可见；操作栏打开时焦点进入可操作元素，`Esc` 返回终端。
- 光标闪烁遵守「减少动效」；操作栏不使用强制动画。
- 中文等输入法合成路径必须可用；合成期间不触发快捷键，合成确认不发送额外 Enter。该路径依赖真实系统输入法。
- 终端字号可放大到 32 而不截断关键操作。

### 平台与 Shell 能力

- 仅支持 Windows 10/11；单窗口、单实例、仅暗色模式。
- 自动 Shell 探测链：`pwsh.exe` → `powershell.exe` → `cmd.exe`；设置中心可覆盖默认 Shell。
- PowerShell 会话加载用户 profile 并提供 Shell 集成；cmd 与无集成能力的自定义 Shell 不提供命令边界、自动标题与目录跟踪，历史恢复使用固定等待。
- Windows 10 早期版本缺少所需控制台能力时，应用给出一次性提示并保持基本输入输出；鼠标滚轮转发等增强能力不可用。该限制根因在操作系统版本，不由应用静默绕过。
- 系统默认浏览器、邮件程序与文件关联由操作系统决定；应用只分派允许的 scheme。
- DPI 缩放、多显示器与窗口跨屏移动时，终端重新测量并适配，不出现网格错位。
- Windows 路径大小写不敏感；工作目录校验按系统语义比较。UNC 路径仅在项目根或已登记 Agent 目录内时允许。

### 安全与隐私

- 应用发起的终端工作目录仅限项目根与已登记的 Agent 全局目录；校验基于解析后的真实路径，防止符号链接逃逸允许根。Shell 内部 `cd` 不受此限制，但新终端继承目录时重新校验。
- OSC 8 仅打开 `http`、`https`、`mailto`；其他 scheme 一律忽略，防止本地文件或自定义协议被终端输出触发。
- OSC 52 默认只允许聚焦终端写入，永不响应读取；后台写入需用户显式开启且仅限活跃项目。
- 粘贴包含控制字符或超长多行时要求确认，防止终端输出诱导的粘贴注入。
- 终端内容与剪贴板内容不得写入日志、设置或布局文件。
- 历史会话恢复命令只包含经过校验的会话 ID 与 CLI 契约参数，不拼接终端输出或用户任意文本。
- 自定义 Shell 只接受可执行文件路径，不提供任意启动参数注入入口。
- 终端子进程继承应用环境；日志与错误提示不得输出环境变量、凭据或令牌。
- 权限错误、目录不存在、路径越界必须显式提示，不静默回退到不安全目录。

## 验收判据

### 面板模型与编号

| 场景 | 判据 |
|---|---|
| 单面板单 PTY | 新建终端后，面板内容区只有一个终端画面；一个终端面板只对应一个 PTY，不存在第二个会话或第二套输入输出 |
| 并排终端 | 在两个面板组各新建终端；两个 PTY 独立运行，切换面板组不重建会话 |
| 项目级编号 | 项目 A 依次得到 `terminal-0`、`terminal-1`；关闭 `terminal-0` 后新建得到 `terminal-2`；项目 B 从 `terminal-0` 开始 |
| 编号重启 | 重启应用后终端编号与关闭前一致，不按恢复顺序重算 |
| 页签栏「+」 | 在指定面板组点击；新终端落在该面板组，工作目录符合入口规则 |
| 页签右键新建 | 右键任意终端页签选择「新建终端」；新终端落在同一面板组，工作目录继承被右键终端 |
| 文件树入口 | 对文件打开终端，起始目录为文件所在目录；对文件夹打开终端，起始目录为文件夹自身 |
| Agent 全局文件入口 | 有活跃项目时在活跃项目创建终端；无活跃项目时提示先打开项目，不静默失败 |
| 独立创建 | 同一入口重复点击创建多个独立终端，不复用已有会话 |
| 跨项目拖动 | 将终端面板拖到其他项目被拒绝；原终端 PTY 与画面保持 |
| 上限预检 | 已有 64 个 PTY 时新建终端不产生空面板，并显示上限提示 |

### 入口、Shell 与工作目录

| 场景 | 判据 |
|---|---|
| 自动 Shell | 装有 PowerShell 7 时运行 `pwsh`；仅有 Windows PowerShell 时运行 `powershell`；两者都没有时运行 `cmd` |
| 默认 Shell 设置 | 设置中心选择 cmd 后，新终端使用 cmd；选择不存在的自定义路径时创建失败并显示路径与原因，不静默回退 |
| 自动探测全失败 | 各候选均不可用时创建失败，错误列出每个 Shell 的失败原因 |
| profile | 在 PowerShell 终端中可直接使用用户 profile 定义的函数与初始化命令 |
| 工作目录继承 | 在终端中 `cd` 到子目录后新建终端，新终端起始目录为该子目录（Shell 集成可用时） |
| 显式目录优先 | 文件树入口的目录覆盖继承目录与项目根 |
| 目录越界 | 应用发起的目录在允许根外时创建失败并提示；Shell 内 `cd` 到根外不被应用阻止 |
| 项目根失效 | 项目根不存在且入口未指定目录时创建失败并提示，不使用应用自身目录 |
| 目录持久化 | 终端 `cd` 后重启应用，终端在最近目录启动；目录失效时在项目根启动并提示 |
| cmd 降级 | cmd 终端可正常输入输出；无命令边界与自动标题，状态仅按可用事件更新 |

### 输出、回滚与渲染

| 场景 | 判据 |
|---|---|
| 小段输出 | 单字符回显在下一帧内出现 |
| 突发输出 | 全屏 TUI 高频刷新无可见撕裂，最终内容完整 |
| 隐藏项目不丢输出 | 项目 A 终端产生超过 64KB 输出后切到项目 B，再切回 A；回滚范围内内容完整，不因项目不可见而丢弃输出 |
| 隐藏项目继续运行 | 切换项目后终端进程继续运行并产生输出；切回可见最新状态 |
| UTF-8 边界 | 多字节字符跨输出块到达时无乱码、无错位 |
| 回滚上限 | 将回滚行数设为 2000 并新建终端后，输出超过 2000 行时只保留最新 2000 行 |
| 默认回滚 | 回滚行数为默认值时，输出超过 10000 行只丢弃最旧行 |
| 尺寸顺序 | 尺寸变化前已接收的输出按变化前的网格呈现，尺寸变化后的输出按新网格呈现，无丢弃与错位 |
| 高度变化 | 仅改变窗口高度时行数立即变化 |
| 宽度变化 | 快速连续改变宽度只产生一次最终列适配，延迟约 100ms |
| 初始尺寸 | 容器尺寸在 500ms 内可用时按真实尺寸创建；不可用时先以 80×24 创建，就绪后立即适配 |
| 重连尺寸 | 重连使用当前容器尺寸，不使用过期尺寸 |
| 全屏 TUI 适配 | 改变尺寸后全屏 TUI 完整重绘，无残影、错位或撕裂 |
| 渲染降级 | 硬件加速不可用的环境下终端仍可正常输入输出与滚动，无白屏；界面不暴露渲染器名称 |
| 性能提示 | 持续低于性能目标时仅出现一次「终端渲染性能可能下降」提示，不重复打扰 |
| DPI 变化 | 窗口移动到不同缩放比例的显示器后重新适配，无网格错位 |

### 字号、字体与光标

| 场景 | 判据 |
|---|---|
| 字号范围与持久化 | `Ctrl+滚轮` 或设置中心外观页调整字号，限制在 8–32，默认 14；所有终端同步；重启后恢复最后保存值 |
| 字号边界 | 达到 8 或 32 后继续调整不越界 |
| 字号即时适配 | 字号变化后网格与 PTY 尺寸立即同步，不受列去抖影响，不重启进程 |
| 字体家族 | 设置中心外观页选择等宽字体后所有终端立即生效；重启后恢复；字体缺失时回退主题等宽字体栈 |
| 编辑器隔离 | 调整终端字号不改变编辑器字号 |
| 光标闪烁 | 设置中心终端页关闭闪烁后光标常亮；开启系统「减少动效」时默认不闪烁 |

### 键盘、选区与粘贴

| 场景 | 判据 |
|---|---|
| 基本输入 | 输入文本并回车，Shell 收到并回显 |
| 复制 | 选中文本后 `Ctrl+Shift+C`，系统剪贴板为选中文本；无选区时不改变剪贴板 |
| 粘贴 | `Ctrl+Shift+V` 与 `Shift+Insert` 均把剪贴板文本送入终端 |
| `Ctrl+Enter` | 前台程序收到 0x0A（LF），不是回车 |
| `Ctrl+C` | 前台程序收到 0x03；工作态转为注意态；重复按不产生额外状态变化 |
| 保留键 | 设置中心拒绝把命令绑定到 `Ctrl+C`、`Ctrl+V`、`Ctrl+X`、`Ctrl+Z`、`Ctrl+A` |
| 输入法 | 中文合成文本正常输入；合成期间快捷键不触发；合成确认不额外发送 Enter（人工实机核验） |
| 鼠标跟踪 | 前台程序启用鼠标跟踪时滚轮交给程序；按住 `Shift` 滚轮仍滚动本地回滚 |
| 拖拽选区 | 拖拽可选择文本；开始输入清除选区；软换行复制为连续文本，硬换行保留换行 |
| 粘贴控制字符 | 剪贴板含 ESC 等控制字符时出现确认；取消后终端不收到任何字节 |
| 粘贴多行 | 超过 50 行时出现确认并显示行数；确认后内容按原样粘贴 |
| 粘贴超大 | 超过 10MB 时拒绝并提示，终端不收到内容 |
| 页签重命名 | 页签聚焦时 `F2` 进入重命名；终端输入区聚焦时 `F2` 发送给前台程序；CLI 运行中不进入重命名 |
| 重命名校验 | 空或纯空白提交显示「名称不能为空」；超过 128 字符显示「名称过长」 |

### 链接与剪贴板序列

| 场景 | 判据 |
|---|---|
| OSC 8 悬停 | 悬停显示下划线与包含完整 URL 的工具提示 |
| OSC 8 打开 | `Ctrl+单击` 使用系统默认浏览器打开 `https` 链接；不按 `Ctrl` 单击不打开 |
| 普通 URL | 终端输出中的普通 URL 文本不可点击 |
| 危险 scheme | `file:`、自定义 scheme 不被打开，显示「不支持的链接类型」 |
| OSC 8 超长 | 超过 8KB 的链接被忽略，不打开 |
| OSC 52 聚焦写入 | 聚焦终端收到 OSC 52 后系统剪贴板更新，画面不显示该序列，并出现提示 |
| OSC 52 后台忽略 | 默认设置下，非聚焦终端或隐藏项目终端收到 OSC 52 时不改变剪贴板 |
| OSC 52 后台开关 | 开启「允许非聚焦终端写入剪贴板」后，活跃项目内非聚焦终端可写入；隐藏项目终端仍不可写入 |
| OSC 52 读取 | 程序发送读取请求时永不返回剪贴板内容 |
| OSC 52 超限 | 超过 1MB 的负载不改变剪贴板，聚焦时提示已忽略 |

### 生命周期、退出栏与恢复

| 场景 | 判据 |
|---|---|
| 进程退出 | 执行 `exit` 后显示退出码（0 或非 0 与真实值一致；不可用时为 `?`）与「重新连接」「关闭面板」 |
| 退出后等待 | 进程退出后不进行任何操作，终端保持退出操作栏，不自行启动新会话 |
| 重连 | 按 `Enter` 后得到新的 Shell；已有回滚内容保留并出现「新会话」分隔标记 |
| 启动失败 | 使用不存在或越界目录创建终端时显示「终端启动失败」操作栏与一次提示；按 `Enter` 重试 |
| 重复失败 | 连续重试失败时操作栏更新，不重复弹提示 |
| 关闭面板 | 关闭终端面板后对应 PTY 终止；重新创建得到新编号与新进程 |
| 关闭面板组 | 面板组内全部终端 PTY 终止；运行中终端按工作区关闭守卫确认 |
| 项目删除 | 删除项目需确认；确认后该项目全部 PTY 终止 |
| 窗口关闭 | 先冲刷设置与布局，再终止所有 PTY，无孤儿进程；终端清理阶段不超过 3 秒 |
| 上限恢复 | 布局中终端数超过 64 时，仅前 64 个连接，其余显示失败；关闭一个后可重试成功 |
| 历史恢复 | 历史会话恢复在提示符就绪后注入命令并回车；PowerShell 最长等待 10 秒，cmd 约 0.5 秒 |
| 历史恢复失败 | 前台提示或后台系统通知包含会话 ID 前 8 位与原因；其他终端不受影响 |
| 注入取消 | 注入前关闭面板或进程退出，恢复命令不再发送 |
| 切面板保活 | 同面板组切面板、切换项目后进程、画面、回滚、工作目录、自定义标题与编号保留 |
| 关闭重开 | 关闭后重开为新进程、新编号；自定义标题不保留，工作目录按入口；无显式入口时继承聚焦终端目录或项目根 |
| 应用重启 | 新进程；编号、自定义标题与工作目录恢复；画面、回滚、状态与 CLI 元数据不恢复；不抢焦点 |

### 通知、状态同步与安全

| 场景 | 判据 |
|---|---|
| CLI 标题与图标 | 在 PowerShell 终端运行已注册 CLI，标题变为 CLI 标题，出现 CLI 图标与状态圆点；命令退出后恢复默认标题并清除标记 |
| 自定义标题优先 | 先重命名为「后端」再运行 CLI；标题保持「后端」，CLI 标题只在悬停提示中显示；CLI 退出后仍为「后端」 |
| 四态颜色 | 工作/注意/完成/错误分别显示绿/黄/灰/红圆点，并提供对应可读文本 |
| 状态同步 | 终端标题与状态变化实时反映到导航树活跃会话行；激活该行直接切换到对应项目并聚焦面板，无提示与确认 |
| 失焦通知 | CLI 任务完成或等待输入且窗口失焦时发送系统通知并闪烁任务栏；窗口聚焦时不发送 |
| 通知去重 | 窗口失焦时同类事件在去重窗口内重复触发，只出现一次系统通知与一次任务栏闪烁 |
| 重启状态 | 重启后终端不显示上次的状态圆点或 CLI 图标，直至再次识别到 CLI 会话 |
| 目录沙箱 | 应用发起的目录越界时创建失败；Shell 内 `cd` 不被阻止 |
| 粘贴注入 | 含控制字符的粘贴必须确认；取消后无字节发送 |
| 剪贴板隐私 | 日志与设置中不出现终端内容或剪贴板内容 |
| 键盘可达 | 不使用鼠标可完成复制、粘贴、重连与关闭；字号经设置中心外观页调整 |
| 状态可读 | 状态圆点有文本与名称，错误有文字原因，不以颜色为唯一信息 |
| 减少动效 | 开启系统减少动效后光标不闪烁，操作栏无强制动画 |
| 输入法 | 人工实机核验中文合成输入与快捷键隔离 |
| Windows 10 早期版本 | 启动时一次性提示；基本输入输出可用，增强能力不可用时不影响终端核心功能 |
| 性能 | 多个隐藏项目终端持续输出时界面仍可交互 |

## 关键决策与依据

| 规则 | 原因 | 边界 |

| 一个终端面板只承载一个 PTY；并排终端由多个面板组承载 | 终端身份与 AI CLI 上下文一一对应，避免终端层与工作区层出现两套布局模型 | 面板组拆分、合并与拖拽归工作区壳；跨项目拖动拒绝 |
