# 终端面板

> 拥有逻辑终端、PTY、Shell、输入输出、回滚搜索和命令／Git 补全；工作区关闭、PathPolicy 和系统通知由各自所有者定义。

## 逻辑终端与生命周期

- 一个 Terminal 面板对应一条逻辑终端记录，任何时刻最多一个存活 PTY；面板内不再分屏，并排终端通过 PanelGroup 实现。
- 终端编号按项目分配，从 0 开始且不复用，仅用于 `terminal-N` 显示；它不是逻辑终端或 Panel 身份。
- 自定义标题优先于 CLI 标题和默认编号，最长 128 字符；关闭终端删除其逻辑记录，新建终端不继承已关闭终端的编号、标题或 cwd。
- 项目切换和同组切换不销毁 PTY、画面或回滚；跨面板组移动不重建进程，跨项目移动被拒绝。
- 进程退出后保留当前内存画面并显示退出码和“重新连接／关闭面板”；不自动启动新 Shell。手动重新连接创建新 PTY，保留内存回滚并插入新会话分隔，不恢复原进程。
- 已存在终端的启动或重连失败保留 Panel、错误和重试；显式新建在无法创建可用终端时不留下空 Panel。
- 关闭连接中的终端取消创建并终止已启动子进程；所有 PTY、读写任务和句柄都有显式关闭路径。
- 应用级存活 PTY 上限为 64，只统计存活进程；已退出记录和尚未懒启动的记录不占额度。

## 新建与 cwd

- 默认 Shell 自动探测为 `pwsh.exe` → `powershell.exe` → `cmd.exe`；候选须成功创建并在 500 毫秒稳定窗内未退出。显式 Shell 失败不静默换 Shell，可由用户选择自动探测重试。
- 自定义 Shell 只接受可执行文件路径，不提供参数注入。PowerShell 加载用户 profile，并注入 Shell 集成；`cmd` 按能力降级。
- 交互入口显式目录优先：文件使用父目录，目录使用自身；未提供 cwd 时使用目标项目根，不继承另一终端的 cwd。
- 指定 `project_root` 的外部请求只接受已登记项目；未指定时按 cwd 最深匹配。显式 cwd 不存在、非目录或未授权时拒绝，不回退项目根或活跃项目。
- AgentRoot 只有显式开启终端能力后才能作为 cwd 授权来源；只读授权不等于终端授权。
- Shell 内 `cd` 不被应用限制；应用只跟踪最近 cwd，并在新终端或恢复使用时重新授权。
- 历史会话与启动恢复可在保存 cwd 失效时回退目标项目根并提示；项目根也无效时保留启动错误，不使用应用自身目录。

## 输出、回滚与尺寸

- PTY 输出按顺序解析，跨块 UTF-8 不得产生乱码；隐藏项目和面板只暂停绘制，不暂停进程或丢弃字节。
- 重新可见时显示最新缓冲，不补放中间帧；突发输出按帧合并，洪峰时施加背压而不是丢弃数据。
- 回滚默认 10,000 行，可配置 1,000–100,000 行，超出丢弃最旧行；备用屏内容不进入普通回滚。
- 终端输出、回滚、选区和搜索数据不持久化，也不进入日志、备份或诊断。
- 尺寸变化先按旧网格处理已接收输出，再应用新尺寸并通知 PTY；初始尺寸暂不可用时使用 80×24，容器就绪后立即适配。
- 字号全局共享，默认 14、范围 8–32；字体使用等宽字体族。变化只调整网格和 PTY 尺寸，不重启进程。
- 光标固定竖线，可配置闪烁；减少动效时默认不闪烁。颜色来自主题 ANSI 映射，不提供独立终端配色。
- GPU 不可用时允许软件渲染且功能不变；不得把渲染器名称或性能假象暴露为用户契约。

## 输入、选区与剪贴板

- 普通按键编码发送到 PTY；`Ctrl+C` 始终发送中断，不能被复制或其他命令替换，可增加额外中断键。
- 默认 `Ctrl+Shift+C` 复制选区，`Ctrl+Shift+V`／`Shift+Insert` 粘贴，`Ctrl+Enter` 发送 LF，`Ctrl+Shift+A` 全选。命令绑定由统一目录管理。
- `Shift+方向键`、`Shift+PageUp/PageDown`、`Shift+Home/End` 扩展选区；软换行复制为连续文本，硬换行保留换行。
- 备用屏全选与扩选仅限当前可提供画面；鼠标跟踪启用时普通拖拽与滚轮交给前台程序，`Shift+拖拽` 和 `Shift+滚轮` 强制本地选择与回滚。
- 粘贴优先使用前台程序支持的括号粘贴，不自动追加 Enter。含危险控制字符或超过 50 行须确认，超过 10 MB 拒绝；确认框不展示剪贴板正文。
- OSC 8 只有 `http`、`https`、`mailto` 可经 `Ctrl+单击` 打开；普通 URL 文本不自动识别，超过 8 KB 或其他协议拒绝。
- OSC 52 只写不读；默认仅聚焦且属于活跃项目的终端可写，非聚焦写入须显式开启，隐藏项目始终禁止。单条上限 1 MB，非法编码或超限不修改剪贴板。
- 复制、粘贴和剪贴板错误可见，但日志与提示不得包含剪贴板或终端正文。

## 只读回滚搜索

- `Ctrl+Shift+F` 打开当前终端的只读搜索，搜索普通文本、不区分大小写，提供上一处、下一处和当前／总数。
- 搜索只读取当前终端可提供的回滚与画面，不写 PTY、不修改输出、不改变前台程序状态；备用屏只搜索当前可提供的备用屏内容。
- 当前匹配滚动到可见区域；新输出到达后按最新可提供内容更新或明确使结果失效，不把旧位置当作稳定事实。
- 不提供正则、整词、跨终端搜索、命令块导航、输出导出或内容右键菜单。
- 搜索词、匹配、位置和高亮均为瞬态；关闭重开与重启均不恢复，也不得进入日志、备份或诊断。

## 命令与 Git 补全

### 可信输入与呈现

- 补全默认开启，提供 Inline、Popup、Hybrid；候选只在可信 Shell 输入行工作，接受候选只修改当前输入，不直接执行命令。
- 备用屏、前台应用接管输入、历史召回或光标操作导致行镜像不可信时，不显示补全也不采集历史；不得猜测真实输入行。
- 默认 `Right` 接受 ghost；无弹窗时 `Tab` 可接受 ghost，有弹窗时用于候选导航；`Up/Down` 移动候选，`Enter` 只接受已选候选，无选中项时原样交给 PTY，`Esc` 只关闭可见候选。上述动作纳入统一命令目录。
- 接受后仍需用户显式提交命令；加载中的候选不得因 `Enter` 被当作已接受。

### 来源与方言

- 候选来源限本地命令历史、目录历史、可执行命令、路径、Git refs／remotes 与项目脚本声明；不执行项目脚本，不为补全访问网络。
- PowerShell、Cmd 和原生 Posix Shell 分别解析；未知 Shell 使用字面量规则，不猜测复杂语法，不通过 WSL 获取候选。
- 计算在后台执行；输入、cwd、项目、方言或进程变化时取消旧请求，过期结果不得回填。
- Git 或其他单一来源失败只移除该来源候选，不用无关历史伪装精确结果，也不阻塞终端输入。

### 本地学习数据

- 命令与目录历史默认在本机采集，并在设置中明确披露；历史采集可独立于补全显示开关停用和清空。
- 只记录可信 Shell 行中实际提交的命令和目录事实；备用屏、CLI 交互提示和不可信镜像不记录。
- 数据有界保存，超限时淘汰最旧或低价值项；清空同时取消待写并清除内存数据，不影响 Shell／CLI 自己的历史。
- 历史不进入加密备份、普通设置导出、日志或诊断包；应用不承诺识别命令或路径中的所有秘密。

## CLI 状态与历史恢复

- 已注册 CLI 可通过命令边界、hooks 与状态信号更新标题、图标和工作／注意／完成／错误状态；普通命令不伪造这些状态。
- 自定义标题不被 CLI 覆盖；CLI 运行中不可重命名，结束后恢复默认标题优先级。
- 状态与系统通知按 [系统集成](../system-integration.md) 聚合；隐藏终端可继续产生事件，但不得抢焦。
- 历史恢复只注入经 CLI 能力定义且校验过会话标识的命令；等待 Shell 就绪，失败保留 Panel 与重试，不在关闭后继续注入。
- CLI hooks 信号与 Agent 状态事件不因界面隐藏而停止；终端输出和 AI 会话正文仍不因此落盘。

## 元数据恢复与懒启动

- 应用重启恢复所有未关闭逻辑终端记录及其编号、自定义标题和 cwd；已明确关闭的记录不恢复。
- 可见且关闭前处于运行条件的终端自动创建 PTY；隐藏终端只恢复元数据，首次变为可见时按需启动。
- 关闭前已经退出的终端恢复退出状态和重试入口，不自动运行新 Shell；终端输出与回滚不恢复。
- 恢复或懒启动按确定性顺序检查 64 个存活 PTY 上限；额度不足时保留未启动记录为待启动或错误状态，关闭其他终端后可重试。
- 恢复失败保留 Panel、错误与重试；不得创建重复记录。保存 cwd 失效按恢复例外回退项目根并提示。
- 正常关闭先提交逻辑终端记录，再终止 PTY；最终退出标记失败按工作区规则处理。

## 验收判据

- **Given** 新建终端未提供 cwd，**When** 同项目另一终端位于子目录，**Then** 新终端仍使用项目根；显式非法 cwd 则拒绝。
- **Given** 布局含可见、隐藏和已退出终端，**When** 重启，**Then** 全部记录恢复，只有符合条件的可见终端自动启动，隐藏懒启动，已退出不自动运行。
- **Given** 有 64 个存活 PTY 及更多已退出记录，**When** 再启动一个终端，**Then** 按存活数拒绝且既有记录不丢失；一个 PTY 退出后可重试。
- **Given** 终端隐藏期间持续输出，**When** 重新可见，**Then** 回滚范围内内容连续且只显示最新画面。
- **Given** 备用屏或不可信行镜像，**When** 输入或触发补全，**Then** 不显示候选、不采集历史；可信 Shell 行接受候选后仍需再次提交才执行。
- **Given** 补全请求发出后 cwd 改变，**When** 旧结果返回，**Then** 结果被丢弃；Git 来源失败不影响其他来源。
- **Given** 清空命令与目录历史，**When** 有待写数据，**Then** 待写取消且内存清除，Shell 自己的历史不受影响。
- **Given** 在回滚中搜索普通文本，**When** 前后导航，**Then** 计数与位置更新且 PTY 未收到搜索字节；搜索状态不持久化。
- **Given** 非聚焦或隐藏项目终端发送 OSC 52，**When** 未获对应授权，**Then** 剪贴板不变；读取请求永不返回内容。
