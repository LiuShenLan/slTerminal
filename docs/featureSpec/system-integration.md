# 系统集成

> 拥有托盘、登录启动、窗口几何与材质、更新、界面语言、系统通知、任务栏和诊断；工作区关闭与单实例命令语义归各自所有者。

## 托盘与启动

- 托盘提供恢复窗口与退出；最小化仍到任务栏，关闭窗口始终执行统一退出，不提供关闭到托盘。
- 开机启动开关反映 Windows 实际启动项状态；外部删除或修改启动项后，界面重新对账，不以设置值伪造实际状态。
- 静默启动只用于登录自启且依赖托盘可用；手动再次启动通过单实例移交恢复并前置既有窗口。
- 托盘不可用时不得宣称可静默驻留；相关选项禁用并说明，退出语义不变。

## 窗口几何与材质

- 窗口尺寸、位置、最大化状态与显示器信息按机器持久化；跨机器备份恢复不得把不可见几何直接套用。
- 启动恢复时把离屏窗口夹回当前可见工作区；显示器移除、DPI 或工作区变化后仍保证标题栏与主要操作可达。
- 材质为固定暗色选项：无、Mica、Mica Alt、Aero、Acrylic；默认无。选项不改变主题语义 token，不提供浅色或跟随系统。
- 当前 Windows 版本或渲染能力不支持的材质禁用并说明，不静默宣称生效。

## 自动更新

- 自动检查默认开启，后台下载默认关闭；手动检查始终可用。
- 发布资产必须与当前架构、目标版本和资产类型精确匹配；下载后按发布方声明的完整哈希校验。不匹配、缺哈希或校验失败的资产不得执行。
- 下载不等于安装。安装须用户确认，并先完成统一关闭与状态提交；更新不得绕过脏 Document、存活 PTY 或最终状态失败守卫。
- 新版本成功启动后才标记更新成功；启动或安装失败保留或恢复可用旧版本，并提供错误与重试。
- 不自动降级，不执行来源不明资产，不保存代理凭据，不清除用户数据来“修复”更新。

## 界面语言

- 语言选项为 `System`、`English`、`简体中文`，默认 `System`；系统语言无法匹配时使用 English。
- 应用自有文案即时切换，不重建工作区、不丢失修改；缺失翻译回退 English，不显示内部翻译键名。
- 文件内容、终端与 CLI 输出、路径、品牌、协议字段和日志不随界面语言翻译。

## 系统通知与任务栏

- 桌面通知总开关只控制系统通知；应用内通知仍按各功能规则显示。
- 通知类别为任务完成、等待输入、权限请求和错误。任务栏闪烁是独立开关，且只在窗口失焦时触发。
- 系统通知不重复骚扰；窗口重新聚焦后相关等待提示可清理，应用内错误仍保留到解决或关闭。
- 任务栏聚合优先级固定为：错误 → 等待输入的暂停态 → 工作不确定进度 → 清除。高优先级状态存在时不得被低优先级覆盖。
- 不伪造百分比；无法取得确定进度时使用不确定态。任务结束、取消或应用退出后清理对应进度。

## 诊断与清理

- 诊断包采用明确白名单，导出前显示内容预览与脱敏结果；默认包含版本、系统与运行能力、脱敏日志、错误码和健康状态。
- 默认不包含完整路径、命令／目录历史、终端输出、文件正文、AI 会话、剪贴板、崩溃快照、恢复点、备份、原始内存转储或任何凭据。完整路径须单独显式选择。
- 复制诊断信息采用同一脱敏边界；运行环境自检异步执行，显示通过、失败或不可用及原因，可重跑。
- 普通一键清理逐项列出并二次确认，只清理可安全重建的旧日志、已完成更新下载和不再承担恢复职责的崩溃现场。
- 不得清理活跃恢复快照、恢复点、历史删除隔离区、设置、项目、CLI 文件或进行中任务占用文件。
- 审计日志与普通缓存分开确认；清理失败逐项可见，部分成功不得报告为全部完成。

## 验收判据

- **Given** 用户关闭主窗口，**When** 托盘仍启用，**Then** 应用仍执行统一退出而非隐藏到托盘；托盘退出也走同一关闭链。
- **Given** 窗口记录位于已移除显示器，**When** 启动恢复，**Then** 窗口被夹回可见工作区且主要操作可达。
- **Given** 下载资产架构不符或哈希不符，**When** 校验，**Then** 不安装、不执行，并保留当前可用版本。
- **Given** 更新安装前存在脏 Document，**When** 用户确认安装，**Then** 先完成统一关闭守卫，不以更新为由直接终止进程。
- **Given** 桌面通知关闭而任务栏闪烁开启，**When** 失焦终端请求关注，**Then** 不弹系统通知，但可按规则闪烁；应用内通知仍存在。
- **Given** 错误与工作状态同时存在，**When** 更新任务栏，**Then** 错误优先；工作进度不显示伪造百分比。
- **Given** 切换界面语言，**When** 存在未保存文本和打开的工作区，**Then** 自有文案即时更新且现场不重建，缺译显示 English。
- **Given** 诊断清理涉及活跃快照、隔离区或进行中下载，**When** 预览与执行，**Then** 这些对象不进入删除集合；审计清理需独立确认。
