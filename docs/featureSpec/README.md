# slTerminal 功能需求规格

> 目标态功能需求总览：项目、项目布局、面板组与面板模型，面板与侧栏行为，跨域契约、能力/状态/快捷键矩阵与文档地图。

## 定位与范围

- 本规格描述 slTerminal 的目标态（to-be）功能需求，作为后续详细设计与实现的输入。
- 覆盖终端、编辑器、Markdown、Diff、GitShow、设置中心、导航树、文件浏览器、Commit、Agent 全局文件，以及跨域交互与持久化契约。
- 除“目标术语与当前代码术语的概念映射”外，不描述当前实现状态、代码结构、接口签名、文件清单或测试实现。
- 产品定位约束：Windows 10/11、单窗口单实例、仅暗色模式、GPU 加速渲染、默认 PowerShell 7；不走 WSL。
- 工作区模型为 **项目 → 项目布局 → 面板组 → 面板**：每个项目恰好一个项目布局；项目布局内部可拆分面板组；每个面板组是页签组，可承载多个面板；多项目布局同时存活，切换项目只改变可见性。

## 术语

| 术语 | 定义 |
|---|---|
| 项目 | 顶层容器，对应一个根目录，恰好拥有一个项目布局；项目列表持久化。 |
| 项目布局 | 项目对应的整个网格面板布局；多项目布局同时存活，切换项目只改变可见性。 |
| 面板组 | 项目布局内部的页签组，拥有独立页签栏；可多个、可嵌套、可拆分/合并。 |
| 面板 | 面板组内的一个页签条目，是工作区可承载的最小 UI 单元。 |
| 面板类型 | 封闭集：终端、编辑器、Markdown 文档、Diff、GitShow、设置中心。 |
| 活跃项目 | 主区当前显示的项目；存在项目时恰好一个。 |
| 项目根 | 项目对应的根目录；文件浏览器、Commit、终端默认目录的基准。 |
| 设置中心 | 活动栏底部配置钮或 `Ctrl+,` 打开的项目内设置面板。 |

状态保留矩阵的固定维度：**同面板组切面板 / 切换项目 / 关闭后重开 / 应用重启**。

## 目标术语与当前代码术语的概念映射

下表只用于实现落点参考，不是兼容约束；目标层级与当前实现术语不是一一对应，实现以本规格术语为准。

| 目标术语 | 当前代码中的近似概念 | 说明 |
|---|---|---|
| 项目 | 无直接对应 | 目标态新增的顶层容器；当前实现尚无项目模型。 |
| 项目布局 | 全局工作区布局与会话快照 | 当前为单工作区布局；目标态每项目一份。 |
| 面板组 | 标签页内的分屏树/窗格并列 | 当前没有独立的页签组层级；目标态面板组是页签容器。 |
| 面板 | 标签页（`WorkspaceTab`）或终端窗格（`Pane`） | 取决于面板类型；目标态面板是面板组内的页签条目。 |

## 面板能力矩阵

| 面板类型 | 用途 | 主要入口 | 默认形态 | 脏状态 |
|---|---|---|---|---|
| 终端 | 运行 shell 与编码 CLI；一个面板对应一个 PTY | 导航树、面板组头部 `+`、文件树/Agent 文件的“在终端中打开”、历史会话恢复 | 终端画面 | 无 |
| 编辑器 | 编辑文本文件；`.html`/`.htm` 以源码显示 | 文件浏览器双击、Commit added/untracked、Markdown 本地链接、从文件浏览器拖入编辑器 | 编辑区 | 有 |
| Markdown 文档 | Markdown 源码与渲染两态 | 文件浏览器双击 `.md`/`.markdown`、Markdown 本地链接 | 渲染态 | 有（源码态修改） |
| Diff | HEAD 与工作区双栏或行内对比；冲突快照只读对比 | Commit modified/renamed/conflict、编辑器 Git 行标、编辑器/Markdown 冲突横幅 | 并排双栏 | 有（工作区侧；快照模式无） |
| GitShow | 只读查看 HEAD 内容 | Commit deleted | HEAD 只读内容 | 无 |
| 设置中心 | 应用与 Agent 配置 | 活动栏底部配置钮、`Ctrl+,` | 快捷键页 | 有（Hooks 手动保存；自动保存失败单独标识） |

## 跨域不变量

- **工作区模型**：项目 → 项目布局 → 面板组 → 面板；每项目恰好一个项目布局；空面板组自动移除；禁止跨项目移动面板；新建项目自动成为活跃项目；项目显示名可重命名，重命名允许重名，创建时重名追加后缀；项目身份是稳定 `ProjectId`，根路径词法唯一并做真实路径查重。
- **面板类型**：终端、编辑器、Markdown 文档、Diff、GitShow、设置中心；未知类型恢复时丢弃并聚合警告。
- **文件打开路由**：`.md/.markdown` → Markdown 面板；`.html/.htm` → 编辑器源码，右上悬浮按钮交系统默认程序打开磁盘版本；其他文本 → 编辑器；二进制/不支持 → 错误提示或系统程序打开。自动打开限项目根、仓库实际根与已登记 Agent 全局目录；项目根外、仓库根内的文件以根外只读模式打开；仓库根外仅经 Markdown 显式链接只读打开；系统另存为对话框是显式写入例外。每项目每路径只有一个编辑器视图。
- **Git 仓库根**：Commit、Diff、GitShow、文件浏览器统一使用项目根所在的 Git 仓库实际根；允许项目根为仓库子目录；不自动初始化仓库。
- **焦点**：布局恢复不抢焦；显式打开/激活按面板焦点落点聚焦；只读视图显式打开/点击可聚焦；`Ctrl+Tab`/`Ctrl+Shift+Tab` 在活跃项目面板组的面板间循环焦点；切项目恢复该项目上次聚焦面板；启动不抢焦。
- **脏状态与关闭**：编辑器、Markdown 源码态、Diff 工作区侧、设置中心（Hooks 手动保存）为脏状态来源；单面板提供“保存并关闭”；批量关闭、项目移除、窗口关闭提供“保存全部并关闭”，任一保存失败中止关闭并保留全部面板；关闭链为冲刷设置与布局 → 并发终止 PTY → 保存项目数据，各阶段 ≤3 秒，最坏约 9 秒。
- **持久化**：侧栏布局 500ms；应用设置 2 秒；终端 cwd/编号 300ms；项目布局 2 秒（含 Diff 面板参数）；设置与布局写盘失败必须可见；关闭前强制冲刷。
- **通知**：悬停暂停 + 关闭按钮；终端任务完成/等待输入仅在窗口失焦时发系统通知并去重；错误横幅按各篇规则持久。
- **设置入口**：有项目时设置中心是项目内面板；无项目时配置钮/`Ctrl+,` 打开仅含应用页的全局设置浮层；应用页承载范围外能力的配置入口与保存纪律。
- **单实例**：第二次启动激活并前置已有窗口，可携带仅聚焦/打开项目/打开文件/新建终端意图；目标不存在时提示，不自动创建项目。

| 项目身份 | 稳定 `ProjectId` 是身份；根路径词法唯一并做真实路径查重；显示名可重命名，重命名允许重名，创建时重名追加后缀；项目顺序可拖拽并持久化 | `workspace/navigation.md` |
| 文件视图 | 每项目每路径单一编辑器视图；Commit 来源不产生后缀视图 | `panels/editor.md` |
| 聚焦落点 | 恢复不抢焦；显式打开/激活聚焦；`Ctrl+Tab` 焦点逃逸 | `workspace/shell.md` |
| 关闭安全 | 单面板保存并关闭；批量保存全部；失败保留面板；关闭链分阶段限时 | `workspace/shell.md` |
| 设置作用域 | 每项目一个设置面板，共享全局配置；Hooks 绑定所属项目；`Ctrl+,` 打开/聚焦；无项目时打开仅含应用页的全局设置浮层 | `panels/settings.md` |

## 明确不做

以下为明确不恢复的功能级能力；完整清单、平台/第三方边界与不可自动化面见 [验收与豁免](acceptance.md)。

- 终端：配色方案、搜索、滚动条、滚动锁定、内容右键菜单、扩展选区、全选、`Ctrl+End`、字号快捷键、光标样式、原地重启、文件拖入、命令块、输出导出、自动重连、终端内分屏、输入模式页。
- Markdown：代码块复制/语言标签、公式源码复制、图片放大/复制路径、渲染态右键菜单；Mermaid 首版不渲染。
- 文件树：type-ahead、树内拖拽移动、框选、长操作进度条、监听失效轮询兜底。
- Commit：多选与批量回滚/删除。
- Agent：根层空白区新建/粘贴、节点排序、独立滚动、深层过滤。
- 产品定位约束：Windows 10/11、单窗口单实例、仅暗色、无 WSL；HTML 不渲染；Markdown 两态；终端面板内不分屏。
- 范围外能力：Runtime API、更新链、托盘、开机启动、AI Providers/助手、加密备份、补全、终端增强、界面语言等属于迁移能力；本规格只定义应用页位置、节序、保存纪律与安全红线。
- 其他：外部操作系统文件拖入不支持；Image/Merge 面板不进入封闭集；无障碍专用能力（屏幕阅读器/ARIA/读屏播报/WCAG 校验/高对比度/大字体适配）不提供，保留键盘、焦点、IME/CJK、减少动效。

## 维护规则

- 本规格只记目标态需求与决策依据；不写实现细节、当前状态、过程记录、过程编号、行号或快照数字。
- 契约数值（超时、容量、阈值、尺寸）可保留；用户可见文件路径与外部格式可保留；内部 schema 键、字段名、存储文件名留给详细设计。
- 每篇只定义自己拥有的契约；跨域契约在所有者篇更新，其他篇引用。
- 修改功能行为时同步更新对应功能篇、状态/快捷键矩阵与 `acceptance.md` 的明确不做清单。
