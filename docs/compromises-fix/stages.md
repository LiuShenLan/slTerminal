# 妥协修复 Stage 划分（stages）

> 配套：`checklist.md`（44 项六段式明细，修复步骤唯一真值源）、`execution-plan.md`（编排参数）、`workflows/verify/stage-NN.md`（逐 Stage 机械断言）。
> 本文只写：每 Stage 的 ID 列表、agent 分工表（证明文件不重叠）、实现要点（项目坑引用）、验证项口径、commit message。修复步骤细节一律回查 checklist.md 对应 CP 条目，本文不复制。

## 全局约定

- **Stage 串行**，每 Stage 完成后跑该 Stage 门禁 + verify 断言，全绿后 commit 再进下一 Stage。
- **Stage 内并行 agent ≤5，两并行 agent 禁止改同一文件**；共享文件冲突在分工表「定序/冲突约定」列显式化解（并入同 agent 或子波次串行）。
- **L1 定向测试命令形态切换（全册适用）**：S02 完成**前** = `cargo test --test lib_tests <filter> -- --test-threads=1`；S02 完成**后**该形态失效，恢复 `cargo test <filter> -- --test-threads=1`。各 Stage verify 已按此时点书写。
- **文档同步前置**：各 Stage 同步本 Stage 触及的登记点原文（ADR / 模块 CLAUDE.md / test-exemptions.md），S12 只做 compromises.md 销项总扫 + 一致性抽查。
- **compromises.md 销项勾选统一收口**：条目内「docs/compromises.md 勾选销项」步骤（CP-001/045/029 等散见）一律由主 agent 在该 Stage verify 全绿后、commit 前执行，**不进任何并行 agent 分工表**（防多 agent 并行撞同一文件；销项是状态确认不是修复动作）。
- **测试纪律**：并行 agent 不跑共享资源冲突的测试（PTY/端口/全局锁），重构期只做编译级检查（`cargo test --no-run` / `npx tsc --noEmit`），真实执行由全量测试 agent 单点跑；cargo 系命令共享 target 锁，排队属正常勿中止。
- **门禁补充**：触及 tsc include 外文件（`e2e-tests/**`、`scripts/**`）的 Stage，门禁补 `npx vite build` 或脚本直跑验证。
- 每项的六段式明细（位置/现状/步骤/测试/文档/验证）见 `checklist.md` 同名 CP 条目；>150 行大代码块以「照抄 review-NN 步骤 X.Y」指针引用，review 文件在 `docs/compromises-fix/` 同目录。
