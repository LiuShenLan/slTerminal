# 03 域 — 历史会话（扫描 / 删除 / 恢复 / 聚合 UI）

> 总规格：`docs/spec/multi-cli/00-需求规格.md`（决策 D6/D10）。现状基线：`docs/analysis/03-claude-history.md`（24 项全量盘点）。

## 1. 域范围与分层结论

| 层 | 内容 | 抽象结论 |
|----|------|---------|
| **provider 接口层（泛化）** | HistoryProvider trait（scan/delete/validate_session_id）、`agent_history_scan/delete` 命令、`AgentHistorySession` DTO、恢复编排四步框架、聚合 UI（三下拉框/懒加载/组默认收起/展示派生纯函数） | 泛化为 CLI 无关机制 |
| **claude provider 实现（专属保留）** | 扫描根 `~/.claude/projects`（03-1）、存储布局假设（03-2）、排除规则（03-3）、双窗口轻量解析（03-5）、可见 prompt 判定（03-6）、标题回退链（03-7）、cwd 解析/孤儿判定（03-9）、删除范围（03-11）、`claude --resume` 命令构造（03-13/15） | 全部归 claude provider，行为零改动 |
| **通用安全/容错（机制保留）** | `is_uuid_filename`（03-4）、双窗口解析手法（03-5）、降级条目契约（03-8）、SEC-05 校验模式（03-10）、删除流程（03-20） | 作为 provider 可复用工具/契约保留，供未来 CLI provider 复用 |

## 4. 边界条件

1. **provider 扫描性能**：聚合 scan 串行遍历各 provider（每 provider 内部已有双窗口轻量解析）；未来多 provider 时可改并行——一期单 provider 不引入复杂度。
2. **空扫描根**：claude provider 根不存在 → 空数组（现状 BE-02 保留）；聚合层在全部 provider 返回空时返回空数组（UI 空态「暂无历史会话」不变）。
3. **降级条目**：单文件解析失败 → 降级条目（仅 sessionId+cliId+mtimeMs，title=null）语义保留；title 为 null 时行展示 sessionId 前 8 位（现状保留）。
4. **运行中会话操作冲突**：「二次 resume 冲突」外部假设（03-16）为 claude 语义，保留在 claude profile 的菜单策略注释中；抽象层的「运行中禁删除」通用矩阵不依赖该假设。
