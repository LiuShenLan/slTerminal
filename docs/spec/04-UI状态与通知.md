## 5. 边界条件

1. **matchedCommand-only 会话**：OSC 133 通道建行但无 hooks 事件流——四态恒 🟡（attention）、用量 `--`、无 sessionId；现状语义保留，不视为缺陷（见 01 域已知限制表）。
2. **终端内 CLI 切换**：同一终端先跑 claude 后跑其他 CLI——OSC 133 C 每次命中即更新 agentSession.cliId（现状 matchedCommand 覆盖语义的自然延伸）；hooks 事件到达时按 MC-205 以 payload.cliId 优先（防反查到已切换的旧 cliId）。
3. **未知 cliId 事件**：payload.cliId 未注册 → console.warn + 跳过（不建行、不置图标、不通知），不抛异常（MC-206 一致）。
4. **中断滞留 ⚡ 自愈**：claude 中断不发 hook 事件的已知行为（panels/CLAUDE.md 中断场景节）为 claude 语义，保留在 claude profile 注释；四态状态机本身不引入中断出边。
